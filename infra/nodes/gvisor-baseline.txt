# gVisor security baseline version (SEC-002 P-04).
#
# The first non-comment line is the baseline. Node admission (gate A) compares
# `runsc --version` against it; a node below the baseline does not join the pool
# and one already in the pool is drained.
#
# The baseline must be upstream's latest release or the one before it (N or N-1)
# and must not have been published more than 90 days ago. .github/workflows/
# gvisor-baseline.yml checks that daily and opens an issue when it drifts; the
# 24h escape-CVE SLA under sandbox isolation and execution security starts from that issue being opened.
#
# `unset` = no baseline chosen. The daily check skips instead of failing, and
# IaC rendering an unset baseline is fail-closed: the admission probe has
# nothing to compare against, so no node is admitted.
#
# CI's Suite 1 installs exactly this version, and P-03 rebuilds the node pool
# at this version or newer rather than upgrading nodes in place.
#
# The `sha512` lines pin gvisor.tar.zstd per architecture. Installers compare
# the download against these reviewed values, never against a checksum served
# next to the tarball. Bump both lines together with the release.
