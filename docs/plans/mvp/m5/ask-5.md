# 問 5 個人：搜不到之後，他們真的會想做一個嗎

- 依據：[ADR-053](../../../adr/ADR-053-the-assumption-under-m5-gets-its-own-five-people.md)（本題脫離 D 日、成為 M5 的投入上限）
- 要驗的假設：[ADR-046](../../../adr/ADR-046-generating-a-skill-from-a-task-description.md) 的整個前提——**使用者找不到現成的東西時，會想要一個被做出來**
- 現況：**這個假設至今零證據**
- 成本：5 人 × 5～8 分鐘，**不需要產品、不需要 D 日、不需要凍結**

## 1. 為什麼是回溯訪談，不是給他看畫面

閘門版（[moderator-guide §3.D](../gate-test/moderator-guide.md)）問的是「**看到我們的無結果畫面之後**你會怎樣」。這一版問的是「**上次在真實生活裡**找不到，你做了什麼」。

差別不只是時程：**ADR-046 賭的是一種人的性質，不是我們某一版 UI 的反應**。回溯版完全不被我們的畫面定錨，所以對「這種人想不想要一個東西被做出來」這件事，它其實是更乾淨的證據。

**兩者互補，都保留。** 閘門版驗的是入口設計（`GEN-004`），這一版驗的是前提本身。

## 2. 找誰

**5 人，從 [recruit.md](../gate-test/recruit.md) 的候補名單取，不動正式 9 人。**

分層直接用 recruit.md §3 的 **Q2 一題**（那一題單獨就是分層器）：

| 目標 | Q2 選項 | 人數 |
| --- | --- | --- |
| 學習者 | **A**（用過 AI 助理，沒裝過也沒寫過這種東西） | **3** |
| 改善者 | **B**（裝過或複製過別人的，小改過幾句） | **2** |
| 精深者 | C | **0**——他本來就會自己寫，問他等於問一個已知答案 |
| — | D（沒用過 AI 助理） | 排除 |

> ⚠️ **被問過的人不能再當閘門受測者**（`m4/README §5.3` 理由②：看過的人就不再是第一次）。這是本題唯一的成本，所以從候補取。

## 3. 腳本（照著唸，三題，不加不減）

> 開場：「想請教你一件跟工作習慣有關的事，大概五分鐘，沒有對錯，我只是想知道實際上發生什麼。」

**Q1（定錨，不記分）**
> 「最近一次你想讓 AI 幫你處理某件**會重複發生**的事，是什麼事？」

（等他講完。**不要**幫他補例子。他想不出來就換一個人。）

**Q2（分支條件）**
> 「那件事你有沒有去找過現成的東西——別人寫好的指令、模板、外掛之類的？找到了嗎？」

- 找到了 → 「那如果**沒**找到呢，你會怎麼辦？」（轉 Q3，記為**假設性回答**，見 §4）
- 沒找到 → 直接 Q3

**Q3（主問，這是唯一計分的一題）**
> 「找不到之後，你做了什麼？」

**問完就等。不補充、不換句話說、不遞台階。** 停頓十秒是正常的。

## 4. 絕對禁止

1. **不得出現這些詞**：生成、做一個、Skill、Skill Hub、平台、產品、幫你寫。**一次都不行。**
2. **不得給選項。** 「你是自己弄還是找別人？」這種二選一會製造一個他沒有的答案。
3. **不得追問「為什麼不自己做一個」。** 那是把答案塞進他嘴裡。
4. **主持人一旦違反上述任一條，該人記 `contaminated`，不計入 5 人。**
5. Q2 走「找到了」分支的，其 Q3 記為**假設性回答**——**它不計入決策門檻**，只當質性材料。**需要 5 筆真實經驗**，不足就再找人。

## 5. 記錄

每人一列，逐字。

| 欄 | 內容 |
| --- | --- |
| `layer` | `learner` ／ `improver`（Q2 選項 A／B） |
| `task_raw` | Q1 的原話 |
| `searched` | 有找 ／ 沒想到要找 |
| `real_or_hypothetical` | `real`（Q2 沒找到）／ `hypothetical`（Q2 找到了） |
| **`next_step_raw`** | **Q3 的逐字原話**——這是唯一真正重要的一欄 |
| `next_step_class` | 見下 |
| `contaminated` | 主持人破功時填，並寫明破在哪一句 |

`next_step_class` 六態**與 [gate-test/recording-sheet.md](../gate-test/recording-sheet.md) 第 9 欄逐字相同**，好讓兩批資料可以並排讀：

`build_it_himself`／`ask_ai_to_build`／`rewrite_query`／`other_site`／`give_up`／`dont_know`

> **只有受訪者自己先講出來才算。** 「我就自己打一長串指令貼給它」＝ `build_it_himself`；「我叫它幫我寫一個提示詞模板」＝ `ask_ai_to_build`；「就算了，自己手動做」＝ `give_up`。

## 6. 門檻（**在問之前就定好，不在看到答案之後**）

**分母是 `real` 且未 `contaminated` 的那 5 筆。**

| 5 人中自發落入 `build_it_himself`／`ask_ai_to_build` | 處置 |
| --- | --- |
| **0** | **假設沒有支持。** M5 停在契約層，**重開 [ADR-046](../../../adr/ADR-046-generating-a-skill-from-a-task-description.md)**——那不是延期，是那份 ADR 的前提沒有成立 |
| **1～2** | **弱訊號。** [ADR-053](../../../adr/ADR-053-the-assumption-under-m5-gets-its-own-five-people.md) 決策 2 的投入上限維持，等閘門的 in-context 版本再決 |
| **3 或以上** | **解除投入上限**，`GEN-002`～`011` 可做。**曝光旗標不解除**——它綁的是漏斗讀數，與本題無關 |

**n=5 是方向性的，不是統計的。** 0 與 3 之間的區別是方向不是顯著性，本表已按這個限制設計。

## 7. 問完之後

1. 5 筆逐字記錄落 `m5/report-ask-5.md`（格式照 §5 的欄位）。
2. 回寫 [m5/README.md](README.md) §前期驗證的第 2 列，與 [ADR-046](../../../adr/ADR-046-generating-a-skill-from-a-task-description.md) §0。
3. 依 §6 的門檻決定 `GEN-002`～`011` 動不動。
4. **閘門那一題不刪**——它驗的是入口設計，和這一題不是同一件事。[moderator-guide §3.D](../gate-test/moderator-guide.md) 已註明這 5 人不在正式 9 人裡，所以閘門當日不會有人被問第二次。
