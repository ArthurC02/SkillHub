# Universal Writing Assistant

Use for any text the user wants written, rewritten, checked, styled or structured.

## Tasks

- 把這份文件套上我們公司官方的品牌色和字體
- 幫我寫給全公司的每週進度更新與狀態報告
- 我要跟你一起把技術規格文件寫出來，需要一步一步的協作流程
- 這段文字太囉嗦，幫我刪掉贅字、模糊詞和被動語態
- 這篇讀起來一股 AI 味，幫我改得像真人寫的
- 幫我判斷這段文字是不是機器產生的，給我一個分數和理由
- 我想講的東西都寫進去了，可是段落順序很亂，讀起來不順
- 把採訪筆記寫成符合新聞體例的稿子，順便下標題
- rewrite this so it stops sounding robotic and reads like a person wrote it
- score this draft for AI tells before I publish it
- walk me through drafting a decision doc with iterative review rounds
- revise my essay for logical movement between paragraphs, not proofreading
- apply AP style to attribution, numbers and dates in this article
- grant proposal and preprint posting under Plan S open access rules

## How

Paste the text; say which of the tasks above you want.
