## 目的
將一份英文使用手冊完整翻譯為繁體中文，保留原文的技術含義、操作順序與格式結構；專有名詞第一次出現時，需在中文後附上原文。

## 翻譯原則
1. **完整翻譯，不摘要、不改寫**：所有標題、段落、步驟、警告、註解、表格內容、圖說、按鈕名稱、選單名稱與頁首頁尾文字都要翻譯。
2. **保留結構**：維持原手冊的章節層級、編號、項目符號、表格欄位、注意事項與順序。
3. **專有名詞首次附原文**：
   - 第一次出現時寫成「繁體中文譯名（Original Term）」。
   - 之後同一名詞只用一致的中文譯名即可。
   - 若原文本身就是品牌、型號、介面按鈕或不可翻譯字串，保留原文，必要時可加中文說明。
4. **術語一致**：同一術語在全文使用同一譯法；若有多種可能譯法，優先採用手冊上下文中最一致、最易理解的譯名。
5. **不擅自補充**：不要加入原文沒有的說明、註解或例子；若遇到不清楚的術語，保留原文並以括號標示，避免誤譯。
6. **單位與數值**：數字、單位、版本號、錯誤碼、路徑、命令、程式碼、網址、型號通常保留原樣；必要時可在中文中調整語序，但不可改變數值。
7. **介面文字**：按鈕、選單、欄位名稱若是產品介面的一部分，優先保留原文並在首次出現時附中文譯名，除非已有明確且一致的官方中文介面譯名。
8. **警告與注意**：保留原文的強調程度，例如 WARNING、CAUTION、NOTE 等，並翻成對應的繁體中文標示。

## 工作流程
1. 先通讀整份手冊，辨識：
   - 章節結構
   - 重複術語
   - 專有名詞、產品名、功能名、介面字串
   - 表格、清單、警告、步驟與圖說
2. 建立一致的術語譯法，並在首次出現時加上原文。
3. 逐段翻譯，保持原有格式與順序。
4. 檢查全文：
   - 是否有漏譯段落
   - 是否有術語前後不一致
   - 是否所有首次出現的專有名詞都附了原文
   - 是否保留了編號、項目符號與表格結構
5. 若原文含糊或可能有歧義，優先忠實呈現原文語意，不要自行推測。

## 輸出要求
- 只輸出翻譯後的繁體中文內容。
- 保留原手冊的標題層級與格式。
- 專有名詞首次出現時使用「中文（原文）」格式。
