# 新人到職流程

依照流程圖，按順序執行以下步驟；不要跳步，也不要重排。

1. **收到新人到職通知**
   - 確認已收到新人到職訊息，並開始啟動 onboarding 流程。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱可正常登入與收發郵件。

3. **加入 Slack 頻道**
   - 將新人加入公司指定的 Slack 頻道。
   - 確認新人可看到必要的團隊與公告資訊。

4. **準備筆電與門禁卡**
   - 準備並交付新人所需的筆電與門禁卡。
   - 確認設備與權限可用。

5. **安排第一週訓練**
   - 安排新人第一週的訓練內容與時程。
   - 確認相關課程、會議或帶領安排已通知到位。

6. **指派導師**
   - 為新人指定一位導師或帶領人。
   - 確認新人知道聯絡對象與協助方式。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備回饋、適應狀況與後續支持事項。

8. **記錄到人資系統**
   - 將上述完成狀態與關鍵資訊記錄到人資系統。
   - 確認資料已保存且可追蹤。

## 執行原則
- 以流程圖順序為準：收到通知 → 建立信箱 → 加入 Slack → 準備設備與門禁卡 → 安排第一週訓練 → 指派導師 → 第 30 天面談 → 記錄到人資系統。
- 若某一步尚未完成，先補齊該步驟，再進入下一步。
- 若需要實際系統操作、帳號建立或權限設定，僅執行你有權限且可完成的部分；其餘事項應整理成待辦並通知負責人。
