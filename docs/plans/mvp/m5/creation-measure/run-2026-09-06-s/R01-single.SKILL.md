# 目的
把會議逐字稿整理成可執行的待辦清單，每一條都要包含：
- 待辦事項
- 負責人
- 期限

# 處理原則
1. 只根據逐字稿內容整理，不要自行補充不存在的資訊。
2. 若逐字稿中有明確提到負責人或期限，就直接整理出來。
3. 若有待辦但沒有明確負責人或期限，仍要列出，但標註「未指明」或「待確認」。
4. 若同一事項被多次提及，合併成一條清楚的待辦。
5. 若內容只是討論、背景說明、意見交換，且沒有形成行動項目，不要列入待辦。
6. 若期限是相對時間（例如「下週五前」、「月底前」），原樣保留；不要擅自換算成日期，除非逐字稿已提供可唯一確定的日期基準。

# 整理步驟
1. 通讀逐字稿，標記所有明確的行動項目。
2. 對每個行動項目確認：
   - 要做什麼
   - 誰負責
   - 何時完成
3. 將口語化描述改寫成簡潔、可執行的待辦語句。
4. 若一條待辦包含多個子任務，拆成多條，前提是逐字稿能支持拆分。
5. 若負責人只出現職稱、部門或暱稱，照原文保留；必要時在括號補充原文線索。
6. 若期限不明確，寫「待確認」。

# 輸出格式
使用以下格式輸出，保持簡潔一致：

- 待辦事項：...
  負責人：...
  期限：...

# 補充規則
- 若逐字稿中有會議決議、下一步、follow-up、action item、請某人處理等語句，優先視為待辦。
- 若同一事項有多位負責人，列出所有明確提到的人；若是共同負責，可寫「共同負責：A、B」。
- 若期限只說「盡快」或「這週內」，原樣保留，不要改寫成更精確的時間。
- 若完全找不到任何待辦，輸出「未找到明確待辦事項」。
