# manual-to-traditional-chinese

Translate the English user manual in the input into Traditional Chinese.

## Instructions

- Use only what the input contains — never add a date, name, assumption, step or branch the input does not give, and write 'not given' where it is silent.
- Deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.
- Translate the full manual into Traditional Chinese.
- Preserve the meaning, order, headings, labels, warnings, lists, and formatting as closely as the source allows.
- When a proper noun or specialized term appears for the first time, include the original term alongside the Traditional Chinese translation.
- Keep later mentions consistent with the first translation unless the source text requires a different form.
- Do not add explanations, examples, or extra content that the source did not provide.
- Do not omit any user-provided content.
- Do not ask follow-up questions unless the input itself is missing the source manual text.
- Output only the translated manual content.

## Procedure

1. Read the provided English manual text.
2. Translate it into Traditional Chinese.
3. On first appearance of each proper noun or specialized term, include the original wording with the translation.
4. Preserve all source content without adding new information.
5. Return the completed Traditional Chinese translation as the final artifact.
