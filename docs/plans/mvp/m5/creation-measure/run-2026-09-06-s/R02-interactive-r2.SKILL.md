# 目的
處理使用者提供的 Excel 客戶名單：去除重複列，並標記缺少電話的列。

# 適用時機
當輸入是 Excel 或可轉成表格的客戶名單，且需求明確包含「去重」與「標記缺少電話」時使用。

# 執行原則
- 不新增輸入沒有提供的欄位；若需要標記，只能使用分開且明確的標記欄位。
- 輸出只能包含原始欄位與必要的標記欄位；不得使用「備註」或其他未定義欄位。
- 去重與缺少電話是兩種不同判定，必須分開標示，不可用同一欄混寫成單一狀態。
- 若使用者沒有指定去重依據，先停止處理並回覆確認問題，請使用者指定要用哪個欄位或哪些欄位判定重複。

# 操作步驟
1. 讀取使用者提供的表格資料。
2. 判定去重依據。
   - 若輸入已明確指定去重規則，直接依該規則處理。
   - 若輸入沒有指定去重規則，先停止處理並回覆一個簡短確認問題。
3. 去除重複列。
   - 先列出哪些原始列被判定為重複，再輸出保留後的結果。
   - 在輸出中以明確標記區分保留列與重複列。
4. 標記缺少電話的列。
   - 以輸入中既有的電話欄位為準。
   - 電話值空白、缺值或等同缺失時，必須在表格中明確標記為缺少電話。
   - 缺少電話的標記不得依賴備註欄。
5. 保留原始主要欄位資訊。
   - 輸出必須仍是可直接閱讀的表格結果。
   - 只保留輸入提供的欄位與必要的標記欄位。
6. 輸出完成後，交付整理後的結果本身，並讓每個被標記的列直接可辨識。

# 輸出要求
- 以表格或可直接轉成表格的結構輸出。
- 明確顯示哪些列被去重後保留，哪些列被視為重複。
- 明確顯示哪些列缺少電話。
- 不要只做描述性回覆；要提供整理後的成品。
