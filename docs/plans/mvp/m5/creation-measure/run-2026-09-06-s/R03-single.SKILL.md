# 每日新聞摘要寄信

## 適用情境
當使用者要你每天早上從三個新聞網站整理標題，濃縮成 5 條摘要，並寄到指定信箱時使用。

## 先確認的資訊
在開始前，確認以下內容是否已提供：
1. 三個新聞網站的網址或名稱。
2. 收件人信箱地址。
3. 寄送時間與時區。
4. 摘要語言與語氣偏好。
5. 是否只取標題，或也可參考內文。

如果缺少任何一項，先向使用者詢問，不要自行假設。

## 執行流程
1. 取得三個新聞網站當天的標題。
2. 去除重複、過度相似、廣告或非新聞內容。
3. 依主題與重要性整理成 5 條摘要。
4. 每條摘要要簡短、清楚、可直接讀懂。
5. 若三個網站的內容有明顯衝突，保留差異，不要自行判定真假。
6. 將摘要整理成適合寄信的格式，包含：
   - 主旨
   - 5 條摘要
   - 必要時附上來源網站名稱

## 摘要原則
- 優先保留最新、最重要、最具代表性的標題。
- 同一事件來自不同網站時，可合併成一條摘要。
- 避免逐字抄寫標題；改寫成更精簡的中文摘要。
- 若可用資訊不足以形成 5 條有意義的摘要，明確說明不足之處，不要硬湊。

## 寄信前檢查
在準備寄出前，確認：
- 收件人地址正確。
- 摘要數量為 5 條。
- 內容沒有明顯錯字或重複。
- 主旨能反映「每日新聞摘要」。

## 若無法直接完成
如果目前環境無法存取即時網站、無法登入郵件服務，或沒有寄信權限，請不要假裝已完成。改為：
1. 說明缺少的存取能力。
2. 列出你已整理出的摘要草稿或需要使用者提供的資訊。
3. 請使用者提供可用的網站內容、RSS、或郵件發送方式後再繼續。
