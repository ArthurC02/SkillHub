# 目的
清理 Excel 客戶名單：去除重複資料，並標記缺少電話的列。

# 適用情境
當你拿到一份 Excel 名單，需要：
1. 找出並移除重複客戶資料。
2. 標記電話欄位空白、缺值或明顯無效的列。

# 執行步驟
1. **確認欄位結構**
   - 找出代表客戶識別的欄位，通常是姓名、公司、Email、電話或其組合。
   - 找出電話欄位名稱，確認是否有多個電話欄位（例如手機、公司電話）。
   - 若沒有明確的唯一識別欄位，優先以「姓名 + 公司 + 電話」或「姓名 + Email」作為判定重複的依據。

2. **先備份原始檔**
   - 在不覆蓋原始資料的前提下另存一份副本。
   - 後續所有清理都在副本上進行。

3. **標記缺少電話的列**
   - 新增一欄，例如「電話狀態」或「缺少電話」。
   - 對每一列檢查電話欄位：
     - 若空白、只有空格、只有符號、或內容明顯不是電話號碼，標記為「缺少電話」。
     - 若有有效電話，標記為「有電話」或留空，依需求一致處理。
   - 若有多個電話欄位，任一欄有有效電話即可視為已提供電話；全部都缺失才標記缺少電話。

4. **定義重複規則**
   - 先決定重複判定方式，並全表一致使用。
   - 建議優先順序：
     1. Email 相同視為重複。
     2. 若沒有 Email，則以「姓名 + 公司」或「姓名 + 電話」判定。
     3. 若資料品質較差，可用「姓名 + 公司 + 電話」綜合判定。
   - 若同一客戶有多筆資料但電話不同，保留資訊較完整的一筆。

5. **去除重複資料**
   - 先依重複規則排序或檢視，找出重複群組。
   - 每組重複資料只保留一筆。
   - 保留原則：
     - 優先保留欄位最完整的一筆。
     - 若完整度相同，保留最早出現的一筆。
   - 刪除前先確認是否有特殊情況，例如同名不同人、同公司不同聯絡人。

6. **檢查結果**
   - 確認重複筆數已減少，且沒有誤刪不同客戶。
   - 確認缺少電話的列都已被正確標記。
   - 抽查幾筆重複與缺電話案例，驗證規則是否符合預期。

7. **輸出整理後檔案**
   - 保留原始欄位。
   - 若有新增「電話狀態」欄位，保留在結果檔中。
   - 另存為新檔，避免覆蓋原始資料。

# 注意事項
- 如果資料中有格式不一致的電話號碼，先統一格式再判斷是否缺失。
- 如果欄位名稱不明確，先人工確認哪一欄是電話欄。
- 若無法可靠判定重複，應先列出疑似重複群組供人工確認，而不是直接刪除。
