# 目的
將一週內的每日花費整理成清楚的表格，逐筆標示類別，並在週末產出各類別合計與總計。

# 適用情境
- 使用者提供一週的花費明細，想整理成表格。
- 使用者要求每筆支出都要有類別。
- 使用者要求週末或週結時，按類別加總。

# 處理流程
1. **先確認資料範圍**
   - 找出是否涵蓋 7 天，或明確的一週區間。
   - 若日期不完整，仍依使用者提供的日期順序整理；不要自行補資料。

2. **整理每筆花費**
   - 將每筆支出拆成以下欄位：
     - 日期
     - 星期
     - 項目/用途
     - 類別
     - 金額
   - 若使用者未提供類別，根據用途歸類到最合理的類別。
   - 類別名稱要一致，避免同義詞混用；例如「餐飲」不要同時寫成「吃飯」與「外食」。

3. **建立每日表格**
   - 依日期排序。
   - 同一天有多筆支出時，逐筆列出，不要合併，除非使用者明確要求合併。
   - 若某天沒有支出，保留該日期並標示「無支出」或留空，視輸出格式一致處理。

4. **週末彙總各類別合計**
   - 將整週所有支出依類別加總。
   - 產出一個「類別合計」區塊，至少包含：
     - 類別
     - 合計金額
   - 再產出整週總支出。
   - 若使用者要求，也可補上每日小計，但核心必須有類別合計。

5. **檢查一致性**
   - 確認所有金額加總後，等於各類別合計再加總的總支出。
   - 若有無法判定的項目，標示為「未分類」並保留在合計中。

# 輸出格式
使用表格輸出，建議分成兩段：

## 1. 每日花費明細
| 日期 | 星期 | 項目/用途 | 類別 | 金額 |
|---|---|---:|---:|---:|
| 2026-09-01 | 一 | 早餐 | 餐飲 | 60 |

## 2. 週末類別合計
| 類別 | 合計金額 |
|---|---:|
| 餐飲 | 420 |
| 交通 | 180 |
| 其他 | 90 |
| 總支出 | 690 |

# 類別整理原則
- 優先使用使用者原本提供的類別。
- 若沒有類別，依內容推定常見類別，例如：
  - 餐飲：早餐、午餐、晚餐、飲料、點心
  - 交通：捷運、公車、計程車、油費、停車費
  - 生活用品：清潔用品、日用品、衛生紙
  - 娛樂：電影、遊戲、訂閱、聚餐娛樂
  - 其他：無法明確歸類者
- 若一筆支出同時涉及多個用途，依主要用途歸類；必要時可在項目欄補充說明。

# 注意事項
- 不要自行捏造不存在的花費。
- 不要省略任何使用者提供的支出項目。
- 若金額單位不一致，先統一成同一貨幣再整理；若無法判定，先保留原單位並提醒使用者。
