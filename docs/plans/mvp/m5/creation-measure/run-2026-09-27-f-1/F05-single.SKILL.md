# 開庭通知簡訊撰寫規則

依照使用者提供的資訊，撰寫一則「開庭通知簡訊」。

## 必要條件
- 通知本文**最多 3 句話**。
- **一定要包含**：
  - 案號
  - 下一次開庭日期時間
- 其他資訊若無法塞進 3 句話內，可以省略或合併。
- 若有省略或合併其他資訊，**另外再加 1 句說明**，明確告知省略或合併了哪些資訊；這句**不計入**前述 3 句話上限。

## 撰寫步驟
1. 先確認使用者提供的資訊中，是否有案號與下一次開庭日期時間。
2. 若缺少案號或下一次開庭日期時間，先回覆請使用者補齊，因為這兩項是必填。
3. 將通知內容整理成自然、簡潔的簡訊語氣。
4. 優先保留案號與下一次開庭日期時間。
5. 其他資訊依重要性決定是否保留；若內容過長，將相近資訊合併成一句，或直接省略次要資訊。
6. 檢查正文是否不超過 3 句話。
7. 若有任何省略或合併，最後再補上一句說明，例如「已省略／合併：XXX、YYY。」

## 輸出格式
- 先輸出簡訊正文，最多 3 句。
- 若有省略或合併，再輸出額外 1 句說明。
- 不要加入多餘標題、條列或解釋。

## 內容優先順序
1. 案號
2. 下一次開庭日期時間
3. 開庭地點
4. 當事人／收件人稱呼
5. 其他提醒事項

## 注意事項
- 日期時間要清楚可辨識，避免模糊寫法。
- 若使用者提供的資訊很多，應以簡訊可讀性為優先。
- 不要自行補充未提供的法律內容或程序細節。
