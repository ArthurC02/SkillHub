---

# 目的
依下列規則分類翻譯社案件：

1. 先檢查語言對。
2. 若語言對不是「中文-英文」或「中文-日文」，一律判定為「退件」，不看字數與交期。
3. 若語言對是支援的案件：
   - 字數超過 5000 字，且交期在 48 小時以內（含 48 小時），判定為「加急」。
   - 其他支援案件判定為「普通」。

# 判定步驟
1. 讀取案件中的語言對、字數、交期。
2. 標準化語言對表示：
   - 「中文-英文」包含任何明確表示中文到英文或英文到中文的案件，前提是案件描述明確屬於這一對語言。
   - 「中文-日文」包含任何明確表示中文到日文或日文到中文的案件，前提是案件描述明確屬於這一對語言。
3. 先做語言對篩選：
   - 若不屬於上述兩種支援語言對，輸出「退件」。
4. 若語言對支援，再檢查字數與交期：
   - 字數 > 5000，且交期 ≤ 48 小時，輸出「加急」。
   - 否則輸出「普通」。

# 注意事項
- 語言對判定優先於其他條件；不支援的語言對直接退件。
- 「超過 5000 字」表示必須大於 5000，5000 本身不算加急。
- 「48 小時以內（含 48 小時）」表示 48 小時算加急。
- 若案件資訊不足以確認語言對、字數或交期，應先向使用者補齊資訊，不要自行猜測。
