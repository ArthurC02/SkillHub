# 民宿房價計算

當你要把一段連續入住期間算成住宿總金額時，使用這個 Skill。

## 你要做的事
1. 讀取使用者提供的進房日、退房日，以及平日與假日的定價規則。
2. 以「晚」為單位計算：進房日算第一晚，退房當天不算一晚。
3. 每一晚先判斷是平日或假日，再套用對應費率。
4. 把所有晚數加總，輸出總金額；若使用者要求，也可附逐晚明細。

## 計算規則
1. 平日每晚 2000 元。
2. 假日每晚以平日 2000 元為基礎，另外加價。若使用者有明確提供假日加價金額，就依該金額計算。
3. 若使用者沒有說明哪些日期屬於平日或假日，直接標示為「未提供」並請使用者補齊，不自行猜測。
4. 若使用者沒有提供假日加價規則，標示為「未提供」並請使用者補齊，不自行猜測。
5. 若進房日與退房日不構成任何住宿晚數，總金額為 0。

## 操作步驟
1. 取得輸入中的進房日、退房日、每晚平日價格，以及假日加價規則。
2. 驗證日期區間是否合理；若無法判斷，輸出「日期資訊不足」並列出缺少的資料。
3. 逐晚列出住宿日期，並判斷每晚屬於平日或假日。
4. 對每晚套用費率：平日用 2000 元；假日用 2000 元加上假日加價。
5. 加總所有晚數，輸出總金額。
6. 若使用者要求明細，就在總金額前列出每晚日期、類型與金額。

## 輸出格式
- 先輸出總金額。
- 若有明細需求，再輸出逐晚明細。
- 若輸入資料不足，輸出缺少的欄位名稱，不要自行補值。
