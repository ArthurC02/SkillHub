# 目的
協助撰寫畫廊開幕邀請文，語氣正式、優雅，並且**必須完整保留**以下事實資訊：
- 展覽名稱
- 展期（起訖日期）
- 開幕茶會時間
- 開幕茶會地點

## 使用原則
1. 先確認所有必要資訊是否齊全。
2. 任何情況下都不得自行改寫、推測、補寫或省略上述四項事實。
3. 若資訊不完整、彼此矛盾，或日期／時間／地點有歧義，先提出需要補充或釐清的問題，不要直接成文。
4. 文字風格應正式、優雅、得體，適合畫廊、藝術機構或展覽活動使用。
5. 可加入禮貌性的邀請語、簡短展覽介紹或敬邀措辭，但不得影響事實正確性。

## 撰寫流程
### 1. 檢查必要資訊
確認是否已提供：
- 展覽名稱
- 展期開始日期
- 展期結束日期
- 開幕茶會時間
- 開幕茶會地點

若任一項缺漏，先回覆缺少哪些資訊，並請使用者補齊。

### 2. 保留事實原文
撰寫時，以下資訊應以使用者提供的內容為準：
- 展覽名稱不得更名
- 日期不得更動格式或內容，除非使用者明確要求統一格式
- 時間不得自行換算或推測
- 地點不得簡化到可能造成誤解

### 3. 組織文案
建議結構如下：
- 開頭敬語或邀請語
- 展覽名稱
- 展期資訊
- 開幕茶會時間與地點
- 結尾敬邀蒞臨

### 4. 語氣要求
- 使用正式、優雅、簡潔的語句
- 避免口語化、過度熱情或過度行銷式表達
- 避免誇張修辭掩蓋必要資訊

## 建議寫法
可採用以下句型組合，但需依實際資訊替換：
- 「敬邀您蒞臨」
- 「展覽名稱：……」
- 「展期：……至……」
- 「開幕茶會將於……舉行」
- 「地點：……」
- 「誠摯期待您的光臨」

## 品質檢查
完成後，逐項確認：
- 展覽名稱是否完全正確
- 展期起訖日期是否完整且未寫錯
- 開幕茶會時間是否完整且未寫錯
- 開幕茶會地點是否完整且未寫錯
- 文案是否維持正式優雅語氣
- 是否沒有遺漏任何必要事實

## 若資訊不足
若無法確認上述必要資訊，請不要生成邀請文；改為列出缺少項目並請求補充。
