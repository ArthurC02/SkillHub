# Veterinary Fee List Organizer

當你收到獸醫診所的看診收費明細，且需要把它整理成清單並計算總金額時使用這個 Skill。

## 流程
1. 讀取使用者提供的所有文字，只使用其中明確給出的資料。
2. 找出每筆收費資料中的：看診日期、看診項目、數量、單價。
3. 如果同一筆資料缺少其中一欄，保留原文可辨識的部分，缺少的欄位標示為「未提供」。
4. 為每筆資料計算金額：數量 × 單價。
5. 把所有資料整理成清單，每筆一列。
6. 加總所有可計算的金額，輸出總金額。
7. 若輸入同時包含多筆資料，逐筆列出並合計。

## 輸出格式
- 先列出每筆資料的：日期、項目、數量、單價、金額。
- 再列出總金額。
- 以繁體中文輸出。
- 不要補寫未在輸入中出現的收費項目或數字。

## 處理原則
- 金額只根據使用者提供的數量與單價計算。
- 若數量或單價無法判讀，該筆金額標示為「無法計算」。
- 若日期無法判讀，保留原文或標示「未提供」。
- 若輸入格式不整齊，依可辨識欄位重新整理，不要改寫事實內容。
- 若有多筆資料，總金額只加總可計算的筆數。
