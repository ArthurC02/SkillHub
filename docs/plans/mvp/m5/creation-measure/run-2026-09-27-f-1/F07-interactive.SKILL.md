# 何時使用
當你收到一位學生本學期缺席次數與家長通知需求，且已確定缺席滿 3 次就要發出警告信並處理教務系統標記時使用。

# 你要產出什麼
1. 一封可直接寄給家長的缺席警告信。
2. 一段可交給教務系統操作人員使用的標記說明，內容要指向把該學生標記為「留意名單」。
3. 若缺席次數未達 3 次，只輸出不符合門檻的結果，不產生警告信。

# 執行步驟
1. 讀取輸入中的學生姓名、班級、家長稱謂或收件資訊、本學期缺席次數、缺席紀錄、學校名稱，以及教務系統登入或操作說明。
2. 檢查缺席次數：
   - 若少於 3 次，直接輸出「未達警示門檻」，並說明本次不產生警告信，也不進行留意名單標記。
   - 若為 3 次以上，繼續下一步。
3. 依輸入資料撰寫家長警告信：
   - 信件語氣正式、可直接寄出。
   - 明確寫出學生本學期缺席已達 3 次或以上。
   - 提到缺席紀錄中提供的日期。
   - 若收件資訊只有家長稱謂，仍以該稱謂作為稱呼；若姓名、班級或學校名稱未提供，明確寫成「未提供」。
4. 整理教務系統標記內容：
   - 寫明要在教務系統中將該學生標記為「留意名單」。
   - 只根據輸入中的登入與操作說明整理，不新增任何未提供的系統資訊。
   - 不要宣稱已經登入、已經更新或已經完成任何系統操作；本 Skill 只準備可直接使用的內容。
5. 合併輸出結果：先給警告信，再給教務系統標記說明。
6. 若輸入同時出現彼此矛盾的缺席次數或無法判定是否達 3 次，直接說明資料矛盾，並請使用者確認後再處理。

# 輸出格式
- 第一段：標題為「家長缺席警告信」。
- 第二段：標題為「教務系統標記說明」。
- 若未達門檻：標題為「未達警示門檻」，並只輸出原因。

# 注意
- 不要自行補齊未提供的事實。
- 不要把系統操作寫成已完成。
- 不要輸出與門檻無關的內容。
- 如缺少必要欄位，就在輸出中標記為「未提供」。
