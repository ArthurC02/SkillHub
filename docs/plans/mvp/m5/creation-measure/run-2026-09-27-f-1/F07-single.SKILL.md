# 目的
當學生本學期缺席滿 3 次時，依學校規範產生一封給家長的缺席警告信，並在已授權、可登入的教務系統中將該生標記為「留意名單」。

# 使用前提
- 只有在你已經取得學生本學期缺席次數、學生基本資料、家長聯絡資訊，以及學校要求的信件格式時才執行。
- 若沒有教務系統的登入權限、無法完成登入、或系統沒有「留意名單」功能，先停止並回報無法代為完成的原因，改為提供可手動執行的步驟清單。
- 不要猜測學生姓名、缺席次數、家長稱謂、班級、學號、日期或聯絡方式；缺少資料時先詢問。

# 執行流程
1. **確認觸發條件**
   - 檢查學生本學期缺席是否已滿 3 次。
   - 若少於 3 次，不產生警告信，也不做系統標記。
   - 若剛好或超過 3 次，繼續下一步。

2. **蒐集必要資訊**
   - 學生姓名
   - 班級／座號或學號（依學校慣例）
   - 本學期缺席次數與缺席日期（若信件需要列出）
   - 家長姓名或稱謂
   - 家長聯絡方式或收件方式（若信件需要）
   - 學校要求的警告語句、簽名單位、聯絡窗口
   - 教務系統名稱與登入方式

3. **撰寫缺席警告信**
   - 內容應包含：
     - 收件對象（家長／監護人）
     - 學生姓名與班級資訊
     - 已達本學期缺席 3 次的事實
     - 提醒家長留意出缺席狀況
     - 若學校有規定，加入後續聯繫或改善建議
     - 結尾署名與日期
   - 語氣保持正式、客觀、禮貌，不加入未經確認的指控。
   - 若學校有固定模板，優先遵循模板；若沒有，使用簡潔正式格式。

4. **登入教務系統**
   - 只有在你已被授權且可合法存取時才登入。
   - 使用既有登入流程，不要嘗試繞過驗證、重設密碼或存取未授權資料。
   - 若登入失敗，記錄失敗原因並停止後續標記。

5. **標記為「留意名單」**
   - 在學生資料頁或出缺席／輔導相關功能中，尋找「留意名單」或等效標記。
   - 將該生加入「留意名單」。
   - 若系統要求原因，填入「本學期缺席滿 3 次」或學校指定的標準原因。
   - 儲存後再次確認標記已成功寫入。

6. **完成後回報**
   - 回報已產生的信件內容或可直接寄送的版本。
   - 回報系統標記是否成功。
   - 若任何步驟無法完成，清楚說明卡在哪一步，以及需要哪些資訊或權限。

# 失敗處理
- 若資料不足：先列出缺少項目，等待補齊。
- 若系統沒有「留意名單」：回報系統不支援此功能，並建議改用學校既有的替代標記流程。
- 若無法登入：停止，不要嘗試其他未授權方式。
- 若學生缺席未達 3 次：僅回報尚未達標，不執行任何通知或標記。
