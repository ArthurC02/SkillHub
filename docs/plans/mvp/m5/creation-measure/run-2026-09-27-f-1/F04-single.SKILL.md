# 民宿房價計算 Skill

## 目的
根據連續入住期間，計算住宿總金額。規則是：
- 平日每晚 2000 元
- 假日每晚依加價後的價格計算
- 以「晚」為單位計費，退房當天不算一晚

## 使用時機
當使用者要你幫忙算某段住宿期間的總房價，且需要依平日/假日分別計價時，啟用此 Skill。

## 計算前先確認的資訊
若資訊不足，先向使用者確認以下內容：
1. 入住日期與退房日期
2. 日期格式與時區/地區慣例（若有歧義）
3. 假日的定義與加價方式
   - 哪些日期算假日：例如週六、週日、國定假日，或兩者皆是
   - 假日每晚價格是多少，或是平日價格要加多少
4. 是否有其他費用或折扣（若有，需另外列出）

## 計算規則
1. 只計算入住到退房前一晚的每一晚。
2. 逐晚判定該晚屬於平日或假日。
3. 平日每晚固定 2000 元。
4. 假日依使用者提供的加價規則計算；若使用者只說「假日會加價」但未提供金額，不能自行猜測，必須先詢問。
5. 總金額 = 所有晚數的房價加總。

## 計算步驟
1. 取得入住日與退房日。
2. 列出每一個住宿夜晚對應的日期。
3. 依假日定義判斷每晚是平日或假日。
4. 分別計算每晚金額。
5. 加總得到總金額。
6. 回覆時最好同時列出：
   - 總晚數
   - 平日晚數與金額
   - 假日晚數與金額
   - 總金額

## 回覆格式建議
- 若資訊完整：直接給出計算結果，並簡短列式。
- 若資訊不足：明確指出缺少哪些條件，請使用者補充後再算。

## 注意事項
- 不要把退房當天算進住宿晚數。
- 不要自行假設假日加價規則；若未提供，先詢問。
- 若使用者提供的是日期區間但未說明年份，需確認年份以避免平假日判定錯誤。
