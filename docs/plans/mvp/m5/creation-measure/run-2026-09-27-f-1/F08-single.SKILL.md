# 目的
將零散的獸醫診所看診資料整理成可讀的收費清單，並正確計算每筆小計與總金額。

# 何時使用
當使用者提供或要求整理以下資訊時使用：
- 看診日期
- 看診項目
- 數量
- 單價

# 工作流程
1. **先確認資料是否完整**
   - 每一筆收費至少要有：日期、項目、數量、單價。
   - 若缺少任一欄位，先列出缺少的欄位並請使用者補齊。
   - 若日期格式不一致，統一成同一格式後再整理。

2. **整理成清單**
   - 依照使用者提供的順序列出每一筆。
   - 每筆包含：
     - 看診日期
     - 看診項目
     - 數量
     - 單價
     - 小計

3. **計算小計**
   - 每筆小計 = 數量 × 單價。
   - 若數量或單價不是數字，先嘗試從文字中辨識可計算的數值；若仍無法判定，請回覆需要確認。

4. **計算總金額**
   - 總金額 = 所有小計加總。
   - 若有折扣、稅金或其他附加費，但使用者未要求處理，先不要自行加入。
   - 若使用者有提到折扣、稅金、掛號費、藥費等，應依其規則另外列出並說明是否納入總金額。

5. **輸出格式**
   - 以表格或條列清單呈現，清楚標示欄位。
   - 建議格式如下：

     | 看診日期 | 看診項目 | 數量 | 單價 | 小計 |
     |---|---:|---:|---:|---:|
     | 2026-01-01 | 診察費 | 1 | 500 | 500 |

   - 最後另列：
     - **總金額：** XXX

# 注意事項
- 不要自行捏造未提供的收費項目。
- 若同一日期有多筆項目，仍逐筆列出，不要合併，除非使用者明確要求合併。
- 金額計算要一致，避免四捨五入規則不明時自行改變數字；若有小數，保留原始精度並清楚顯示。
- 若使用者提供的是圖片、掃描檔或手寫內容，先辨識出文字，再依上述流程整理；若無法辨識，請明確說明哪些欄位看不清楚。
