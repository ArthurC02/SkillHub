# 翻譯社案件分類

這個 Skill 用來把翻譯社案件分成「退件」、「加急」或「普通」。

## 什麼時候使用
- 當你收到一則案件資訊，要先看語言對，再依字數與交期判斷分類。
- 當你需要把規則固定成可重複執行的分類流程時。

## 輸入
每次處理一則案件，案件至少要有：
- 語言對
- 字數
- 交期（小時）

## 處理順序
1. 先讀取案件的語言對。
2. 如果語言對不是「中文-英文」或「中文-日文」，直接判定為「退件」。
3. 如果語言對是支援的案件，再讀取字數與交期。
4. 若字數超過 5000，且交期在 48 小時以內（含 48 小時），判定為「加急」。
5. 其餘支援案件一律判定為「普通」。

## 判定規則
- 支援語言對：
  - 中文-英文
  - 中文-日文
- 退件：任何其他語言對，且不再看字數或交期。
- 加急：支援案件，字數 > 5000，且交期 <= 48 小時。
- 普通：支援案件但不符合加急條件。

## 輸出
只輸出最終分類結果之一：
- 退件
- 加急
- 普通

## 執行注意事項
- 不要把不支援的語言對拿去套字數或交期條件。
- 交期的邊界是 48 小時，48 也算在內。
- 字數的邊界是 5000，必須「超過」5000 才能進入加急條件。
