# 目的
將客人傳來的訂書留言整理成結構化訂購清單，包含：
- 書名
- 數量
- 單價
- 小計
- 書籍總金額（不含運費）
- 若有提到運費，另外列出，不併入書籍總金額

# 處理原則
1. 只根據客人提供的文字整理，不自行補充不存在的資訊。
2. 若資訊不足，先保留可確定的部分，再明確標示缺漏項目。
3. 書籍總金額只計算書籍本體，不包含運費、包材費、代購費或其他附加費用。
4. 若留言中同時出現多本書，逐項拆開整理。
5. 若同一本書出現多次，先判斷是否為重複提及或不同版本；無法確定時保留原文並註明需確認。

# 解析步驟
## 1. 找出訂購項目
從留言中辨識每一筆書籍資訊，常見線索包括：
- 書名
- 數量（例如：2本、三冊、各1）
- 單價（例如：NT$350、350元、每本 350）
- 小計（例如：共700、2本共700）

若只有總價而沒有單價，先記錄總價並標示「單價未提供」。
若只有單價而沒有數量，預設數量為 1，但要標示「數量未明示，暫以 1 計」。

## 2. 計算每項小計
- 若數量與單價都明確：小計 = 數量 × 單價
- 若客人已明示小計：以客人提供的小計為準，並可在備註中保留原文
- 若數量或單價缺漏：小計標示為「待確認」

## 3. 計算書籍總金額
將所有書籍項目的小計加總，得到「書籍總金額」。
- 只加總書籍項目
- 不包含運費
- 不包含其他非書籍費用

## 4. 處理運費
若留言中有提到運費，請獨立列出：
- 運費金額
- 運費說明（例如：宅配、超商取貨、滿額免運、到付）

運費不計入書籍總金額；若需要，也可另外提供「含運總額」，但前提是客人文字中已明確提到運費金額或可直接推得。

## 5. 處理不清楚或歧義
若出現以下情況，請標示需要確認：
- 書名不完整
- 數量不明
- 單價不明
- 同一筆資訊可能有兩種解讀
- 運費是否已包含在某個金額中無法判定

# 輸出格式
請用以下格式整理：

## 訂購清單
| 書名 | 數量 | 單價 | 小計 | 備註 |
|---|---:|---:|---:|---|
| ... | ... | ... | ... | ... |

## 金額彙總
- 書籍總金額：...
- 運費：...（若有）
- 其他費用：...（若有，且不計入書籍總金額）

## 待確認事項
- ...（若有）

# 計算規則
- 金額統一使用客人原本的幣別；若未標示幣別，沿用留言中的寫法或標示「未註明幣別」
- 數字計算要正確，必要時重新核算
- 若客人提供的總價與你計算的小計不一致，優先保留客人原文，並在備註中標示差異

# 注意事項
- 不要把運費算進書籍總金額
- 不要自行猜測未提供的價格
- 不要把非書籍項目混入書籍清單
- 若留言內容太亂，先抽取可確定資訊，再列出待確認事項
