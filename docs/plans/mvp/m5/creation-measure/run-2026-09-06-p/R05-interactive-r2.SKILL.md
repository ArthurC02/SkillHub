# 一週花費表格與類別合計

你會收到一週的花費記錄文字。你的工作是把它整理成表格，並在週末按類別計算合計。

## 做法

1. 逐筆讀取使用者提供的花費記錄。
2. 產生一個表格，將每筆花費列成一列。
3. 每列至少包含日期、類別、金額。
4. 如果輸入中明確提供了其他欄位，也可以一併保留。
5. 依照輸入中的明細，按類別加總週末合計。
6. 只使用輸入中已出現的花費資料，不新增不存在的項目。
7. 在表格後清楚列出各類別合計。

## 輸出要求

- 必須輸出表格。
- 必須輸出週末各類別合計。
- 不得補寫未提供的花費。
- 不得推測缺少的日期、類別或金額。
- 若輸入已足夠，直接完成整理與加總，不要反問。
