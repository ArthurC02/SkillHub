## 目的
將使用者提供的履歷改寫為「資料分析職缺導向」的一頁版，優先凸顯可量化成果、資料處理能力、分析工具與商業影響。

## 先確認資訊
如果使用者沒有同時提供以下內容，先用最少問題補齊：
1. 原始履歷全文。
2. 想投遞的資料分析職缺類型或職稱。
3. 是否有特別要保留或避免的內容。

若使用者只提供履歷，仍可直接改寫，但要以通用資料分析職缺為目標。

## 改寫原則
1. 以一頁內為目標，內容精簡、密度高。
2. 以資料分析相關關鍵字重寫，但不得捏造經歷、工具、學歷或成果。
3. 優先保留與強化以下內容：
   - SQL、Python、R、Excel、Tableau、Power BI、Looker 等工具
   - 資料清理、資料建模、報表、自動化、A/B test、統計分析
   - 商業分析、營運優化、成效追蹤、指標設計
   - 可量化成果，例如提升效率、降低成本、增加轉換率
4. 將一般職務描述改寫成「分析動作 + 工具/方法 + 成果」的句型。
5. 若原履歷缺少資料分析經驗，改寫時要把可轉移技能轉成分析語言，但不要誇大。
6. 避免空泛形容詞，少用「負責」、「協助」；改用具體動詞，如「建立」、「分析」、「優化」、「自動化」、「驗證」。

## 建議結構
輸出時依下列順序整理：
1. 姓名與聯絡資訊
2. 專業摘要 2–3 句
3. 核心技能 1 行或短條列
4. 工作經歷：每段 2–4 點，重點放在成果與方法
5. 學歷與證照：保留與職缺相關者

## 改寫步驟
1. 先讀取原始履歷，找出與資料分析最相關的經驗、工具、專案與成果。
2. 刪除與目標職缺關聯低、過於冗長或重複的內容。
3. 將每段經歷改寫成可掃讀的條列，並盡量加入數字、比例、時間、規模或影響範圍。
4. 若有多種工具或技能，將最相關者前置。
5. 若原文沒有摘要，新增一段專業摘要，明確對齊資料分析職缺。
6. 檢查整體篇幅，必要時再壓縮，確保一頁內可讀。

## 內容取捨
- 保留：分析、報表、儀表板、資料處理、商業洞察、跨部門溝通、專案成果。
- 弱化：與分析無關的行政細節、過度敘事、重複職責。
- 若有多份經歷，優先保留最能證明分析能力的內容。

## 輸出要求
1. 直接輸出改寫後的履歷內容。
2. 使用繁體中文，除非使用者原本要求英文。
3. 內容要自然、專業、適合直接貼到履歷文件中。
4. 不要附加解釋、評語或改寫說明。
5. 不要使用超過一頁的篇幅；若資訊過多，優先保留最相關內容。
