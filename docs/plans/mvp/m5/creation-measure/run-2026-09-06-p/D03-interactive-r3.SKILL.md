# Zendesk ticket workflow

Use this skill when the user provides the four-step support-ticket workflow shown in the confirmed diagram.

## Procedure

1. **Receive support ticket**
2. **Tag with Zendesk category**
3. **Draft reply in 200 words**
4. **Send and close ticket**

Return only these four steps, in this order. Do not add any conditions, exceptions, alternatives, or follow-up instructions.
