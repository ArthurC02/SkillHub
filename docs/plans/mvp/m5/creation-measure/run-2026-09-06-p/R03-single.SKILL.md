# 每日新聞摘要寄信流程

這個技能的目標是：每天早上把三個新聞網站的標題整理成 5 條摘要，並寄到指定信箱。

## 先確認是否可執行

如果你沒有以下任一項，先不要假裝已完成：
- 可存取三個新聞網站的方式（例如瀏覽工具、RSS、或已提供的標題來源）
- 可寄信的方式（例如 SMTP、郵件 API、或已授權的寄信工具）
- 收件人信箱地址
- 三個新聞網站的名稱或來源網址
- 需要寄送的時間與時區

如果缺少其中任何一項，先向使用者詢問，或明確說明目前只能先整理流程，不能實際完成寄送。

## 執行步驟

1. **取得當日標題**
   - 從三個指定新聞網站收集今天的標題。
   - 優先使用網站提供的 RSS、公開標題頁或已授權的資料來源。
   - 若某網站無法讀取，記錄原因，不要自行編造標題。

2. **去重與合併**
   - 將三個來源的標題合併。
   - 移除重複或高度相似的標題。
   - 將相近主題歸類，例如政治、國際、科技、財經、社會、體育。

3. **整理成 5 條摘要**
   - 從合併後的標題中挑出最重要的 5 個主題。
   - 每條摘要用一句話表達，重點是「今天發生了什麼」而不是逐字重寫標題。
   - 若標題資訊不足以形成摘要，就保留為簡短、忠實的概述，不要補充未確認的細節。
   - 若三個網站的內容明顯偏向同一事件，可合併成一條摘要。

4. **檢查內容品質**
   - 確認 5 條摘要都來自已取得的標題內容。
   - 確認沒有捏造數字、人物、地點或結果。
   - 確認語氣中立、簡潔，適合寄給收件人。

5. **組成郵件內容**
   - 主旨建議格式：`每日新聞摘要 - YYYY-MM-DD`
   - 內文建議包含：
     - 簡短開頭
     - 5 條摘要清單
     - 如有需要，可附上來源網站名稱
   - 若某來源缺失，簡短註明「部分來源今日無法取得」。

6. **寄送郵件**
   - 使用可用的寄信工具或郵件服務寄到指定信箱。
   - 寄出前再次確認收件人地址與主旨。
   - 若寄送失敗，回報失敗原因與已完成的摘要內容。

## 建議的郵件格式

主旨：`每日新聞摘要 - 2026-09-06`

內文：

早安，以下是今天的新聞摘要：

1. ...
2. ...
3. ...
4. ...
5. ...

來源：網站 A、網站 B、網站 C

## 例外處理

- **網站無法存取**：只使用可取得的來源，並註明缺少哪一個來源。
- **標題過少**：仍輸出 5 條，但必須明確標示資訊不足，避免補寫未確認內容。
- **無法寄信**：保留整理好的摘要，回報需要可用的寄信工具或授權。
- **使用者未提供三個網站**：先詢問網站名稱或網址，不要自行選擇新聞來源。
