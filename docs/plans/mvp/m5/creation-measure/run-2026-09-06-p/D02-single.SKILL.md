# 目的
依照流程：收到客戶 Excel 訂單 → 轉成 CSV 格式 → 檢查缺漏欄位 → 匯入 Shopify 後台 → 回覆客戶已入單。

# 執行步驟
1. **接收並確認 Excel 訂單**
   - 先確認檔案可開啟，且內容確實是客戶訂單。
   - 若檔案損毀、格式不明或不是訂單，先請對方重新提供可讀取的 Excel 檔。

2. **轉成 CSV 格式**
   - 將 Excel 內容整理成 Shopify 可接受的 CSV 結構。
   - 保留必要欄位與每筆訂單資料的一致性。
   - 若原始 Excel 有多個工作表，先確認哪一個是要匯入的訂單資料。

3. **檢查缺漏欄位**
   - 檢查每筆資料是否缺少匯入所需欄位。
   - 常見需確認的內容包括：商品、數量、收件資訊、聯絡資訊、地址、配送或其他匯入必要欄位。
   - 若發現缺漏或格式不符：
     - 先標記缺漏項目。
     - 不要直接匯入有明顯錯誤的資料。
     - 回頭向客戶或資料提供者確認補齊後再繼續。

4. **匯入 Shopify 後台**
   - 使用整理好的 CSV 進行匯入。
   - 匯入前再次確認欄位對應正確，避免資料進錯欄位。
   - 匯入後檢查結果是否成功，並確認訂單是否已正確建立。

5. **回覆客戶已入單**
   - 若匯入成功，回覆客戶訂單已完成入單。
   - 若有部分資料缺漏、匯入失敗或需要補件，清楚列出問題與需要客戶提供的資訊。

# 注意事項
- 不要假設缺少的欄位內容；缺什麼就先確認什麼。
- 若資料格式不一致，先統一再匯入。
- 匯入前後都要保留可追蹤的紀錄，方便查核與修正。
