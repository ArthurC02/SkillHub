# 目的
把會議逐字稿轉成一份清楚、可追蹤的待辦清單，每一條都要包含：
- 待辦事項
- 負責人
- 期限

# 使用原則
- 只根據逐字稿中明確提到的內容整理，不要自行補充不存在的任務、負責人或日期。
- 若資訊不足，先標示為「未指明」或「待確認」，不要硬猜。
- 優先保留原意與原始措辭，再整理成簡潔可執行的行動項目。
- 同一項工作若有多個子步驟，合併成一條主待辦，必要時在備註中列出子步驟。

# 處理步驟
1. **通讀逐字稿**
   - 找出所有明確的行動、決議、指派、追蹤事項、承諾與下一步。
   - 排除純討論、背景說明、重複寒暄、與任務無關的內容。

2. **辨識待辦項目**
   - 將「要做什麼」改寫成動詞開頭的任務。
   - 若同一件事在不同段落被重複提到，只保留一條，避免重複。

3. **找出負責人**
   - 以逐字稿中明確指派的人為準。
   - 若只有團隊或部門，寫成該團隊/部門名稱。
   - 若完全沒有指派，填「未指明」。

4. **找出期限**
   - 優先使用逐字稿中的明確日期、時間、會議後多久、或相對期限。
   - 若是相對時間，保留原表述，例如「本週五前」、「下次會議前」。
   - 若沒有期限，填「未指明」。

5. **整理成清單**
   - 每條待辦都要有三個欄位：待辦事項、負責人、期限。
   - 若有必要，可加上「備註」欄補充上下文，但不要取代前三個欄位。

# 輸出格式
請輸出成條列或表格，格式一致、易讀。

## 建議表格格式
| 待辦事項 | 負責人 | 期限 | 備註 |
|---|---|---|---|
| ... | ... | ... | ... |

# 品質檢查
在輸出前確認：
- 每一條待辦都有負責人與期限；若缺少，已標示「未指明」或「待確認」。
- 沒有把推測當成事實。
- 沒有遺漏逐字稿中明確提到的重要行動項目。
- 用詞簡潔，適合直接轉貼到工作追蹤工具。
