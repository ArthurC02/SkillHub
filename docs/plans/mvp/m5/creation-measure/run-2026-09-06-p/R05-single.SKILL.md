# 目的
將一週內的每日花費整理成清楚的表格，逐筆標示類別，並在週末計算各類別合計。

# 適用情境
- 使用者提供零散的每日花費文字、照片轉寫、聊天紀錄或清單，要求整理成一週表格。
- 使用者希望每筆支出都有類別標籤。
- 使用者要求在週末做各類別加總。

# 工作流程
1. **先確認資料範圍**
   - 找出一週的起訖日期，或確認是「最近七天」還是「某個指定週」。
   - 若日期不完整，先依使用者提供的順序整理，不要自行捏造日期。

2. **抽取每筆花費**
   - 對每筆記錄擷取：
     - 日期
     - 項目/用途
     - 金額
     - 幣別（若有）
     - 類別
   - 若原始資料沒有類別，根據用途歸類到最合理的類別。
   - 類別要一致，避免同義不同名；例如「餐飲」「吃飯」統一成同一類。

3. **建立每日明細表**
   - 以日期排序。
   - 每筆支出獨立一列。
   - 建議欄位如下：
     - 日期
     - 項目
     - 類別
     - 金額
     - 備註（可選）
   - 若同一天有多筆，全部列出，不要合併。

4. **處理缺漏與不明項目**
   - 金額缺漏：標示為「未提供」，不要猜測。
   - 類別不明：先標為「其他」或「未分類」，並在備註說明原因。
   - 日期不明：放在「日期未明」區塊，並提醒使用者補資料。

5. **週末彙總各類別合計**
   - 只對已分類且有金額的項目加總。
   - 依類別彙總整週總額。
   - 若同一類別有多種寫法，先統一後再加總。
   - 若有幣別混用，分幣別分開計算，不要直接相加。

6. **輸出週末總表**
   - 以類別為列，顯示：
     - 類別
     - 合計金額
     - 筆數（可選）
   - 若使用者需要，也可再補一列「總支出」。

# 建議輸出格式
## 每日明細
| 日期 | 項目 | 類別 | 金額 | 備註 |
|---|---|---:|---:|---|
| 週一 | 早餐 | 餐飲 | 80 |  |
| 週一 | 捷運 | 交通 | 50 |  |

## 週末類別合計
| 類別 | 合計金額 | 筆數 |
|---|---:|---:|
| 餐飲 | 430 | 6 |
| 交通 | 120 | 3 |

# 注意事項
- 不要自行補齊不存在的花費。
- 不要把不同幣別混在一起加總。
- 類別命名要前後一致。
- 若使用者只提供部分資料，先整理已有內容，再列出缺少哪些資訊。
