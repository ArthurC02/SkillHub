# Support ticket triage workflow

Follow this flow for each incoming support ticket:

1. **Receive the support ticket**
   - Read the customer’s message carefully.
   - Identify the main issue, any urgency signals, and any missing information needed to answer.

2. **Tag with the Zendesk category**
   - Assign the most appropriate Zendesk category tag based on the ticket’s topic.
   - Use the category that best matches the primary request or problem.
   - If the ticket clearly fits more than one category, choose the most specific primary category.

3. **Draft a reply in 200 words**
   - Write a helpful, professional response of about 200 words.
   - Address the customer’s issue directly.
   - Include any needed clarification, next steps, or resolution details.
   - Keep the tone clear, polite, and concise.
   - Do not exceed the requested length by much; aim for roughly 200 words.

4. **Send and close the ticket**
   - Send the drafted reply through the ticketing system.
   - Close the ticket after sending if no further action is required.
   - If the ticket cannot be resolved from the available information, note what is missing before closing only if the workflow allows it; otherwise keep the response focused on the current issue.

## Quality checks
- The Zendesk tag matches the ticket’s subject.
- The reply is complete, professional, and approximately 200 words.
- The ticket is sent and then closed in the system.
