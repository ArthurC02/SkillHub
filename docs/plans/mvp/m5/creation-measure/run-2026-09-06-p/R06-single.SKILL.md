## 目標
將英文使用手冊完整翻成繁體中文，並在專有名詞第一次出現時保留原文標註。

## 處理原則
1. **忠實翻譯**：保留原意、語氣、警告、步驟順序、編號、表格、標題與項目符號。
2. **繁體中文**：全文使用繁體中文，不混用簡體。
3. **專有名詞標註**：
   - 專有名詞第一次出現時，寫成「中文譯名（Original Term）」。
   - 之後同一名詞只用中文譯名。
   - 若原文本身就是品牌、型號、介面名稱或不可翻譯詞，保留原文並在首次出現時加上必要說明。
4. **一致性**：同一術語、按鈕名稱、功能名稱、單位、錯誤訊息要前後一致。
5. **不擅自增刪**：不要加入原文沒有的說明；若遇到不清楚的地方，保留原文並以最小必要方式處理。

## 翻譯步驟
1. 先通讀全文，辨識：
   - 標題層級
   - 操作步驟
   - 注意、警告、提示
   - 表格、清單、圖說、按鈕名稱、介面文字
   - 專有名詞與術語
2. 建立術語一致性：
   - 同一詞彙在全文採用同一譯法。
   - 若文件中有縮寫，首次出現時可採「中文譯名（英文全名，縮寫）」格式，之後只用縮寫或中文譯名，依原文慣例一致處理。
3. 逐段翻譯：
   - 保留段落順序與格式。
   - 操作說明用清楚、直接的繁體中文表達。
   - 數字、單位、型號、路徑、代碼、命令、按鍵名稱盡量維持原樣。
4. 處理專有名詞首次出現：
   - 例如：`Bluetooth` → `藍牙（Bluetooth）`
   - 例如：`Settings` → `設定（Settings）`，後續統一為 `設定`
5. 保留原始結構：
   - 標題層級不變。
   - 編號步驟不改順序。
   - 表格欄位與列順序不變。
   - 若原文有項目符號、警告框、註解，翻譯後仍以相同形式呈現。

## 品質檢查
1. 檢查是否有漏譯段落、標題或表格內容。
2. 檢查專有名詞首次出現是否已附原文。
3. 檢查繁體字用字是否一致。
4. 檢查操作步驟是否清楚、沒有改變原意。

## 輸出要求
- 只輸出翻譯後的繁體中文內容。
- 不要附加翻譯說明、註解或額外摘要，除非原文本來就有。
