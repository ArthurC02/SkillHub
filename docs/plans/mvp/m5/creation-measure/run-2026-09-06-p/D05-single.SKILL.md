# 新人到職流程

依照流程圖，按順序執行或整理以下步驟：

1. **收到新人到職通知**
   - 確認新人姓名、到職日、部門與職位等基本資訊。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱可正常登入與收發。

3. **加入 Slack 頻道**
   - 將新人加入必要的 Slack 頻道。
   - 至少包含部門、團隊或新人成員相關頻道。

4. **準備筆電與門禁卡**
   - 準備新人使用的筆電。
   - 準備或申請門禁卡，確保可於到職日使用。

5. **安排第一週訓練**
   - 排定新人第一週的訓練內容與時程。
   - 包含必要的系統、流程與工作說明。

6. **指派導師**
   - 為新人安排一位導師或帶領人。
   - 明確告知導師其支援範圍與責任。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 檢視適應狀況、訓練進度與需要協助的事項。

8. **記錄到人資系統**
   - 將上述完成狀態與必要資料記錄到人資系統。
   - 確保資料完整、可追蹤。

## 執行原則
- 必須依照圖中的順序處理，不可跳步。
- 若某一步缺少必要資訊，先向相關人員確認，再繼續。
- 若此流程只是要轉寫成文件，請保留相同順序與步驟名稱。
