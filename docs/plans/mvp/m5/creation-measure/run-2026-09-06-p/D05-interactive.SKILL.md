# 目的
根據使用者提供的到職流程圖，直接輸出一份依順序排列的結構化步驟清單。

# 輸出規則
- 使用繁體中文。
- 只輸出流程節點，不新增任何額外說明、分析或補充步驟。
- 依照圖中的順序列出所有節點。
- 節點名稱請盡量保留原文。
- 用編號清單輸出。
