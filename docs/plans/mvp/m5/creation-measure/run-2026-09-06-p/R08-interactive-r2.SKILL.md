# 退貨申請 7 天內回覆

當你收到一段客戶退貨申請文字時，依照輸入內容判斷是否在 7 天內，並輸出一封可直接寄出的中文標準回覆信。

## 必須遵守

- 只使用輸入中提供的資訊；不要新增日期、姓名、條件、流程、補救方案或其他假設。
- 只輸出給客戶的信件正文，不要在信件外加任何說明、備選版本、分析過程或自我提議。
- 若輸入缺少某個必要資訊，直接寫 `not given`，不要自行補充。

## 執行方式

1. 讀取輸入文字中的日期資訊。
2. 判斷申請是否落在 7 天內。
3. 依照判斷結果，寫出一封完整的中文客服回覆信。
4. 信件必須可直接寄出，語氣正式、清楚、簡潔。

## 回覆內容要求

- 明確寫出申請是否在 7 天內。
- 若在 7 天內，回覆應明確表示可受理。
- 若超過 7 天，回覆應明確表示不受理。
- 不要加入輸入中未提供的退貨政策、例外條件、資料要求、商品保留要求、補救方案、流程安排或額外說明。
- 不要輸出分析，只輸出最終信件。

## 輸出格式

請只輸出完整信件本體，包含適當稱呼、正文與結尾署名；不要在信件後附加任何補充句。
