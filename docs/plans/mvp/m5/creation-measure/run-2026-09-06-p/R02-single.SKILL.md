# 目標
將 Excel 中的客戶名單去除重複，並標記缺少電話的列。

# 適用情況
當你拿到一份 Excel 客戶名單，需要：
1. 找出並移除重複資料；
2. 標記電話欄位空白或缺值的列。

# 執行步驟

## 1. 先確認欄位結構
- 打開工作簿，確認哪一欄是用來判斷重複的主鍵。
- 若沒有明確主鍵，優先使用最能代表客戶唯一性的欄位組合，例如：姓名 + 電話、姓名 + Email、客戶編號。
- 確認電話欄位名稱，後續用來檢查是否缺少電話。

## 2. 先備份原始資料
- 在原工作表旁建立一份副本，或另存新檔。
- 所有清理動作都在副本上進行，保留原始資料不變。

## 3. 去除重複資料
- 依照確認好的判斷欄位，使用 Excel 的「移除重複」功能。
- 若重複判斷需要多欄組合，務必一次選取所有相關欄位。
- 移除後，檢查剩餘筆數是否合理，並確認沒有誤刪明顯不同的客戶。
- 若資料中有空白列、合併儲存格或格式不一致，先整理成標準表格再去重。

## 4. 標記缺少電話的列
- 在電話欄旁新增一欄，例如「電話狀態」或「缺少電話」。
- 對每一列檢查電話欄：
  - 若電話欄為空白、只有空格、或明顯不是有效電話內容，標記為「缺少電話」。
  - 若有電話，標記為「正常」或留白，依需求一致處理。
- 若需要更醒目，可使用底色、字色或篩選標記缺少電話的列。

## 5. 驗證結果
- 用篩選功能檢查：
  - 是否還有重複客戶；
  - 是否所有缺少電話的列都已被標記。
- 隨機抽查幾筆資料，確認去重沒有誤傷正常資料。

## 6. 輸出整理後檔案
- 將清理後的工作表另存為新檔。
- 檔名建議包含日期或版本，例如「客戶名單_去重_缺電話標記.xlsx」。

# 注意事項
- 如果「重複」的定義不明確，先詢問使用者要以哪幾個欄位判斷。
- 如果電話欄位格式混亂，先統一格式再判斷是否缺少電話。
- 若資料量很大，優先使用 Excel 篩選、條件格式與移除重複功能完成，不要手動逐列處理。
