# 企業健檢 LINE 行前通知

把行政提供的一筆或多筆企業健檢資料，分別改寫成可直接使用的繁體中文 LINE 通知。只準備訊息，不代為傳送。

## 步驟

1. 將輸入分成獨立資料筆；一筆資料產生一則通知，不混用不同筆的資訊。擷取健檢日期、集合時間、空腹要求、編製日期、帶時間戳記的更新，以及其他明確提供的事項。保留事實原意與原有值，不補造資訊。
2. 若日期或時間有不同值，逐項優先採用時間戳記最新的值；沒有時間戳記可供比較時，採用最後提及的值。將採用依據簡短寫進該則通知。若有無法使用的值（例如不存在的日期），指出值並請提出請求的人確認；不輸出依賴該值的結果，但仍完成其他可完成的內容，不以問題作為結尾。
3. 若健檢日期缺漏，使用編製日期；若未提供編製日期，以執行當日作為基準。從基準日的下一天開始，取最近的週一至週五，不考慮假日。用下列命令計算；每筆資料各自計算一次：
   - 有編製日期：`python scripts/next_weekday.py --after YYYY/MM/DD`
   - 沒有編製日期：`python scripts/next_weekday.py`
   日期計算器也可用 `--after` 改變基準日期。依命令輸出採用日期，並將任何標明假設值的輸出行原字照錄在答案中、緊鄰該則通知。
4. 若集合時間缺漏，假設為 08:00；通知中必須明確標示該時間是假設值。日期由缺漏資料推算時，也必須在通知中明確標示是假設日期。可用以下命令整理日期、時間及更新衝突；每筆資料一個 `--entry`，格式為 `時間戳記|日期|時間`，沒有值的欄位留空，且依原文順序輸入：
   - `python scripts/resolve_health_check.py --entry '時間戳記|日期|時間'`
   - 多筆更新時重複 `--entry`；沒有時間戳記時，時間戳記欄留空。
   - 有編製日期時另加 `--compile-date YYYY/MM/DD`。該程式列出選定值及假設值；將每一行標明假設值的輸出原字照錄在答案中、緊鄰該則通知。輸出與原始資料格式不同時，通知盡可能沿用原始格式。
5. 每則通知都要保留健檢日期、集合時間及「需空腹 8 小時」的意思。不要把推定值寫成已確認事實；未提供、且沒有依規則採用假設值的相關資訊，標為「未提供」。
6. 用自然、簡潔的 LINE 語氣寫成段落，不用條列。若省略或合併了其他提供的資訊，另用一句話具體說明實際省略或合併的內容；沒有省略或合併時不必寫這句。日期或時間有矛盾時，說明採用依據。
7. 為每則通知另存一個文字檔，只放該則通知。依該通知實際採用的日期、時間執行句數及必備事實檢查；替換下列引號中的範例值為該筆的值，並把每項必備事實各自作為一個 `--require` 參數：
   `python scripts/check_output.py notice.txt --max-sentences 4 --require 'YYYY/MM/DD' --require 'HH:MM' --require '空腹 8 小時'`
   若通知明確標示假設或採用更新依據，也要確保這些文字仍符合句數上限。修改後重新檢查，直到檢查程式印出 `OK`。若多筆資料，逐則檢查；最後回答只放各則可直接使用的通知及規定須照錄的假設值輸出行，不加入檢查說明。

若當次要求還包括其他外部動作，逐項以一行說明該動作本 Skill 無法代辦，並指出須由提出請求的人或其指定負責者執行。傳送 LINE 訊息：此 Skill 無法代為傳送；由提出請求的人自行傳送。
