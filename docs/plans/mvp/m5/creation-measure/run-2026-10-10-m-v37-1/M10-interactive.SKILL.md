# 車站行李寄放收費試算

依使用者提供的每筆件數與寄放天數，計算件數費、天數費及套用單筆上限後的應收總額。費率與上限採用本 Skill 明列的規則，不查詢外部資料。

## 步驟

1. 從輸入整理每筆資料的件數與寄放天數；保留每筆資料的原始順序。可辨認的資料列以一筆寄放處理。
2. 如果缺少件數或天數，直接提供可填寫的格式，不要猜值：`件數：[未提供]，天數：[未提供]`。對資料中已齊全且有效的其他筆，仍繼續試算。
3. 將每筆完整資料轉成 `件數,天數` 格式。從放置本 `SKILL.md` 的目錄執行腳本，每筆資料各帶一個 `--item`，例如：`python scripts/luggage_fee.py --item 3,3 --item 4,4`。
4. 以腳本輸出為準，逐筆回覆件數費、天數費、未封頂合計與應收總額，附上簡短計算式。原樣複製腳本輸出中任何說明假設值的整行；不得自行改寫計算結果。
5. 若腳本拒絕輸入，修正命令格式或你能確定的輸入錯誤後重跑。若值本身無法判定，明確列出無法使用的值，不計算依賴該值的金額，並在該筆結果中標示 `[未提供]`，請提出需求的人確認正確值；其他可計算的筆數仍照常呈現。缺少整筆資料時，提供步驟 2 的可填格式。

## 固定收費規則

- 件數費：前 3 件每件 50 元，第 4 件起每件 30 元。
- 天數費：以整筆寄放天數計算，不按件數倍增；前 3 天每天 80 元，第 4 天起每天 50 元。
- 件數費與天數費相加後，單筆應收總額最高為 800 元。
