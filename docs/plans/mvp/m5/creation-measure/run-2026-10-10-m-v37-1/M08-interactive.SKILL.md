# 魚苗訂單核對

依下列步驟核對使用者提供的訂單訊息。保留原文中的品項、數量、單價、日期及幣別，不自行換算幣別或補造事實；只將能確定是魚苗或水草的項目納入總額，其他項目列出但排除。

1. 從訊息辨識每筆訂單及其日期、幣別、品項、數量、單價與單位。依意義辨識魚苗和水草；未提及的其他類別視為不計入總額。把同一筆訂單中同一品項的數量記在同一項，保留每個原始數值；缺少或無法判定的數量、單價、日期、幣別或名稱標為「未提供」，不可猜測。若原文的單價不清楚，記為缺少單價，並保留原文說法。
2. 將整理後的訂單寫入目前目錄的 `orders-input.json`。格式為 `{"orders":[{"name":"訂單名稱或 null","date":"日期原文或 null","currency":"幣別原文或 null","items":[{"name":"品項原文或 null","included":true,"quantities":["數量原文"],"unit_prices":["單價原文"],"unit":"單位原文或 null"}]}]}`。`included` 僅在能確定為魚苗或水草時設為 `true`；其他情況設為 `false`。缺少數量或單價用空陣列；同一品項出現的每個數量或單價各列為一個字串。缺少欄位用 `null`。不得把使用者原文中的不同數值合併或自行挑選。
3. 從放有此 `SKILL.md` 的目錄執行：`python scripts/order_check.py --input orders-input.json`。腳本負責檢查公曆日期、數量矛盾及負數，計算可用的品項金額與訂單金額。若因自己建立的輸入檔或參數格式收到錯誤，修正該輸入並重跑；不可把自己造成的錯誤留成空白結果。
4. 依腳本輸出逐筆整理核對結果，呈現每個原文品項、數量、單價、單位、金額，以及排除的項目。保留原始事實的寫法，並呈現腳本算出的金額；不對缺漏資料臆測。若日期無效、數量為負或同一品項有不同數量，明確指出具體值並請使用者確認，不選值；該筆訂單不得提供小計或最終總額。若只有缺少可計價的數量或單價，標明缺漏並請使用者補充，不宣告最終總額，但列出已知可計算項目的小計。其他非魚苗／水草項目及運費不計入總額。
5. 一次交付完整的核對結果；缺少的事實標為「未提供」，矛盾列為待確認，不要只提出問題而不提供其餘可完成的結果。回覆最後用簡短陳述收束，不以問題作結。
