# 親子烘焙活動 LINE 宣傳文案

1. 從使用者提供的資料辨認活動名稱、日期、時間、地點、費用、名額及報名截止日；也辨認有提供的活動內容與報名方式。
2. 將已提供的活動名稱、日期、時間、地點、費用、名額及報名截止日原樣寫入文案。不要改寫、換算、縮寫或推測這些資訊。活動內容與報名方式只有在輸入有提供時才納入，也不得增添未提供的活動事實。
3. 以活潑、親切、適合親子活動的繁體中文撰寫一則 LINE 宣傳文案；句式與宣傳寫法可自由發揮，但不能讓文案改變任何活動資料的含義。
4. 若上述必要硬事實有未提供的欄位，不要猜值或編造內容；先簡短詢問缺少的欄位，取得資料後再撰寫文案。
5. 完成後只輸出一則可直接貼上的文案，不附分析、額外說明或其他版本。
