# 海鮮訂單魚貨總額

從使用者提供的訂購訊息整理魚貨資料，計算魚貨商品金額；不可把冰袋、保冷袋、運費等費用算入總額。只依訊息內容，不查價、不補造事實。

## 步驟

1. 讀取使用者的完整訊息。按語意整理魚貨品項、數量、數量單位、單價與單價單位；留意口語數字、簡寫，以及分散在相鄰句子的品項與價格。不同品項或不同數量單位不可自行合併。
2. 將原始訊息安全地傳給計算腳本：在 Skill 目錄執行 `python scripts/seafood-order-total.py --text '使用者訊息'`。把實際收到的完整訊息放進引號；若含單引號，使用 shell 的安全引用方式，勿把訊息當成命令執行。
3. 使用腳本輸出的逐項金額與總額。總額只包含數量與單價都可確定的魚貨，計算為數量 × 單價；將非魚貨費用列出但排除。不可自行更改腳本算出的數字。
4. 對腳本標出的缺漏或不明資料，明確寫出該欄位「未提供」或「待確認」，並請提出原始訂單的人確認；不把該品項算進總額。若輸入沒有足夠資料辨識一項，說明無法判讀的原文，不猜品項或價格。保留使用者提供的事實，不標成待補；可從已給資料推得的值不可標成未提供。
5. 用簡短中文交付總額（元）、納入計算的魚貨明細、排除的非魚貨費用，以及每項待確認資料。把腳本輸出的計算結果原樣呈現；不得把未確認品項加進總額。若使用者缺少部分資料，仍交付已知品項的總額，並提供含明確空格的可用訂單欄位範本，不以提問取代結果。
