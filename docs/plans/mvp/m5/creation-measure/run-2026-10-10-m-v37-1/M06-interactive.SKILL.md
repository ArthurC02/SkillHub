# 音樂教室試聽確認簡訊

依序完成以下步驟：

1. 從請求中取出試聽日期、時間、教室編號、試聽費金額及改期截止日；逐項保留使用者提供的原文，不自行改寫數值或補造資料。
2. 用繁體中文寫成一行簡訊，保留上述五項資料。只在字數有餘裕時加入其他資訊；不加前言、引號、說明或字數統計。
3. 將簡訊本文原樣存入目前目錄的 `sms.txt`，不得附加標題或多餘換行。從放有本 `SKILL.md` 的目錄執行下列命令，`--require` 值使用本次提供資料中各項必要資訊的最短辨識核心：

   ```sh
   python scripts/check_output.py sms.txt --max-chars 50 --require "$DATE_CORE" --require "$TIME_CORE" --require "$ROOM_CORE" --require "$FEE_CORE" --require "$DEADLINE_CORE"
   ```

   以實際值代入各項核心。若未印出 `OK`，只刪減其他資訊並重新檢查；不得刪改必要資訊。回答時只輸出 `sms.txt` 的內容，並逐字保留檢查所需的字詞。
4. 對任何本次請求提到、但此 agent 無法執行的外部動作，不得聲稱已完成。備妥簡訊後，回答最後為每項動作各加一行，明確寫出「此 agent 無法執行〔動作〕；請由〔提出請求者或請求中指定的負責人〕執行。」
