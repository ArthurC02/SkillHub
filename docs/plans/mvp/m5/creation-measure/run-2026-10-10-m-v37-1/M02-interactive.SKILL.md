## 用途
依使用者提供的票券資料計算退款總額；不查詢票務系統，也不辦理退票。

## 步驟
1. 從請求辨認每筆資料的標籤、票價（元）、張數、開演日、退票申請日，以及主辦方是否取消（是／否）。一次處理所有資料；逐字保留已提供的事實，不推測缺漏值。日期格式為 `YYYY-MM-DD`。
2. 對缺少資料的項目，不阻止其他完整資料的計算；在結果中標示缺少的欄位，並提供該筆可填寫的模板：`[標籤]：票價 [　] 元，張數 [　]，開演日 [YYYY-MM-DD]，申請日 [YYYY-MM-DD]，主辦方取消：[是／否]`。不為該筆編造退款額。
3. 對每筆資料分別執行下列命令；`ID`、`PRICE`、`COUNT`、`SHOW_DATE`、`APPLY_DATE`、`CANCELLED` 依序替換為該筆實際值。取消狀態使用 `是` 或 `否`。從 SKILL.md 所在目錄執行：
   `python scripts/calculate_refund.py --id ID --price PRICE --count COUNT --show-date SHOW_DATE --apply-date APPLY_DATE --cancelled CANCELLED`
4. 依序呈現每筆標籤、日期相差天數、適用規則與程式輸出的退款額，使用元並固定顯示兩位小數。日期相差天數為開演日減申請日。主辦方取消一律全額退，優先於其他規則；否則 7 天以上退總票價的 80%，1 至 6 天退 50%，0 天或申請日晚於開演日退 0 元。總票價為票價乘張數；金額四捨五入至小數點後兩位，不另扣手續費。
5. 若程式以代碼 2 拒絕資料，指出它輸出的無法使用之值，請提出請求的人確認或更正該值；不要計算依賴該值的金額。仍繼續計算其他完整且有效的資料。只詢問無法使用的值，不詢問其他事情。
6. 交付所有可算資料的結果、無法計算資料的缺欄或待確認值，以及相應填寫模板。若請求提及本 Skill 無法執行的其他動作，準備好可直接使用的內容，並以一行說明該動作本 Skill 無法執行、改由提出請求的人或請求指定負責者執行。
