# 獨木舟租借計費

依照確認的計費規則，計算一筆或多筆獨立租借的應收租金。

## 步驟

1. 從請求中找出每筆租借的實際使用分鐘數，按原有順序整理；每筆租借分開計算。不要把不同租借的分鐘數相加。
2. 若沒有提供任何分鐘數，回覆可用範本：`應收租金：〔分鐘數未提供〕元`。不要為缺少的數值猜測或計算。
3. 若有分鐘數，從存放本 `SKILL.md` 的目錄執行下列命令，將尖括號說明替換為請求中各筆分鐘數的原始數值，並以空格分隔：
   ```sh
   python scripts/calculate_rental.py -- <分鐘數...>
   ```
4. 呈現腳本輸出的每筆結果，不改動金額或順序。若腳本另外指出無法使用的值，原樣呈現該行，並告知提出請求的人確認並提供正確值；不要計算依賴該值的金額。腳本拒絕任何命令列值時，先修正命令列傳入方式，再執行一次。
5. 回覆只呈現已計算的租金結果，以及必要的無法使用值說明；不添加未提供的折扣、稅費或其他費用。
