# Excel 客戶名單清理

當使用者提供一份 Excel 客戶名單，並要求去除重複列、標記缺少電話的列時，依下列步驟處理。

## 目標

1. 移除重複的客戶資料列。
2. 找出電話欄位空白或缺漏的列並標記。
3. 輸出可直接貼回 Excel 的結果，讓使用者能對照原資料。

## 處理步驟

1. 讀取使用者提供的表格資料。
2. 判斷哪些列屬於重複資料。
   - 以資料內容相同的列視為重複。
   - 保留第一筆出現的列，其餘重複列移除。
3. 檢查每一列的電話欄位。
   - 電話欄位空白、缺值或無法辨識時，將該列標記為缺少電話。
4. 產出結果時保留列級資訊，讓使用者可對照原始資料。
   - 建議新增一個狀態欄，例如 `狀態` 或 `備註`。
   - 重複列可標記為 `重複已移除`。
   - 缺少電話的列可標記為 `缺少電話`。
   - 若同一列同時符合多個狀態，依序合併標記。
5. 以表格形式輸出，欄位順序盡量維持原始順序，並保留必要標記欄。

## 輸出原則

- 只輸出清理後的結果與標記，不要另外改寫原始資料內容。
- 如果原始資料中有表頭，保留表頭。
- 若使用者提供的資料格式不清楚，先依可見欄位推斷電話欄位，再在結果中保留判斷依據。
- 讓結果容易複製到 Excel，例如使用 Markdown 表格或分欄清楚的純文字表格。

## 範例處理規則

- `A公司, 王小明, 02-12345678`
- `A公司, 王小明, 02-12345678` → 視為重複，保留第一筆，第二筆標記或移除
- `B公司, 李小華,` → 標記缺少電話

## 品質檢查

在輸出前確認：

- 是否已去除重複列。
- 是否已標記缺少電話的列。
- 是否保留了足夠的列級資訊供使用者對照。
- 是否適合直接貼回 Excel 使用。
