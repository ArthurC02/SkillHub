## 目標
將一份英文使用手冊完整翻譯為繁體中文，保留原意、結構與可讀性；專有名詞在第一次出現時以「中文（原文）」呈現，之後可只用中文譯名。

## 處理原則
1. **完整翻譯**：不要摘要、刪節或改寫成說明文；保留所有段落、標題、列表、表格、警告、注意事項與步驟順序。
2. **繁體中文**：輸出一律使用繁體中文。
3. **專有名詞處理**：
   - 第一次出現的專有名詞、產品名、功能名、按鈕名、介面名稱、縮寫或術語，寫成「中文譯名（原文）」。
   - 若該詞沒有自然中文譯名，可保留原文並在第一次出現時加註簡短中文說明。
   - 後續出現時，使用已建立的中文譯名，避免重複括號。
4. **一致性**：同一術語、按鈕、選單名稱、錯誤訊息與欄位名稱，全文保持一致。
5. **格式保留**：盡量維持原手冊的章節層級、編號、項目符號、表格欄位與順序。
6. **不可補寫內容**：不要加入原文沒有的功能說明、操作建議或註解；若原文不清楚，忠實保留並以最小幅度處理。

## 翻譯步驟
1. 先通讀全文，辨識：
   - 標題與章節結構
   - 專有名詞、縮寫、產品元件名稱
   - 操作步驟、警告、注意、提示
   - 表格、圖說、按鈕文字、選單項目
2. 建立術語對照：
   - 為每個重要專有名詞決定一致的中文譯法。
   - 若同一詞在不同地方有不同語境，優先維持同一譯名，必要時在首次出現時補充說明。
3. 逐段翻譯：
   - 先保留原有結構，再逐句轉成自然的繁體中文。
   - 操作說明使用清楚、直接的命令式語氣。
   - 警告與注意事項保持原本的強調程度。
4. 檢查一致性：
   - 專有名詞首次出現是否有原文。
   - 按鈕、選單、介面名稱是否前後一致。
   - 數字、單位、版本號、型號、路徑、代碼是否正確保留。
5. 最後校對：
   - 確認沒有漏譯段落或表格。
   - 確認沒有把英文原文整段保留下來，除非它是必須保留的名稱、代碼或介面文字。

## 輸出要求
- 只輸出翻譯後的繁體中文內容。
- 保留原手冊的結構與順序。
- 專有名詞第一次出現時附原文，之後使用中文譯名。
