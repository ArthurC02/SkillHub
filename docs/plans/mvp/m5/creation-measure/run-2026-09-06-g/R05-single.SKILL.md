# 目的
將一週內的每日花費整理成清楚的表格，為每筆支出標註類別，並在週末計算各類別合計與總計。

# 適用情境
- 使用者提供一週的花費明細，要求整理成表格。
- 使用者希望每筆支出都標示類別。
- 使用者要求在週末做分類加總、週報統計或週結算。

# 工作流程
1. **確認資料範圍**
   - 先辨識是否涵蓋完整的一週。
   - 若日期不完整，仍依使用者提供的日期整理，不自行補資料。
   - 若金額、日期或類別不明，先列為「待確認」而不要猜測。

2. **整理每日明細**
   - 以日期為主軸，逐日列出每筆花費。
   - 每筆至少包含：
     - 日期
     - 項目/用途
     - 類別
     - 金額
   - 若使用者未提供類別，根據項目名稱做最合理的分類；若無法判斷，標為「其他」或「待確認」。

3. **統一類別**
   - 將相近名稱合併成一致類別，避免同義不同名造成統計分散。
   - 例如可將「餐飲」「吃飯」「午餐」統一為「餐飲」，前提是符合使用者資料內容。
   - 類別名稱要簡短、固定、可重複使用。

4. **建立每日表格**
   - 以表格呈現一週每日花費。
   - 建議欄位：
     - 日期
     - 星期
     - 項目
     - 類別
     - 金額
     - 備註（如有）
   - 同一天多筆支出時，逐筆列出，不要合併成單一金額，除非使用者要求。

5. **週末分類合計**
   - 在週末或表格下方，按類別加總整週金額。
   - 同時計算：
     - 各類別合計
     - 全週總支出
   - 若需要，也可補充每日小計，但核心一定要有類別合計。

6. **檢查一致性**
   - 確認所有明細金額加總等於全週總支出。
   - 確認各類別合計加總等於全週總支出。
   - 若有差異，回頭檢查是否漏列、重複或四捨五入造成誤差。

# 輸出格式
使用清楚的 Markdown 表格。

## 明細表
| 日期 | 星期 | 項目 | 類別 | 金額 | 備註 |
|---|---|---|---|---:|---|
| 2026-09-01 | 一 | 早餐 | 餐飲 | 60 |  |

## 類別合計
| 類別 | 合計 |
|---|---:|
| 餐飲 | 420 |
| 交通 | 180 |
| 其他 | 50 |
| **總計** | **650** |

# 處理原則
- 不要自行捏造不存在的花費。
- 不要把不確定的項目硬分到特定類別；不確定就標「其他」或「待確認」。
- 金額以使用者提供的幣別與格式為準；若幣別混用，先分開列示並提醒。
- 若使用者要求「週末算出各類別合計」，則合計應以整週資料為準，並在週末區塊呈現。
- 若資料量很大，仍保持表格可讀性，必要時先按日期排序，再按時間或輸入順序排列。
