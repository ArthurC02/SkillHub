# 目的
將會議逐字稿轉成結構化待辦清單，每一條都要包含：
- 待辦事項
- 負責人
- 期限

# 處理原則
1. 只根據逐字稿內容整理，不要自行補充未提到的事實。
2. 若逐字稿中有明確的行動承諾、指派、截止日或時間點，優先轉成待辦。
3. 若有多個人共同負責，保留所有明確提到的負責人；若只有團隊或部門，寫成逐字稿中的原文。
4. 若期限只提到相對時間，保留原文，例如「本週五前」、「下次會議前」。
5. 若逐字稿沒有明確負責人或期限，標記為「未提及」，不要猜測。
6. 若同一事項在不同段落重複提到，合併成一條待辦，避免重複。
7. 若內容只是討論、背景說明、意見交換，且沒有形成行動項目，不列入待辦。

# 萃取步驟
1. 通讀逐字稿，找出所有具有行動性質的句子。
2. 判斷是否為待辦：
   - 有人被指派去做某事
   - 有人承諾會完成某事
   - 有明確截止時間或交付點
3. 為每個待辦整理三個欄位：
   - 待辦事項：用簡潔動詞開頭，描述要完成的事
   - 負責人：逐字稿中明示的人名、角色或單位
   - 期限：逐字稿中明示的日期、時間或相對期限
4. 若逐字稿同時包含多個子任務，且負責人或期限不同，拆成多條待辦。
5. 若一條待辦包含多個步驟但同一負責人與期限，可合併成一條，內容用分號或逗號簡述。

# 輸出格式
請輸出為清楚的清單或表格，建議格式如下：

| 待辦事項 | 負責人 | 期限 |
|---|---|---|
| ... | ... | ... |

# 品質檢查
輸出前確認：
- 每條待辦都有負責人欄位
- 每條待辦都有期限欄位
- 沒有把推測內容寫進去
- 沒有漏掉明確的行動項目
- 沒有把純討論內容誤列為待辦
