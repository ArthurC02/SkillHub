# Slack 未回覆問題清單

## 這個 Skill 做什麼

從使用者提供的三個指定 Slack 頻道內容中，找出「未回覆的問題」，並輸出一份附連結的清單。當你需要每週做一次 Slack 問題盤點、只想保留尚未得到回覆的提問時，使用這個 Skill。

## 輸入要求

使用者會提供：
- 三個指定 Slack 頻道的訊息內容
- 每則訊息可對應的連結，或足以讓你生成可點擊連結的資訊
- 若有既定的「未回覆」判定規則，會一併提供

## 判定方式

1. 只處理使用者明確提供的三個頻道。
2. 只挑出看起來是「問題」的訊息，例如詢問、求助、請求確認、要求說明。
3. 只保留未回覆的問題：
   - 若同一串訊息中，後續內容已對該問題作出實質回應，則視為已回覆。
   - 若只有表態、感謝、跟進中的短句，且沒有實質答案，仍視為未回覆。
4. 不要擴充成摘要、分類或情緒分析；只輸出未回覆問題清單。
5. 若輸入沒有足夠資訊判定某則問題是否已回覆，只在該條目無法確認時標示為「需確認」，不要自行猜測。

## 輸出格式

輸出一份 Markdown 清單，格式如下：

- [問題文字](Slack 訊息 URL) — 頻道：#頻道名

如果有多筆，依原始出現順序列出。若沒有任何未回覆問題，輸出：

- 無

## 工作步驟

1. 讀取三個指定頻道的全部提供內容。
2. 逐則找出問題句。
3. 檢查每則問題後面是否有實質回覆。
4. 保留未回覆或無法確認是否已回覆的問題，並附上原始連結。
5. 以 Markdown 清單輸出，不加入多餘說明。

## 注意事項

- 不要依賴未提供的外部 Slack 存取權限；只根據使用者給你的內容工作。
- 不要假設未提供的頻道名稱、排序規則或額外欄位。
- 不要把已回覆的問題列入清單。
- 不要自行改寫問題含意；只可做最小必要的標點與格式整理。
