# Excel 客戶名單清理

此技能用於處理 Excel 中的客戶名單，目標是：
1. 去除重複資料。
2. 標記缺少電話的列。

## 執行步驟

1. **確認資料範圍與欄位**
   - 找出客戶名單所在的工作表。
   - 確認哪一欄是用來判斷重複的主鍵，通常是「客戶名稱」、「電話」或兩者組合。
   - 確認電話欄位名稱。

2. **先備份原始資料**
   - 在同一活頁簿中複製工作表，或另存一份副本。
   - 保留原始資料不變，所有清理都在副本上進行。

3. **去除重複資料**
   - 以最能代表同一客戶的欄位作為去重依據。
   - 若只有一個明確識別欄位，使用該欄位去重。
   - 若單一欄位不足以判斷，使用多欄組合去重，例如「客戶名稱 + 電話」。
   - 去重時保留第一筆出現的資料，除非資料規則要求保留最新一筆。
   - 去重後，記錄被移除的重複筆數。

4. **標記缺少電話的列**
   - 檢查電話欄是否為空白、只有空格，或是缺少有效內容。
   - 新增一欄，例如「電話缺失」或「缺少電話」。
   - 對缺少電話的列標記為「是」、「缺少」或 `TRUE`；其餘列標記為「否」或 `FALSE`。
   - 若需要，也可用醒目底色標示缺少電話的列，但欄位標記必須保留。

5. **檢查結果**
   - 確認去重後筆數是否合理。
   - 確認所有缺少電話的列都已被標記。
   - 抽查幾筆資料，確保沒有誤刪正常資料。

6. **輸出整理後的檔案**
   - 將清理後的工作表另存為新檔，避免覆蓋原始檔。
   - 檔名可加上 `cleaned`、`deduped` 或日期以便辨識。

## 注意事項

- 如果無法明確判斷哪個欄位代表同一客戶，先詢問使用者要以哪個欄位或欄位組合去重。
- 如果電話欄位格式不一致，先統一空白與格式，再進行缺失標記。
- 若資料中有合併儲存格、篩選或公式，先確認去重與標記不會破壞原有結構。
