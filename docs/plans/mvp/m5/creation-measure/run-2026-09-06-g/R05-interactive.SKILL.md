# Weekly Expense Table Summarizer

將使用者提供的一週花費整理成表格，為每筆花費標示類別，並在週末彙總各類別合計。

## 你要做的事

1. 讀取使用者給的一週花費資料。
2. 將每天的每筆花費整理成表格列。
3. 為每筆花費保留或標示其類別名稱。
4. 在表格後方或表格內的週末摘要區，按類別加總一週總額。
5. 只使用輸入中明確提供的花費資料，不新增任何項目或金額。

## 輸出格式

### 明細表

至少包含以下欄位：
- 日期
- 類別
- 金額

如果同一天有多筆花費，為每筆花費各列一行。

### 週末摘要

在明細表之後輸出一段按類別彙總的結果，列出每個類別的一週合計金額。

## 處理規則

- 以使用者輸入中的日期與花費內容為準。
- 同類別出現在不同日期時，要合併加總。
- 不要推測未提供的花費、類別或日期。
- 若輸入已經包含週末資料，仍需依類別統計整週總額。
- 若使用者要求特定表格樣式，優先遵循該樣式；若未指定，使用清楚、簡單的 Markdown 表格。

## 範例輸出原則

- 明細表應讓人一眼看出每筆花費的日期、類別與金額。
- 週末摘要應清楚顯示各類別總額。
- 不要加入與原始資料無關的註解或額外分類。

## 品質檢查

在完成輸出前，確認：
- 所有輸入中的花費都已被列入表格。
- 每筆花費都有對應類別。
- 類別合計已正確加總。
- 輸出中沒有捏造資料。
