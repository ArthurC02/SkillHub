# 每日新聞摘要寄送

## 這個技能做什麼
每天早上從三個新聞網站整理標題，濃縮成 5 條摘要，並寄到指定信箱。

## 先確認的事項
如果尚未提供以下資訊，先向使用者確認：
1. 三個新聞網站的網址。
2. 收件人信箱地址。
3. 寄送時間與時區。
4. 是否有偏好的摘要語氣或格式。
5. 是否允許使用網站首頁標題，或必須抓取特定分類頁。

## 執行流程
1. 取得三個新聞網站當天的標題。
   - 優先使用網站首頁或指定分類頁的最新標題。
   - 若網站有明確的「最新」、「頭條」、「熱門」區塊，優先採用。
   - 只保留與當天新聞相關的標題，避免重複或廣告內容。

2. 整理標題內容。
   - 將三個網站的標題合併後去重。
   - 找出跨網站重複出現或主題相近的新聞。
   - 以 5 條摘要呈現，優先涵蓋最重要、最具代表性的主題。
   - 每條摘要要短、清楚、可直接閱讀，避免逐字複製標題堆疊。

3. 撰寫郵件內容。
   - 主旨建議格式：`每日新聞摘要 - YYYY-MM-DD`
   - 內文包含：
     - 簡短開頭
     - 5 條摘要
     - 如有需要，可在每條後面附上來源網站名稱
   - 保持中性、客觀，不加入未經標題支持的推測。

4. 寄送郵件。
   - 使用可用的郵件工具或既有寄信流程發送。
   - 寄出前再次確認收件人與主旨無誤。

## 無法直接完成時怎麼做
如果目前沒有：
- 可存取的網路瀏覽工具，或
- 可用的寄信工具，或
- 已授權的信箱登入/SMTP 設定，

則不能直接完成自動抓取與寄送。此時應改為：
1. 明確說明缺少哪些能力。
2. 請使用者提供三個網站網址與收件信箱。
3. 請使用者提供可用的抓取與寄信方式，或改成手動提供標題後再協助整理成 5 條摘要。

## 品質檢查
在完成前檢查：
- 是否真的來自三個指定網站。
- 是否只有 5 條摘要。
- 是否有重複或過度相似的內容。
- 是否沒有捏造新聞細節。
- 是否已使用正確日期與收件人。
