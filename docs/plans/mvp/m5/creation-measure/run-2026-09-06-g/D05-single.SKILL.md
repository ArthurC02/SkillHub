# 新人到職流程

依照圖中的順序執行或整理流程，不要跳步。

## 流程步驟
1. **收到新人到職通知**
   - 確認新人姓名、到職日、部門、職稱與聯絡方式。
   - 若資訊不完整，先向人資或主管補齊。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認帳號命名規則、權限與初始密碼設定。
   - 完成後記錄信箱資訊，並依公司規範通知相關人員。

3. **加入 Slack 頻道**
   - 將新人加入必要的 Slack 頻道。
   - 至少包含部門、專案與公告類頻道；若公司有固定新人頻道，也一併加入。
   - 確認新人可正常存取。

4. **準備筆電與門禁卡**
   - 安排新人所需的筆電、周邊設備與門禁卡。
   - 檢查設備是否可用、帳號是否已設定、門禁權限是否正確。
   - 若有資產編號或領用紀錄，完成登記。

5. **安排第一週訓練**
   - 排定新人第一週的訓練內容與時程。
   - 包含公司制度、工具使用、工作流程與必要的安全/資安說明。
   - 將訓練安排通知新人與相關講師或主管。

6. **指派導師**
   - 為新人指定一位導師或 buddy。
   - 明確告知導師支援範圍，例如日常問題、流程熟悉與部門協作。
   - 確認新人知道聯絡對象。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 檢視適應狀況、訓練進度、工作障礙與後續支援需求。
   - 將面談重點與後續行動記錄下來。

8. **記錄到人資系統**
   - 將以上完成事項與關鍵資訊登錄到人資系統。
   - 確保紀錄包含完成時間、負責人與未完成事項。
   - 若有缺漏，先補齊再結案。

## 執行原則
- 依序完成，前一步未完成前不要進入下一步。
- 若某一步需要外部權限、實際設備或系統登入而目前無法取得，先列出缺少的資訊與需要聯絡的對象。
- 保留可追蹤紀錄，方便人資、主管與 IT 查核。
