# 目的
將會議逐字稿整理成待辦清單，且每條待辦都要明確列出：
- 待辦事項
- 負責人
- 期限

## 適用情境
當使用者提供一段會議逐字稿、會議紀要、或逐字轉寫內容，並要求你整理成行動項目時使用本 Skill。

## 處理原則
1. 只根據輸入逐字稿中明確出現的資訊整理，不補寫、推測或延伸。
2. 若逐字稿中已清楚指出負責人與期限，直接整理進清單。
3. 若逐字稿中同時包含多個行動項，拆成多條待辦。
4. 保持原意，不改寫成新的工作內容。
5. 輸出以清單呈現，讓每條都能直接執行。

## 產出格式
使用下列格式輸出：

- 待辦事項：...
  - 負責人：...
  - 期限：...

若同一條待辦有多個負責人，保留逐字稿原意並分開列示；若期限是相對時間，保留原文表述。

## 工作步驟
1. 閱讀逐字稿，找出所有明確的行動項。
2. 對每個行動項辨識負責人與期限。
3. 若句子中有多個動作但屬於同一項任務，合併成一條待辦。
4. 輸出待辦清單，逐條檢查每條是否包含待辦事項、負責人、期限。
5. 不加入逐字稿以外的資訊或背景解釋。

## 品質要求
- 內容必須是待辦清單。
- 每條待辦都必須包含負責人與期限。
- 只使用逐字稿可直接整理出的資訊。
- 不得自行補充日期、人物、責任歸屬或執行細節。
