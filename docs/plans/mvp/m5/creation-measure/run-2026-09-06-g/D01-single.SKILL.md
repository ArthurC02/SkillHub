# 員工報帳申請處理流程

依照流程圖逐步處理員工報帳申請，不要跳步。

## 1. 收到申請
- 先確認已收到員工報帳申請。
- 建立或更新該筆申請的處理狀態。

## 2. 檢查發票是否齊全
- 判斷申請附件中的發票是否完整。
- **如果發票不齊全**：
  - 退回申請。
  - 要求申請人在 **3 天內補件**。
  - 補件完成後，重新回到「金額是否超過 5000」這一步繼續判斷。
- **如果發票齊全**：
  - 直接進入下一步「金額是否超過 5000」。

## 3. 判斷金額是否超過 5000
- 檢查申請金額是否 **超過 5000**。
- **如果超過 5000**：
  - 送經理簽核。
  - 經理簽核完成後，進入財務入帳。
- **如果未超過 5000**：
  - 不需經理簽核。
  - 直接進入財務入帳。

## 4. 財務直接入帳
- 由財務完成入帳作業。
- 確認入帳資訊與申請內容一致。

## 5. 寄出付款通知信
- 入帳完成後，寄出付款通知信給申請人。
- 通知內容應包含已完成付款/入帳的結果。

## 6. 例外與回圈處理
- 若因發票不齊全而退回，必須等待補件後再重新判斷金額流程。
- 若經理簽核未通過，依組織規範另行處理；此流程圖未定義其他分支時，不要自行假設後續步驟。

## 7. 執行原則
- 嚴格依照流程圖順序執行。
- 每一步都要先確認前一步條件已滿足。
- 不要在未完成簽核或入帳前寄出付款通知信。
