## 目的

每週從三個 Slack 頻道中找出「未回覆的問題」，整理成可追蹤的清單，並附上每則訊息的連結。

## 適用範圍

- 只處理使用者指定的三個頻道。
- 只列出「問題」且「尚未回覆」的訊息。
- 若無法直接存取 Slack、無法查看頻道內容，或沒有訊息連結可取得，則先說明需要哪些頻道名稱、時間範圍與可存取的訊息來源；不要自行編造結果。

## 判定規則

1. **問題**：訊息內容是在提問、請求協助、尋求確認、或明確等待他人回應。
2. **未回覆**：該訊息下方沒有任何回應，包含：
   - 沒有 thread reply
   - 沒有後續明確答覆
   - 沒有人在同一串對話中完成處理或確認
3. **排除項目**：
   - 只是公告、轉貼、純資訊分享
   - 已經有人回覆或在 thread 中完成處理
   - 明顯不是問題的訊息
4. **時間範圍**：以「每週」為單位，優先檢查最近 7 天；若使用者另有指定週期，依指定週期。

## 作業步驟

1. 讀取三個目標頻道的訊息。
2. 逐則找出符合「問題」定義的訊息。
3. 檢查每則問題是否有回覆：
   - thread 是否有 reply
   - 是否有後續訊息直接回答
   - 是否已被標記為已處理（若來源可見）
4. 只保留未回覆者。
5. 為每則保留項目記下：
   - 頻道名稱
   - 發問者
   - 訊息摘要
   - 訊息連結
   - 發問時間
6. 若同一人同一主題重複發問，保留最早且最完整的一則，其他可合併註記為重複。
7. 若訊息內容不清楚是否為問題，保守處理：只有在明確看得出是提問時才列入。

## 輸出格式

用清單輸出，每一項一行，格式如下：

- [頻道名] 發問者：問題摘要｜時間｜連結

## 補充規則

- 連結必須指向原始 Slack 訊息或 thread。
- 摘要要短，保留關鍵字與問題核心。
- 若結果很多，依時間由新到舊排序，或依使用者要求排序。
- 若某個頻道完全沒有未回覆問題，也要在結果中註明該頻道為空。
