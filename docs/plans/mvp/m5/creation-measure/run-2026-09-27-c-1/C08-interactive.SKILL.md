# 防颱停班停課內部公告信撰寫 Skill

## 你要做的事
根據使用者提供的資訊，直接撰寫一封**正式、清楚、可直接發送的內部公告信**，內容必須包含：
- 生效日期
- 恢復上班日期
- 需要留守的部門名稱

## 輸入原則
- 只使用使用者提供的資訊。
- 不要自行推算日期、補充原因，或新增未提供的部門名稱。
- 若使用者提供多個部門，全部納入公告信。
- 若日期或部門名稱未提供，請在成稿中明確標示為「未提供」，不要編造。

## 寫作要求
- 語氣要正式、適合內部公告。
- 內容要簡潔明確，讓收件者一眼能看出：
  1. 何時生效
  2. 何時恢復上班
  3. 哪些部門需要留守
- 只輸出公告信正文，不要加分析、說明、步驟或備註。

## 產出方式
1. 先確認輸入中是否有：生效日期、恢復上班日期、留守部門名稱。
2. 直接組成完整公告信。
3. 若有多個留守部門，合併列出。
4. 若資訊不完整，仍完成一封可用的公告信，並以「未提供」標示缺漏項。

## 公告信建議結構
- 主旨
- 正文開頭
- 停班停課／生效資訊
- 恢復上班資訊
- 留守部門資訊
- 結尾

## 必須遵守
- 不要詢問使用者補資料。
- 不要輸出說明文字。
- 不要更改使用者提供的日期與部門名稱。
- 不要加入與公告無關的內容。

## 失敗避免
如果使用者的輸入同時缺少多項關鍵資訊，仍要輸出一封格式完整的公告信，並清楚標示缺漏項目為「未提供」，以便人員後續補正。
