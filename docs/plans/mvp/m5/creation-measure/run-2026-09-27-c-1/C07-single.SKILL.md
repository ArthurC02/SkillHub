# 目的
用來核對員工出差報帳明細，計算每天的花費總和，並確認所有日期加總後是否與員工填寫的總計一致。

# 適用情境
- 收到員工的出差報帳明細、收據清單或費用表。
- 需要檢查每日金額是否正確、總計是否一致。
- 需要找出差異並回報哪一天或哪一筆有問題。

# 核對流程
1. **先辨識資料欄位**
   - 找出每一筆費用的日期、項目、金額。
   - 找出員工填寫的「每日小計」與「總計」欄位；若沒有每日小計，就直接依日期彙總。
   - 確認金額單位一致，例如都是同一幣別。

2. **整理成日期分組**
   - 將同一天的所有費用歸在同一組。
   - 若同一天有多筆費用，逐筆保留，避免漏算。
   - 若日期格式不一致，先統一成同一格式再分組。

3. **計算每日加總**
   - 對每個日期，把該日所有金額相加。
   - 若明細中已有每日小計，仍要自行重算一次以驗證。
   - 記錄每一天的計算結果，方便比對。

4. **計算整體總和**
   - 將所有日期的每日加總再相加，得到整體總額。
   - 若表單有員工填寫的總計，將其與計算結果比對。

5. **檢查一致性**
   - 若計算總額 = 員工填寫總計，標記為一致。
   - 若不一致，找出差額：
     - 差額 = 計算總額 - 員工總計
   - 進一步檢查：
     - 是否有某一天漏算或重複算。
     - 是否有金額輸入錯誤。
     - 是否有小數位或四捨五入差異。

6. **輸出核對結果**
   - 以清楚格式列出：
     - 每日日期
     - 該日明細筆數
     - 該日加總
     - 全部日期總和
     - 員工填寫總計
     - 是否一致
   - 若不一致，明確指出差額與可疑日期。

# 建議輸出格式
- 日期：YYYY-MM-DD
- 該日筆數：N
- 該日加總：X
- 全部加總：Y
- 員工填寫總計：Z
- 結果：一致 / 不一致
- 差額：Y - Z

# 注意事項
- 不要自行補齊缺漏金額；若資料不完整，應標示缺漏並請求補件。
- 若同一筆費用出現兩次，需標記為可能重複報帳。
- 若有幣別不同、稅額未含、或匯率換算，需先確認是否應納入同一總計。
- 若表單同時有「未稅」、「稅額」、「含稅」欄位，應依報帳規則確認要加總哪一種金額，避免混算。
