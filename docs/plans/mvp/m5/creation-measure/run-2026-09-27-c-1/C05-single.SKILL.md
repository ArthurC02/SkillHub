# 目的
將一段客服回覆改寫成**不超過 30 個字**的極短訊息，且**必須同時包含**：
1. 退款金額
2. 退款日期
3. 訂單編號

若無法在 30 個字內同時保留三項資訊，先嘗試更精簡的表達；若仍做不到，明確告知無法在限制內完整保留，並請求使用者放寬字數限制或提供更短的原文。

# 處理步驟
1. **先抽取三項必要資訊**
   - 退款金額：保留原始數字與幣別/單位。
   - 退款日期：保留原始日期格式，優先用最短且不失真的寫法。
   - 訂單編號：保留完整編號，不可省略關鍵字元。

2. **確認是否可壓縮**
   - 檢查原文是否已包含三項資訊。
   - 若缺少任一項，不要自行補造；改為要求提供缺少資訊。

3. **改寫成短句**
   - 優先使用最短可讀格式，例如：
     - `退款$100 1/5 訂單A123`
     - `退100元 1/5 訂單A123`
   - 可省略贅字，如「已為您」、「將於」、「處理完成」等。
   - 不要加入原文沒有的承諾、原因或額外說明。

4. **字數檢查**
   - 以最終輸出為準，確認**不超過 30 個字**。
   - 若超過，進一步刪除非必要字詞，但不得刪除三項必要資訊。

5. **完整性檢查**
   - 最終輸出必須同時包含：退款金額、退款日期、訂單編號。
   - 任一項缺失都視為不合格，需重新改寫。

# 輸出規則
- 只輸出改寫後的短句，不要加標題、說明或項目符號。
- 不要輸出多個版本。
- 不要超過 30 個字。
- 不要遺漏退款金額、退款日期、訂單編號。

# 若資訊不足
若原文沒有提供三項資訊中的任一項，輸出一句簡短提示，要求補齊缺少資訊，例如：
`請提供退款金額、日期與訂單編號`
但若此提示會超過 30 個字，優先保留「請提供」與缺少項目名稱，並盡量精簡。
