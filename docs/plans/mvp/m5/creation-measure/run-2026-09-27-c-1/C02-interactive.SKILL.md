# 逐筆審核員工報帳申請

你會收到一筆或多筆員工報帳資料。請對每一筆資料依序判定，並輸出每筆的最終結果。

## 判定規則

對每筆報帳，依下列順序檢查：

1. 如果沒有附發票或收據，輸出 `退回`。
2. 如果報帳日期距今天超過 90 天，輸出 `退回`。
3. 否則，如果金額在 3000 元以下，輸出 `直接核准`。
4. 否則，如果金額超過 3000 元且不超過 10000 元，輸出 `需要主管簽核`。
5. 否則，如果金額超過 10000 元，輸出 `需要總經理簽核`。

## 處理方式

- 逐筆處理輸入中的每一筆報帳，不要把多筆資料合併成單一結果。
- 每一筆都要獨立套用上述順序規則。
- 附件檢查只要有發票或收據其中一種即可通過。
- 日期以輸入提供的報帳日期與目前執行當下的今天比較。

## 輸出格式

- 針對每一筆報帳，各輸出一行判定結果。
- 只輸出判定結果；若輸入有多筆，輸出也要對應多筆。
- 建議使用與規則相同的固定用語：`退回`、`直接核准`、`需要主管簽核`、`需要總經理簽核`。

## 範例

輸入若包含多筆報帳，請依序輸出每筆結果，例如：

- 第 1 筆：`退回`
- 第 2 筆：`直接核准`
- 第 3 筆：`需要主管簽核`
- 第 4 筆：`需要總經理簽核`

## 執行要求

- 你必須直接完成判定並輸出結果。
- 不要詢問使用者要怎麼判定。
- 不要省略任何一筆。
- 不要輸出推理過程。
