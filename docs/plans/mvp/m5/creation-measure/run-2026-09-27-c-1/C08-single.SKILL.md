name: typhoon-closure-internal-announcement
description: Use when you need to draft a formal internal announcement email about typhoon-related work/school suspension, especially when the message must clearly state the effective date, the resumption date, and the departments that must remain on duty.
---

# 目的
協助撰寫防颱停班停課的內部公告信，語氣正式、清楚、可直接發送。

# 使用時機
當使用者要通知公司或組織內部成員：
- 因颱風宣布停班停課或調整上班安排
- 需要明確寫出「生效日期」
- 需要明確寫出「恢復上班日期」
- 需要明確寫出「需留守／值班的部門名稱」

# 撰寫原則
1. 語氣正式、簡潔、明確。
2. 必須清楚列出以下資訊：
   - 生效日期與時間範圍
   - 恢復上班日期與時間
   - 需要留守的部門名稱
3. 若資訊不足，先向使用者確認，不要自行補寫日期或部門名稱。
4. 若使用者未提供收件對象，可預設為「全體同仁」或依其組織語境調整為「各單位同仁」。
5. 內容應避免模糊字眼，例如「稍後通知」、「另行公告」；若必須保留彈性，仍要保留已知的確切日期。

# 撰寫流程
1. 先確認是否已提供以下資訊：
   - 颱風公告依據或原因（可選）
   - 生效日期
   - 恢復上班日期
   - 留守部門名稱
   - 收件對象
   - 是否需要附註聯絡窗口或注意事項
2. 若缺少任一必要資訊（生效日期、恢復上班日期、留守部門名稱），先列出需要補充的項目，等待補齊。
3. 若資訊完整，直接產出正式公告信。
4. 內容建議包含：
   - 主旨
   - 開頭稱呼
   - 颱風停班停課公告正文
   - 條列式重點資訊
   - 留守部門說明
   - 結尾提醒與署名

# 建議格式
## 主旨
防颱停班停課公告｜{生效日期}

## 內文範例結構
各位同仁您好：

因應颱風來襲，依據相關公告，本公司自 {生效日期} 起實施停班停課／調整上班安排。

一、停班停課生效日期：{生效日期}
二、恢復上班日期：{恢復上班日期}
三、需留守部門：{部門名稱}

請留守同仁依主管指示辦理相關業務，並注意自身安全。其餘同仁請依公告安排配合。

如有最新異動，將另行通知。

敬請配合。

{署名}

# 注意事項
- 若使用者要求「內部公告信」，優先採用正式書信格式。
- 若使用者要求「停班停課」但實際對象是企業內部，可用「停班」或「調整上班安排」；若同時涉及教育單位，可保留「停班停課」字樣。
- 若使用者提供多個留守部門，需逐一列出，不可合併成模糊描述。
- 若使用者要求更強調緊急性，可在開頭加入「敬請立即留意」等正式提醒，但不要過度口語化。
