# 每週週報自動寄送 Skill

## 先確認這件事能不能真的自動化
這個需求**可以被規劃與設定流程**，但是否能「真的每週五自動寄出」取決於你是否已經有可用的郵件與排程環境，例如：
- 郵件服務（Gmail、Outlook、公司信箱）
- 排程工具（系統排程、工作流程平台、郵件自動化服務）
- 已授權的帳號與寄信權限

如果目前沒有這些工具或權限，先不要假設能直接完成；應改為收集必要資訊並產出可執行的設定方案。

## 目標
協助使用者把週報寄送流程固定化，讓系統在每週五自動寄給主管，並在之後不需要手動操作。

## 執行步驟

### 1. 收集必要資訊
先確認以下內容：
- 主管收件人信箱
- 寄件帳號與可用郵件服務
- 週報內容來源
  - 固定模板
  - 手動撰寫後自動寄出
  - 從文件、表單、試算表或系統彙整
- 寄送時間
  - 每週五的幾點
  - 時區
- 是否需要副本收件人（CC/BCC）
- 郵件主旨格式
- 郵件正文格式
- 是否需要附件
- 是否需要失敗通知或寄送紀錄

如果缺少任何一項，先列出缺口並請使用者補齊。

### 2. 判斷自動化方式
根據可用環境，選擇最合適的方式：
- **郵件平台內建排程**：若郵件服務支援延後寄送或規則自動化
- **工作流程平台**：若可用自動化工具串接郵件與排程
- **系統排程**：若可在電腦或伺服器上執行定時任務

若沒有任何可用工具，明確告知：這個需求不能只靠文字指令完成，必須先有可執行的郵件與排程環境。

### 3. 定義週報內容生成方式
選擇一種固定方式：
- **固定模板**：每週填入相同欄位
- **半自動彙整**：從指定來源抓取內容後組成週報
- **完全手動撰寫後自動寄送**：先完成內容，再由排程在指定時間寄出

若內容來源不明，先建立最簡單的模板，避免流程卡住。

### 4. 建立寄送規則
設定以下規則：
- 每週五觸發
- 觸發時間固定
- 若當週週報已寄出則不重複寄送
- 若寄送失敗，記錄錯誤並通知使用者
- 若主管信箱變更，需更新設定

### 5. 準備郵件格式
建議固定以下欄位：
- 主旨：`週報 - YYYY/MM/DD`
- 收件人：主管信箱
- 內文：
  - 本週重點
  - 進度更新
  - 風險與阻礙
  - 下週計畫
- 附件：如有需要則附上週報文件

### 6. 驗證流程
在正式啟用前，先做一次測試：
- 模擬一個週五觸發
- 確認信件能成功寄出
- 確認收件人、主旨、內容、附件都正確
- 確認時區與時間無誤
- 確認不會重複寄送

### 7. 啟用後的維護
啟用後只需在以下情況更新設定：
- 主管更換
- 寄送時間更改
- 週報格式變更
- 郵件帳號或權限變更
- 自動化工具失效或停用

## 產出內容
當你處理這個需求時，應輸出：
1. 一份清楚的自動化流程說明
2. 一份需要填入的資訊清單
3. 一份可執行的排程與寄送規格
4. 若工具不足，明確說明無法直接完成自動寄送，並列出缺少的條件

## 注意事項
- 不要假設已經有登入或授權
- 不要假設可以直接操作外部郵件系統
- 不要承諾「已經排程完成」除非實際環境與工具已確認可用
- 若使用者只提供一句需求，先問清楚必要資訊，再設計流程
