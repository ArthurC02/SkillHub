# 逐筆報帳審核

依照下列規則，對**每一筆**報帳申請獨立判定結果並輸出。

## 審核順序

對每筆報帳，必須依以下順序檢查：

1. **先檢查是否附發票或收據**
   - 若沒有附發票或收據，結果一律為：**退回**。
   - 這一步優先於其他所有規則。

2. **再檢查報帳日期是否超過 90 天**
   - 以今天為基準，若報帳日期距離今天**超過 90 天**，結果一律為：**退回**。
   - 這一步也優先於金額規則。

3. **最後依金額判定簽核層級**
   - 金額 **3000 元以下**：**直接核准**
   - 金額 **超過 3000 元到 10000 元（含 10000 元）**：**需要主管簽核**
   - 金額 **超過 10000 元**：**需要總經理簽核**

## 判定規則細節

- 「沒有附發票或收據」包含：
  - 明確標示未附
  - 附件欄位為空
  - 無法確認有任何有效憑證
- 「報帳日期距離今天超過 90 天」以自然日計算。
- 金額判定以單筆報帳金額為準，不與其他筆合併。
- 每筆報帳都要獨立輸出結果，不可只給整體結論。

## 輸出格式

對每筆報帳輸出一行，至少包含：

- 報帳識別資訊（如編號、姓名或摘要）
- 判定結果
- 若為退回，簡短說明原因
- 若需簽核，說明簽核層級

### 建議格式

- `報帳A：退回（未附發票或收據）`
- `報帳B：退回（報帳日期超過 90 天）`
- `報帳C：直接核准`
- `報帳D：需要主管簽核`
- `報帳E：需要總經理簽核`

## 實作步驟

對輸入中的每一筆報帳，依序執行：

1. 讀取該筆的附件狀態、報帳日期、金額。
2. 若無發票或收據，輸出退回。
3. 否則若日期超過 90 天，輸出退回。
4. 否則依金額門檻輸出對應結果。
5. 重複直到所有報帳都完成審核。

## 注意事項

- 不要跳過任何一筆。
- 不要把多筆報帳合併判定。
- 若資料不足以確認是否有發票/收據或日期是否超過 90 天，應先標示為需要補件或補充資訊；但若系統要求只能在既定四類中輸出，則以最保守方式處理並說明原因。
