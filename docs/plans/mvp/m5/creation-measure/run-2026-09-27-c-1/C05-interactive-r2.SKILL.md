# compress-customer-service-refund-reply

你會收到一段客服回覆文字。你的工作是把它壓縮成一則可直接使用的短回覆，並嚴格滿足以下要求：

1. 輸出不超過 30 個字。
2. 輸出一定要包含退款金額。
3. 輸出一定要包含退款日期。
4. 輸出一定要包含訂單編號。
5. 三項資訊缺一不可。

## 執行方式

- 先從輸入中找出退款金額、退款日期、訂單編號。
- 只保留這三項必要資訊，以及為了讓句子通順而不可避免的最少連接文字。
- 不新增輸入沒有提供的金額、日期、編號或其他事實。
- 如果原文用不同寫法表示同一資訊，就保留其實際值，不要自行改寫成新數字或新日期。
- 盡量壓縮到最短，但不能犧牲三項必要資訊。

## 當資訊不足時

- 如果輸入缺少任一必要資訊，就明確指出缺少哪些項目。
- 不要自行補寫、猜測或用看似合理的值替代。
- 若因為缺漏而無法同時滿足 30 字限制與三項完整性，優先保留「缺少項目」的明示結果，且不要默默省略缺項。

## 輸出要求

- 直接輸出完成的短回覆。
- 不要附加說明、分析、標題或步驟。
- 若字數與三項資訊兩者衝突，保留三項資訊，並仍盡量不超過 30 個字。

## 可用的常見寫法

- 可以使用「退」「退款」「已退」等最短且仍清楚的連接詞。
- 可以用符號或標點協助壓縮，但不要讓內容變得不清楚。
- 若三項資訊都存在，優先把它們直接拼成最短可讀句。

## 範例思路

- 輸入含有「訂單編號 A12345、退款金額 1200 元、退款日期 2024/09/18」時，輸出應只保留這三項核心資訊，且字數不超過 30 個字。
- 輸入若缺少退款日期，輸出應明示「缺退款日期」或等值的缺漏提示，而不是捏造日期。
