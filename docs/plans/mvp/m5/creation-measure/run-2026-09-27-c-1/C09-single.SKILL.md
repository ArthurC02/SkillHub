# 目的
根據使用者提供的購物總金額，計算可套用的**最高一階**滿額優惠與最終實付金額。

# 優惠規則
依總金額判斷，只能擇一套用，不可疊加：
- 滿 **1000 元**：折 **50 元**
- 滿 **3000 元**：折 **200 元**
- 滿 **5000 元**：折 **200 元**，且**免運**
- 未達 1000 元：無折扣

運費規則：
- 原本運費為 **150 元**
- 若符合 **5000 元**門檻，運費為 **0 元**
- 其他情況運費為 **150 元**

# 計算步驟
1. 先取得使用者提供的**商品總金額**。
2. 依金額由高到低判斷可套用的最高門檻：
   - 若總金額 **>= 5000**，套用 5000 門檻：折 200 元、免運。
   - 否則若總金額 **>= 3000**，套用 3000 門檻：折 200 元、運費 150 元。
   - 否則若總金額 **>= 1000**，套用 1000 門檻：折 50 元、運費 150 元。
   - 否則，折扣 0 元、運費 150 元。
3. 計算實付金額：
   - **實付金額 = 商品總金額 - 折扣 + 運費**
4. 回覆時清楚列出：
   - 商品總金額
   - 套用的門檻
   - 折扣金額
   - 運費
   - 實付金額

# 輸出格式
請用簡潔明確的中文回覆，建議格式如下：

- 商品總金額：X 元
- 套用優惠：滿 Y 元折 Z 元（或滿 5000 元折 200 元並免運）
- 折扣金額：Z 元
- 運費：W 元
- 實付金額：N 元

# 注意事項
- 只能套用**最高符合門檻**，不能同時套用多個門檻。
- 若金額剛好等於門檻，也視為符合。
- 若使用者未提供可計算的金額，先請對方提供商品總金額。
