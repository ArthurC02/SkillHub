# 目的
將三家供應商的報價整理成可比較的表格，並找出每個品項的最低價與最便宜供應商。

# 適用情境
- 使用者提供三家供應商的報價單、圖片、PDF、試算表或文字內容。
- 需要把不同格式的報價統一成同一張比價表。
- 需要判斷每個品項誰最便宜，並指出是否有價格不可直接比較的情況。

# 工作原則
1. 只根據使用者提供的資料整理，不自行補價格。
2. 若品項名稱、規格、單位、幣別、稅別或數量不一致，先標示為「需確認」再比較。
3. 若報價包含運費、稅金、折扣、最小訂購量、不同包裝規格，需先說明是否已納入比較。
4. 若無法直接比價，明確列出原因，不要硬判定最低價。

# 處理步驟

## 1. 先盤點資料
從三家供應商資料中擷取以下欄位：
- 供應商名稱
- 品項名稱
- 規格/型號
- 單位
- 數量
- 單價
- 幣別
- 稅別（未稅/含稅）
- 小計或總價
- 交期、運費、備註（若有）

若資料缺漏，保留空白並註記「未提供」。

## 2. 統一比較基準
在比價前先確認並統一：
- 同一品項是否為相同規格或可視為同等品
- 單位是否一致（例如：pcs、箱、組、kg）
- 價格是否同為未稅或含稅
- 幣別是否一致；若不同，需先換算後再比價，並註明匯率來源若使用者有提供
- 是否需要把運費或其他附加費平均到單價中

若無法統一，將該列標為「不可直接比較」。

## 3. 建立比價表
輸出一張表，建議欄位如下：
- 品項
- 規格/型號
- 單位
- 數量
- 供應商 A 單價
- 供應商 B 單價
- 供應商 C 單價
- 最低價
- 最便宜供應商
- 備註

若同一品項有多個規格，分開列示，不要混在同一列。

## 4. 判定最便宜
對每個可比較品項：
- 比較三家單價或換算後單價
- 找出最低價
- 若有同價，標示「並列最低」
- 若價格差異極小但資料基準不同，先標示「需確認後再判定」

## 5. 補充摘要
在表格後提供簡短摘要：
- 哪一家整體最低價品項最多
- 哪一家平均價格較低（僅限可比較品項）
- 哪些品項無法直接比較及原因

# 輸出格式
使用繁體中文，並保持清楚易讀。

## 建議格式
### 比價表
| 品項 | 規格/型號 | 單位 | 數量 | 供應商A單價 | 供應商B單價 | 供應商C單價 | 最低價 | 最便宜供應商 | 備註 |
|---|---|---:|---:|---:|---:|---:|---:|---|---|

### 摘要
- 最多最低價品項：
- 平均價格最低：
- 需確認項目：

# 品質檢查
在完成前檢查：
- 是否每個品項都已對應到三家供應商
- 是否有把不同單位或不同稅別誤判為可比
- 是否清楚標示缺漏資料與不可比較項目
- 是否所有最低價判定都可追溯到原始數字

# 若資料不足
如果使用者提供的資料不足以完成比價，先列出缺少的欄位，並請使用者補齊後再整理。
