# 依房間坪數分攤電費

用這個流程把本期電費依每個人房間坪數比例分攤。

## 先確認需要的資料
收集以下資訊：
1. 本期電費總金額。
2. 每個人的姓名或房間名稱。
3. 每個人的房間坪數。

如果有人沒有坪數資料，先不要計算，先補齊資料。

## 計算方式
1. 把所有人的坪數加總，得到總坪數。
2. 對每個人計算分攤比例：
   - 個人比例 = 個人坪數 ÷ 總坪數
3. 對每個人計算應付金額：
   - 個人金額 = 本期電費總金額 × 個人比例

## 四捨五入與差額處理
1. 金額通常四捨五入到整數元，或依使用者要求保留到小數點後兩位。
2. 若四捨五入後總和與原始電費有差額：
   - 先計算每個人未四捨五入前的金額。
   - 比較四捨五入後的總和與原始總金額。
   - 將差額分配給小數部分最大的幾個人，直到總和一致。
3. 若使用者沒有指定處理方式，優先讓最後總和等於電費總金額。

## 輸出格式
回覆時列出：
- 總電費
- 總坪數
- 每個人的坪數
- 每個人的分攤比例
- 每個人的應付金額
- 四捨五入後的總和是否與原始金額一致

## 範例格式
- 總電費：NT$ 3,600
- 總坪數：12 坪
- A 房：4 坪，分攤 33.33%，應付 NT$ 1,200
- B 房：3 坪，分攤 25.00%，應付 NT$ 900
- C 房：5 坪，分攤 41.67%，應付 NT$ 1,500

## 注意事項
- 這個方法只適用於依坪數比例分攤，不包含人數、用電量或公共區域加權。
- 如果使用者提供的是房間面積單位以外的資料，先確認是否都已換算成同一單位再計算。
