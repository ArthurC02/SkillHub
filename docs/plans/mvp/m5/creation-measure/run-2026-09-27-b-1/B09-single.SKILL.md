name: reply-quote-with-quality-constraint
description: Use when you need to draft a customer-facing quotation reply that must explain a delivery request cannot be met because a new flavor requires a mandatory 14-day full quality inspection before shipment.
---

# 目的
協助撰寫給客戶的報價回覆，當客戶要求 7 天內交貨，但因為是新口味且公司規定出貨前必須完成 14 天品管全檢時，清楚、禮貌地說明無法承諾 7 天交貨，並提供可行替代方案。

# 使用時機
當你收到客戶詢問報價或交期，且已知：
- 客戶要求的交期短於公司內部規範
- 產品屬於新口味／新配方／新規格
- 公司有固定的出貨前品管或全檢天數要求

# 處理步驟
1. 先確認關鍵事實：
   - 客戶要求的交期：7 天
   - 產品狀態：新口味
   - 公司規定：出貨前需完成 14 天品管全檢

2. 判斷可否承諾：
   - 若公司規定不可例外，明確表示無法配合 7 天交貨。
   - 不要暗示可以先出貨再補檢，也不要承諾未經確認的例外。

3. 回覆內容要包含三個部分：
   - 感謝客戶需求與詢問
   - 說明限制原因：新口味需 14 天品管全檢，故無法於 7 天內出貨
   - 提供替代方案：例如調整交期、先安排檢驗排程、或請客戶接受較長交期

4. 語氣要求：
   - 禮貌、專業、簡潔
   - 避免推卸責任
   - 避免過度技術化，讓客戶容易理解

5. 若需要直接產出回覆文字，使用以下結構：
   - 開頭：感謝與確認需求
   - 中段：說明新口味需 14 天品管全檢，無法滿足 7 天交期
   - 結尾：提出可配合的最早交期或請客戶確認是否接受調整

# 建議回覆範例
「感謝您的詢問。此款為新口味，依公司規定出貨前需完成 14 天品管全檢，因此目前無法配合 7 天內交貨。若您方便，我們可以依 14 天檢驗時程安排出貨，並協助您確認可行交期。」

# 注意事項
- 不要自行縮短品管天數。
- 不要在未確認前承諾例外出貨。
- 若客戶要求更快交期，應先回報內部確認是否有正式核准機制，再對外回覆。
