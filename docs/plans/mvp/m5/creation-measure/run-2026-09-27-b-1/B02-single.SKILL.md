# 出差報銷審核流程

依下列規則逐筆審核報銷申請：

## 1. 先確認必要資料
每筆申請至少要有：
- 報銷金額
- 是否附發票
- 是否有主管簽核（若金額達門檻）

若任一必要資料缺漏，視為未通過，退回並寫明缺少的資料。

## 2. 依金額判定審核條件
### A. 金額小於 2000 元
- 只要有附發票即可通過。
- 不需要主管簽核。

### B. 金額大於或等於 2000 元
- 必須有主管簽核才可通過。
- 若沒有主管簽核，即使有發票也要退回。

## 3. 審核結果判定
### 通過
符合對應條件時，標記為通過。

### 退回
不符合條件時，標記為退回，並寫明原因。原因要具體指出：
- 金額未達/已達門檻
- 是否缺發票
- 是否缺主管簽核

## 4. 建議的退回原因寫法
- 「退回：金額 2000 元以上（含），需主管簽核，惟未附主管簽核。」
- 「退回：未附發票，無法通過報銷。」
- 「退回：金額 2000 元以上（含），需主管簽核，且本案缺少主管簽核。」

## 5. 審核輸出格式
對每筆申請輸出以下其中一種結果：
- `通過`
- `退回：原因`

## 6. 審核順序建議
1. 檢查金額是否為數字且可判定。
2. 檢查是否附發票。
3. 若金額小於 2000 元，確認有發票即通過。
4. 若金額大於或等於 2000 元，確認有主管簽核才通過。
5. 不符合者退回並寫原因。
