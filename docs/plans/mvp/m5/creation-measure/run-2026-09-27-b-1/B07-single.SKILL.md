# Customer Satisfaction Survey Questionnaire

Use this skill when the user wants a customer satisfaction survey, feedback form, or post-interaction questionnaire.

## Goal
Produce a clear, usable questionnaire that measures customer satisfaction and identifies improvement opportunities.

## Process
1. **Clarify the survey context if needed**
   - If the user has not specified the business, product, service, or channel, ask for it.
   - If the user has not specified the survey length, default to a short survey of 8–12 questions.
   - If the user has not specified the language, write the survey in the user’s language.

2. **Choose the survey structure**
   Include these sections in order:
   - Greeting / purpose statement
   - Overall satisfaction
   - Specific experience areas
   - Loyalty / recommendation
   - Open-ended feedback
   - Optional demographics or segmentation questions only if relevant

3. **Write questions that are easy to answer**
   - Use one idea per question.
   - Prefer a mix of rating-scale, multiple-choice, and open-ended questions.
   - Use consistent scales, such as 1–5 or 1–10, and label them clearly.
   - Avoid leading, double-barreled, or overly technical wording.

4. **Include core satisfaction measures**
   At minimum, include questions for:
   - Overall satisfaction
   - Whether expectations were met
   - Ease of doing business / using the service
   - Staff or support quality, if applicable
   - Product/service quality, if applicable
   - Likelihood to recommend
   - One or two open-ended improvement questions

5. **Adapt to the customer journey**
   - For service interactions, include timeliness, professionalism, and resolution quality.
   - For products, include quality, usability, reliability, and value.
   - For digital experiences, include navigation, speed, and clarity.
   - For retail or in-person experiences, include environment, staff helpfulness, and checkout experience.

6. **Keep it concise unless the user asks for more**
   - Default to 8–12 questions.
   - If the user asks for a longer survey, expand with optional sections.

7. **Provide ready-to-use output**
   - Present the survey as a numbered list.
   - Include suggested answer options for each closed question.
   - If helpful, add a short intro text and a thank-you closing.

## Recommended question set
Use or adapt these questions:
1. Overall, how satisfied are you with your experience?
2. To what extent did our product/service meet your expectations?
3. How easy was it to complete your task or get what you needed?
4. How would you rate the quality of the product/service?
5. How would you rate the helpfulness or professionalism of our team? (if applicable)
6. How likely are you to recommend us to others?
7. What did we do well?
8. What could we improve?
9. Is there anything else you would like to share?

## Output guidance
- If the user asks for a polished questionnaire, format it as a survey ready to copy into a form tool.
- If the user asks for a brief version, keep only the essential questions.
- If the user asks for a specific audience, tailor wording to that audience’s level of familiarity.
- If the request lacks enough detail to tailor the survey, state the missing context and ask concise follow-up questions.
