# 目的
協助把一批發票資料整理成可核銷、可上傳的狀態，並在條件允許時完成上傳前的準備與檢查。

# 適用範圍
- 發票、收據、費用單、報銷單的整理
- 核對金額、日期、供應商、稅額、幣別、部門/專案歸屬
- 彙整成公司記帳或核銷系統需要的欄位格式
- 檢查缺件、重複、異常與待補資料

# 重要限制
- 若需要登入公司系統、使用內網、或實際上傳資料，而目前沒有可用的授權、帳號或工具，先停止在「準備」階段，不要假裝已完成上傳。
- 若資料含有敏感個資、稅務資訊或公司機密，只處理完成任務所需的最少資訊。
- 若發票影像或表格內容不清楚，先標記為待確認，不要自行補寫。

# 工作流程

## 1. 盤點資料
先確認手上有哪些資料來源，例如：
- 發票影像、PDF、照片
- Excel/CSV/Google Sheet
- Email 轉寄內容
- 手動列出的費用清單

建立一份清單，逐筆記錄每張單據是否具備以下欄位：
- 單據編號/發票號碼
- 日期
- 供應商名稱
- 品項或用途
- 金額（未稅、稅額、含稅）
- 幣別
- 付款方式
- 部門/專案/成本中心
- 可否報銷的備註

## 2. 標準化欄位
把所有資料統一成同一格式：
- 日期統一為公司要求格式；若未知，保留原始日期並註記格式
- 金額統一為數字格式，保留小數位
- 供應商名稱統一大小寫與常用別名
- 同一筆資料若有多個來源，以原始憑證為準，其他來源作為備註

## 3. 驗證與對帳
逐筆檢查：
- 是否有重複發票號碼或重複金額/日期/供應商組合
- 金額是否與稅額、含稅金額一致
- 日期是否落在本月或公司允許的核銷期間
- 是否缺少必要欄位
- 是否有超出報銷規則的項目（例如私人消費、不可報銷品項、缺少抬頭）

把問題分成三類：
- 可直接上傳
- 需補件/待確認
- 不可核銷

## 4. 整理成上傳格式
依公司記帳系統要求，整理成可匯入的表格或欄位順序。若沒有明確格式，至少整理成以下欄位：
- 發票號碼
- 日期
- 供應商
- 摘要/用途
- 金額
- 稅額
- 幣別
- 部門/專案
- 備註
- 附件檔名或連結
- 狀態

若系統需要附件命名規則，統一命名，例如：
- 日期_供應商_金額_發票號碼

## 5. 上傳前檢查
在任何實際上傳前，確認：
- 已取得授權
- 已登入正確帳號與正確公司/帳套
- 匯入欄位對應正確
- 附件已完整
- 沒有把待確認資料誤列為可核銷

若沒有登入或上傳工具，輸出一份「可直接貼入系統」的整理結果與待辦清單，交由有權限的人上傳。

## 6. 完成核銷所需輸出
最後整理成三份結果：
1. **可上傳清單**：所有可直接核銷的單據
2. **待補件清單**：缺少資料、需確認或需補附件的單據
3. **異常清單**：重複、不可報銷、金額不一致或超出規則的單據

每筆至少包含：
- 識別資訊
- 問題或狀態
- 建議處理方式

# 品質要求
- 不要自行編造缺失欄位
- 不要把未確認資料標成已核銷
- 不要忽略重複與金額不一致
- 若資料量大，先分批處理並保留中間結果

# 若資訊不足時要問的問題
- 公司記帳系統需要哪些欄位與格式？
- 本月核銷的截止日期是什麼？
- 哪些費用類型可報銷、哪些不可報銷？
- 是否需要依部門、專案或成本中心分類？
- 是否有固定的附件命名或匯入模板？

# 交付標準
完成時應能提供：
- 已整理好的發票/核銷資料
- 缺漏與異常摘要
- 若無法實際上傳，則提供可直接上傳的匯入檔內容或清單，以及明確的下一步。
