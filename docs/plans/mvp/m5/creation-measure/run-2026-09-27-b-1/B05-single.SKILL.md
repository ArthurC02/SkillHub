# 目的
將會議記錄整理成可執行的待辦事項清單，並為每一項補上負責人與期限。

# 適用情境
- 使用者提供會議記錄、逐字稿、討論摘要或會議筆記。
- 使用者要求整理成待辦事項、action items、follow-ups、下一步。
- 使用者特別要求每項包含負責人與期限。

# 工作原則
1. 只根據會議內容整理，不要自行杜撰任務、負責人或日期。
2. 若資訊不足，保留為「未指明」或「待確認」，不要猜測。
3. 將同義或重複事項合併，避免重複列出。
4. 優先保留具體、可執行、可驗收的事項。
5. 若會議內容同時包含決策、問題、風險與待辦，待辦事項只收錄需要後續執行的項目。

# 處理步驟
1. 通讀整份會議記錄，標記所有明確或隱含的行動項目。
2. 對每個行動項目抽取以下欄位：
   - 事項內容：用一句話描述要做什麼。
   - 負責人：會議中明確指定的人；若未指定，寫「未指明」。
   - 期限：會議中提到的日期、時間點或相對期限；若未指定，寫「待確認」。
   - 備註：必要時補充依據、前提或依賴項。
3. 若同一事項有多個步驟，拆成多個可執行項目；若只是同一事項的補充說明，合併處理。
4. 若期限是相對時間（例如「下週五前」），保留原文；若會議日期已知且使用者要求換算成絕對日期，才換算。
5. 若負責人只出現職稱或團隊名稱，照原文保留，不要自行對應到具體姓名。
6. 若會議記錄中有明確的優先順序，依優先順序排序；否則依出現順序排序。

# 輸出格式
請輸出為清楚的待辦事項清單，建議使用表格：

| # | 待辦事項 | 負責人 | 期限 | 備註 |
|---|---|---|---|---|
| 1 | ... | ... | ... | ... |

# 補充規則
- 若會議記錄中完全沒有可辨識的待辦事項，明確回覆「未找到明確待辦事項」，並簡短說明原因。
- 若有多個負責人，寫成「A、B」或「A / B」。
- 若期限不一致，保留最早被明確指定的期限，並在備註中註明其他說法。
- 若內容含有待確認事項，將其列為待辦，但在期限欄標示「待確認」。
- 保持語言與原始會議記錄一致；若原文是中文，輸出中文。
