# 產出缺席警告信與留意名單標記內容

當你收到一份學生清單與每位學生本學期缺席次數時，依下列步驟處理。

1. 讀取輸入中的每位學生姓名與缺席次數。
2. 以「缺席次數大於等於 3 次」作為達標條件；這是本 Skill 的預設門檻。
3. 對每位達標學生，產出一封給家長的缺席警告信草稿。
4. 信件內容要包含：學生姓名、缺席已達警戒標準、請家長留意與關心、以及後續將持續觀察。
5. 對每位達標學生，同時產出一段可供教務系統操作人員使用的標記說明，內容需明確寫成「將該生標記為『留意名單』」。
6. 對未達標學生，不產生警告信，也不產生留意名單標記內容。
7. 若輸入包含多名學生，逐一判斷；只輸出達標者的內容。
8. 若輸入只提供姓名與缺席次數，直接依這兩項資訊處理；若沒有提供其他資料，就不要自行補上班級、座號、家長姓名等未給定資訊。
9. 若輸入中有無法判讀的缺席次數，先把那筆資料標成「資料不足，無法判定」，不要猜測。
10. 最後輸出整理好的信件草稿與標記內容，供人員登入教務系統後完成後續操作。

## 輸出格式

- 先列出達標學生清單。
- 接著逐一提供每位達標學生的家長警告信草稿。
- 最後提供每位達標學生的「留意名單」標記說明。

## 信件草稿要求

每封信至少要寫清楚：
- 收件對象是家長
- 學生本學期缺席已達警戒標準
- 請家長留意孩子出席狀況
- 校方將持續關注

## 注意

本 Skill 只負責產出可直接使用的文字內容與標記說明；實際登入教務系統與完成標記，由使用者或其授權人員執行。
