# 目的
當學生本學期缺席滿 3 次時，依學校既定格式撰寫一封給家長的缺席警告信，並完成教務系統中的「留意名單」標記流程。

# 使用前提
- 你必須已經取得可用的學生資料、缺席次數、班級、座號、家長稱謂、學校名稱、承辦單位與聯絡方式。
- 你必須已經知道學校要求的信件語氣、格式與是否需要列出缺席日期。
- 若需要登入教務系統，而你沒有登入權限、帳號、密碼或多因素驗證方式，則不能完成系統標記；此時只能整理待辦資訊與操作步驟，請使用者或授權人員登入。

# 判斷條件
1. 先確認該生「本學期缺席次數」是否已達 3 次。
2. 若未滿 3 次：
   - 不寄發警告信。
   - 不進行「留意名單」標記。
   - 回報目前缺席次數與尚未達標。
3. 若已滿 3 次或以上：
   - 產生缺席警告信。
   - 進入教務系統將該生標記為「留意名單」。

# 信件撰寫步驟
1. 使用正式、客觀、不中傷的語氣。
2. 信件至少包含以下內容：
   - 收件人：家長／監護人
   - 學生姓名、班級、座號
   - 說明該生本學期缺席已達 3 次
   - 提醒缺席可能影響學習進度與出席紀錄
   - 請家長留意並協助督促到校
   - 如學校有規定，加入聯絡窗口與回覆方式
3. 若學校有固定模板，優先套用模板；若沒有，使用簡潔正式的通知格式。
4. 不要加入未經確認的懲處、法律結論或醫療判斷。
5. 若缺席原因已知且可公開，僅在使用者提供且學校允許時簡要提及；否則不要臆測。

# 教務系統標記步驟
1. 登入教務系統。
2. 找到學生資料頁或出缺席管理頁。
3. 搜尋該生，確認姓名、班級、學號或其他識別資訊無誤。
4. 找到「留意名單」或相近功能名稱（例如：關注名單、需留意學生、輔導追蹤名單）。
5. 將該生加入「留意名單」。
6. 儲存變更並確認系統顯示成功。
7. 記錄操作時間與結果，方便後續追蹤。

# 若系統介面名稱不同
- 以功能意義為準，不要只依按鈕文字。
- 若找不到對應功能，先搜尋系統內的學生關懷、輔導、追蹤、名單管理等區塊。
- 若仍無法確認，停止操作並回報需要人工確認。

# 驗證與例外處理
- 在送出信件或完成標記前，先再次核對學生身份與缺席次數。
- 若發現資料不一致，先停止並要求更正。
- 若系統操作失敗，保留已整理的信件內容與失敗原因，等待重試或人工處理。
- 若無法登入教務系統，明確說明原因，不要假裝已完成標記。

# 建議輸出
- 一份可直接使用的缺席警告信正文。
- 一段系統操作紀錄，包含：學生姓名、缺席次數、是否已標記留意名單、操作結果。
