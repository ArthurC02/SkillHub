# 社區庭園維護費用計算

依照以下規則計算單次服務費用。輸入只需要兩個數值：**草坪面積（平方公尺）**與**樹木棵數**。

## 計算步驟

1. **先處理草坪面積**
   - 將草坪面積**無條件進位到最接近的 10 平方公尺**。
   - 例如：36 → 40，40 → 40，41 → 50。

2. **計算草坪基本費**
   - 進位後面積 **100 平方公尺以下（含 100）**：收 **2000 元**。
   - 進位後面積 **超過 100 平方公尺、300 平方公尺以下（含 300）**：收 **3500 元**。
   - 進位後面積 **超過 300 平方公尺**：
     - 先收 **3500 元**。
     - 再加收超過 300 平方公尺的部分，每 **10 平方公尺 100 元**。
     - 超過部分也以 10 平方公尺為單位計算，若有零頭仍視為一個 10 平方公尺單位。

3. **計算樹木修剪費**
   - 前 **3 棵**已包含在基本費內。
   - 第 **4 棵起**，每棵加收 **300 元**。

4. **加總費用**
   - 總費用 = 草坪基本費 + 樹木加收費。

5. **套用上限**
   - 單次服務總費用**上限為 6000 元**。
   - 若計算結果超過 6000 元，最後一律收 **6000 元**。

## 計算公式

- 進位後草坪面積 = `ceil(草坪面積 / 10) × 10`
- 樹木加收棵數 = `max(0, 樹木棵數 - 3)`
- 樹木加收費 = `樹木加收棵數 × 300`
- 若進位後面積 ≤ 100：草坪費 = 2000
- 若 100 < 進位後面積 ≤ 300：草坪費 = 3500
- 若 進位後面積 > 300：
  - 草坪費 = `3500 + ceil((進位後面積 - 300) / 10) × 100`
- 總費用 = `min(6000, 草坪費 + 樹木加收費)`

## 輸出要求

回覆時應清楚列出：
- 草坪面積進位後的數值
- 草坪費用
- 樹木加收費用
- 原始總費用
- 套用上限後的最終費用

## 注意事項

- 只要草坪面積不是 10 的倍數，就要往上進位。
- 樹木費只計算超過 3 棵的部分。
- 最終金額不得超過 6000 元。
