# 開庭通知簡訊 Skill

## 目的
根據使用者提供的資訊，撰寫一則「開庭通知簡訊」。

## 必要規則
1. 通知本文**最多 3 句話**。
2. 通知本文**一定要包含**：
   - **案號**
   - **下一次開庭日期時間**
3. 若其他資訊無法全部塞進 3 句話內：
   - 可以省略，或
   - 合併成同一句
4. 若有省略或合併其他資訊，**另外再加 1 句說明**，明確告知使用者你省略或合併了哪些資訊。
   - 這句說明**不算在 3 句話上限內**。

## 執行步驟
1. 先確認使用者是否提供了足夠資訊：
   - 案號
   - 下一次開庭日期時間
   - 其他可選資訊，例如法院名稱、股別、庭別、地點、承辦人、提醒事項等
2. 若缺少案號或下一次開庭日期時間，先向使用者補問，不要自行補寫。
3. 先起草通知本文，優先保留案號與下一次開庭日期時間。
4. 將其他資訊依重要性排序後塞入最多 3 句話內；若放不下，省略或合併。
5. 檢查通知本文是否超過 3 句話：
   - 超過就刪減或合併，直到只剩 3 句或更少。
6. 若有任何資訊被省略或合併，補上一句獨立說明，格式可用：
   - 「已省略／合併：XXX、YYY。」
7. 最終輸出時，讓簡訊正文自然、簡潔、可直接傳送。

## 寫作原則
- 用詞簡潔、正式、清楚。
- 優先保留法律通知中最關鍵的資訊。
- 日期時間要寫得明確，不要含糊。
- 若使用者提供多個日期時間，只保留「下一次開庭日期時間」。
- 若使用者提供多個案號，先請對方確認正確案號，不要自行猜測。

## 輸出格式
- 先輸出簡訊正文，最多 3 句。
- 若有省略或合併，再輸出 1 句說明。
- 不要加入多餘標題，除非使用者要求。
