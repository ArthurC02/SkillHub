# 民宿房價計算

這個 Skill 用來把一段連續入住期間換算成住宿總金額，並列出逐晚明細。

## 何時使用
- 使用者提供入住日期與退房日期時
- 需要計算每晚金額與總金額時
- 需要分辨平日、假日並套用不同費率時

## 計算規則
- 每晚以「入住當晚」計算，退房當天不算一晚。
- 平日每晚 2000 元。
- 假日每晚 2500 元。
- 若使用者沒有提供完整假日定義，先依使用者明確指出的假日日期計算；若未提供任何可判定的假日資訊，輸出時標示「假日未給定，已按平日計算」。

## 作業步驟
1. 讀取使用者提供的入住日期、退房日期與假日資訊。
2. 檢查日期是否可用：
   - 退房日必須晚於入住日。
   - 若日期格式無法判讀，輸出「日期格式不明，無法計算」。
3. 依日期順序列出所有住宿晚數：從入住當晚開始，到退房前一晚結束。
4. 對每一晚判定是平日或假日。
5. 逐晚套用費率：
   - 平日：2000 元
   - 假日：2500 元
6. 加總所有晚數金額，得到總金額。
7. 輸出結果，包含：
   - 住宿區間
   - 每晚日期
   - 平日/假日判定
   - 每晚金額
   - 總金額

## 輸出格式
- 先列出住宿區間。
- 再逐晚列出每晚金額。
- 最後列出總金額。
- 若資料不足以判定，明確標示缺少的資訊，不要自行補齊。

## 必要時的處理
- 如果入住日與退房日相同或退房日早於入住日，輸出「入住與退房日期不合理，無法計算」。
- 如果使用者沒有提供假日資訊，而題目又要求區分平日與假日，輸出時要標示假日資訊未給定，並按已知規則處理。
- 若使用者提供的假日規則與平日規則互相衝突，保留明確指定的費率，並註明另一項未使用。
