# 目的
撰寫畫廊開幕邀請文，語氣正式、優雅，並且**必須完整保留**以下事實資訊：
- 展覽名稱
- 展期（起訖日期）
- 開幕茶會時間
- 地點

## 使用時機
當使用者要你把展覽資訊整理成一段或多段可直接發送的邀請文，且要求語氣正式、典雅時，使用此 Skill。

# 核心原則
1. **不得改寫事實資訊**：展覽名稱、日期、時間、地點必須原樣保留或在不改變內容的前提下呈現。
2. **不得省略**：四項資訊缺一不可。
3. **不得自行補寫未知資訊**：若缺少任一必要資訊，先要求補齊，不要猜測。
4. **語氣正式優雅**：用詞莊重、流暢、適合邀請函或開幕公告。

# 工作流程
## 1. 檢查必要資訊
確認是否已提供以下四項：
- 展覽名稱
- 展期起訖日期
- 開幕茶會時間
- 地點

若任一項缺少，回覆時只列出缺少項目，請使用者補充後再撰寫。

## 2. 保留事實內容
撰寫時將上述資訊清楚放入文中，建議以以下方式呈現：
- 在標題或首段點出展覽名稱
- 在正文中交代展期
- 以獨立句或條列寫出開幕茶會時間與地點

## 3. 語氣與文風
- 使用正式、典雅、克制的語氣
- 可加入邀請、敬邀、誠摯歡迎蒞臨等措辭
- 避免過度口語、誇張或輕佻表達
- 避免加入與事實無關的臆測內容

## 4. 輸出格式建議
可輸出為一段完整邀請文，或「標題＋內文」格式。若使用者未指定格式，採用以下結構：

- 標題：展覽名稱＋開幕邀請
- 內文：
  1. 開場邀請句
  2. 展覽名稱
  3. 展期
  4. 開幕茶會時間
  5. 地點
  6. 結尾敬邀語

# 寫作模板
以下為可直接套用的結構，請依使用者提供的資訊填入，且不得改動事實內容：

**標題**
《展覽名稱》開幕邀請

**內文**
誠摯邀請您蒞臨《展覽名稱》開幕茶會。
本展將自【展期起始日期】至【展期結束日期】展出，敬請於【開幕茶會時間】蒞臨【地點】。
敬邀您撥冗前來，共同見證展覽開幕，並與我們共享這段美好的藝術時光。

# 品質檢查
完成後自我檢查：
- 是否清楚寫出展覽名稱？
- 是否完整寫出展期起訖日期？
- 是否完整寫出開幕茶會時間？
- 是否完整寫出地點？
- 是否維持正式優雅語氣？
- 是否沒有新增或誤寫事實？

若任何一項不符合，必須修正後再輸出。
