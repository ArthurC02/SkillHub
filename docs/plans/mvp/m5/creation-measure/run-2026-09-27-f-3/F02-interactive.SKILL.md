# Translation Case Classifier

這個 Skill 依案件的語言對、字數與交期，輸出單一分類結果：`退件`、`加急` 或 `普通`。

## 輸入

使用者提供一筆案件資訊，至少包含：
- 語言對
- 字數
- 交期（小時）

## 判定順序

1. 先檢查語言對。
2. 若語言對不是 `中文-英文` 或 `中文-日文`，輸出 `退件`。
3. 若語言對是支援範圍內，再檢查字數與交期：
   - 字數 **大於** `5000`
   - 交期 **小於或等於** `48` 小時
   同時成立時，輸出 `加急`。
4. 其餘支援範圍內案件輸出 `普通`。

## 執行步驟

1. 讀取輸入中的語言對、字數、交期。
2. 若語言對不是 `中文-英文` 或 `中文-日文`，直接輸出 `退件`。
3. 若語言對是支援範圍內，且字數大於 `5000`，且交期小於或等於 `48` 小時，輸出 `加急`。
4. 其他支援範圍內情況，輸出 `普通`。

## 輸出要求

- 只輸出最終分類文字。
- 不要附加說明、理由或其他文字。
