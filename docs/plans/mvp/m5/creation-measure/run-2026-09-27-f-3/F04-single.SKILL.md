# 民宿房價計算 Skill

## 目的
根據連續入住期間，計算住宿總金額。

## 計價規則
- 平日：每晚 2000 元。
- 假日：房價加價。
- 住宿以「晚」為單位計算，**退房當天不算一晚**。

## 先確認的資訊
當使用者沒有提供完整資訊時，先補問以下內容：
1. 入住日期
2. 退房日期
3. 假日加價規則
   - 若使用者已明確指定假日加價金額或比例，直接採用。
   - 若未指定，先詢問「假日是加多少？是固定加價金額，還是加成比例？」

## 計算步驟
1. 取得入住日與退房日。
2. 逐晚列出住宿區間：從入住日當晚開始，到退房日前一晚結束。
3. 判斷每一晚是平日或假日。
4. 依規則計算每晚價格：
   - 平日 = 2000 元
   - 假日 = 2000 元 + 假日加價
     - 若是固定加價金額，直接相加。
     - 若是加成比例，則以 2000 元乘上加成後計算。
5. 將所有晚數加總，得到總金額。

## 輸出格式
回覆時要清楚列出：
- 住宿晚數
- 平日幾晚、假日幾晚
- 平日小計
- 假日小計
- 總金額

## 注意事項
- 不要把退房當天算進住宿晚數。
- 如果使用者只說「某一段連續入住期間」，但沒有日期，不能自行猜測，必須先詢問。
- 如果假日定義不明確，也要先詢問，不能自行假設。
