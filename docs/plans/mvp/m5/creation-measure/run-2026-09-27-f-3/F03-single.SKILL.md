# 目的
將客人傳來的訂書留言整理成結構化訂購清單，列出每本書的書名、數量、單價與小計，並計算**書籍總金額**；若訊息中提到運費，需另外列出，且**不計入書籍總金額**。

# 處理原則
- 只根據客人留言中的內容整理，不自行補充不存在的資訊。
- 若資訊不完整，先整理已知內容，再列出缺漏項目供後續確認。
- 書籍總金額只包含書籍小計加總，不包含運費、包材費或其他費用。
- 若留言同時包含多筆書單，全部納入同一份整理結果。

# 解析步驟
1. **讀取留言全文**，找出所有與訂書相關的資訊。
2. **辨識每一筆書籍項目**：
   - 書名
   - 數量
   - 單價
   - 小計
3. **計算小計**：
   - 若有數量與單價，則小計 = 數量 × 單價。
   - 若客人已明確寫出小計，優先採用客人提供的數字；若與計算結果不一致，保留客人原文數字並註記需確認。
4. **加總書籍金額**：
   - 將所有書籍小計相加，得到書籍總金額。
   - 不要把運費算進去。
5. **處理運費**：
   - 若留言有提到運費，單獨列出運費金額與說明。
   - 若運費未明確金額，只記錄「有提到運費」並標示金額未提供。
6. **整理成清楚格式**：
   - 先列訂購清單。
   - 再列書籍總金額。
   - 最後列運費（若有）。

# 輸出格式
請用以下結構輸出：

## 訂購清單
| 書名 | 數量 | 單價 | 小計 |
|---|---:|---:|---:|
| ... | ... | ... | ... |

## 書籍總金額
- NT$ ...

## 運費
- 若有金額：NT$ ...
- 若只有提到但未寫金額：已提到運費，金額未提供
- 若未提到：未提到運費

## 備註
- 列出缺漏資訊、疑似不一致之處、或需要人工確認的地方。

# 金額處理規則
- 金額以留言中的幣別為準；若未標示幣別，預設以原文常見幣別呈現，不要擅自換算。
- 計算時保留合理的小數位；若是整數金額，輸出整數即可。
- 若留言中出現折扣、訂金、預付款、運費、手續費等，除非明確說明是書籍價格的一部分，否則不要納入書籍總金額。

# 資訊不足時的處理
- 若缺少書名：標示為「書名未提供」。
- 若缺少數量：預設為 1，但在備註中註明是推定值。
- 若缺少單價且無法計算小計：保留空白或標示「未提供」。
- 若無法判斷某數字是單價還是小計：依上下文判斷；仍不確定時，在備註中說明。

# 注意事項
- 不要把運費算進書籍總金額。
- 不要自行推測未出現的書名或價格。
- 若留言包含多種商品，只有明確屬於書籍的項目才納入本技能的清單。
