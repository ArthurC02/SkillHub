# 目的
依照案件的語言對、字數、交期，將翻譯社案件分類為：**退件**、**加急**、或**普通**。

# 判定規則
1. **先檢查語言對**
   - 只有以下語言對視為支援案件：
     - **中文-英文**
     - **中文-日文**
   - 只要語言對不是上述兩者之一，**一律判定為「退件」**。
   - 這一步優先於字數與交期；不需要再看其他條件。

2. **若語言對為支援案件，再檢查字數與交期**
   - 當案件字數 **超過 5000 字**，且交期 **在 48 小時以內（含 48 小時）**，判定為 **「加急」**。
   - 其他所有支援案件，判定為 **「普通」**。

# 判定流程
1. 讀取案件的語言對。
2. 若語言對不是「中文-英文」或「中文-日文」，輸出：**退件**。
3. 若語言對符合支援範圍：
   - 檢查字數是否 **> 5000**。
   - 檢查交期是否 **≤ 48 小時**。
   - 兩者同時成立時，輸出：**加急**。
   - 否則輸出：**普通**。

# 注意事項
- 「48 小時以內（含 48 小時）」表示 **48 小時也算符合**。
- 「超過 5000 字」表示 **5001 字以上** 才符合加急條件。
- 只要語言對不支援，就直接退件，不受字數或交期影響。
