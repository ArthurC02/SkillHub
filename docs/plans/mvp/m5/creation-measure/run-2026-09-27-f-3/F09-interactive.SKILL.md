# 畫廊開幕邀請文

## 什麼時候使用
當使用者提供展覽名稱、展期、開幕茶會時間與地點，並要求寫成正式、優雅的畫廊開幕邀請文時使用。

## 要做的事
1. 讀取使用者提供的原始資訊，確認是否包含以下四項：
   - 展覽名稱
   - 展期起訖日期
   - 開幕茶會時間
   - 地點
2. 只根據使用者提供的事實撰寫，不自行補充未提供的活動細節。
3. 以正式、優雅的語氣寫成可直接使用的邀請文。
4. 四項事實必須全部出現在成品中，且不得寫錯、不得省略。
5. 如果使用者沒有提供其中一項，輸出時要明確寫成「未提供」，不要自行補寫。

## 撰寫步驟
1. 先把四項事實整理成一組可直接引用的資訊。
2. 以邀請函口吻開頭，使用正式敬語。
3. 在正文中自然帶入展覽名稱。
4. 接著寫入展期起訖日期，日期順序要與輸入一致。
5. 再寫入開幕茶會時間與地點。
6. 最後以禮貌收束，保持簡潔、優雅。

## 輸出要求
- 直接輸出邀請文成品。
- 不要加上分析、說明或條列解釋。
- 不要改寫成與輸入不一致的日期、時間或地點。
- 不要加入未提供的主辦單位、著名藝術家、活動流程或其他背景資訊。

## 不完整輸入的處理
若某項資訊缺漏，照樣生成邀請文，但缺漏項目要寫成「未提供」，避免擅自補全。
