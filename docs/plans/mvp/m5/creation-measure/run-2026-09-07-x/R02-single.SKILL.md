# Excel 客戶名單清理

依照下列流程處理 Excel 名單：去除重複資料，並標記缺少電話的列。

## 1. 先確認欄位
- 找出代表客戶識別的欄位，通常是「姓名」、「手機」、「電話」、「Email」或其組合。
- 找出電話欄位名稱，確認哪些儲存格算是「缺少電話」：
  - 空白
  - 只有空格
  - 只有符號或無法辨識為電話的內容
- 如果檔案中沒有明確電話欄位，先回報這一點，並請使用者指定哪一欄要視為電話。

## 2. 去除重複
- 先備份原始工作表，避免直接覆蓋原始資料。
- 以最能代表同一客戶的欄位組合判定重複：
  - 若有唯一客戶編號，優先用它。
  - 若沒有，通常以「姓名 + 電話」或使用者指定的欄位組合判定。
- 對重複列保留一筆，其餘刪除或移到另一張工作表，並保留處理前後的紀錄。
- 若同一客戶有多筆資料但電話不同，先不要自行合併；改為標記為疑似重複，等待人工確認。

## 3. 標記缺少電話的列
- 在原表新增一欄，例如「電話狀態」或「缺少電話標記」。
- 對每一列檢查電話欄：
  - 有電話：填入「有電話」或留空，依使用者需求一致處理。
  - 沒有電話：填入「缺少電話」。
- 若需要更醒目，可另外用底色、字色或篩選條件標示缺少電話的列。

## 4. 檢查結果
- 確認重複列已處理完成，且沒有誤刪不同客戶。
- 確認所有缺少電話的列都已被標記。
- 若資料量不大，可抽查幾筆重複與缺電話案例，確認規則一致。

## 5. 輸出
- 儲存為新檔，保留原始檔不變。
- 若有需要，另外輸出一份摘要：
  - 原始筆數
  - 刪除的重複筆數
  - 缺少電話的筆數
  - 最終保留筆數

## 6. 若資訊不足時要先問
- 如果沒有明確的重複判定欄位，先詢問要用哪些欄位判定重複。
- 如果沒有明確電話欄位，先詢問哪一欄是電話。
- 如果使用者希望「去除重複」的定義是保留最新、保留最完整或保留第一筆，也要先確認。
