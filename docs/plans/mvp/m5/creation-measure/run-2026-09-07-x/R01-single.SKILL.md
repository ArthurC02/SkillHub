# 目的
把會議逐字稿轉成結構化待辦清單，並確保每一條都包含：
- 待辦事項
- 負責人
- 期限

# 使用時機
當輸入是會議逐字稿、會議紀錄、轉錄文字，且目標是整理成可執行的 action items 時，載入此技能。

# 處理步驟
1. **先通讀全文**
   - 找出所有明確的行動、承諾、決議、後續跟進事項。
   - 將純討論、背景說明、重複內容排除在待辦之外。

2. **辨識待辦項目**
   - 只保留可執行的事項。
   - 若同一事項被多次提及，合併為一條。
   - 若一段話包含多個動作，拆成多條待辦。

3. **為每條待辦補齊三個欄位**
   - **待辦事項**：用簡短、具體、可執行的動詞開頭描述。
   - **負責人**：優先使用逐字稿中明示的人名或角色。
   - **期限**：優先使用明示日期、時間、會議前/後、某日之前等資訊。

4. **處理缺漏資訊**
   - 如果逐字稿沒有明確說出負責人，標示為「未指派」或依上下文最可能的角色，但不要憑空捏造。
   - 如果沒有明確期限，標示為「未提及」或「待確認」。
   - 不要自行推測日期、姓名或承諾內容。

5. **保留必要上下文**
   - 若待辦需要依賴前提，簡短補充在事項描述中。
   - 若期限是相對時間，保留原文語意，例如「本週五前」、「下次會議前」。

6. **輸出格式**
   - 以清單或表格輸出。
   - 每條至少包含：
     - 待辦事項
     - 負責人
     - 期限
   - 若有需要，可加上「備註」欄位放置關鍵背景，但不要取代前三項。

# 品質檢查
- 每條待辦都必須是可執行動作，不是抽象主題。
- 不要把討論結論誤寫成待辦。
- 不要遺漏明確提到的負責人與期限。
- 若資訊不足，明確標示缺漏，不要猜測。
