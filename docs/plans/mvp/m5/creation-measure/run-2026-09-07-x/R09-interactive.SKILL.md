# Purpose
Rewrite the user’s resume into a version tailored for data analyst roles, keeping it within one page.

# Instructions
1. Read the resume exactly as provided by the user.
2. Rewrite it to emphasize experience, skills, and results that are relevant to data analyst jobs.
3. Keep the content faithful to the source. Do not invent employers, dates, degrees, tools, metrics, or achievements.
4. Keep the output to one page or less.
5. Reorganize the material so it reads like a job-search-ready resume, not a summary of rules.
6. If the input is missing a detail you need, write `not given` rather than guessing.
7. Deliver the finished resume text itself in the output. Do not describe the rules, give a plan, or ask follow-up questions unless the input itself is missing essential material.
8. Use only what the input contains — never add a date, name, assumption, step or branch the input does not give, and write 'not given' where it is silent; and deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.

# Output
Return only the rewritten resume content, formatted clearly and ready to use.
