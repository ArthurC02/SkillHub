# 新人到職流程

依照圖中的順序執行；這是一個線性流程，沒有分支判斷。

## 步驟

1. **收到新人到職通知**
   - 確認已收到正式的新進人員到職通知。
   - 取得新人姓名、到職日、部門、職稱與主管資訊。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱可正常登入，並記錄帳號資訊。

3. **加入 Slack 頻道**
   - 將新人加入必要的 Slack 頻道。
   - 至少包含部門、團隊與公告相關頻道。

4. **準備筆電與門禁卡**
   - 準備新人報到所需的筆電與門禁卡。
   - 確認設備可用、已完成基本設定，門禁卡可正常使用。

5. **安排第一週訓練**
   - 規劃新人第一週的訓練內容與時程。
   - 安排必要課程、系統介紹與工作流程說明。

6. **指派導師**
   - 指派一位導師或 buddy 協助新人適應。
   - 告知導師其支援範圍與預期協助事項。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備回饋重點：適應狀況、訓練進度、問題與支援需求。

8. **記錄到人資系統**
   - 將以上完成事項記錄到人資系統。
   - 確保資料完整、可追蹤，並保留必要備註。

## 執行原則

- 按照圖示順序完成，不要跳步。
- 若某一步缺少必要資訊，先向主管、人資或相關部門確認，再繼續。
- 完成後應留下可追蹤紀錄，方便後續查核與交接。
