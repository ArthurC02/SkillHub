## 目標
將一份英文使用手冊翻成繁體中文，保留原意、語氣與操作順序；專有名詞第一次出現時，需在中文後附上原文。

## 工作流程

1. **先通讀全文**
   - 先快速掃描整份手冊，確認章節結構、重複術語、產品名稱、按鈕名稱、警告與注意事項。
   - 找出需要固定譯法的專有名詞與術語，建立一致的翻譯方式。

2. **建立術語一致性**
   - 對同一術語、功能名稱、介面標籤、錯誤訊息，前後使用相同譯法。
   - 若某些詞不宜翻譯或翻譯後容易混淆，保留原文並在首次出現時加上中文說明。

3. **逐段翻譯**
   - 依原文順序翻譯，不改變章節層級、步驟順序或條列結構。
   - 保留數字、單位、型號、快捷鍵、路徑、代碼、命令與按鍵標示的原始資訊。
   - 若原文有警告、注意、提示、備註，翻譯時維持其語氣與重要性。

4. **專有名詞標註規則**
   - 專有名詞第一次出現時，格式為：`中文譯名（Original Term）`。
   - 之後再次出現時，只用中文譯名，除非上下文需要再次標示原文以避免歧義。
   - 若原文本身就是品牌、產品名、功能名或介面名稱，優先保留原文並加中文說明，而不是硬翻成不自然的詞。

5. **保留格式與可讀性**
   - 盡量維持原手冊的標題、編號、項目符號、表格與段落分隔。
   - 若原文有圖說、按鈕文字、選單名稱，翻譯時保持簡潔一致。
   - 讓中文讀起來自然，但不要擅自增刪操作步驟或技術含義。

6. **完成後檢查**
   - 檢查是否有漏譯、重譯、術語不一致、專有名詞首次出現未附原文的情況。
   - 檢查數字、單位、警告內容、步驟順序是否與原文一致。
   - 若原文含糊不清，翻譯時忠實反映原意，不自行補充未提供的資訊。

## 輸出要求
- 只輸出繁體中文譯文。
- 保留原手冊的結構與順序。
- 專有名詞首次出現時附原文。
