# 目的
把一週內的每日花費整理成清楚的表格，為每筆支出標上類別，並在週末計算各類別合計。

# 適用情境
- 使用者提供一週的花費明細，要求整理成表格。
- 使用者希望每筆支出都有類別標記。
- 使用者要求在週末做分類加總或週報統計。

# 工作流程
1. **收集資料**
   - 取得一週內每筆花費的日期、金額、用途/品項。
   - 若使用者已提供類別，直接沿用。
   - 若未提供類別，根據用途推定最合理的類別，並保持一致。

2. **建立每日明細表**
   - 依日期排序。
   - 每筆花費至少包含以下欄位：
     - 日期
     - 項目/用途
     - 類別
     - 金額
   - 若同一天有多筆，逐筆列出，不要合併，除非使用者明確要求。

3. **統一類別**
   - 將相近項目歸入同一類別，例如：
     - 餐飲
     - 交通
     - 購物
     - 娛樂
     - 生活用品
     - 醫療
     - 其他
   - 若資料中出現不明確項目，先歸入「其他」，並在表格中保留原始用途。

4. **計算週末合計**
   - 以整週所有資料為準，按類別加總金額。
   - 若使用者指定週末只看週六、週日，則另外提供週末兩日的分類合計。
   - 若未指定，預設輸出「本週各類別合計」。

5. **輸出格式**
   - 先輸出每日明細表。
   - 再輸出分類合計表。
   - 若需要，可再附上總支出與每日小計。

# 表格格式建議
## 每日明細
| 日期 | 項目/用途 | 類別 | 金額 |
|---|---|---:|---:|
| 週一 | 早餐 | 餐飲 | 80 |
| 週一 | 捷運 | 交通 | 50 |

## 類別合計
| 類別 | 合計 |
|---|---:|
| 餐飲 | 560 |
| 交通 | 210 |
| 購物 | 430 |

# 計算規則
- 金額以數字加總，不要把貨幣符號算進去。
- 同一筆支出只計一次。
- 若有退款或負數金額，照原始數值計入，並在必要時註明。
- 若資料缺少日期或金額，先向使用者確認，不要自行補值。

# 品質檢查
- 確認每筆支出都有類別。
- 確認類別名稱一致，避免同義不同名造成分散統計。
- 確認合計數字與明細加總一致。
- 若一週資料不完整，明確標示缺漏日期。
