# 每日新聞摘要寄送

這個技能用來把三個新聞網站的標題整理成 5 條摘要，並準備成可寄出的早報內容。

## 先確認可行性

1. 確認你是否能存取這三個新聞網站的公開標題頁。
2. 確認你是否有可用的寄信方式：
   - 若有郵件工具或既有寄信流程，就直接使用。
   - 若沒有寄信工具，明確告知無法實際寄出，只能產生可複製的郵件草稿。
3. 若網站需要登入、付費、或有反爬限制而無法合法取得標題，停止並回報限制，不要嘗試繞過。

## 收集標題

1. 從三個新聞網站各自取得最新標題。
2. 優先使用首頁、新聞列表頁、或 RSS/公開標題頁。
3. 記錄每則標題的來源網站與時間戳記（若頁面提供）。
4. 若某網站暫時無法讀取，保留其他網站可用標題，並在最終內容中註明缺漏來源。

## 整理成 5 條摘要

1. 將三個網站的標題合併後去重。
2. 挑選最重要、最具代表性的 5 則新聞。
3. 每條摘要要：
   - 簡短
   - 以中文表達
   - 保留原意，不加入未驗證資訊
   - 盡量說明事件主題與關鍵動作
4. 若標題本身資訊不足，摘要只能根據標題改寫，不可自行補充細節。
5. 若三站標題高度重複，合併為一條摘要，並在來源中列出多個網站。

## 組成寄信內容

1. 郵件主旨建議格式：`每日新聞摘要 - YYYY-MM-DD`
2. 郵件內文包含：
   - 簡短開頭
   - 5 條摘要清單
   - 每條摘要後附來源網站名稱
   - 若有缺漏來源或抓取限制，單獨註明
3. 內文保持精簡、可直接寄出。

## 寄送流程

1. 若有可用寄信工具：
   - 填入收件者信箱
   - 使用整理好的主旨與內文
   - 寄出前檢查收件者、主旨、內容是否正確
2. 若沒有可用寄信工具：
   - 產生完整郵件草稿
   - 清楚標示「未實際寄出」
   - 提供可直接貼到郵件客戶端的內容

## 品質檢查

在完成前檢查：

- 是否真的來自三個新聞網站
- 是否只有 5 條摘要
- 是否沒有捏造標題以外的資訊
- 是否有標示來源
- 是否符合「每天早上」的排程需求；若無排程工具，說明只能手動執行或需外部排程系統

## 無法自動化時的處理

如果目前環境不能：

- 連上新聞網站
- 取得標題
- 寄送電子郵件
- 設定早晨排程

就不要假裝已完成。改為回報缺少的能力，並提供可執行的下一步清單。
