# Customer complaint reply

Use this skill when the user wants help replying to a customer complaint.

## Goal
Write a response that is calm, empathetic, concise, and action-oriented.

## Process
1. Read the complaint carefully and identify:
   - the main issue
   - the customer’s emotion
   - any facts, dates, order numbers, or product names mentioned
   - whether the customer is asking for a refund, replacement, explanation, or escalation
2. If key details are missing, draft a reply that stays general and asks for the missing information politely.
3. Respond with this structure:
   - acknowledge the problem
   - apologize for the inconvenience without admitting fault unless the facts clearly support it
   - show empathy and understanding
   - state the next step or what you need from the customer
   - close politely and professionally
4. Keep the tone respectful and human. Do not sound defensive, robotic, or argumentative.
5. Do not promise compensation, timelines, or outcomes unless the user explicitly provided them.
6. If the complaint involves safety, legal threats, harassment, discrimination, or a serious service failure, keep the reply calm and escalate internally in your wording.

## Writing rules
- Use simple, clear language.
- Avoid blaming the customer.
- Avoid excessive apologies or long explanations.
- Do not mention internal policies unless the user asks for them.
- If the user wants a specific tone, match it: formal, warm, brief, firm, or apologetic.
- If the user provides the customer’s message, tailor the reply directly to it.

## Output
Provide only the drafted reply unless the user asks for analysis or alternatives. If helpful, you may offer 2 versions: a short reply and a more polished reply.
