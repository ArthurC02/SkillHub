# 競爭對手價格變動追蹤

此技能用於**監測三家競爭對手官網的價格是否有變動**，並在發現變動時整理成可通知的摘要。

## 先確認的資訊
在開始前，先向使用者確認以下內容：

1. 三家競爭對手的官網網址
2. 要追蹤的商品名稱、SKU、頁面連結或分類頁
3. 需要比對的價格欄位
   - 售價
   - 原價/折扣價
   - 運費是否要納入
4. 比對頻率
   - 每日、每週、每小時，或手動執行
5. 通知方式
   - 電子郵件、聊天訊息、簡訊，或僅輸出報告
6. 是否有登入、地區限制、Cookie 同意、年齡驗證或反爬限制

如果缺少上述資訊，先停止並請使用者補齊。不要自行猜測商品或網站。

## 能做與不能做
- 你可以：
  - 整理監測規則
  - 比對兩次抓取結果
  - 彙整價格變動摘要
  - 產出通知內容
- 你不能：
  - 代替使用者登入受保護網站
  - 繞過反爬、驗證碼或付費牆
  - 保證即時抓取成功

若網站需要登入或其他人工驗證，請請使用者提供已授權的存取方式或改用可公開存取的頁面。

## 執行流程

### 1. 建立基準資料
對每一家競爭對手、每個商品頁面，記錄：
- 網站名稱
- 商品名稱
- 頁面 URL
- 擷取時間
- 價格數值
- 幣別
- 是否含稅
- 是否含運
- 促銷標記（如有）

若同一商品在不同頁面有不同價格，優先使用使用者指定的頁面；若未指定，使用最接近實際銷售頁的價格。

### 2. 重新抓取並標準化
每次檢查時，將新抓到的價格標準化成可比較格式：
- 去除貨幣符號後保留幣別
- 將千分位與小數格式統一
- 分開處理原價、折扣價、會員價、組合價
- 若頁面顯示多個價格，依使用者指定的欄位優先順序比對

若無法判定哪個價格是主要售價，記錄為「價格欄位不明」，並請使用者確認。

### 3. 比對變動
將新資料與基準資料比對，判斷：
- 價格上升
- 價格下降
- 價格不變
- 價格欄位消失或新增
- 幣別改變
- 折扣狀態改變

計算變動幅度：
- 絕對差額
- 百分比差異（若基準價格不為 0）

### 4. 產出通知
若有變動，通知內容至少包含：
- 競爭對手名稱
- 商品名稱
- 舊價格 → 新價格
- 變動幅度
- 變動時間
- 商品頁連結
- 備註（例如：原價/折扣價切換、幣別變更、無法確認欄位）

若沒有變動，則輸出簡短狀態：
- 哪些網站已檢查
- 哪些商品價格維持不變
- 是否有抓取失敗或欄位不明

### 5. 處理抓取失敗
若遇到以下情況，記錄原因並繼續處理其他網站：
- 頁面無法開啟
- 內容載入不完整
- 價格由腳本動態生成且無法取得
- 被要求登入或驗證
- 頁面結構改變導致無法定位價格

不要捏造價格。無法取得時，明確標示為「未取得」。

## 建議輸出格式
使用表格或條列整理：

| 網站 | 商品 | 舊價格 | 新價格 | 變動 | 狀態 | 備註 |
|---|---|---:|---:|---:|---|---|
| A 官網 | 商品 X | 1000 | 950 | -50 (-5%) | 下降 | 折扣價更新 |

## 若使用者要長期追蹤
請建議使用者提供：
- 固定檢查時間
- 每個商品的唯一識別方式
- 通知收件人或頻道
- 是否要保留歷史紀錄

若沒有持續執行機制，這個技能只能協助整理單次檢查結果與通知內容，不能自行在背景持續監控。
