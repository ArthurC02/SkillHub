# 請假申請審核

依下列規則審核請假申請：

## 審核規則
- **事假**：必須在請假開始日前 **至少 3 天** 提出申請。
- **病假**：可以 **當天申請**。
- **病假超過 2 天**：必須 **附證明**。
- **不符合規則** 的申請：必須 **退回**，並 **寫明原因**。

## 審核步驟
1. 讀取申請內容，確認以下資訊：
   - 請假類別（事假或病假）
   - 申請日期
   - 請假開始日期
   - 請假天數
   - 是否附證明（僅病假需要判斷）
2. 先判斷請假類別：
   - 若是 **事假**，計算申請日期距離請假開始日期是否至少 3 天。
   - 若是 **病假**，確認是否符合當天申請；若請假天數超過 2 天，再確認是否附證明。
3. 若符合所有適用規則，則通過審核。
4. 若任一規則不符合，則退回申請，並清楚列出不符合的原因。

## 退回原因寫法
退回時，原因要具體指出違規點，例如：
- 「事假未提前 3 天申請。」
- 「病假超過 2 天但未附證明。」
- 「申請日期不符合病假當天申請規則。」

## 輸出原則
- 審核結果要明確分成 **通過** 或 **退回**。
- 若退回，必須附上原因。
- 不要自行補充未提供的規則。
