# 目的
根據「這個月的出勤紀錄」計算每個人的加班時數，並標出加班時數超過 46 小時的人員。

# 適用情境
- 輸入是本月出勤紀錄、考勤表、打卡明細、排班加班表或類似資料。
- 需要按人彙總加班時數。
- 需要找出加班時數 > 46 小時的名單。

# 執行步驟
1. **確認資料範圍**
   - 只使用「本月」的出勤紀錄。
   - 若資料跨月，先排除非本月資料，或依日期欄位篩選出本月區間。

2. **辨識可用欄位**
   - 找出每筆紀錄中與人員識別、日期、加班時數相關的欄位。
   - 常見欄位可能是：姓名、工號、部門、日期、加班時數、加班分鐘數、加班起訖時間。

3. **整理每筆加班資料**
   - 若資料已直接提供「加班時數」，直接使用。
   - 若只有加班起訖時間，先計算每筆加班時數。
   - 若只有分鐘數，先換算成小時：`小時 = 分鐘 ÷ 60`。
   - 若同一人同一天有多筆加班，先把同一天的加班加總，再進行月總計。

4. **按人彙總本月加班時數**
   - 以「人員」為單位加總整個月的加班時數。
   - 若有同名不同人，優先用工號或其他唯一識別欄位區分。
   - 保留計算過程，避免重複計算或漏算。

5. **判斷是否超過 46 小時**
   - 對每個人的月加班總時數進行比較。
   - 若 `加班總時數 > 46`，標記為「超過 46 小時」。
   - 若剛好等於 46 小時，不算超過。

6. **輸出結果**
   - 以清楚表格列出：
     - 人員名稱/工號
     - 本月加班總時數
     - 是否超過 46 小時
   - 對超標者加上明顯標記，例如：`⚠ 超過 46 小時`。
   - 如需要，可另外列出超標名單摘要。

# 建議輸出格式
| 人員 | 工號 | 本月加班總時數 | 是否超過 46 小時 |
|---|---:|---:|---|
| 王小明 | A001 | 48.5 | ⚠ 是 |
| 李小華 | A002 | 42.0 | 否 |

# 注意事項
- 若資料缺少加班時數，不能自行猜測；應先從原始欄位計算或請求補資料。
- 若同一筆紀錄有異常值（例如負數、空值、明顯不合理的超大值），先標記為待確認，不要直接納入總計。
- 若使用時間格式計算，統一換算成小數小時，並在最後保留適當小數位數（例如 1 或 2 位）。
- 若使用者提供的是圖片、掃描檔或非結構化文字，先整理成可計算的表格，再進行彙總。
