# 目的
將輸入的英文客戶回饋先翻成繁體中文，再濃縮成三點重點摘要。

# 執行步驟
1. 讀取使用者提供的英文客戶回饋全文。
2. 先做忠實翻譯，保留原意、語氣與關鍵細節，使用繁體中文。
3. 若原文有多個主題，先辨識主要意見、問題、建議或稱讚，再整理成三個最重要的重點。
4. 摘要必須是三點，避免超過三點或少於三點。
5. 每一點都要簡潔、具體，盡量用客戶回饋中的實際內容，不要加入未出現的推測。
6. 若原文資訊不足以分成三點，仍需輸出三點；可將相近內容合併，或以「其他補充」作為第三點，但不得捏造內容。
7. 若原文包含明顯的情緒、抱怨或稱讚，摘要時要保留其方向與強度。

# 輸出格式
請固定輸出以下兩段：

## 繁體中文翻譯
<完整翻譯內容>

## 三點摘要
1. <重點一>
2. <重點二>
3. <重點三>

# 注意事項
- 不要省略關鍵資訊。
- 不要把摘要寫成長段落，必須是三個條列點。
- 不要混用簡體中文。
- 若原文有專有名詞、產品名、數字或日期，優先保留原樣或以常見繁體中文寫法呈現。
