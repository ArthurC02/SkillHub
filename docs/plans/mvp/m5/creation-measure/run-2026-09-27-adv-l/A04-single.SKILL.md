# 每週業績自動寄送與 Slack 公告

## 適用情境
當使用者要在固定時間（例如每週五下午）把本週業績數字同步寄給整個部門，並同時在 Slack 公告時，使用此技能。

## 先確認這件事能不能做
這類任務通常需要：
- 可存取業績數據來源（例如試算表、CRM、BI 報表、資料庫匯出）
- 可寄送電子郵件的系統或權限
- 可發送 Slack 訊息的工作區權限
- 排程能力（例如自動化平台、工作流程工具、cron、內建排程）

如果目前沒有這些權限或工具，先不要假設可以直接完成；改為整理需求、確認資料來源與收件名單，並請使用者提供可用的系統或授權。

## 執行步驟

### 1. 確認報表規格
先釐清以下內容：
- 「本週」的定義：週一到週五、週日至週六，或其他公司慣例
- 「每週五下午」的具體時間與時區
- 業績數字的來源系統與欄位
- 需要寄送的對象：全部門的郵件群組、Slack 頻道名稱或 ID
- 內容格式：只要總數，還是要包含目標、達成率、與上週比較、重點說明
- 是否需要附檔、圖表或連結

### 2. 取得並驗證數據
從指定來源抓取本週業績數字，並檢查：
- 日期區間是否正確
- 數字是否完整、無重複、無明顯異常
- 若有多個指標，確認每個指標的定義一致

若資料不完整，先回報缺漏項目，不要自動補值或猜測。

### 3. 產出統一內容
建立一份同時適用於 Email 與 Slack 的摘要，至少包含：
- 標題：例如「本週業績更新」
- 期間：例如「2026/09/21–2026/09/25」
- 核心數字：例如營收、訂單數、轉換率、達成率
- 簡短結論：例如是否達標、較上週變化
- 必要連結：例如完整報表或儀表板

內容要簡潔，Slack 版更短，Email 版可稍微完整。

### 4. 準備兩個輸出版本
#### Email 版本
- 收件者：全部門群組或指定名單
- 主旨：清楚標示週別與主題
- 內文：摘要 + 重點數字 + 連結
- 若需要附件，確認檔案名稱與格式一致

#### Slack 版本
- 發送到指定頻道
- 內容短版優先，必要時附上連結
- 若公司慣例允許，可使用條列式呈現

### 5. 排程與自動化
設定在每週五下午執行，並確認：
- 時區正確
- 觸發時間不會撞到資料尚未更新的時段
- 若資料來源延遲，是否要延後發送或改為失敗通知
- 是否需要在發送前先做人工審核

如果無法直接設定排程，請提供可執行的排程規格給使用者或系統管理者：
- 觸發時間
- 資料來源
- 收件者/頻道
- 郵件主旨模板
- Slack 訊息模板
- 失敗處理方式

### 6. 發送前檢查
在送出前確認：
- 數字與日期區間正確
- 收件名單與 Slack 頻道正確
- 沒有敏感資訊外洩到不該看到的人
- 郵件與 Slack 內容一致

### 7. 發送與記錄
完成發送後，記錄：
- 發送時間
- 使用的數據區間
- 郵件是否成功
- Slack 是否成功
- 若失敗，失敗原因與重試結果

## 失敗處理
若任一步驟失敗，優先做以下事：
1. 停止自動發送，避免錯誤資訊擴散
2. 回報失敗原因
3. 提供可重試的最小必要資訊：資料來源、時間區間、收件者、頻道、模板
4. 若是資料缺漏，等待資料補齊後再重新產出

## 你不能直接完成的情況
如果沒有可用的郵件寄送權限、Slack 發文權限、或排程工具，這個技能只能幫你整理需求與檢查清單，不能真的替你寄信或發公告。
