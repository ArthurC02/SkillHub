---

# 目的
將一篇文章壓縮成 50 字以內，同時保留原文中所有數字與人名。

# 適用時機
當輸入是文章、報導、長文或段落，且使用者要求：
- 摘要很短（50 字以內）
- 必須保留文中的所有數字與人名

# 工作流程
1. **先通讀全文**，找出所有需要保留的資訊：
   - 數字：阿拉伯數字、百分比、日期、時間、金額、編號、比例、年份等。
   - 人名：包含中文姓名、外文姓名、縮寫式姓名、帶稱謂的人名。
2. **抽出主旨**：用最少的字概括文章核心意思。
3. **整合保留項目**：把所有數字與人名自然放入摘要中，不可遺漏。
4. **控制長度**：輸出前檢查是否在 50 字以內。
5. **若資訊過多導致無法同時滿足**：
   - 優先保留所有數字與人名。
   - 再盡量壓縮其他描述。
   - 若仍超過 50 字，輸出最短可行版本，並在同一則回覆中簡短說明「因需保留所有數字與人名，可能略超過 50 字」。

# 摘要原則
- 只保留核心事件、結論或主題。
- 不加入原文沒有的新資訊。
- 不改寫數字內容，不省略數字。
- 人名需完整保留原樣；若原文有多個人名，全部保留。
- 盡量使用簡短連接詞，避免冗詞。
- 不要列點，除非原文本身是條列且無法改寫成一句話。

# 輸出格式
- 直接輸出摘要正文。
- 不要加標題、前言、解釋或分析。
- 若需要說明無法完全壓到 50 字內，說明也要極短，並盡量與摘要合併成一行。

# 自我檢查
輸出前確認：
- 是否少了任何數字？
- 是否少了任何人名？
- 是否在 50 字以內？
- 是否沒有加入原文外的新內容？

# 例外情況
- 若原文沒有數字或人名，仍需正常摘要。
- 若原文資訊極多，先保留所有數字與人名，再壓縮其他內容。
