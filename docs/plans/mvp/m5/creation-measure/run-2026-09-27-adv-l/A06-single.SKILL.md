# Self-Introduction Writing Skill

## Purpose
Write a clear, natural self-introduction in Chinese based on the user’s situation, audience, and desired tone.

## When to use
Use this skill when the user asks to:
- write a self-introduction
- draft an introduction for an interview, class, event, email, or profile
- rewrite or improve an existing self-introduction

## Procedure
1. **Identify the context**
   - Determine where the self-introduction will be used: interview, school, workplace, networking, speech, social media, or other.
   - If the context is missing, ask for it before writing.

2. **Collect the essential details**
   Ask for the information needed to make the introduction specific and useful:
   - name or preferred name
   - current role, school, or background
   - major, profession, or area of expertise
   - key strengths or achievements
   - interests or personality traits
   - purpose of the introduction
   - target audience
   - desired tone: formal, friendly, concise, confident, warm, etc.

3. **Choose the structure**
   Use a structure that fits the context:
   - **Short introduction**: name → background → strengths → closing
   - **Interview introduction**: name → education/work experience → relevant skills → motivation → closing
   - **School/class introduction**: name → grade/major → hobbies → personality → closing
   - **Professional profile**: role → expertise → achievements → value offered → closing

4. **Write in natural Chinese**
   - Use smooth, idiomatic Chinese.
   - Keep the wording appropriate to the audience.
   - Avoid overly stiff or generic phrases unless the user requests a formal style.
   - Do not invent personal facts. If details are missing, either ask follow-up questions or write a template clearly based only on provided information.

5. **Adjust length to the request**
   - If the user asks for a short version, keep it brief and direct.
   - If the user asks for a detailed version, include more background and personality.
   - If no length is specified, provide a concise but complete introduction.

6. **Offer variants when helpful**
   - If the user’s request is broad, provide 2–3 versions with different tones, such as formal, friendly, and concise.
   - If the user gives enough detail for one strong version, provide that version first and optionally offer a shorter or more formal rewrite.

## Output rules
- Write the self-introduction directly in Chinese.
- Keep it aligned with the user’s stated purpose and audience.
- If important information is missing, ask focused follow-up questions instead of guessing.
- If the user wants a template, provide a fill-in-the-blank version.
