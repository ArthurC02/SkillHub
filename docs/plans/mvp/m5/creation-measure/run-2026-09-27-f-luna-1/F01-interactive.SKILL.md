# 包裹運費計算

依輸入重量逐筆計算運費，輸出原重量、進位後重量、未封頂金額及實收運費。只計算此處定義的運費；不推定其他費用或折扣。

1. 從使用者訊息擷取每筆包裹的重量及標籤。重量單位以公斤計；若未提供標籤，按出現順序使用 A、B、C 等標籤，並在結果中說明此預設。不得自行補造重量。
2. 若沒有任何重量，交付可直接填寫的命令模板，將 `<標籤>=<公斤重量>` 標為待填欄位；不得執行模板或把空欄當作數值。若數值互相矛盾或無法使用，說明問題並指出需使用者確認之處；不得猜測或計算該筆。
3. 在包含本 `SKILL.md` 的目錄，以每筆一個 `--weight 標籤=重量` 參數執行腳本；把使用者提供的實際標籤和重量代入：

   ```bash
   python scripts/calculate_freight.py --weight A=3.2 --weight B=5
   ```

4. 將腳本輸出的表格原樣交付。表格逐筆呈現原重量、無條件進位至整數公斤後的重量、未封頂金額和受 600 元上限約束後的實收運費；不得合併不同包裹計費。腳本拒絕輸入時，照實說明該輸入無法計算，不要自行改值。
