# 社區庭園單次維護費

依使用者提供的一筆或多筆服務資料，計算每筆草坪與樹木修剪費用，並輸出逐筆明細。不把多筆服務合併計價。

## 步驟

1. 讀取使用者訊息，擷取每筆服務的庭園名稱、草坪面積（平方公尺）與樹木棵數。依訊息使用的語言回覆。不要推測未提供的名稱或數值；缺少欄位時標示「未提供」，並提供帶有「〔請填入…〕」標記的可用輸入範本，不以猜測值計算。若資料互相矛盾或不可能，簡要指出問題並請使用者確認，不自行裁定。
2. 將完整資料逐筆傳給計算腳本；每筆資料使用一組 `--service`，從放有本 `SKILL.md` 的目錄執行：
   `python scripts/calculate_fee.py --service "庭園名稱" 草坪面積 樹木棵數`
   多筆資料就在同一命令中重複 `--service "庭園名稱" 草坪面積 樹木棵數`。面積填數字，棵數填整數。
3. 呈現腳本印出的逐筆計價明細。不得合併服務、合併套用上限、補入未提供的費用，或宣稱已執行任何外部操作。
