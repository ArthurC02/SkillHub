## 用途與預設

把使用者提供的獸醫診所收費資料整理成逐筆清單，計算每筆金額及全部可計算項目的總額。預設保留原有項目順序；同一天的項目仍逐筆列出，不合併。未指定幣別時不加幣別符號。只整理已提供的資料，不推測價格、診療內容或會計規則。

## 步驟

1. 從輸入辨識日期、項目、數量與單價；來源可為文字或表格。整理時保留原順序。缺漏欄位填「未提供」，不要猜測。若沒有任何收費資料，提供一份欄位標示為「未提供」的清單範本，並說明目前沒有可計算的項目。
2. 在目前工作目錄建立 `input.tsv`，使用 UTF-8、以 Tab 分隔，首列必須為 `date<Tab>item<Tab>quantity<Tab>unit_price`；每筆資料各佔一列。將空白或缺漏值寫為「未提供」，不要把原文沒有提供的幣別補上。
3. 從含有此 Skill 的目錄執行：

   ```sh
   python scripts/calculate.py input.tsv
   ```

4. 若腳本因格式或不可用的數值而報錯，修正 `input.tsv` 中對應的輸入格式後重跑；不得改猜或改寫來源中的數值。遇到來源資料彼此矛盾或無法合理計算的情況，明確指出矛盾或限制，請提供者確認；不要自行選定一個版本。
5. 將腳本輸出的逐筆清單與總額直接交付。若有缺漏，保留「未提供」標記及腳本對總額完整性的說明；只計算可計算的明細，並清楚指出總額是否完整。
