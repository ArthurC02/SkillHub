# 翻譯社案件分類

依案件表格逐案判定分類與理由，並保留原有順序。只使用「退件」、「加急」及「普通」三種分類。

## 步驟

1. 讀取使用者提供的案件表格。需要分類但未提供案件資料時，不猜測資料；輸出下方 TSV 範本，空白欄位表示尚未提供：

   ```text
   語言對\t字數\t剩餘交期（小時）
   [未提供]\t[未提供]\t[未提供]
   ```

2. 將案件資料整理成 UTF-8 TSV 檔 `cases.tsv`，欄位依序為 `語言對`、`字數`、`剩餘交期（小時）`，每案一列。保留語言對文字，不改寫或推測別名。輸入沒有案件標識欄時，按列序稱為「案件1」、「案件2」等。

3. 在本 Skill 的目錄執行：

   ```sh
   python scripts/classify_cases.py cases.tsv
   ```

   腳本會按輸入順序檢查語言對，並輸出每案分類及簡短理由。數值欄位須是可讀取的非負數；若檔案或資料無法使用，呈現腳本的一行錯誤訊息，不自行補值或分類。

4. 將腳本印出的內容原樣交付使用者。分類規則是：語言對不是精確的「中文-英文」或「中文-日文」時，判為「退件」，且不再看字數或交期；受支援案件只有在字數大於 5000 且剩餘交期小於或等於 48 小時時判為「加急」，其他受支援案件判為「普通」。
