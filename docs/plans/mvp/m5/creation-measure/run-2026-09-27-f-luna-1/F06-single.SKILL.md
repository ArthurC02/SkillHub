## 目標

產生一則到府維修預約確認簡訊，本文總長不超過30字，且必須包含預約日期、預約時間及應收訂金金額。

## 步驟

1. 從使用者提供的資訊確認日期、時間及應收訂金金額。不得猜測或自行補造任何值。若缺少其中一項，先只詢問缺少的資訊；取得完整資訊後再撰寫簡訊。
2. 使用精簡且清楚的格式，例如：`預約{日期}{時間}應收訂金{金額}元`。保留足以辨識的日期、時間及金額，不要加入問候、稱呼、解釋或其他非必要內容。
3. 計算簡訊本文字數：每個中文字、英文字母、數字、空格及標點符號各計1字。確認日期、時間和訂金金額都清楚呈現，且總字數不超過30。
4. 若超過30字，先移除多餘空格與非必要文字，再採用不含糊的精簡日期、時間及金額寫法。不可刪除三項必要資訊，也不可改變其值。若仍無法在30字內表達，向使用者詢問較精簡且不失真的寫法。
5. 最終回覆只輸出簡訊本文，不加引號、標題、說明、字數統計或其他文字。
