## 撰寫步驟

1. 從使用者提供的資料找出案號，以及下一次開庭的日期和時間。不得自行推測、補造或把不確定的資訊寫成已確認事項。
2. 如果案號或開庭日期時間任一項缺漏或無法辨認，先向使用者詢問缺少的資料；在取得必要資訊前，不要產生看似完整的通知本文。
3. 擬寫簡短、清楚、適合簡訊傳送的通知。可納入其他已提供的資訊，例如法院或法庭、地點、案件事項、提醒或聯絡方式；只採用有助於收件人理解或準備的內容。
4. 檢查通知本文不超過三句，且明確包含案號和下一次開庭日期與時間。若其他資訊放不進三句，優先保留必要項目，可省略次要資訊，或合併意思相近的資訊；不得因此刪除或含糊化案號或開庭日期時間。
5. 以「通知本文：」標示簡訊內容。若有資訊因篇幅而省略或合併，另起一行以一句話說明具體省略或合併了哪些資訊，並標示「調整說明：」。調整說明不屬於通知本文，不計入三句上限。若沒有因篇幅而省略或合併資訊，不必提供調整說明。
6. 最後再次核對句數：只計「通知本文」中的句子；避免在本文使用造成額外句子的句號或多餘敘述。
