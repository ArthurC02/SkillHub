# 到府維修預約確認簡訊

根據使用者提供的預約資料撰寫一則單行簡訊。只準備簡訊本文，不代為傳送。

1. 從輸入讀取預約日期、預約時間及應收訂金金額。保留這三項資料原樣，不補造或改寫資料；只省略多餘的標籤、空格與客套文字。
2. 若輸入缺少預約資料，使用「未提供」標記缺少的欄位，並以方括號保留可填寫的位置，形成可用範本；不猜測資料。使用者未指定語氣時，採用簡潔、禮貌的常見簡訊語氣。
3. 以最精簡的自然中文組成一行簡訊，包含所有有提供的日期、時間與訂金金額。不得附加說明、引號或字數統計。
4. 在存放本 SKILL.md 的目錄，以 shell 將唯一的簡訊本文寫入 `sms.txt`。使用 `cat > sms.txt`，輸入本文後以單獨一行 `EOF` 結束。
5. 在同一目錄執行 `python scripts/check_output.py --max-chars 30`，並對每個有提供的日期、時間及訂金金額各加一個 `--require "資料原文"`。若未通過，縮短連接語或其他非資料文字，不改動資料，重新寫入檔案並重跑檢查，直到顯示 `OK`。若三項資料本身無法在 30 字元內完整容納，保留 30 字元硬限制並在簡訊中簡短標示未能完整納入的欄位。
6. 回覆 `sms.txt` 的檔案內容，且只回覆該內容；由使用者自行決定是否傳送。
