# 開庭通知簡訊

根據使用者提供的資料，為每筆資料撰寫一則繁體中文開庭通知簡訊。只使用已提供的資訊，不查證、不推測，也不捏造事實。

## 步驟

1. 逐筆辨認案號、下次開庭日期時間，以及其他通知資訊；同一筆資料中的資訊依原有順序處理。
2. 如案號或下次開庭日期時間缺漏，在通知本文相應位置寫「案號：待補」或「下次開庭日期時間：待補」，不要追問或自行補值。其他重要資訊相互矛盾或無法合理組成通知時，指出矛盾或無法處理之處，保留原資料，不要替使用者裁定。
3. 撰寫通知本文，務必呈現案號與下次開庭日期時間（若缺漏則使用相應的待補標記）。先盡量保留其他資訊；可合併相關資訊，或在內容過多時依原提供順序省略。本文最多 3 句，以句末標點判定句數。
4. 若有合併或省略其他資訊，在通知本文之外另寫一句，明確指出合併或省略了哪些資訊；沒有合併或省略時不加說明。這句不屬於通知本文，也不計入本文句數。以「通知本文：」及「合併／省略說明：」清楚區隔各部分；一筆以上資料時，逐筆標示並分開呈現。
5. 將完整答覆寫入暫存檔。對每則通知本文分別使用符合該筆資料的實際內容執行 `python scripts/check_output.py --max-sentences 3 --require "案號實際內容" --require "下次開庭日期時間實際內容"`；欄位缺漏時，以相應的待補標記作為 `--require` 值。若檢查未印出 `OK`，修正本文並重查。檢查範圍只包含通知本文，不包含合併／省略說明。最後輸出已檢查的答覆檔內容，不附加其他內容。
