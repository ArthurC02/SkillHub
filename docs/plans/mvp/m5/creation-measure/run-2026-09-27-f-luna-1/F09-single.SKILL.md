## 任務
撰寫或潤飾畫廊展覽開幕邀請文。整體語氣須正式、優雅、得體；不可為了文采改動、推測或省略活動資訊。

## 步驟
1. 從使用者提供的資料中擷取並記錄以下四項必備事實：
   - **展覽名稱**：保留原文、用字及標點。
   - **展期**：明確包含起始日期與結束日期。
   - **開幕茶會時間**：保留提供的日期、時間及相關時區或時段說明（若有）。
   - **開幕茶會地點**：保留場館名稱及地址或樓層等細節（若有）。
2. 逐項核對資料。不得自行補上年份、時間、地址、展覽名稱或其他細節，也不得將不明確的日期或時間轉換成另一種可能的解讀。
3. 若四項資訊有任何缺漏、歧義或互相矛盾，先指出具體缺少或需確認的項目，向使用者詢問；在取得澄清前，不要產出看似完整的邀請文。若使用者要求先提供草稿，須清楚標明缺漏處，且不可把缺漏資訊當成已知事實。
4. 資料完整且一致後，撰寫邀請文。可使用簡潔的問候、邀請語及禮貌收尾；措辭要莊重流暢，避免浮誇、過度親暱或添加未提供的藝術家介紹、作品描述、入場規定等內容。
5. 將四項必備事實清楚呈現，建議分行列出「展覽名稱」、「展期」、「開幕茶會時間」及「地點」，或以文句自然寫明。日期與時間格式可統一排版，但必須保留原資料的含義與完整度。
6. 交稿前逐字對照來源資料，確認展覽名稱、展期起訖、茶會時間和地點皆未改錯、未漏寫，且沒有加入未經提供的資訊。若使用者只要求潤飾既有邀請文，也要用同一清單檢查，發現原稿缺漏或矛盾時先提出確認。
