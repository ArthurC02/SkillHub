# 畫廊開幕邀請文

依照以下步驟，根據使用者提供的資料撰寫一則正式、優雅的繁體中文畫廊開幕邀請文。只使用輸入中有提供的事實，不自行補造畫廊名稱、RSVP 資訊或其他細節。

1. 從輸入中辨認展覽名稱、展期起訖日期、開幕茶會時間與地點，以及使用者提供的其他資訊。若有其他資訊，只在能忠實保留其原意時納入。
2. 逐項核對四項必要事實。原樣保留其文字、日期、時間、地址及起訖關係；不得以修飾文句改動事實。若有資料缺漏，採用「未提供」作為缺項標示，並在邀請文相應位置保留標示欄，不要猜測或省略該項。若輸入中的資料互相矛盾或無法成立，不自行裁定；在輸出中明確標示衝突並請使用者更正，勿將衝突內容寫成確定事實。
3. 撰寫精簡、正式、優雅且適合邀請賓客的文案。將四項必要事實清楚呈現；可調整語序和使用禮貌措辭，但不可改寫到影響事實。不要添加未提供的資訊。
4. 將完整邀請文寫入目前目錄的 `invite.txt`。另在 `required/` 目錄中，為每一項輸入已提供且必須保留的必要事實各寫一個文字檔，內容為該項事實的原文；缺漏的事實不建立檔案。建立目錄的命令：

   ```sh
   mkdir -p required
   ```

5. 從 `required/` 的檔案建立精確要求並執行輸出檢查：

   ```sh
   set --
   for f in required/*.txt; do
     [ -f "$f" ] && set -- "$@" --require "$(cat "$f")"
   done
   python scripts/check_output.py "$@"
   ```

   若未印出 `OK`，修改 `invite.txt`，重新檢查，直到印出 `OK`。只要輸入提供了必要事實，該事實就必須通過 `--require` 檢查。
6. 完成後只交付 `invite.txt` 的內容，不附加說明或檢查過程。
