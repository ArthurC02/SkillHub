# 整理訂書留言

## 用途
將客人提供的中文自由文字整理為訂購清單，計算不含運費的書籍金額總計，並將提及的運費另列。只依留言整理，不查外部書目或價格資料。

## 步驟
1. 從輸入留言逐項擷取書名原文、數量、單價、小計及運費。保留書名原文；若書名有多種可能，完整保留各可能名稱並標示「待確認」，不自行選定。不要把運費併入書籍小計。
2. 將金額轉成不含幣別符號的數字；保留留言提及的幣別。若幣別未提供，使用「幣別未註明」，不要假定幣別。建立每項商品的 JSON 物件，欄位為 `title`（字串）、`title_clear`（布林值）、`quantity`（正整數或 `null`）、`unit_price`（數字或 `null`）、`subtotal`（數字或 `null`）。不明資訊填 `null`，不得猜測。數量省略時，僅在書名明確時將 `quantity` 設為 `1`；否則填 `null`。若留言只給總價，放入 `subtotal`；若只給單價，放入 `unit_price`。重複使用 `--item` 傳入各項 JSON。
3. 將每筆已提及的運費金額作為數字，重複使用 `--shipping` 傳入。運費有提及但金額不明時，不傳入猜測值，稍後在結果中註明「金額未提供」。
4. 在 SKILL.md 所在目錄執行腳本，依實際商品與運費數量重複 `--item` 和 `--shipping`，並以 `--currency` 傳入留言明示的幣別；若有多種幣別或未明示幣別，不傳 `--currency`。

   ```bash
   python scripts/calculate_order.py --item '{"title":"留言中的書名","title_clear":true,"quantity":1,"unit_price":null,"subtotal":null}'
   ```

   這是命令格式範例，不是答案。換成擷取出的實際資料；不得把範例內容當作留言事實。
5. 若腳本退出碼為 2，將錯誤訊息和造成問題的留言資訊一併呈現，請客人確認矛盾或無法使用的資料，不自行消解。否則直接呈現腳本印出的訂購清單、書籍金額總計及運費合計。對無法計算的項目明確標示，並說明書籍總計只包含可計算項目；若留言提到但沒有金額的運費，也另行註明。只交付整理結果，不宣稱已聯絡、下單或做其他外部操作。
