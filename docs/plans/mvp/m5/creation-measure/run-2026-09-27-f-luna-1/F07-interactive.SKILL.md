## 用途與限制

根據使用者提供的本學期學生資料，判斷缺席是否滿 3 次。對達門檻者準備一封尊重、清楚的家長警告信草稿，並建議標記為「留意名單」；未達門檻者不產生信件、不提供標記建議。

使用者提供的次數視為本學期累計數字，且所有列出的缺席均納入計算。不得推測未提供的姓名、家長稱謂或次數。你只有本地檔案與 shell，沒有教務系統登入、修改或寄信工具；只準備可供使用者自行處理的內容，絕不可聲稱已登入、寄信或完成標記。

## 步驟

1. 從使用者訊息逐筆擷取學生姓名、家長稱謂及本學期缺席次數。保留原始姓名與稱謂，不自行補全。資料缺漏時使用 `?` 表示未提供；沒有任何學生資料時，繼續執行腳本以產生資料格式範本。
2. 在含有此 `SKILL.md` 的目錄中，為每筆資料加一個 `--student` 參數，格式為 `姓名|家長稱謂|次數`。用 shell 引號保護每筆完整資料，並執行：

   ```sh
   python scripts/absence_decision.py --student '王小明|王先生|2' --student '林安琪|林女士|3'
   ```

   將範例參數替換為使用者實際提供的資料；傳入所有學生，不限於可能達門檻者。缺漏欄位傳入 `?`，例如 `'姓名|?|3'`。若沒有學生資料，不傳 `--student` 參數。次數若不是可用的非負整數，照實說明輸入無法判定並請使用者確認，不要猜測或改寫資料。
3. 將腳本印出的內容作為結果呈現，不自行改動判定、次數或未提供資訊的標示。內容包括逐生判定、符合門檻者的信件草稿與標記建議；若無資料，則包括可用的輸入範本。
4. 清楚保留結果中的限制說明：沒有登入或修改教務系統，也沒有實際完成名單標記。把信件草稿與建議交給使用者自行複核及處理。
