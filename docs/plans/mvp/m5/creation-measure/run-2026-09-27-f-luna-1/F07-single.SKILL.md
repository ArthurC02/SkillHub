---

## 流程

1. **確認個案與權限**
   - 確認學生身分、班級、本學期的起訖日期，以及提出需求者有權處理該生出缺席資料。
   - 只使用校方核准的出缺席紀錄與教務系統。不要索取或記錄使用者的密碼；只有在已登入且經授權的工作階段或核准工具可用時，才進行系統操作。
   - 若無法確認授權、學生身分或學期範圍，先詢問並暫停，不要寄信或修改紀錄。

2. **核實缺席次數**
   - 查閱本學期官方出缺席紀錄，確認哪些紀錄依校規計入「缺席」。依校方規定處理請假、遲到、部分時段缺課、更正紀錄及重複紀錄；不要自行假定哪些情況計入。
   - 計算該生本學期累計缺席次數，並核對紀錄日期，避免漏算或重複計算。
   - 若已達 3 次或以上，進入下一步。若未達 3 次，不寄發警告信，也不標記為「留意名單」；回覆目前已核實的次數與尚未達門檻。
   - 若資料矛盾、缺少紀錄，或校規對計算方式不明確，先向負責的校方人員查證，不要推測或採取標記行動。

3. **準備家長警告信**
   - 使用校方核准的聯絡方式，確認收件人為學生的家長或法定監護人。信中只包含該學生所需資訊，不揭露其他學生或不必要的敏感資料。
   - 清楚說明本學期截至核對日期的缺席次數、校方的關切、希望家長採取的行動，以及聯絡學校的方式。只陳述已核實的事實；不要自行增加處分、截止日期或政策承諾。
   - 可依校方規定調整以下草稿：

     **主旨：本學期缺席情形提醒——[學生姓名]**

     [家長／監護人稱謂]您好：

     根據學校截至 [核對日期] 的出缺席紀錄，[學生姓名] 本學期累計缺席 [次數] 次。依學校出缺席追蹤流程，我們特此提醒您留意學生的到課情形，並請您與 [學生姓名] 一同檢視出席狀況。如紀錄有誤，或您希望說明相關情況，請透過 [校方核准的聯絡方式] 與 [聯絡人／單位] 聯繫。

     感謝您的協助。

     [學校／班級／聯絡人]

   - 寄出前再次核對姓名、收件人、缺席次數、日期與聯絡方式，並遵守校方的審核或通知程序。若規定要求主管審閱，先送審，不要自行寄出。

4. **在教務系統標記**
   - 只有在已獲授權且系統工作階段可用時，才進入校方正式教務系統。不得嘗試繞過登入、權限或安全控管。
   - 依系統提供的搜尋功能確認學生身分與本學期紀錄；再次確認缺席已達門檻。
   - 將該生標記為「留意名單」。如系統要求原因或備註，填寫簡潔、客觀且必要的內容，例如「本學期缺席達校方追蹤門檻；已依流程處理家長通知」，並遵循校方紀錄規範。
   - 儲存後確認畫面顯示標記已生效，且標記的是正確學生與學期。若操作失敗、無此選項或顯示資料不一致，停止重試並通知有權限的校方人員處理。

5. **回報結果**
   - 僅回報必要資訊：核實的缺席次數、警告信是已草擬／已依規定寄出／待審核，以及「留意名單」標記是已確認完成或尚未完成。
   - 若沒有可用的登入工作階段、核准系統工具或足夠權限，明確說明無法替使用者登入或修改教務系統；提供上述安全操作步驟，並請有權限的人員自行完成。不得聲稱已寄信或已標記，除非確實完成並確認。
