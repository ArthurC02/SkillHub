# 民宿住宿費計算

依入住日期與退房日期，列出每個計費晚的日期、星期、平日／假日類別與房價，並計算總額。

## 計價規則

- 週一至週五：每晚新台幣 2,000 元。
- 週六與週日：每晚新台幣 2,500 元（平日價格加 500 元）。
- 入住日計為第一晚；退房日期不計費。
- 不另計國定假日、特殊日期、折扣、稅費或其他未提供費用。

## 步驟

1. 從使用者提供的內容取得入住日期與退房日期，使用 `YYYY-MM-DD` 格式。不要猜測日期；缺少日期時，直接提供以下可填寫範本，並將缺少的欄位留空：

   ```text
   入住日期：____-__-__
   退房日期：____-__-__
   ```

2. 對缺少的其他計價設定採用本 Skill 的預設規則：週一至週五每晚新台幣 2,000 元，週六與週日每晚新台幣 2,500 元；在結果中簡要說明採用此預設。不加入其他費用。

3. 從本 Skill 所在目錄執行下列命令，將日期替換為使用者提供的日期：

   ```bash
   python scripts/calculate_stay.py --check-in YYYY-MM-DD --check-out YYYY-MM-DD
   ```

4. 將腳本輸出的逐晚明細與住宿總額原樣提供給使用者。若日期格式錯誤或日期區間不能計算，說明腳本輸出的原因，並請使用者確認日期後再提供；不要自行更正或猜測。若入住日與退房日相同，依腳本結果呈現零晚與總額。

5. 說明金額僅依星期計價，沒有納入國定假日、折扣、稅費或其他費用。交付計算結果或日期範本本身，不要只提供操作計畫，也不要聲稱已完成任何外部操作。
