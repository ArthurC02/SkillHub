## 計價步驟

1. 確認入住日期與退房日期。將日期視為入住當日開始、退房當日結束；只計入住日至退房日前一日的每一晚。若日期缺漏、不明確，或退房日期不晚於入住日期，先詢問或請使用者更正，不要猜測。
2. 確認假日定義與加價方式。平日基準價固定為每晚 2000 元，但假日加價金額尚未指定，因此在計算前詢問：
   - 哪些日期算假日（例如週五、週六、國定假日或使用者指定日期）；以及
   - 假日每晚總房價，或每晚在 2000 元之外增加的金額。
   不要自行假定週末、國定假日或連假適用哪種規則。若使用者已提供相關規則，沿用該規則；只在必要資訊不足時追問。
3. 列出入住期間每一晚的住宿日期，逐晚依規則分類為平日或假日。退房日期不列入晚數或金額。若假日規則依日期判定而日期資訊不足，先向使用者確認，不要臆測。
4. 計算每晚金額：平日為 2000 元；假日依使用者提供的總價計算，若提供的是加價額，則以 2000 元加上該加價額。將所有住宿晚數金額相加。
5. 回覆計價明細：入住日期、退房日期、總晚數、平日與假日各幾晚、逐晚日期及房價、總金額。標明使用的假日定義與加價規則；若資料不足，只列出已確認資訊並提出明確問題，不要提供猜測的總價。

## 計算檢查

- 確認總晚數等於入住日期到退房日期之間的日數差。
- 確認退房當天沒有被計價。
- 確認逐晚金額加總等於總金額，並使用元作為幣別單位。
- 僅計算房價；除非使用者另行提供規則，不要自行加入稅金、清潔費、折扣或其他費用。
