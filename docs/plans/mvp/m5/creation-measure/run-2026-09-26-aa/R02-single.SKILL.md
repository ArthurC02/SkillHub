# 目的
清理 Excel 客戶名單：去除重複資料，並標記缺少電話的列。

# 適用情境
當輸入是一份 Excel 名單，且需要：
1. 找出並移除重複客戶資料；
2. 標記電話欄位空白、缺值或無效的列。

# 執行步驟
1. **確認欄位結構**
   - 找出代表客戶識別的欄位，通常是姓名、公司、Email、電話或其組合。
   - 找出電話欄位名稱，確認是否有多個電話欄位（例如手機、公司電話）。
   - 若欄位名稱不明確，先根據表頭判斷，再依資料內容確認。

2. **備份原始資料**
   - 在不覆蓋原始檔的前提下另存一份清理版本。
   - 若可在同一活頁簿操作，先複製工作表再處理。

3. **定義重複規則**
   - 優先使用最能唯一識別客戶的欄位組合。
   - 常見規則：
     - 若有客戶編號，使用客戶編號判定重複。
     - 若沒有客戶編號，使用姓名 + 電話，或姓名 + Email。
     - 若資料欄位較少，使用姓名 + 公司名稱。
   - 若資料中存在明顯格式差異，先做基本標準化：去除前後空白、統一大小寫、移除多餘符號後再比對。

4. **去除重複資料**
   - 依定義好的重複規則找出重複列。
   - 保留第一筆出現的資料，或依使用者指定保留最新/最完整的一筆。
   - 若無額外規則，預設保留第一筆，刪除後續重複列。
   - 在刪除前先記錄重複筆數，方便回報。

5. **標記缺少電話的列**
   - 新增一個標記欄位，例如「電話缺失」或「缺少電話」。
   - 對以下情況標記為缺少電話：
     - 電話欄位空白；
     - 只有空白字元；
     - 內容為無效占位值，例如「N/A」、「-」、「無」、「未知」。
   - 標記方式可用「是/否」、「缺少/正常」或 TRUE/FALSE，但需一致。

6. **檢查結果**
   - 確認重複列已移除。
   - 確認所有缺少電話的列都已被標記。
   - 抽查幾筆資料，確認沒有誤刪或誤標。

7. **輸出結果**
   - 儲存為新的 Excel 檔案或新的工作表。
   - 若需要交付摘要，回報：
     - 原始筆數；
     - 移除的重複筆數；
     - 缺少電話的筆數；
     - 最終保留筆數。

# 注意事項
- 若重複判定規則不明確，先詢問使用者要以哪些欄位判定重複。
- 若電話欄位名稱不只一個，需先確認要標記哪一欄，或是否要任一電話欄缺失即標記。
- 不要直接覆蓋原始檔，除非使用者明確要求。
