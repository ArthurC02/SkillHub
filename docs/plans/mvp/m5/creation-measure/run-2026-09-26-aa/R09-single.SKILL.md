## 目的
將使用者提供的履歷改寫為更符合資料分析職缺的一頁版，重點放在數據處理、分析方法、商業洞察、工具能力與可量化成果。

## 使用時機
在使用者要求「改寫履歷」、「轉成資料分析版本」、「縮成一頁內」或明確提到資料分析、數據分析、BI、商業分析、分析師等職缺時使用。

## 工作流程
1. 先確認輸入內容是否足夠：
   - 若有完整履歷，直接開始改寫。
   - 若資訊不足，先向使用者索取必要內容：
     - 現有履歷全文
     - 目標職缺名稱或職缺描述（若有）
     - 希望保留或強調的經歷、工具、產業
2. 讀取履歷後，抽出與資料分析相關的內容：
   - 數據整理、報表、儀表板、A/B test、SQL、Python、Excel、Tableau、Power BI、統計分析、商業洞察、流程優化、跨部門協作
   - 任何可量化成果，例如提升轉換率、降低成本、縮短工時、提高準確率
3. 重新組織內容，優先保留與資料分析最相關的資訊：
   - 個人簡介／摘要
   - 核心技能
   - 工作經歷
   - 學歷與證照
   - 專案經驗（若比一般工作經歷更能證明分析能力）
4. 改寫原則：
   - 以資料分析職缺常見關鍵字表達，但不要捏造經歷、工具或成果
   - 將一般職務描述改寫成「分析問題 → 使用方法/工具 → 產出洞察 → 帶來影響」的句型
   - 優先使用動詞開頭的條列句
   - 每段都盡量包含可驗證的成果或具體責任
   - 刪除與目標職缺關聯低的內容，避免過長
5. 長度控制：
   - 產出以一頁內為目標
   - 若內容過多，優先保留最近、最相關、最具量化成果的經歷
   - 精簡重複描述，避免冗詞與空泛形容詞
6. 若使用者未提供職缺描述，則以通用資料分析職缺為基準；若有職缺描述，則優先對齊其要求。

## 內容建議結構
- 標題：姓名、聯絡方式、LinkedIn／作品集（若有）
- 簡介：2–3 句，概括分析背景、工具能力與商業價值
- 核心技能：5–8 項，聚焦資料分析工具與方法
- 工作經歷：每段 2–4 點條列，強調成果與分析方法
- 專案／證照／學歷：僅保留與職缺高度相關者

## 寫作規則
- 使用繁體中文，除非使用者要求其他語言
- 保持專業、精煉、可直接投遞
- 不要加入虛構學歷、證照、工具或數據
- 不要寫成求職信；這個技能的輸出是履歷版本
- 若原始履歷缺少量化成果，可保留原意並建議使用者補充數字，但不要自行編造

## 輸出格式
直接輸出改寫後的履歷內容，不要附加分析過程、評語或修改說明。
