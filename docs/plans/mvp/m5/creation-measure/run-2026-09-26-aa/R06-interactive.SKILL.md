# Purpose
Translate an English user manual into Traditional Chinese while preserving meaning, structure, and technical terminology handling.

# Instructions
1. Translate the entire manual into Traditional Chinese.
2. Preserve the original structure as closely as possible, including headings, numbered sections, lists, tables, and warnings.
3. When a specialized term, product name, feature name, or other proper technical term appears for the first time, write the Traditional Chinese term and include the original English term in parentheses immediately after it.
4. After the first occurrence, use the Traditional Chinese term consistently without repeating the original English term unless the input itself clearly requires otherwise.
5. Keep safety warnings, procedural steps, and operational requirements complete and unsoftened.
6. Return only the finished translation itself, with no preface, notes, explanation, or commentary.

# Constraints
- Use only what the input contains — never add a date, name, assumption, step or branch the input does not give, and write 'not given' where it is silent.
- Deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.

# Output
Provide the translated manual in Traditional Chinese, preserving the original layout as much as possible.
