# 每日新聞摘要寄送流程

## 先確認這件事是否可執行
這個任務需要：
- 可存取三個新聞網站的即時內容
- 可寄送電子郵件的帳號或郵件工具
- 已知收件人信箱
- 若要每天早上自動執行，還需要排程機制

如果目前沒有網路存取、沒有郵件權限，或沒有排程環境，就不能直接完成寄送；此時只能先整理需求、確認來源網站與收件資訊，或請使用者提供可用工具。

## 執行步驟
1. 取得三個新聞網站的首頁或新聞列表頁。
2. 擷取每個網站當天最新、最重要的標題。
3. 去除重複或高度相似的標題。
4. 將三個網站的標題整合成 5 條摘要：
   - 每條摘要以一個主題為主
   - 優先保留跨網站重複出現或最重要的新聞
   - 用簡短、客觀的語句改寫，不加入未確認的細節
5. 檢查摘要是否涵蓋三個來源，且總數正好是 5 條。
6. 撰寫郵件內容：
   - 主旨：每日新聞摘要
   - 內文：5 條摘要，必要時附上來源網站名稱
   - 若來源標題有明顯時間差或更新，註明「以目前可取得的最新標題為準」
7. 寄送到使用者指定的信箱。

## 摘要撰寫規則
- 只根據標題與可直接確認的資訊整理，不要自行補充新聞內容。
- 若標題含有明顯偏見或誇張字眼，摘要時改寫成中性表述。
- 若某網站今天沒有可用標題，記錄為「來源暫無可用標題」，但仍維持 5 條總數。
- 若三個網站的新聞高度重疊，優先合併成較少的主題，再補足到 5 條。

## 郵件格式建議
- 主旨：每日新聞摘要（YYYY-MM-DD）
- 內文：
  - 今日摘要
  - 1. ...
  - 2. ...
  - 3. ...
  - 4. ...
  - 5. ...
  - 來源：網站 A、網站 B、網站 C

## 若要自動化
- 先確認三個網站是否允許抓取標題。
- 設定每天早上固定時間執行。
- 每次執行前先檢查來源是否可連線。
- 若抓取失敗，改為寄送錯誤通知或略過當次寄送，避免寄出空白內容。
