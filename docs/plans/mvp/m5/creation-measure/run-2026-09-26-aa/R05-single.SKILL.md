# 目的
將一週內的每日花費整理成清楚的表格，為每筆支出標註類別，並在週末計算各類別合計與總計。

# 適用情境
- 使用者提供一週的花費明細，要求整理成表格。
- 使用者希望每筆支出都標示類別。
- 使用者要求在週末做分類加總、看出各類別花了多少。

# 工作流程
1. **先確認資料是否完整**
   - 檢查是否有一週內的每日花費明細。
   - 若缺少日期、金額、品項或用途，先向使用者補問。
   - 若使用者沒有提供分類，根據品項或用途推定合理類別；若無法判定，標為「其他」。

2. **建立每日明細表**
   - 以日期為主軸列出每筆花費。
   - 每筆至少包含：
     - 日期
     - 項目/用途
     - 類別
     - 金額
   - 若同一天有多筆，逐筆列出，不要合併，除非使用者明確要求合併。

3. **統一類別名稱**
   - 將相近類別合併成一致名稱，例如：
     - 餐飲、吃飯、外食 → 餐飲
     - 交通、車資、捷運、公車 → 交通
     - 購物、日用品、雜貨 → 購物/日用品
   - 保持類別數量精簡且一致。

4. **計算週末分類合計**
   - 以整週所有支出為範圍，按類別加總。
   - 同時計算：
     - 各類別合計
     - 全週總支出
   - 若使用者指定「週末」只做週六、週日的合計，則只統計週六與週日；否則預設為整週結算。

5. **輸出表格**
   - 先輸出每日明細表。
   - 再輸出週末/週結分類合計表。
   - 表格欄位建議如下：
     - 明細表：日期｜項目｜類別｜金額
     - 彙總表：類別｜合計
   - 金額格式保持一致，必要時加上貨幣單位。

6. **檢查一致性**
   - 確認所有明細金額都有被納入分類合計。
   - 確認總計等於各類別合計之和。
   - 若有四捨五入或格式差異，說明原因。

# 輸出原則
- 以簡潔、清楚的表格呈現。
- 不要省略任何已提供的花費。
- 若資料不足，先列出缺少項目並請使用者補充。
- 若分類有推定，保持一致並避免過度細分。
