# 新人到職流程

依照流程圖中的順序執行，不要跳步，也不要自行新增未出現在圖中的流程。

## 執行順序
1. **收到新人到職通知**
   - 確認已收到新人到職訊息，並開始後續準備。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認帳號可正常使用。

3. **加入 Slack 頻道**
   - 將新人加入需要的 Slack 頻道。
   - 確認其可接收團隊溝通資訊。

4. **準備筆電與門禁卡**
   - 準備新人報到所需的筆電與門禁卡。
   - 確認設備與權限已可交付。

5. **安排第一週訓練**
   - 規劃新人第一週的訓練內容與時程。
   - 確認相關人員知道安排。

6. **指派導師**
   - 為新人指定導師或帶領人。
   - 確認新人知道聯絡對象。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備回饋與追蹤事項。

8. **記錄到人資系統**
   - 將上述到職處理結果記錄到人資系統。
   - 確保資料完整且可追蹤。

## 注意事項
- 這個流程是線性的；若某一步尚未完成，先補齊再往下進行。
- 若流程圖之外缺少必要資訊，先向相關單位確認，再繼續。
