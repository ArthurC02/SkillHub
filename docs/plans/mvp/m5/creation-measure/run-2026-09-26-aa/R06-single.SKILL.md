## 目的
將一份英文使用手冊完整翻譯為繁體中文，並在專有名詞第一次出現時保留原文。輸出應忠實、自然、術語一致，且保留原手冊的章節、條列、警告、表格與編號結構。

## 工作流程

1. **先通讀全文**
   - 先確認手冊主題、受眾、語氣、術語密度與結構。
   - 找出重複出現的專有名詞、產品名稱、功能名稱、按鈕名稱、錯誤訊息、法規名詞與縮寫。

2. **建立術語一致性**
   - 為每個專有名詞決定固定譯法。
   - 同一名詞在全文中必須一致翻譯。
   - 若某名詞需要保留原文，第一次出現時寫成「中文譯名（Original Term）」；之後只用中文譯名，除非原文對理解必要。
   - 縮寫第一次出現時，若有必要，寫成「中文全名（英文縮寫）」；後續只用縮寫或中文全名，依上下文一致處理。

3. **逐段翻譯**
   - 保留原文的章節順序、標題層級、編號、項目符號與表格結構。
   - 指令句要自然、清楚，符合繁體中文技術文件語氣。
   - 不要自行增刪內容，不要補寫原文沒有的說明。
   - 若原文含警告、注意、提示、步驟、前置條件，請維持其功能與語氣強度。

4. **處理專有名詞與介面文字**
   - 產品名、公司名、功能名、按鈕名、選單名、欄位名、錯誤碼等，依一致規則處理。
   - 若介面文字在產品中通常不翻譯，則保留原文並在首次出現時加中文說明；若應翻譯，則採固定譯法。
   - 對於不確定是否為專有名詞的詞，優先查閱全文上下文，必要時採「中文譯名（原文）」以降低歧義。

5. **保留格式與可讀性**
   - 保留原有的粗體、斜體、程式碼、連結、註腳、表格欄位與清單層級。
   - 若原文有圖說、截圖標註或按鍵組合，翻譯時保持簡潔一致。
   - 單位、數字、日期格式可依繁體中文習慣調整，但不得改變原意。

6. **完成後自我檢查**
   - 檢查是否有漏譯段落、重複段落或錯置標題。
   - 檢查專有名詞首次出現是否已附原文。
   - 檢查術語是否前後一致，尤其是同一功能、按鈕、錯誤訊息。
   - 檢查是否保留了所有警告、注意事項與步驟順序。

## 翻譯原則
- 忠實優先，不擅自改寫內容。
- 用詞自然、正式、適合使用手冊。
- 專有名詞首次出現附原文，之後維持一致。
- 若原文含歧義，保留可追溯性，不要憑空補充。
- 若遇到無法判定的術語，先依上下文採最保守譯法，並在首次出現時保留原文。
