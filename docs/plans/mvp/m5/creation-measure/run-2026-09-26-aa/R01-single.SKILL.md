# 目的
把會議逐字稿整理成一份清楚、可執行的待辦清單，每一條都要包含：
- 待辦事項
- 負責人
- 期限

# 使用時機
當輸入是會議逐字稿、會議紀錄、錄音轉文字內容，且需求是整理成行動項目時使用本技能。

# 處理原則
1. 只根據逐字稿內容整理，不要自行補充不存在的任務。
2. 若逐字稿中有明確提到負責人與期限，直接保留。
3. 若有任務但缺少負責人或期限，先從上下文找最合理的對象或日期。
4. 若仍無法確定，明確標示「待確認」，不要猜測。
5. 同一件事若被重複提到，合併成一條待辦。
6. 將口語、零散、重複的內容改寫成簡潔的行動句。
7. 優先保留會議中已經形成共識、需要後續執行的事項。

# 整理步驟
1. 通讀逐字稿，標記所有看起來是任務、決議、跟進事項、交辦事項的句子。
2. 對每個項目判斷：
   - 這是不是可執行的動作？
   - 誰負責？
   - 何時完成？
3. 將每個項目改寫成一條待辦。
4. 若期限是相對時間，保留原意並盡量轉成明確日期；若無法轉換，保留原文並註明待確認。
5. 若負責人只出現職稱或團隊名稱，照原文寫出。
6. 若有多個負責人，列出主要負責人，必要時補充協作人員。

# 輸出格式
請輸出成條列清單或表格，建議欄位如下：
- 待辦事項
- 負責人
- 期限
- 備註（可選，用於補充依據或待確認事項）

# 範例格式
- 待辦事項：整理新版提案並寄給客戶
  - 負責人：王小明
  - 期限：2026-10-03
  - 備註：會議中提到「下週三前」

# 注意事項
- 不要把討論內容、背景說明、抱怨或未決定事項誤寫成待辦。
- 不要省略負責人與期限；若缺漏，務必標示待確認。
- 若逐字稿內容不足以判定任務，先列出可確認的項目，再列出待確認清單。
