# 依流程處理客戶 Excel 訂單

依照圖中的流程執行：收到客戶 Excel 訂單 → 轉成 CSV 格式 → 檢查缺漏欄位 → 匯入 Shopify 後台 → 回覆客戶已入單。

## 執行步驟

1. **收到客戶 Excel 訂單**
   - 先確認收到的是可讀取的 Excel 檔案。
   - 檢查檔案是否能開啟、是否有多個工作表、以及哪一個工作表是訂單資料。
   - 若檔案無法讀取或內容明顯不完整，先回報問題並請對方重新提供。

2. **轉成 CSV 格式**
   - 將訂單資料整理成 Shopify 可匯入的 CSV。
   - 保留必要欄位名稱與資料格式一致性，避免欄位順序或名稱錯誤。
   - 若原始 Excel 有合併儲存格、空白列、註解列或格式化文字，先整理成純資料列再輸出。

3. **檢查缺漏欄位**
   - 檢查每筆訂單是否缺少匯入所需欄位。
   - 特別留意常見必填資訊，例如：商品、數量、收件人資訊、地址、聯絡方式、SKU、變體、價格或其他 Shopify 匯入所需欄位。
   - 若發現缺漏：
     - 先標記缺漏項目。
     - 能從其他欄位推得的資料先補齊。
     - 無法補齊的部分，整理成待確認清單，請客戶補資料後再繼續。

4. **匯入 Shopify 後台**
   - 使用整理好的 CSV 進行 Shopify 後台匯入。
   - 匯入前再次確認欄位對應正確、資料沒有明顯錯位、日期與數字格式正確。
   - 匯入後檢查結果是否成功，並確認訂單是否已建立或更新。
   - 若匯入失敗，根據錯誤訊息回頭修正 CSV，再重新匯入。

5. **回覆客戶已入單**
   - 在確認匯入成功後，回覆客戶訂單已完成入單。
   - 若有缺漏資料、匯入警告或需要客戶確認的項目，一併簡潔說明。
   - 回覆內容應包含：已入單狀態、是否有異常、以及後續需要客戶配合的事項（如有）。

## 注意事項

- 不要直接假設缺漏欄位的內容；無法確認時要先標記並詢問。
- 匯入前務必檢查 CSV 是否符合 Shopify 的欄位要求。
- 若流程中任何一步無法完成，先停止並回報原因，不要跳過檢查直接匯入。
