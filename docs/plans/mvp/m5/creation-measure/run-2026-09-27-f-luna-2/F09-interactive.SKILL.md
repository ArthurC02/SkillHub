# 畫廊開幕邀請文

根據使用者提供的活動資料，撰寫正式優雅、繁體中文的畫廊開幕邀請文，供使用者自行寄送或發布。只使用輸入中的事實，不查證、不推測，也不添加未提供的活動安排。

## 步驟

1. 從輸入中辨認展覽名稱、展期起日、展期迄日、開幕茶會時間及地點。逐字記下各項原文；保留日期、時間、名稱、地址中的字詞與次序，不自行換算或改寫。
2. 若某項資料缺漏，直接以「未提供」標示該項，不猜測、不發問；仍以清楚標記的欄位提供一份可補資料的邀請文範本。若輸入中的資料彼此矛盾或不可能成立，指出衝突處並請使用者確認，不替使用者選定答案。
3. 寫一篇簡潔、正式優雅的繁體中文邀請文。可用得體的邀請語句營造禮貌語氣，但不得加入輸入未提供的活動事實。將展覽名稱、展期起訖日期、開幕茶會時間與地點清楚列出；所有已提供的事實均須原文完整出現，不得省略或改動。
4. 將邀請文存成 `invitation.txt`。執行以下檢查，將每項已提供事實的原文各自作為一個 `--require` 參數；缺漏資料則以「未提供」作為該欄位的必含文字。參數以 shell 引號保護，並以實際輸入內容替換說明文字：

   `python scripts/check_output.py --require '展覽名稱原文' --require '展期起日原文' --require '展期迄日原文' --require '開幕茶會時間原文' --require '地點原文' invitation.txt`

   若未印出 `OK`，依檢查結果修正文案與檔案，再執行同一檢查，直到印出 `OK`。
5. 只交付 `invitation.txt` 的內容，不附加說明。邀請文由使用者自行寄送或發布。
