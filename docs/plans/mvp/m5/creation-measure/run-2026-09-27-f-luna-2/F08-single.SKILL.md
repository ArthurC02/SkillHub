## 任務
將使用者提供的獸醫看診收費資料整理為清楚的明細清單，列出看診日期、看診項目、數量、單價，並計算每項小計與總金額。

## 步驟
1. 從輸入中辨認每筆看診的日期，以及每項收費的項目名稱、數量和單價。保留原本使用的貨幣與金額精度；若使用者未提供貨幣，不要自行指定。
2. 若資料包含不同看診日期，按日期分組；同一天有多個項目時，逐項列出。若日期未提供，標示「日期未提供」，不要推測日期。
3. 檢查每個收費項目是否有可用的數量與單價。只有在兩者明確時才計算小計：`數量 × 單價`。數量或單價缺漏、格式不清，或有多種合理解讀時，將該欄標示為「未提供」或「待確認」，並向使用者詢問；不要自行補值或把不明項目當作零元。
4. 計算每個日期的已確認項目小計，以及整份清單的總金額。總金額只包含數量與單價都已確認的項目；若仍有待確認項目，清楚註明此總額尚未包含它們，並避免把它說成最終應收金額。
5. 重新核對每項乘法與加總。不要自行加入未提供的稅金、折扣、診療費或其他費用。若使用者明確提供額外費用或調整，依其資料列項並納入計算；有歧義時先詢問。
6. 以繁體中文回覆，採用下列格式；依實際資料調整日期分組與欄位內容：

### 看診日期：YYYY-MM-DD

| 看診項目 | 數量 | 單價 | 小計 |
|---|---:|---:|---:|
| 項目名稱 | 2 | $100 | $200 |
| **本日小計** |  |  | **$200** |

**總金額：$200**

若貨幣未知，金額僅照輸入呈現，不加貨幣符號。若有未確認項目，在清單後列出待確認欄位與具體問題，並註明總金額的計算範圍。若使用者只提供部分資料，先整理已知內容，再詢問完成計算所需的缺漏資訊。
