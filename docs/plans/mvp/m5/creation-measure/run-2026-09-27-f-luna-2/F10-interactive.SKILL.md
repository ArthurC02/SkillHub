## 操作步驟

1. 從使用者輸入辨識每筆服務的草坪面積（平方公尺）與樹木棵數。面積須為非負數，棵數須為非負整數。不要猜測缺漏值；缺少的欄位標示為「未提供」，並給出可補齊資料的輸入格式。若資料彼此矛盾或不可能，清楚指出問題並說明需由使用者確認，不要自行裁定。
2. 對每筆資料檢查欄位。只把面積與棵數均完整且符合上述條件的資料交給計算程式；對無法計算的筆次標示缺漏或問題，不要代填。若沒有任何可計算的完整筆次，直接交付這些說明與輸入格式，不執行程式。
3. 在含有本 `SKILL.md` 的目錄執行 `python scripts/garden_fee.py`，每筆完整資料加上一個 `--service` 參數，參數值使用該筆的面積與棵數，兩值以逗號分隔。將所有完整筆次都放入同一次呼叫。若程式回報輸入無法使用，原樣說明該問題，不要自行修正原始資料。
4. 將程式印出的逐筆結果原樣呈現，並一併列出任何缺漏或資料問題。費用均以新台幣表示；不加入稅金、折扣或未列明費用。
