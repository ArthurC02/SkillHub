## 撰寫步驟

1. 從使用者提供的資料中找出案號、下一次開庭日期與時間，以及其他希望放進通知的資訊。
2. 確認案號和開庭日期、時間都有明確資料。不得自行推測或編造；任一項缺少或含糊時，先向使用者詢問缺少或需確認的內容，不要產出看似完整的通知。
3. 撰寫簡潔、清楚、適合簡訊傳送的通知本文。案號與下一次開庭日期、時間是必填資訊；其他資訊可合併精簡，必要時省略。保留日期、時間及地點等資料原意，不要因精簡而改變。
4. 檢查通知本文的句數：最多 3 句。以句號、問號或驚嘆號等句末標點判斷句子；不要用分行或分號規避句數限制。標示清楚的日期或時間不單獨算句子。
5. 若有省略或合併使用者提供的其他資訊，在通知本文之後另加一句說明，列出省略或合併了哪些資訊。這句是給使用者的說明，不屬於通知本文，也不受 3 句上限限制。若沒有省略或合併，不必加說明句。
6. 以「通知本文：」及（若需要）「編輯說明：」分開呈現，避免說明句被誤認為簡訊內容。

## 輸出前檢查

- 通知本文不超過 3 句。
- 通知本文明確包含案號及下一次開庭日期、時間。
- 沒有把未提供或不確定的資訊寫成事實。
- 任何省略或合併都已在通知本文之外用一句話交代。
