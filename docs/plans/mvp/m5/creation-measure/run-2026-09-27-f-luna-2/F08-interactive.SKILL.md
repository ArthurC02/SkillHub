## 工作方式

整理使用者貼上的看診資料，保留其日期與項目名稱，計算每筆小計及總金額；不提供診療或定價建議。使用者未指定幣別時，沿用未標示幣別的數字，不自行添加幣別。不要補猜缺漏的價格或其他資料。

## 步驟

1. 從本次訊息擷取看診資料列；每列應包含日期、項目、數量及單價，欄位可用 `｜` 或 `|` 分隔。忽略不含欄位分隔符的說明文字。
2. 若沒有可用資料，輸出下方空白模板，缺漏欄位標示「未提供」；不要編造明細或金額。若資料互相矛盾或無法判讀，明確標示「需確認，未計算」，指出有問題的欄位，不自行裁決。
3. 對完整且可判讀的資料，從存放本 SKILL.md 的目錄執行以下命令；將 `--data` 的值替換為使用者貼上的原始資料列，保留換行及欄位內容：

   ```sh
   python scripts/calculate_fees.py --data '2026-09-01｜診察｜數量 1｜單價 500
   2026-09-01｜疫苗｜數量 2｜單價 350'
   ```

4. 將腳本印出的 Markdown 表格及總金額原樣作為回答。若腳本以錯誤結束，不呈現計算結果；以繁體中文說明腳本指出的輸入問題，並提供以下可填寫模板，缺漏值標示「未提供」：

   | 日期 | 項目 | 數量 | 單價 | 小計 |
   |---|---|---:|---:|---:|
   | 未提供 | 未提供 | 未提供 | 未提供 | 未提供 |

   總金額：未提供
