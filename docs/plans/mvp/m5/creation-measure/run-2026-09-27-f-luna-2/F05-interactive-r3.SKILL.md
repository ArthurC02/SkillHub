# 開庭通知簡訊

依輸入資料撰寫正式、簡潔的繁體中文開庭通知。只使用輸入中提供的事實；不推測或添加法律資訊。每筆資料各處理一則通知，依序完成，不因資料缺漏而停止整批處理。

## 步驟

1. 將輸入中每筆通知資料分開處理。辨認案號、下一次開庭日期時間及其他資料；保留原有的案號與日期時間寫法，不自行改寫其含義。
2. 若案號或下一次開庭日期時間缺漏，不編造通知；簡短說明缺少哪些必要資料，並以明確問題請使用者補充。不要輸出看似完整的通知。
3. 若必要資料齊全，先撰寫通知本文：最多三句，以「。」「？」「！」作為句界。本文必須包含案號及下一次開庭日期時間。正式、易讀地精簡其他資料，能合併就合併；不可因此改變或增添事實。
4. 逐項比對輸入中的其他資訊與通知本文。只要有任何其他資訊被合併或省略，即使內容仍完整易讀，也必須在通知本文外另寫一句，明確列出所有合併或省略的資訊；此說明不計入本文三句上限。若其他資訊均未合併或省略，則不需加說明。
5. 對每則完整通知，把通知本文寫入暫存檔，從包含此 SKILL.md 的目錄執行平台提供的句數及必備內容檢查：`python scripts/check_output.py notice.txt --max-sentences 3 --require "$CASE" --require "$DATETIME"`。將 `$CASE`、`$DATETIME` 換成該筆輸入中的案號及下一次開庭日期時間原文；若未通過，修改本文並重查至輸出 `OK`。資料不足提示不作為完整通知檢查，不可為通過檢查而補造必要事實。
6. 將所有逐筆結果按輸入順序寫入最終答案檔，完整保留通知本文及其省略／合併說明，並讓各筆結果清楚分開。最終回覆只提供該檔案內容。
