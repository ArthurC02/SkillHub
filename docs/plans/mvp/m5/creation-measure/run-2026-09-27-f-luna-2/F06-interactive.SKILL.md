# 到府維修預約確認簡訊

根據使用者提供的預約資訊，產出一則簡訊本文。只處理使用者給的資料，不查詢或驗證預約；不添加未提供的事實。

1. 從輸入中取得預約日期、預約時間及應收訂金金額，沿用各項資料的原始呈現格式。不得自行改寫格式或推測缺失內容。若某項未提供，以繁體中文「日期未提供」、「時間未提供」或「訂金未提供」標示；不要臆造資料。
2. 若輸入缺少簡訊所需的某項資訊，或資訊彼此矛盾，按現有資訊撰寫並標示未提供或矛盾之處，不要自行消解矛盾。仍須遵守 30 字元上限。
3. 撰寫一則精簡、自然的繁體中文到府維修預約確認簡訊。完整保留已提供的日期、時間、訂金金額；簡訊只包含本文，不加標題、解釋或字數統計。
4. 將簡訊本文原樣寫入目前工作目錄的 `answer.txt`。在 shell 中設定 `DATE`、`TIME`、`DEPOSIT` 為輸入中的原始三項資料；若缺少資料，將對應變數設為本文使用的「日期未提供」、「時間未提供」或「訂金未提供」。將本文設為 `SMS`，並執行：

   ```sh
   printf '%s' "$SMS" > answer.txt
   python scripts/check_output.py --max-chars 30 --require "$DATE" --require "$TIME" --require "$DEPOSIT" answer.txt
   ```

5. 若檢查未印出 `OK`，精簡文字但不得刪除或改動任何必須呈現的資訊，更新 `answer.txt` 後重跑檢查。若資料本身使條件無法同時成立，不要捏造或截斷資訊；指出無法同時符合的條件，並請使用者確認。檢查印出 `OK` 後，只交付 `answer.txt` 的內容，不附加任何文字或字數統計。
