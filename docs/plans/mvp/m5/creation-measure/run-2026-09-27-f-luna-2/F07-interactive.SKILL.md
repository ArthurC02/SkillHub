# 缺席警告信與留意名單待辦

根據使用者提供的學生姓名、家長稱謂或姓名、缺席次數，判斷哪些學生達到 3 次門檻。為符合門檻者撰寫繁體中文、專業中性的家長警告信，並列出由獲授權人員執行的「留意名單」待辦。此 Skill 只處理使用者提供的資料；不登入、不修改教務系統，也不聲稱已完成標記。

## 步驟

1. 讀取使用者提供的學生資料。預期每筆包含學生姓名、家長稱謂或姓名、缺席次數；學期名稱可選。若學期名稱未提供，採用「本學期」，並在輸出中說明此預設。不得自行推測缺席原因、日期或校方政策。
2. 將每筆資料轉成一個 `姓名|家長稱謂或姓名|缺席次數` 記錄。若有學期名稱，加入 `--term`。以每筆資料各一個 `--record` 參數執行下列命令；引號內使用原始資料，不要省略或合併記錄：
   `python scripts/classify_absences.py --record '學生姓名|家長稱謂或姓名|缺席次數'`
   例如實際有多筆時，對同一命令重複加入 `--record '…'`；若有指定學期，使用 `--term '實際學期名稱'`。依照腳本結果區分達門檻與未達門檻的學生。若腳本因無法使用的輸入而退出，指出哪筆資料無法處理，不要猜測或代填缺席次數。
3. 對每位達門檻者撰寫一封繁體中文、專業且中性的信。以提供的家長稱謂或姓名稱呼對方，交代提供資料中的學生姓名、學期名稱（未提供時使用「本學期」）及實際缺席次數，說明這是一封缺席警告通知，並請家長留意孩子的出席情形。不要新增缺席原因、日期、後果或校方政策；缺少的稱謂或姓名以「未提供」標示，不要杜撰。
4. 在每位達門檻學生的信件後，分別列出一項「留意名單」待辦，明確寫明需由獲授權人員在教務系統執行；註明 Skill 未登入或修改系統，標記尚未完成。不得把待辦描述成已完成的操作。
5. 對未達門檻者，清楚列出未達門檻，且不替該生撰寫警告信或列出留意名單待辦。若所有資料均未達門檻，也要交代沒有學生觸發處理。交付依輸入資料產生的結果本身。
