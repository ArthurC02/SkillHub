# 整理訂書留言

將客人留言整理成繁體中文訂購清單。只使用留言提供的資訊，不查價、不猜書名、價格或其他商品資料。

## 步驟

1. 閱讀完整留言，逐項辨認訂購品項、書名、數量、單價，以及運費。把明確指向同一品項的資訊合併；不同品項分開列出。不要把運費計入書籍金額。
2. 依留言記錄每項資訊。未寫數量時按 1 本，並在輸出中註明這是採用的預設。未提供書名、單價或其他必要資訊時標示「未提供／待確認」。書名或訂購內容有歧義、矛盾或不可能時，不自行裁定：列為待確認，並在輸出中寫明需要客人確認的內容。不要以推測補值。
3. 只將書名、數量和單價均可確認的品項交給計算腳本。歧義或缺少必要資訊的品項不計入可確認金額。從本 Skill 所在目錄執行下列命令；對每個可確認品項重複附加 `--item`，並以留言中實際抽取的書名、數量及單價替換命令參數：

   `python scripts/calculate_order.py --item "書名" 數量 單價`

   若有多個品項，在同一命令中重複使用 `--item "書名" 數量 單價`。若運費明確且金額可確認，附加 `--shipping 運費金額`；每個待確認品項附加 `--pending "書名或原文品項" "待確認原因"`。運費未提及時不要傳入 `--shipping`；未提供或有歧義時在結果中另列待確認的運費，不要猜金額。保留留言中的實際金額數字。呈現腳本輸出的逐項小計、書籍總額、完整性及運費結果，不自行改寫或重算數字。
4. 輸出訂購清單，逐項列出書名、數量、單價、小計；缺失或歧義欄位清楚標示待確認。接著列出「書籍總金額（不含運費）」並註明是否完整；只要有任何品項因缺少資訊或歧義而未計入，就標示「總額尚未完整」。另列留言中提及的運費；若未提及，寫「留言未提及運費」。若留言有矛盾或不可能的內容，列明原文及待確認處，將確認要求寫在清單中，不以問題句作為整份輸出的結尾。

## 計算腳本

此腳本只加總已確認的品項；所有金額運算由腳本執行。
