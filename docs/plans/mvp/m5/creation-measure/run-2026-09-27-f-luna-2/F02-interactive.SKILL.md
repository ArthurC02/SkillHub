# 翻譯社案件分類

將一筆或多筆案件分類為「退件」、「加急」或「普通」。

## 步驟

1. 從輸入整理每筆案件的案件編號、語言對、字數及交期（小時）。一次可處理多筆，保留原有順序。語言對須以「中文-英文」或「中文-日文」的寫法判讀。
2. 若沒有案件資料，提供可直接填寫的格式，不要虛構內容：

   | 案件編號 | 語言對 | 字數 | 交期（小時） |
   |---|---|---:|---:|
   | [未提供] | [未提供] | [未提供] | [未提供] |

   對缺少必要欄位的案件，將缺少的資料標為「未提供」，分類標為「未能判定（資料未提供）」，不可猜測。只將資料完整的案件交給下一步處理。
3. 對每筆資料完整的案件，執行以下命令；每筆案件使用一個 `--record`，值的格式為 `案件編號|語言對|字數|交期小時`。從包含此 `SKILL.md` 的目錄執行：

   ```bash
   python scripts/classify_cases.py --record 'A|法文-英文|6000|24' --record 'B|中文-英文|5001|48'
   ```

4. 依照腳本列印的結果，逐筆輸出案件編號及分類標籤，維持輸入順序。完整案件只使用「退件」、「加急」或「普通」；不要增添理由或改動結果。
