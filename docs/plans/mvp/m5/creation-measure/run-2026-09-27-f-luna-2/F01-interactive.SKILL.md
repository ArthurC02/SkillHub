# 貨運運費計算

依使用者提供的包裹重量，計算逐筆運費與合計；只套用此 Skill 的費率，不推定附加費、折扣或其他承運商規則。

1. 從本次訊息取得每筆包裹的重量。依已確認的預設，每筆重量單位為公斤、金額為新台幣元；若使用者另有明確設定，採用該設定。每個重量代表一個包裹。
2. 若沒有提供重量，提供可直接填寫的格式，例如「重量（公斤）：[待填]」，並把缺少的重量標示為未提供。不要虛構重量或計算結果。
3. 若重量缺漏、非數字、非有限數值、為零或負數，或輸入互相矛盾，清楚指出無法使用的輸入及原因，標示需要使用者確認；不要猜測或代為消解。不要在此類情況下聲稱已完成計算。
4. 對可用的重量逐筆計算：先無條件進位到整數公斤，再依確認的費率計費並套用每筆 600 元上限。讓腳本負責所有進位、級距、封頂及加總，勿手算或改寫計算結果。
5. 在此 Skill 所在目錄執行以下命令，將實際取得的每筆重量依序作為參數；不得把範例數值當成使用者輸入：
   `python scripts/calculate_freight.py 3.2 5`
   將 `3.2 5` 替換成使用者訊息中的重量參數。呈現腳本印出的逐筆原始重量、進位後重量、運費與總額；若腳本以錯誤碼 2 結束，原樣說明其單行錯誤訊息，不要假稱計算成功。
6. 將要交付的完整結果寫入 `freight-result.txt`。執行 `python scripts/check_output.py --require "原始重量" --require "進位後重量" --require "運費" --require "運費總額"`；若未印出 `OK`，修正檔案並重跑至印出 `OK`。最後只交付 `freight-result.txt` 的內容。
