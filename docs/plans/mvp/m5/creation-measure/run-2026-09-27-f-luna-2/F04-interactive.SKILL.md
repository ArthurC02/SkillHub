# 民宿連續住宿費用計算

依使用者提供的入住日、退房日及可選的假日日期，計算連續住宿費用。只使用本 Skill 隨附的腳本及本機檔案，不查詢或推定國定假日。

## 步驟

1. 從使用者訊息讀取入住日與退房日；日期格式採 `YYYY-MM-DD`。如有使用者明確提供的其他假日日期，也一併讀取。
2. 缺少入住日、退房日或日期格式不完整時，不猜日期；交付以下可用輸入範本，將未知值標成「未提供」：

   ```text
   入住日期：未提供
   退房日期：未提供
   其他假日日期：未提供
   ```

   說明缺少的資料，讓使用者補上後再計算。若日期互相矛盾、無法解析，或退房日不晚於入住日，說明問題並請使用者確認；不要自行修正或計算。
3. 使用下列缺少設定時的預設規則，並在結果中明示：台灣當地日曆；平日每晚新台幣 2000 元；週五與週六夜晚每晚加收 500 元，按假日價 2500 元計；週日夜晚按平日價。使用者提供的其他假日日期也按假日價計，不另外查詢國定假日。
4. 在放置本 `SKILL.md` 的目錄執行腳本。每晚日期一晚一筆；入住日當晚計費，退房日不計費。將使用者提供的其他假日日期以重複的 `--holiday` 參數傳入；沒有其他假日日期時，不加該參數。命令格式如下，日期值取自使用者輸入：

   ```bash
   python scripts/calculate_stay.py --check-in YYYY-MM-DD --check-out YYYY-MM-DD [--holiday YYYY-MM-DD ...]
   ```

5. 若腳本因日期或期間無效而以代碼 2 結束，照實呈現其單行錯誤，不要編造金額；如屬輸入互相矛盾，請使用者確認。若成功，將腳本輸出的逐晚明細、平日／假日晚數及新台幣總額完整交付，不另外改算或省略。
