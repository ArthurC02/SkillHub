## 目的與限制

處理本學期缺席次數達到 3 次（含）以上的學生：核實出勤紀錄、撰寫家長警告信，並在已提供且獲授權的教務系統工作階段中，將學生標記為「留意名單」。本 Skill 不提供登入憑證，也不能自行取得或繞過存取權；若沒有系統存取權，明確告知使用者尚未完成標記，並整理需由授權人員執行的步驟。

## 執行流程

1. **確認學生與學期**
   - 取得學生的正式姓名、可供辨識的校內識別資訊，以及本學期的起訖範圍。
   - 若身分、學期或校方缺席計算規則不明，先向使用者或授權校務人員詢問，不要自行推定。
   - 只使用處理此任務所需的學生資料；不要在信件或非必要紀錄中加入敏感資訊。

2. **核對缺席次數**
   - 查閱本學期的正式出勤紀錄，依校方規則確認哪些紀錄計入「缺席」。請勿自行把遲到、請假或其他出勤狀態算作缺席。
   - 留意重複紀錄、已更正紀錄及日期範圍，必要時請授權人員確認。
   - 未達 3 次時，不撰寫本次警告信，也不新增「留意名單」標記；告知目前核對的次數與計算依據。
   - 達 3 次或以上時繼續下一步。記錄核對時間、學期、缺席次數與採用的校方計算規則，以便追溯。

3. **避免重複處理**
   - 檢查是否已就本學期同一門檻寄出或準備過警告信，以及學生是否已在「留意名單」。
   - 若已處理，勿重複新增標記或重複寄信；回報現有狀態。若紀錄不確定，先請授權人員確認。

4. **撰寫家長警告信**
   - 用校方核准的語言與格式撰寫。信中清楚說明學生本學期經核對的缺席次數、校方希望家長採取的後續行動，以及聯絡校方詢問或更正紀錄的方式。
   - 採用中性、尊重且不帶責備的語氣。不要推測缺席原因、引用未核實的政策或承諾未獲授權的後果。
   - 使用已確認的學生與家長稱謂、日期及聯絡資訊。資料不足時先詢問，不要輸出含待填欄位的信件。
   - 先提供信件草稿供使用者或校方依流程核准。除非使用者明確授權且校方流程允許，不要自行寄出或宣稱已寄出。

5. **更新教務系統名單**
   - 只有在具備使用者明確授權的有效系統工作階段時才操作。使用校方正式入口與既定流程；不要猜測介面位置、捏造操作結果或嘗試繞過登入、權限或驗證程序。
   - 依校方正式識別資料找到正確學生，重新核對姓名及識別資訊，確認沒有選錯人。
   - 將該生標記為「留意名單」，並依系統允許的欄位記錄本學期缺席次數、核對日期及處理依據。不要加入無關的個人資料。
   - 確認系統已保存變更後，才回報標記完成。若無權限、系統無法使用或無法確認保存結果，停止操作並明確回報未完成及需要授權人員處理的事項。

6. **回報處理結果**
   - 簡要回報核對的學期與缺席次數、警告信草稿是否完成、是否已依授權寄出，以及「留意名單」標記是否已確認保存。
   - 將尚待核准、寄送或系統更新的項目明確列出，不要把草稿描述成已寄送，也不要把待辦描述成已完成。
   - 依校方隱私與紀錄保存規範處理資料，不要在不受核准的渠道轉傳學生出勤資訊。
