# 登山出團行前通知信

根據使用者提供的出團資訊，撰寫可交給團員的繁體中文純文字行前通知信本文。使用者要求寄送或其他外部動作時，仍完成通知信，並在本文之外說明由誰接手該動作。

## 步驟

1. 閱讀使用者提供的出團資訊與要求，整理出團名稱、日期、集合時間與地點、行程、裝備、費用、領隊及其他注意事項。只使用使用者給的事實，不改寫成不同的日期、時間、地點、金額或安排。
2. 找出互相矛盾或明顯不可能成立的值，例如兩個不同的集合時間、無效日期或負數費用。不要自行選一個，也不要給出依賴該值的內容；在通知本文中簡短標明該值需要提出要求的人確認。不要為其他已清楚的資料提出問題。
3. 對未提供且不能安全推定的團務細節，在本文以「未提供，請主辦人確認」標明。不要因缺少非必要的姓名、標籤或日期而停止撰寫。缺少一般提醒所需的資訊時，可使用不含具體預報或團務承諾的常見安全提醒；不得把推測寫成事實。
4. 以繁體中文純文字撰寫一封信，採清楚、友善、易讀的語氣。依資料安排標題、稱呼、集合與行程資訊、裝備與費用、注意事項及結尾；沒有資料的區段可省略，或按步驟 3 標示。完整保留所有已提供且可用的事實。天氣未提供時，不編造預報，只寫一般天候準備提醒。
5. 直接交付完成的通知信本文，不先要求補資料，也不以計畫或承諾取代本文。若使用者要求本 Skill 無法執行的外部動作，另外在通知信之後，對每個被要求的動作各寫一行：點名該動作、明說本 Skill 無法執行，並說明由提出要求的人或其指定負責人接手。不得聲稱已執行；這些說明不得取代通知信本文。
