# 海鮮現場訂購算帳

依客人訊息整理魚貨訂單，計算商品金額；冰袋、保冷袋與運費不屬於魚貨商品總額。

## 步驟

1. 閱讀本次訂單訊息，按意思辨認魚貨品項、數量、計價單位、單價和單價所屬單位。不要只依字面格式判斷；口語或順序凌亂的描述也要整理。只有魚貨商品列入計算。
2. 將冰袋費、保冷袋費、運費及其他非魚貨費用排除。不要把它們加進魚貨小計。
3. 只依訊息明確提供的資訊和可由同品項上下文確定的資訊補齊欄位。例如，同一品項明確沿用先前的單價時，沿用該單價，並在答覆中指出這項推斷。不要自行查價或捏造訂購內容。
4. 不可確定的欄位標示為「未提供」；若同一欄位有互相衝突的值，列出各值並請提出訂單的人確認。仍計算其他資料完整的品項，但不要把不完整或有衝突的品項算入已知小計。列出已知小計時，明確說它不含待確認項目；若沒有可計算品項，提供可直接補填的品項欄位格式，不要把零說成訂單總額。不要為不影響計算的姓名、標籤或日期追問。
5. 對每筆資料完整、單位可換算的魚貨，轉成以下格式；數量和單價用十進位數字，單價單位寫在最後一欄：`品項|數量|數量單位|單價|單價單位`。每筆重複使用一次 `--item`。例如，按單位計價的項目應讓數量單位與單價單位一致；斤與兩可以互換，1 斤 = 16 兩。不要把袋費或運費傳給腳本。
6. 從放有本檔案的目錄執行腳本，將下列命令中的示例參數替換為第 5 步整理的資料；每筆魚貨各加一個 `--item`：
   `python scripts/calculate_total.py --item '品項|數量|數量單位|單價|單價單位'`
   腳本會印出每筆金額和已知魚貨小計。照原樣呈現所有計算結果；有欄位未提供或待確認時，將小計清楚標成已知小計，而不是完整總額。
7. 回覆以元標示結果，簡要列出明細、被排除的費用，以及實際採用的上下文推斷。不得聲稱已核實價格。若資料缺漏或衝突，清楚標示未提供的欄位或需要訂購人確認的值；在這些問題解決前，不把依賴它們的數額說成總額。
8. 對本次請求明確要求的任何寄送、付款、下單、聯絡或其他外部操作，只準備可供使用的內容，不可聲稱已執行。答覆最後為每項被要求的操作各用一行：寫明操作、明確說本 Skill 無法執行，並指出必須由提出請求的人（或請求中指定負責的人）執行。
