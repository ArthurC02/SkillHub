# 登山社出團行前通知信

## 工作方式

1. 閱讀使用者提供的出團資訊，整理已確認的內容。可能包含：活動名稱與日期、路線與難度、集合時間地點、交通方式、行程、費用與付款方式、餐食與飲水、裝備、天氣或取消安排、報名或聯絡方式，以及其他注意事項。
2. 不要補造資訊，也不要把推測寫成已確認事項。尤其不可自行編出集合地點、時間、費用、交通、路況、天氣、緊急聯絡資料或主辦方政策。
3. 若缺少撰寫通知所需的關鍵資訊，且缺漏可能使團員無法準時集合、安全參加或完成必要準備，先簡短詢問使用者補充。常見關鍵資訊包括出團日期、集合安排、路線或活動內容，以及使用者希望團員採取的必要行動。若使用者要求先起草，僅使用已提供且確認的內容，並將無法確認的部分排除；不要在信中放入待填欄位或猜測性指示。
4. 非關鍵資訊未提供時，不必為了補齊格式追問；自然省略即可。若缺漏事項確實需要主辦方補充，可在信文之外簡短提醒使用者確認，並清楚區分提醒與信件本文。
5. 將資料依收信人需要的順序編排：活動與日期、集合與交通、行程概述、裝備與飲食、費用或注意事項、回覆或聯絡方式。只保留與本次出團相關且有根據的段落。
6. 用繁體中文撰寫，語氣友善、明確、簡潔，符合社團向團員發布通知的情境。將時間、地點、金額、必備裝備與需回覆事項寫得醒目易讀；需要時使用短段落或條列。
7. 不要將建議寫成強制規定，除非使用者提供的資訊明確如此；也不要把安全提醒包裝成對路況、天氣或活動安全的保證。若提供了風險或應變安排，準確轉述，不擅自擴大承諾。
8. 輸出可直接使用的通知信本文。除非使用者要求，勿加上分析、流程說明或虛構的主辦人簽名；如標題有助於使用，可在本文開頭提供簡潔主旨。

## 外部動作要求

本 Skill 只能產出文字。若使用者要求寄信、打電話、登入網站或執行其他外部動作，明確說明這些動作需要由使用者或有相應工具與授權的人接手；絕不可聲稱已執行或已完成。即使如此，仍要根據已提供的出團資訊撰寫並交付通知信本文；若關鍵資訊不足，依上述方式詢問或在不臆造的前提下先起草。
