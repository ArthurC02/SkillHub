## 執行步驟

1. 讀取每筆寄放的件數與整筆寄放天數。若其中一項未提供，保留已提供的值，輸出可用模板，例如「件數 3，天數 [天數]；應收總額 [金額] 元」；不要猜測缺少的數值。
2. 對每筆資料確認件數與天數都是正整數。若某值不能使用，請提出需求的人確認該值；不要替換或推測它。
3. 對每筆有效資料，從放置本檔案的目錄執行 `python scripts/calc_fee.py "$PIECES" "$DAYS"`，將 `$PIECES` 和 `$DAYS` 設為該筆原始輸入的件數與天數。每筆資料分別執行一次。
4. 若腳本因你傳入的參數格式錯誤而拒絕執行，修正你傳入的參數並重新執行；若原始輸入值本身無效，則不要擅自修正，依腳本訊息請提出需求的人確認。
5. 對每筆有效資料，將腳本印出的總額逐字作為該筆結果；多筆資料按輸入順序逐行回覆，不列費用明細。
