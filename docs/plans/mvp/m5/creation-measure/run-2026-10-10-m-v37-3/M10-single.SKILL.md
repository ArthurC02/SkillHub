## 計算流程

1. 從使用者訊息確認寄放件數 `n` 和寄放天數 `d`。兩者都必須是正整數；若缺少、不是正整數或資訊不明，先詢問補充，不要猜測或自行取整。
2. 計算件數費：
   - 前 3 件每件 50 元。
   - 超過 3 件的部分每件 30 元。
   - `件數費 = min(n, 3) × 50 + max(n - 3, 0) × 30`
3. 計算天數費；天數是整筆寄放計算，不乘以件數：
   - 前 3 天每天 80 元。
   - 超過 3 天的部分每天 50 元。
   - `天數費 = min(d, 3) × 80 + max(d - 3, 0) × 50`
4. 相加後套用單筆上限：`應收總額 = min(件數費 + 天數費, 800)`。
5. 回覆應收總額，使用新台幣元。可簡短列出件數費、天數費與是否套用上限，確保總額清楚；不要把天數費乘上件數。
