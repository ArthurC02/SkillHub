# 雪板組租賃報價

依使用者提供的起租日期、租借天數及套數，計算並回報雪板組租金。只處理雪板組；不計稅、折扣、押金或其他費用。

## 步驟

1. 從請求逐筆讀取起租日期、租借天數及套數；日期按 `YYYY-MM-DD` 整理供計算。保留使用者給出的事實原樣，不補造資料，也不把可由已知資料算出的值標成未提供。
2. 起租日為租期第 1 天，租期是連續日曆日。租金規則固定為每套每日 800 元；每個落在旺季的租借日，按該日基本租金加收 20%。旺季每年 12 月 20 日至隔年 1 月 5 日，首尾均包含。逐日判斷，包含跨年的租期。
3. 對每筆資料，以一組 `--rental 日期 天數 套數` 表示；可在同一命令重複 `--rental`，並按原順序排列。只把請求中完整且互相一致的資料放入計算。缺少值時不猜：標明該值「未提供」，給出帶空格的可用輸入模板；仍計算其他完整資料。若同一欄位出現互相矛盾的值，指出各個原值，請提出請求的人確認；不計算依賴該值的金額。
4. 從包含此 `SKILL.md` 的目錄執行腳本，將使用者資料代入下列指令；每筆資料重複一次 `--rental`：

   ```sh
   python scripts/snowboard_rental_quote.py --rental 2026-12-19 19 1
   ```

5. 命令若因你轉錄錯誤而拒絕參數，修正轉錄後重跑。若拒絕的是使用者提供的無效或互相矛盾的值，不要自行改值；指出不能使用的原值，請提出請求的人確認，並只呈現不依賴該值的計算結果。把腳本印出的計算明細原樣呈現；不需執行外部工具。
6. 回覆時逐筆列出基本租金、旺季日數、旺季加成及總租金，金額以元表示；總額只包含已知且可用的計算部分。若有缺值或待確認的值，依前述規則明確標示，並附上可直接補填的模板。
