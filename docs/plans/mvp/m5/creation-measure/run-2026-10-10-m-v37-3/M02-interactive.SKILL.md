# 小劇場票券退票試算

依使用者提供的訂單資料試算退款額；只計算，不代替主辦方政策或實際辦理退票。

## 步驟

1. 從需求中逐筆讀取單張票價、張數、開演日期、退票申請日期，以及是否由主辦方取消。把每筆資料整理成 JSON 物件，欄位為 `price`、`quantity`、`show_date`、`request_date`、`cancelled`；日期用 `YYYY-MM-DD`，取消狀態用 `是` 或 `否`。保留使用者提供的值，不要猜測或改寫。
2. 對所有可計算的訂單，在含有此 `SKILL.md` 的目錄執行 `python scripts/refund.py --order '<第一筆 JSON>' --order '<第二筆 JSON>'`；只有一筆時只傳一個 `--order`。按需要為每筆資料重複 `--order`，並以 shell 引號包住 JSON。
3. 將腳本印出的每一行退款總額原樣呈現，逐筆對應到輸入資料。若腳本以代碼 2 拒絕某個值，指出它不能使用的值，請提出需求的人確認該值；不要提供依賴該值的退款額。若只是整理參數時出錯，修正參數後重新執行。
4. 若執行者的需求要求實際辦理退票或退款入帳：本 Agent 無法執行；須由提出需求的人或其指定的主辦方負責人辦理。
