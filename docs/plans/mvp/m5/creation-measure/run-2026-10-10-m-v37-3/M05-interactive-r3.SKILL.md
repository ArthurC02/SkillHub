# 企業健檢 LINE 行前通知

依下列步驟，將每筆行政健檢資料改寫為一則可供員工使用的 LINE 通知；只使用輸入中提供的事實。

1. 找出每筆資料的健檢日期、集合時間、空腹要求及其他通知資訊，將各筆資料分開處理，不混用內容。
2. 每則通知都保留健檢日期、集合時間及「空腹 8 小時」。若日期或集合時間未提供，該欄寫「待補」；不得推測或捏造，仍須完成草稿。空腹要求用清楚文字表達為「需空腹 8 小時」。
3. 非必要資訊逐項處理：若保留，將每項資訊各寫成獨立句，不要把不同資訊合併、並列或概括成同一句；若受四句上限影響而無法逐項保留，就省略部分或全部非必要資訊，並另用一句具體列出實際省略的資訊。若確實合併資訊，也另用一句明確說明合併了哪些內容。不得暗示省略的細節仍已提供。句數不足時，優先保留健檢日期、集合時間、空腹 8 小時要求，以及交代實際合併或省略內容所需的句子；以自然、精簡的繁體中文撰寫，不用條列。
4. 將每則通知分開存成暫存文字檔，逐則執行 `python scripts/check_output.py <檔案路徑> --max-sentences 4 --require <該則日期或待補> --require <該則集合時間或待補> --require '空腹 8 小時'`。若檢查不通過，修改通知並重跑；不可刪除必須保留的資訊。檢查通過後，將通知依輸入順序合併為最終答案檔，再逐則確認其仍符合相同條件。
5. 回答前，依請求中實際提到的外部動作，在答案末尾逐項加一行：寫明動作、本代理無法執行該動作，並指出由提出請求的人或請求指定的負責人執行。這是適用於任何該類動作的限制，不代表已完成該動作。
6. 最後將完整答案（各則通知及適用的動作說明）寫入答案檔，執行 `python scripts/check_output.py <答案檔路徑> --max-sentences 4 --require <各則通知必須保留的最短日期或待補字樣> --require '空腹 8 小時'`，確認檢查結果為 `OK`；若不通過，修改答案並重跑。回覆時只提供答案檔內容，不附加檔外說明。

`check_output.py` 由執行環境提供；不需加入 Skill 檔案。
