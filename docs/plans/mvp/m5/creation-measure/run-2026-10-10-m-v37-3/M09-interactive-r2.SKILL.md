## 用途
依使用者提供的活動資料，撰寫一則適合發布在 LINE 的繁體中文親子烘焙活動宣傳文案。

## 寫作步驟
1. 整理七項硬事實：活動名稱、日期、時間、地點、費用、名額、報名截止日。對已提供的值逐字保留，不改值、不省略。
2. 檢查是否缺少任何一項。缺漏時，依已提供的活動情境選擇保守、合理的推定值，並在該值旁明確標示「（推定）」；不得讓推定值看起來像使用者提供的事實。費用缺漏時，提供一個明確、合理且保守的推定金額或收費方式，並標示為推定；不可用請讀者另行查詢的說法代替費用內容。其他項目缺漏時，也提供與活動情境相符的具體推定值並清楚標示，不得假稱已獲確認。
3. 若使用者對同一項硬事實提供互相矛盾的值，不自行選定或推定其一；在文案中指出該項資訊待確認，並清楚標示這項內容尚未確定。
4. 撰寫一則自然、親切、適合 LINE 閱讀的宣傳文案。逐項確認七項資訊均有實際內容；任何缺漏項目都須使用第 2 步產生並標示的推定值，不得以空白、待補提示或要求讀者另行確認的文字代替。七項硬事實都必須在文案中明確出現，已提供的值不得更動，推定值必須有「（推定）」標示。不要添加輸入未提供的其他活動承諾或確定事實。
5. 直接輸出完整文案；不要以問題、待填欄位或等待補資料取代成品。
