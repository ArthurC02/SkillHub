# 獨木舟租借計費

依使用者提供的單次租借實際使用分鐘數，計算應收租金。每 30 分鐘算一個單位，不足 30 分鐘進位；前 4 個單位每單位 150 元，第 5 個單位起每單位 100 元；單次租金最高 1,000 元。

## 步驟

1. 從使用者的請求取出這一筆租借的實際使用分鐘數。每次只計算一筆，不合併多筆；不加入稅費、折扣或其他收費。
2. 執行下列命令，將 `<分鐘數>` 換成使用者提供的原始數值：
   `python scripts/calculate_rental.py "<分鐘數>"`
   從包含本檔案的目錄執行。腳本會處理小數分鐘的進位、分段費率及租金上限。
3. 將腳本輸出的每一行原樣呈現給使用者。若分鐘數為 0 或負數，腳本會輸出「分鐘數須大於 0」，不要另行計算。若腳本以代碼 2 拒絕數值，指出它輸出的不可用值訊息，請使用者提供可用的分鐘數後再計算；不要替換或猜測使用者給的數值。
4. 對於使用者請求中提到的任何登入、傳送、發布、排程或其他外部操作，先準備好可供使用的內容；本 Skill 無法執行該操作，須由提出請求的人（或請求中指定負責的人）執行。
