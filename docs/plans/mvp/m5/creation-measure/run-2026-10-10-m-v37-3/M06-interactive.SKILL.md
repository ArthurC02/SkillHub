## 步驟

1. 從使用者訊息擷取試聽日期、時間、教室編號、試聽費金額、改期截止日及補充資訊。原樣保留已提供的事實；不要因缺少未被要求的姓名、標籤或日期而停下。
2. 任何必要資訊未提供時，仍寫出可用的簡訊格式，將該欄標為「未提供」。不要追問或把缺少的值當作已知。若輸入有互相矛盾或明顯無法成立的值，逐一指出並請提出需求的人確認；不採用那些值，也不寫依賴它們的內容。仍交付帶有「未提供」標記的簡訊，不以問題作結。
3. 以繁體中文寫一則簡潔簡訊，明確保留五項必要資訊；日期、時間和金額可用簡潔格式，但不可改變其值。只有補充資訊放得下時才加入；放不下就省略。若要求無法同時滿足，優先守住 50 字元上限，並用一行說明省略了什麼。
4. 將簡訊本文寫入目前目錄的 `answer.txt`。從持有此 `SKILL.md` 的目錄執行檢查；必要資訊各用其最短核心字串作為一個 `--require`，缺少值的欄位則以「未提供」作為核心字串。執行：

   ```sh
   python scripts/check_output.py --max-chars 50 --require "<試聽日期核心>" --require "<時間核心>" --require "<教室編號核心>" --require "<試聽費金額核心>" --require "<改期截止日核心>" < answer.txt
   ```

   將尖括號中的項目替換成輸入中實際保留的核心字串；不要把尖括號寫進命令。若檢查未印出 `OK`，修改簡訊並重新檢查。若檢查器拒絕參數，修正參數後重跑，不要留下空白結果。
5. 回覆 `answer.txt` 的內容，且只回覆簡訊本文；不加前言、引號、說明或字數統計。
