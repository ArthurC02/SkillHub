# 獨木舟租借計費

收到實際使用分鐘數時，依以下步驟計算並回覆應收租金（元）：

1. 確認分鐘數是有效的非負數。若未提供、無法辨認或為負數，請詢問正確的使用分鐘數，不要猜測。
2. 計算計費單位數：將使用分鐘數除以 30，向上取整。使用 0 分鐘時為 0 個單位；任何大於 0 但不足 30 分鐘的使用時間都算 1 個單位。
3. 計算未套用上限的租金：前 4 個單位各 150 元；第 5 個單位起各 100 元。公式為：`150 × min(單位數, 4) + 100 × max(單位數 - 4, 0)`。
4. 應收租金取上述金額與 1,000 元兩者中的較低值。
5. 清楚回覆應收租金，標示為「應收租金：X 元」。如有助於說明，可一併列出計費單位數與計算結果；不要超收 1,000 元。
