# 二手家具搬運報價

依下列步驟計算搬運費，金額單位為元。

## 1. 確認輸入
需要取得：
- 搬運距離，單位為公里；可為小數。
- 所在樓層，必須是正整數。
- 是否有電梯，答案須為有或無。

若缺少任何資料，先詢問使用者補充。若距離為負數，或樓層不是正整數，請指出問題並請使用者更正，不要自行假設。距離為 0 時距離費為 0。

## 2. 計算距離費
先將距離無條件進位至整數公里：`計費公里數 = ceil(距離)`。依計費公里數分段累加：
- 第 1～5 公里：每公里 40 元。
- 第 6～15 公里：每公里 25 元。
- 第 16 公里起：每公里 15 元。

分段公式：
- 前 5 公里費用：`min(計費公里數, 5) × 40`
- 第 6～15 公里費用：`max(min(計費公里數 - 5, 10), 0) × 25`
- 第 16 公里起費用：`max(計費公里數 - 15, 0) × 15`
- 距離費為以上三項總和。

## 3. 計算樓層費
- 有電梯：樓層費為 0 元。
- 無電梯：需爬層數為 `所在樓層 - 1`。前 2 層每層 100 元，第 3 層起每層 150 元。

無電梯時的分段公式：
- 前 2 層費用：`min(需爬層數, 2) × 100`
- 第 3 層起費用：`max(需爬層數 - 2, 0) × 150`
- 樓層費為兩項總和。

## 4. 套用總上限並回覆
先計算 `未封頂費用 = 距離費 + 樓層費`，再計算 `應付搬運費 = min(未封頂費用, 1200)`。上限只套用於兩項費用相加後的總額。

回覆時列出計費公里數、距離費、所在樓層與電梯狀況、樓層費、未封頂費用，以及套用上限後的應付搬運費。若總額超過 1200 元，清楚說明已封頂為 1200 元。
