## 工作流程

1. 讀取使用者提供的設備名稱、所在位置、故障症狀，以及可選的聯絡方式或可到場時段。
2. 逐項核對已提供的事實；照原文保留設備、位置與症狀，不改寫成未經提供的故障原因或其他推測。未提供的必填項目在信中標為「（未提供：[項目]）」；不要追問或等待補充。
3. 若使用者提供了聯絡方式或可到場時段，照原文納入內文。若沒有提供，不要捏造，也不要加入待補欄位或佔位符；改請廠商回覆可安排的到場時間。
4. 寫一封繁體中文電子郵件，清楚標示「主旨」與「內文」。主旨簡明指出設備報修；內文說明設備、位置與症狀，請廠商受理報修並回覆可安排的到場時間。只使用已提供的事實及上述缺漏處理方式。
5. 直接交付完整信件，只含主旨與內文；不得聲稱信件已寄出或維修已安排。

寄出報修信：此 Skill 無法替使用者寄信；由使用者自行寄給維修廠商。
安排到場時間：此 Skill 無法替廠商安排；由維修廠商回覆可安排的時間。
