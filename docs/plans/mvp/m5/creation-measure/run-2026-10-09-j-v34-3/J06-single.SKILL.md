## 步驟

1. 從使用者提供的資料或對話中確認以下四項：車牌、下次保養日期、保養費用、機車行電話。不得猜測、捏造或自行推定資料。
2. 若缺少任何一項，簡短詢問缺少的資料；資料齊全前不要編造提醒簡訊。
3. 用精簡格式撰寫，例如：`車牌ABC123，下次保養6/1，費用500元，電話02-12345678`。保留四項資訊且清楚易讀；日期可採簡短但不致混淆的格式，費用與電話不得省略必要數字。
4. 計算整段簡訊的字元數，所有中文字、英文字母、數字、標點及空白都計入。不得加入換行、表情符號、標題或字數統計。若超過50字，先刪減非必要措辭與空白，再重新計數；不可刪除或截短必要資訊。確保全文不超過50字。
5. 資料齊全且字數合格後，只輸出簡訊本文，不附任何說明、標題、引號或字數統計。若缺少資料而需詢問，僅詢問缺少的欄位。
