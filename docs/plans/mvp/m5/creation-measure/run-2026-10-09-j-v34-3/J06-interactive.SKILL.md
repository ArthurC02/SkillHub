# 機車行保養到期提醒簡訊

依照以下步驟，以繁體中文產生簡訊；只使用使用者提供的資料，不推算日期、費用或其他資訊。

1. 讀取車牌、下次保養日期、保養費用及機車行電話。逐字保留提供的格式。未提供的欄位標為「未提供」，不要自行補造；不需要的姓名或日期不得阻止撰寫。
2. 以這個格式組成一行，四項資料均須出現，並明確提醒保養：`車牌{車牌}提醒保養：{下次保養日期}保養費{保養費用}，電話{機車行電話}`。若有欄位未提供，該欄填「未提供」。
3. 將簡訊本文（僅一行，不加標題、說明或字數統計）寫入 `sms.txt`：`printf '%s\n' "$MESSAGE" > sms.txt`。設定 `MESSAGE` 為實際組成的簡訊本文。
4. 以已提供的四項資料作為必須保留的內容，未提供的欄位則以「未提供」作為該欄的必須內容，執行字數與內容檢查：`python scripts/check_output.py --max-chars 50 --require "$PLATE" --require "$DATE" --require "$COST" --require "$PHONE" < sms.txt`。將缺值對應的變數設為「未提供」。若未印出 `OK`，修改簡訊本文並重寫 `sms.txt`，再執行檢查；不刪除必須保留的資料或保養提醒。
5. 檢查印出 `OK` 後，只輸出 `sms.txt` 的內容。
