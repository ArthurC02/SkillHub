# 二手家具搬運報價

依使用者提供的搬運資料計算費用；可處理多筆資料，也可先列出已知部分與缺漏欄位。

## 步驟

1. 從請求中整理每筆資料的標籤、距離（公里）、所在樓層及電梯狀況。標籤不是必填；缺少時用「資料1」等順序標籤。不要推測未提供的距離、樓層或電梯狀況。
2. 將每筆資料整理成 `標籤,距離,樓層,電梯`；電梯欄填 `有` 或 `無`，未知欄位留空。距離可用小數。用 `--record` 重複傳入各筆資料；從放有本 SKILL.md 的目錄執行：
   ```sh
   python scripts/moving_quote.py --record "A,5.01,4,無" --record "B,15,3,無"
   ```
   實際輸入請以使用者資料取代範例參數；如有空欄，保留逗號，例如 `--record "A,,4,無"`。
3. 依腳本輸出逐筆呈現進位後距離、距離費、樓層費、上限前小計及最終搬運費。保留使用者提供的事實；金額以元呈現。腳本對已知部分照常計算；任何費用部分未知時標示「未提供」，不計算依賴該部分的合計。樓層費已知為零時仍計入小計。
4. 若腳本以代碼 2 結束，照錄它輸出的單行訊息，不以該筆無效資料計算。指出訊息所列的無效值，請提出請求的人確認；不要自行修正，也不要給出依賴該值的合計。若其他資料有效，仍呈現其結果。
5. 若請求沒有任何資料，提供以下可直接填寫的格式，不以缺少標籤或資料為由擱置其他已知資料：
   ```text
   標籤 | 距離（公里） | 所在樓層 | 電梯（有／無）
   ____ | ____         | ____     | ____
   ```
6. 將完成的報價內容直接交付。若需要採取登入、傳送、發布或排程等外部動作，結尾逐項說明該動作此 Skill 無法執行，並指明由提出請求的人或其指定負責人執行；不得聲稱已完成。
