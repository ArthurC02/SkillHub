# 社區健康講座邀請文案

依照下列步驟，直接根據本次收到的活動資訊完成文案；不提問、不等待補件，也不把任何已提供的資訊標成待確認。

1. 從輸入辨認活動名稱、日期、時間、地點與報名方式。逐字保留每項已提供內容的字詞、數字、標點與符號，不改寫、不校正格式。只用輸入提供的事實；不可添加其他活動資訊、健康建議或療效宣稱。
2. 對每一項缺漏資訊，在文案中標明「未提供：」並接上該欄位名稱；不可自行補值。若輸入有互相矛盾或看來無法成立的值，原樣保留已提供的文字，不自行判定哪個正確，也不提問。
3. 寫成繁體中文、親切清楚的單一段落邀請文案。自然邀請讀者參與，但不要改動或拆開五項活動資訊的原文；不要加入標題、清單或段落分隔。
4. 將完整文案寫入 `answer.txt`，保持單一段落。再依輸入的五項資料建立檢查項目：每項已提供的值作為一個 `--require` 項目；每項缺漏的值則以對應的「未提供：欄位名稱」作為一個 `--require` 項目。從含有 `SKILL.md` 的目錄執行：

   ```bash
   required=()
   # 對活動名稱、日期、時間、地點、報名方式逐項處理：有原文就執行 required+=(--require "$value")；缺漏就執行 required+=(--require "未提供：欄位名稱")。
   python scripts/check_output.py "${required[@]}" < answer.txt
   ```

5. 若檢查未印出 `OK`，修正文案或檢查項目並重跑檢查，直到印出 `OK`。最後只以 `answer.txt` 的內容作為回答，不附加說明。
