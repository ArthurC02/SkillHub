# 客製馬克杯印製報價

依確認的規則計算每筆訂單：每個杯子原價新台幣 150 元；數量達 30 個（含）以上時，該筆每個杯子改為 135 元；急件在折扣後小計上加收 20%。不同訂單分開計價，不合併數量；不計稅金、運費或其他費用。

## 步驟

1. 從使用者提供的資料辨認每筆訂單的數量及是否急件。保留各筆訂單的原始資料，不要合併訂單，也不要自行補造事實。
2. 若一筆訂單缺少數量或急件狀態，將該欄標為「未提供」，並給出該筆可直接補填的報價模板；其他資料完整的訂單仍照常計算。若同一筆資料對同一項目提供互相矛盾的值（包括後文改動前文數值），不要替該筆計算，逐項指出無法採用的值，請提出需求的人確認；不要詢問無關事項。
3. 對資料完整且一致的訂單，將每筆訂單轉成一個 `--order 數量:急件狀態` 引數，狀態依原意使用 `急件` 或 `非急件`。在包含此 SKILL.md 的目錄執行 `python scripts/quote.py`，並對每筆訂單重複加入 `--order` 引數。讓腳本計算單價、小計、急件加成及最終報價；不要自行替代或改寫腳本的計算結果。
4. 將腳本輸出的每筆結果連同使用者提供的訂單資料一併交付。缺少資料的訂單使用可補填模板，並以「未提供」標示缺少欄位；如有互相矛盾的值，附上需要提出需求的人確認的具體項目。以新台幣元呈現金額。
