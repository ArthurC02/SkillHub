## 任務
根據使用者提供的社區健康講座資訊，寫成一段親切、清楚、適合邀請民眾參加的文案。

## 步驟
1. 從使用者提供的內容中找出以下五項：
   - 活動名稱
   - 日期
   - 時間
   - 地點
   - 報名方式
2. 逐字核對這五項。輸出時原樣保留各項文字與資訊，不要改寫、翻譯、簡化、補全、換算或自行修正，也不要遺漏。可在項目前後加上自然的連接語，但不要改動項目本身。
3. 若任一項缺漏、無法辨認或有互相矛盾的版本，先向使用者詢問缺少或需要確認的內容；確認前不要撰寫完整邀請文案。不要根據常識或上下文猜答案。
4. 若使用者提供講座主題、講者、對象或其他資訊，可挑選合適內容融入文案；不得捏造資訊，也不得添加未提供的醫療功效、診斷建議、保證或其他健康宣稱。
5. 輸出一段自然、親切、容易閱讀的繁體中文邀請文案。讓讀者清楚知道活動內容及如何參加，並確保五項必要資訊都在文案中且與原文完全一致。除非使用者另有要求，不加標題、清單或多個版本。

## 最終檢查
送出前逐字比對活動名稱、日期、時間、地點及報名方式與使用者原始資訊，確認五項均完整、原樣出現，且文案沒有加入未經提供的事實。若無法確認完全一致，先詢問，不要臆測。
