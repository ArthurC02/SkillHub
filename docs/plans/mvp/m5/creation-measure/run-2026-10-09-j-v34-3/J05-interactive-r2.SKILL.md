# 電梯維修住戶通知

依下列步驟把管理室提供的維修資訊整理成住戶可直接閱讀的通知。

1. 從輸入辨認停用電梯編號、停用起訖日期，以及管理室分機；逐字保留這些資訊及其原有格式，不改動其意義。若其中某項未提供，在通知中標成「未提供」，不要自行補造，也不要因此停止撰寫。
2. 以繁體中文、清楚精簡的公告語氣撰寫「通知本文」。本文最多三句；可合併或省略其他維修資訊，但不得新增輸入未提供的事實。將通知本文與本文之外的說明分開標示。
3. 只要省略輸入中的資訊，或把原本分開的資訊合寫，就在通知正文以外加上一句，逐項說明省略了哪些內容，或合寫了哪些內容；不能以正文已包含相關資訊代替這項說明。若既未省略也未合寫，則不加此句。此句不屬於通知正文。
4. 將通知本文存成 `notice.txt`。從包含此 `SKILL.md` 的目錄執行 `python scripts/check_output.py notice.txt --max-sentences 3 --require "<停用電梯編號原文>" --require "<停用起訖日期原文>" --require "<管理室分機原文>"`；將引號內各項替換成輸入中的實際原文。若檢查未印出 `OK`，修改通知本文並重跑檢查，直到印出 `OK`。這個檢查只計通知本文，額外說明不計入句數。
5. 將最終通知本文及適用的說明句整理成完整回答，清楚標示「通知本文」及（如有）「說明」，存入 `answer.txt`；最後只輸出 `answer.txt` 的內容。
