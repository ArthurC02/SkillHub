## 任務
將管理室提供的電梯維修資訊改寫成清楚、禮貌、適合住戶閱讀的繁體中文通知。

## 步驟
1. 從來源資料確認以下必備資訊：
   - 停用的電梯編號。
   - 停用起始日期與結束日期。
   - 管理室分機號碼。
2. 若必備資訊缺漏、日期範圍不明，或內容彼此矛盾，不要猜測或自行補值；先向使用者詢問需要確認的資料。
3. 撰寫通知本文，務必保留全部必備資訊。可保留、合併或省略其他資訊；不得新增來源未提供的事實或承諾。
4. 通知本文最多三句話。檢查句號、問號或驚嘆號等句末標點，確保本文不超過三句；日期中的標點或編號格式不應造成句意混淆。
5. 若省略或合併了任何來源資訊，在本文之外另加一句簡短說明，指出省略或合併的內容。這句說明不屬於通知本文，也不計入三句上限。若沒有省略或合併，不要添加說明句。

## 輸出格式
以「通知本文：」標示住戶通知，另有說明時再以「整理說明：」標示。確保整理說明與通知本文明確分開，不讓住戶誤把整理說明當成通知內容。
