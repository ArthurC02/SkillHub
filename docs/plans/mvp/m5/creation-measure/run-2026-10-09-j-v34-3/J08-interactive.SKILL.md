# 倉庫進貨驗收紀錄核對

核對使用者貼上的驗收紀錄，合併符合規則的重複紀錄，計算可確定的小計與合計，並列出需由使用者確認的矛盾。只依照提供的資料處理；不查外部庫存或價格。

## 步驟

1. 取得使用者貼上的資料。資料若未提供，直接交付以下空白範本，不要等待補件：

   ```text
   請提供驗收紀錄：
   品項,數量,單價,驗收日期
   [品項],[數量],[單價],[驗收日期]
   ```

2. 將原始紀錄整理成 UTF-8 CSV 檔 `records.csv`，欄名使用 `品項,數量,單價,驗收日期`。保留原始數值與日期，不補造缺漏資料。從存放本 SKILL.md 的目錄執行：

   ```sh
   cat > records.csv <<'EOF'
   品項,數量,單價,驗收日期
   [逐筆照抄使用者提供的紀錄]
   EOF
   python scripts/reconcile.py --input records.csv
   ```

   將方括號中的提示替換成使用者實際提供的資料；不要把提示文字當作紀錄執行。若使用者資料中有逗號、引號或換行等 CSV 特殊字元，按 CSV 規則引用欄位。

3. 依腳本輸出整理並直接交付核對結果。相同品項的數量與單價均一致時，視為重複紀錄，合併列示且只計算一次，不累加數量。數量或單價有不同值時，列出矛盾並請使用者確認；不得自行選值，也不得計算該品項小計。負數數量同樣列為矛盾且不計算小計。不得計入任何依賴未解決數量或單價的總額。

4. 日期按公曆 `YYYY-MM-DD` 檢查。不存在或格式不符的日期須列出並請使用者確認，但日期不影響金額：只要品項的數量與單價明確且數量非負，仍計算小計。若金額資料均明確，即使日期待確認也照常列出驗收總額；若任何數量或單價矛盾、缺漏或不可用，完整驗收總額標示為「待確認」，並另外列出所有可確定品項的金額小計。

5. 每項缺少的欄位標示為「未提供」；不可猜測或把可由資料推算的值標成未提供。對每個矛盾，指出品項、實際衝突值或有問題的日期，以及需使用者確認的事項。腳本以狀態 2 結束時，照錄其單行錯誤訊息，指出其中不可用的值並請使用者確認；不要使用該值計算。回答須包含結果或可用範本，並以陳述式結尾，不要以問題作結。
