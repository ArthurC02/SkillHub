# 社區團購訂單加總

依使用者貼上的群組訊息擷取訂單，合併同品項訂購數量，計算商品小計與總額；宅配及其他配送費不計入商品總額。

## 步驟

1. 閱讀使用者提供的完整訊息，擷取每個成員提到的品項、數量、計量單位及單價。只使用訊息提供的事實，不推測未提及的品項、價格或數量。
2. 合併不同成員對同一品項的數量。只有能確認是同一品項、同一計量單位且單價一致的訂購才合併。清楚表示要買、但未寫數量的品項按 1 件處理；保留訊息中使用的數量單位。
3. 將未明確的品項、數量或單價列為「待確認」，如實指出缺少或互相矛盾的值，不猜數字，也不把該筆不確定金額納入總額。若單價缺少，不為它計算小計。只有在訊息有明確說明時才列出待確認的理由。
4. 將可確定的每項訂購整理成 `品項|合併數量|單位|單價` 格式，將待確認項目整理成 `品項|待確認原因` 格式。每筆各存成一個 shell 變數 `record` 後，分別加入以下陣列：

   ```bash
   items=()
   pending=()
   items+=(--item "$record")
   pending+=(--pending "$record")
   ```

   沒有待確認項目時，`pending` 保持空陣列。運費及配送費不要放進 `items`。
5. 從放有此 `SKILL.md` 的目錄執行以下命令，將擷取的訂購資料作為參數傳入腳本：

   ```bash
   python scripts/sum_orders.py "${items[@]}" "${pending[@]}"
   ```

   腳本會合併可計算的項目、列出小計並加總商品總額。呈現腳本輸出的數量、小計及總額，不另行改算。若腳本以錯誤結束，指出它所列明的無效或矛盾值，請提出要求的人確認；不要提供依賴該值的總額。仍須在同一答覆提供目前能確定的結果，並將受影響數值標示為待確認。
6. 用繁體中文交付訂單表格及商品總額，並列出待確認項目。運費與配送費不計入商品總額。金額未標幣別時，使用新台幣作為常見預設，並在相關金額旁說明「未標幣別，暫按新台幣；可更改」；有標幣別時照原訊息呈現，不轉換。輸入未提供的欄位標示「未提供」。
