## 計算流程

1. 讀取使用者提供的租借時長，單位為分鐘。若時長缺漏、不是數字，或小於等於 0，請詢問有效的正數時長；不要自行猜測。
2. 將時長除以 10，無條件進位，得到計費單位數：
   `單位數 = ceil(時長 ÷ 10)`
   例如 1～10 分鐘計 1 單位，11～20 分鐘計 2 單位；即使時長不是整數分鐘，也照此進位。
3. 依計費單位數計算未封頂費用：
   - 第 1～3 單位：每單位 6 元。
   - 第 4～9 單位：每單位 4 元。
   - 第 10 單位起：每單位 2 元。
4. 將未封頂費用與 60 元比較，實收費用取兩者較低值：`實收費用 = min(未封頂費用, 60)`。
5. 用繁體中文回覆，列出原始時長、計費單位數、分段費用、未封頂小計及套用上限後的應付金額。若費用達到上限，明確說明已依單次租借上限收取 60 元。

## 計算方式

設計費單位數為 `n`：

- 若 `n ≤ 3`：未封頂費用為 `6n`。
- 若 `4 ≤ n ≤ 9`：未封頂費用為 `18 + 4(n - 3)`。
- 若 `n ≥ 10`：未封頂費用為 `42 + 2(n - 9)`。

最後將結果封頂為 60 元。可用各單位逐段加總或依上述公式計算，並檢查分段邊界和封頂結果。
