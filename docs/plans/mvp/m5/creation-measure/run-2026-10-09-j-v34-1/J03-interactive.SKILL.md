# 社區團購訂單加總

整理使用者貼上的群組訂購訊息，列出可確認的商品訂單與商品總額；宅配運費及其他非商品費用不計入。

## 步驟

1. 閱讀所有訊息，只抽取明確可辨識的商品訂購。記錄品名、數量、計量單位和單價；價格按訊息明示的每個計量單位解讀，不做幣別換算。
2. 排除宅配運費及其他非商品費用。不要把它們列為商品或加進商品總額。
3. 對品名、計量單位和單價都相同的可確認訂單合併數量；品名、單位或單價不同的項目分開列。保留訊息提供的名稱、數值和單位，不自行改寫成未提供的事實。
4. 將無法確定品名、數量或單價的訂購內容列在「待確認」區，說明缺少或不確定的資訊；不猜測、不納入已確認數量，也不納入商品總額。若同一筆訂單的數值互相矛盾，列出各個原始值，標示「待確認」，並請提出需求的人確認；不計算依賴該值的金額。
5. 將可確認項目整理成以下欄位：品名、合併數量、單價、小計。數量以各筆明確數量相加；小計為合併數量乘以單價。若輸入沒有提供任何訂購訊息，仍回傳此表格模板，未提供的欄位標示「未提供」：

   | 品名 | 合併數量 | 單價 | 小計 |
   |---|---:|---:|---:|
   | 未提供 | 未提供 | 未提供 | 未提供 |

6. 從工作目錄（此 `SKILL.md` 所在目錄）執行計算腳本。每一筆可確認訂購各給一個 `--item` 參數，格式為 `品名|數量|單位|單價`；有多筆時重複使用 `--item`。只傳入可確認的商品，不傳入待確認內容或非商品費用。例如：

   ```bash
   python scripts/calculate_total.py --item '品名|數量|單位|單價'
   ```

   以腳本輸出的合併項目、小計和總額為準，將其呈現在答案中。若腳本指出某個值無法使用，照實標示該值並請提出需求的人確認；不提供依賴它的總額。
7. 在表格後列出「商品總額」，只加總可確認商品的小計；即使沒有可確認商品，也列出腳本算出的總額。另設「待確認」區，列出每筆未確認訊息和所缺或矛盾的資訊。不要把運費或其他非商品費用算入商品總額。
