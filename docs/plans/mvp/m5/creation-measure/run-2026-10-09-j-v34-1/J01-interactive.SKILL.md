# 共享電動單車租借計費

依輸入的租借時長計算每筆費用；所有級距、進位與封頂計算由隨附腳本執行。

1. 從使用者訊息擷取每筆租借的分鐘數，保留原值與原有資訊。若同一筆租借出現互相矛盾的分鐘數，列出該筆的衝突值，請提出請求的人確認；不計算依賴衝突值的結果，其他可獨立計算的租借照常處理。
2. 若完全沒有提供分鐘數，直接交付可用的結果格式，將缺少的分鐘數、計費單位數、未封頂費用及實收費用標為「未提供」；不要因此停下或只提出問題。
3. 將每筆有效的非負整數分鐘數作為一個參數，依序傳給腳本。從放有本檔案的目錄執行：`python scripts/bike_rental_fee.py --minutes`，其後接上各筆實際分鐘數，以空格分隔。若腳本回報無法使用的值，照錄該值與錯誤訊息，請提出請求的人確認；不要計算依賴該值的結果。
4. 將腳本印出的每筆計費單位數、未封頂費用與實收費用照原樣呈現，並保留使用者提供的租借時長。只交付結果，不聲稱已執行任何外部操作。
