# 大樓電梯維修通知

將管理室提供的維修資料改寫成住戶可閱讀的繁體中文通知；每筆資料各產生一則通知。

## 步驟

1. 找出每筆資料中的停用電梯編號、停用起始日期、停用結束日期及管理室分機。將原資料中的這些內容照原樣保留，不推測或補充事實。若資料只提供停用日期，並明確寫明當日恢復，將該日期同時作為起始日與結束日，並在通知中明確寫出兩端日期；不得只用「當日恢復」等說法代替結束日期。
2. 將同一筆資料的其他資訊整理成簡潔、清楚的通知本文。把維修原因與其直接造成的影響合併為同一項簡潔表述。一般性的替代措施建議若非安全或理解通知所必需，從本文省略。只要有整併或刪除內容，說明句須逐項交代資訊類別及所採處理方式，讓讀者能分辨哪些內容被合寫、哪些內容未納入；不要只籠統說已整理。不得省略或改寫必要欄位，也不要把一筆資料的資訊帶入另一筆通知。
3. 為每筆資料檢查必要欄位。若欄位缺漏，用「【未提供：欄位名稱】」標明；若日期不存在或同一欄位有互相矛盾的值，用「【待提出者確認：欄位名稱與原值】」標明，並請提出者確認。不要替缺漏或矛盾的值作推斷，也不要因缺少未要求的名稱或標籤而停止處理。照樣交付通知，不以提問取代成品。
4. 將每則通知的本文控制在最多 3 句。若有省略或合併資訊，在該則通知本文之外另列一句說明；此說明不算入本文句數。沒有省略或合併時，不加說明句。
5. 將完整答案寫入 `answer.txt`。逐則將每一則通知本文寫入暫存檢查檔，從本 Skill 的目錄執行 `python scripts/check_output.py --max-sentences 3` 檢查該檔；若未印出 `OK`，修整本文後重查。再將整理好的完整答案存入 `answer.txt`，執行 `python scripts/check_output.py --max-sentences 3` 檢查其中每一則本文（檢查時逐則使用本文檔案）。只有所有本文檢查均印出 `OK` 後，才以 `answer.txt` 的內容作為回答，不加檔案以外的文字。
