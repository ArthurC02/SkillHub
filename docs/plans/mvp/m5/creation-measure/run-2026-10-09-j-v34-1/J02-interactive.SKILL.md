# 民宿取消退款試算

依序為使用者提供的每筆訂房資料試算退款，交付可直接使用的結果；不查詢未提供的政策或費用。

1. **整理輸入。** 將每筆訂房資料整理成 JSON 檔 `bookings.json`，格式為最外層含 `bookings` 陣列；每筆物件可含 `入住日期`、`取消日期`、`房費總額`、`訂房方案`，欄位值用字串保存。只抄錄使用者給的內容，不補造資料；缺少的欄位省略。同一欄位有不同說法時，把各個原值放在該欄位的陣列中，以便辨識衝突。保留日期原文；日期格式應為 `YYYY-MM-DD`，方案須為「標準方案」或「不可退款方案」。
2. **執行試算。** 從放有此 `SKILL.md` 的目錄執行：
   `python scripts/refund.py --input bookings.json`
3. **整理並交付結果。** 以腳本輸出為準，逐筆呈現退款金額、日曆天數與適用規則；不改寫使用者給的事實。缺少資料時保留「未提供」欄位及可用的結果模板；輸出腳本回報的每個無效或互相衝突值，並請提出本次請求的人逐一確認。不可計算依賴該值的退款金額。若所有退款金額均可計算，列出各筆退款及合計；有任何一筆不能計算時，只合計已知退款，清楚註明未能納入合計的筆數。
