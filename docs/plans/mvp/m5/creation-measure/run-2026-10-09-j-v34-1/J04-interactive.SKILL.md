# 客製馬克杯印製報價

依使用者提供的訂單杯數及急件狀態，計算報價。以新台幣元列出適用單價、商品小計、急件加成和最後總價；不自行加入稅金、運費、折扣或其他費用。

## 步驟

1. 從輸入整理每筆訂單的杯數與急件狀態。杯數須為正整數，急件狀態須明確為「是」或「否」。不需要為未被要求的姓名、標籤或日期追問。
2. 若杯數或急件狀態缺漏，照原樣提供已知資料，將缺漏欄位標為「未提供」，並給出可直接使用的報價列模板；不替缺漏資訊編造數值。仍可計算其他資料完整的訂單。
3. 將資料完整的每筆訂單轉成 `杯數:急件狀態`，每筆使用一個 `--order` 參數。從本 SKILL.md 所在目錄執行：
   ```sh
   python scripts/quote.py --order '<杯數>:<是或否>' [--order '<杯數>:<是或否>' ...]
   ```
   例如，狀態只接受 `是` 或 `否`；將命令中的格式說明替換成使用者實際提供的值。不要自行補入使用者未提供的杯數或急件狀態。
4. 腳本依杯數選用單價：未滿 30 個為每個 150 元；30 個以上（含 30 個）為每個 135 元。商品小計為杯數乘以適用單價。急件加成按商品小計的 20% 計算，非急件加成為 0 元。最後總價為商品小計加急件加成。腳本以新台幣整數元呈現；因規格未指定零頭處理，採四捨五入至整數元，並在結果旁註明這項假設可由使用者更改。20% 是本 Skill 採用的已確認急件加成假設。
5. 將腳本印出的每筆結果完整呈現，不省略適用單價、商品小計、急件加成或最後總價。若腳本因某個值無法計算而拒絕執行，指出每個不能使用的值，請提出請求的人確認該值；不要提供依賴該值的總價，也不要追問其他未影響計算的事項。
