# 社區健康講座邀請文案

將使用者提供的活動資訊整理成一段親切、清楚、可直接使用的繁體中文邀請文案。一次處理當下收到的內容；不要追問、查網路或聲稱資訊已查證。

## 步驟

1. 從輸入辨認活動名稱、日期、時間、地點、報名方式，以及可用的講座介紹或邀請語氣線索。尊重輸入中對同一項目的更正；若同一項目仍有互相矛盾的值，不自行選擇或合併，將該項標成「資料有衝突，請確認」，並在文案中留出標記空格。
2. 對五項指定資料逐項處理：已提供且沒有衝突的值，連同原文字詞、數字、標點及括號逐字保留，不改寫、不校正、不換算。未提供的值須採用普通、可更改且不冒充已知事實的暫定假設，並在該值旁標明「暫定，可更改」。若未提供報名方式，採用暫定的現場報名方式，寫明「請於活動當日到場報名」，並標示這是待確認的假設；不得添加未提供的聯絡方式或其他具體活動事實。其他缺項只在有合理預設值時補足；無法合理預設時，標明「未提供」並保留可供補填的空格。
3. 以繁體中文寫成一段邀請文字，包含五項指定資料各一次或以上。語氣親切、清楚；只使用輸入提供的其他活動資訊，不添加未提供的主辦單位、費用、聯絡方式或醫療效果承諾。若有暫定假設，緊鄰該值說明「暫定，可更改」；對未提供項目或衝突值，明確標示其狀態，不把它說成已知事實。結尾採邀請語，不提出問題。
4. 將完整文案寫入工作目錄的 `invitation.txt`。從本 SKILL.md 所在目錄執行 `python scripts/check_output.py --require '活動名稱的完整原文' --require '日期的完整原文或未提供標記' --require '時間的完整原文或未提供標記' --require '地點的完整原文或未提供標記' --require '報名方式的完整原文或未提供標記'`。把引號中的示例文字換成這次輸入中相應的完整原文，或換成文案實際使用的未提供／衝突標記；保留 shell 引號並為每項指定資料各提供一個 `--require`。若未印出 `OK`，修正文案並重跑，直到印出 `OK`。最後只回答 `invitation.txt` 的完整內容。
