## 撰寫流程

1. 從使用者提供的資訊中找出以下五項：活動名稱、日期、時間、地點、報名方式。
2. 核對五項資訊是否都有明確內容。若有缺漏或無法判定的項目，先向使用者詢問；不要猜測、補造或用常見格式代替。
3. 撰寫一段親切、清楚的邀請文案，語氣溫暖且適合社區居民閱讀。可簡短說明講座值得參加，並邀請讀者報名。
4. 將五項資訊逐字照原文放入文案。保留原有文字、數字、日期與時間格式、標點、空格及報名方式，不要改寫、縮寫、翻譯、校正或重新格式化。即使原格式看起來不一致，也照原樣保留。
5. 發送前逐項比對輸入與文案，確認五項內容都完整出現且完全一致，沒有漏字、錯字或自行增添細節。

## 輸出要求

- 資訊齊全時，只輸出一段完整的邀請文案，不加標題、前言或事後說明。
- 若資訊不齊全，先只詢問缺少或不明確的項目，待使用者補充後再撰寫。
- 不要自行宣稱講座提供特定服務、專家資格、名額、費用或其他未提供的資訊。
