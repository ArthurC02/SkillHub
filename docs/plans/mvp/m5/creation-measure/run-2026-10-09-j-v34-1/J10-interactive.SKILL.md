# 二手家具搬運報價

依下列步驟處理每筆搬運資料；不查外部資料，也不把尚未提供的資料當成已知。

1. 從使用者訊息辨認每筆資料的距離（公里）、所在樓層及電梯狀態，保留使用者給的值與寫法。樓層須為正整數；電梯狀態須明確為「有電梯」或「無電梯」。
2. 若同一筆資料對同一項目出現互相矛盾的值（包括後來改動先前數值），列出各個值，請提出需求的人逐項確認；不要計算依賴該項目的結果。若值明確不合理，例如負距離、非正整數樓層或無法辨認的電梯狀態，也列出原值，請提出需求的人確認。只指出有問題的值，不要替換成猜測值。
3. 對未提供的必要資料，標示「未提供」，並在該筆輸出提供可直接補填的欄位：距離（公里）：____；所在樓層：____；電梯狀態（有電梯／無電梯）：____。不因缺少標籤、名稱或其他非必要資訊而停止計算。
4. 將資料完整且有效的各筆搬運轉成腳本參數。從放有此 SKILL.md 的目錄執行下列命令；每筆資料重複一次 `--case`，其後依序放該筆的距離、樓層、電梯狀態，值照原樣提供：
   `python scripts/used-furniture-moving-quote.py --case 距離公里 樓層 電梯狀態`
   若輸入有多筆，將多組 `--case 距離公里 樓層 電梯狀態` 接在同一命令中。不要把缺漏或有疑義的筆數傳給腳本。若命令意外回傳錯誤，保留錯誤訊息，指出其中無法使用的值，請提出需求的人確認；不要為該值計算費用。
5. 將腳本印出的結果原樣呈現，讓每筆結果清楚對應原輸入。結果包含無條件進位後距離、距離費、樓層費、未封頂合計及套用上限後的搬運費；對缺漏或待確認的筆數只呈現已知資料與補填欄位，不呈現依賴缺漏或疑義值的總額。
6. 將完整回答寫入 `answer.txt`，執行 `python scripts/check_output.py --require "進位後距離" --require "距離費" --require "樓層費" --require "搬運費"`；依檢查結果修正檔案並重跑，直到輸出 `OK`。最後只交付 `answer.txt` 的內容。
