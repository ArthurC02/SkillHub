## 產生保養到期提醒簡訊

1. 確認已有以下資料：車牌、下次保養日期、保養費用、機車行電話。不得猜測、捏造或自行補上缺漏資料；若缺少任何一項，先向使用者索取缺漏資料，不要輸出不完整簡訊。
2. 用繁體中文組成一句精簡、清楚的提醒，並明確標示四項資訊，例如使用「車牌」「保養日」「費用」「電話」等短標籤。保留使用者提供的資料內容；日期與金額可採精簡格式，但不可造成誤解。
3. 計算簡訊全文字數，包含所有中文字、英文字母、數字、標點及空白；每個字元各計 1 字。若超過 50 字，刪減非必要措辭或空白後重新計算，直到不超過 50 字。不可刪除四項必要資訊。
4. 最終回覆只輸出簡訊本文，不加標題、引號、字數統計或任何說明。
