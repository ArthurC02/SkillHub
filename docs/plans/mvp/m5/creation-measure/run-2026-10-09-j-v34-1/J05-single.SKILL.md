## 工作流程

1. 從管理室提供的資訊中找出並核對三項必備內容：
   - 停用的電梯編號。
   - 停用起始日期與結束日期。
   - 管理室聯絡分機。
2. 若任何必備內容缺漏、日期不完整或有歧義，不要猜測或自行補值；先向使用者詢問缺少或需要確認的資訊，再撰寫通知。
3. 以清楚、簡潔、適合住戶閱讀的繁體中文撰寫通知本文。本文最多三句，並須完整保留上述三項必備內容。日期與電梯編號照原始資訊表達，不要擅自改動。
4. 其他資訊可以保留、合併或省略。不得加入來源未提供的事實、原因、承諾或替代安排。
5. 若省略任何提供的資訊，或將數項資訊合併表達，在通知本文之外另加一句，具體說明省略或合併了哪些內容。這句是編輯說明，不屬於通知本文的三句上限。若沒有省略或合併，不要加編輯說明。

## 輸出格式

先輸出標示為「通知」的本文，確保最多三句。若有省略或合併，再另起一行以「編輯說明：」開頭，用一句話交代處理內容；不要把編輯說明放進通知本文。
