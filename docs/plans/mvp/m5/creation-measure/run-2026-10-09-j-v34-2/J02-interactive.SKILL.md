# 民宿訂房取消退款試算

依使用者提供的訂房資料計算日曆天數、退款比例與退款金額；不可退款方案優先於標準方案規則。只使用已提供的資料，不推定額外費用或其他退款規則。

## 步驟

1. 讀取每筆訂房的入住日期、取消日期、房費總額與方案。日期使用 `YYYY-MM-DD`；方案須為「標準方案」或「不可退款方案」。如有幣別，保留原幣別；沒有幣別就不指定。
2. 缺少欄位時保留已提供的事實，將缺少值標成「未提供」，不可自行補值。把每筆資料整理成腳本參數值：入住日期、取消日期、房費總額、方案、幣別，依此順序以 `|` 分隔；缺少欄位時保留空欄。每筆資料各帶一次 `--booking`。沒有任何訂房資料時，仍執行腳本以產生可用的空白輸出模板。
3. 從存放本 SKILL.md 的目錄執行 `python scripts/refund.py`，並接上整理好的 `--booking` 參數；呈現腳本輸出的結果，不自行改算。
4. 腳本依入住日期減取消日期計算日曆天數。標準方案按 7 天以上退款 100%、3 至 6 天退款 50%、2 天以下退款 0%；不可退款方案一律退款 0%。金額按小數點後兩位四捨五入，恰逢半分時進位。腳本會在所有訂房資料完整且可用時，按幣別列出退款合計。
5. 若腳本以代碼 2 結束，完整呈現其結果與錯誤訊息；針對訊息列出的每個不可用值，明確請求提出請求的人確認該值。無法計算的欄位留作標記空白，不輸出依賴該值的金額或合計；仍交付已能產生的結果，不以問題結尾。
