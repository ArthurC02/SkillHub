# 共享電動單車租借計費

依使用者提供的租借時長，計算每筆租借的計費單位、封頂前金額與套用每筆 60 元上限後的費用。只使用使用者指定的規則，不加入其他費用或優惠。

## 步驟

1. 從使用者訊息整理每筆租借的時長（分鐘），保留每個數值的原樣與順序。每筆時長是獨立的一筆租借。
2. 若沒有提供時長，準備一筆標明「時長：未提供」的結果範本；不要猜測時長。若有時長，將它們作為位置參數傳給腳本。從放有本 `SKILL.md` 的目錄執行，例如：
   ```sh
   python scripts/calculate_fare.py -- 0 1 30
   ```
   把範例數值替換成使用者實際提供的全部時長；不得把範例當作答案。
3. 呈現腳本輸出的每筆結果，包含時長、進位後單位數、封頂前金額與最終費用。輸出另列無法使用的值時，照原樣指出每個值，請提出請求的人確認；不要替該筆計算，也不要計算依賴該值的金額。其他有效租借仍照常呈現。
4. 若時長未提供，交付可直接使用的範本，並將缺少的欄位標明「未提供」：
   ```text
   租借 1：時長：未提供（分鐘）｜計費單位：未提供｜封頂前金額：未提供 元｜最終費用：未提供 元
   ```
5. 直接交付結果或範本；不要只給計算計畫，也不要聲稱已執行任何外部操作。
