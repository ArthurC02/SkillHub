# 大樓電梯維修住戶通知

將管理室提供的維修資訊整理成可直接使用的繁體中文住戶通知；只使用輸入提供的事實，不補造資訊。

## 步驟

1. 從輸入辨認停用的電梯編號、停用起訖日期及管理室分機。照輸入保留這些內容的寫法；不得省略或改變其值。
2. 整理其餘資訊時，逐項記下所有省略的內容，以及所有合併處理的內容；即使合併後的句子仍保留了原資訊，也必須記錄該合併。只要有任何省略或合併，就必須在 answer.txt 的通知本文結束後另起一段，標示「修改紀錄：」並逐項說明省略或合併了什麼；不得把修改紀錄放入 notification-body.txt，也不得因相關資訊已在本文出現而省略紀錄。只有完全未省略且未合併任何資訊時，才不列修改紀錄。
3. 以繁體中文撰寫通知，分別標示「通知本文：」及（適用時）「修改紀錄：」。通知本文最多 3 句；修改紀錄置於本文之外，不計入本文句數，也不受本文句數上限限制。不可為縮短輸出而省略必須列出的修改紀錄。只使用輸入提供的事實，不補造資訊。
4. 若必要資訊未提供，在通知本文相應位置以「［未提供：項目］」標明，並提供可直接使用的通知內容；不為未提供的值猜測或補造。若同一必要項目有互相矛盾的值，標明各個原值及其衝突，請提出請求的人確認；不選擇其中一個，也不寫依賴該項目的結論。其他內容照常整理，不因缺少無關的名稱、標籤或日期而中止。
5. 將通知本文寫入 `notification-body.txt`。從同一份內容另外將完整輸出（本文及有需要時的修改紀錄）寫入 `answer.txt`，並執行：

   ```bash
   python scripts/check_output.py --max-sentences 3 notification-body.txt
   ```

   若未印出 `OK`，修改 `notification-body.txt` 並重跑檢查。檢查通過後，只以 `answer.txt` 的內容作為回覆；不得用整份回覆的句數檢查取代本文句數檢查。
