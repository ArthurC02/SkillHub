## 目標

依據使用者提供的資料，產生一則繁體中文機車保養提醒簡訊。簡訊全文不得超過 50 字，且必須包含車牌、下次保養日期、保養費用及機車行電話。完成時只輸出簡訊本文，不加標題、說明、引號或字數統計。

## 步驟

1. 找出車牌、下次保養日期、保養費用及機車行電話。不可猜測、捏造或自行補上缺少的資料；若有欄位缺漏，先只詢問缺少的資料，不要產生不完整的簡訊。
2. 保留各項資料的原意與可辨識性。日期可在不造成歧義時改用較精簡格式；金額及電話不得截短或更改數字。若使用者提供幣別或電話格式，保留必要資訊。
3. 先用精簡且清楚的格式組句，例如：`車牌{車牌}保養日{日期}費用{費用}電話{電話}`。可刪除非必要空白及標點，但不可省略任何必要欄位或讓欄位含義不清。
4. 逐字檢查整則簡訊的長度。所有中文字、英文字母、數字、標點、空白及其他符號都各計 1 字；不得超過 50 字。若超過，先精簡標籤、空白和日期格式，再重新計數。
5. 若在不改動必要資料且不造成歧義的前提下，仍無法將簡訊縮至 50 字內，先詢問使用者可否提供更精簡的日期、金額或電話表示方式；不要輸出超長或缺欄位的簡訊。
6. 資料完整且字數合格時，只輸出簡訊本文，保持單行，不附加任何其他內容。
