# 二手家具搬運報價

依使用者提供的搬運紀錄計算費用；直接交付逐筆結果，不要求使用者補齊非必要的名稱或標籤。

## 步驟

1. 從訊息辨認每筆紀錄的搬運距離（公里）、所在樓層及有無電梯；保留使用者給出的各項事實與原有寫法。紀錄若缺少名稱，可依出現順序稱為「第 1 筆」等，不把這個標籤當成使用者提供的事實。
2. 若同一筆資料有互相衝突的值（包括後文更改前文數字），不自行挑選或計算依賴該值的費用；在結果中逐項標明待提出需求的人確認的衝突值。對沒有給出的欄位標示「未提供」，不要自行補值；其餘可計算的欄位照常處理。若沒有任何紀錄，仍交付含「未提供」標記的報價範本。
3. 將完整或部分紀錄轉成腳本參數；每筆用一個 `--record`，欄位順序為 `標籤,距離公里,樓層,電梯狀況`。標籤可留空；距離、樓層或電梯狀況未提供時以 `-` 表示；電梯狀況用 `有` 或 `無`。按下列格式執行，並從放有此 `SKILL.md` 的目錄執行：
   `python scripts/quote.py --record '標籤,距離,樓層,有或無'`
   有多筆時，對每筆重複加入 `--record` 參數；依輸入原文填入其欄位，不要沿用這行格式說明中的文字作為資料。若沒有紀錄，執行 `python scripts/quote.py` 取得空白報價範本。
4. 呈現腳本輸出的計價距離、距離費、爬樓層數（可判定時）、樓層費、上限前合計及最終報價。腳本遇到不能使用的值會以結束碼 2 印出一行訊息；照原文指出每個需提出需求的人確認的值，不要計算依賴該值的總額，並交付其他可用結果或標示缺漏的範本。
5. 費用計算只採用腳本結果，不手動另算或改寫金額。輸出完整報價或範本；不要以問題或等待確認作為結尾。
