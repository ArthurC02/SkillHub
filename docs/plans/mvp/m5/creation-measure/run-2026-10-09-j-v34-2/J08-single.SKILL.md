## 工作流程

1. **讀取並整理紀錄**
   - 從使用者提供的內容擷取每筆紀錄的品項、數量、單價、驗收日期；保留原始數值與文字，不要默默更正、四捨五入或補猜缺漏資料。
   - 以明確的品名或品項編號辨識同一品項；名稱相似但無法確定為同品項時，先列出歧義並詢問，不要自行合併。
   - 若欄位缺漏、格式無法辨讀，或數量／單價不是可解析的數值，指出紀錄與欄位並詢問使用者補充。不要計算依賴該欄位的金額。

2. **驗證資料與標記阻礙**
   - 檢查日期是否為有效的日曆日期，包括月份天數與閏年；例如不存在的日期不可當作有效日期。若日期格式有多種合理解讀，請使用者確認。
   - 數量小於零時，標記為異常並請使用者確認正確數量；不得自行改成正數或零。
   - 比對同一品項的數量。若紀錄中數量不一致且內容未清楚表明它們是不同批次／不同驗收行，列出各筆原值並請使用者確認；不可自行挑一個數字、平均或加總來消除矛盾。
   - 若同一品項的單價不一致，或幣別、單位等差異可能改變計算結果，也列出差異並詢問使用者如何處理。不要假設不同單價可任意套用到所有數量。
   - 若使用者清楚表示同品項的不同紀錄是各自獨立的驗收行，依各行資料分別核算；不得把同一品項不同日期的行誤判為可互相取代的數量。若是否獨立仍不清楚，先詢問。

3. **計算可確認的金額**
   - 只有在品項、數量、單價及計算所需資料都明確且無未解矛盾時，才計算該行小計：`數量 × 單價`。
   - 同品項有多筆已確認的獨立驗收行時，分別列出各行小計；只有在使用者的紀錄明確要求依品項彙總時，才加總該品項各行小計。
   - 驗收總額只加總所有可確認的行小計。若有任何未解問題可能影響總額，不要把部分金額稱為「驗收總額」或「最終總額」。可另外提供清楚標示的「已確認小計（不含待確認紀錄）」；若沒有可核算的紀錄，說明目前無法計算。
   - 依使用者指定的幣別與精度呈現。若未提供精度，不要擅自改動輸入單價；顯示計算式與足以核對的結果，並在存在幣別或精度歧義時先詢問。

4. **回覆結果與待確認事項**
   - 先簡述已核對的範圍，再用表格列出可核算紀錄的品項、數量、單價、小計及驗收日期。
   - 對每項異常列出相關原始紀錄、具體矛盾及需要使用者確認的問題。待確認的行將小計標為「未計算」，不要填入猜測金額。
   - 所有阻礙解除後，依使用者確認的資料重新核對並計算完整驗收總額；不要沿用被更正前的計算值。
