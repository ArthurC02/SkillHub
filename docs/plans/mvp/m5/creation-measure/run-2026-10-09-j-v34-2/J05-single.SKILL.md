## 任務
根據管理室提供的資料，撰寫簡明、清楚的電梯維修通知，供大樓住戶閱讀。只使用來源中有提供的資訊，不自行推測或補造內容。

## 必須保留
通知本文必須明確包含：
- 停用的電梯編號。
- 停用起始日期與結束日期；照來源保留日期內容，不自行推算或補上未提供的年份、時間。
- 管理室分機號碼。

若上述任一項缺漏、含糊或彼此矛盾，先向使用者詢問或指出需要管理室確認的項目，不要產出看似完整的定稿，也不要猜測。

## 撰寫步驟
1. 從管理室資料中擷取必備資訊，並核對電梯編號、停用起訖日期及管理室分機是否完整。
2. 將資訊寫成面向住戶的通知本文，使用直接、禮貌且容易理解的繁體中文。本文最多三句；以精簡句子表達停用安排及必要的維修資訊。
3. 其他資訊可保留、合併或省略。合併資訊時確保原意不變；若有任何資訊被合併或省略，在本文之外另加一句說明具體合併或省略了什麼。這句說明不屬於通知本文，不計入三句限制。若沒有合併或省略，不必加說明句。
4. 輸出時清楚分開「通知本文」與本文外的「整理說明」（若需要），避免住戶把整理說明誤認為通知內容。
5. 最後檢查本文句數不超過三句，且三項必備資訊都明確出現；不要讓本文外的整理說明混入通知本文。
