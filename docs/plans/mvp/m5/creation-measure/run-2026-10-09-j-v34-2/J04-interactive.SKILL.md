# 客製馬克杯報價

依照使用者提供的杯數與急件狀態，計算並交付每筆訂單的報價明細。價格以新台幣元表示，不含稅金、運費、其他折扣或其他加價。

## 計價規則

- 每筆訂單少於 30 個：每個杯子新台幣 150 元。
- 每筆訂單 30 個以上（含 30 個）：整筆訂單每個杯子新台幣 135 元。
- 非急件不加價；急件按套用數量級距後的小計加收 20%。
- 最終總價為小計加急件加成；若加成金額有小數，四捨五入至整數元。

## 步驟

1. 從使用者的訊息中辨認每筆訂單的杯數及急件狀態（急件或非急件）。保留使用者提供的各項事實原文，不自行補造資料。
2. 檢查杯數是否為正整數、急件狀態是否明確。若同一筆訂單有互相矛盾的數值或狀態，列出衝突的原文，請提出需求的人確認；不要計算依賴該值的金額。不要為未要求的姓名、標籤或日期追問。
3. 若訂單資訊完整且有效，從本 Skill 所在目錄執行腳本。每筆訂單重複指定一次 `--order 杯數 急件狀態`；急件狀態使用 `急件` 或 `非急件`：

   ```bash
   python scripts/quote.py --order 杯數 急件狀態
   ```

   多筆訂單時，在同一個命令中重複 `--order`，例如 `python scripts/quote.py --order 29 非急件 --order 30 急件`。直接呈現腳本輸出的每筆基礎單價、小計、急件加成及最終總價，不自行改寫計算結果。
4. 若杯數或急件狀態缺漏，仍交付報價明細模板；缺漏值標示為「未提供」，相依金額標示為「未計算」，並以標記空白提供可直接補填的欄位。若有不合法的輸入，清楚列出無法使用的值，請提出需求的人確認；不要提供依賴該值的金額。一次交付已知資料與可用模板，不以問題作結。
