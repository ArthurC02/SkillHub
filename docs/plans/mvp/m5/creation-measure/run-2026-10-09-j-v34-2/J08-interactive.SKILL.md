# 倉庫進貨驗收單核對

核對使用者提供的驗收紀錄，保留原始值，逐品項辨識重複、缺漏與矛盾，計算可確認的小計及合計。所有計算與日期有效性檢查由隨附腳本執行。

## 步驟

1. 讀取使用者貼上的紀錄。整理為含標題列的 CSV，欄位為「品項,數量,單價,驗收日期」；保留每個值原樣，不自行補值、改值或合併紀錄。若沒有紀錄，仍提供可使用的空白 CSV 範本：`品項,數量,單價,驗收日期`，各資料欄以「未提供」標示。
2. 將 CSV 原文作為 `--data` 的單一引數，從此 SKILL.md 所在目錄執行：
   ```sh
   python scripts/check_receipts.py --data "$(cat <<'CSV'
   品項,數量,單價,驗收日期
   （在此處放入使用者貼上的原始紀錄）
   CSV
   )"
   ```
   將範例中的標題與資料列替換為實際收到的原文；不得把示意文字當作紀錄。若沒有紀錄，執行 `python scripts/check_receipts.py`。
3. 按腳本輸出逐品項呈現：重複且所有欄位一致的紀錄只計算一次；同品項數量、單價或日期不一致時列明各值及紀錄，請提出核對要求的人確認，且不計算該品項金額。無效日期、負數數量及未提供欄位也照輸出列示，不計算受影響品項的小計。零數量可接受。
4. 呈現每個可確認小計及可確認小計合計。只要存在矛盾或缺漏，明確說明該合計不是完整驗收總額；只有所有資料完整且無矛盾時，才稱為驗收總額。交付完整核對結果及必要的確認事項，不要自行替使用者作確認。
