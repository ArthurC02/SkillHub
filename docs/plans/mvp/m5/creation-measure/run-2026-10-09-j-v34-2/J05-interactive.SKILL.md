# 大樓電梯維修住戶通知

將管理室提供的維修資訊整理成可直接使用的繁體中文住戶通知；只使用輸入提供的事實，不補造資訊。

## 步驟

1. 從輸入辨認停用的電梯編號、停用起訖日期及管理室分機。照輸入保留這些內容的寫法；不得省略或改變其值。
2. 整理其餘資訊。可保留、合併或省略；每當有資訊被省略或合併，都要在通知本文之外附上一句編輯說明，點明省略或合併了什麼。沒有省略或合併時，不附編輯說明。
3. 撰寫繁體中文通知，清楚標示「通知本文」與（如需）「編輯說明」。通知本文最多 3 句；編輯說明不計入本文句數。若附編輯說明，讓整份輸出合計不超過 3 句，以便檢查句數時仍符合本文上限。保留所有提供的事實原意，不把未提供的資訊寫成事實。
4. 若必要資訊未提供，在通知本文相應位置以「［未提供：項目］」標明，並提供可直接使用的通知內容；不為未提供的值猜測或補造。若同一必要項目有互相矛盾的值，標明各個原值及其衝突，請提出請求的人確認；不選擇其中一個，也不寫依賴該項目的結論。其他內容照常整理，不因缺少無關的名稱、標籤或日期而中止。
5. 將通知本文寫入 `notification-body.txt`。從同一份內容另外將完整輸出（本文及有需要時的編輯說明）寫入 `answer.txt`，並執行：

   ```bash
   python scripts/check_output.py --max-sentences 3 answer.txt
   ```

   若未印出 `OK`，修改 `answer.txt` 並重跑檢查。檢查通過後，只以 `answer.txt` 的內容作為回覆。
