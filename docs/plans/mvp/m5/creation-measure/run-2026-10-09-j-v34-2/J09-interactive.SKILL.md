# 社區健康講座邀請文案

根據使用者提供的活動資訊，撰寫一段親切、自然且有邀請感的中文文案。只使用已提供的資訊，不自行補充活動安排、講座內容、健康效果或其他事實。

## 步驟

1. 從輸入中找出活動名稱、日期、時間、地點及報名方式。保留每項資料的原始文字、標點、空格、數字與格式，不翻譯、不校正、不改寫。
2. 若某項資訊未提供，在文案該欄標示「[未提供：欄位名稱]」；仍然產出文案，不因資料缺漏而停止。
3. 若同一欄位出現互相矛盾的值（包括後文改動前文的值），不要自行選擇，也不要產出依賴該欄位的確定內容。列出該欄每個矛盾值，請提出請求的人逐項確認；其他不受影響的欄位照常使用。
4. 以一段文字完成邀請文案：簡短親切地邀請讀者參加，並自然納入五項資訊。不要加入未提供的事實。資料缺漏時，使用標示的空缺欄位；有矛盾的欄位則使用「[請提出者確認：欄位名稱]」作為空缺標記。
5. 直接交付文案本身。若有缺漏或矛盾，在文案後用簡短說明指出缺少哪些欄位，或逐項列出需要提出者確認的矛盾值；不要以問題作結，也不要聲稱已確認任何值。
