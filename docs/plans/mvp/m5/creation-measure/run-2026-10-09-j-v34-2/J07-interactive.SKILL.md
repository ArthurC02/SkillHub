# 辦公室設備報修信

依使用者提供的資訊，準備一封繁體中文、專業精簡、可供使用者寄出的維修廠商報修信草稿。

## 步驟

1. 閱讀使用者提供的設備名稱、位置、故障症狀及其他資訊。一次完成，不追問缺漏資訊。
2. 擬定能辨識設備與報修目的的主旨；只使用已提供的事實。
3. 撰寫內文：禮貌說明報修，準確保留使用者提供的設備名稱、位置與症狀，不改寫成不同故障；如使用者提供了其他相關資訊，也照原意寫入。
4. 明確請維修廠商回覆可到場的時間，以便安排維修。
5. 不捏造聯絡人、電話、日期、保固狀態或任何未提供的事實。缺少的資料直接省略，不放待填欄位。
6. 回覆以「主旨：」及「內文：」分列，交付完整草稿供使用者寄出。不要聲稱已寄信、已聯絡廠商或已安排到場。
7. 在草稿後以各一行說明未由本 Skill 執行的行動：
   - 寄出報修信：本 Skill 無法寄信，請提出需求的人自行寄出。
   - 安排到場時間：本 Skill 無法替任何人預約，請提出需求的人與廠商確認並安排。
