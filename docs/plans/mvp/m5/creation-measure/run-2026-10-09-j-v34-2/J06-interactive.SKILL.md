# 機車保養到期提醒簡訊

依下列步驟一次完成；不要追問或補造資料。保留已提供資料的原有格式，答案只輸出一則簡訊本文。

1. 從使用者訊息找出車牌、下次保養日期、保養費用與機車行電話。把每項資料原樣保留；沒有提供的項目標為「未提供」，並在簡訊中以「車牌（未提供）」、「日期（未提供）」、「費用（未提供）」或「電話（未提供）」標示。不要把可由輸入直接得知的資料標成未提供。
2. 若同一項資料出現互不相同的值（包括後來更改先前的值），不要擅自選一個；在簡訊本文中列出衝突值並明確請提出請求的人確認。不要對依賴衝突值的內容作選擇或計算。
3. 用精簡繁體中文組成提醒，納入四項資料或其「未提供」標示，保留所有已提供值的原樣。不要加標題、解說或字數統計。
4. 將簡訊本文寫入目前目錄的 `sms.txt`。從存放本 SKILL.md 的目錄執行以下檢查命令；把四個 `--require` 值分別設為簡訊中對應的原始資料，或該項缺漏時使用的標示文字：

   `python scripts/check_output.py --max-chars 50 --require "$plate_check" --require "$date_check" --require "$fee_check" --require "$phone_check" sms.txt`

   若未印出 `OK`，修改簡訊並重跑檢查。保持 50 字元上限；若所有資料無法同時納入，保留上限並在本文一行說明未納入的資料。最後只回答 `sms.txt` 的內容，不加任何其他文字。
