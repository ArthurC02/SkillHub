# 冷藏食材到貨驗收判定

依下列規則判定冷藏食材到貨驗收結果。此 Skill 只處理**冷藏食材**；若不是冷藏食材，應先確認是否適用本規則。

## 需要的資訊
- 到貨溫度（°C）
- 效期日期
- 到貨日期

## 判定步驟
1. **先看到貨溫度**
   - 若到貨溫度 **超過 7°C**（不含 7°C），直接判定為：**拒收退回**。
   - 不需要再看效期剩餘天數。

2. **若到貨溫度在 7°C 以下或等於 7°C**
   - 計算「效期距到貨日的天數」：
     - 以**效期日期 - 到貨日期**計算天數。
     - 只看日期，不另外加入時間差。

3. **依天數判定**
   - 若效期距到貨日 **超過 2 天**：判定為 **合格**。
   - 若效期距到貨日 **2 天以内（含 2 天）**：判定為 **警示**，並註記 **需要優先當天用完**。

## 判定結果格式
輸出時請明確給出以下其中一種結果：
- **合格**
- **警示：需要優先當天用完**
- **拒收退回**

## 注意事項
- 「7°C 以下」在本規則中包含 **7°C**。
- 「超過 7°C」表示 **大於 7°C**，7°C 本身不屬於拒收條件。
- 若效期日期早於到貨日期，則天數為 0 天以下，仍視為 **警示** 的範圍內，除非到貨溫度超過 7°C，則仍以 **拒收退回** 為準。
- 若輸入資訊不足，先補齊到貨溫度、效期日期、到貨日期後再判定。
