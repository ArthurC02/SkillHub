# 目的
將客戶傳來的活動洽詢文字整理成固定欄位，方便後續報價、排程或場地確認。

# 適用情境
當輸入是一段或多段自然語言訊息，內容可能包含活動需求、聯絡資訊、日期、人數、預算與場地偏好時，使用此 Skill。

# 輸出欄位
請只整理以下欄位：
- 聯絡人姓名
- 聯絡電話
- 活動日期
- 預估人數
- 預算上限
- 場地偏好

# 處理步驟
1. 先通讀整段訊息，找出與活動洽詢相關的資訊。
2. 逐一擷取六個欄位的內容。
3. 若同一欄位出現多個候選值，優先採用：
   - 明確標示為聯絡人、姓名、電話、日期、人數、預算、場地偏好的內容
   - 最近一次更正或補充的內容
4. 若欄位未明確出現，填寫「未提及」。
5. 若日期、人數、預算有模糊寫法，保留原意並盡量標準化：
   - 活動日期：保留原文日期，必要時可補成較清楚的格式，但不要自行推測未寫出的日期
   - 預估人數：保留數字與單位，例如「約 50 人」
   - 預算上限：保留金額與幣別，例如「NT$30,000」或「三萬元以內」
   - 場地偏好：保留原文描述，例如「戶外草地」、「台北市區」、「有投影設備的室內場地」
6. 不要加入原文沒有的資訊，不要自行補全姓名、電話或日期。
7. 若訊息中有多個聯絡方式，優先擷取最像主要聯絡人的姓名與電話；若無法判斷，保留最完整且最直接對應的資訊。

# 輸出格式
請用以下格式輸出，欄位順序固定：

- 聯絡人姓名：
- 聯絡電話：
- 活動日期：
- 預估人數：
- 預算上限：
- 場地偏好：

# 注意事項
- 只根據輸入文字整理，不要查詢外部資料。
- 不要推測未明示的資訊。
- 若訊息包含多個活動，優先整理使用者最主要詢問的那一個；若無法判斷，請以最完整的一組資訊為準。
