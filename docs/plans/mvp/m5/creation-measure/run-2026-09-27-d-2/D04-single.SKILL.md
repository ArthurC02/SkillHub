# 目的
根據本週收到的特休申請，為診所櫃台排出下週一到週六的值班表，並盡量避免把請假日排到班。

# 適用範圍
- 人員固定為：小雅、阿ken、Ivy。
- 排班區間為下週一到週六，診所週日公休，不排班。
- 輸入通常包含：
  - 三位人員各自的特休申請日期
  - 班表規則（例如每天需要幾人、是否要輪班、是否有固定不可排時段）
- 若資訊不足，先整理缺口並提出需要補充的資料，不要自行捏造。

# 工作流程

## 1. 先整理輸入
把使用者提供的資訊拆成三類：
1. 人員名單：小雅、阿ken、Ivy
2. 請假日期：逐一列出每個人的特休日期
3. 排班規則：
   - 每天需要幾位櫃台人員
   - 是否每人每天最多一班
   - 是否有固定休假、固定上班、或其他限制

如果使用者沒有明確給出「每天需要幾人」，先詢問；不要假設。

## 2. 建立排班日期
- 找出「下週一」到「下週六」的實際日期。
- 週日不排班。
- 若使用者提供的是相對日期或本週日期，先換算成明確日期再排。

## 3. 標記不可排班日
對每位人員建立可排班清單：
- 若某日是該人特休，標記為不可排班。
- 若有其他限制（例如固定門診、外訓、不可上班），同樣標記為不可排班。

## 4. 依規則排班
依照使用者提供的班表規則安排下週一到週六。

排班原則：
1. 先滿足每天最低人力需求。
2. 優先避開請假日。
3. 盡量平均分配三人的班數。
4. 若有輪班規則，優先維持輪替公平。
5. 若某天可排人數不足，明確標示缺口，不要硬排。

### 建議的排班順序
- 先排限制最多的日期（例如只有 1 人可上班的日子）。
- 再排一般日期。
- 最後檢查每人總班數是否過度集中。

## 5. 檢查衝突
完成後逐項檢查：
- 是否有人被排到特休日
- 是否每天人數符合需求
- 是否有漏排日期
- 是否有重複排班或超出規則

若有衝突：
- 先嘗試在同週內調整其他日期
- 若仍無法解決，列出無法滿足的日期與原因

## 6. 輸出班表
輸出時請用清楚表格，至少包含：
- 日期
- 星期
- 值班人員
- 備註（例如：請假、缺人、調班原因）

若需要，也可另外附上：
- 每人本週總班數
- 每人請假日與實際排班日對照

# 輸出格式建議
使用以下格式之一：

## 方案 A：表格
| 日期 | 星期 | 值班人員 | 備註 |
|---|---|---|---|
| 2026-xx-xx | 一 | 小雅、Ivy | 阿ken請假 |

## 方案 B：逐日清單
- 週一 2026-xx-xx：小雅、Ivy（阿ken請假）
- 週二 2026-xx-xx：...

# 缺資料時的處理
如果缺少以下任一項，先提出問題，不要直接排：
- 下週的實際日期或可用來換算日期的基準日
- 每天需要幾位值班人員
- 三位人員各自的特休日期
- 任何額外排班限制

# 品質要求
- 不要把週日排進班表。
- 不要忽略請假日。
- 不要自行新增不存在的人員。
- 若無法完全滿足需求，要清楚說明哪一天缺人、缺幾人、原因是什麼。
