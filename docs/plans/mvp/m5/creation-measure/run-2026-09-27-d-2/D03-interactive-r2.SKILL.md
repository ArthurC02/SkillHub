# Activity Inquiry Extractor

從客戶傳來的活動洽詢文字中，擷取並整理成固定欄位。

## 你要做的事

讀取使用者提供的一段自由文字，直接輸出以下 6 個欄位：

1. 聯絡人姓名
2. 聯絡電話
3. 活動日期
4. 預估人數
5. 預算上限
6. 場地偏好

## 處理原則

- 只根據輸入文字擷取，不要補寫不存在的資訊。
- 若欄位在原文中沒有明確出現，填入空字串 `""`。
- 優先保留原文語意，不要自行改寫成更抽象或更完整的內容。
- 不要自行推算日期、金額、人數或地點。
- 若電話、日期、金額或場地偏好有多種寫法，保留原文中可辨識的內容。

## 預設輸出格式

請輸出為 JSON 物件，欄位固定如下：

```json
{
  "聯絡人姓名": "",
  "聯絡電話": "",
  "活動日期": "",
  "預估人數": "",
  "預算上限": "",
  "場地偏好": ""
}
```

## 擷取規則

### 1. 聯絡人姓名

- 擷取客戶自稱的姓名或簽名中的姓名。
- 若原文同時出現公司名、職稱與姓名，以明確姓名為準。
- 若無法確定姓名，留空。

### 2. 聯絡電話

- 擷取手機、市話或其他明確可聯絡的電話號碼。
- 保留原文格式即可，例如含空格、連字號或括號都可以。
- 若有多個電話，優先取最像聯絡電話的主要號碼；若無法判定主號碼，取最先出現者。

### 3. 活動日期

- 擷取原文中的日期、時間或日期表達。
- 可以保留原文格式，例如 `2026/11/14`、`11 月 14 日`、`下週六`。
- 不要換算成其他日期格式，也不要補年份。

### 4. 預估人數

- 擷取人數、席次、參與人數、預計到場人數等明確數量。
- 保留原文數字或文字數量表達，例如 `120 人`、`百人以上`。
- 若只有範圍，保留原文範圍。

### 5. 預算上限

- 擷取預算、最高預算、預算上限、可接受金額等表達。
- 保留原文金額格式，例如 `NT$300,000`、`3 萬元`。
- 若是區間或上限，保留原文原樣。

### 6. 場地偏好

- 擷取場地相關偏好，例如地區、交通條件、空間型態、容納需求、設備需求等。
- 保留原文中的偏好描述，不要自行整理成推論後的條列。
- 若原文包含多個偏好，合併成單一欄位內容即可。

## 輸出要求

- 直接輸出 JSON，不要加前言、解釋或分析。
- 欄位名稱必須完全一致。
- 欄位順序固定為：聯絡人姓名、聯絡電話、活動日期、預估人數、預算上限、場地偏好。
- 每個欄位都必須出現在輸出中；缺值一律用空字串。

## 範例

輸入：

> 您好，我是林怡君，電話 0912-345-678。我們想在 2026/11/14 舉辦公司尾牙，預計 120 人，預算上限 NT$300,000，場地希望是台北市區、交通方便、可容納百人以上的宴會廳。

輸出：

```json
{
  "聯絡人姓名": "林怡君",
  "聯絡電話": "0912-345-678",
  "活動日期": "2026/11/14",
  "預估人數": "120 人",
  "預算上限": "NT$300,000",
  "場地偏好": "台北市區、交通方便、可容納百人以上的宴會廳"
}
```
