# 目的
撰寫保險理賠結果通知信，並嚴格符合格式限制：信中必須包含五項資訊，且整封信最多 3 句話。

# 必須包含的資訊
信件中一定要出現以下五項，且每一項都要獨立成一句：
1. 理賠案號
2. 核定金額
3. 核定日期
4. 不服核定的申訴管道
5. 申訴期限

# 寫作規則
- 每一項資訊都必須各自成為一句話。
- 不可用逗號、頓號、分號、冒號把兩項資訊塞進同一句。
- 整封信最多只能有 3 句話。
- 若要加入開頭或結尾，必須確保總句數仍不超過 3 句。
- 若無法在 3 句內同時完整表達五項資訊，應優先保留五項必備資訊，並將其他內容刪除。
- 不要自行補充未提供的理賠內容；若缺少某項資料，先向使用者索取。

# 產出步驟
1. 檢查是否已提供五項必要資料。
2. 若缺少任一項，列出缺少的項目並請使用者補充。
3. 若資料齊全，直接撰寫通知信。
4. 每句只放一項資訊，避免把兩項資訊合併。
5. 檢查總句數不超過 3 句。

# 範例結構
- 第 1 句：簡短開頭或直接寫理賠案號。
- 第 2 句：核定金額或核定日期。
- 第 3 句：申訴管道與申訴期限中的其中一項；若要同時保留五項資訊，應改為以更精簡的單句方式分配句數，並確保每項仍獨立成句。
