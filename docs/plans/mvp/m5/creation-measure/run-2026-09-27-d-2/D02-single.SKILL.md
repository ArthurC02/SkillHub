# 自助倉儲入倉資格審核

依照申請人的信用分數、近一年逾期繳費次數，以及是否曾有毀損倉儲設施紀錄，判定入倉等級與押金要求。

## 審核順序

1. **先檢查是否曾有毀損倉儲設施紀錄。**
   - 只要有任何毀損紀錄，**直接判定為 D 級**。
   - **D 級結果：拒絕承租。**
   - 不再看信用分數或逾期繳費次數。

2. **若沒有毀損紀錄，再看信用分數與近一年逾期繳費次數。**
   - **信用分數達 700 分以上（含 700）且近一年逾期繳費 0 次**：
     - 判定為 **A 級**
     - **免押金**
   - **信用分數達 700 分以上（含 700）但近一年逾期繳費 1 次以上**：
     - 判定為 **B 級**
     - **押金為 1 個月租金**
   - **信用分數未滿 700 分**：
     - 判定為 **C 級**
     - **押金為 2 個月租金**
     - **需要連帶保證人**

## 判定規則細節

- 「達 700 分以上」表示 **700 分也算符合**。
- 「近一年逾期繳費 1 次以上」表示 **1 次、2 次或更多都屬於 B 級條件**，前提是信用分數至少 700。
- 若同時符合多個條件，**以毀損紀錄優先**；其次依信用分數與逾期次數判定 A/B/C。

## 輸出格式

審核結果應明確列出：
- 等級：A / B / C / D
- 結果：免押金 / 押金金額規則 / 需要連帶保證人 / 拒絕承租
- 判定依據：信用分數、近一年逾期繳費次數、是否有毀損紀錄

## 範例

- 信用分數 720，近一年逾期 0 次，無毀損紀錄 → **A 級，免押金**
- 信用分數 700，近一年逾期 2 次，無毀損紀錄 → **B 級，押金 1 個月租金**
- 信用分數 650，近一年逾期 0 次，無毀損紀錄 → **C 級，押金 2 個月租金，需連帶保證人**
- 信用分數 800，近一年逾期 0 次，但有毀損紀錄 → **D 級，拒絕承租**

## 審核步驟清單

- 先確認是否有毀損倉儲設施紀錄。
- 若有，直接輸出 D 級與拒絕承租。
- 若無，再確認信用分數是否達 700。
- 若信用分數達 700，再確認近一年逾期繳費次數是否為 0。
- 依結果輸出 A、B 或 C 級與對應條件。
