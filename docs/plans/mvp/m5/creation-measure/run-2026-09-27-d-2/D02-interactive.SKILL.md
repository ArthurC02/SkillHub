# 自助倉儲入倉資格審核

依照使用者提供的申請資訊，判定審核等級、是否可承租、押金要求與是否需要連帶保證人。

## 輸入

從使用者訊息中找出以下資訊：
- 信用分數
- 近一年逾期繳費次數
- 是否曾有毀損倉儲設施紀錄
- 租金金額

若租金金額未提供，而結果需要計算押金，請以「租金金額未提供」標示，不要自行編造金額。

## 判定順序

1. **先看是否曾有毀損倉儲設施紀錄**
   - 只要曾有毀損紀錄，不論信用分數與逾期次數，一律判定為 **D 級**。
   - **D 級 = 拒絕承租**。
   - 這個條件優先於其他所有條件。

2. **若沒有毀損紀錄，再看信用分數**
   - **信用分數 700 分以上（含 700）**：
     - 近一年逾期繳費 **0 次** → **A 級**，**免押金**。
     - 近一年逾期繳費 **1 次以上** → **B 級**，**押金為 1 個月租金**。
   - **信用分數未滿 700 分**：
     - → **C 級**，**押金為 2 個月租金**，且**需要連帶保證人**。

## 輸出格式

請直接輸出審核結果，內容包含：
- 審核等級（A / B / C / D）
- 是否可承租
- 押金要求或免押金
- 是否需要連帶保證人
- 如需押金，請同時計算金額

## 計算押金

- **1 個月租金押金** = 租金金額 × 1
- **2 個月租金押金** = 租金金額 × 2

若租金金額與月數同時可得，請把計算步驟寫清楚，再給最後金額。

## 輸出規則

- 不要額外新增未提供的審核條件。
- 不要更改「700 分以上」包含 700 分的定義。
- 若資訊不足以完成押金金額計算，就明確說明缺少哪個欄位。
- 先套用 D 級規則，再套用其他規則。

## 結果示例

- 若信用分數 700、近一年逾期 0 次、無毀損紀錄 → A 級、免押金、可承租。
- 若信用分數 700、近一年逾期 2 次、無毀損紀錄 → B 級、押金為 1 個月租金、可承租。
- 若信用分數 699、近一年逾期 0 次、無毀損紀錄 → C 級、押金為 2 個月租金、需要連帶保證人、可承租。
- 若曾有毀損紀錄 → D 級、拒絕承租。
