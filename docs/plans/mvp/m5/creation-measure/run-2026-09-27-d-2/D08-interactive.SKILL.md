# 自費醫材同意書口語說明信改寫

你要把使用者提供的《自費醫材同意書》改寫成一封給病人看的繁體中文說明信。目標是讓內容更口語、更容易理解，但**所有關鍵數字與專有名稱必須逐字保留**，特別是：
- 醫材品名
- 自費金額
- 健保給付上限
- 病人簽署期限

## 你要直接完成的事
1. 讀取使用者提供的同意書全文。
2. 將原文改寫成一封語氣親切、清楚、適合病人閱讀的說明信。
3. 保留原文中所有關鍵資訊，且**不得改字、改數字、改單位或改期限表述**。
4. 只做表達方式改寫，不要把它重寫成法律文件或公文。
5. 以繁體中文輸出成品。

## 必須遵守的寫作規則
- 不新增原文沒有的醫療承諾、法律承諾、風險說明、療效保證或費用項目。
- 不刪除原文中影響病人決策的重點。
- 如果原文有多個數字、名稱或期限，全部都要保留。
- 如果原文沒有提供某個必要資訊，就不要自行編造；只保留已提供的內容。
- 內容要自然像一封說明信，而不是條列式摘要。

## 建議的輸出方式
- 可用「親愛的病人您好」或同等自然的開頭。
- 用簡單句說明這份同意書是在講什麼。
- 接著把原文中的重點資訊整理成容易懂的段落。
- 文末可用溫和語氣提醒病人留意簽署期限或聯絡診所確認，但**前提是原文有提到**。

## 檢查清單
在輸出前，確認以下項目都符合：
- [ ] 內容是繁體中文
- [ ] 語氣口語、清楚、非公文式
- [ ] 醫材品名逐字保留
- [ ] 自費金額逐字保留
- [ ] 健保給付上限逐字保留
- [ ] 病人簽署期限逐字保留
- [ ] 沒有新增原文未提及的費用、風險或法律效果
- [ ] 成品可直接給病人閱讀

## 遇到原文缺漏時怎麼做
如果使用者提供的同意書原文本身缺少某些資訊，就只根據已提供內容改寫，不要補寫不存在的細節。
