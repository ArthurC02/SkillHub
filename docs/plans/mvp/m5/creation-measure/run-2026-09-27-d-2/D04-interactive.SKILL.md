# 診所櫃台值班表排班 Skill

你會收到一段排班需求文字，內容通常包含：
- 小雅、阿ken、Ivy 三人的本週特休申請日期
- 目前班表格式，或至少可輸出的欄位樣式
- 需要產出的期間，預設為下週一到週六

你的任務是：直接產出可用的診所櫃台值班表，避免特休衝突，並維持使用者提供的輸出格式；若資訊不足，請用最常見的排班假設完成，不要停下來追問。

## 你要遵守的規則

1. **先辨識輸入中的日期與人員**
   - 找出小雅、阿ken、Ivy 各自的特休日期。
   - 找出使用者要求排出的天數範圍。
   - 若輸入明確寫了「下週一到週六」，就只排這 6 天，不要包含週日。

2. **排班時避開特休**
   - 每一天只能安排沒有請特休的人。
   - 如果某一天仍然有人可排，就從可排人員中安排。
   - 如果輸入沒有提供更細的輪班規則，採用最常見的做法：**每天至少 1 人值班**。

3. **遇到人力不足時要明說**
   - 若某一天因特休或其他限制導致無法排出完整值班，直接標示該日無法完成完整排班。
   - 不要編造不存在的人名或班次。

4. **沿用使用者提供的表格格式**
   - 如果輸入有明確的欄位順序或表格結構，例如「星期｜值班人員」，就照那個結構輸出。
   - 如果沒有提供格式，使用簡單表格：`星期｜值班人員`。

5. **輸出要可直接使用**
   - 直接給出排好的值班表。
   - 不要只解釋規則。
   - 不要把週日排進去。

## 必要假設

如果輸入沒有寫清楚，請採用以下常見假設並在輸出中保留結果：
- 排班範圍：下週一到週六
- 週日公休
- 每日至少 1 人值班
- 使用者提供的表格格式優先沿用

## 輸出格式

使用表格或接近表格的清單，範例如下：

| 星期 | 值班人員 |
| --- | --- |
| 週一 | 小雅 |
| 週二 | 阿ken |
| 週三 | Ivy |
| 週四 | 小雅 |
| 週五 | 阿ken |
| 週六 | Ivy |

如果某天無法排班，請直接寫：

| 星期 | 值班人員 |
| --- | --- |
| 週一 | 無法完成完整排班 |

## 注意事項

- 不要詢問使用者下一步要怎麼做；直接完成排班結果。
- 不要自行新增資料來源。
- 不要假裝知道未提供的班表細節。
- 如果輸入同時要求「保持原格式」與「內容很短」，優先保留硬性限制，並在輸出中簡短說明省略了什麼。
- 任何數字、日期或人名都只能使用輸入中給出的資訊；未提供的內容請標示為「未提供」。
- 若輸出中有彼此相關的數量，請把總數一起寫出來。
- 任何數字請先逐步算清楚，再在輸出前把結果重新加總一次確認。
- 請用輸入的語言輸出，包含標籤、表格欄位名稱與說明。
- 你不能替使用者送出、排程或通知任何事情；請只提供可直接使用的值班表內容，並明說送出或排程仍由使用者完成。
- 交付的內容必須是完成品本身，不要只描述規則、計畫或要權限的請求。
