# 目的
將診所既有的「自費醫材同意書」改寫成較口語、容易理解、適合病人閱讀的說明信，同時**嚴格保留**指定欄位與數字/名稱原文不變。

# 適用時機
- 使用者提供一份已完成的自費醫材同意書，要求改寫成白話說明信。
- 需要降低公文語氣、提升可讀性，但不能改動關鍵資訊。
- 文件內容可能包含醫療專有名詞、費用、期限、健保資訊等，需要保留原意。

# 必須保留不變的內容
以下內容在改寫時**一個字都不能改**，包含全形半形、數字、單位、標點、空格與大小寫：
- 醫材品名
- 自費金額
- 健保給付上限
- 病人簽署期限

若原文中這些資訊出現多次，所有出現位置都必須完全一致。

# 工作流程
1. **先辨識原文中的關鍵不可改內容**
   - 找出醫材品名、自費金額、健保給付上限、病人簽署期限。
   - 若這些資訊在原文中有格式差異，先以原文出現的字串為準，不自行統一格式。

2. **保留法律/醫療風險較高的核心意思**
   - 不可刪除會影響病人理解的重要資訊，例如：
     - 這是自費項目
     - 與健保給付的差異
     - 可能的費用負擔
     - 是否需要簽署與何時簽署
     - 若有疑問可向醫療人員詢問
   - 但可將語氣改為較親切、清楚、直接。

3. **改寫成說明信語氣**
   - 用「您」或「病人」作為對象。
   - 句子短一些，避免過度官樣文章。
   - 可用條列整理重點，但不要改動必須保留的原文片段。
   - 若原文有過多重複或冗長句，可合併精簡，但不得改變意思。

4. **保持資訊完整與一致**
   - 不新增原文沒有的醫療承諾、療效保證或法律結論。
   - 不推測未提供的費用、期限或適應症。
   - 不把「可能」「依實際情況」等限制語刪掉，除非原文明確沒有。

5. **輸出前做一致性檢查**
   - 檢查醫材品名、自費金額、健保給付上限、病人簽署期限是否與原文完全相同。
   - 檢查是否有把數字、單位、百分比、日期格式改掉。
   - 若發現無法在不改動關鍵字串的前提下完成改寫，應保留原文該段並只改寫其他部分。

# 改寫原則
- 保留原意，不改事實。
- 以病人看得懂為優先。
- 避免過度正式、冗長、被動語態。
- 不使用法律術語包裝成建議或判斷。
- 不加入未經原文支持的內容。

# 建議輸出格式
可依下列方式整理成說明信：
- 開頭：簡單說明這份文件的用途
- 主體：用白話說明醫材用途、費用與健保差異、簽署提醒
- 結尾：提醒如有疑問可詢問醫師或護理人員

# 注意事項
- 若使用者提供的內容缺少上述必保留資訊，先指出缺少哪些欄位，再請對方補齊後才能改寫。
- 若原文中有明顯矛盾，先標示矛盾處，不要自行修正。
- 若要求同時「完全不改字」與「改寫」，以保留關鍵字串原文為優先，其他部分再做白話化處理。
