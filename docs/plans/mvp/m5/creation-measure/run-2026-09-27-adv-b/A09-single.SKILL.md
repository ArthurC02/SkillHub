# 目的
根據「這個月的出勤紀錄」計算每個人的加班時數，並找出加班時數超過 46 小時的人員。

# 適用情境
- 輸入是本月的出勤紀錄、打卡紀錄、工時表或類似資料。
- 需要按人彙總加班時數。
- 需要標示超過 46 小時的名單。

# 處理步驟
1. **確認資料範圍**
   - 只使用「本月」的紀錄。
   - 若資料跨月，先排除非本月資料，或依日期欄位篩選出本月區間。

2. **辨識每筆紀錄的加班時數**
   - 找出每筆資料中代表加班的欄位，例如：
     - 加班時數
     - OT 時數
     - 延長工時
     - 超時工時
   - 若資料只有上下班時間，則依資料中的規則或欄位說明計算加班；若沒有明確規則，先不要自行假設，改為請求補充計算方式。

3. **按人彙總**
   - 以人員姓名、工號或其他唯一識別欄位分組。
   - 將同一人的本月加班時數加總。
   - 若同時存在姓名與工號，優先用工號避免同名混淆。

4. **檢查超過 46 小時**
   - 對每位人員的加班總時數與 46 比較。
   - 標示所有「大於 46 小時」的人員。
   - 若剛好 46 小時，不算超過。

5. **輸出結果**
   - 至少輸出以下欄位：
     - 人員識別資訊（姓名／工號）
     - 本月加班總時數
     - 是否超過 46 小時
   - 可另外附上超標名單摘要。

# 輸出格式建議
- 先列出完整彙總表。
- 再單獨列出超過 46 小時的人員。
- 若資料有缺漏或欄位不明，先說明無法可靠計算的原因，不要硬算。

# 注意事項
- 不要把正常工時誤算成加班。
- 不要混入非本月資料。
- 若同一人有多筆紀錄，必須全部加總。
- 若資料單位是分鐘，先統一換算成小時再比較 46 小時門檻。
