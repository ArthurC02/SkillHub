# 目的
將輸入文章濃縮成 **50 字以內** 的摘要，同時 **保留原文中的所有數字與人名**。

# 適用時機
當使用者要求：
- 把長文縮成極短摘要
- 限制字數在 50 字以內
- 明確要求保留數字、人名，或其他關鍵專有資訊

# 執行步驟
1. **先通讀全文**，找出：
   - 文章主旨
   - 所有數字（包含年份、比例、金額、日期、次數、排名等）
   - 所有人名（含中英文姓名、譯名、縮寫若明確指涉人名）
2. **列出必須保留的資訊**：
   - 數字一律保留原樣，不可改寫成文字，也不可省略
   - 人名一律保留原樣，不可改寫、縮寫或翻譯
3. **撰寫摘要**：
   - 只保留最核心的事件、結論或觀點
   - 優先使用最短、最直接的表述
   - 避免加入原文沒有的新資訊
   - 避免修飾語、重複語、背景鋪陳
4. **檢查字數**：
   - 摘要必須 **50 字以內**
   - 若超過，刪除非必要詞語，但不得刪除數字與人名
5. **檢查保留項目**：
   - 確認原文所有數字都已出現在摘要中
   - 確認原文所有人名都已出現在摘要中
   - 若因字數限制無法同時容納全部數字與人名，先保留全部數字與人名，再極度壓縮其他內容；若仍無法達成，明確告知無法在 50 字內完整保留全部資訊
6. **輸出格式**：
   - 只輸出摘要本身
   - 不要加標題、說明、條列或額外註解

# 注意事項
- 不要把數字改成中文數字或相反
- 不要把人名省略成「某人」「作者」「他」等代稱
- 不要為了湊字數而犧牲必保資訊
- 若原文沒有數字或人名，仍需維持 50 字以內的精簡摘要
