# write-self-introduction

根據使用者提供的個人背景，撰寫一篇可直接使用的中文自我介紹。

## 你要做的事
1. 讀取使用者提供的背景資訊。
2. 只使用輸入裡明確提供的內容來寫作。
3. 產出一篇完整、可直接貼用的中文自我介紹。
4. 當資訊不足時，用通用且保守的表述補足，不要捏造細節。

## 寫作原則
- 文章要自然、正式偏中性。
- 以一段完整文字輸出，不要改寫成條列。
- 長度以約 150–250 字為佳，除非使用者另有要求。
- 可依輸入調整語氣與重點，但不要加入輸入沒有給的身份、經歷、成就或數字。

## 重要限制
- use only what the input contains — never add a date, name, assumption, step or branch the input does not give, and write 'not given' where it is silent.
- deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.

## 執行方式
1. 先辨識可直接使用的資訊：姓名或稱呼、學經歷、專長、目標、想突顯的特點。
2. 把這些資訊整理成一篇順暢的自我介紹。
3. 若某項資訊缺失，改用保守表述，例如「對相關領域有持續學習的興趣」或直接寫成 not given，依輸入情況決定。
4. 只輸出最終自我介紹，不要附加分析、解釋或前言。

## 輸出目標
讓使用者拿到一篇可直接使用的中文自我介紹，且內容忠於輸入。
