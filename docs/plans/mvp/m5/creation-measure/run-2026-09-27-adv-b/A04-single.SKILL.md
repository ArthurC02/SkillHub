# 週五業績公告流程

此技能用於把「每週五下午自動把本週業績數字寄給全部門，同時在 Slack 公告」拆成可執行的流程。若目前沒有可用的郵件系統、Slack 權限、資料來源或排程工具，先完成資訊蒐集與流程設計，再交由可用系統實作。

## 先確認需求
1. 確認「本週」的定義：
   - 以週一到週五？
   - 以最近 7 天？
   - 是否依時區計算。
2. 確認「業績數字」的來源：
   - 報表系統、資料庫、試算表、CRM、BI 儀表板或人工整理檔。
3. 確認要公告的指標：
   - 總營收、訂單數、轉換率、達標率、成長率等。
4. 確認收件與公告對象：
   - 全部門的郵件群組名稱或名單。
   - Slack 頻道名稱或 ID。
5. 確認寄送時間：
   - 每週五下午的具體時間點。
   - 若遇假日或系統維護，是否提前或延後。
6. 確認格式要求：
   - 郵件主旨、內文格式、是否附表格或附件。
   - Slack 訊息是否要簡短摘要、連結到完整報表，或附圖。

## 執行流程
1. 取得本週業績數字。
2. 驗證數字完整性：
   - 檢查是否缺值、重複、異常跳動。
   - 若資料不完整，先標記為待確認，不要直接發送錯誤數字。
3. 產出兩份內容：
   - **郵件版**：較完整，適合部門內閱讀。
   - **Slack 版**：精簡摘要，適合快速瀏覽。
4. 在內容中包含：
   - 本週期間。
   - 核心業績數字。
   - 與上週或目標的比較。
   - 必要的說明或提醒。
5. 發送郵件給全部門。
6. 在指定 Slack 頻道公告相同資訊的精簡版。
7. 記錄發送結果：
   - 成功時間。
   - 收件群組與頻道。
   - 是否有失敗或重試。

## 郵件內容建議
- 主旨：`本週業績更新｜YYYY/MM/DD - YYYY/MM/DD`
- 內文結構：
  1. 開頭一句摘要。
  2. 主要數字列表或表格。
  3. 與上週/目標比較。
  4. 補充說明與下一步。

## Slack 公告建議
- 內容保持簡短：
  - 一句摘要。
  - 3 到 5 個關鍵數字。
  - 連結到完整報表或郵件。
- 若公司文化允許，可使用固定格式方便辨識。

## 失敗處理
1. 若無法取得資料：
   - 不要發送空白或猜測數字。
   - 通知負責人補資料。
2. 若郵件發送失敗：
   - 記錄錯誤原因。
   - 重試一次或改由備援群組發送。
3. 若 Slack 發送失敗：
   - 先保留郵件發送結果。
   - 待權限或連線恢復後補發。

## 需要人工確認的事項
- 是否允許自動發送，或需先審核後發送。
- 是否有敏感數字需要遮蔽。
- 是否要同時附上原始資料檔。
- 是否要在節假日調整排程。

## 重要限制
這個技能只能協助整理流程、檢查需求與準備公告內容；若要真正自動寄信、發 Slack 或設定排程，必須使用可用的郵件、Slack 與排程系統完成，且需要相應權限。
