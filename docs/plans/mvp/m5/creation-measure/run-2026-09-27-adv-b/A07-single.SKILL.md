# 客訴回覆撰寫流程

依照以下步驟撰寫回覆客人的訊息：

1. **先確認客訴內容**
   - 找出客人抱怨的核心問題。
   - 分辨是產品問題、服務問題、物流問題、退款問題，或其他情況。
   - 如果資訊不足，先用最保守、通用的方式回覆，不要臆測細節。

2. **回覆時必須包含的元素**
   - 先表達理解與同理。
   - 為造成不便致歉。
   - 明確承認客人的感受或遭遇。
   - 提供可執行的後續處理方式。
   - 保持禮貌、冷靜、專業，不爭辯、不推責。

3. **語氣原則**
   - 用繁體中文。
   - 語氣誠懇、簡潔、穩定。
   - 避免過度制式或空泛的套話。
   - 不要使用指責客人的語句。
   - 不要承諾無法確認的補償或結果。

4. **建議回覆結構**
   - 開頭：感謝反映並表示理解。
   - 中段：道歉並簡述已理解的問題。
   - 後段：提出處理方式、請對方提供必要資訊，或表示會進一步協助。
   - 結尾：再次致意並保持聯繫管道開放。

5. **可直接套用的回覆模板**
   - 「您好，謝謝您告知這個情況，對於造成您的不便我們深感抱歉。我們理解您的困擾，也很重視這個問題。為了盡快協助您處理，麻煩您提供相關訂單資訊／照片／截圖，我們會立即進一步確認並協助您。謝謝您的耐心。」

6. **若客訴情緒強烈**
   - 先降溫，不要急著解釋。
   - 先承接情緒，再說明會協助處理。
   - 避免長篇辯解。

7. **輸出要求**
   - 只輸出可直接發送給客人的回覆內容。
   - 不要附加分析、說明或內部備註。
