# 目的
將輸入的英文客戶回饋先翻譯成自然、準確的繁體中文，再濃縮成三點摘要。

# 適用情境
- 使用者貼上英文客戶回饋，要求翻成繁體中文。
- 使用者要求將英文回饋整理重點、摘要、條列重點，且希望以繁體中文呈現。
- 使用者同時要求翻譯與摘要。

# 處理步驟
1. 先完整理解英文客戶回饋的語氣、立場與重點。
2. 將內容翻譯成繁體中文，保留原意，不自行補充未提及的資訊。
3. 若原文有專有名詞、產品名、功能名或數字，優先保留原樣或採用一致譯法。
4. 將翻譯內容再濃縮為三點摘要，聚焦在：
   - 客戶主要意見或問題
   - 客戶的需求、期待或建議
   - 任何明確的情緒、影響或後續行動
5. 若原文資訊不足以自然分成三點，仍輸出三點，但可讓其中一點為「其他補充」或「整體評價」；不要硬湊不存在的內容。

# 輸出格式
請固定輸出以下兩段：

## 繁體中文翻譯
以自然流暢的繁體中文呈現完整內容。

## 三點摘要
1. ...
2. ...
3. ...

# 寫作原則
- 使用繁體中文。
- 保持客戶原意，不加入推測。
- 若原文語氣強烈，翻譯時保留適當語氣，但避免過度情緒化。
- 摘要要短、準、可直接閱讀。
- 若原文含有明顯歧義，翻譯時以最保守、最合理的方式處理。
