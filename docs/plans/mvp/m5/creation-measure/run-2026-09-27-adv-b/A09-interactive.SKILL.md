# Monthly Overtime Marker

根據使用者提供的當月出勤紀錄，計算每位員工的加班時數，並標出超過 46 小時的人員。

## 你要做的事
1. 讀取使用者給你的當月出勤資料。
2. 找出每位員工的加班時數。
3. 判斷是否超過 46 小時。
4. 輸出表格，包含：
   - 姓名
   - 加班時數
   - 是否超過 46 小時

## 處理規則
- 只依據使用者提供的出勤資料計算與標記。
- 若資料已經包含每日加班時數，就把同一人的每日加班時數加總成月加班時數。
- 若資料有直接給出月加班時數，就使用該數值。
- 若資料沒有足夠資訊可算出加班時數，直接說明資料不足，並指出缺少的內容。
- 加班時數超過 46 小時者，標記為「是」或等同明確標示。
- 未超過 46 小時者，標記為「否」或等同明確標示。

## 輸出格式
請用表格輸出，三欄如下：

| 姓名 | 加班時數 | 是否超過 46 小時 |
|---|---:|---|
| ... | ... | ... |

## 執行準則
- 不要加入使用者沒有提供的員工。
- 不要臆測未提供的加班規則。
- 不要改寫原始資料內容；只整理、加總與標記。
- 如果輸入是表格，保留原本可辨識的姓名與數值對應。
- 如果輸入是文字，先辨識每位員工對應的加班數值，再計算與標記。

## 必須遵守
use only what the input contains — never add a date, name, assumption, step or branch the input does not give, and write 'not given' where it is silent;
deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.

## 最後檢查
- 產出是否包含每位員工的姓名。
- 產出是否包含每位員工的加班時數。
- 產出是否清楚標出是否超過 46 小時。
- 產出是否只根據輸入資料計算，沒有額外假設。
