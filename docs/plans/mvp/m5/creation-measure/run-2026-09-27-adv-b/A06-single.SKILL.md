# 自我介紹撰寫技能

當使用者要寫自我介紹時，依下列流程協助完成。這個技能只負責寫作與整理內容；如果缺少關鍵資訊，先提出最少必要的問題再動筆。

## 1. 先確認使用情境
先判斷自我介紹要用在哪裡，因為不同情境長度與語氣不同。必要時詢問：
- 用途：面試、課堂報告、社群簡介、活動開場、履歷、申請文件、其他
- 目標讀者：主管、老師、同學、陌生網友、活動參與者等
- 語言：中文、英文，或雙語
- 長度：短版、中版、長版，或指定字數
- 語氣：正式、自然、親切、專業、活潑

如果使用者已經提供足夠資訊，就直接寫，不要多問。

## 2. 蒐集內容素材
若資訊不足，優先詢問以下項目中最重要的幾項：
- 姓名或稱呼
- 身分／職業／年級／科系
- 主要經歷或專長
- 個人特色或優勢
- 興趣、價值觀、目標
- 想讓讀者記住的一句話

若使用者只想要一篇通用自我介紹，可用以下結構引導：
1. 開頭：姓名與基本身分
2. 中段：學經歷、專長、個性或興趣
3. 結尾：目前目標、期待或一句收尾

## 3. 撰寫原則
撰寫時遵守以下原則：
- 內容真實，不自行捏造經歷、證照、職稱或成就
- 依情境調整正式程度
- 句子簡潔，避免空泛形容詞堆疊
- 以第一人稱撰寫，除非使用者要求第三人稱
- 若資訊很少，寫成通用但自然的版本，不要硬編細節
- 若使用者提供條列資料，可整理成順暢段落

## 4. 建議結構
### 短版自我介紹
- 1 段，約 50–120 字
- 適合社群、活動報到、簡短開場

### 中版自我介紹
- 2–3 段，約 120–250 字
- 適合面試、課堂、申請、一般場合

### 長版自我介紹
- 3–5 段，約 250 字以上
- 適合正式申請、演講開場、詳細履歷摘要

## 5. 產出格式
輸出時優先提供：
1. 一篇可直接使用的自我介紹
2. 若有需要，再附上 1–2 個不同語氣或長度的版本
3. 若資訊不足，先列出你需要的問題，等使用者回答後再完成

## 6. 範例寫法
若使用者沒有提供太多資訊，可先給一個通用模板式版本，例如：
- 「大家好，我叫＿＿＿，目前是＿＿＿。平常我對＿＿＿很有興趣，也持續在＿＿＿方面學習與累積經驗。我個性＿＿＿，做事＿＿＿，希望未來能在＿＿＿持續成長，謝謝大家。」

## 7. 編修與優化
完成初稿後，檢查：
- 是否符合指定字數與情境
- 是否有重複或冗長句子
- 是否語氣一致
- 是否有不自然或過度誇大的表達

若使用者要求「更口語」「更正式」「更有自信」「更簡短」，直接重寫成對應版本。
