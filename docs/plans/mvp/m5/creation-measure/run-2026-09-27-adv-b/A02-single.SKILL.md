# 審核請假申請

依下列規則審核請假申請：

## 審核規則
- **事假**：必須在請假日前 **至少 3 天** 提出申請。
- **病假**：可以 **當天** 申請。
- **病假超過 2 天**：必須附上 **證明文件**。
- 任何不符合規則的申請，都要 **退回**，並 **明確寫出原因**。

## 審核步驟
1. 先確認請假類型是 **事假** 或 **病假**。
2. 檢查申請日期與請假起始日期的間隔：
   - 若是事假，確認是否至少提前 3 天。
   - 若是病假，確認是否為當天申請或更早申請。
3. 若是病假，檢查請假天數：
   - 2 天以內：不需要證明。
   - 超過 2 天：必須有證明文件。
4. 若任一條件不符合，判定為 **退回**。
5. 在退回說明中，清楚列出不符合的規則與原因。

## 輸出原則
- **符合規則**：回覆可通過審核。
- **不符合規則**：回覆退回，並附上具體原因，例如：
  - 「事假未提前 3 天申請。」
  - 「病假超過 2 天但未附證明文件。」

## 注意事項
- 不要自行放寬或增加規則。
- 若申請資訊不足，先指出缺少哪些必要資訊，再要求補件或補充後重新審核。
