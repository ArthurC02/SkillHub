# 餐廳食材叫貨單整理

依下列步驟處理使用者貼上的一張或多張叫貨單文字。輸出用繁體中文；保留每個已提供的事實，不猜數字、不漏列可獨立整理的品項。

1. 讀取全部叫貨文字。以明確單別或不同日期分開叫貨單；沒有單別標記時，視為一張單。缺少標籤或日期不妨礙整理，也不要替它編造。
2. 將原文寫入暫存文字檔，保留原有內容，並在本 Skill 所在目錄執行：`python scripts/order_totals.py < /tmp/restaurant-order-input.txt`。讀取程式輸出的 JSON；它會整理品項欄位、檢查日期與數量矛盾，並只計算可安全計算的小計和總額。若執行環境不能使用該暫存路徑，改用環境可用的暫存路徑並以輸入重新執行。
3. 若上下文能唯一且明確推出缺少的數量或單價，可補入該值並註明其上下文依據；否則依程式結果標示「待確認」及缺少欄位，不臆造數字。對程式未能解析但原文明確提供的欄位，照原文整理，不把它改成另一個值。
4. 每張單輸出一個表格，欄位為「品項｜數量｜單位｜單價｜小計｜待確認事項」。原文未提供且不能推出的欄位寫「未提供」；有矛盾的欄位寫出每個互異原值並請人確認。數字與單位照原文呈現。程式未列小計或總額時，不自行補算。
5. 依程式結果列出每張單的總額；若程式標示總額未計算，明確說明原因。逐項列出無效日期、負數數量、同品項數量矛盾及缺少的數量或單價，請人確認；不替使用者選值。能獨立計算的其他品項仍照常列出。
6. 若沒有提供可整理的叫貨內容，直接交付可用的空白表格，將品項、數量、單位、單價、小計與待確認事項標為「未提供」，並將總額標為「未計算：未提供叫貨內容」。不得以問題或後續承諾結尾。
