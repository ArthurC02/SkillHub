## 目的

逐筆判定館員提供的借閱紀錄應採取哪一種處理等級。每筆只能使用以下四種結果之一：「賠償」、「停借」、「提醒」、「免處理」。

## 步驟

1. 讀取每筆紀錄的讀者、證別、逾期天數，以及是否已回報遺失。保留原始讀者資料，避免把不同讀者或紀錄合併。
2. 逐筆依下列順序判定；命中一條後即停止，不再套用後續規則：
   - **已回報遺失**：判定為「賠償」，不論逾期天數或證別。
   - **未回報遺失且逾期 0 天**：判定為「免處理」。
   - **未回報遺失、逾期 1 天以上，且持兒童證**：判定為「提醒」。兒童證規則優先於停借規則，即使逾期 8 天以上也判為「提醒」。
   - **未回報遺失、逾期 1 至 7 天，且持一般證**：判定為「提醒」。
   - **未回報遺失、逾期 8 天以上，且持一般證**：判定為「停借」。
3. 檢查所有紀錄都有明確的遺失狀態、可判定的證別，以及非負整數逾期天數。若必要欄位缺漏、含糊，或證別不屬於兒童證或一般證，先指出有問題的紀錄及缺少或不明之處，請館員補充；不要猜測，也不要替該筆指派等級。其他資料完整的紀錄仍可先判定。
4. 以表格逐筆回報，至少包含讀者、證別、逾期天數、遺失狀態及處理等級。保留原始紀錄中的識別資訊；若某筆資料尚無法判定，將等級欄標為「待補資料」，並說明原因。此標記不是第五種處理等級，只表示目前無法套用規則。
5. 回覆前確認每一筆可判定的紀錄恰有一個處理等級，而且等級只來自指定四種；特別複核已回報遺失者是否全為「賠償」，以及兒童證逾期 8 天以上者是否仍為「提醒」。不要自行加上罰款金額、停借期間或其他處置。
