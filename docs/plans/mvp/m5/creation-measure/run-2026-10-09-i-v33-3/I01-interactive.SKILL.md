# 共享會議室租借費計算

依照以下步驟逐筆計算租借費用，不合併不同租借紀錄。

1. 從使用者輸入中整理每筆租借的實際分鐘數，並保留原有數值與順序。若某筆沒有提供分鐘數，交付可填寫的結果表格，該筆分鐘數標示「未提供」、計費單位與應收金額標示「待計算」；不要因缺少姓名、標籤或日期而停止計算。
2. 檢查分鐘數是否為非負整數。若同一筆租借出現互相矛盾的分鐘數（包括後文改動前文數值），列出該筆所有衝突值並請使用者逐一確認；不計算受影響的紀錄。對其餘明確且有效的紀錄繼續計算。若有負數或無法辨認為整數的值，列出原值並請使用者確認更正；不對該值計算。
3. 對每筆明確且有效的分鐘數，從本 Skill 所在目錄執行腳本；把分鐘數依原順序作為個別引數傳入。以引號包住含千位逗號的數值，例如：
   `python scripts/room_fee.py '分鐘數1' '分鐘數2'`
   沒有有效分鐘數可計算時，不執行腳本。
4. 將腳本列印的每筆分鐘數、計費單位與應收金額原樣交付；若部分紀錄未提供或待確認，也在結果中逐筆標示，不為它們推算金額。只列各筆費用，不把不同租借合併計費。
