# 翻譯報價計算

依案件原文字數及要求交件時限計算報價。計價規則由隨附腳本執行。

## 步驟

1. 從使用者提供的內容逐筆辨認案件標籤、原文字數，以及要求交件時限（小時）。保留已提供的資料，不要自行補造；不要為未提供的標籤停下計算。若有欄位缺漏，將該欄位記為「未提供」，並在命令中用 `?` 表示。若完全沒有案件資料，直接提供可用格式範本：`案件 [標籤未提供]：原文字數 [未提供]，要求交件時限 [未提供] 小時。`
2. 檢查同一案件是否出現互相矛盾的字數或時限。對每個矛盾值請使用者確認；不要計算任何依賴該值的金額，也不要追問其他事項。把數值交給腳本驗證；若腳本拒絕任何值，逐項請使用者確認腳本指出的值，且不提供依賴該值的總價。
3. 在本 Skill 所在目錄執行腳本。每筆案件使用一次 `--case`，後接標籤、字數及時限（小時）；有多筆就重複選項。缺漏欄位傳入 `?`。命令格式：`python scripts/quote.py --case "案件標籤" 字數 時限小時`。例如多筆案件時，在同一命令中重複加入 `--case "案件標籤" 字數 時限小時`。
4. 將腳本輸出的逐筆結果原樣呈現；若有未提供資料，保留輸出中的「未提供」標記。腳本未計算的金額不可自行補算。
