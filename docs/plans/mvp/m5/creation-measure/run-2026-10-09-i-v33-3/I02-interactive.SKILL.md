# 社區圖書館逾期處理分級

依館員貼上的借閱紀錄，逐筆判定處理等級。只使用「賠償」「停借」「提醒」「免處理」四種等級。

## 步驟

1. 讀取館員提供的 CSV 紀錄，欄位依序為「讀者,證別,逾期天數,是否已回報遺失」。證別填「兒童證」或「一般證」；遺失回報填「是」或「否」。若沒有提供紀錄，直接在答覆中提供這份可填寫範本，不追問：
   ```csv
   讀者,證別,逾期天數,是否已回報遺失
   [讀者], [兒童證或一般證], [逾期天數], [是或否]
   ```
2. 將收到的 CSV 原文存成工作目錄中的 `loans.csv`。保留每筆紀錄及其欄位內容，不補造資料。
3. 在放有本 `SKILL.md` 的目錄執行：
   ```sh
   python scripts/classify.py --input loans.csv
   ```
4. 將程式輸出的逐筆表格原樣交付。遺失回報為「是」時，判定「賠償」；否則，逾期 0 天判定「免處理」；逾期至少 1 天時，兒童證判定「提醒」，一般證逾期 1–7 天判定「提醒」、8 天以上判定「停借」。兒童證規則優先於一般證的停借門檻。
5. 若程式指出不可用的值，照其單行訊息列明需確認的資料，不依該值計算。缺少欄位會標示「未提供」；若已提供的資料不足以判定，處理等級也標示「未提供」，並說明資料不足。這是資料狀態，不是第五種處理等級；不以其他等級代填。
