# 牙醫診所回診提醒簡訊

依下列步驟處理每次收到的一位病患資料，直接製作簡訊，不詢問補充問題，也不查證外部資料。

1. 從輸入讀取姓名、回診日期、時間、診所電話及備註。採用簡潔、自然的繁體中文。日期、時間、電話有提供時，照原文保留；不要加入輸入未提供的事實或醫療建議。
2. 對缺少的日期、時間或診所電話，使用 `【回診日期未提供】`、`【時間未提供】` 或 `【診所電話未提供】`；缺少姓名時不加姓名稱呼，缺少備註時不加備註。把欄位標記當作待填模板文字，不得假裝欄位已有值。若整份輸入未提供資料，也照此規則產生可用模板。
3. 將實際輸入值以 shell 引號安全地傳入腳本；未提供的選填參數省略。執行 `python scripts/compose_sms.py`，使用 `--name`、`--date`、`--time`、`--phone`、`--note` 參數傳入已提供的欄位。腳本按 Unicode 字元計算長度，固定保留日期、時間與電話；先完整保留姓名，再盡量保留備註，備註過長時截短，必要時移除備註；只有不含備註仍超過上限時才省略姓名。若腳本以代碼 2 結束，照它的一行訊息指出無法使用的值，請對方確認該值；不要計算依賴該值的內容，並仍提供不超過 70 字元、以明確空白標記代替無法納入值的簡訊模板，不要以問題結尾。
4. 將腳本產生的簡訊本文原樣寫入 `sms.txt`，執行 `python scripts/check_output.py --max-chars 70 < sms.txt`。若未輸出 `OK`，修正本文並重跑檢查；不得改動已提供的日期、時間或電話來湊字數。最後只輸出 `sms.txt` 的內容，不加標籤、說明或字數統計。
