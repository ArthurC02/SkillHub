## 工作流程

1. 讀取客人的訂單訊息，只依訊息整理報價；不要查網路、使用外部價目資料或自行補造商品事實。
2. 逐項辨識品名、數量、單位、單價，以及外送車資。保留訊息給出的品名與數字；將「一打」換算為 12。數量沒寫時採用 1，並在輸出註明「數量未提供，依預設以 1 計」。不得把車資當成品項。
3. 單價寫「免費」或「0 元」時，照樣列出品項並以 0 計算小計。沒有提供單價時，單價標示「待確認」，不猜價，並說明總額尚未包含該品項。若同一品項的數量或單價出現互相矛盾的值，保留各個原始值、標示「需確認」並請客人確認；不計算依賴該值的小計或總額。請確認的敘述用陳述句，不以問題結尾。
4. 為每項建立一個計算參數，格式為 `品名|數量|單位|單價`，逐項傳給計算腳本。單價用訊息中的原始表示法；缺價用 `?`；有矛盾的數量或單價用 `!` 加上各個互相矛盾的原始值與其脈絡。免費品項使用 `免費` 或 `0 元`。數量缺漏依步驟 2 傳入 `1`。單位或品名未提供時，該欄留空；不要因此停止可做的計算。
5. 從包含 `SKILL.md` 的目錄執行：`python scripts/quote_orders.py --item '品名|數量|單位|單價'`。每個品項都加一個 `--item` 參數；有車資時另加 `--delivery-fee '金額'`。逐字呈現腳本輸出的報價；另外依原訊息補上必要的確認說明。不要把車資加進任何小計或品項總額。
6. 若訊息沒有提供任何品項，提供可直接填用的報價範本，並以「［未提供］」標示缺少的內容；此時不執行計算腳本。若有品項但缺少其他資訊，仍完成報價，清楚標示未提供的欄位，不以問題結尾。
7. 輸出繁體中文，包含每項的品名、數量、單位、單價與小計，以及品項總額和備註。數量依預設補為 1 時說明該預設。車資金額只在備註提及，並註明「司機到府另收、不計入品項總額」。凡資料未提供且無法推得的欄位，標示「未提供」或依上文標示「待確認」；不得把已提供的事實改標為未提供。若有未確認品項，列出目前可計算的總額並清楚說明哪些品項尚未計入。最後直接交付完整報價，不以問題、計畫或承諾結尾。
