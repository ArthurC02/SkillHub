# 房租催繳通知信

依照以下步驟撰寫一封房東可直接貼上寄出的通知信。

1. **確認必要資料**：檢查是否有房客姓名、欠繳月份、欠繳金額及明確的繳款期限。若有必要資料缺漏或內容互相矛盾，先向房東詢問，不要猜測或自行填入日期、金額或月份。
2. **核對金額與明細**：依房東提供的資料逐項列出欠繳月份及對應金額；若只提供總額，就列出總額，不要推算各月金額。保留房東使用的幣別與數字格式；若未提供幣別，不要自行指定。
3. **處理繳款資訊**：只在房東提供時列出付款方式、帳戶、收款人、物件地址、聯絡方式或其他付款指示。若未提供，不要編造，也不要以待填空格充當可直接寄出的內容。
4. **撰寫通知信**：使用繁體中文，語氣禮貌、清楚且堅定。包含適當的主旨、稱呼、欠繳明細、欠繳總額（僅在可由提供資料確認時列出）、明確繳款期限、付款指示（如有）、請房客完成付款或聯絡房東的請求，以及禮貌結尾。期限照原資料呈現，避免改寫成可能造成歧義的相對日期。
5. **避免未經證實的內容**：不得自行加上滯納金、利息、額外費用、違約後果、驅逐或法律行動的威脅，也不得宣稱信件符合特定地區法律。若房東要求加入法律後果但沒有提供可核實的依據，請提醒其先確認適用規定，並提供不含該主張的通知信。
6. **輸出格式**：若資料足夠，直接輸出完整信件，不加前言、分析或多餘說明，讓房東可以複製寄出。若資料不足，簡短列出需要補充的資料，暫不輸出帶有猜測或空白欄位的信件。

建議信件結構：

- 主旨：租金繳款提醒／租金催繳通知
- 稱呼房客
- 說明目前有租金尚未繳付
- 以清單列出月份與金額，並列出可確認的總額
- 清楚寫明繳款期限與已提供的付款方式
- 請房客於期限前完成付款；若已付款，請房客忽略通知或提供付款資訊以便核對
- 房東署名（僅在房東提供姓名時列出）
