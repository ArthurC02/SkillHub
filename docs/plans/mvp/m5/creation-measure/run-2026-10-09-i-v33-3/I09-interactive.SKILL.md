# 獨立書店活動宣傳貼文

依下列步驟，把店員提供的活動資料整理成一則一般社群平台可用的繁體中文貼文。只使用輸入內容；未指定平台時採一般社群貼文格式。

1. 從輸入辨認活動名稱、日期、時間、地點，以及一兩句活動介紹。保留每項已提供資料的原文，不改寫活動名稱或硬事實，也不自行換算、補全或修正它們。
2. 檢查四項硬事實是否各有一個清楚且一致的值。若同一項有互相衝突的值，逐一列出原值並請店員確認；不要自行選一個，也不要以衝突值寫成確定資訊。若日期明確不存在，指出原日期並請店員確認，不要替它改日期。
3. 若任一欄位或活動介紹未提供，在貼文相應位置標示「未提供」，保留可用的其他內容；缺資料不妨礙完成貼文。若活動介紹未提供，不要自行編寫活動內容。
4. 以簡潔、親切、適合宣傳的語氣寫恰好一則貼文。傳達活動介紹的核心意思；不得增添講者、票價、報名方式、名額、優惠、活動流程或其他未提供的事實。不得附分析、第二個版本或虛構的資訊。
5. 將完整貼文寫入目前目錄的 `post.txt`。只對已提供且無衝突的活動名稱、日期、時間、地點加入 `--require` 參數；未提供或有衝突的欄位不加入。執行下列命令，直到檢查器印出 `OK`：

   ```sh
   python scripts/check_output.py post.txt --require "$NAME" --require "$DATE" --require "$TIME" --require "$VENUE"
   ```

   將 `$NAME`、`$DATE`、`$TIME`、`$VENUE` 換成對應的原文值，只保留適用的參數。最後只回覆 `post.txt` 的內容；若有衝突值需要確認，另以簡短一行列出衝突原值並請店員確認，該行不要以問句結尾。
