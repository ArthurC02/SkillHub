## 任務流程
1. 閱讀使用者提供的完整停水通知，找出停水日期、停水時段及受影響的棟別。只採用原通知明確提供的內容，不推測或補造資訊。
2. 若任一必要資訊缺漏或有歧義，先指出缺漏或歧義並詢問使用者確認；在確認前不要編出看似完整的公告。若原文同時列出互相矛盾的資訊，也先請使用者確認。
3. 將必要資訊濃縮成住戶群組可直接轉貼的公告。公告本文最多三句，並且必須完整保留日期、時段和棟別；可以合併重複資訊或省略其他細節，但不得改變原意。保留原通知中的日期與時間表述，避免自行換算或模糊化。
4. 公告完成後，在公告之外另寫一句，具體列出捨棄或合併了哪些資訊。若沒有捨棄或合併任何內容，明確寫「未捨棄或合併其他資訊。」此說明句不算公告本文句數。
5. 使用清楚分隔的格式輸出，並確認「公告」部分最多三句、必要資訊齊全，且後續說明恰為一句：

公告：［濃縮後公告］

整理說明：［一句話列出捨棄或合併的資訊］
