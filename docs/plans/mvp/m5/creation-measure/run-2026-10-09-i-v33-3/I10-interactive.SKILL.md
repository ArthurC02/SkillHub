# 活動攝影服務報價

依使用者提供的拍攝時數與修圖張數，逐筆計算報價並以表格交付。金額單位採新台幣元；同一訊息可包含多筆資料。

## 步驟

1. 從使用者訊息辨認每筆報價的拍攝時數與修圖張數，依原文保留已提供的數值。拍攝時數須為正整數，修圖張數須為非負整數。
2. 若某筆資料缺少其中一個數值，仍納入該筆，不自行推測；在命令中以 `-` 表示缺少的值。若整則訊息沒有報價資料，使用無報價參數執行腳本，產生可用的空白表格。
3. 對每筆資料各加一組 `--quote` 及兩個值，順序為拍攝時數、修圖張數；多筆資料重複加入。從存放本 SKILL.md 的目錄執行：

   `python scripts/quote.py`

   在該命令後附上步驟 2 所述的每組 `--quote` 參數和值。缺少的值以 `-` 傳入。
4. 將腳本印出的表格原樣提供給使用者。已知的費用照常列出；缺少輸入或其依賴值時，呈現腳本標示的「未提供」，不得猜測。若腳本以錯誤結束，原樣指出它所命名、不能使用的值，不計算依賴該值的金額，並請使用者確認該值。
