## 工作流程

1. 從使用者提供的內容整理房客姓名、各欠繳月份與該月金額、繳款期限；不補問資料。每個未提供的欄位在信中標為「【房客姓名未提供】」、「【欠繳月份未提供】」、「【金額未提供】」或「【繳款期限未提供】」。
2. 保留已提供的每項資料原文，包括日期寫法及金額寫法。只將數值用於檢查及加總；沒有提供幣別時，不加幣別。不要補入付款方式、聯絡資訊、逾期費用、法律後果或其他未提供的事實。
3. 將每筆欠款整理為月份與金額。若同一月份出現不同金額，或月份、日期、金額不是可用的值，列出每一個無法採用的原值，明確請房東逐項確認；不要計算依賴這些值的合計。其他無疑義的欄位照常使用，不要追問其他事項。日期按西曆檢查是否存在；金額不得為負數。
4. 在含有完整月份及金額的每筆資料都可用時，從本 Skill 所在目錄執行 `python scripts/rent_total.py`，將實際提供的資料以 `--tenant`、`--deadline` 及重複的 `--item 月份=金額` 引數傳入；只傳入已提供的姓名及期限引數。每個欠款月份各傳一個 `--item`。金額引數保留原有數字表示，月份及日期使用使用者提供的原文。若有月份已提供但其金額未提供，該筆以空金額傳入，例如 `--item '2026年7月='`。呈現腳本輸出的合計，不自行重算。若腳本以代碼 2 結束，照錄它指出的值並請房東確認；不要呈現依賴該值的合計。
5. 寫出一封繁體中文、禮貌明確且可直接複製的信，包含主旨、稱呼、逐月欠款明細、欠款合計及繳款期限。缺少的資料以步驟 1 所列標記呈現；若無法計算合計，明確說明欠款合計因何未能計算，不要猜測。凡有無法採用的值，在信後以一行列出原值並請房東確認。不要以問題結尾；提供信件本身，不要只給撰寫計畫。
6. 另以一行結尾說明：「寄送：本 Skill 無法替你寄出；須由房東自行貼上並寄送。」只準備信件，不宣稱已寄出。
