## 使用時機
收到管委會提供的完整停水通知，並要整理成住戶群組公告時使用。只根據輸入內容，不補充通知中沒有的事實。

## 步驟
1. 從通知中找出停水日期、停水時段及受影響棟別；照通知原文保留每項已提供的值。另記下其他資訊，以便說明哪些內容被省略或合併。
2. 比對通知中指向同一項停水資訊的值。若日期、時段或棟別有不同值，逐一列出相衝突的值，請使用者確認；不要自行選定，也不要把相衝突的值寫成確定資訊。不要為了未要求的名稱、標籤或日期提問。
3. 寫出「住戶公告」及公告本文。本文最多三句，以「。」「！」「？」計算句數；保留日期、時段和棟別。已提供的值照原文寫；缺少的必填資訊標為「未提供」，並以標記的空白補成可用模板，例如「【停水日期：未提供】」。不要把未提供的資訊標成待確認。只在不擠占必填資訊的句數時，納入有用的其他細節；其餘省略或合併。
4. 在公告之外加上「資訊處理說明：」並用一句話說明省略或合併了哪些資訊。說明須點出通知中實際省略或整併的內容類別，例如作業原因、住戶應採取的措施、施工限制、進度安排或致歉；不可只用籠統描述帶過。只列通知中確實出現、且未納入公告本文的內容，不得臆造。沒有其他資訊被省略或合併時，明說「未省略或合併其他資訊」。如有互相矛盾的必填值，在同一句中列出每組衝突值並以陳述句請使用者確認；不要以問題收尾。不得另加第二句說明。
5. 把完整答案寫入 `answer.txt`，包含公告標題、公告本文及那一句資訊處理說明。依確認的標點規則自行確認公告本文至多三句，然後從存放本 SKILL.md 的目錄執行：
   ```sh
   python scripts/check_output.py --max-sentences 4 --require "住戶公告" --require "資訊處理說明" < answer.txt
   ```
   若未輸出 `OK`，修改 `answer.txt` 後重跑；最後只回覆 `answer.txt` 的內容，不附加其他文字。
