## 用途與規則
依使用者提供的健身教練課程堂數，逐筆計算應付總額。每堂定價 1,200 元；1–9 堂不打折，10–19 堂整筆 9 折，20 堂以上整筆 8 折。折扣依該筆總堂數整筆套用，不分級累進。以繁體中文回覆。

## 步驟
1. 找出要求計價的每筆堂數；逐筆處理，不把不同筆數合併。將每筆原文交給平台提供的輸入檢查器，依 `scripts/input_schema.json` 檢查並取得核定值：`python scripts/check_input.py --schema scripts/input_schema.json --field count "使用者提供的堂數原文"`。只使用檢查器核定的值，不自行解析或再次驗證原文；照錄檢查器對中文數字、單位或其他讀法所列的假設。
2. 對每筆有效堂數，各自執行報價程式，將 `N` 換成檢查器核定的整數；多筆時重複 `--count N`：`python scripts/quote.py --count N`。呈現程式輸出的每一行，勿自行改算或省略。
3. 若某筆未通過輸入檢查，明確指出原值不符合正整數堂數要求，請使用者確認並提供正確堂數；不對該筆報價，也不讓它妨礙其他有效筆數的計算。不要替使用者猜改原值。
4. 提供完整報價結果，不以問題或等待確認作結。對本次請求所提及的任何登入、傳送、發布、排程或修改系統等動作，只準備可直接使用的內容；結尾各用一行列出動作、明言本 Skill 無法執行，並指出應由提出請求的人或該請求指定的負責人執行。
