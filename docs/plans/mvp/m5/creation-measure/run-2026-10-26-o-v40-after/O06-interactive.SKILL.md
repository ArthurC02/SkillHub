# 計程車車資試算

使用者要求試算這套車資，或提供一筆／多筆行程資料時，依以下步驟逐筆計算並整理結果。只採用本 Skill 所列費率，不推算其他地區、時段或附加費。

## 步驟

1. 逐筆讀取行程標籤、里程及夜間狀態。里程可用公里或公尺表示；夜間狀態由使用者提供，「是」代表夜間搭乘，「否」代表非夜間。不要從時間自行判斷夜間狀態。
2. 對每筆有提供的里程，將原文放入 `MILEAGE`，執行 `python scripts/check_input.py --mileage "$MILEAGE"`。只使用檢查器解析後的公里數；保留並在回答中照錄檢查器列出的讀法假設。不可自行重新解析或驗證原始里程。若里程未提供，在結果表中標為「未提供」，不要替它計價。
3. 對每筆已檢查的里程，將檢查器給出的公里數放入 `CHECKED_MILEAGE`，將使用者提供的「是」或「否」換成 `yes` 或 `no` 放入 `NIGHT`，執行：
   `python scripts/taxi_fare.py --mileage "$CHECKED_MILEAGE" --night "$NIGHT"`
   將腳本輸出的結果用於該行程。若必要欄位未提供，在結果表標為「未提供」並指出缺少的欄位；不要自行填入行程資料。
4. 將所有行程整理成表格，列出行程標籤、使用者原文中的里程、使用者原文中的夜間狀態及車資。無效里程須標示無效且不列車資；不要因此略過其他有效行程。照錄檢查器的讀法假設，並簡短說明無效里程不計價。

## 費率與無效里程

費率只由 `scripts/taxi_fare.py` 計算：起跳 85 元，含前 1.25 公里；超過部分每 200 公尺或不足 200 公尺均加收 5 元；夜間另加 20 元。里程不大於 0 時標示無效、不計價。不要在回答中手算或另行改寫腳本算出的金額。
