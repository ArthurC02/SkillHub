# 電影院票價試算

使用者提供一筆或多筆觀影資料時，依年齡及場次計算票價，並以簡潔表格逐筆呈現。只處理固定票價，不加入其他票種、折扣或費用。

## 步驟

1. 從使用者提供的資料逐筆讀取識別標記（若有）、年齡及場次；識別標記只用來對應結果，不是必填。保留使用者寫出的原始內容，不改寫或猜測未提供的資料。
2. 先對每筆資料執行平台提供的輸入檢查器 `python scripts/check_input.py`，並依 `scripts/input_schema.json` 檢查年齡。檢查器若將中文數字讀作數值，採用該讀法並在結果旁照原文列出檢查器輸出的假設。檢查器拒絕的年齡標示為「年齡無效」，不計該筆票價；仍繼續處理其他資料。若同一筆資料明確給出互相矛盾的年齡，標示「年齡互相矛盾，無效」，不計該筆票價；其他資料照常計算。不要把無效值改成另一個數字。
3. 對檢查通過的每筆資料，使用檢查器確認後的年齡執行 `python scripts/ticket_price.py --age "$age" --session "$session"`，將該筆年齡與場次帶入對應參數。保留腳本輸出的票價。場次只能是「平日」或「假日」；若場次無法使用，依腳本訊息指出該筆場次無效，不輸出票價，並繼續處理其餘資料。若腳本拒絕參數，修正傳入參數後重跑，不要留下空白結果。
4. 以表格列出每筆資料的識別標記（若有）、原始年齡、原始場次及票價或無效原因；不省略使用者提供的有效資料。每一筆有中文數字讀法假設的結果旁，逐字抄錄檢查器輸出的假設。只呈現已知或可由輸入算出的內容；未提供的欄位標示為「未提供」，不要因此停止計算。
5. 如使用者要求執行登入、傳送、發布、排程或其他外部動作，先準備可直接使用的內容；最後逐項用一行說明該動作無法由本 Skill 執行，並指出須由提出要求的人或其指定負責人執行。
