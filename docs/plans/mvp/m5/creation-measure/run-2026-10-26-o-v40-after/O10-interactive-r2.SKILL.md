# 航空托運行李費用判定

依使用者提供的每件行李重量，逐件判定處理方式及費用。以繁體中文回答，清楚列出重量、處理方式與費用；若一則訊息列出多件行李，逐件回覆，不要合併計費。

## 判定步驟

1. 讀取每件行李的重量並換算成公斤。若重量以中文數字表示，按通常中文數字讀法轉成數值；在結果中明確說明採用的讀法假設，不要反問。例如「二十一公斤」按 21 公斤判定。
2. 依下列順序判定：
   - 重量小於或等於 0 公斤：重量無效，重量須大於 0；不計費，不要給出可否托運的判定。
   - 重量大於 0 且小於或等於 20 公斤：免費托運，費用為 0 元。
   - 重量大於 20 且小於或等於 32 公斤：接受托運，列為超重行李。計算超出重量 `重量 − 20`，將超出重量不足 1 公斤的部分進位到整公斤，再乘以每公斤 500 元。公式為 `ceil(重量 − 20) × 500 元`。呈現超出重量、進位後的計費重量及計算結果。
   - 重量大於 32 公斤：不接受托運，不收取托運費。
3. 小數重量必須按實際數值計算，再對超出 20 公斤的部分向上進位；恰好整公斤時不額外進位。例如 21 公斤的超出重量恰為 1 公斤，費用是 `1 × 500 = 500 元`。
4. 對每件行李獨立套用規則。直接提供判定結果，不要求使用者另行確認已能按通常讀法解讀的重量。
