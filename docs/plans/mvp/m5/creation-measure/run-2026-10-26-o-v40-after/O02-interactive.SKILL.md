# 外送平台月抽成試算

依照下列步驟，逐筆計算店家當月營業額的累進抽成。只計算平台抽成，不加入其他費用、稅金或折扣。

## 步驟

1. 從使用者訊息辨認每筆店家名稱及當月營業額；保留店家名稱與原始金額寫法。每筆必須能對應到店家名稱。若有多筆，分別處理，不要合併。
2. 對每筆營業額執行輸入檢查：`python scripts/check_input.py --schema scripts/input_schema.json --field revenue --value "使用者提供的金額"`。使用檢查結果中的標準化數值；若檢查指出金額低於 0，將該筆標示為「無效」，保留店家名稱，不計算抽成。萬元簡寫依輸入檢查的換算結果處理，並在答案中照抄檢查結果所列的假設。其他無法確認或互相矛盾的金額，請向提出請求的人確認，不要替他改值。
3. 對每筆通過檢查的金額，從包含 `SKILL.md` 的目錄執行 `python scripts/commission.py "檢查後的營業額數值"`。依腳本印出的金額回覆；不要自行重算或改變精度。
4. 逐筆輸出店家名稱及平台抽成，金額以元呈現、固定兩位小數。無效筆輸出店家名稱及「無效」。如檢查結果列出假設，將每一行假設原文逐字附在答案中。

## 輸出規則

使用簡潔的逐筆清單，讓每個結果都能對應到原店家。營業額缺少時，不要猜測；提供可直接填入店家名稱及營業額的格式，並將未提供的值標示為「未提供」。缺少店家名稱不妨礙已知金額的計算，但結果須指出店家名稱未提供。
