# 目的
將一週內的每日花費整理成表格，為每筆支出標註類別，並在週末計算各類別合計與總計。

# 適用情境
- 使用者提供一週的花費明細，要求整理成表格。
- 使用者希望每筆支出都有類別標記。
- 使用者要求在週末做分類加總、統計各類別總額。

# 處理流程

## 1. 先確認資料是否足夠
若資料不完整，先整理已知內容，並列出缺少的欄位，通常需要：
- 日期或星期
- 金額
- 支出項目/用途
- 若有，付款方式或備註

若缺少日期但有星期，仍可依星期整理；若缺少類別，先根據用途推定最合理類別，並在結果中保持一致。

## 2. 建立每日明細表
將每筆支出拆成一列，至少包含以下欄位：
- 日期 / 星期
- 項目
- 類別
- 金額
- 備註（可選）

類別應盡量簡潔且一致，例如：
- 餐飲
- 交通
- 生活用品
- 娛樂
- 醫療
- 其他

若同一項目可歸入多個類別，優先使用最直接的用途分類，並保持全週一致。

## 3. 按日整理
將同一天的支出放在一起，方便檢視每日花費。
若使用者要的是「一週的每日花費」，則每日都應有對應列；沒有支出的日期也要標示為 0 或「無支出」。

## 4. 週末做分類合計
在週末或表格末尾，彙總整週各類別金額：
- 將同類別的所有金額相加
- 同時計算整週總支出
- 若需要，也可補上每日總額

輸出時至少提供：
- 各類別合計
- 週總計

## 5. 輸出格式
優先使用清楚的 Markdown 表格。

### 每日明細表範例欄位
| 日期 | 星期 | 項目 | 類別 | 金額 | 備註 |
|---|---|---:|---|---:|---|

### 週末分類合計範例欄位
| 類別 | 合計 |
|---|---:|

## 6. 金額處理規則
- 金額以數字呈現，統一單位。
- 若有小數，保留原始精度或四捨五入到小數點後兩位，前後一致。
- 合計時避免遺漏任何一筆。

## 7. 品質檢查
輸出前檢查：
- 每筆支出是否都有類別
- 每一天是否都有列出
- 類別合計是否等於所有明細加總
- 週總計是否正確

# 回應原則
- 只根據使用者提供的花費資料整理，不自行捏造支出。
- 若資料不足以完成分類或加總，明確指出缺少哪些資訊，並先整理現有資料。
- 若使用者未指定類別，使用最少且一致的類別集合，避免過度細分。
