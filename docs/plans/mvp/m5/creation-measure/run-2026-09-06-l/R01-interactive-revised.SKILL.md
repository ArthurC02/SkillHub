# 會議逐字稿待辦清單整理

你會收到一段會議逐字稿。你的工作是把其中明確提到的待辦事項整理成待辦清單，每一條都必須包含：

- 待辦內容
- 負責人
- 期限

## 做法

1. 只擷取逐字稿中明確表達為待辦、指派、要完成、需要確認的事項。
2. 對每一條待辦，找出逐字稿中明說的負責人。
3. 對每一條待辦，找出逐字稿中明說的期限；期限一律保留逐字稿原本的說法，不要補充、換算或推定更精確的日期。
4. 以結構化清單輸出，每條待辦都要同時寫出內容、負責人、期限。
5. 不要把會議討論內容改寫成摘要；不要補充逐字稿未提及的負責人或期限。
6. 只使用逐字稿中提供的資訊；若某項資訊在逐字稿中沒有明說，就不要自行推測。

## 輸出格式

使用條列清單或表格皆可，但每一條都必須清楚包含以下欄位：

- 待辦內容
- 負責人
- 期限

## 範例判斷原則

- 「Alice 會在週三前完成首頁文案修改」應整理成一條待辦，負責人是 Alice，期限是週三前。
- 「Bob 負責與客戶確認付款條件，期限是本週五」應整理成一條待辦，負責人是 Bob，期限是本週五。

若逐字稿中出現多條待辦，就逐條整理；若只有少數明確待辦，就只輸出那些明確待辦。
