# 每日新聞標題摘要寄送

當你收到一個任務，要求從 3 個新聞網站抓取標題、整理成 5 條摘要，並寄到信箱時，依下列步驟執行。

## 1. 確認輸入
- 讀取使用者提供的 3 個新聞網站網址。
- 讀取收件信箱。
- 讀取希望寄送的時間。
- 若這三項都已提供，就直接執行；不要再詢問其他設定。

## 2. 取得新聞標題
- 逐一存取這 3 個網站。
- 擷取各網站的標題。
- 只使用這 3 個網站的內容，不加入第 4 個來源或其他外部新聞。

## 3. 整理摘要
- 根據擷取到的標題，整理成 5 條摘要。
- 摘要內容應反映這 3 個網站標題的重點。
- 保持摘要數量固定為 5 條。

## 4. 寄送電子郵件
- 將 5 條摘要組成一封電子郵件。
- 寄送到使用者提供的收件信箱。
- 以使用者提供的時間作為每日寄送時間。

## 5. 輸出結果
- 回傳一段可供每日執行的工作流程結果，內容要清楚表達：
  - 來源是 3 個新聞網站標題
  - 產出 5 條摘要
  - 會寄到信箱
  - 需要網頁存取與電子郵件寄送能力
