# Excel 客戶名單去重與缺少電話標記

當任務是清理 Excel 客戶名單時，依照以下流程處理：去除重複資料，並標記缺少電話的列。

## 1. 先確認欄位與判定規則
1. 打開工作表，先看欄位名稱。
2. 找出可用來判定重複的欄位，通常優先順序是：
   - 客戶編號 / ID
   - 電話
   - 姓名 + 公司
   - 姓名 + 電話
   - 其他能唯一識別客戶的欄位組合
3. 如果欄位不足以可靠判定重複，先保留原始資料，不要自行猜測合併規則；改為回報需要哪個欄位來判定。

## 2. 去除重複資料
1. 以最穩定、最能代表同一客戶的欄位組合作為去重依據。
2. 若有完全相同的客戶編號，視為重複。
3. 若沒有客戶編號，則以姓名、電話、公司等欄位組合判定是否重複。
4. 保留第一筆或最完整的一筆，刪除其餘重複列。
5. 若同一客戶有多筆資料但內容不完全相同，優先保留資訊較完整的一筆；若無法判斷，保留最早出現的一筆並記錄不確定性。

## 3. 標記缺少電話的列
1. 檢查電話欄是否為空白、只有空格、或明顯不是電話內容。
2. 對缺少電話的列新增標記：
   - 若已有「備註」或「狀態」欄，填入「缺少電話」。
   - 若沒有合適欄位，新增一欄「電話缺失」或「缺少電話」並標記為「是」。
3. 不要填入推測電話號碼。

## 4. 驗證結果
1. 確認重複列已移除，且剩餘資料筆數合理。
2. 確認所有電話空白的列都已被標記。
3. 檢查是否有因格式差異造成的假重複，例如：
   - 電話含空格、連字號、國碼差異
   - 姓名大小寫或前後空白
4. 若有格式差異，先標準化再重新判定是否重複。

## 5. 輸出要求
1. 保留原始欄位順序，除非需要新增「缺少電話」標記欄。
2. 若有修改，儲存為新檔，避免覆蓋原始檔。
3. 如需交付結果，提供：
   - 去重後的筆數
   - 標記缺少電話的筆數
   - 使用的去重依據欄位

## 6. 無法直接完成時
如果目前沒有可用的 Excel 檔案、無法讀取工作表、或欄位不足以可靠判定重複，先說明缺少哪些資訊，再請提供檔案或欄位結構。
