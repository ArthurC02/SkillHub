## 目標
將英文使用手冊完整翻譯為繁體中文，保留原意、操作順序、警告與格式結構；所有專有名詞在第一次出現時以「中文（原文）」呈現，之後只用中文或依上下文一致處理。

## 翻譯原則
1. **忠實完整**：不得省略、增補或改寫手冊中的資訊。
2. **繁體中文**：全文使用繁體中文，術語前後一致。
3. **專有名詞首次標註原文**：
   - 人名、產品名、功能名、按鈕名、選單名、介面標籤、公司名、標準名、型號名等，第一次出現時寫成「中文譯名（Original）」。
   - 若該名詞沒有自然中文譯名，可直接保留原文，第一次出現時可寫成「Original」或「Original（如需說明）」；之後維持一致。
4. **格式保留**：盡量保留原手冊的章節、標題、條列、表格、注意事項、警告、步驟編號與圖說順序。
5. **術語一致**：同一術語在全文使用同一譯法；若原文有縮寫，首次出現時可寫成「中文（英文縮寫）」並在後文沿用縮寫或中文，視可讀性決定。
6. **不自行補充**：不要加入原文沒有的說明、註解或背景知識。

## 工作流程
1. **先通讀全文**，辨識：
   - 章節結構
   - 重複術語
   - 專有名詞
   - 警告/注意/提示
   - 表格、清單、按鈕與介面文字
2. **建立術語一致性**：
   - 對同一名詞固定譯法。
   - 若手冊中有產品介面文字，優先保留原介面名稱並在首次出現時附中文。
3. **逐段翻譯**：
   - 依原順序翻譯，不重排內容。
   - 步驟說明保持簡潔、可操作。
   - 技術名詞、單位、數值、型號、路徑、命令、按鍵名稱保持準確。
4. **處理專有名詞**：
   - 第一次出現：中文（原文）
   - 後續出現：中文或原文縮寫，保持一致
5. **保留版面語意**：
   - 標題層級對應翻譯後的層級。
   - 表格欄位名稱翻譯後仍維持表格結構。
   - 圖說、註腳、警告框內容一併翻譯。

## 輸出要求
- 只輸出翻譯後的繁體中文內容。
- 不要附加翻譯說明、過程筆記或雙語對照，除非原手冊本身就是雙語格式。
- 若原文中有不清楚、疑似 OCR 錯誤或缺字，先依上下文做最合理翻譯；若無法判定，保留原文並以最小幅度標示不確定內容。
