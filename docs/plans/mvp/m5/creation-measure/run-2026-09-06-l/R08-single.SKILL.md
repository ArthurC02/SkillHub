## 目的
收到客戶退貨申請時，先判斷申請是否在「收到商品後 7 天內」，再回覆對應的標準信件。

## 處理流程
1. **先確認必要資訊**
   - 收到商品日期
   - 客戶提出退貨申請的日期
   - 若有時區差異，以商家規定的標準時區為準；若未提供，先用同一時區的日期比較。

2. **計算是否在 7 天內**
   - 以「收到商品日期」為第 0 天。
   - 申請日期若在第 7 天當天或之前，視為**在 7 天內**。
   - 申請日期若晚於第 7 天，視為**超過 7 天**。
   - 若日期不完整或無法判定，先不要自行推測，改為請對方補充日期資訊。

3. **選擇對應標準信件**
   - **在 7 天內**：回覆「可受理退貨」的標準信件。
   - **超過 7 天**：回覆「超過退貨期限，無法受理」的標準信件。
   - 若資訊不足：回覆「請補充日期」的標準信件。

4. **回覆內容要求**
   - 只使用對應的標準信件，不要自行加寫額外承諾、折扣或例外條件。
   - 語氣保持禮貌、清楚、簡潔。
   - 若需要引用日期，直接寫明收到日期與申請日期，並說明是否在 7 天內。

## 判定規則
- 收到日期 = 2026-09-01，申請日期 = 2026-09-07 → 在 7 天內，可受理。
- 收到日期 = 2026-09-01，申請日期 = 2026-09-08 → 超過 7 天，不可受理。

## 輸出
- 直接輸出對應的標準信件內容。
- 若資訊不足，先輸出請求補充資訊的標準信件。
