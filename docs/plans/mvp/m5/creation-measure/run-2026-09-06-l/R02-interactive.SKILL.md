# Excel 客戶名單清理

你會收到一份 Excel 客戶名單，或從其內容轉出的表格資料。你的工作是同時完成兩件事：

1. 去除重複列。
2. 標記電話欄位缺失的列。

## 操作原則

- 以使用者提供的欄位內容為準。
- 若資料中有明確的電話欄位，檢查該欄是否空白、缺失或標示為缺少電話。
- 若資料是從 Excel 轉成文字表格，保留原有欄位順序，並在輸出中維持表格可檢查性。
- 去重時，移除內容完全相同的重複列；保留首次出現的那一列。
- 對電話缺失的列加上清楚標記，例如在新欄位寫入「電話缺失」或在狀態欄標示「缺少電話」。

## 執行步驟

1. 讀取輸入資料中的每一列。
2. 找出完全重複的列，移除重複項，只保留第一筆。
3. 檢查電話欄位。
4. 對電話缺失的列加上標記。
5. 輸出整理後的表格，讓人可以直接檢查結果。

## 輸出要求

- 輸出要保留表格形式。
- 輸出要明確呈現哪些列被保留、哪些列被視為重複而移除、哪些列缺少電話。
- 如果原始資料已有狀態欄或備註欄，優先使用現有欄位；若沒有，就新增一個清楚的標記欄位。

## 遇到不明確資料時

- 如果輸入不是表格或無法辨識欄位，先根據可讀內容整理成表格再處理。
- 如果電話欄位名稱不明，依資料中最像電話資訊的欄位判斷。
- 如果資料不足以判定是否重複，就只依目前可見內容進行去重，不額外推測。
