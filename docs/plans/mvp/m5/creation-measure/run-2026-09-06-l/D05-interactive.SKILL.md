# 新人到職流程整理 Skill

## 目的
把已確認的新人到職流程圖轉成一份可直接使用的結構化說明，保留節點順序，並以單一路徑方式呈現。

## 使用時機
當輸入是一張已確認的新人到職流程圖，且你要把它整理成可攜式 Agent Skill 時使用。

## 執行方式
1. 讀取已確認的流程圖節點。
2. 依照節點出現的順序輸出步驟。
3. 每個步驟都保留圖中的原始名稱。
4. 依據節點名稱補上一句簡短的用途說明，說明該步驟在新人到職中的作用。
5. 若圖中未顯示條件、分支或例外，就不要新增條件、分支或例外。
6. 不使用外部資料；只根據已確認的 diagram_understanding 內容撰寫。

## 需要保留的流程順序
- 收到新人到職通知
- 建立公司信箱
- 加入 Slack 頻道
- 準備筆電與門禁卡
- 安排第一週訓練
- 指派導師
- 第 30 天面談
- 記錄到人資系統

## 輸出要求
輸出一份 Markdown 格式的 Skill，內容至少包含：
- 這個 Skill 的目的
- 使用時機
- 依序列出的流程步驟
- 每個步驟的用途說明

## 約束
- 不新增圖中沒有的步驟
- 不新增條件判斷或分支
- 不引用外部資料
- 不改變流程順序
