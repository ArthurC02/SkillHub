# Slack 未回覆問題週報

## 目的

將指定的 3 個 Slack 頻道中，符合使用者提供的「未回覆」規則的問題訊息整理成每週清單，並附上可點擊連結。

## 使用時機

當輸入明確指定：
- 3 個 Slack 頻道
- 未回覆的判定規則
- 週彙整的輸出需求

就執行本 Skill。

## 操作步驟

1. 讀取使用者提供的 3 個 Slack 頻道。
2. 只處理這 3 個頻道；不要自行加入其他頻道。
3. 依使用者提供的規則，判定哪些訊息屬於「問題」，哪些屬於「未回覆」。
4. 將符合條件的項目整理成「每週」清單。
5. 每筆項目至少包含：
   - 問題內容
   - 可點擊的 Slack 連結
6. 輸出時維持清單格式，讓每筆都能直接對照原始訊息。

## 輸出要求

- 只輸出符合條件的未回覆問題。
- 明確標示這是週彙整。
- 不要補充未提供的頻道、規則或欄位。

## 當資料不足時

如果沒有提供 3 個頻道、未回覆判定規則，或無法取得 Slack 資料，就直接說明缺少哪些必要輸入；不要自行推測。
