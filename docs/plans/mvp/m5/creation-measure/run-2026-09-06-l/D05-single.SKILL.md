# 新人到職流程

依照流程圖執行，順序不可跳步：

1. **收到新人到職通知**
   - 確認新人姓名、到職日、部門、職稱與聯絡方式。
   - 若資訊不完整，先向通知來源補齊。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱命名規則、權限與初始密碼設定符合公司規範。
   - 完成後記錄帳號資訊與交付方式。

3. **加入 Slack 頻道**
   - 將新人加入必要的 Slack 頻道。
   - 至少包含部門、團隊與新人成員常用頻道。
   - 若有公開/私密頻道權限差異，依職務需求設定。

4. **準備筆電與門禁卡**
   - 安排新人所需筆電、配件與門禁卡。
   - 檢查設備是否可用、已完成基本設定，門禁權限是否正確。
   - 若設備或門禁卡尚未就緒，立即追蹤負責單位。

5. **安排第一週訓練**
   - 排定新人第一週的訓練內容與時程。
   - 包含公司制度、工作流程、工具使用與必要的安全/資安訓練。
   - 將訓練安排通知相關講師或負責人。

6. **指派導師**
   - 為新人指定一位導師或 buddy。
   - 明確告知導師支援範圍、聯絡方式與預期協助事項。
   - 確認新人知道導師是主要諮詢窗口。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備面談重點：適應狀況、工作進度、困難點與後續支援。
   - 若需要，提前收集主管與導師回饋。

8. **記錄到人資系統**
   - 將上述完成狀態與關鍵資訊登錄到人資系統。
   - 確保紀錄包含帳號、設備、訓練、導師與面談安排結果。
   - 若流程中任何一步未完成，先標註待辦與負責人，再結案。

## 執行原則
- 嚴格依照流程順序處理。
- 每一步完成後再進入下一步。
- 若缺少必要資訊或權限，先補齊再繼續。
- 這是一個流程圖所示的作業流程；若實際系統操作不可用，應改為整理待辦清單與需確認事項，而不是臆測完成。
