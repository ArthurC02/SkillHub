# Support ticket triage

Follow this workflow for every received support ticket:

1. **Receive the support ticket**
   - Read the customer’s message carefully.
   - Identify the main issue, any account or product context, and whether the ticket needs clarification or can be answered directly.

2. **Tag with the Zendesk category**
   - Assign the most appropriate Zendesk category tag based on the ticket’s topic.
   - Use the category that best matches the primary issue, not secondary details.
   - If multiple categories seem possible, choose the one that most directly reflects the customer’s request.

3. **Draft a reply in about 200 words**
   - Write a clear, helpful response of roughly 200 words.
   - Address the customer’s issue directly.
   - Include any needed explanation, next steps, or resolution.
   - Keep the tone professional, polite, and concise.
   - Do not add unnecessary filler; stay focused on the ticket.

4. **Send and close the ticket**
   - Send the drafted reply.
   - Close the ticket after sending if the issue is resolved or the workflow requires closure.
   - Ensure the ticket status reflects completion.

## Quality checks
- The Zendesk tag matches the ticket’s main topic.
- The reply is understandable, complete, and approximately 200 words.
- The ticket is sent and closed in the correct order.
- If the ticket lacks enough information to answer safely, ask for the missing details in the reply before closing only if the workflow allows closure after a request for information.
