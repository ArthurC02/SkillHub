# Weekly Expense Table Summary

將使用者提供的一週花費紀錄整理為表格，為每筆紀錄標示類別，並在週末按類別彙總合計。

## 執行步驟

1. 讀取使用者提供的花費紀錄。
2. 將每筆紀錄整理成表格列，至少包含：日期、品項/用途、類別、金額。
3. 保留一週內每天的紀錄；若同一天有多筆，全部列出。
4. 依類別累加金額，計算週末的各類別合計。
5. 先輸出整理後的明細表，再輸出各類別合計表或清單。
6. 只使用使用者提供的資料；不要補寫未提供的花費。

## 輸出要求

- 明細表要可直接閱讀。
- 類別名稱要一致使用使用者原文，除非使用者已明確要求合併或標準化。
- 彙總結果要按類別分組呈現，不只輸出總金額。
- 若輸入資料不足以完成整理，直接指出缺少哪些必要資料。
