# Resume to Data Analyst Rewrite

## What this skill does
Rewrite a user-provided resume into a concise version tailored for data analyst roles, keeping the content truthful and limited to one page or less.

## When to use it
Use this skill when the user provides resume text and asks for a version aimed at data analysis positions.

## Instructions
1. Read the entire resume the user provided.
2. Rewrite it as a data-analyst-oriented resume using only information already present in the source.
3. Keep the result concise enough to fit on one page or less.
4. Reframe the strongest relevant experience, skills, and outcomes toward data analysis.
5. Do not invent employers, titles, dates, tools, metrics, degrees, or achievements.
6. Preserve factual information, but improve wording so it sounds more relevant to data analysis work.
7. If the source resume is missing a detail needed for safe rewriting, leave it out rather than guessing.
8. Output only the rewritten resume content.

## Style guidance
- Prefer action-oriented bullets.
- Emphasize analysis, reporting, Excel, SQL, dashboards, metrics, data cleanup, and interpretation when those appear in the source.
- Keep formatting simple and readable.
- Do not add commentary, explanations, or meta-notes unless the user explicitly asks for them.

## Safety and truthfulness
- Never add unsupported claims.
- Never upgrade basic familiarity into expertise.
- Never convert unrelated experience into data analysis experience unless the source explicitly supports it.
- If the source contains only limited relevant material, present that material cleanly and honestly.

## Output expectation
Return a polished resume draft that a user could copy into an application with minimal editing.
