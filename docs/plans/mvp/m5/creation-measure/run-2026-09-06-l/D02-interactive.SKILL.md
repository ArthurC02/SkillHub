# Shopify 訂單入單流程

當你收到一段描述「客戶 Excel 訂單 → CSV 轉換 → 欄位檢查 → Shopify 匯入 → 回覆已入單」的需求時，依照下列步驟整理並執行同一條主流程。此 Skill 只處理這個線性流程；若輸入內容缺少其中任何一個步驟，先指出缺少之處，不要自行補步驟。

## 步驟

1. **收到客戶 Excel 訂單**
   - 先確認輸入中是否明確提到客戶提供的 Excel 訂單內容。
   - 若已提供，將它視為流程起點；若未提供，說明目前缺少訂單來源，無法繼續。

2. **轉成 CSV 格式**
   - 將 Excel 訂單整理為 CSV 形式的資料結構或文字表示。
   - 保持欄位名稱與資料對應清楚，避免改寫原始欄位含義。

3. **檢查缺漏欄位**
   - 檢視 CSV 內容是否有明顯缺漏欄位。
   - 若發現缺漏，列出缺少的欄位；若未發現，明確寫出已完成檢查。

4. **匯入 Shopify 後台**
   - 以流程描述的方式表示將 CSV 匯入 Shopify 後台。
   - 不要宣稱已實際連線或真的完成系統操作；只描述流程中的匯入動作。

5. **回覆客戶已入單**
   - 在流程末端寫出已回覆客戶「已入單」或等義的完成通知。
   - 若前一步驟資訊不足而無法完成流程，則先說明卡在哪一步，不要假裝已回覆。

## 輸出要求

- 依照上述 5 個步驟的順序輸出。
- 內容要像流程摘要或操作摘要，避免加入未提及的新步驟。
- 若輸入只是在要求整理這個流程，直接產出整理後的 Skill 內容；若輸入本身缺少必要資訊，明確指出缺口。
- 保持簡潔，讓讀者能一眼看出從 Excel 訂單到回覆已入單的完整主線。
