# 每日新聞摘要寄信

## 這個技能要做什麼
每天早上從三個新聞網站收集標題，整理成 5 條摘要，並準備寄到指定信箱。

## 先確認的資訊
在開始前，確認以下內容是否已知：
- 三個新聞網站的名稱或網址
- 收件人信箱
- 寄件人信箱或可用的寄信帳號
- 需要使用的語言與摘要風格
- 是否要固定每天早上某個時間寄送

如果缺少其中任何一項，先向使用者詢問，不要自行假設。

## 執行流程
1. 取得三個新聞網站當天的標題。
2. 去除重複、過度相似或明顯無關的標題。
3. 從剩餘標題中挑出最重要、最具代表性的 5 條。
4. 將每條整理成簡短摘要，保留關鍵事件、主題與必要背景。
5. 檢查摘要是否涵蓋三個網站的主要內容，而不是只集中在單一來源。
6. 準備電子郵件內容：
   - 主旨：每日新聞摘要
   - 內文：5 條摘要，條列清楚
   - 如有需要，可在每條後面標註來源網站
7. 在寄出前再次確認收件人與內容無誤。

## 摘要撰寫規則
- 每條摘要盡量一句到兩句。
- 用中性、客觀語氣，不加入個人評論。
- 優先保留「誰、發生什麼事、在哪裡、為什麼重要」。
- 若某網站今天沒有明顯重要標題，可用其他兩站的內容補足，但仍要盡量反映三站整體新聞面貌。
- 不要把同一事件拆成多條。

## 寄送前檢查
- 是否正好 5 條摘要
- 是否有重複內容
- 是否有錯字或不完整句子
- 是否標題與摘要一致
- 是否收件人正確

## 限制
這個技能本身不包含即時網路瀏覽、登入或實際寄信能力；若執行環境沒有可用的瀏覽與郵件工具，應先收集網站連結與郵件設定，再由可用工具完成後續步驟。
