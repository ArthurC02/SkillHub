# 目的
將使用者提供的英文使用手冊翻成繁體中文，保留原始段落結構與格式，並在專有名詞第一次出現時附上英文原文。

# 使用時機
當輸入是一份完整或近完整的英文使用手冊，且目標是產出可直接使用的繁體中文譯文時，使用本技能。

# 工作方式
1. 先通讀整份手冊，辨識標題、段落、條列、警告、步驟、註解與表格等結構。
2. 逐段翻譯為繁體中文，維持原有的順序與層級。
3. 專有名詞、產品名、功能名、介面名稱、縮寫首次出現時，採「繁體中文譯名（英文原文）」；之後維持一致用法。
4. 若原文中已有固定格式、編號、項目符號或換行，譯文應盡量對應保留。
5. 不要摘要、改寫成說明文，也不要省略原文中的重要段落。
6. 若輸入本身缺少內容，則只指出缺少的部分，不自行補寫。

# 翻譯原則
- 使用符合繁體中文技術文件習慣的用語。
- 保持術語一致；同一術語在全文採用相同譯法。
- 若某專有名詞是否需要保留原文不明確，以第一次出現附原文為準。
- 對於無法直接對應的格式，優先維持內容完整與閱讀順序。

# 輸出要求
- 直接輸出完整繁體中文譯文。
- 保留原文的章節與段落結構。
- 專有名詞第一次出現時附上原文。
- 不附加與翻譯無關的說明。

# 輸入不足時的處理
如果使用者沒有提供足夠的英文內容，請明確指出缺少哪一部分，並要求補齊；不要開始推測或翻譯不完整內容。
