## 目的
每週從三個 Slack 頻道中找出「問題訊息」裡尚未得到回覆的項目，整理成可直接貼出的清單，並附上每則訊息的連結。

## 適用情境
- 使用者要做每週 Slack 問題追蹤
- 需要從三個指定頻道彙整未回覆問題
- 需要輸出可點擊的訊息連結與簡短摘要

## 先確認的資訊
如果輸入中沒有明確提供，先向使用者確認：
1. 三個 Slack 頻道名稱或連結
2. 週期範圍（例如：最近 7 天、上週一到週日）
3. 「未回覆」的判定方式：
   - 完全沒有任何回覆
   - 或只有提問者自回、但沒有他人回覆
4. 輸出語言與格式偏好

## 作業步驟
1. 逐一檢視三個頻道在指定週期內的訊息。
2. 找出看起來是「問題」的訊息，例如：
   - 以問號結尾
   - 明確詢問協助、狀態、原因、做法
   - 需要他人確認、決策或排除問題
3. 對每則候選問題檢查串列回覆：
   - 若沒有任何他人回覆，視為未回覆
   - 若只有表情符號、已讀、或提問者自己的補充，仍視為未回覆
   - 若已有實質回覆，排除
4. 去除重複或明顯同一事件的重複提問；保留最早或最完整的一則，並在必要時合併描述。
5. 為每則未回覆問題整理以下資訊：
   - 頻道名稱
   - 發問者
   - 發問時間
   - 問題摘要，控制在一句話內
   - 訊息連結
6. 依時間排序，通常以最早未回覆的問題排前面；若使用者要求，也可改為最新優先。

## 輸出格式
使用條列清單，每項一行，格式如下：
- [頻道名] 發問者｜時間｜問題摘要｜連結

若需要更清楚，可在清單前加上簡短標題，例如：
- 本週未回覆問題

## 品質檢查
- 只列出真正未回覆的問題，不要把已解決或已有回覆的訊息混入
- 每項都要有可點擊的訊息連結
- 摘要要忠實反映原文，不要自行補答案
- 若某頻道本週沒有未回覆問題，仍保留該頻道的檢查結果，但不要硬湊項目

## 限制
這個技能只負責整理與輸出清單；如果沒有 Slack 存取權、頻道清單、或週期範圍，就先請使用者提供，不能自行假設。
