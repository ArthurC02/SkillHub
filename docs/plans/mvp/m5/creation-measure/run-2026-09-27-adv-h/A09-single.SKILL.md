# 目的
根據「這個月的出勤紀錄」計算每個人的加班時數，並找出加班時數超過 46 小時的人。

# 適用情境
- 輸入是月度出勤紀錄、打卡明細、工時表或類似資料。
- 需要彙總每個人的加班時數。
- 需要標示超過 46 小時的名單。

# 執行步驟
1. **確認資料範圍**
   - 只使用「這個月」的紀錄。
   - 若資料跨月，先排除非本月資料，或請求明確的月份範圍。

2. **辨識每筆紀錄的欄位**
   - 找出員工識別資訊：姓名、工號或其他唯一標識。
   - 找出加班時數欄位；若沒有直接提供加班時數，則依資料中的規則計算。
   - 若有多筆同一人的紀錄，準備做加總。

3. **整理每個人的加班時數**
   - 將同一人的所有本月加班時數加總。
   - 若資料中有不同類型的加班，先依資料定義確認是否都要納入總和。
   - 若欄位單位不是「小時」，先換算成小時後再加總。

4. **檢查資料品質**
   - 若某筆紀錄缺少姓名/工號或加班時數，先標記為缺漏。
   - 若同一人出現多個不同名稱但疑似同一人，先不要自行合併，改為列出待確認項目。
   - 若加班時數格式不一致，統一成數字小時再計算。

5. **判定是否超過門檻**
   - 對每個人計算出的本月加班總時數，與 46 小時比較。
   - 超過 46 小時者標記為「超過 46 小時」。
   - 等於 46 小時者不算超過。

6. **輸出結果**
   - 以清楚表格列出：
     - 姓名/工號
     - 本月加班總時數
     - 是否超過 46 小時
   - 另外單獨列出超過 46 小時的人員名單。

# 輸出格式建議
- 先給總表，再給超標名單。
- 若資料不足以計算，明確說明缺少哪些欄位，並列出需要補充的資訊。

# 注意事項
- 不要把正常工時誤算成加班時數。
- 不要自行猜測缺失數值。
- 若原始資料的加班定義不明，先依資料提供者的規則處理，或請求補充說明。
