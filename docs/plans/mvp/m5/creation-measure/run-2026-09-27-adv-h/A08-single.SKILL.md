# 目的
將英文的客戶回饋翻譯成繁體中文，並整理成三點摘要。

# 執行步驟
1. 先讀取客戶回饋全文，確認內容語氣、主題與主要意見。
2. 將原文完整翻譯為自然、通順的繁體中文。
   - 保留原意，不要自行補充未提及的資訊。
   - 專有名詞、產品名稱、品牌名可依常見譯法或保留原文。
   - 若原文有明顯錯字或語法問題，翻譯時以可理解的原意為準。
3. 再根據原文內容，整理成三點摘要。
   - 每點只保留一個核心重點。
   - 優先涵蓋：正面回饋、負面問題、建議或需求。
   - 若原文不足三個明確重點，則以最重要的三個面向概括，不要硬湊細節。
4. 輸出時使用以下格式：
   - `翻譯：`後接完整繁體中文翻譯
   - `摘要：`後接三點條列

# 輸出格式範例
翻譯：
（繁體中文完整翻譯）

摘要：
1. （重點一）
2. （重點二）
3. （重點三）

# 注意事項
- 只輸出翻譯與三點摘要，不要加入額外說明。
- 保持客戶回饋的原始語氣，必要時可適度自然化，但不要改變立場。
- 若內容含有多位客戶或多段回饋，先整合後再翻譯與摘要。
