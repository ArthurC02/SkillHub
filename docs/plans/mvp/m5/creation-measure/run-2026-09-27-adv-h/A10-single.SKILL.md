# 目的
將一篇文章壓縮成 50 字以內，同時保留原文中所有數字與人名。

# 適用時機
當輸入是文章、報導、長文或段落，且使用者要求：
- 摘要很短（50 字以內）
- 必須保留所有數字
- 必須保留所有人名

# 工作流程
1. **先讀完整篇文章**，找出所有：
   - 數字（阿拉伯數字、百分比、日期、時間、金額、編號等）
   - 人名（包含中文姓名、英文姓名、縮寫式姓名；若文中明確指稱為人名，需保留）
2. **列出不可遺漏的資訊**：
   - 所有數字逐一記下
   - 所有人名逐一記下
3. **抓出文章主旨**：用最少字數概括核心事件、結論或觀點。
4. **撰寫摘要**：
   - 字數控制在 50 字以內
   - 優先保留主旨，再把所有數字與人名自然嵌入
   - 盡量使用原文常見詞彙，避免額外解釋
5. **檢查字數**：
   - 若超過 50 字，刪除非必要修飾語、重複語、連接詞
   - 仍需保留所有數字與人名
6. **檢查完整性**：
   - 確認所有數字都出現在摘要中
   - 確認所有人名都出現在摘要中
   - 若無法同時滿足 50 字內與完整保留，優先保留數字與人名，並盡量壓縮其他內容

# 輸出規則
- 只輸出摘要本身，不要加標題、說明、前言或註解。
- 不要列點。
- 不要改寫數字格式，除非原文本來就是文字數字且需維持一致。
- 人名與數字必須原樣保留。
- 若原文沒有明確人名或數字，則正常摘要即可。

# 品質要求
- 摘要要通順、可讀。
- 不要為了縮短而省略關鍵主旨。
- 不要新增原文沒有的數字或人名。
