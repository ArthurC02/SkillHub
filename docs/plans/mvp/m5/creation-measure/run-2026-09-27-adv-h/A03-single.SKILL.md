# 目的
將客服信箱中「上週」收到的客訴信整理成分類統計表，供後續分析或回報使用。

# 適用範圍
- 只處理使用者已提供、或系統可直接讀取到的郵件內容。
- 若無法直接存取信箱、郵件匯出檔或郵件清單，先說明無法自行登入或抓取信箱內容，並改為請使用者提供郵件匯出檔、轉寄內容或 CSV/Excel。

# 作業步驟
1. **確認資料來源**
   - 先確認可用的輸入是什麼：郵件正文、標題清單、匯出檔、CSV、Excel、或截圖文字。
   - 若資料不足以判斷哪些信件屬於「上週」，請先請使用者提供日期範圍或直接提供上週郵件清單。

2. **篩選上週客訴信**
   - 以郵件日期為準，篩出上週收到的信件。
   - 若資料中同時包含非客訴信，先排除明顯非客訴內容，例如通知信、行銷信、系統信。
   - 若無法明確判定是否為客訴，保留在「待確認」類別，不要自行刪除。

3. **建立分類規則**
   - 依郵件內容將客訴歸類到可重複使用的主分類。
   - 建議至少包含以下類別，若內容需要可再新增：
     - 商品品質
     - 配送/物流
     - 退款/退貨
     - 帳務/付款
     - 服務態度
     - 網站/系統問題
     - 訂單問題
     - 其他
     - 待確認
   - 若一封信同時涉及多個問題，依主要訴求歸類；必要時可在備註欄標示次要類別。

4. **逐封標記欄位**
   - 對每封客訴信至少記錄：
     - 收件日期
     - 寄件者或客戶識別資訊（若可見）
     - 主旨
     - 分類
     - 是否已處理/待處理（若內容可判斷）
     - 簡短摘要
   - 摘要只保留與客訴原因相關的重點，不要抄錄整封信。

5. **統計彙總**
   - 計算每個分類的信件數量。
   - 若資料足夠，另外統計：
     - 已處理 vs 待處理
     - 每類平均件數或占比
     - 最高頻問題
   - 若有重複來信，依使用者需求決定是按「信件數」或「客戶數」統計；若未指定，預設以信件數統計，並註明。

6. **輸出分類統計表**
   - 先輸出總覽，再輸出明細表。
   - 建議格式如下：

   ### 上週客訴統計總覽
   | 分類 | 件數 | 占比 | 備註 |
   |---|---:|---:|---|
   | 商品品質 | 0 | 0% |  |
   | 配送/物流 | 0 | 0% |  |
   | 退款/退貨 | 0 | 0% |  |
   | 帳務/付款 | 0 | 0% |  |
   | 服務態度 | 0 | 0% |  |
   | 網站/系統問題 | 0 | 0% |  |
   | 訂單問題 | 0 | 0% |  |
   | 其他 | 0 | 0% |  |
   | 待確認 | 0 | 0% |  |

   ### 明細清單
   | 日期 | 寄件者 | 主旨 | 分類 | 狀態 | 摘要 |
   |---|---|---|---|---|---|
   |  |  |  |  |  |  |

7. **品質檢查**
   - 確認總件數等於明細列出的信件數。
   - 確認每封信只出現在一筆明細中。
   - 若有無法判斷的內容，集中放入「待確認」，並在備註說明原因。

# 輸出原則
- 使用繁體中文。
- 以表格為主，文字說明保持簡短。
- 不要臆測郵件內容；看不到的資訊標示為「未提供」或「無法判斷」。
- 若資料來源不是郵件原文而是截圖或掃描檔，先嘗試整理可辨識文字，再標示不清楚之處。
