# 目的
協助使用者寫出一篇合適的自我介紹。這個技能不直接捏造個人資訊；若資訊不足，先補問關鍵內容，再根據情境撰寫。

# 使用流程
1. **確認使用情境**
   - 先判斷自我介紹要用在哪裡：面試、課堂報告、社群貼文、申請文件、活動開場、履歷摘要、其他。
   - 若使用者沒有說明，先詢問用途與希望的語氣。

2. **蒐集必要資訊**
   至少確認以下項目：
   - 姓名或稱呼
   - 身分/角色（學生、工程師、設計師、轉職者等）
   - 目前所在單位或學校
   - 專長、經歷或亮點
   - 想強調的個人特質
   - 介紹用途與字數/長度需求
   - 語言與語氣（正式、自然、活潑、簡短）

3. **整理內容結構**
   依情境選擇合適順序：
   - 開頭：姓名與基本身分
   - 中段：學經歷、專長、成果、興趣或個人特色
   - 結尾：目前目標、期待、聯絡或收尾句

4. **撰寫原則**
   - 內容要真實，不補寫未提供的經歷。
   - 用詞要符合情境；正式場合避免過度口語。
   - 若資訊很少，寫成通用版並明確保留可替換位置。
   - 避免空泛形容詞堆疊，盡量用具體事實或例子。

5. **輸出格式**
   - 直接提供可使用的自我介紹正文。
   - 若有需要，可同時提供：
     - 簡短版
     - 標準版
     - 正式版
   - 若使用者要求修改，依回饋調整長度、語氣與重點。

# 可用寫作模板
## 通用版
大家好，我叫〔姓名〕，目前是〔身分/角色〕，就讀/任職於〔學校/公司/單位〕。我的主要專長是〔專長〕，過去曾參與〔經歷或成果〕。我個性上比較〔特質〕，平常也喜歡〔興趣〕。希望未來能在〔目標或方向〕持續成長，謝謝大家。

## 面試版
您好，我是〔姓名〕，目前擔任/就讀〔身分與單位〕。我主要的背景在〔領域〕，曾經負責〔經歷1〕、〔經歷2〕，累積了〔能力或成果〕。我擅長〔技能〕，也很重視〔特質，例如溝通、合作、解決問題〕。這次希望能把我的經驗運用在〔目標職位/方向〕，並持續學習成長。

## 社群簡介版
嗨，我是〔姓名〕，一個〔身分/興趣標籤〕。平常喜歡〔興趣〕，也在〔領域〕持續學習與分享。這裡會記錄我的〔內容主題〕，歡迎交流！

# 需要補問時的問題
若資訊不足，優先詢問：
- 這篇自我介紹要用在哪裡？
- 希望多長？
- 想要正式、自然還是活潑的語氣？
- 你希望我一定要提到哪些經歷、專長或特質？

# 注意事項
- 不要替使用者編造學歷、工作、證照、得獎紀錄。
- 若使用者只提供很少資訊，先寫一版簡潔通用稿，再請對方補充細節以便優化。
- 若使用者要求特定格式，例如第一人稱、第三人稱、條列式、口語版，優先遵守。
