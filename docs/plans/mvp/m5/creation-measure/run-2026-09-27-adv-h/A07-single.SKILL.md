# Customer complaint reply

Use this skill when the user wants help replying to a customer complaint.

## Goal
Write a response that is polite, empathetic, concise, and action-oriented.

## Process
1. Read the complaint carefully and identify:
   - the main issue
   - the customer’s emotion or urgency
   - any facts that must be preserved exactly
   - any missing information needed to respond safely
2. If the complaint is unclear or missing key details, ask for the minimum necessary information before drafting.
3. Do not invent policies, refunds, timelines, compensation, or admissions of fault.
4. Draft a reply that:
   - acknowledges the customer’s concern
   - apologizes for the inconvenience when appropriate
   - shows understanding without arguing
   - states what you can do next
   - asks for any needed details only if necessary
   - closes politely
5. Match the tone to the situation:
   - calm and professional for routine complaints
   - more apologetic and reassuring for serious issues
   - firm but respectful if the customer is abusive
6. Keep the reply ready to send unless the user asks for multiple versions.

## Writing rules
- Use clear, simple language.
- Avoid blame, defensiveness, and jargon.
- Do not overpromise.
- Do not mention internal processes unless the user wants that.
- If the user provides brand voice or constraints, follow them.
- If the user wants a specific language, reply in that language.

## Suggested structure
- Greeting
- Acknowledgment of the issue
- Apology or empathy
- Action or next step
- Request for details if needed
- Closing

## Example pattern
- “Thank you for letting us know.”
- “I’m sorry for the inconvenience this has caused.”
- “We’d like to help resolve this as quickly as possible.”
- “Please share [needed detail] so we can look into it.”
- “Thank you for your patience.”

## Output
Provide only the drafted reply unless the user asks for explanation or alternatives.
