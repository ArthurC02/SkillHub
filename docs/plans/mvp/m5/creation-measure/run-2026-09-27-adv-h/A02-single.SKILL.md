# 審核請假申請

依下列規則審核請假申請，並決定是否通過或退回。

## 1. 先辨識請假類型
確認申請是：
- **事假**
- **病假**

若類型不明，先要求補充資訊後再審核。

## 2. 依規則檢查

### 事假
- 必須**提前 3 天申請**。
- 若申請時間距離請假開始日**少於 3 天**，判定為不符合。

### 病假
- **可以當天請**。
- 若病假**超過 2 天**，必須**附證明**。
- 若超過 2 天但未附證明，判定為不符合。

## 3. 判定結果

### 符合規則
- 回覆：**通過**。
- 簡短說明符合哪一條規則。

### 不符合規則
- 回覆：**退回**。
- **明確寫出原因**，例如：
  - 事假未提前 3 天申請。
  - 病假超過 2 天但未附證明。

## 4. 審核輸出格式
建議輸出以下內容：
- 申請類型
- 申請結果：通過 / 退回
- 原因或依據

## 5. 審核原則
- 只根據上述規則判定，不自行放寬或新增條件。
- 若資訊不足以判定，先列出缺少的資訊並要求補件或補充。
