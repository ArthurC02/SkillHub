# 目的
將一週內的每日花費整理成清楚的表格，為每筆支出標註類別，並在週末彙總各類別合計。

# 適用情境
- 使用者提供一週的花費明細，要求整理成表格。
- 使用者希望每筆支出都有類別標記。
- 使用者要求在週末或週結時計算各類別合計。

# 處理流程
1. **先確認資料範圍**
   - 讀取使用者提供的一週資料。
   - 若日期不完整，先依現有資料整理，不自行補造缺漏。
   - 若同一天有多筆支出，逐筆列出，不合併除非使用者明確要求。

2. **建立每日明細表**
   - 以日期為主軸，列出每筆花費。
   - 每筆至少包含：
     - 日期
     - 項目/用途
     - 金額
     - 類別
   - 若使用者未提供類別，根據用途推定最合理的類別，並保持一致。
   - 類別命名要簡潔一致，例如：餐飲、交通、購物、娛樂、生活、醫療、其他。

3. **檢查分類一致性**
   - 同類用途應使用相同類別名稱。
   - 若某筆支出難以歸類，放入「其他」，不要硬猜。
   - 若金額單位不一致，先統一後再計算。

4. **計算週末各類別合計**
   - 以整週資料為基礎，按類別加總。
   - 若使用者指定週末才結算，則在週末區塊輸出各類別總額。
   - 同時可提供整週總支出，方便對照。

5. **輸出格式**
   - 先輸出「每日花費明細表」。
   - 再輸出「週末類別合計表」。
   - 表格欄位建議如下：
     - 每日明細表：日期｜項目｜類別｜金額
     - 類別合計表：類別｜合計金額
   - 金額格式保持一致，必要時保留到小數點後兩位。

# 表格規則
- 日期順序依時間先後排列。
- 同一天內可依金額或輸入順序排列，但要一致。
- 類別合計只計入該週內的資料。
- 若有退款、折扣或負數金額，照實記錄並納入合計。

# 輸出範例結構
## 每日花費明細
| 日期 | 項目 | 類別 | 金額 |
|---|---|---:|---:|
| 週一 | 早餐 | 餐飲 | 50 |
| 週一 | 公車 | 交通 | 30 |

## 週末類別合計
| 類別 | 合計金額 |
|---|---:|
| 餐飲 | 50 |
| 交通 | 30 |

# 注意事項
- 不要省略任何已提供的花費。
- 不要把未提供的資料補成完整一週。
- 若使用者資料格式混亂，先整理成一致表格，再做分類與加總。
- 若無法判斷類別，明確標為「其他」。
