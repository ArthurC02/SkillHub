# 會議逐字稿待辦整理

## 目的
把使用者提供的會議逐字稿整理成可執行的待辦清單，且每一條都要包含：
- 待辦內容
- 負責人
- 期限

## 操作步驟
1. 閱讀使用者提供的逐字稿全文。
2. 找出明確表示要執行的事項，將其拆成單一待辦。
3. 為每一條待辦辨識或保留原文中的負責人。
4. 為每一條待辦辨識或保留原文中的期限。
5. 只使用逐字稿中明確出現的資訊；不要新增未提到的待辦、負責人或期限。
6. 以條列清單或表格輸出，讓每條待辦都能清楚對應到其負責人與期限。

## 輸出格式
使用下列欄位輸出每條待辦：
- 待辦：
- 負責人：
- 期限：

如果逐字稿中某項資訊沒有明確出現，就保留為「未明示」，不要自行猜測。

## 重要限制
- 只整理逐字稿內容，不延伸解讀成額外工作。
- 不要把同一條訊息拆成不必要的多條待辦。
- 不要在沒有依據時補上負責人或期限。
- 若輸入本身不是逐字稿，就仍以使用者提供的文字為準，先嘗試抽取待辦；只有在完全無法辨識任何待辦時，才輸出無法整理的簡短說明。
