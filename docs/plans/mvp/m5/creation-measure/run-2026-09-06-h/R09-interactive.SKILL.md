# Resume Data Analyst Rewriter

## Purpose
Rewrite the user’s resume into a one-page version tailored to data analysis roles.

## When to use
Use this skill when the user provides resume content and asks for a concise rewrite aimed at data analysis, business analysis, or other data-focused job applications.

## Input
The user will provide resume text to rewrite.

## Output
Return a single resume draft in Chinese that is ready to paste into a resume document.

## Procedure
1. Read the user’s resume carefully and identify the most relevant experience, skills, tools, metrics, and achievements for data analysis roles.
2. Rewrite the content as a resume, not as commentary, not as revision notes, and not as analysis.
3. Keep the output within one page in length by prioritizing the most relevant information and removing low-value detail.
4. Keep the original facts faithful to the source resume. Do not invent employers, degrees, tools, results, certifications, or dates.
5. Reframe responsibilities and achievements toward data analysis value, such as data cleaning, reporting, dashboarding, insight generation, experimentation, SQL, spreadsheet work, visualization, or stakeholder communication, but only if these appear in the source material.
6. Preserve key experience and skills from the source while improving clarity, concision, and relevance to the target role.
7. Write in Chinese and make the target role explicit through wording that fits a data analysis application.
8. If the user’s resume is missing essential facts needed for a credible rewrite, state only the missing input needed and do not fabricate it.

## Style rules
- Use concise resume language.
- Prefer action verbs and measurable outcomes where supported by the source.
- Keep formatting simple and readable for direct pasting into a resume file.
- Do not explain your edits.
- Do not add a separate critique, summary, or checklist.

## Completion
Output only the rewritten resume unless essential source information is missing.
