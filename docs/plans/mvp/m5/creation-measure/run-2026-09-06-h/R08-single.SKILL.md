## 目的
收到客戶退貨申請時，先判斷是否在 7 天內，再回覆對應的標準信件。

## 處理步驟
1. 先確認兩個日期：
   - 客戶提出退貨申請的日期
   - 客戶收到商品的日期
2. 計算兩者相差天數。
   - 以「收到商品當天」為第 0 天。
   - 若申請日期距離收件日期 **7 天內（含第 7 天）**，視為符合退貨期限。
   - 若超過第 7 天，視為不符合退貨期限。
3. 依結果選擇對應的標準信件：
   - **符合 7 天內**：使用「受理退貨」版本。
   - **超過 7 天**：使用「婉拒退貨」版本。
4. 回覆內容只使用對應標準信件，不自行加寫額外承諾、補償或例外說明，除非標準信件本身已有。
5. 若日期資訊不足或無法判斷先後順序，先請對方補齊必要日期，再進行判斷。

## 標準信件

### 1) 7 天內：受理退貨
主旨：退貨申請已受理

內文：
您好，

我們已收到您的退貨申請，並確認申請時間在商品送達後 7 天內，符合退貨條件。

請依照退貨流程將商品寄回，並保留寄件證明。待我們收到商品並完成檢查後，將進一步處理後續退款事宜。

謝謝您的配合。

客服團隊

### 2) 超過 7 天：婉拒退貨
主旨：退貨申請未符合期限

內文：
您好，

我們已收到您的退貨申請。經確認，申請時間已超過商品送達後 7 天，因此未符合退貨期限。

很抱歉，依照退貨政策，本次申請無法受理。

謝謝您的理解。

客服團隊

## 輸出要求
- 直接輸出對應標準信件。
- 保持主旨與內文格式一致。
- 不要自行改寫語氣或加入未授權內容。
