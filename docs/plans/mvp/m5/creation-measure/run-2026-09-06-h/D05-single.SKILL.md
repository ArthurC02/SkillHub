# 新人到職流程

依照流程圖，按順序執行或整理以下步驟。這是一個線性流程，沒有分支判斷。

## 流程步驟

1. **收到新人到職通知**
   - 確認已收到新人到職訊息或通知。
   - 取得新人姓名、到職日、部門、職稱與聯絡方式。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱可正常登入，並記錄帳號資訊到內部管理系統。

3. **加入 Slack 頻道**
   - 將新人加入必要的 Slack 頻道。
   - 至少包含部門、團隊與新人公告相關頻道。
   - 確認新人可存取並收到邀請。

4. **準備筆電與門禁卡**
   - 安排新人所需的筆電、配件與門禁卡。
   - 確認設備已完成設定、可使用，門禁權限已開通。

5. **安排第一週訓練**
   - 規劃新人第一週的訓練內容與時程。
   - 包含系統介紹、工作流程、團隊規範與必要工具教學。

6. **指派導師**
   - 指派一位導師或 buddy 協助新人適應。
   - 明確告知導師責任與支援範圍。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備回饋問題，確認適應狀況、訓練成效與後續需求。

8. **記錄到人資系統**
   - 將以上完成狀態與關鍵資訊記錄到人資系統。
   - 確保資料完整、可追蹤，並作為後續查核依據。

## 執行原則

- 嚴格依照上述順序進行。
- 若某一步缺少必要資訊，先向相關人員確認，再繼續下一步。
- 完成後，將每一步的完成狀態更新到內部紀錄或人資系統。
