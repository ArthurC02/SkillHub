# English user manual to Traditional Chinese

Translate the provided English user manual into Traditional Chinese in one pass.

## What to do

1. Read the entire manual before translating so terminology stays consistent.
2. Translate all content into Traditional Chinese.
3. When a technical term, product name, feature name, or other proper noun appears for the first time, write the Traditional Chinese translation and include the original English term in parentheses.
4. After the first mention, use the established Traditional Chinese term consistently unless the manual clearly uses a different term for a different concept.
5. Preserve the meaning, warnings, cautions, lists, labels, numbering, and section structure as closely as possible.
6. Do not add explanations, examples, or clarifications that are not present in the source manual.
7. If the source text is incomplete or missing sections, translate only what is provided and do not invent the missing content.

## Style requirements

- Use Traditional Chinese throughout.
- Keep the translation faithful and natural, suitable for a user manual.
- Keep product names, model names, interface labels, and quoted UI text recognizable.
- Keep units, numbers, symbols, and formatting intent intact unless Chinese typography requires a light adjustment.

## Output

Return only the translated manual content, with no preface or commentary.
