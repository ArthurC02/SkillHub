## 目標
將英文使用手冊完整翻成繁體中文，保留原意、操作順序、警告與格式層級；所有專有名詞在第一次出現時要附上原文，之後可只用中文譯名。

## 處理原則
1. **完整翻譯，不摘要**：不要省略步驟、注意事項、表格、標題、圖說、按鈕名稱、錯誤訊息或警告。
2. **繁體中文優先**：用自然、正式、清楚的繁體中文表達，避免直譯到不通順。
3. **首次出現附原文**：專有名詞、產品名、功能名、介面名稱、縮寫、技術術語第一次出現時，寫成「中文譯名（原文）」；若原文本身就是縮寫，可寫成「中文譯名（英文縮寫）」。
4. **一致性**：同一術語前後譯法一致；若前文已定譯名，後文沿用。
5. **保留格式結構**：維持章節、條列、編號步驟、表格、注意/警告區塊與圖示說明的層級。
6. **不改變操作含義**：按鍵、選單路徑、數值、單位、型號、版本號、路徑、命令與代碼要準確保留。

## 翻譯步驟
1. 先通讀全文，辨識：
   - 章節標題與小節標題
   - 專有名詞與縮寫
   - 操作步驟、前置條件、結果、警告、注意事項
   - 表格欄位、清單、圖說、按鈕/選單名稱
2. 建立術語對照：
   - 為每個重要專有名詞決定固定譯名
   - 第一次出現時採「譯名（原文）」格式
   - 若原文在同一段落重複出現，可在後續改用譯名
3. 逐段翻譯：
   - 先保留原有段落與標題層級，再翻成繁體中文
   - 編號步驟保持原順序，不重排
   - 若原文有條列，翻譯後仍用條列
4. 處理介面與操作文字：
   - 按鈕、選單、欄位名稱若是產品介面文字，保留原文並加中文說明，首次出現時附原文
   - 例如：按一下「儲存（Save）」
5. 處理警告與注意：
   - 明確區分 Warning、Caution、Note 等語氣
   - 翻譯時保留其重要性，不弱化也不誇大
6. 檢查一致性與完整性：
   - 確認沒有漏譯段落、表格列、註解或腳註
   - 確認首次出現的專有名詞都有原文標註
   - 確認數字、單位、符號、路徑、版本號未被改錯

## 術語標註規則
- **第一次出現**：中文譯名（原文）
- **後續出現**：只用中文譯名，除非需要避免歧義
- **縮寫**：若縮寫常見，可寫「中文全名（縮寫）」；首次出現時可同時保留英文全名
- **產品名稱/品牌名**：通常保留原文，必要時加中文說明，不強行翻譯品牌名

## 輸出要求
- 只輸出翻譯後的繁體中文內容
- 保留原文的結構與順序
- 不加入與原文無關的說明、註解或摘要
- 若原文有不清楚或無法辨識的片段，保留原樣並以最小必要方式標示不確定性，不要自行補寫內容
