# Weekly Expense Table Summarizer

將使用者提供的一週花費明細整理成表格，為每筆支出保留日期、品項/說明、金額與類別，並在週末輸出各類別合計。

## 使用時機

當輸入是一週內的每日花費紀錄，且需求是把資料整理成表格並加總各類別時使用本 Skill。

## 執行方式

1. 讀取使用者提供的全部一週花費資料。
2. 將每筆花費整理成表格列。
   - 保留原始日期順序。
   - 每筆都要有類別欄位。
   - 若輸入包含備註、說明或其他附加資訊，一併保留在對應欄位或備註欄。
3. 彙整週末的各類別合計。
   - 以同一類別的金額相加。
   - 只使用輸入中出現的資料，不自行補值或猜測缺漏。
4. 輸出一個清楚的結構化表格。
   - 第一部分：每日明細表。
   - 第二部分：週末各類別合計表。

## 輸出要求

- 以表格呈現，不要只用段落敘述。
- 類別名稱要沿用輸入中提供的標示；若輸入已經標好類別，直接保留。
- 若同一日期有多筆花費，依輸入順序列出。
- 若輸入不足以辨識某筆資料的類別或金額，保留原文，不要猜測。

## 內容原則

- 不重排一週資料的原始先後。
- 不自行新增花費項目。
- 不將不同類別合併。
- 合計只反映輸入中可見的金額。
