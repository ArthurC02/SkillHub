# Excel 客戶名單去重與缺電話標記

## 適用情境
當你拿到一份 Excel 客戶名單，需要：
1. 去除重複資料；
2. 標記沒有電話號碼的列。

## 先確認欄位
1. 打開 Excel 檔案，確認哪一欄是「客戶識別欄位」：通常是姓名、公司名、Email、客戶編號，或多欄組合。
2. 確認哪一欄是電話欄位。
3. 如果欄名不明確，先根據資料內容判斷，避免誤刪。

## 去除重複資料
1. 先決定「重複」的判定方式：
   - 若有唯一客戶編號，以該欄判定；
   - 若沒有唯一編號，通常以姓名 + 公司名 + Email 或姓名 + 電話的組合判定。
2. 在原始資料上先建立備份工作表，避免直接覆蓋。
3. 使用 Excel 的「資料」→「移除重複」功能，選取用來判定重複的欄位。
4. 執行前確認是否要保留第一筆出現的資料；一般情況下保留第一筆。
5. 執行後檢查移除結果，確認沒有把不同客戶誤判成重複。

## 標記缺少電話的列
1. 在電話欄旁新增一欄，例如「電話狀態」或「缺電話標記」。
2. 對每一列檢查電話欄是否為空、只有空白、或只有無效占位字元。
3. 在新欄填入明確標記，例如：
   - `缺少電話`
   - `有電話`
4. 若需要更醒目，可對 `缺少電話` 的列套用底色或篩選條件格式。

## 建議的公式做法
如果要用公式自動標記：
1. 在新欄輸入判斷公式，依電話欄位置調整。
2. 例如電話在 B 欄時，可用：
   - `=IF(TRIM(B2)="","缺少電話","有電話")`
3. 向下填滿整欄。
4. 若電話欄可能含公式結果或特殊空值，先確認顯示內容是否真的為空。

## 完成後檢查
1. 確認去重後筆數是否合理，與原始 200 筆相比是否符合預期。
2. 篩選「缺少電話」列，抽查幾筆確認標記正確。
3. 儲存為新檔，保留原始檔不變。

## 注意事項
- 不要只用姓名單欄去重，除非業務規則明確允許，否則容易誤刪同名不同人。
- 若資料中有合併儲存格、空白列或格式不一致，先整理再去重。
- 若使用的是 Excel 表格功能，公式與篩選會更穩定。
