# 每日新聞摘要寄信

這個技能描述的是一個**需要即時網站存取與可用寄信權限**的工作流程。若目前沒有瀏覽器、網路存取、郵件發送工具，或尚未提供收件信箱與可用的新聞網站網址，先不要假裝已完成；改為收集必要資訊並準備摘要格式。

## 先確認的資訊
1. 三個新聞網站的網址。
2. 收件人的電子郵件地址。
3. 寄送時間與時區，預設為每天早上固定時間。
4. 是否只要標題，或允許根據標題與導言做更精簡的摘要。
5. 是否有語言偏好、字數限制、或特定主題優先順序。

## 每日執行流程
1. 依序打開三個新聞網站。
2. 擷取當天最新或首頁最重要的標題。
3. 去除重複、過度相似、廣告、置頂但無新聞價值的項目。
4. 依重要性與跨站重複度整理成 5 條摘要：
   - 優先保留跨站都出現的重大事件。
   - 若同一事件在多站出現，合併成一條。
   - 每條摘要以一句話表達，避免長段落。
5. 檢查是否涵蓋三個網站的主要資訊；若某站沒有明顯新聞，註明「今日該站無新增重要標題」而不要硬湊內容。
6. 撰寫郵件內容：
   - 主旨：`每日新聞摘要 - YYYY-MM-DD`
   - 內文先寫簡短開頭，再列出 5 條摘要。
   - 如有必要，在每條後面附上來源網站名稱。
7. 使用可用的郵件工具寄出。
8. 寄出前做最後檢查：日期正確、收件人正確、沒有超過 5 條、沒有把未確認的內容寫成事實。

## 摘要寫法
- 保持中性，不加入個人評論。
- 以標題資訊為主，不擴寫未確認細節。
- 若標題本身不完整，摘要要保守，例如「某政策/事件持續發展」而不是補充猜測。
- 優先使用清楚、可直接閱讀的中文。

## 無法自動完成時
如果沒有即時網路、無法登入新聞網站、或沒有寄信工具，請改為：
1. 列出需要的網站與收件資訊。
2. 提供可直接貼上的摘要模板。
3. 說明需要人工補上最新標題後才能寄出。

## 建議郵件格式
主旨：每日新聞摘要 - 2026-09-06

早安，以下是今天整理的 5 條新聞摘要：
1. …
2. …
3. …
4. …
5. …

如需，我也可以再幫你整理成更短版或依主題分類。
