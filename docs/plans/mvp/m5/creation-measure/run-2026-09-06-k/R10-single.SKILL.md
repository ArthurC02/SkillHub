## 目的
每週從三個 Slack 頻道中找出「有問題、但尚未回覆」的訊息，整理成可直接分享的清單，並附上每則訊息的連結。

## 適用範圍
- 只處理使用者指定的三個頻道。
- 只列出看起來是在提問、請求協助、或需要他人確認的訊息。
- 只列出尚未出現明確回覆的項目。

## 作業步驟
1. 取得本週範圍。
   - 以最近 7 天為預設週期，除非使用者另外指定週起訖。
   - 若需要更精準，依對話中的日期或週期定義調整。

2. 逐一檢視三個頻道。
   - 只看指定頻道內的訊息。
   - 找出符合以下特徵的訊息：
     - 以問句結尾。
     - 包含「請問」、「麻煩」、「需要」、「有人知道嗎」、「可否」、「能否」等求助語氣。
     - 明確要求回覆、確認、協助、排除問題、或等待決策。

3. 判斷是否「未回覆」。
   - 視為已回覆：
     - 同串中有人直接回答問題。
     - 原作者已明確表示問題已解決。
     - 有明確的後續處理結果，且不再需要回覆。
   - 視為未回覆：
     - 只有按讚、表情符號、或無關留言。
     - 只有轉貼、補充資訊，但沒有回答問題本身。
     - 問題仍懸而未決，串內沒有明確答案。

4. 去除重複與過度相似項目。
   - 同一問題在同一串內多次追問，只保留最早且最完整的一則。
   - 若不同頻道出現相同內容，分開列出，因為來源不同。

5. 為每個項目整理必要資訊。
   - 頻道名稱
   - 發問者
   - 訊息摘要：用一句話概括問題
   - 連結：使用該則 Slack 訊息的永久連結

## 輸出格式
以條列清單輸出，每項一行，格式如下：
- [頻道] 發問者：問題摘要｜連結

## 排序規則
- 先列最早出現的未回覆問題。
- 若同時間接近，優先列較明確、較需要處理的問題。

## 注意事項
- 不要把一般討論、閒聊、公告、或已解決事項列入。
- 不要猜測回覆內容；只有在串內能明確看出已回覆時才排除。
- 若某頻道本週沒有未回覆問題，該頻道可略過不寫。
