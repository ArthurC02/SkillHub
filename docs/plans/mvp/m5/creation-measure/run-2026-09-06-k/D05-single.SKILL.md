# 新人到職流程

依照流程圖，按順序執行以下步驟：

1. **收到新人到職通知**
   - 確認新人姓名、到職日、部門、職稱與主管資訊。
   - 若資訊不完整，先向 HR 或招募窗口補齊。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱命名規則、權限與是否已啟用。

3. **加入 Slack 頻道**
   - 將新人加入必要的 Slack 頻道。
   - 至少包含部門、公告與新人成長/入職相關頻道；若公司有固定清單，依清單處理。

4. **準備筆電與門禁卡**
   - 安排新人所需的筆電、帳號登入資訊與基本軟體。
   - 準備門禁卡或其他出入權限。
   - 若設備或門禁需要申請，提前完成申請與領用安排。

5. **安排第一週訓練**
   - 排定新人第一週的訓練內容與時程。
   - 包含公司介紹、工具使用、部門流程與必要的合規/安全訓練。

6. **指派導師**
   - 為新人指定一位導師或 buddy。
   - 明確告知導師支援範圍、聯絡方式與陪伴期間。

7. **第 30 天面談**
   - 安排新人到職第 30 天的回顧面談。
   - 檢視適應狀況、訓練進度、問題與後續支援需求。

8. **記錄到人資系統**
   - 將上述完成狀態與關鍵資訊登錄到人資系統。
   - 確保紀錄包含到職通知、帳號建立、設備/門禁、訓練、導師與 30 天面談結果。

## 執行原則
- 嚴格依照流程順序處理。
- 若任何一步缺少必要資訊或資源，先補齊再往下進行。
- 若公司內部有既定表單、系統或權限流程，優先遵循內部規範。
