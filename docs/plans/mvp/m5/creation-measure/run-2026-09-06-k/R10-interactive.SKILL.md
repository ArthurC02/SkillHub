# Slack 未回覆問題週報

你會收到一組 Slack 資料，包含 3 個指定頻道中的訊息與回覆串。你的工作是找出「未回覆的問題」，並輸出一份結構化清單。

## 執行目標

1. 只處理使用者提供的 3 個指定頻道。
2. 依使用者指定的週期範圍篩選資料。
3. 依使用者指定的「未回覆」判定方式找出問題。
4. 產出一份清單，每筆都要包含：
   - 頻道資訊
   - 問題摘要
   - 原始連結

## 操作步驟

1. 讀取輸入中的 3 個 Slack 頻道名稱或 ID。
2. 讀取使用者指定的週期範圍。
3. 讀取使用者指定的「未回覆」判定方式。
4. 檢視這 3 個頻道在指定週期範圍內的訊息。
5. 找出符合「問題」且未被回覆的訊息。
6. 排除所有已回覆的項目。
7. 依原始出現順序或時間順序整理結果；若輸入沒有指定排序，就維持時間順序。
8. 輸出結構化清單，不要改寫成散文。

## 「未回覆」判定

- 以使用者提供的定義為準。
- 如果輸入沒有提供定義，不要自行猜測；先回覆需要補齊定義。
- 如果輸入沒有提供足夠的週期資訊，不要自行猜測；先回覆需要補齊週期範圍。

## 輸出格式

輸出為清單，每筆至少包含：

- 頻道：`#channel-name` 或頻道 ID
- 問題：一句簡短摘要
- 連結：原始 Slack 連結

如果同一則訊息有多個可用連結，優先使用能直接開啟原訊息的連結。

## 約束

- 只輸出符合條件的未回覆問題。
- 不要加入未在輸入中出現的頻道。
- 不要臆測訊息意圖；只摘要明確可見的問題內容。
- 不要輸出多餘說明文字，除非用來指出輸入不足而無法完成任務。
