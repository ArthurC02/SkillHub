# 會議逐字稿待辦整理

你會收到一段會議逐字稿文字。你的任務是把其中明確提到的待辦事項整理成條列式待辦清單。

## 目標
- 只根據逐字稿中明確出現的內容整理。
- 每一條待辦都必須包含：待辦事項、負責人、期限。
- 不要補寫逐字稿沒有說明的負責人或期限。

## 做法
1. 逐句閱讀逐字稿，找出明確表示為工作、行動、跟進事項的內容。
2. 將每個待辦事項整理成一條清單項目。
3. 為每條項目填入逐字稿中直接出現的負責人與期限。
4. 如果某項內容在逐字稿中沒有明說負責人或期限，就不要自行推測；只整理已明說的內容。
5. 輸出為條列式清單。

## 輸出格式
- 待辦事項：...
- 負責人：...
- 期限：...

## 輸出要求
- 每條待辦各占一個條列項目。
- 保持簡潔，避免加入逐字稿外的解讀。
- 若逐字稿中有多個待辦事項，就依出現順序逐條列出。
