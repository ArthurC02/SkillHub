# Excel 客戶名單去重與缺少電話標記

依照下列步驟處理 Excel 名單，目標是：
1. 去除重複客戶資料。
2. 標記缺少電話的列。

## 1) 先確認欄位
- 找出哪一欄是客戶識別依據，通常是以下其中一種：
  - 客戶名稱
  - 公司名稱
  - 電話號碼
  - Email
  - 以上欄位的組合
- 找出電話欄位名稱，確認哪些儲存格代表「缺少電話」：
  - 空白
  - 只有空格
  - 文字如「無」、「N/A」、「-」等若資料規則視為缺少，也要一併納入

## 2) 先保留原始資料
- 不要直接覆蓋原始工作表。
- 先另存一份副本，或在新工作表中處理。
- 若有多個工作表，先確認要處理的是哪一張。

## 3) 去除重複資料
- 先判斷重複的定義：
  - 若有明確唯一鍵，依唯一鍵去重。
  - 若沒有唯一鍵，通常以「客戶名稱 + 電話」或「公司名稱 + 電話」作為判斷依據。
- 去重前先排序或檢查資料，避免誤刪。
- 去重時保留一筆代表資料，其餘重複列移除。
- 若同一客戶有多筆資料但電話不同，先不要直接刪除；應依資料規則決定是否視為不同客戶。

## 4) 標記缺少電話的列
- 在電話欄旁新增一欄，例如：`電話狀態` 或 `缺少電話`
- 對每一列判斷電話欄是否為空：
  - 空白 → 標記為「缺少電話」或 `是`
  - 有電話 → 標記為「正常」或 `否`
- 若資料中有多個電話欄位，依需求決定：
  - 只要任一電話欄有值就視為有電話
  - 或必須主要電話欄有值才算完整

## 5) 檢查結果
- 確認去重後筆數是否合理。
- 抽查幾筆重複資料，確認沒有誤刪。
- 抽查缺少電話的列，確認標記正確。
- 若需要交付，保留：
  - 去重後的名單
  - 缺少電話標記欄

## 6) 若資料規則不明，先詢問
如果無法從欄位名稱判斷去重依據，或電話缺失的判定標準不清楚，先向使用者確認：
- 要用哪個欄位判斷重複？
- 空白以外的哪些值也算缺少電話？
- 是否要保留重複資料中的最新一筆？

## 7) 交付內容
- 提供已去重的 Excel 檔。
- 提供已標記缺少電話的結果。
- 若有任何不確定的去重規則，明確註記處理方式。
