# Excel 客戶名單去重與缺電話標記

## 目的
處理一份 Excel 客戶名單時，同時完成兩件事：
1. 去除重複資料列。
2. 標記缺少電話的列。

## 何時使用
當輸入是一份客戶名單表格，而且你需要把重複資料整理掉，同時找出電話欄位空白的列時，使用這個 Skill。

## 執行步驟
1. 讀取使用者提供的 Excel 表格。
2. 找出名單中的資料列，保留原本欄位。
3. 依照整列內容判定重複列；內容完全相同的資料列視為重複。
4. 移除重複列，只保留每組重複資料中的第一筆。
5. 檢查每一列的電話欄位。
6. 若電話欄位空白、缺值或沒有可用電話內容，就在該列加上缺電話的標記。
7. 輸出整理後的表格，讓結果仍可對應回原始 Excel 列。

## 輸出要求
- 輸出必須是表格型結果。
- 必須同時呈現去重後的資料與缺電話標記。
- 若同一列同時符合重複與缺電話條件，結果中仍需反映這兩件事。

## 缺少電話的標記方式
- 若原始表格已有適合的標記欄位，優先使用該欄位。
- 若沒有現成的標記欄位，新增一個清楚表示缺電話狀態的欄位。
- 標記內容應能讓人一眼看出該列缺少電話。

## 重複判定
- 以使用者提供的表格內容為準，內容完全相同者視為重複。
- 若使用者在輸入中明確指定不同的重複判定方式，遵循使用者指定的方式。

## 不足資訊時的處理
- 如果無法辨識哪一欄是電話欄位，先詢問使用者電話欄位名稱。
- 如果輸入不是表格資料，或無法對應到 Excel 內容，先要求提供可處理的表格內容。

## 輸出示例原則
- 直接回傳整理後的表格。
- 不要只描述結果，要讓使用者可以立刻用輸出做後續處理。
