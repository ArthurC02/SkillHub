## 目標
將英文使用手冊完整翻譯為繁體中文，保留原意、操作順序與格式結構；專有名詞、產品名、功能名、縮寫或術語在第一次出現時以「中文（Original）」呈現，之後可只用中文或依上下文一致使用。

## 翻譯原則
1. **完整性優先**：不要省略段落、步驟、警告、註解、表格標題、圖說或清單項目。
2. **結構保留**：維持原文的章節層級、編號、項目符號、表格與順序。
3. **術語一致**：同一術語在全文使用一致譯法；若原文已有固定譯名，優先採用常見繁中譯法。
4. **首次出現附原文**：
   - 專有名詞、產品名稱、功能名稱、介面名稱、按鈕名稱、縮寫或重要術語第一次出現時寫成「繁中譯名（Original）」。
   - 之後若不影響理解，可只用繁中譯名。
5. **保留不可翻內容**：型號、代碼、命令、路徑、變數名、API 名稱、按鍵組合、錯誤碼、單位與數值通常保留原樣，只翻譯周邊說明。
6. **語氣自然且準確**：使用繁體中文的說明書語氣，避免直譯造成拗口，但不要擅自改寫操作含義。
7. **警告與注意事項**：原文中的 WARNING / CAUTION / NOTE / IMPORTANT 要明確對應翻譯，並保留其提示性質。

## 工作流程
1. **先掃描全文**，找出：
   - 章節結構
   - 重複術語
   - 專有名詞與縮寫
   - 表格、清單、警告、圖說
2. **建立術語一致性**：
   - 若全文同一術語多次出現，統一譯法。
   - 若某術語第一次出現，採「中文（Original）」格式。
3. **逐段翻譯**：
   - 依原文順序翻譯，不重排內容。
   - 長句可依繁中語序適度拆分，但不得改變意思。
4. **保留格式**：
   - 標題層級照原文。
   - 編號步驟、子項目、表格欄位與條列維持原結構。
   - 若原文有粗體、斜體、程式碼樣式，盡量對應保留。
5. **檢查首次出現標註**：
   - 確認每個重要專有名詞第一次出現都有原文括註。
   - 若同一名詞在不同章節首次出現，仍以全文第一次出現為準。
6. **校對一致性**：
   - 檢查術語是否前後一致。
   - 檢查數字、單位、步驟順序、條件句與否定句是否翻對。

## 輸出要求
- 只輸出翻譯後的繁體中文內容。
- 不要附加翻譯說明、註解、摘要或雙語對照，除非原文本身有這些內容。
- 若原文包含表格或清單，請以可讀且對應原文的格式呈現。
- 若遇到無法確定的術語，先依上下文選擇最合理譯法，並保持全文一致。
