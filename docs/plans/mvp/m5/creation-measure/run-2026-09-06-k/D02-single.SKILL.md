# 目的
將客戶提供的 Excel 訂單整理成 Shopify 可匯入的 CSV，先檢查必要欄位是否缺漏，再匯入 Shopify 後台，最後回覆客戶已完成入單。

# 執行流程
1. **收到客戶 Excel 訂單**
   - 先確認檔案可開啟，且內容是訂單資料而非其他附件。
   - 若檔案無法讀取、格式損毀或內容不完整，先回覆客戶請重新提供可用檔案。

2. **轉成 CSV 格式**
   - 將 Excel 內容整理為 CSV。
   - 保留訂單所需的欄位與資料列，避免在轉檔時遺失商品、數量、收件資訊或備註。
   - 若原始 Excel 有多個工作表，先確認哪一個是正式訂單資料，再進行轉換。

3. **檢查缺漏欄位**
   - 檢查 CSV 是否包含匯入 Shopify 所需的必要欄位。
   - 特別確認常見關鍵資料是否齊全，例如：
     - 顧客姓名
     - Email 或聯絡方式
     - 商品名稱或 SKU
     - 數量
     - 收件人資訊
     - 地址
     - 郵遞區號
     - 訂單備註或特殊需求（如有）
   - 若發現缺漏：
     - 先整理出缺少哪些欄位。
     - 若可從原檔補齊，就補齊後再繼續。
     - 若無法補齊，先向客戶確認，不要直接匯入不完整資料。

4. **匯入 Shopify 後台**
   - 使用整理完成且欄位完整的 CSV 進行匯入。
   - 匯入前再次確認欄位對應正確，避免商品、數量或收件資訊對錯。
   - 匯入後檢查結果是否成功，並確認沒有明顯錯誤或失敗列。
   - 若匯入失敗，根據錯誤訊息回頭修正 CSV，再重新匯入。

5. **回覆客戶已入單**
   - 在確認 Shopify 後台已成功建立訂單後，回覆客戶已完成入單。
   - 若有任何異常，例如缺資料、匯入失敗、需補件，也要一併告知客戶目前進度與需要配合的事項。

# 注意事項
- 不要在未檢查欄位前直接匯入。
- 不要假設缺漏資料的內容；缺什麼就先確認什麼。
- 若流程中任何一步無法完成，先停下來整理問題，再向客戶回報。
