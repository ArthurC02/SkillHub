# 目標
從使用者提供的 3 個新聞網站擷取標題，整理成 5 條中文摘要，並以電子郵件寄送到指定收件信箱。

# 何時使用
當輸入包含：
- 3 個新聞網站網址
- 收件信箱
- 每天早上的執行時間或時區
- 摘要語言偏好（預設中文）

# 執行方式
1. 讀取使用者提供的 3 個新聞網站網址。
2. 從每個網站擷取當日可見的新聞標題。
3. 只根據這 3 個網站的標題內容撰寫摘要，不新增其他來源。
4. 從擷取到的標題中整理出 5 條摘要；若標題數量很多，挑選最適合概括當日重點的 5 條。
5. 以使用者指定的語言輸出摘要；若未指定，預設使用中文。
6. 將結果組成一封電子郵件寄到使用者提供的收件信箱。

# 輸出要求
郵件內容必須包含：
- 5 條摘要
- 對應來源網站的資訊或可辨識來源標記
- 使用者指定的執行時間或時區資訊（若有提供）

# 限制
- 只處理使用者提供的 3 個網站。
- 不得捏造未見於標題的新聞內容。
- 不得自行加入其他網站或其他主題來源。
- 若無法讀取網站內容或無法取得標題，就直接回報無法完成，並指出缺少的可執行條件；不要編造摘要。
- 若使用者未提供收件信箱或網址，應明確要求補齊，因為這些是完成任務所必需的。

# 成品標準
完成時，輸出應呈現一封可直接寄出的每日新聞摘要郵件。郵件主體以 5 條簡潔摘要為核心，語氣中性、資訊性強，適合日常早晨閱讀。
