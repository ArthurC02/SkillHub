# 英文使用手冊翻譯成繁體中文

## 目的
將使用者提供的英文使用手冊內容翻譯成繁體中文，並在專有名詞第一次出現時附上英文原文。

## 適用時機
當輸入是一段或多段英文手冊、說明書、操作指南或產品文件，需要轉成繁體中文，而且要保留專有名詞首次出現的原文標示時，使用本 Skill。

## 輸入
- 使用者提供的英文手冊全文或其中一段。
- 若使用者只提供部分內容，就只翻譯已提供的內容。
- 不假設有未提供的頁面、圖片或外部資料。

## 輸出原則
- 以繁體中文輸出完整翻譯稿。
- 忠實對應原文內容，不改寫成摘要，不自行補充原文沒有的說明。
- 保留原文的段落結構、標題層級與條列形式；若原文結構不明，則以最清楚的可讀格式呈現。
- 專有名詞第一次出現時，在同一處附上英文原文；後續再次出現時，通常只保留中文譯名，除非原文語境需要再次標示。
- 專有名詞、產品名、介面名稱、按鈕名稱、功能名稱、錯誤訊息與型號名稱，優先維持一致譯法。
- 若原文已有固定譯名慣例，沿用一致的繁體中文譯法；若不確定，採用直譯且保留原文。

## 翻譯步驟
1. 讀取使用手冊內容，先辨識標題、段落、條列、警告、注意事項與操作步驟。
2. 將每一段內容翻成自然、清楚的繁體中文。
3. 找出專有名詞與關鍵術語，並在第一次出現時補上英文原文。
4. 檢查全文是否仍與原文內容對應，沒有遺漏、擴寫或摘要化。
5. 輸出可直接閱讀的繁體中文翻譯稿。

## 品質要求
- 句子要自然通順，但不得犧牲原意。
- 專有名詞標示要一致。
- 技術用語、數字、單位、型號、警告與操作順序要保留原意。
- 若原文有明顯歧義，依最保守且貼近字面的方式翻譯，不自行猜測未提供的上下文。

## 失敗情況
- 如果使用者提供的內容不足以形成翻譯稿，就只指出缺少的內容，不補造內容。
- 如果輸入不是英文手冊內容，則仍依照可見文字處理，不自行改變任務範圍。
