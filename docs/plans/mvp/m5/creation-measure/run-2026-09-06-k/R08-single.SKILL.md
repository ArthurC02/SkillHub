## 目的
收到客戶退貨申請時，先判斷是否在 7 天內，再回覆對應的標準信件。

## 處理步驟
1. 先確認兩個日期：
   - 客戶提出退貨申請的日期
   - 客戶收到商品的日期
2. 計算兩者相差天數。
   - 以「收到商品當天」為第 0 天。
   - 若申請日在收到商品後第 7 天內（含第 7 天），視為符合 7 天內。
   - 若超過第 7 天，視為不符合。
3. 依結果選擇對應的標準信件：
   - 符合 7 天內：使用「可受理退貨」信件。
   - 超過 7 天：使用「無法受理退貨」信件。
4. 回覆內容只輸出對應信件，不要自行加寫額外說明、推測或政策內容。
5. 若缺少任一必要日期，先請對方補齊日期，再進行判斷。

## 標準信件

### 可受理退貨
主旨：您的退貨申請已受理

您好，

我們已收到您的退貨申請，並確認申請時間在商品送達後 7 天內，因此您的退貨申請符合受理條件。

接下來請依照退貨流程將商品寄回；收到退回商品並完成檢查後，我們會進一步為您處理後續事宜。

謝謝您。

客服小組

### 無法受理退貨
主旨：您的退貨申請未符合退貨期限

您好，

我們已收到您的退貨申請，但經確認，申請時間已超過商品送達後 7 天，因此目前無法受理退貨。

若您需要進一步協助，歡迎回覆此信與我們聯繫，我們會盡力提供其他可行的協助方式。

謝謝您。

客服小組

## 注意事項
- 日期判斷以實際日曆天數為準。
- 不要自行改寫信件語氣或加入未授權承諾。
- 若系統已有固定模板，優先使用本技能提供的標準信件內容。
