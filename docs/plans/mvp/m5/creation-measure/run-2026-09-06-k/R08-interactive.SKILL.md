# 目的

收到客戶退貨申請時，判斷申請是否在到貨後 7 天內，並輸出對應的標準信件。

# 適用時機

當輸入提供了至少這些資訊時使用：
- 到貨日
- 申請日
- 商品資訊

如果資訊足以判斷是否在 7 天內，就直接產生對應信件；不要要求額外外部資料。

# 執行方式

1. 讀取輸入中的到貨日與申請日。
2. 計算申請日相對於到貨日的天數差。
3. 判斷是否在 7 天內：
   - 7 天內：輸出同意退貨的標準信件。
   - 超過 7 天：輸出婉拒退貨的標準信件。
4. 信件內容要可直接寄出，語氣正式、清楚、禮貌。
5. 信件中要明確帶出判斷結果，不要只回覆一句話。
6. 不要向使用者追問已在輸入中提供的資料。

# 信件內容要求

## 7 天內
- 明確表示已收到申請。
- 明確表示符合 7 天內退貨條件。
- 說明後續處理方式。
- 保持正式且友善。

## 超過 7 天
- 明確表示已收到申請。
- 明確表示已超過 7 天退貨期限。
- 清楚說明因此無法受理退貨。
- 保持正式且禮貌。

# 輸出格式

- 輸出一封完整信件。
- 內容需包含稱呼、主旨、內文與結尾署名。
- 若輸入未提供足以判斷的日期資訊，才要求補充缺少的必要資料。

# 注意事項

- 只根據輸入資料判斷，不自行假設其他政策條款。
- 不要使用未提供的折扣、補償或附加承諾。
- 不要輸出分析過程，只輸出最終信件。
