# 員工報帳流程圖整理

## 用途
當你收到一張「員工報帳申請」流程圖，或一段描述相同節點與分支的流程文字時，使用這個技能把流程整理成可執行的步驟說明，保留節點、判斷條件與分支方向。

## 輸入
一段流程圖內容或等價的流程文字，內容應能對應到流程中的節點與分支。

## 處理方式
1. 先依流程圖的順序讀出節點。
2. 遇到判斷節點時，明確標示條件名稱。
3. 依照圖上的分支方向，逐一展開是／否分支。
4. 不要新增流程圖沒有的步驟、角色或條件。
5. 不要改寫分支順序；只能照圖上的連線輸出。
6. 圖上若有含糊之處，保留為說明，不自行補完。

## 依圖步驟輸出
請依下列節點順序整理流程：

1. **收到員工報帳申請**
   - 這是流程起點。

2. **發票是否齊全**
   - 依圖上的判斷結果分支。
   - 若 **否**：**退回並要求 3 天內補件**。
   - 若 **是**：進入下一個判斷節點。

3. **金額是否超過 5000**
   - 依圖上的判斷結果分支。
   - 若 **是**：**送經理簽核**，之後進入財務處理。
   - 若 **否**：直接進入財務處理。

4. **財務直接入帳**
   - 依圖上的連線執行此步驟。
   - 這一步是金額判斷後的後續處理。

5. **寄出付款通知信**
   - 這是流程結尾。

## 輸出要求
- 必須保留流程節點的原始語意。
- 必須保留兩個判斷條件：**發票是否齊全**、**金額是否超過 5000**。
- 必須保留分支方向：**發票是否齊全 = 否** 時退回補件；**發票是否齊全 = 是** 時進入下一判斷；**金額是否超過 5000 = 是** 時送經理簽核；**金額是否超過 5000 = 否** 時直接入帳。
- 必須包含 **退回並要求 3 天內補件**、**送經理簽核**、**財務直接入帳**、**寄出付款通知信**。
- 不要加入流程圖未出現的角色、審核規則或例外情況。

## 當圖面資訊不足時
如果輸入沒有足夠資訊對應到這些節點，就只說明缺少哪些圖上資訊，不要猜測。
