# 目的
將一週內的每日花費整理成清楚的表格，為每筆支出加上類別，並在週末彙總各類別合計。

# 適用情境
- 使用者提供一週的花費明細，要求整理成表格。
- 使用者希望每筆支出都標示類別。
- 使用者要求在週末或週結時，計算各類別總額。

# 處理流程
1. **先確認資料範圍**
   - 讀取使用者提供的一週資料。
   - 若資料缺少日期、金額、品項或類別，先用最少必要問題補齊。
   - 若使用者沒有指定分類方式，依內容自行歸類，但要保持一致。

2. **建立每日明細表**
   - 以日期為主軸，逐筆列出花費。
   - 每筆至少包含：
     - 日期
     - 項目／用途
     - 金額
     - 類別
   - 若同一天有多筆支出，分列多行。

3. **統一類別**
   - 將相近項目歸入同一類別，避免重複命名。
   - 類別名稱要簡短、固定、可重複使用。
   - 若資料中已有類別，優先沿用原類別；只有在明顯不一致時才統一修正。

4. **計算週末各類別合計**
   - 將整週所有支出依類別加總。
   - 輸出各類別總額與整週總支出。
   - 若使用者要求，也可同時列出每日小計。

5. **輸出格式**
   - 先給每日明細表。
   - 再給週末分類合計表。
   - 金額欄位格式保持一致，必要時補上貨幣單位。

# 建議表格格式
## 每日明細
| 日期 | 項目 | 類別 | 金額 |
|---|---|---:|---:|
| 週一 | 早餐 | 餐飲 | 50 |
| 週一 | 公車 | 交通 | 30 |

## 週末分類合計
| 類別 | 合計 |
|---|---:|
| 餐飲 | 350 |
| 交通 | 120 |
| 其他 | 80 |
| 總計 | 550 |

# 注意事項
- 不要把同一筆支出重複計入。
- 若某筆支出無法明確分類，先放入「其他」，並在需要時註明原因。
- 若使用者提供的資料跨越多週，先依週分組，再分別整理與加總。
- 若資料量很大，仍維持同樣欄位結構，避免省略關鍵資訊。
