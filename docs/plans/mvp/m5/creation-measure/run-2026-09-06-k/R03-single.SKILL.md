# 每日新聞摘要寄信

## 適用情境
當使用者要你每天早上從三個新聞網站整理標題，濃縮成 5 條摘要，並寄到指定信箱時使用。

## 先確認的資訊
如果以下資訊未提供，先向使用者確認：
1. 三個新聞網站的網址或名稱。
2. 收件人信箱地址。
3. 寄送時間與時區。
4. 摘要語言與語氣偏好（例如：繁中、簡潔、中性）。
5. 是否要保留來源連結。
6. 是否有排除主題或關鍵字。

## 執行流程
1. 取得三個新聞網站當天的標題。
2. 去除重複、相近或明顯同義的標題。
3. 依重要性、影響範圍與時效性挑選最值得關注的內容。
4. 整理成 5 條摘要，每條摘要應：
   - 簡短明確
   - 只包含一個重點
   - 避免抄寫原標題
   - 必要時保留來源名稱或連結
5. 檢查是否涵蓋三個網站的主要資訊；若某站今日無重要標題，可在摘要中反映其缺乏重大更新，而不要硬湊內容。
6. 以適合寄信的格式撰寫郵件主旨與內文。
7. 寄送前再次確認收件人與內容無誤。

## 摘要撰寫規則
- 以 5 條為固定輸出數量。
- 優先保留對讀者最有價值的新聞。
- 若三站內容高度重疊，合併成一條摘要並註明多來源一致。
- 若某則新聞資訊不足，摘要中只寫已確認的事實，不推測。
- 避免評論、立場或未驗證細節。

## 郵件格式建議
- 主旨：`每日新聞摘要 - YYYY-MM-DD`
- 內文結構：
  1. 簡短開頭
  2. 5 條摘要清單
  3. 來源列表（可選）

## 限制與注意事項
- 這個技能需要即時瀏覽新聞網站與寄送電子郵件的能力；如果目前沒有可用的瀏覽或寄信工具，或沒有使用者提供的信箱/網站資訊，就先收集資訊，不要假裝已完成。
- 若網站需要登入、付費或有反爬限制，應明確告知使用者並請其提供可存取的替代來源。
