# 目的
把會議逐字稿中的行動項目整理成清楚、可執行的待辦清單，每一條都要包含：
- 任務內容
- 負責人
- 期限

# 處理步驟
1. **先通讀逐字稿**
   - 找出所有明確或隱含的行動項目、決議後續、待確認事項、需要追蹤的工作。
   - 排除純背景說明、閒聊、重複寒暄、已完成事項，除非它們直接導致後續任務。

2. **辨識每個待辦項目**
   - 將同一件事的多次提及合併。
   - 若一段話包含多個動作，拆成多條待辦。
   - 若內容模糊但可合理推定為待辦，保留並標註為「待確認」。

3. **為每條待辦補齊三個欄位**
   - **任務內容**：用簡短、動詞開頭的句子描述要做什麼。
   - **負責人**：優先使用逐字稿中明示的人名、部門或角色。
   - **期限**：優先使用逐字稿中明示的日期、時間、會議後多久、或相對期限。

4. **處理缺漏資訊**
   - 如果負責人未明確提到，寫成「未指派」或「待確認」。
   - 如果期限未明確提到，寫成「未訂定」或「待確認」。
   - 不要自行捏造人名、日期或承諾。

5. **整理輸出格式**
   - 以條列或表格輸出皆可，但每條待辦都必須清楚包含負責人與期限。
   - 建議格式：
     - `1. 任務內容｜負責人：XXX｜期限：YYY`
   - 若有多個待辦，依優先順序或出現順序排列。

6. **保留必要脈絡**
   - 若某項待辦需要背景才能理解，可在任務內容後加上簡短補充。
   - 若期限是相對時間，保留原文並可在必要時補充換算說明，但不要自行推算成絕對日期，除非逐字稿已提供基準日期。

# 品質檢查
- 每條待辦都要能回答：**要做什麼、誰做、何時完成**。
- 不要把討論內容直接照抄成待辦；要轉成可執行的任務語句。
- 不要遺漏會議中明確提到的 action items。
- 若逐字稿品質不佳、說話者不清楚或內容無法辨識，明確標示不確定之處，而不是猜測。
