# 目的
將會議逐字稿轉成可執行的待辦清單，每一條都必須包含：
- 待辦事項
- 負責人
- 期限

# 處理步驟
1. **先通讀逐字稿**，找出所有明確或隱含的行動項目。
2. **只保留可執行事項**：
   - 要有人去做
   - 有明確結果或交付物
   - 不是純討論、背景說明或重複確認
3. **為每個待辦補齊三個欄位**：
   - **待辦事項**：用簡短、動詞開頭的句子描述
   - **負責人**：優先採用逐字稿中明示的人名；若只提到職稱或團隊，照原文寫出
   - **期限**：優先採用逐字稿中明示的日期、時間或相對期限（例如「本週五前」、「下次會議前」）
4. **若逐字稿沒有明確負責人**，不要自行猜測；改寫為「待確認」並保留原文可推得的線索。
5. **若逐字稿沒有明確期限**，不要自行編造；寫成「待確認」並保留原文提到的時間線索。
6. **合併重複項目**：同一件事若被多次提到，整理成一條，避免重複。
7. **拆分複合項目**：若一條包含多個不同動作，拆成多條待辦，讓每條都能單獨指派與追蹤。
8. **保留必要上下文**：若待辦需要背景才能理解，可在事項中加上簡短補充，但不要寫成長段落。

# 輸出格式
使用清楚的清單或表格，建議格式如下：

| 待辦事項 | 負責人 | 期限 |
|---|---|---|
| ... | ... | ... |

# 品質檢查
在輸出前確認：
- 每一條都有負責人
- 每一條都有期限
- 沒有把推測當成事實
- 沒有遺漏明確提到的行動項目
- 沒有把討論內容誤寫成待辦
