# 每日新聞標題摘要寄信流程

此技能用於「每天早上把三個新聞網站的標題整理成 5 條摘要寄到信箱」的工作。若沒有可用的網頁瀏覽與寄信工具，或沒有提供新聞網站與收件信箱，先停止並向使用者索取必要資訊。

## 先確認的資訊
1. 三個新聞網站的網址。
2. 收件者信箱地址。
3. 寄送時間與時區（例如每天早上 08:00，Asia/Taipei）。
4. 是否只取首頁標題，或指定版面/分類。
5. 摘要語言與風格（預設：繁體中文、精簡、中性）。

## 執行步驟
1. 在每天早上指定時間收集三個新聞網站的最新標題。
2. 只擷取標題與必要的來源資訊，不要加入未驗證的內容。
3. 去除重複或高度相似的標題。
4. 將三個網站的標題整合成 5 條摘要：
   - 每條摘要應涵蓋一個主要新聞主題。
   - 優先保留跨網站重複出現或最重要的新聞。
   - 若標題過多，先按主題分群，再濃縮成一句話。
5. 每條摘要都要清楚、短句化，避免推測細節。
6. 在信件中附上來源網站名稱，必要時列出對應標題。
7. 寄出前檢查：
   - 是否確實只有 5 條摘要。
   - 是否沒有捏造內容。
   - 是否包含三個網站的資訊來源。

## 建議信件格式
主旨：每日新聞摘要（YYYY-MM-DD）

內文：
早安，以下是今天的 5 條新聞摘要：

1. ...
2. ...
3. ...
4. ...
5. ...

來源：
- 網站 A
- 網站 B
- 網站 C

## 品質規則
- 只根據實際看到的標題撰寫摘要。
- 不要加入評論、預測或未確認資訊。
- 若某網站當天無法存取，明確註明缺少來源，並只用可取得的標題整理；若來源不足以形成可靠摘要，先回報使用者。
- 若標題語言混雜，摘要仍以使用者指定語言輸出。

## 無法自動完成時
如果目前環境沒有網頁存取、排程或寄信能力，請告知使用者：
- 需要哪些工具或權限才能自動化。
- 目前只能提供摘要撰寫規則與手動流程，不能直接完成抓取與寄送。
