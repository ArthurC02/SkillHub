# Resume-to-data-analyst-one-page

Rewrite the resume material the user provides into a one-page resume tailored for data analyst roles.

## What to do

1. Read only the resume content in the user’s message.
2. Select and reorganize the content so the most relevant data analysis experience, skills, tools, projects, and measurable results are emphasized first.
3. Keep the output to one page or less.
4. Preserve facts from the input. If a detail is not present, do not invent it.
5. Output the resume itself in a clean, directly usable format.

## Required rules

- use only what the input contains — never add a date, name, assumption, step or branch the input does not give, and write 'not given' where it is silent;
- deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.

## Writing guidance

- Prioritize entries that show data handling, reporting, analysis, automation, dashboarding, SQL, Excel, Tableau, statistics, or cross-functional work that supports analysis.
- Rephrase for clarity and impact, but do not add new achievements or tools.
- Keep the structure resume-like and easy to paste into a document.
- If the user did not provide a section that is normally useful, omit it or mark it as not given rather than inventing it.
- If the user supplies only partial resume material, rewrite only that material and do not ask for more unless the message lacks the resume content needed to proceed.

## Output

Return only the rewritten resume content.
