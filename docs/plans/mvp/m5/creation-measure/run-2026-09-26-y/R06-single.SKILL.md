## 目標
將一份英文使用手冊完整翻譯為繁體中文，保留原意、語氣與操作順序；所有專有名詞在第一次出現時以「繁中譯名（原文）」呈現，之後統一使用繁中譯名。

## 翻譯原則
1. **完整性優先**：不得省略段落、步驟、警告、注意事項、表格、標題、圖說或按鈕文字。
2. **忠實且自然**：保留技術含義與操作指示，譯文要符合繁體中文使用習慣。
3. **專有名詞處理**：
   - 第一次出現時寫成「繁中譯名（原文）」。
   - 若原文本身就是常見介面文字、產品名、功能名或縮寫，仍需在首次出現時保留原文。
   - 後續出現時只用繁中譯名；若該詞在同一段落內反覆出現，可視可讀性適度省略重複原文。
4. **術語一致**：同一術語全篇固定同一譯法；不要在不同章節改譯。
5. **格式保留**：盡量維持原手冊的章節層級、編號、項目符號、表格結構與強調格式。
6. **介面文字**：按鈕、選單、欄位名稱、錯誤訊息等若屬產品介面內容，翻譯時保留原文首次出現格式，並盡量與原介面語氣一致。
7. **單位與數值**：數字、單位、型號、版本號、路徑、命令、代碼、網址、檔名通常保留原樣；必要時可在中文說明中補充解釋，但不要改動其技術內容。

## 工作步驟
1. 先通讀全文，辨識：
   - 章節結構
   - 重複術語
   - 專有名詞、產品名、功能名、按鈕名、縮寫
   - 警告、注意、提示、前置條件與步驟
2. 建立一致的術語譯法，優先採用：
   - 原手冊內部前後一致的用法
   - 常見繁中技術譯名
   - 若無明確慣用譯法，採直譯且保持可理解
3. 逐段翻譯，保持原有順序與層級。
4. 首次出現的專有名詞以「繁中譯名（原文）」呈現；若同一詞在標題中首次出現，也要遵守此規則。
5. 檢查是否有：
   - 遺漏段落或列表項
   - 術語前後不一致
   - 原文格式被破壞
   - 首次出現未附原文
6. 若原文有不清楚、掃描錯字或語意模糊之處，保留最保守且可理解的譯法，不要自行補寫不存在的內容。

## 輸出要求
- 只輸出繁體中文譯文，不要附翻譯說明、註解或雙語對照，除非原文要求。
- 保留原手冊的標題層級與段落結構。
- 若原文包含表格，請以可讀的 Markdown 表格或等效結構重現。
- 若原文包含清單、警告框、步驟編號，請維持其順序與語氣。
