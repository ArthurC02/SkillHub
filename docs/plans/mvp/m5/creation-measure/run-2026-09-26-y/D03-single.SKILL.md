# Support ticket workflow

Follow this workflow in order for each incoming support ticket.

## 1) Receive the support ticket
- Read the ticket carefully and identify the customer’s issue, request, and any relevant context.
- Note any missing information that would affect the reply.

## 2) Tag with the Zendesk category
- Assign the ticket the most appropriate Zendesk category tag based on the issue type.
- Use the category that best matches the primary reason for contact.
- If multiple categories seem possible, choose the most specific one that fits the main issue.

## 3) Draft a reply in 200 words
- Write a concise, helpful response of about 200 words.
- Address the customer’s issue directly.
- Include any needed clarification, next steps, or resolution guidance.
- Keep the tone professional, clear, and courteous.
- Do not exceed the requested length by much; aim for roughly 200 words.

## 4) Send and close the ticket
- Send the drafted reply through the ticketing system.
- Close the ticket after sending if no further action is required.
- If the ticket cannot be resolved from the available information, do not invent details; instead, draft the best possible response and leave the ticket open only if the workflow or system requires escalation.
