# 目的
將一週的每日花費整理成清楚的表格，為每筆支出標示類別，並在週末計算各類別合計。

# 適用情境
- 使用者提供一週內的花費明細，要求整理成表格。
- 使用者要求每筆支出加上類別。
- 使用者要求在週末或週結時，統計各類別總額。

# 工作流程
1. **先確認資料是否完整**
   - 需要至少包含：日期、金額、用途/項目。
   - 若缺少類別，根據用途推定最合理的類別；若無法判定，標為「其他」。
   - 若缺少日期或金額，先向使用者補問，不要自行補值。

2. **建立每日明細表**
   - 以一週為單位，按日期排序。
   - 每筆支出至少包含以下欄位：
     - 日期
     - 項目/用途
     - 類別
     - 金額
   - 若同一天有多筆支出，逐筆列出，不要合併，除非使用者明確要求合併。

3. **統一類別名稱**
   - 將相近項目歸入一致類別，避免同義不同名。
   - 建議類別可包含：
     - 餐飲
     - 交通
     - 生活用品
     - 娛樂
     - 醫療
     - 通訊
     - 住宿
     - 教育
     - 其他
   - 若使用者已有指定類別，優先沿用使用者的分類。

4. **計算週末各類別合計**
   - 將整週所有支出依類別加總。
   - 若同一類別跨多天出現，合併計算。
   - 需要時也可附上總支出。

5. **輸出格式**
   - 先輸出「每日花費表」。
   - 再輸出「週末類別合計表」。
   - 表格欄位建議如下：
     - 每日花費表：日期｜項目/用途｜類別｜金額
     - 類別合計表：類別｜合計金額
   - 金額格式保持一致，必要時保留到小數點後兩位。

# 判定規則
- 食物、飲料、外食、超商餐點 → 餐飲
- 公車、捷運、計程車、油錢、停車費 → 交通
- 衛生紙、清潔用品、日用品 → 生活用品
- 電影、遊戲、聚餐娛樂、訂閱服務 → 娛樂
- 看診、藥品、保健品 → 醫療
- 手機費、網路費、通話費 → 通訊
- 房租、旅館、民宿 → 住宿
- 書籍、課程、學費 → 教育
- 無法明確歸類 → 其他

# 注意事項
- 不要憑空捏造不存在的支出。
- 不要把不同日期的支出混在一起。
- 若使用者提供的是圖片、截圖或手寫內容，先辨識出每筆支出，再依上述流程整理。
- 若資料量很大，仍需保持逐筆可追溯，不要只給總額。
