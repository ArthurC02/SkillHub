# Excel 客戶名單去重與缺電話標記

依照下列步驟處理 Excel 名單：

1. **確認資料欄位**
   - 找出客戶名單中用來判斷重複的欄位。
   - 若沒有明確規則，優先使用「姓名 + 電話」作為去重依據；若電話欄位缺失，則以其他可辨識欄位（例如姓名、公司、Email）組合判斷。
   - 找出電話欄位名稱，確認哪些列是空白、缺值、只有空白字元，或格式明顯不是電話。

2. **先備份原始資料**
   - 在原檔中另存新版本，避免直接覆蓋原始資料。
   - 若可行，先複製工作表再進行清理。

3. **標記缺少電話的列**
   - 新增一欄，例如「電話狀態」或「缺電話標記」。
   - 對電話欄位為空白、僅有空白字元、或明顯缺漏的列，標記為「缺少電話」。
   - 其餘列標記為「有電話」或留白，依使用者需求一致處理。

4. **去除重複資料**
   - 先決定保留規則：通常保留第一筆出現的資料，或保留電話較完整、資訊較完整的一筆。
   - 依前述重複判斷欄位找出重複列。
   - 刪除重複列時，保留一筆代表資料，不要同時刪除所有重複項。
   - 若同一客戶有多筆資料但電話不同，先依使用者指定的規則處理；若未指定，保留資訊最完整的一筆。

5. **檢查結果**
   - 確認剩餘資料筆數合理，且重複列已移除。
   - 確認所有缺電話列都已被正確標記。
   - 檢查是否有因空白、前後空格、大小寫不同而漏判的重複資料。

6. **輸出整理後的檔案**
   - 保留原始欄位與新增的標記欄位。
   - 若需要，另存為新檔，避免覆蓋原始檔。

7. **若規則不明，先詢問**
   - 若無法判定重複依據，或電話欄位名稱不明，先向使用者確認。
   - 若資料中有多個可能的電話欄位，也先確認要使用哪一欄。

注意：此技能只負責資料清理與標記；若需要實際開啟、編輯或儲存 Excel 檔，需在可操作檔案的環境中執行。
