## 目的
收到客戶退貨申請時，先判斷是否在購買日起 7 天內，再輸出對應的標準回覆信件。

## 判斷步驟
1. 先取得必要資訊：
   - 購買日期
   - 退貨申請日期
   - 若有，訂單編號與商品名稱
2. 計算兩個日期相差的天數。
3. 依規則判斷：
   - **7 天內（含第 7 天）**：可受理退貨，使用「受理退貨」標準信件。
   - **超過 7 天**：不可受理退貨，使用「超過期限」標準信件。
4. 若日期資訊不足或無法判斷，先要求補齊日期，不要直接下結論。

## 標準信件
### A. 7 天內：受理退貨
- 主旨：`退貨申請已受理`
- 內文需包含：
  1. 感謝聯繫
  2. 告知申請在 7 天內，已可受理退貨
  3. 說明後續退貨流程或請客戶依指示辦理
  4. 若需要，請客戶提供訂單編號以便處理

### B. 超過 7 天：不受理退貨
- 主旨：`退貨申請未能受理`
- 內文需包含：
  1. 感謝聯繫
  2. 說明申請已超過 7 天期限，因此無法受理退貨
  3. 保持禮貌與同理，不要爭辯
  4. 若適用，可建議改以其他協助方式處理

## 寫作要求
- 只輸出對應的標準信件，不要額外解釋判斷過程。
- 語氣要禮貌、清楚、簡潔。
- 若有訂單編號或商品名稱，應自然帶入信件中。
- 不要自行延伸未提供的退貨政策細節。
