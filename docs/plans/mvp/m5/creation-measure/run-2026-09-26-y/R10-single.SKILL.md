## 目的

每週從三個 Slack 頻道中找出「問題但尚未被回覆」的訊息，整理成可直接貼出的清單，並附上每則訊息的連結。

## 適用時機

- 使用者要你做每週 Slack 問題彙整
- 需要從三個頻道中找出未回覆的提問
- 需要輸出成清單並保留原始訊息連結

## 作業步驟

1. **確認範圍**
   - 先確認要檢查的三個 Slack 頻道名稱或連結。
   - 若使用者沒有提供，先請對方指定三個頻道，因為無法自行猜測。
   - 確認時間範圍是「最近一週」或使用者指定的週期。

2. **找出問題訊息**
   - 在每個頻道中找出看起來是在提問、求助、請確認、請協助的訊息。
   - 優先判斷以下類型為問題：
     - 含有問號
     - 使用「請問」「有人知道」「可以幫忙」「想確認」等語句
     - 明確要求回覆或協助的訊息
   - 排除純公告、閒聊、已完成事項、轉貼資訊。

3. **判斷是否已回覆**
   - 檢查每則問題訊息下方是否已有回覆。
   - 若有明確回覆、解答、確認、接手或後續處理，視為已回覆，不列入清單。
   - 若只有表情符號反應、未形成文字回覆，仍視為未回覆。
   - 若回覆內容只是延伸討論但沒有回答原問題，保守起見仍可列入，並在理由中註明「未見明確答覆」。

4. **整理未回覆項目**
   - 只保留未回覆的問題。
   - 每則項目至少包含：
     - 頻道名稱
     - 發問者
     - 問題摘要
     - 訊息連結
   - 若同一串討論中有多則相近問題，合併為一項，避免重複。

5. **排序原則**
   - 依時間由新到舊或依頻道分組皆可，但整份輸出要一致。
   - 若使用者沒有指定，建議先依頻道分組，再在各頻道內按時間排序。

6. **輸出格式**
   - 用簡潔清單輸出。
   - 每一項一行或一個條目，格式固定，方便複製。
   - 建議格式：
     - `- [頻道名] 發問者：問題摘要｜連結`
   - 若需要更清楚，可加上日期或時間：
     - `- [頻道名] 2026-09-26 發問者：問題摘要｜連結`

## 注意事項

- 不要把已經有人回覆的問題列進去。
- 不要臆測回覆內容；看不到明確文字回覆時，才列為未回覆。
- 若無法存取 Slack、無法查看訊息串或無法取得連結，應明確說明限制，並請使用者提供匯出內容或可讀取的訊息資料。
- 若三個頻道名稱不明確，先詢問，不要自行補齊。
