# 新人到職流程

依照流程圖中的順序執行或整理新人的到職作業。此技能只描述流程本身；若實際執行需要登入系統、寄送郵件或聯絡他人，則由代理人依現有權限完成，無法完成的部分要明確標示並向使用者確認。

## 流程順序

1. **收到新人到職通知**
   - 確認新人姓名、到職日、部門、職稱、主管與聯絡方式。
   - 若資訊不完整，先補齊再往下進行。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認帳號命名規則、權限與是否需要轉寄設定。

3. **加入 Slack 頻道**
   - 將新人加入必要的 Slack 頻道。
   - 至少包含部門、公告與新人導覽相關頻道；若公司有固定清單，依清單加入。

4. **準備筆電與門禁卡**
   - 安排新人所需的筆電、配件與門禁卡。
   - 確認設備已可使用、帳號已登入或已可初始化。

5. **安排第一週訓練**
   - 排定新人第一週的訓練內容與時程。
   - 包含公司制度、工具使用、部門工作流程與必要的安全/資安訓練。

6. **指派導師**
   - 為新人指定導師或 buddy。
   - 記錄導師姓名、聯絡方式與支援範圍。

7. **第 30 天面談**
   - 安排到職第 30 天的回顧/面談。
   - 準備要確認的項目：適應狀況、訓練成效、問題與後續支援。

8. **記錄到人資系統**
   - 將上述完成狀態與必要資訊登錄到人資系統。
   - 若某步驟尚未完成，註明原因、負責人與預計完成時間。

## 執行原則

- 嚴格依照上述順序處理，除非使用者明確要求調整。
- 每完成一步就更新狀態，避免遺漏。
- 若流程圖未提供細節，不要自行補充公司政策；改為提出需要確認的資訊。
- 若無法實際操作某系統，請回報可完成的部分與待辦事項。
