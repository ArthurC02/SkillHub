## 目標
根據房東提供的資料，寫出一封可直接貼上寄出的租金催繳通知信，清楚列出欠繳月份、各期金額、欠繳總額及繳款期限。

## 作業步驟
1. 擷取房客姓名、欠繳月份、金額，以及明確的繳款期限。若房東另外提供寄件人姓名、付款方式、匯款資訊或聯絡方式，才將其納入信中。
2. 檢查資料是否足以列出明細並計算總額：
   - 若每個月份各有金額，逐月列出，並加總確認總額。
   - 若提供的是每月固定租金，且明確指出哪些月份欠繳，按月份計算並列出各月金額與總額。
   - 若只提供總額，卻要求欠繳明細，或月份、金額對應不清、總額與明細加總不符，先簡短詢問缺少或矛盾之處；不要猜測，也不要產出含不確定數字的信。
   - 若繳款期限未提供或日期不明確，先詢問期限，不要自行設定。
3. 使用房東提供的日期、月份、幣別與金額格式。除非資料明確，勿假定幣別、租約內容、付款狀況或其他背景事實。
4. 以繁體中文撰寫，語氣禮貌、直接且堅定。內容至少包括：
   - 清楚的主旨，例如「租金繳款提醒」。
   - 對房客的稱呼。
   - 說明目前仍有租金未繳，並逐項列明欠繳月份及金額。
   - 欠繳總額。
   - 請房客於指定期限前繳清；如房東提供付款方式或帳戶資訊，照原資料列出。
   - 請房客於完成付款後告知，或如已付款請回覆核對（可用中性、簡短語句）。
   - 適當的結尾。只有在房東提供姓名時才以其姓名署名；不可留下待填佔位符。
5. 只輸出可直接寄出的信件內容，包含主旨與正文；不要附上分析、提醒或未提供資料的佔位符。若資料不足，則只提出必要的澄清問題。

## 內容限制
- 不得捏造催繳紀錄、已通知日期、付款承諾、滯納金、利息、法律後果、解約或其他處置。
- 不要把一般提醒寫成法律通知，也不要聲稱已採取任何行動。
- 不擅自改動房東提供的期限；期限前後用語須與日期一致。
