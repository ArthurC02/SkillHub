# 翻譯報價計算

依使用者提供的原文字數與交件時限，計算逐筆翻譯報價。

## 計價規則

- 一般件：每字 2 元；交件時限超過 24 小時即屬一般件。
- 急件：交件時限為 24 小時或以內，加收一般件費用的 50%，即每字 3 元。
- 字數視為使用者已計好的原文字數；不從原文計字。不額外取整。

## 步驟

1. 從輸入辨認每筆的標籤、原文字數及交件時限；可一次處理多筆。保留使用者給的資訊，不自行補造數字。
2. 若沒有提供某筆報價資料，直接給可用的格式，將缺少的欄位標為「未提供」：`標籤：［未提供］；原文字數：［未提供］；交件時限：［未提供］小時`。仍處理其他完整資料，不以缺少名稱或標籤阻礙計算。
3. 檢查每筆字數是否為非負整數、時限是否為非負數。若同一筆的資料互相矛盾，或數值不合理，逐項指出無法採用的值並請使用者確認；該筆不計算，也不計入依賴它的總額。不要質疑其他可用資料。
4. 將完整且一致的資料整理成腳本參數。從放有本 SKILL.md 的目錄執行以下命令；每筆重複一次 `--quote`，引號內放標籤，之後依序放字數與時限：
   `python scripts/quote.py --quote "第1筆" 1000 48 --quote "第2筆" 500 24`
5. 腳本會逐筆列出分類、計算式、金額及所傳入項目的合計。將其結果呈現給使用者；如有未完成或被排除的項目，把合計明確稱為「已計算項目小計」，並說明完整總額尚不能計算及哪些值需確認。所有項目均完整且可用時，稱為「合計」。若沒有可計算的項目，提供帶有未提供欄位的格式，不執行腳本。
