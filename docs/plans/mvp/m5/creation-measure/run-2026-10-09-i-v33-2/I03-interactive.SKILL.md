## 步驟

1. 閱讀本次提供的客人訂單訊息；只整理這則訊息中的內容，不查外部資料、不推測價格，也不把外送車資算入品項金額。
2. 逐項抽出品名、數量、計價單位與單價。保留原訊息提供的品名、單位與金額；將「一打」換算為 12，同一計數單位明確寫成「兩打」等數量時按每打 12 換算。明示「免費」或 0 元的贈品照列。訊息缺少的欄位記為「未提供」；含糊、互相矛盾或無法由本訊息確認的欄位記為「待確認」。不得用猜測補值；同一欄位有不同說法時，將該欄位列為待確認。
3. 將每個品項整理為 JSON 陣列，欄位使用 `name`、`quantity`、`unit`、`unit_price`。數量填數字；單位填文字；單價填數字或 `免費`。缺少或待確認的欄位分別填 `未提供` 或 `待確認`。品名未提供時可省略 `name`。將實際 JSON 設為 shell 變數 `ITEMS_JSON`，再執行：

   `python scripts/quote.py --items "$ITEMS_JSON"`

4. 若訊息提及外送車資，將車資金額設為 shell 變數 `DELIVERY_FEE`；金額不明時設為 `未提供`。重新執行並附上該選項：

   `python scripts/quote.py --items "$ITEMS_JSON" --delivery-fee "$DELIVERY_FEE"`

   此選項只產生備註，不會納入品項小計或總額。若腳本以錯誤碼 2 結束，照其單行訊息列明無法使用的值，不要以該值計算；其他欄位仍可整理。修正抽取時確有誤讀的值後再執行；若輸入本身有衝突或無法確定，就將該欄位標為「待確認」再執行。
5. 將腳本印出的表格、已確認品項總額及必要備註直接作為本次答覆。若有待確認或未提供的品項金額，保留腳本的總額涵蓋範圍說明，不把該項目加入總額。若未提供訂單訊息，直接給出可用的報價表模板，缺少的內容標為「未提供」，不提問。
