## 目的

逐筆將借閱紀錄分為且只分為以下四種處理等級：**賠償、停借、提醒、免處理**。依下列優先順序判定，不要自行增加規則、罰款或其他處理方式。

## 讀取與檢查紀錄

1. 將館員提供的資料拆成一筆一筆紀錄，保留每筆的讀者資訊以便對應結果。
2. 每筆需要判定的欄位為：讀者、證別、逾期天數、是否已回報遺失。
3. 先檢查「是否已回報遺失」：
   - 若明確為「是」，直接判為**賠償**；不需要再考慮證別或逾期天數。
   - 若明確為「否」，繼續檢查逾期天數與證別。
   - 若欄位缺漏或值不明，且無法確定是否已回報遺失，不要猜測；將該筆列在待補資料清單中。
4. 對未遺失紀錄，確認逾期天數是可判讀的非負整數，證別可明確辨認為「兒童證」或「一般證」。缺漏、格式錯誤、負數或無法辨認的欄位，列為待補資料，不要替該筆指定處理等級。

## 判定流程

對已確認「未回報遺失」的紀錄，依序套用：

1. 逾期 **0 天**：判為**免處理**。
2. 逾期 **1 天以上**，且持**兒童證**：判為**提醒**。兒童證規則優先於停借門檻。
3. 逾期 **1 至 7 天**，且持**一般證**：判為**提醒**。
4. 逾期 **8 天（含）以上**，且持**一般證**：判為**停借**。

已回報遺失的紀錄一律依前述規則判為**賠償**，不受逾期天數或證別影響。

## 輸出

- 依輸入順序逐筆列出結果，使用表格，至少包含「讀者」與「處理等級」欄；可加上「判定依據」欄，簡短說明適用的規則。
- 「處理等級」欄只能使用**賠償、停借、提醒、免處理**四種值。
- 若有資料不足的紀錄，另列於表格之外，指出讀者或原始紀錄位置，以及需要補充或更正的欄位；不要把待補資料當成第五種處理等級，也不要擅自推定結果。
- 不要省略任何可判定的紀錄，也不要合併不同讀者的紀錄。若同一讀者有多筆紀錄，逐筆保留並分別判定。
