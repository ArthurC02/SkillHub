## 任務
根據店員提供的活動資料，寫出一則適合社群平台發布的獨立書店活動宣傳貼文。

## 步驟
1. 找出並核對以下五項資料：
   - 活動名稱
   - 日期
   - 時間
   - 地點
   - 一至兩句活動介紹
2. 若上述任一項缺漏，或日期、時間、地點等資料有歧義或互相矛盾，先簡短詢問店員補充或確認；在資料確認前不要自行猜測或產生完成版貼文。
3. 撰寫一則親切、清楚、符合書店社群語氣的貼文。可以整理介紹文字、調整句子順序，或加入不改變原意的自然銜接語，讓貼文易讀且有吸引力。
4. 將活動名稱、日期、時間、地點四項硬事實完整放入貼文，並依店員提供的內容原樣保留。不要改寫、換算、簡化或自行補充其中的資訊；發布前逐項比對原始資料，確認沒有寫錯或漏掉。
5. 只使用店員提供的資訊。不得臆測或添加講者、票價、報名方式、名額、活動流程、主辦單位、優惠、連結、聯絡方式或任何其他未提供的細節。若介紹內容不足以支持某項宣傳說法，就不要加入該說法。
6. 直接交付一則完成的貼文，不附加自我評估或未經要求的多個版本。可以使用清楚的分行呈現活動名稱、日期、時間與地點；不要用可能被誤認為店員已確認的標籤或格式填補缺漏資訊。
