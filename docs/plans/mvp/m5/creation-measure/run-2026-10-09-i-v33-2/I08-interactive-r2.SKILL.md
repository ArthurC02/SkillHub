# 餐廳食材叫貨單整理

將廚房提供的口語叫貨訊息整理成繁體中文 Markdown 表格；每筆叫貨單各自計算，不把不同叫貨單的金額合併。無需外部工具。

## 步驟

1. 閱讀使用者提供的全部叫貨訊息，按訊息中明確標示的叫貨單分組；沒有標示叫貨單時，視為一筆叫貨單。格式未指定時，使用 Markdown 表格。不要因缺少姓名、叫貨單名稱或日期而停止整理。
2. 從原文逐筆摘錄品項、數量、單位、單價、價格單位／幣別及日期。保留原文寫法與精度，不換算、不補造；缺少的欄位標示「未提供」。將每個品項出現的數量都保留，以便檢查矛盾；不要自行選一個數量。
3. 建立輸入資料檔，將摘錄內容轉成下列 JSON 結構；每個叫貨單使用一個物件，每個品項紀錄使用一個 item 物件。缺少的值填 `null`，數值欄位只放原文數字字串。`name` 是叫貨單標籤，`date` 是日期，`item` 是品項名稱，`quantity` 是數量，`unit` 是數量單位，`price` 是單價數字，`price_unit` 是單價的單位／幣別文字。

   ```json
   {"orders":[{"name":null,"date":null,"items":[{"item":null,"quantity":null,"unit":null,"price":null,"price_unit":null}]}]}
   ```

4. 從含有本 SKILL.md 的目錄執行下列命令。把步驟 3 的實際 JSON 內容放在 heredoc 中，存成 `/tmp/restaurant-order-input.json`；不要把示例的 `null` 當成原文資料。腳本會驗證明確日期、找出同單同品項的數量衝突與負數，計算可用的小計及總額，並輸出完整的繁體中文整理結果。直接呈現腳本輸出的內容，不另行改寫或補算。

   ```sh
   cat > /tmp/restaurant-order-input.json <<'JSON'
   {"orders":[]}
   JSON
   python scripts/order_calc.py --input /tmp/restaurant-order-input.json
   ```

5. 對標記的衝突、負數或不存在日期，以「待確認」說明是哪個值有問題，並在整理結果中明確請負責人確認；不計算依賴問題資料的小計或總額。其他有效品項的小計仍照常列出。只有在一筆叫貨單的所有小計都已知、日期有效（或未提供），且沒有數量衝突或負數時，才列該單總額。若缺少欄位或價格單位不一致，照腳本輸出指出未提供／不能合計，不猜測或換算。
6. 以整理結果本身作為回答；最後保留腳本輸出的確認責任說明，不以問題句結尾。
