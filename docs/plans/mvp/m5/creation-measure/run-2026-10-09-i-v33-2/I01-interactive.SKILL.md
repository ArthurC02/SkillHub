# 共享會議室租借費計算

根據一次租借的實際使用分鐘數，計算計費單位、各級費用、上限前費用與應收金額。每次只計算一筆；不加入稅金、折扣或其他未提供的規則。

## 步驟

1. 從輸入找出這次租借的實際使用分鐘數。若沒有提供，採用「分鐘數未提供」的預設狀態；不可猜測數值，直接執行不帶分鐘數的命令，讓輸出提供可用模板。若同一次租借出現不同分鐘數，逐一照原文列出這些值，標示需要確認，並且不計算費用。
2. 若分鐘數是負數、不是可用的整數，或其他輸入值無法使用，不要自行修正或計算；照腳本的單行錯誤訊息指出該值需確認。不要追問其他事項。
3. 在此 `SKILL.md` 所在目錄開啟 shell。將輸入中提供的非負整數分鐘數原樣放入 shell 變數 `MINUTES`，再執行：

   ```sh
   python scripts/room_fee.py --minutes "$MINUTES"
   ```

   若分鐘數未提供，執行：

   ```sh
   python scripts/room_fee.py
   ```

4. 將腳本輸出的計費單位、分級費用、上限前費用及應收金額交付給使用者；同時保留使用者提供的分鐘數原文，不改寫該事實。若輸出是未提供分鐘數的模板，直接交付模板，不能替空白補值。
