# 活動攝影服務報價

依照使用者提供的拍攝時數與修圖張數，逐筆計算報價。可在同一則訊息中處理多筆。

## 步驟

1. 從訊息辨認每筆報價的拍攝時數與修圖張數，保留使用者給的數值與筆次。拍攝時數和修圖張數都應是整數；修圖張數依預設視為非負整數。若使用者沒指定貨幣單位，沿用規格中的「元」。
2. 若某筆缺少時數或張數，照樣交付該筆的報價模板，把未提供的欄位標為「未提供」，不要代填，也不要算依賴該欄位的費用。繼續處理其他資料完整的報價。
3. 找出不能使用的值：例如負數、非整數、無法辨認的數值，或同一筆資料對同一欄位給了互相衝突的值（包括後文改動前文）。逐一標出筆次、欄位和原值，要求使用者確認；受影響的筆次不計算。不要對其他資料提出無關問題。
4. 對資料完整且沒有衝突的報價，從本 SKILL.md 所在目錄執行以下命令格式；每筆加一個 `--quote`，值為 `拍攝時數:修圖張數`。例如，將辨認到的數值代入命令：

   ```bash
   python scripts/quote.py --quote '拍攝時數:修圖張數' --quote '拍攝時數:修圖張數'
   ```

   一筆報價只提供一個 `--quote`。沒有任何完整報價可計算時，不執行腳本。
5. 將腳本印出的每筆拍攝費、修圖費、封頂前總額和封頂後應收總額原樣呈現。對缺少欄位的筆次提供可直接補值的模板，並把缺少的欄位標為「未提供」；對不能使用的值列出確認事項。保留所有已提供的事實，不把任何已知資料標成待提供。若有完整報價可計算，也一併交付其結果；結尾不另加問題、計畫或承諾。
