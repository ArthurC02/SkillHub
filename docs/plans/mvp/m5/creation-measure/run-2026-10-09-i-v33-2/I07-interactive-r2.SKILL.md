## 用途
依房東提供的資料，準備一封繁體中文、正式而有禮貌的租金催繳通知信。只整理已提供的事實；不代替房東寄信。

## 步驟
1. 從輸入辨認房客姓名、每筆欠繳月份與該月金額、繳款期限。假設列出的欠繳明細就是本次要催繳的全部明細；金額照輸入呈現，不添加幣別。只在來源有明確資料時才加入其他資訊。
2. 保留所有已提供的事實。姓名、期限或明細缺漏時，不追問；信中以「（未提供）」標示缺少的欄位，並提供可用的通知信範本。缺少的明細金額不視為零。若知道有一筆欠款但該筆金額未提供，勿把已知金額小計說成欠款合計。
3. 將月份整理成 `YYYY-MM`、期限整理成 `YYYY-MM-DD`，作為計算器輸入；信件中的月份、金額、期限仍按原資料呈現。對每筆已提供金額使用一次 `--item 'YYYY-MM=金額'`，重複選項以列出多個月份。資料不完整時加上 `--incomplete`；若同一月份、姓名或期限有不同說法，將各說法分別傳入對應的重複選項。執行：
   `python scripts/sum_rent.py --item 'YYYY-MM=金額'`
   將命令中的月份與金額替換為來源所載值；有多筆明細時，每筆各加一個 `--item`。有姓名或期限可供驗證時，分別使用 `--tenant '姓名'` 與 `--deadline YYYY-MM-DD`；有多個說法時重複該選項。資料不完整時在命令中加入 `--incomplete`。從 Skill 所在目錄執行，讀取並呈現計算器輸出。
4. 若計算器以代碼 2 結束，逐一指出它列出的無法使用值，請房東確認每一項；不要提供依賴該值的合計。其他資料仍足以撰寫的部分照常整理，不詢問無關事項。遇到缺少資料而不是錯誤值時，依步驟 2 標示未提供，不把缺漏當成錯誤值。
5. 寫出信件，依序包含主旨、稱呼、簡短禮貌的催繳說明、逐月欠款明細、欠款合計、繳款期限與不需捏造個人資料的結尾。合計只採用計算器列出的結果；資料不完整時採用計算器所標示的小計與合計狀態。缺少合計或期限時標示「（未提供）」。不添加威脅、法律主張、特定司法管轄區的法律建議、未提供的付款方式或其他事實。輸出信件本身，讓房東可直接複製使用。
6. 若需說明寄送限制，將簡短說明置於信件之前，清楚標示為信件外備註；信件本身須從主旨開始，並以結尾收束。結尾後不得附加任何說明、限制聲明或操作提示。

## 可用時的執行格式
從含有本 SKILL.md 的目錄執行以下命令，並按步驟 3 將實際資料放入選項：

```sh
python scripts/sum_rent.py --item 'YYYY-MM=金額' --deadline YYYY-MM-DD --tenant '姓名'
```
