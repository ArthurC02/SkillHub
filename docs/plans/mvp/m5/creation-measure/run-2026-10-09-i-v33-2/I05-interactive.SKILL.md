## 工作流程

1. 讀取使用者貼上的停水通知，只以通知文字為依據；不查詢外部資料，也不補寫通知未提供的事實。
2. 從通知逐字擷取停水日期、停水時段及受影響棟別。若日期、時段或棟別未提供，在公告中以「日期未提供」、「時段未提供」或「受影響棟別未提供」標明；通知缺少必要資料時，仍提供可直接編修的公告，不要以提問取代交付。
3. 若同一項資訊出現互相矛盾的值，公告不得自行選定其一或把它當成已確認事實。保留矛盾的原文值，標明該項資訊無法判定，並以陳述句指出需由管委會確認的項目；不要詢問其他事項。
4. 撰寫繁體中文住戶群組公告：公告本文最多 3 句，保留日期、時段、受影響棟別及其原文寫法；可省略或合併其他資訊，不得改變其意思。通知若未提供標籤、名稱或日期，不要因此停下工作。
5. 在公告本文之外另寫恰好 1 句，明確指出省略或合併了哪些資訊。若沒有省略或合併的資訊，就明確寫出沒有省略或合併其他資訊。公告本文與說明句分開標示；說明句不計入公告本文的 3 句上限。
6. 將完整輸出（公告本文及其外的說明句）寫入 `answer.txt`。逐項確認公告本文不超過 3 句、說明恰好 1 句，並從通知擷取日期、時段和棟別原文，設為以下 shell 變數；缺少的項目不設為必須包含的值：

   ```sh
   DATE_TEXT='通知中的日期原文'
   TIME_TEXT='通知中的時段原文'
   BUILDING_TEXT='通知中的受影響棟別原文'
   ```

   用下列命令檢查完整輸出最多 4 句，並要求三項必要資訊都包含通知中有提供的原文。若檢查未印出 `OK`，修正 `answer.txt` 並重跑，直到印出 `OK`；最後只回覆 `answer.txt` 的內容。

   ```sh
   python scripts/check_output.py --max-sentences 4 --require "$DATE_TEXT" --require "$TIME_TEXT" --require "$BUILDING_TEXT"
   ```
