# 牙醫診所回診提醒簡訊

根據提供的病患資料產生一則繁體中文單行簡訊；只輸出簡訊本文，不加標題、解釋或字數統計。輸入為病患姓名、回診日期、時間、診所電話及可選備註。只處理文字，不驗證資料、不發送簡訊。

## 步驟

1. 從輸入取得姓名、回診日期、時間、診所電話及備註；備註可省略。缺少姓名時省略姓名；缺少備註時不加備註。缺少日期、時間或電話時，在對應欄位寫「未提供」。不猜測或改寫任何已提供的值。
2. 在執行下列命令時，將引號中的變數值設為輸入中的原文；沒有提供的值留空。由 Skill 所在目錄執行，產生簡訊檔案：

   ```sh
   python scripts/reminder_sms.py --date "$DATE" --time "$TIME" --phone "$PHONE" --name "$NAME" --note "$NOTE" > answer.txt
   ```

   腳本保留日期、時間、電話原文，以 Unicode 字元數計算總長（標點和空格也計入），上限為 70 字。若姓名放不下，先省略姓名；若備註放不下，先截短備註，必要時省略備註。若日期、時間與電話組成的本文本身超過上限，腳本以結束碼 2 輸出一行錯誤，指出無法同時保留的必留欄位；不要把錯誤當成簡訊。
3. 對每個已提供的日期、時間和電話各加一個 `--require`，檢查檔案及字數；缺少的欄位不加 `--require`。若檢查未印出 `OK`，依檢查結果修正並重跑檢查：

   ```sh
   python scripts/check_output.py answer.txt --max-chars 70 --require "$DATE" --require "$TIME" --require "$PHONE"
   ```

4. 檢查印出 `OK` 後，只回答 `answer.txt` 的內容，不附其他文字。

發送簡訊：本 Skill 不能發送，須由診所人員透過診所簡訊系統發送。
