# 社區圖書館逾期處理分級

依館員提供的借閱紀錄，逐筆判定處理等級，輸出讀者、處理等級與判定理由，並保留原順序。

## 步驟

1. 將館員提供的完整紀錄（包含欄名）原樣寫入 `records.txt`。欄位依序為「讀者、證別、逾期天數、已回報遺失」；可使用以 `｜`、`|` 或定位字元分隔的表格。只接受「兒童證」或「一般證」、「是」或「否」，以及非負整數天數。
2. 從包含本 `SKILL.md` 的目錄執行：
   ```sh
   python scripts/classify_overdue.py records.txt
   ```
3. 將腳本輸出的 Markdown 表格原樣交付；不得改變紀錄順序或增加其他處理等級。判定依序為：已回報遺失→「賠償」；未遺失且逾期 0 天→「免處理」；未遺失且逾期至少 1 天、持兒童證→「提醒」；其餘一般證逾期 1–7 天→「提醒」，8 天以上→「停借」。

輸入假設為完整且有效，證別及遺失狀態限於上述值。遇到無法使用的格式或值時，腳本會指出問題並停止，不會替該批紀錄判定。
