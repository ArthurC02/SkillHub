# 目的
根據「這個月的出勤紀錄」計算每個人的加班時數，並找出加班時數超過 46 小時的人員。

# 適用情境
- 輸入是本月出勤紀錄、打卡紀錄、工時表或類似資料。
- 需要按人彙總加班時數。
- 需要標示超過 46 小時的名單。

# 執行步驟
1. **確認資料範圍**
   - 只使用「本月」的出勤紀錄。
   - 若資料跨月，先排除非本月資料。
   - 若月份不明，先向使用者確認要計算哪一個月。

2. **辨識每筆紀錄的欄位**
   - 找出至少以下資訊：
     - 人員姓名或識別碼
     - 日期
     - 加班時數，或可推算加班時數的欄位
   - 若加班時數未直接提供，依資料中的規則計算；若規則不明，先請使用者提供計算方式。

3. **整理每個人的加班時數**
   - 將同一人的所有本月加班時數加總。
   - 若同一人有多筆紀錄，全部納入。
   - 若資料有重複或疑似異常值，先標記並說明，不要自行刪除，除非使用者明確要求。

4. **判斷是否超過門檻**
   - 以 46 小時為門檻。
   - 若某人本月加班總時數 **大於 46 小時**，標記為「超過 46 小時」。
   - 若剛好 46 小時，不算超過。

5. **輸出結果**
   - 以清楚表格列出：
     - 姓名/識別碼
     - 本月加班總時數
     - 是否超過 46 小時
   - 對超過 46 小時的人員加上明顯標記，例如：`⚠ 超過 46 小時`。

# 輸出格式建議
| 姓名 | 本月加班總時數 | 狀態 |
|---|---:|---|
| A員 | 48.5 | ⚠ 超過 46 小時 |
| B員 | 42.0 | 正常 |

# 注意事項
- 不要把正常工時誤算成加班時數。
- 若資料只有每日總工時，且沒有明確加班欄位，必須先確認加班計算規則。
- 若資料不足以計算，先列出缺少哪些欄位，再請使用者補資料。
