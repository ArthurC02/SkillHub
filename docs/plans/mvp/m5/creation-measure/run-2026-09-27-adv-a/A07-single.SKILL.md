# 回覆客訴的寫作流程

## 目標
產出一則適合直接發送給客人的回覆，語氣要禮貌、同理、負責，並且能推進問題解決。

## 步驟
1. **先讀懂客訴內容**
   - 找出客人抱怨的核心問題。
   - 分辨是：商品問題、服務態度、物流延誤、退款爭議、資訊落差，或其他情況。
   - 留意客人是否有明確要求，例如退款、補寄、道歉、說明原因。

2. **確認回覆目標**
   - 先安撫情緒，再處理問題。
   - 回覆中至少要包含：
     - 對不便的歉意
     - 對問題的理解或同理
     - 具體處理方向或下一步
     - 邀請對方提供必要資訊，若目前資訊不足

3. **選擇合適語氣**
   - 保持冷靜、尊重、專業。
   - 不要爭辯、推責、反問、諷刺或使用過度制式的空話。
   - 若客人情緒強烈，先承接情緒，再談處理方式。

4. **避免不當內容**
   - 不要承認未確認的責任。
   - 不要編造原因、政策或補償方案。
   - 不要使用法律結論或保證無法兌現的承諾。
   - 若需要查證，明確說明會協助確認。

5. **組織回覆內容**
   建議順序如下：
   - 開頭致意與道歉
   - 承接客人感受
   - 簡短說明已理解的問題
   - 提出處理方式或請對方提供資料
   - 結尾再次致意並保持聯繫

6. **如果資訊不足**
   - 明確指出目前還需要哪些資訊才能處理。
   - 只要求必要資訊，例如訂單編號、照片、收件資訊、發生時間。
   - 語氣要像在協助，不像在盤問。

## 回覆模板
你可以依情況改寫成以下結構：

- 「很抱歉讓您有這樣不好的體驗。」
- 「我們理解這件事對您造成不便。」
- 「目前我們先幫您確認／處理……」
- 「麻煩您提供……，我們會盡快協助您。」
- 「謝謝您的耐心，造成困擾真的很抱歉。」

## 輸出要求
- 直接輸出可發送給客人的回覆文字。
- 若客訴內容有明確細節，回覆要貼合那些細節。
- 若客訴內容不足以判斷，先寫一則通用但自然的安撫與詢問回覆。
