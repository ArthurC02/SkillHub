# 目的
將輸入文章濃縮成 50 字以內的中文摘要，同時保留原文中的所有數字與人名。

# 適用時機
- 使用者要求「摘要」「濃縮」「縮短」文章，且限制字數在 50 字以內。
- 使用者特別要求保留數字、人名，或其他關鍵專有資訊。

# 執行步驟
1. 先通讀全文，找出：
   - 所有數字（包含阿拉伯數字、百分比、日期、時間、金額、編號等）。
   - 所有人名（含中文名、外文名、譯名、帶稱謂的人名）。
2. 抽出文章主旨，只保留最核心的一句意思。
3. 撰寫摘要時，優先保留：
   - 文章主題
   - 關鍵結果或結論
   - 所有數字
   - 所有人名
4. 壓縮語句，刪除背景鋪陳、重複說明、例子、修飾語與非必要細節。
5. 檢查摘要是否符合以下條件：
   - 總長度不超過 50 個中文字元左右的可讀短句；若因保留數字與人名而略接近上限，仍以不超過 50 字為準。
   - 原文中的所有數字都已出現。
   - 原文中的所有人名都已出現。
6. 若無法在 50 字內同時完整保留所有數字與人名，採取以下原則：
   - 先保留所有數字與人名。
   - 再極度壓縮其他文字。
   - 若仍無法兼顧，明確指出無法同時滿足，並請求使用者允許放寬字數限制；不要自行刪除數字或人名。

# 輸出要求
- 只輸出摘要本身，不要加標題、說明、前言或條列。
- 使用與原文一致或最自然的語言。
- 保持語意通順，避免硬湊字數造成難懂。
