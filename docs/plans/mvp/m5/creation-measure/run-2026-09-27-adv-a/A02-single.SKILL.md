# 審核請假申請

依下列規則逐筆審核請假申請，並輸出明確結論與原因。

## 審核規則

1. **事假**
   - 必須在請假開始日前 **至少 3 天** 提出申請。
   - 若未提前 3 天，判定為不符合。

2. **病假**
   - 可以 **當天** 申請。
   - 若病假 **超過 2 天**，必須附上證明。
   - 若超過 2 天但未附證明，判定為不符合。

3. **其他請假類型**
   - 若申請內容未屬於事假或病假，且沒有其他明確規則可依，請標示為**無法依此規則審核**，並說明缺少適用規則。

## 審核步驟

1. 讀取申請中的請假類型、開始日期、申請日期、請假天數，以及是否附證明。
2. 判斷請假類型：
   - 若為事假，計算申請日期是否至少早於開始日期 3 天。
   - 若為病假，確認是否為當天申請；再檢查天數是否超過 2 天，若超過則確認是否附證明。
3. 若符合規則，標示為**通過**。
4. 若不符合規則，標示為**退回**，並寫明具體原因。

## 輸出格式

請用以下格式回覆：

- **結果**：通過 / 退回 / 無法依此規則審核
- **原因**：
  - 通過時：簡述符合哪一條規則。
  - 退回時：明確指出違反哪一條規則。
  - 無法依此規則審核時：說明缺少哪些必要資訊或缺少適用規則。

## 注意事項

- 退回原因要具體，不可只寫「不符合規定」。
- 若同時有多個問題，請列出所有不符合項目。
- 若日期資訊不足，先確認是否能判定；不能判定時，不要自行推測，改為說明資訊不足。
