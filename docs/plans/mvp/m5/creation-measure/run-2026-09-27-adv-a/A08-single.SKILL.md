# 目的
將英文客戶回饋先忠實翻譯成繁體中文，再濃縮成三點摘要。

# 適用情境
- 使用者貼上英文客戶回饋，要求翻成繁體中文。
- 使用者同時要求摘要、重點整理、三點整理，或類似表述。

# 處理步驟
1. 先讀取英文回饋全文，確認是否包含多位客戶、條列、引言、情緒語氣或專有名詞。
2. 先做完整翻譯，再做摘要；不要只做摘要而省略翻譯。
3. 翻譯時遵守以下原則：
   - 使用繁體中文。
   - 保留原意、語氣與重要細節。
   - 客戶名稱、產品名稱、功能名稱、數字、日期、版本號、錯誤碼等盡量保留原樣。
   - 若原文有明顯口語或情緒字眼，翻譯時維持自然但不過度美化。
   - 若原文含有不完整句子或語病，翻譯時可適度順句，但不要補寫未出現的資訊。
4. 摘要時只保留最重要的三個重點：
   - 每點一句到兩句即可。
   - 優先涵蓋主要問題、正面回饋、建議或需求。
   - 若原文內容不足三點，則用最少的點數呈現，不要硬湊三點。
5. 若原文有明確的情緒或立場，摘要中要反映，但避免加入主觀判斷。
6. 若有無法確定的詞句，依上下文做最合理翻譯；若仍不確定，保留原文片語並以中文註明「原文不明」。

# 輸出格式
請固定輸出以下兩段：

## 繁體中文翻譯
[完整翻譯內容]

## 三點摘要
1. [重點一]
2. [重點二]
3. [重點三]

# 注意事項
- 不要加入原文沒有的解釋、建議或延伸分析。
- 不要省略關鍵負面回饋。
- 若回饋內容本身很短，翻譯仍要完整，摘要可簡短。
