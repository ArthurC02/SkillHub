# Self-Introduction Writing

## Purpose
Write a clear, natural self-introduction tailored to the user’s situation, audience, and length requirements.

## Process
1. **Identify the context**
   - Determine where the self-introduction will be used: interview, class presentation, job application, social profile, networking, speech, or general introduction.
   - If the context is missing, ask for it before drafting.

2. **Gather the key details**
   - Name or preferred name
   - Current role or status: student, job seeker, employee, freelancer, etc.
   - Background: education, major, work experience, skills, interests
   - Purpose of the introduction: impress, be friendly, be concise, sound formal, etc.
   - Desired length and tone: short, medium, formal, casual, confident, warm

3. **Choose the structure**
   - Start with a greeting or direct introduction.
   - State the most relevant identity information first.
   - Add 2–4 supporting points that match the audience.
   - End with a closing sentence that expresses interest, enthusiasm, or openness.

4. **Write the draft**
   - Use natural, fluent language.
   - Keep the content relevant to the audience.
   - Highlight strengths with concrete details rather than vague praise.
   - Avoid overloading the text with too many facts.

5. **Refine for fit**
   - Make the tone match the setting.
   - Shorten or expand to the requested length.
   - Remove anything too personal, irrelevant, or repetitive.
   - If the user wants multiple versions, provide variants such as formal, casual, and concise.

## Output guidance
- If enough information is provided, write the self-introduction directly.
- If important details are missing, ask only the minimum necessary questions.
- If the user wants a generic version, provide a flexible template they can adapt.

## Suggested template
- **Opening:** "Hello, my name is ..."
- **Background:** "I am currently ..."
- **Strengths/experience:** "I have experience in ..." / "My strengths are ..."
- **Interest or goal:** "I am interested in ..." / "I hope to ..."
- **Closing:** "Thank you for listening."
