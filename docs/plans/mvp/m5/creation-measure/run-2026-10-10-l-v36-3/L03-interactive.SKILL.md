# 外燴報價整理

把客戶提供的外燴訂購訊息整理成繁體中文報價；只根據訊息，不查價、不補造資料。

## 步驟

1. 逐段閱讀訊息，按品項首次出現的順序抽取品項名稱、數量、單價。保留原文所給的事實與數值；不推定未提供的價格、數量、稅費或其他費用。
2. 將明確說明是客戶直接付給場地方的「場地清潔費」排除於我方報價之外，並記下金額（若有）供備註。把其他提及的品項與費用，包括外送費，列入報價。
3. 檢查每個列入報價的品項。若數量或單價缺少，將其欄位標為「未提供」並在輸出中留下可填寫的標記空格；計算其他資料完整的列，但不得把部分合計說成完整總額。若訊息中同一數值有衝突或後文改動前文，指出品項與互相矛盾的原值，請提出需求的人確認；不計算受該衝突影響的金額或依賴它的總額。不要追問其他事項。
4. 對每筆資料完整且沒有衝突的列，從本 Skill 所在目錄執行下列命令。每筆 `--item` 的值格式為 `品項名稱|數量|單價`；每筆品項各帶一個參數。依實際抽取結果替換引號內內容，並對 shell 特殊字元正確跳脫：

   `python scripts/quote_totals.py --item '品項名稱|數量|單價'`

   有多筆時重複 `--item`，例如命令形式為 `python scripts/quote_totals.py --item '品項甲|數量|單價' --item '品項乙|數量|單價'`。不要把已排除的場地清潔費傳入。若腳本以錯誤結束，照錯誤指出的值處理，不要自行改值或報出依賴該值的總額。
5. 交付報價表，欄位依序為「品項、數量、單價（新台幣）、小計（新台幣）」，品項按訊息出現順序排列。依腳本結果填入各小計與總額，將金額標為 NT$；呈現腳本輸出的計算值，不額外加稅或未提及費用。完整總額只有在所有應計品項都可計算且沒有相關衝突時才列為「報價總額」；否則清楚標示總額尚無法完整計算及原因。另以簡短備註列出被排除的場地清潔費及其付給場地方的性質；沒有這筆費用時不必加備註。提供可以直接使用的報價內容，不以問題或後續承諾收尾。
6. 對每次執行的請求，若其中提到本 Skill 執行環境無法完成的外部動作，仍先交付可用的報價內容，最後逐項用一行寫明該動作、明確說本 Skill 無法代為完成，並指出必須由提出需求的人或該請求指定的負責人完成。不得聲稱已完成該動作。若請求沒有提到此類動作，不加這些行。
