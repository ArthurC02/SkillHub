## 撰寫補件通知信

1. 確認使用者提供了客戶姓名、缺件清單及補件期限。若缺少其中任何一項，先詢問缺少的資訊，不要自行猜測或捏造。
2. 以客戶姓名作為稱呼，採用禮貌、清楚、專業的繁體中文語氣。
3. 簡短說明目前尚需補齊資料，並將使用者提供的每份文件逐項列出。保留文件名稱的原意，不要自行增刪或推測文件內容。
4. 清楚寫出補件期限，沿用使用者提供的日期；若日期有歧義，先請使用者確認，不要自行選定日期。
5. 以簡短的禮貌結尾收束信件。
6. 只輸出通知信本文，不加主旨、分析、前言、占位符或額外說明。
