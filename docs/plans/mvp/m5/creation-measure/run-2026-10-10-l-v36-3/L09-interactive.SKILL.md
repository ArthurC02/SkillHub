# 陶藝活動 Instagram 宣傳貼文

依照以下步驟，直接將使用者提供的活動資料寫成可使用的貼文；只使用該次輸入，不查找或推測外部資訊。

1. 讀取使用者提供的活動資料，辨認活動名稱、日期（含星期）、時間、地點、費用、報名截止日，以及其他明確提供的活動事實。
2. 逐字保留每項已提供的硬事實：保留原有文字、數字、日期、星期、標點、大小寫、貨幣符號與範圍符號，不翻譯、不改寫、不換算、不省略。可在原文前加上欄位標籤，但不得改動事實本身。也逐字保留其他已提供的明確事實。
3. 檢查資料是否有不存在的日期、負數數量，或同一事項出現不同值（包括後文改動先前數值）。對每個問題明確列出相關原文，並請提出請求的人確認；不得選一個值代替，也不得給出依賴該值的合計。不要質疑其他資料。仍在同一回覆中交付貼文草稿，不以提問作結。
4. 使用輕鬆、親切、自然的繁體中文寫簡短開場與收尾。不得添加未提供的活動特色、名額、材料、成品、適合對象、保證、地址細節或其他事實。可加上與陶藝及活動主題相符的一般 hashtag，不把標籤寫成未提供的活動資訊。
5. 加入清楚但不捏造細節的報名行動呼籲。若沒有提供報名方式，只提醒讀者把握截止日並完成報名，不得虛構網址、帳號、電話、私訊方式或其他聯絡資訊。
6. 若某項活動資訊未提供，在貼文相應位置以「未提供」標明；不得因此停止撰寫，也不得把能從已提供資料直接推得的值標為未提供。未被要求、且非完成貼文所必需的名稱、標籤或日期缺漏，不得阻礙撰寫。
7. 直接在本回覆交付完整貼文草稿；缺少的必要欄位以明確標記呈現，不寫成計畫或承諾，也不等待補充資料。貼文之外如有需確認的衝突，另用簡短一行指出並請提出請求的人確認。
8. 對任何超出本 Skill 能力的動作，先準備好可供使用的貼文，並在回覆末尾為該次請求提到的每項動作各寫一行：點名動作、明確說明本 Skill 無法代為執行，並指出由誰負責。最後一行依此格式處理 Instagram 發布：本 Skill 無法代為發布，須由提出請求的人自行發布。
