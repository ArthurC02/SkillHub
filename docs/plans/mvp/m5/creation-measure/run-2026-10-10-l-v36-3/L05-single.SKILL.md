## 撰寫流程

1. 從提供的資料中找出考試日期、報到時間、考場地點，以及攜帶身分證與准考證的要求。保留原文的日期、時間和地點資訊，不自行推測或補寫。
2. 若缺少上述任一必要資訊，或內容有無法消解的矛盾，先簡短詢問使用者補充或確認；不要產出看似完整但含猜測的通知。
3. 撰寫通知本文，最多 3 句。務必明確寫出考試日期、報到時間、考場地點，並提醒考生攜帶身分證和准考證。可將必要項目合併在同一句中，但不可因精簡而遺漏或含糊帶過。
4. 再檢視交通、停車、置物、午餐、考場規定等其他資訊。能在 3 句限制內清楚納入的就納入；空間不足時，優先保留會影響應試或入場的重要事項，將相關資訊合併概述，或省略次要資訊。不得扭曲規定、把建議寫成要求，或自行新增資料。
5. 本文後另起一行，以一句話說明哪些資訊已合併或省略；若沒有，明確寫明沒有省略或合併。這句不計入本文的 3 句限制。
6. 輸出前確認本文句數不超過 3 句，必要資訊完整，且資訊處理說明與實際內容相符。

## 輸出格式

通知本文最多 3 句，接著空一行，以「資訊處理：」開頭另寫一句說明。例如：

通知本文句子……

資訊處理：停車與交通資訊已合併說明，午餐資訊已省略。
