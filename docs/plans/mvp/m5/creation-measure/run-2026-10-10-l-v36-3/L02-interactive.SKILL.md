# 手作文具退貨受理判定

依使用者提供的訂單資料，逐筆套用已確認的退貨規則，輸出唯一判定結果。商品種類照原資料保留供辨識，不影響判定。

## 步驟

1. 讀取每筆訂單的編號、到貨日、申請日、是否客製、是否已使用、是否有瑕疵。每筆資料都照輸入保留，不改寫或推測事實；不需要的訂單名稱或日期不應阻止判定。
2. 日期使用 `YYYY-MM-DD`。將每筆完整資料轉成一個 `--record` 引數，欄位順序為「編號|到貨日|申請日|客製|已使用|有瑕疵」；客製、使用、瑕疵欄位使用「是」或「否」。從放有本檔案的目錄執行：

   `python scripts/refund_decision.py --record '編號|到貨日|申請日|客製|已使用|有瑕疵'`

   每筆訂單各加一個 `--record` 引數。商品種類不傳給腳本，因為規則不依商品種類判定。
3. 腳本按日期相減計算天數，依序判定：客製商品一律不受理；非客製商品在第 0 至第 7 天，未使用或有瑕疵則全額退款，已使用且無瑕疵則不受理；第 8 至第 30 天，有瑕疵則換貨，否則不受理；超過第 30 天一律不受理。依腳本輸出逐筆呈現，結果只用「全額退款」、「換貨」或「不受理」。
4. 若腳本以錯誤碼 2 結束，原樣保留它指出的無效值，不替它判定或提供依賴該值的結果；請要求提出請求的人確認該值。不要質疑其他可用資料。若資料缺漏，標明缺少的值為「未提供」，並提供保留原始資料、以空白標出缺項及結果欄的可用模板；不猜填，也不把可由資料算出的值標成未提供。資訊不足時不得冒填三種判定結果之一。
5. 交付逐筆結果本身，不添加未提供的退貨政策。若請求另提到本 Skill 無法執行的外部動作，先備妥可直接使用的內容；最後逐行寫明該動作、明確指出本 Skill 無法執行，並說明由提出請求的人或請求指定的負責人執行。
