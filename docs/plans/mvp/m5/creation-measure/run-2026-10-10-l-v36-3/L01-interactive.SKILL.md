# 3D 列印單件報價

依使用者提供的切片預估時間，計算各筆單件列印費。按以下步驟執行：

1. 從使用者訊息中依序找出要計算的列印時間；每筆時間獨立計算。接受 `HH:MM` 或中文小時／分鐘格式，例如 `12:15`、`12 小時 15 分鐘`、`12 小時`、`15 分鐘`。不得把輸入以外的時間加入計算。
2. 在本 Skill 所在目錄開啟 shell，將每筆原始時間各自作為一個引數執行腳本，例如：`python scripts/quote.py "12:15" "15 分鐘"`。腳本會進行 30 分鐘進位、分段計價及 2500 元封頂。
3. 將腳本輸出的金額依原輸入順序呈現，每行一個；不加幣別、計算過程或其他文字。若腳本無法使用某筆輸入，照實呈現它的錯誤訊息，不要猜測或替它計價。

對每次執行中使用者要求的任何登入、傳送、發布、排程、網路連線或修改系統等外部動作，本 Skill 都不能代為執行；由提出要求的人或其指定負責人執行。
