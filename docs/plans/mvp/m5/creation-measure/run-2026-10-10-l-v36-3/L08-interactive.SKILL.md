# 蜂蜜批發出貨單

將一則或多則客戶訂購訊息整理成繁體中文出貨單。只使用訊息中提供的品項與數量，不新增品項或價格；固定單價由隨附腳本處理。

## 步驟

1. 從輸入辨認每筆訂單，保留訂單所載的名稱、出貨日期、品項和數量；不要把不同訂單合併。沒有名稱時以「第 N 筆訂單」區分，不因名稱或標籤缺漏而停下。
2. 把每筆訂單整理成下列 JSON 格式，合併為一個 JSON 陣列。`dates` 放入原訊息中的出貨日期；沒有日期時用空陣列。每項的 `product` 和 `quantity` 按原文填入；缺少品項或數量時以 `未提供` 和 `null` 表示。數量矛盾時保留每次出現的記錄，不先選一個數量。
   ```json
   [{"name":"訂單名稱或未提供","dates":["日期原文"],"items":[{"product":"品項原文","quantity":數量或null}]}]
   ```
3. 在含有此 SKILL.md 的目錄執行 `python scripts/shipment_slips.py --orders '<訂單 JSON 陣列>'`。將實際擷取的 JSON 放入引號內；不可用範例資料代替。出貨日期缺漏時，腳本採用執行當日日期；只有要指定其他日期時才加 `--today YYYY-MM-DD`。日期驗證、矛盾檢查、小計與總額均由腳本計算，不要自行重算或改寫計算結果。
4. 把腳本輸出的出貨單原樣作為本次答案。保留所有例外、待確認事項和總額狀態；每一行指出預設假設的文字都須逐字保留。對無效日期、矛盾數量、負數或其他無法使用的資料，清楚列出原值並請提出本次請求的人確認；不計算依賴該資料的金額。對未提供的資料標示「未提供」，不得把可由已知資料算出的日期或金額標成未提供。
5. 對本次請求所提及的任何登入、傳送、發布、排程或其他外部操作，只準備可供使用的內容；本 Skill 執行者無法執行該操作，須用一行明確說明執行者無法執行，並指出應由提出請求的人或該請求指定的負責人執行。
