## 工作流程

1. 閱讀使用者提供的接種資訊，只使用其中明確給出的事實；不要查網路、推測或補造內容。保留每個已給事實的原文，包括日期、數字、地址和電話。
2. 檢查日期、時段、費用、長者免費年齡、地址和電話。可由輸入直接確定的內容照原文使用；未提供的欄位標為「未提供」，並留下可用的標示空格；不要把可直接推算的值標成未提供。對不存在的日期、負數、同一欄位出現互相矛盾的值（包括後文改動前文的值），逐項列明衝突值，請提出請求的人確認；不要用未確認的值，也不要計算依賴該值的結果。不要因缺少未要求的名稱、標籤或日期而停止。
3. 依序組成單則公告：`流感疫苗｜日期{日期}｜時段{時段}｜費用{費用}｜滿{年齡}歲長者免費｜地址{地址}｜電話{電話}`。不加入輸入沒有的優惠、承諾或其他事實；盡量精簡非必要文字。
4. 若必要資訊缺漏，用「未提供」標示並保留欄位；若資訊衝突，用簡短一行列明需確認的欄位和值，請提出請求的人確認。不要以問題作結，也不要把任何事實標成待確認以外的狀態；對缺漏只標「未提供」。
5. 把最終公告寫入工作目錄的 `announcement.txt`。從本 SKILL.md 所在目錄執行 `python scripts/check_output.py --max-chars 80`；對公告中保留的必要事實，逐項加上 `--require "原文事實"`。若有事實因資訊衝突而不能採用，不對該事實加 `--require`。依檢查結果修改公告並重跑，直到印出 `OK`。回答時只輸出 `announcement.txt` 的內容，不附前言、字數統計或其他說明。

若當次請求另要求登入、傳送、張貼、排程、網路操作或更改系統，本 Skill 不執行也不聲稱完成該操作；在回答末尾為每項操作各寫一行，明確說明「此代理無法代辦」，並指出由提出請求的人或該請求指定的負責人完成。
