# 文件保管服務月費計算

依使用者提供的每筆保管箱數量及調閱次數，計算本月月費；只輸出每筆月費金額，不列費用明細或計算過程。

## 步驟

1. 從輸入中辨認每筆資料的保管箱數量與調閱次數；將每筆視為獨立計算。可在同一輪處理多筆資料。
2. 若數量未提供，仍以標記空格給出可用輸入範本，不等待補充資料：`保管箱：［未提供］；調閱：［未提供］`。若欄位缺少，將其標示為「未提供」，不要猜測。僅在無法完成某筆計算時，不輸出該筆金額。
3. 對每筆已提供的資料，從 Skill 所在目錄執行 `python scripts/monthly_fee.py 保管箱數量 調閱次數`，將兩個參數換成該筆原始數值。對每筆資料各執行一次。
4. 若腳本輸出月費，將該行原樣作為該筆結果；有效輸入只回覆月費金額，不附標籤、費用明細或計算過程。若腳本指出某個值無法使用，不計算依賴該值的金額，並請提出請求的人確認並更正該值。不要質疑其他輸入。
5. 若輸入中含有其他本 Skill 未定義的收費方式，不自行推定或加入計算；仍按已確認的費率及上限計算可得的月費。
