# 證照考場考前簡訊通知

把使用者貼上的考試資訊改寫成可直接使用的考生簡訊；只依據輸入，不查網路、不猜測或補造資訊。以繁體中文作答。

## 步驟

1. 從輸入中找出考試日期、報到時間、考場地點，以及攜帶身分證和准考證的要求。逐字保留已提供的日期、時間、地點和規定，不自行改寫其數值或細節；不得把輸入中的事實標成待補。
2. 若上述必備資訊有缺漏，在通知中以「未提供」明確標示缺漏欄位，其他已提供事實仍照常寫入；缺漏不阻止完成通知。若同一欄位有互相矛盾的值，列出衝突值，不自行選定，請提出要求的人確認，且不以其中任一值冒充已確認資訊。
3. 將必備資訊放進通知本文。本文最多 3 句；交通、停車、置物、午餐及其他規定，依考試當日實用性盡量合併或精簡，放不下就省略。不要加入輸入沒有提供的交通路線、規則、推論或其他事實。
4. 通知本文後另起一行，寫恰好一句資訊處理說明，具體、如實交代哪些資訊被省略或合併；沒有資訊被省略或合併時，明確說明沒有省略或合併資訊。本文不加標題，整體不加前言或其他評論。
5. 若輸入要求本 Skill 執行任何環境外動作，只準備好可供使用的通知，不得聲稱已執行。答案最後須為每項該類動作各寫一行：說明具體動作、明確表示本 Skill 無法執行，並指出應由提出要求的人或其指定負責者執行。
6. 將通知本文存為 `notice.txt`，將完整答案（通知本文、資訊處理說明，以及適用時的動作限制說明）存為 `answer.txt`。從已提供的資訊逐字取出日期、報到時間、完整考場地點字串，分別設定為 shell 變數 `DATE`、`TIME`、`VENUE`；執行下列檢查，將雙引號中的必備文字替換為輸入中的原文：

   ```sh
   python scripts/check_output.py --max-sentences 3 --require "$DATE" --require "$TIME" --require "$VENUE" --require "身分證" --require "准考證" < notice.txt
   ```

   若未印出 `OK`，修正通知本文並重跑檢查。這個檢查只套用在通知本文，不把另起一行的資訊處理說明算入 3 句限制。
7. 完成檢查後，答案只輸出 `answer.txt` 的內容，不加任何其他文字。
