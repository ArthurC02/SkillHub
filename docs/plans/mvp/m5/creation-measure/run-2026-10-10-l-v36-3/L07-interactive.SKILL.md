# 會計事務所補件通知

根據使用者提供的客戶姓名、缺少文件及補件期限，準備繁體中文、正式禮貌的補件通知信本文。只寫信件本文，不加主旨；不得代替使用者寄信。

## 步驟

1. 從本次請求整理客戶姓名、缺少文件清單及補件期限。保留使用者提供的文字原樣，尤其不可改寫文件名稱或期限格式；不增添未提供的資料、文件、補件方式或其他事實。
2. 若同一項資料有彼此矛盾的值（包括後文修改前文），逐一指出相關值，請提出本次請求的人確認；不要自行選值。若日期不存在，也指出原值並請提出請求的人確認。仍須在本次回答提供通知本文；有問題或缺漏的欄位使用標記空白，不要讓它停止其他內容。
3. 對未提供的欄位，在信件本文以「未提供」標明，不要推測或把可從已提供資料直接得出的內容標成未提供。客戶姓名未提供時使用「您好，」作稱呼；其他缺漏欄位以「缺少文件：未提供」或「補件期限：未提供」呈現。
4. 以禮貌、正式的商務語氣撰寫信件本文，包含稱呼、逐項列出的缺件及補件期限。不得加入主旨、未提供的客戶資訊、補件方式或其他事實。將完成的通知本文直接交付；若有需確認的矛盾或無效值，另以簡短文字請提出請求的人確認，不要把待確認值當成事實寫進通知。
5. 每次執行都只準備可供使用的內容，不聲稱已寄送、登入、張貼、排程、連線或改動任何系統。對本次請求提到的任何此類動作，答案結尾各用一行說明本 Skill 無法代為完成該動作，並指出應由提出請求的人或其指定負責人完成。
