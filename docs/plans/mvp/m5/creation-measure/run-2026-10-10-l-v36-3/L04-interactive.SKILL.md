# 冷氣清洗報價

依使用者提供的機型、台數與急件狀態，計算每筆報價並交付結果。所有計算只依本 Skill 的價目與輸入，不查詢外部資料。

## 步驟

1. 將使用者輸入分成各筆報價；一筆報價代表同一客戶同一次清洗的所有機型與台數。只接受分離式、窗型。記下每筆兩種機型的台數，以及是否急件；未要求急件即視為非急件。
2. 使用下列固定價目：分離式每台 1,800 元、窗型每台 1,200 元。同一筆總台數滿 3 台（不分機型）時，該筆每台折 100 元；急件在折扣後小計加成 20%。
3. 若數量、機型或急件狀態明確，將每筆整理成 `split=數量,window=數量,rush=yes或no`。例如，分離式 2 台、窗型 1 台、非急件寫成 `split=2,window=1,rush=no`。每筆各給一個 `--quote`，不要把不同清洗併成一筆。
4. 從本 SKILL.md 所在目錄執行：
   `python scripts/quote.py --quote 'split=2,window=1,rush=no'`
   多筆報價時重複提供 `--quote`。只有在使用者指定另一個急件百分比時才提供 `--rush-rate 百分比`；例如 `--rush-rate 25` 代表 25%。保留腳本輸出的每一行，並原樣複製所有說明預設值的行。
5. 若某筆機型或台數未提供，使用 `?` 表示該欄未提供，並執行腳本；不推測缺少的數量。腳本會標出未提供的欄位，並對無法確定的計算標為未提供。若完全沒有報價內容，也執行 `python scripts/quote.py`，交付腳本產生的空白模板。遇到無法使用或互相矛盾的值，照實指出每個值，請提出請求的人確認；不得計算依賴該值的總額。
6. 對其他機型、額外費用或不同折扣規則，明確說明本價目無法計算，不自行編造價格。回覆中交付報價結果本身；不只描述計算步驟。
