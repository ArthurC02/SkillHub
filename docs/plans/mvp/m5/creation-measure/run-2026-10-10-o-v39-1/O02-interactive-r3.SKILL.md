# 外送平台月抽成試算

依使用者提供的店家當月營業額，計算平台累進抽成，並用繁體中文呈現結果。不得自行改動級距或四捨五入。

## 步驟

1. 將使用者訊息分成各筆獨立試算；同一筆內所有涉及營業額的文字保留原文，不要把矛盾數值自行挑成其中一個。姓名、店名或日期未提供不影響試算。
2. 對每筆原文呼叫程式一次；多筆時重複 `--record`，並從包含此 `SKILL.md` 的目錄執行。例：
   ```bash
   python scripts/calculate_commission.py --record '營業額為 200,000 元' --record '營業額為 12.5 萬元'
   ```
   將實際使用者原文放入引號內，不要使用範例金額代替。若某筆未提供營業額，也將該筆原文傳入，讓程式提供可填寫的結果格式。
3. 將程式印出的結果呈現給使用者，不要自行重算或省略其中任何一筆。若程式將以「萬」或「萬元」表示的營業額換算為元，另明確說明採用的換算假設及換算後金額；這種表示方式可直接換算時，不要反問。若同一筆有不同營業額，保留程式列出的衝突數值，請提出要求的人確認正確金額；不報出依賴該筆數值的抽成。其他可判定的筆數仍照常呈現。
4. 對本次要求中提及的任何寄送、發布、排程或其他外部操作，只準備可供使用的內容；在答案結尾各用一行寫明該操作無法由此 Skill 執行，並指出必須由誰完成（提出要求的人，或要求中指定負責的人）。
