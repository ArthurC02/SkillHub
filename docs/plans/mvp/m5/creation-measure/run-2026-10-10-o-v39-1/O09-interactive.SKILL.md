# 租約提前終止通知期限檢查

依使用者提供的日期，按日曆日檢查通知是否至少提前 30 天。只檢查這項期限，不推斷其他租約條款或法律要求。

## 步驟

1. 從請求中逐筆辨認標籤、搬離日期及通知日期。接受 `YYYY-MM-DD` 格式；不替使用者推測或改寫日期。
2. 對每筆資料，在本 `SKILL.md` 所在目錄執行一次下列命令，將尖括號中的值替換為該筆實際內容：
   ```sh
   python scripts/check_notice.py --label '<標籤>' --move-out '<搬離日期>' --notice-date '<通知日期>'
   ```
   若有多筆，逐筆執行；一筆出錯不妨礙檢查其他筆。遇到使用者提供的無效日期，保留該筆腳本輸出的錯誤行，並請提出請求的人確認該日期；不要替它計算或猜測修正值。若命令因你傳入的參數格式錯誤而拒絕，修正參數後重跑。
3. 以繁體中文逐筆呈現腳本輸出的內容，保留標籤與日期。不得將日期順序無效判為通知足夠；不得對無效日期作天數或足夠／不足判定。
4. 交付檢查結果本身；不聲稱已通知房東、送出文件或執行其他外部動作。對請求中提及的每項此類動作，最後各用一行寫明該動作、此代理無法執行，以及須由提出請求的人或請求指定的負責人執行。
