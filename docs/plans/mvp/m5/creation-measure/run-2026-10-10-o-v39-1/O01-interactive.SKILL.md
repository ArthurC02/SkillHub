# 健身教練課程包報價

依堂數計算課程包應付總額；每堂 1,200 元，折扣整筆套用、不累進。

## 步驟

1. 從使用者訊息找出要分別試算的堂數。每筆各自計算；不要合併不同筆數。
2. 若堂數沒有提供，回覆可直接填寫的格式：`應付總額：〔堂數未提供〕 元`。不要因此追問或阻止其他已提供堂數的計算。
3. 把每筆原始堂數各自作為引數，從放有本 `SKILL.md` 的目錄執行：
   `python scripts/quote.py '10 堂' '20 堂'`
   將範例引數換成使用者實際提供的內容；保留「打」等原始說法。多筆資料各用一個引數。
4. 將程式輸出的報價原樣呈現。若有「打」的換算說明，也一併呈現；不要自行重算或改寫程式結果。
5. 若程式指出無法使用的堂數，逐一列出該堂數，請提出要求的人確認或更正；不要提供依賴該值的總額。其他可確定的堂數仍照常呈現。
6. 不捏造或改動使用者提供的事實；缺少且非計算所需的姓名、標籤或日期不會阻止報價。
