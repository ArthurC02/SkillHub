## 用途
依使用者提供的規則，逐筆試算信用卡帳單最低應繳金額。只使用以下公式，不套用其他銀行或法規規則：帳單總額大於 0 且不超過 1,000 元時應繳全額；超過 1,000 元時應繳帳單總額的 10%，但至少 1,000 元；結果有小數時無條件進位至整數元。

## 步驟
1. 以繁體中文讀取使用者提供的帳單金額；每筆記錄分開處理，保留使用者提供的標籤及金額文字。可辨識阿拉伯數字金額（可含千位逗號、小數及正負號）及一般中文數字金額。中文數字依一般讀法轉換，並在該筆結果旁說明這項讀法假設及可修改對應 `entries` 參數。
2. 檢查相同帳單標籤是否出現不同金額。若有，指出該標籤及列出的金額互相衝突，該帳單不計算，請提出要求的人確認正確總額；仍處理其他能確定的帳單。不要將不同標籤的金額合併。
3. 對每筆可辨識且沒有標籤衝突的金額，依確認的公式計算；小於或等於 0 時不計算，提示帳單總額必須大於 0。對其他有效金額照常計算。
4. 從包含此 `SKILL.md` 的目錄，將每筆原始記錄分別作為一個引數執行腳本；保留原文並為每筆加上引號：`python scripts/minimum_due.py "帳單甲：金額文字" "另一筆金額文字"`。呈現腳本輸出的逐筆結果及提示；若輸出有假設行，逐字照抄每一行。
5. 交付完整的逐筆試算結果；不要只回報錯誤或把仍可計算的帳單漏掉。
