## 用途
根據請求中的學員姓名、課程名稱、開課日期、回覆期限及今天日期，準備繁體中文候補遞補通知簡訊。一次可處理多筆；逐筆獨立判斷。

## 步驟
1. 逐筆擷取姓名、課程名稱、開課日期、回覆期限及今天日期。原樣保留所有已提供的事實。若同一欄有互相矛盾的值，不採用其中任何一個；請提出請求人確認那些值，不計算依賴它們的結果。其他無關欄位照常處理。
2. 若必要資料缺漏，仍準備可用簡訊範本；每個缺漏欄位標為「【欄位名稱未提供】」，不可編造資料或追問。沒有提供今天日期時，使用執行當日日期；在相應結果旁註明採用的日期，並說明可用 `--today` 更改。
3. 以原文撰寫禮貌、簡潔的簡訊。對每筆資料，將已提供的姓名、課程名稱、開課日期及回覆期限原樣放入簡訊。不要替已提供但無法判定正確的值套用預設。
4. 對具備可判讀的今天日期及回覆期限的資料，執行下列命令；把各欄位及簡訊放入 shell 變數，並提供對應選項：
   `python scripts/check_sms.py --today "$today" --reply-deadline "$deadline" --name "$name" --course "$course" --start-date "$start" --message "$sms"`
   今天日期未提供時省略 `--today`；任何缺漏欄位省略其選項。必須提供 `--message`。這個程式判讀日期、比較期限、核對已提供資料是否原樣出現在簡訊中，並計算字元數；呈現它印出的結果，假設值說明須逐字照錄。
5. 若回覆期限早於今天，不產生該筆簡訊；呈現程式印出的拒絕結果及原因。期限等於今天有效。日期不存在或格式無法判讀時，程式以退出碼 2 說明哪個值不可用；請請求人確認該值，再對該筆處理。若是你自己的命令參數造成退出碼 2，先修正參數並重跑。
6. 對每筆可產生的簡訊，將該則簡訊本身寫入檔案，執行 `python scripts/check_output.py`，加上 `--max-chars 60`，並以重複的 `--require` 參數列出每個必須原樣保留的已提供資料值；有缺漏欄位時，也以 `--require` 檢查其「未提供」標記。直到程式印出 `OK`。若未通過，精簡一般措辭後重試，不可刪除必須保留的事實。最後只交付檢查過的簡訊、必要的日期拒絕說明及假設說明，不加無關內容。
7. 若請求提及任何外部動作，答案最後逐項列明該動作的名稱、本 Skill 無法代為執行，以及由提出請求的人或其指定負責人執行；不可聲稱已完成該動作。
