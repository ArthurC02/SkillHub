## 用途

依年齡和場次試算電影院票價。使用者可一次提供多筆資料；只處理訊息中實際給出的資料，不要求額外欄位。

## 步驟

1. 從使用者訊息整理每筆資料的 ID（若有）、年齡原文和場次原文。保留原文；不要自行更改使用者提供的事實。年齡以一般讀法可確定為單一數值的中文數字（例如「五歲」）也可計算，並在該筆結果旁說明這是讀法假設。
2. 將每筆資料各自作為 `--record` 引數，格式為 `ID|年齡|場次`；沒有 ID 時用 `未提供`。從放有本 SKILL.md 的目錄執行腳本，例如：

   ```bash
   python scripts/ticket_price.py --record 'A|5 歲|平日' --record 'B|12 歲|假日'
   ```

   有多筆時每筆各加一個 `--record`。照抄訊息中的年齡和場次，不要把場次自行改成「平日」或「假日」。
3. 腳本逐筆輸出票價或錯誤；不同筆分開判定，一筆無效或有矛盾不影響其他可判定資料。若腳本退出碼為 2，閱讀並處理它在標準錯誤輸出的單行提示：更正其中點名的輸入後重跑；不得替該值計算。若錯誤是資料本身無法判定或互相矛盾，告知使用者該筆不能計價並請使用者確認；不提供依賴該值的票價。
4. 以繁體中文逐筆呈現腳本輸出的結果，保留每個 ID、金額及錯誤內容；將腳本列出的任何讀法假設逐字照抄在答案中。不要漏掉任何輸入資料，也不要補造資料。答案以陳述句結束，不以問題作結。
5. 若該次請求提到任何必須由人實際執行的動作，先準備好可直接使用的內容；答案最後另起一行，逐項寫明該動作由本 Skill 執行的代理人無法完成，並清楚指出應由提出請求的人或請求指定負責的人執行。不得聲稱已完成該動作。
