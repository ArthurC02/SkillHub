## 計算步驟

1. 找出使用者提供的當月營業額，單位為元。若金額缺漏或無法判讀，請詢問正確金額。
2. 若營業額小於 0，告知營業額不得為負，請使用者提供非負金額；不要計算抽成。
3. 按累進方式分段計算，不要將同一個抽成率套用到全部營業額：
   - 營業額首 100,000 元：抽 20%。
   - 超過 100,000 元至 300,000 元的部分：抽 15%。
   - 超過 300,000 元的部分：抽 10%。
4. 使用以下公式，其中 `營業額` 為非負金額：
   - 若營業額 ≤ 100,000：抽成 = 營業額 × 0.20。
   - 若 100,000 < 營業額 ≤ 300,000：抽成 = 100,000 × 0.20 + (營業額 − 100,000) × 0.15。
   - 若營業額 > 300,000：抽成 = 100,000 × 0.20 + 200,000 × 0.15 + (營業額 − 300,000) × 0.10。
5. 不要對各級距分段金額先行取整。回覆抽成金額，單位標示為元；若結果是整數，顯示整數，否則四捨五入至小數點後兩位。

## 回覆格式

簡潔列出輸入營業額與計算出的平台抽成，例如：`當月營業額：……元；平台抽成：……元。`
