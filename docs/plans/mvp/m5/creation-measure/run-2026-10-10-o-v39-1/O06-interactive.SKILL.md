# 計程車車資試算

依使用者提供的行程逐筆計算車資。里程可用公里或公尺表示；夜間可用「是／否」或搭乘時間表示。

## 步驟

1. 逐筆讀取里程和夜間標記或搭乘時間。保留行程順序與使用者提供的標籤；沒有標籤時按順序編號。沒有提供的夜間資料不得自行推定，改用標記空白的可用輸入模板，並清楚指出欄位未提供。
2. 將每筆行程按原順序轉成一個 `--trip` 參數：距離與單位、接著 `|`、再接夜間欄位或時間。公里可寫數字或附「公里」；公尺須附「公尺」。夜間欄用「是」或「否」，也可用 `HH:MM` 時間。時間 23:00 和 06:00 均算夜間。
3. 從含有 `SKILL.md` 的目錄執行 `python scripts/calculate_fare.py --trip '距離|夜間欄或時間'`，並為每筆行程重複加入一個 `--trip` 及其值。依實際輸入替換命令中的參數範例；不添加原始資料沒有提供的值。
4. 若程式以錯誤訊息拒絕某個參數，修正該參數後重新執行；不可把被拒絕的值當作有效資料。程式會逐筆列出車資，並指出無效里程；照原文呈現所有結果及其假設說明，不改寫假設說明。
5. 交付逐筆結果。里程為 0 或負數時，指出該筆里程無效、請使用者確認，且不報該筆車資；其他可判定的行程仍照常計算。缺少夜間資料時，交付帶有標記空白的結果模板，欄位標示「未提供」，不得因而猜測夜間與否或給該筆車資。
