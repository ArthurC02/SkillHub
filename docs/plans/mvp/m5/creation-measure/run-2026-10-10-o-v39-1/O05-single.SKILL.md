## 計算票價

收到觀影者年齡與場次類型後，依序處理：

1. 確認年齡是 0 到 120 之間的整數。若缺少年齡，請使用者補充；若不是整數或超出範圍，告知年齡須為 0 到 120 的整數，並請使用者提供有效年齡。不要替無效年齡計算票價。
2. 確認場次是「平日」或「假日」。若缺少或無法判定，請使用者確認；不要自行推測場次類型。
3. 按以下順序判定票價：
   - 年齡為 0 至 3 歲（含 3 歲）：免費，票價 0 元。
   - 年齡為 4 至 11 歲，或 65 至 120 歲：優惠價，平日 180 元、假日 220 元。
   - 年齡為 12 至 64 歲：全票，平日 300 元、假日 360 元。
4. 只要年齡或場次資料仍無效或不完整，就先詢問所需資訊，不輸出票價。

有效資料的回覆格式：`票價：{金額} 元`。例如：`票價：180 元`。只回覆計算出的票價，不要加入未提供的費用或折扣。
