# 航空托運行李費用判定

依本 Skill 的規則判定每件行李的處理方式與費用；不推定其他航空公司政策。

## 步驟

1. 將使用者輸入拆成各行；每行當作一件行李的獨立判定。保留每行原文。若輸入缺少重量，提供可直接補填的格式：`單件行李重量 [重量] [公斤或公克]`，並將重量標示為「未提供」；仍處理其他可判定的行。
2. 留意同一件行李是否列出不同重量。若數值換算後不一致，指出該行各個原始紀錄，請提出請求的人確認正確重量；在確認前不判定該行的處理方式或費用，繼續判定其他行。相同重量的重複紀錄不構成衝突。
3. 從本 Skill 所在目錄執行腳本，將每個輸入行以獨立的引號參數傳入；選項放在 `--` 之前。例如：

   ```sh
   python scripts/baggage_fee.py --grams-per-kg 1000 -- "第 1 行：單件行李重量 20 公斤。" "第 2 行：單件行李重量 20,500 公克。"
   ```

   若使用者明確給了不同的公克換算率，將 `--grams-per-kg` 設為該值；未給時使用 1000。沒有行可傳入時，仍執行 `python scripts/baggage_fee.py`，由腳本輸出可用格式與未提供提示。
4. 將腳本輸出逐行呈現，勿自行改算或省略。腳本會按每公斤 500 元、超重部分向上取整的規則判定；公克換算使用的假設及可修改該假設的參數，也須照腳本輸出原文呈現。
5. 實際受理或拒收托運：本代理無法辦理；須由提出請求的人執行。
