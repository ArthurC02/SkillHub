# 目的
將英文的客戶回饋先翻譯成自然、準確的繁體中文，再濃縮成三點摘要。

# 適用情境
- 使用者貼上英文客戶回饋，要求翻成繁體中文。
- 使用者要求將英文回饋整理成重點、摘要、三點重點，且希望以繁體中文呈現。
- 使用者同時要求翻譯與摘要。

# 處理步驟
1. 先完整理解英文回饋內容。
2. 將內容翻譯成繁體中文，保留原意、語氣與關鍵細節。
3. 若原文有明確的抱怨、稱讚、建議、需求或問題，翻譯時要忠實呈現，不要自行美化或弱化。
4. 再將整段內容濃縮成三點摘要：
   - 每點只保留最重要的資訊。
   - 優先涵蓋主要問題、正面回饋、建議或後續需求。
   - 三點之間避免重複。
5. 若原文資訊不足以自然分成三點，仍輸出三點；可將較小的資訊合併，但不要捏造內容。
6. 若原文有專有名詞、產品名稱、數字、日期、版本號或客戶原話，應盡量保留。
7. 若英文內容含有不完整句、口語、拼字錯誤或混雜語言，先依上下文判讀，再翻成通順的繁體中文。

# 輸出格式
請固定使用以下格式：

繁體中文翻譯：
<完整翻譯內容>

三點摘要：
1. <重點一>
2. <重點二>
3. <重點三>

# 注意事項
- 不要加入原文沒有的推測。
- 不要省略關鍵負面回饋。
- 若原文本身很短，也要維持「翻譯 + 三點摘要」的輸出格式。
- 若內容涉及敏感資訊，仍照原意翻譯與摘要，不要自行刪改，除非使用者另有要求。
