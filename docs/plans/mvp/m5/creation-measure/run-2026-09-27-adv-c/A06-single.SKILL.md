# 自我介紹撰寫流程

當使用者要寫自我介紹、個人簡介、about me、履歷自介、面試自介、社群簡介或演講開場自我介紹時，使用此技能。

## 1. 先確認用途與語氣
先判斷自我介紹要用在哪裡，因為不同場景長度與語氣不同。若使用者沒有提供，先詢問最少必要資訊：
- 使用場景：面試、課堂報告、社團、交友、社群貼文、履歷、申請文件等
- 期望長度：短版、中版、長版
- 語氣：正式、自然、活潑、專業、親切
- 是否要包含：姓名、年齡、學歷、工作經歷、興趣、專長、目標、個性

## 2. 蒐集內容素材
若使用者只說「幫我寫一篇自我介紹」，先引導他提供以下資訊；若資訊不足，不要自行捏造：
- 姓名或稱呼
- 身分背景：學生、上班族、轉職者、自由工作者等
- 學校、科系、公司、職稱或主要經歷
- 主要專長或技能
- 興趣、個性或價值觀
- 想達成的目標或希望別人記住的重點
- 需要避免提到的內容

## 3. 組織成文
依照用途選擇結構：

### 通用結構
1. 開頭問候或自我姓名
2. 身分背景
3. 重要經歷或專長
4. 興趣或個人特色
5. 結尾目標或期待

### 面試/履歷版
1. 姓名與背景
2. 學經歷或工作經驗
3. 核心能力與成果
4. 為何適合這個機會
5. 簡短收尾

### 社群/交友版
1. 簡短自我定位
2. 興趣與個性
3. 生活風格或喜好
4. 想認識什麼樣的人或期待

## 4. 寫作原則
- 用自然、清楚、符合場景的中文
- 避免空泛形容詞堆疊，盡量具體
- 不要加入未經使用者提供的事實
- 若資訊不足，先提問，不要硬寫
- 若使用者要求「更像真人」，可加入較口語但仍得體的表達
- 若使用者要求「正式」，避免過度口語或情緒化

## 5. 產出格式
輸出時可提供：
- 一版完整自我介紹
- 若使用者需要，附上 2 到 3 個不同風格版本
- 若內容較多，可再提供精簡版與加長版

## 6. 若資訊不足時的回覆方式
如果缺少關鍵資訊，先用簡短問題收集資料，例如：
- 你要用在什麼場合？
- 想要正式一點還是自然一點？
- 你希望我幫你寫多長？
- 你有哪些背景、專長或興趣想放進去？

## 7. 完成後檢查
在交付前確認：
- 是否符合使用場景
- 是否沒有捏造資訊
- 是否語氣一致
- 是否長度符合需求
- 是否容易直接使用或稍作修改即可使用
