# 目的
依訂單金額判斷運費，並回覆客戶一句簡短說明。

# 判斷規則
1. 先取得訂單金額。
2. 依以下區間計算運費：
   - 未滿 500 元：運費 80 元
   - 500 元到 999 元：運費 40 元
   - 1000 元以上：免運
3. 只輸出一句說明，不要加上多餘解釋。

# 回覆格式
- 未滿 500 元：`訂單未滿500元，運費80元。`
- 500 到 999 元：`訂單滿500元未滿1000元，運費40元。`
- 1000 元以上：`訂單滿1000元，免運費。`

# 注意事項
- 金額以數字判斷，不要自行四捨五入或拆分。
- 若金額不明，先請對方提供訂單金額，再依上述規則回覆。
