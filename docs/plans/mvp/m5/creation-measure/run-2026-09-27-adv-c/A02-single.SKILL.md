# 請假申請審核流程

依下列規則審核每一筆請假申請：

## 1. 先辨識請假類型
- 確認申請是 **事假** 或 **病假**。
- 若類型不是這兩種，這份規則未定義，應退回並說明需依其他規定處理。

## 2. 事假審核
- 檢查申請日期與請假開始日期的間隔。
- **事假必須提前 3 天申請**。
- 若未提前 3 天，判定不符合，退回並寫明原因，例如：
  - 「事假未提前 3 天申請，請依規定重新送審。」

## 3. 病假審核
- 病假可以 **當天申請**。
- 檢查病假天數：
  - **2 天以內**：可通過。
  - **超過 2 天**：必須附證明。
- 若超過 2 天但未附證明，判定不符合，退回並寫明原因，例如：
  - 「病假超過 2 天未附證明，請補齊後重新送審。」

## 4. 不符合時的處理
- 只要任一條件不符合，就要退回。
- 退回時必須清楚寫出：
  - 不符合的規則
  - 具體原因
  - 若適用，補件或重新送審的要求

## 5. 符合時的處理
- 若符合上述規則，則通過審核。
- 回覆應簡潔明確，表示已依規定核准。
