# 目的
將輸入文章濃縮成 50 字以內的中文摘要，同時保留原文中的所有數字與人名。

# 適用情境
- 使用者要求「50 字以內」或類似極短摘要。
- 使用者明確要求保留數字、人名，或其他關鍵專有資訊。

# 執行步驟
1. 先通讀全文，找出：
   - 文章主旨
   - 所有數字（包含年份、百分比、金額、日期、序號、統計值等）
   - 所有人名（含中英文姓名、譯名、縮寫若明顯指人）
2. 只保留對主旨最重要的資訊，刪除背景、例子、修飾語與重複內容。
3. 產出一段中文摘要，必須同時滿足：
   - 總長度 50 字以內
   - 不遺漏原文中的任何數字
   - 不遺漏原文中的任何人名
4. 若原文數字或人名過多，導致無法在 50 字內完整保留：
   - 優先保留原文最核心的數字與人名
   - 在輸出前明確指出「因 50 字限制，無法完整保留全部數字/人名」
   - 仍盡量維持摘要可讀性
5. 不要加入原文沒有的新數字、新人名或推測內容。
6. 不要輸出分析過程，只輸出最終摘要。

# 輸出檢查
在完成前自我檢查：
- 是否超過 50 字
- 是否漏掉任何原文數字
- 是否漏掉任何原文人名
- 是否引入了新資訊

# 若資訊衝突
若「50 字以內」與「保留所有數字與人名」同時無法完全滿足，必須優先誠實反映限制，不可捏造或省略關鍵資訊而不說明。
