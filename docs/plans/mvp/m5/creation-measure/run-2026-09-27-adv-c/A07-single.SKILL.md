# 目的
根據客人的抱怨內容，撰寫一則專業、同理、可直接送出的回覆，協助安撫情緒、承認問題、說明處理方向，並引導後續溝通。

# 使用流程
1. **先讀懂抱怨重點**
   - 找出客人不滿的核心：產品瑕疵、延誤、服務態度、退款、誤會、其他。
   - 分辨客人是要道歉、要補償、要解釋，還是要立即處理。

2. **確認回覆所需資訊是否足夠**
   - 若缺少關鍵資訊，先向使用者詢問必要內容，例如：
     - 客人原文抱怨內容
     - 品牌/公司名稱
     - 希望的語氣（正式、溫和、簡短、強硬但禮貌）
     - 是否要提到補償、退款、換貨、補寄、客服聯絡方式
   - 若資訊足夠，直接撰寫回覆。

3. **撰寫回覆時遵守的原則**
   - 先同理，再處理：先承認對方感受，不要先辯解。
   - 避免推卸責任、指責客人、過度法律化或冷冰冰的語氣。
   - 若公司有錯，明確道歉；若尚未確認責任，使用中性說法，例如「我們理解您的不便」或「我們會立即協助確認」。
   - 提供下一步：查詢、補件、退款、換貨、聯絡窗口、預計處理時間。
   - 保持簡潔清楚，避免冗長。

4. **建議回覆結構**
   - 開頭致意與同理
   - 對問題表示歉意或理解
   - 簡短說明處理方向
   - 提供具體下一步或聯絡方式
   - 結尾再次致意

5. **語氣與格式**
   - 使用繁體中文。
   - 預設語氣：專業、禮貌、真誠。
   - 若客人情緒強烈，回覆要更穩定、低姿態，但不要卑微。
   - 若需要，可提供 2–3 個版本：
     - 標準版
     - 更溫和版
     - 更簡短版

# 可直接套用的回覆模板
## 通用版
您好，謝謝您告知我們這個情況，也很抱歉讓您有不好的體驗。這確實不是我們希望帶給您的感受，我們非常重視您的反映，會立即協助確認並處理。

為了盡快幫您解決問題，麻煩您提供相關訂單/照片/細節，我們會盡快為您跟進。再次為造成您的不便致歉，謝謝您的耐心。

## 問題尚待確認版
您好，謝謝您的反映，也很抱歉造成您的困擾。我們已經收到您的問題，會立即進一步確認並協助處理。

為了加快處理速度，麻煩您提供更多相關資訊，我們會盡快回覆您後續進度。感謝您的理解與耐心。

## 已確認有疏失版
您好，非常抱歉這次的服務/商品讓您感到不滿意，這是我們的疏失，我們深感抱歉。

我們會立即協助您處理，並盡快提供後續方案。也謝謝您願意告知我們問題，讓我們有機會改善。
