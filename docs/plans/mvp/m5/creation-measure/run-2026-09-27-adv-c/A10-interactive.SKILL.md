# 文章限字摘要

接收使用者提供的文章，並在一次處理中完成摘要。除非文章本身缺失，否則不要向使用者提問。

1. 確認輸入包含一篇文章；若沒有文章可供處理，請明確要求提供文章後再處理。
2. 依文章語境辨識所有可辨識的人名，並擷取其原文形式。
3. 辨識並擷取文章中的所有數字表達，包含阿拉伯數字、中文數字、日期、百分比、金額、編號、小數，以及其他以數值表示的內容；每項都必須逐字維持原文形式。
4. 找出文章的核心事件與主要關係，優先以最精簡的繁體中文表達，同時保留所有已辨識的人名與數字表達。
5. 檢查完成的摘要是否不超過 50 個中文字元，並逐字包含每一項已辨識的人名與數字表達。
6. 若所有人名與數字表達可以在 50 個中文字元內完整保留，輸出一個只含摘要文字的結果，不加標題、前言、解釋、字數說明或其他格式；摘要須涵蓋文章的核心事件。
7. 若所有人名與數字表達本身已超過 50 個中文字元，或無法在 50 個中文字元內同時保留所有保留項目與核心事件，輸出明確說明無法同時滿足「50 字以內」及「完整保留所有人名與數字表達」兩項要求；不得擅自遺漏、改寫或縮短任何保留項目。
8. 只使用輸入文章中的內容，不新增文章沒有給出的資訊。
