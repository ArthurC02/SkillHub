# 目的
根據「這個月的出勤紀錄」計算每個人的加班時數，並標示出加班超過 46 小時的人員。

# 適用情境
- 使用者提供本月出勤紀錄、打卡明細、工時表或類似資料。
- 需要按人彙總加班時數。
- 需要找出加班時數超過 46 小時的人。

# 執行步驟
1. **確認資料範圍**
   - 只使用「這個月」的出勤紀錄。
   - 若資料跨月，先排除非本月資料，或請使用者確認要採計的月份。

2. **辨識每筆紀錄中的加班資訊**
   - 找出每位員工的加班時數欄位，或從上下班時間、休息時間、正常工時規則推算加班。
   - 若資料已直接提供加班時數，直接採用。
   - 若資料只有打卡時間但沒有明確加班欄位，先確認計算規則；若規則缺失，不能自行臆測，應請使用者補充。

3. **按人彙總**
   - 將同一人的所有本月加班時數加總。
   - 保留原始單位一致性；若資料以分鐘提供，先統一換算成小時再彙總，或全程以分鐘計算後再轉回小時。

4. **判斷是否超過 46 小時**
   - 對每個人比較總加班時數與 46 小時。
   - 超過 46 小時者標記為「超過 46 小時」或等效標示。
   - 若剛好 46 小時，不算超過。

5. **輸出結果**
   - 以清楚表格或清單呈現：
     - 姓名/員工編號
     - 本月加班時數
     - 是否超過 46 小時
   - 對超標者加上明顯標記，例如「⚠ 超過 46 小時」。

# 資料不足時的處理
- 如果缺少某些人的加班資料，先列出缺漏項目，不要自行補值。
- 如果出勤紀錄格式不一致，先整理成同一欄位後再計算。
- 如果無法從資料中判定加班時數，請明確說明需要哪些欄位或規則才能完成計算。

# 建議輸出格式
| 姓名 | 本月加班時數 | 是否超過 46 小時 |
|---|---:|---|
| A | 45.5 小時 | 否 |
| B | 48 小時 | ⚠ 是 |

# 注意事項
- 不要把正常工時誤算為加班。
- 不要混入非本月資料。
- 不要在沒有規則的情況下自行推算加班。
