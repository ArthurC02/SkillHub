## 任務

根據使用者提供的三個競爭對手價格頁 URL 與各頁面的基準價格快照，完成一次價格比較並直接輸出報告。每次執行都是手動檢查；不要建立背景排程、持續保存狀態，或發送 Email、Slack 及其他外部通知。

## 規則

Use only what the input contains — never add a date, name, assumption, step or branch the input does not give, and write 'not given' where it is silent.

Deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.

## 執行步驟

1. 從輸入辨識三個價格頁 URL，以及每個 URL 對應的基準價格項目。保留使用者提供的方案名稱、價格、幣別與計費週期；未提供的欄位標示為 `not given`。若執行所需的 URL 或基準價格資料缺失，只指出缺少的資料並停止，不猜測或補造資料。

2. 對每一個使用者提供的 URL 使用 `fetch_url` 讀取最新公開頁面。只使用工具實際回傳且可由來源頁面直接驗證的內容；若頁面無法讀取，為該 URL 明確標示無法讀取，並將無法取得的價格欄位標示為 `not given`，不要捏造價格。

3. 從每個成功讀取的頁面擷取公開可見的方案名稱、價格、幣別與計費週期。保留頁面原文能支持的表示方式；無法確認的欄位寫 `not given`。將目前頁面擷取到的項目與該 URL 的基準項目逐一比對，至少涵蓋基準中每一個項目。

4. 對每個基準項目分類：
   - 名稱、價格、幣別或計費週期與目前頁面不同：列為價格變動，顯示方案名稱、基準價格、目前價格、幣別或計費週期，以及來源 URL。
   - 在目前頁面找不到：列為「可能移除或未找到」，顯示基準項目與來源 URL；不要列為價格未變動。
   - 與基準完全一致：列為沒有偵測到價格變動。

5. 對目前頁面有、但基準快照沒有的可辨識價格項目列為新增，顯示方案名稱、目前價格、幣別或計費週期，以及來源 URL。若頁面內容不足以確認其為價格項目，不要自行推定。

6. 輸出一份分節或分頁的比較報告，三個 URL 各有一個對應區段。每個區段包含來源 URL、檢查時間、變動項目、新增項目、可能移除或未找到項目，以及沒有偵測到變動的項目。檢查時間只使用執行環境或工具明確提供的時間；若沒有提供，寫 `not given`。報告只呈現來源可驗證的結果。
