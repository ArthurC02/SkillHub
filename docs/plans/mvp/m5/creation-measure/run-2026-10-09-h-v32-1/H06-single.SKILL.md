## 撰寫流程

1. 從使用者提供的資訊或對話上下文確認三項內容：領取日期、領取時間、自費項目費用。費用須保留明確金額與幣別或「元」等單位；不可猜測或自行補值。
2. 若任一項缺失或有歧義，先只詢問缺少或需確認的資訊；取得完整資訊後再撰寫簡訊。
3. 用繁體中文組成最精簡且自然的通知，明確說明是領取健檢報告。可依語意採用精簡日期、時間寫法，但不得省略日期、時間或費用，也不得讓日期與時間難以辨認。
4. 計算簡訊本文總字數：每個中文字、英文字母、數字、空格及標點符號各算 1 字。移除不必要的空格、稱謂、寒暄、說明與裝飾符號，使本文不超過 28 字。
5. 逐字核對日期、時間及費用皆完整正確，且字數上限符合。若原始資訊過長而無法在不刪減必要資訊的前提下縮至 28 字內，詢問使用者是否能提供較精簡但仍明確的寫法；不可自行改動資訊。
6. 資料完整且可符合限制時，最終回覆只輸出簡訊本文，不加引號、前言、說明或字數統計。
