# 健身中心會籍到期續約通知

依輸入資料逐筆撰寫友善、簡潔的繁體中文續約通知；只使用已提供的事實，不核實資料，也不推測優惠條款。

1. 依輸入順序辨認每筆資料。保留提供的姓名、到期日期、續約優惠價、日期與價格格式，以及其他資訊原文；不要替換、換算或增添事實。未提供姓名時寫「姓名未提供」；未提供到期日期或續約優惠價時，在通知中明確標示「到期日期未提供」或「續約優惠價未提供」，並以標記空白保留可直接補填的位置。
2. 每筆各寫一則通知。本文最多 2 句，必須包含到期日期及續約優惠價（缺少時依上一步標示）；盡量納入其他資訊。可將資訊合併在同一句中，但不可改變其意思。若有資訊被省略或合併，在該則通知後另加 1 句「補充說明：……」，列明省略或合併了哪些資訊；沒有省略或合併時不加說明句。
3. 若日期不存在、數量為負、同一欄位有互相矛盾的值，或較後的說法改動先前數值，逐一原樣列出有問題的值並寫「請確認以下資料：……」。不採用有問題的值，不輸出依賴它的總數或結論；仍交付其餘可完成的通知，並以標記空白呈現尚無法填入的欄位。不要提出其他問題，也不要讓回覆以問句結尾。
4. 若輸入缺少資料，直接用一般預設值：繁體中文、友善簡潔語氣、依輸入順序處理；在輸出中標示必要但未提供的資料。若完全沒有會員資料，交付一份可用模板，以「【會員姓名：空白】」「【到期日期：空白】」「【續約優惠價：空白】」標記缺項，不要求對方先補資料。
5. 將全部通知與需要的補充說明整理成最終答覆，存入 `answer.txt`，每筆通知作為一個獨立項目。從含有此 SKILL.md 的目錄執行以下命令；每個 `--require` 後的值使用對應會員實際提供的日期與優惠價，若缺少則用通知內的「未提供」標記。逐筆確認本文不超過 2 句且必要資料都出現；若檢查未通過，修改 `answer.txt` 並重跑，直到輸出 `OK`：

```sh
python scripts/check_output.py answer.txt --max-sentences 2 --require "到期日期與日期值" --require "續約優惠價與價格值"
```

6. 最終回覆只提供 `answer.txt` 的內容；不要附上檢查過程或額外前言。
