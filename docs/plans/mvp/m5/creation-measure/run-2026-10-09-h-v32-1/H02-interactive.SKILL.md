# 駕訓班退費資格分類

依輸入資料逐筆分類退費資格，不計算退費金額，也不提供法律或政策判斷。

## 步驟

1. 從使用者提供的資料辨認每筆學員的識別碼、是否已通過路考並取得駕照、以及繳費至今天數。只將明確的「是／否」狀態轉成程式所需的 `是` 或 `否`；不推測缺漏或含糊的事實。保留每項資料原有內容，不改寫數字。
2. 若沒有任何學員資料，直接提供下列可用模板，保留空格並標示資料未提供；不要提問：

   ```text
   識別碼：［未提供］
   已通過路考並取得駕照：［未提供］
   繳費至今天數：［未提供］
   退費分類：［未提供（缺少分類資料）］
   ```

3. 對缺少路考／駕照狀態或繳費天數的個案，不猜測、不分類；在最終內容標示該欄「未提供」，並將分類標示為「未提供（缺少分類資料）」。其他資料完整的個案仍照常處理。識別碼缺少時以「未提供」呈現，不因此停止分類。
4. 對資料完整的個案，從 SKILL.md 所在目錄執行程式；每筆資料使用一次 `--record`，依序提供識別碼、狀態（`是` 或 `否`）、繳費天數：

   ```sh
   python scripts/classify_refund.py --record '甲' '是' '12' --record '乙' '是' '50' --record '丙' '否' '30' --record '丁' '否' '31'
   ```

   將範例資料換成使用者實際提供的資料；缺少識別碼時用 `未提供`。如有欄位缺漏的個案，不要把它當作完整資料傳入程式。
5. 將程式印出的每一行原樣作為完整資料個案的分類結果，並補上步驟 3 所述的缺漏個案標示。若程式以代碼 2 結束，原樣呈現它印出的單行訊息，並說明其中列出的值需要由提供者確認後更正；不要提供依賴那些值的分類。只輸出識別碼與分類，不添加金額或其他判斷。
