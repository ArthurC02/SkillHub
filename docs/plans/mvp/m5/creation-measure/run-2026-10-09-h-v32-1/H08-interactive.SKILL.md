## 使用時機
收到二手服飾收購資料，要整理驗收清單並計算金額時使用。輸入以文字為主；只依據使用者提供的資料，不判斷商品狀況或價格是否合理。

## 步驟
1. 從輸入依原順序辨認每筆資料的收購日期、品項、數量及收購單價。保留每項資料原樣，不補造或改寫事實；未提供的欄位在清單寫「未提供」。若完全沒有資料，仍產出一列欄位標為「未提供」的可用清單範本。
2. 缺少幣別時採用新台幣（TWD），並在答案中說明此預設；數量單位缺少時採用「件」，並說明此預設。保留使用者明示的幣別及數量單位。
3. 檢查數值及日期。辨認不存在的日期、負數量或其他明確不能使用的值，以及同一欄位互相矛盾的值（包括後文改動前文數字）。逐一列明原值並以「請確認：……」請使用者確認，不要用該值計算依賴它的金額；其他不受影響的欄位與計算照常處理。不要追問其他事項。日期或品項缺漏本身不妨礙金額計算。
4. 把每筆數量及單價整理為命令列資料：已提供且可用的數值照實傳入；缺漏或有爭議的數量或單價以 `-` 傳入。從本 Skill 檔所在目錄執行下列命令；`lines` 是依輸入順序建立的 shell 陣列，每個元素為一筆的「數量|單價」：
   ```bash
   args=()
   for line in "${lines[@]}"; do args+=(--line "$line"); done
   python scripts/calc_totals.py "${args[@]}"
   ```
   依程式輸出填入逐筆小計及總金額，並呈現程式印出的內容。若程式以代碼 2 結束，照實列出它印出的單行錯誤，請使用者確認其中點名的值；不要自行代算或提供受該值影響的總額。若有缺漏或不可用的數量／單價，將其小計標為「未計算」；只在所有列都能計算時列出總金額，否則標明總金額未計算及原因。
5. 回答時提供 Markdown 驗收清單表格，依序列出收購日期、品項、數量、收購單價及小計，並獨立標示總金額或未計算原因。列明採用的預設；只包含輸入資料及其計算，不加入新收購資料。以完整清單和結果作答，不以問題或待確認後再完成的承諾結尾。
