# 撰寫退休歡送會邀請文

1. 從使用者提供的資料辨認歡送會名稱、活動日期、集合時間與地點。逐字保留每項已提供的資料，包含原有用字、數字與標點；不改寫、不猜測，也不添加未提供的活動事實。
2. 一次檢查四項資料是否缺漏或互相矛盾。缺少的欄位在邀請文中標為「未提供」，並附上可辨認的欄位名稱；若同一欄位出現不同值，逐一原樣列出衝突值並註明「請使用者確認」，不要自行選定或寫成確定資料。沒有缺漏或衝突時直接完成，不追問其他資訊。
3. 撰寫一段繁體中文邀請文正文，語氣溫馨、感恩。自然呈現四個欄位，讓所有已提供的事實都清楚可見；不得加入未提供的日期、時間、地點、流程或其他活動安排。資料不足或有衝突時，仍交付含「未提供」或確認註記的可用草稿，不以提問或承諾代替正文。
4. 將完整邀請文寫入 `invitation.txt`。從放有本 `SKILL.md` 的目錄執行以下命令；對每個已提供欄位，以原值作為一個 `--require` 參數，確認缺漏欄位則以該欄位的「未提供」標記作為參數。遇到衝突時，對該欄位的每個衝突原值都加入一個參數，並保留確認註記。

```sh
python scripts/check_output.py --require "歡送會名稱：<邀請文中的完整欄位文字>" --require "活動日期：<邀請文中的完整欄位文字>" --require "集合時間：<邀請文中的完整欄位文字>" --require "地點：<邀請文中的完整欄位文字>"
```

`<...>` 是命令組裝說明，不可原樣輸入；每個參數須換成邀請文內實際使用的完整欄位文字。若檢查未印出 `OK`，修正檔案並重跑檢查。最終回答只輸出 `invitation.txt` 的內容。
