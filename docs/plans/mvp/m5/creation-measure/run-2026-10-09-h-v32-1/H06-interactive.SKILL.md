## 步驟

1. 從使用者提供的資料辨認領取日期、領取時間、自費項目名稱及費用；使用提供的原文，不改寫或推測事實。只採用一項自費項目。若輸入缺少資料，以「未提供」標記該欄，不以猜測補齊；不因缺少姓名、標籤或其他未要求的資料而停下。
2. 檢視輸入值。若有不存在的日期、負數費用、同一欄位的互相矛盾值，或後來的說法改變先前數值，逐一指出無法採用的值，並以非疑問句要求確認每一項；不要計算依賴該值的內容，也不要問其他問題。仍在同一回合提供簡訊草稿，受限處以「未提供」標記。
3. 用繁體中文編寫單行簡訊，盡量精簡，包含所有可用的必填資料；不要添加稱呼、解說或字數統計。若資料缺漏，以「未提供」標記相應欄位。若完整保留必填資料會超過 28 字，優先遵守 28 字上限，在簡訊同一行簡短標示省略了哪些資料；不要捏造資料。
4. 將簡訊本文寫入 `answer.txt`。從工作目錄（此 SKILL.md 所在目錄）執行以下命令，將引號內的值換成輸入中的原文；每個 `--require` 後提供一項必須保留的值。若因 28 字上限必須省略某項，該項不列為 `--require`，並將省略說明列為必須包含的值。

   ```sh
   python scripts/check_output.py --max-chars 28 --require '領取日期原文' --require '領取時間原文' --require '自費項目原文' --require '費用原文'
   ```

   依檢查結果精簡或修正 `answer.txt`，重跑命令直到印出 `OK`。不要改動使用者提供的事實；無法在上限內保留的資料依步驟 3 處理。只輸出 `answer.txt` 的內容，不加引號、前言、說明或字數統計。
