# 裝潢工程報價提案

依下列步驟，使用收到的屋主資料產出完整、可供人員使用的繁體中文提案；一次處理，不以追問代替交付。

1. **整理輸入資料。** 擷取屋主提供的工程項目、計價單位、數量、單價、聯絡資訊、丈量安排、建材規格、採購數量、配送資訊，以及已明示的條件。將工程報價與建材採購分開。預設幣別為新臺幣，並在提案中說明這項假設。
2. **檢查資料。** 所有已提供的事實照原文記載，不改寫成另一個事實。缺少的欄位標示「未提供」；不能推定價格、規格、稅額、付款條件、工期或其他工程內容。把每個不可能或互相矛盾的值列為「需確認」，包括後續說法改變前述數字的情況；不要替使用者選一個值，也不要計算依賴該值的金額。只需確認確有問題的值，不要對其他資料提問。即使有缺漏，仍交付可用草案；以標示空白的欄位呈現必要但未提供的內容。
3. **計算明確項目。** 對有明確名稱、單位、非負數量及非負單價的每項工程和建材，從存放本 `SKILL.md` 的目錄執行以下命令；每個項目各加一個對應旗標，格式為 `名稱|單位|數量|單價`。只傳入明確且無爭議的資料；缺少或待確認的值不要代填。命令列參數以引號包住，名稱、單位不可含 `|`。

   ```sh
   python scripts/quote_totals.py --engineering-item '拆除舊地磚|平方公尺|12|800' --material-item '防水材|桶|2|1350' --appointment-date 2026-10-16
   ```

   將範例參數替換為本次實際提供的資料；沒有明確工程或建材項目時，省略該類旗標。沒有丈量日期時，省略 `--appointment-date`。此命令會輸出各項金額與各自小計，照原樣呈現其計算結果。小計只代表已傳入的明確項目；不得將工程與採購小計合併。若命令以代碼 2 結束，照其單行錯誤指出需確認的值，不呈現依賴該值的金額，仍完成提案。
4. **撰寫提案。** 交付屋主可讀的工程報價表，逐列呈現項目、計價單位、數量、單價與金額，並獨立列出工程小計。分開提供建材採購表、配送資訊及採購小計。未提供稅率時不加計稅額；不自行補上稅額、付款條件或工期。把數量與金額標示為草案，提醒人員丈量或人工核實；不得讓未確認資料看起來已確定。
5. **準備丈量聯絡內容。** 依已提供的聯絡對象、建議時段、地址與丈量目的，寫一段可供人員使用的聯絡話術，並請對方確認是否可安排。缺少的欄位標示「未提供」或留標示空白。不得稱已打電話、已聯絡或已確認。
6. **交付完整成品。** 在同一則回覆中提供完整提案、丈量話術與採購資料；把需確認資料逐項列明，並指出任何為遵守硬性限制而未列入的內容。不得以問題、待補資料的承諾或後續計畫取代成品。

電話：本 Skill 無法代為撥打或傳送聯絡內容；由屋主或承辦人員使用上述話術聯絡師傅。

採購：本 Skill 無法登入供應商系統或下單；由獲授權的人員核實資料後自行輸入並下單。
