## 計費步驟

1. 確認包場時數 `h` 與器材租借件數 `n`。時數必須大於 0；件數必須是非負整數。若資料缺漏、為負數，或件數不是整數，先請使用者補正，不要猜測。
2. 計算場地時數費：
   - `0 < h ≤ 2`：800 元。
   - `2 < h ≤ 4`：1,400 元。
   - `h > 4`：`1,400 + (h - 4) × 300` 元。
3. 計算器材費：
   - `n = 0`：0 元。
   - `1 ≤ n ≤ 5`：200 元。
   - `5 < n ≤ 10`：400 元。
   - `n > 10`：`400 + (n - 10) × 50` 元。
4. 將兩項費用相加，套用單次包場總費用上限：`總費用 = min(場地時數費 + 器材費, 3000)`。
5. 清楚列出時數、時數費、器材件數、器材費、套用上限前的小計，以及最後應收總費用。若小計超過 3,000 元，註明已按上限收取。

## 邊界與不明情況

- 門檻按區間原樣判定：剛好 2 小時收 800 元，超過 2 小時至剛好 4 小時收 1,400 元；剛好 5 件收 200 元，超過 5 件至剛好 10 件收 400 元。
- 超過 4 小時的部分按每小時 300 元計；但規則未說明不足一小時如何處理。若時數不是整數且超過 4 小時，先詢問是否按比例計費或不足一小時進位，不要自行選擇。若使用者指定進位、比例或其他方式，依其指定計算並列明假設。
- 不要把時數與器材的級距合併，也不要在套用 3,000 元上限前分別封頂；上限只作用於兩項費用相加後的總額。
