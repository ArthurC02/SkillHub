# 辦公室手搖飲團購訂單整理

依序把使用者提供的訂單文字整理成繁體中文清單，計算飲料金額，並將外送費獨立列出。

1. 逐筆讀取訂單文字，擷取品名、甜度、冰量及其他明確規格、數量、單價，以及明確提到的外送費。只用文字中提供的資料，不推測缺漏的品名、規格、數量或價格。原文未提供的品名或規格寫「未提供」。
2. 僅當品名、所有明確規格及單價都相同時才合併數量；規格或單價不同就分開列。缺少數量或單價時保留該筆，缺少的欄位標示「未提供」。若同一筆或後續更正對同一數值有互相矛盾的說法，列明各個原文數值，請訂購者確認；該筆受影響的數量或金額不參與計算，並標示「需確認」。不要提出其他問題。
3. 將每筆整理成腳本輸入：每筆是一個 JSON 物件，使用 `item`（品名）、`specs`（規格字串）、`quantity`（數量）、`unit_price`（單價）及可選的 `conflict`（矛盾內容說明）欄位。缺少欄位就省略，不要補造數值。數量用整數，單價用原文數字字串；將同一筆矛盾值放在 `conflict`，不要自行選一個值。每筆訂單各用一個 `--order` 引數；每筆明確提到的外送費各用一個 `--delivery-fee` 引數。從存放本 SKILL.md 的目錄執行：

   `python scripts/summarize_orders.py --order "$ORDER_JSON_1" --order "$ORDER_JSON_2" --delivery-fee "$DELIVERY_FEE_1"`

   將命令中的引數依實際筆數增減；若沒有外送費，不傳 `--delivery-fee`。`$ORDER_JSON_1` 等名稱代表本次從原文整理出的 JSON 字串，不是要交給使用者填寫的欄位。若使用者沒有提供訂單文字，仍提供可用的空清單模板，欄位標示「未提供」，並說明沒有訂單資料可供計算。
4. 把腳本輸出的清單、已知金額合計或飲料總金額，以及外送費原樣納入答案。若有未提供的價格、數量或需確認的矛盾，保留腳本的已知金額合計並說明飲料總額不完整；不可提供依賴缺漏或矛盾數值的總額。若沒有提到外送費，標示「外送費：未提供」。輸出完整訂購清單，不附推測的資料。
