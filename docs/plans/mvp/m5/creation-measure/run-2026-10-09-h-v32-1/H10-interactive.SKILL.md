# 運動中心場地包場費用計算

依照輸入的每筆包場時數與器材件數計算費用，並以表格交付結果。

## 步驟

1. 從使用者訊息讀取一筆或多筆紀錄；按輸入順序保留紀錄。記下每筆包場時數與器材件數，輸入中提供的標籤或數值照原樣呈現，不補造資料。標籤不影響計算，也不是執行計算的必要輸入。
2. 直接採用以下常見假設，不另行詢問：正時數不足 1 小時仍收最低場地費；超過 4 小時的不足 1 小時部分按比例計價；器材件數必須是非負整數；最終應付金額四捨五入至整數元，恰為 .5 時進位。缺少的設定採用這些假設，並在回答中說明採用的假設。
3. 檢查每筆時數是否為有限且非負的數值、件數是否為非負整數。若有不能使用的值，不把該筆送去計算；在輸出中原樣指出每個問題值，將該筆的費用欄標為「待確認」，不給依賴該值的合計，並以一行請使用者確認這些值。其他有效紀錄仍照常計算。若有有效紀錄，將它們依序作為重複的 `--record HOURS ITEMS` 參數傳入下列命令；若沒有有效紀錄，執行不帶參數的命令以取得空白表格模板。
4. 從放有本 `SKILL.md` 的目錄執行：

   ```bash
   python scripts/calculate_fees.py --record HOURS ITEMS [--record HOURS ITEMS ...]
   ```

   將每筆實際數值代入一組 `--record HOURS ITEMS`，並以腳本印出的場地費、器材費、封頂前合計、最終應付金額和上限狀態為準。腳本若以代碼 2 回報無法使用的值，原樣保留其錯誤訊息，不為該值計算。
5. 以表格逐筆列出輸入、場地費、器材費、封頂前合計、最終應付金額及是否觸及 3000 元上限。把缺少的欄位標為「未提供」，不得自行填值；只有缺少標籤、而時數與件數齊全時，仍須照常計算。若資料不足以計算某筆，提供該筆的可用表格列並將結果欄標為「未提供」或「待確認」。不得加入其他費用或折扣。完成後在同一則回答中直接交付表格及必要說明，不只提供計畫或問題。

## 費率計算

所有費率級距、比例計算、合計、上限判斷與四捨五入均由腳本執行，不自行重算或在回答中替代腳本的計算結果。
