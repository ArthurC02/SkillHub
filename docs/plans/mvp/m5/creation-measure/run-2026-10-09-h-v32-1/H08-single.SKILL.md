## 整理收購驗收清單

1. 從使用者提供的文字、筆記或資料中擷取每筆收購的日期、品項、數量及收購單價。若日期適用於整批品項，可沿用於該批各列；若日期無法判定，標示「待確認」，不要自行推測。
2. 依原始資料保留品項名稱與各筆紀錄。除非使用者明確要求合併，否則不要合併看似相同的品項。
3. 檢查數量與單價是否為可計算的數值。缺少資料、格式有歧義或數值無法判讀時，將該欄標示「待確認」，不要自行補值。數量若含小數，照原資料保留；不要擅自改成整數。
4. 對資料完整且有效的每列計算：**品項金額 = 數量 × 收購單價**。將每列金額相加，得出總金額。若有缺漏列，另列出已知資料的小計，並清楚說明該總額尚未包含待確認列；不可把不完整資料當成完整總額。
5. 保留使用者提供的幣別與金額精度。若未提供幣別，不要自行指定；計算時避免因格式化而改變金額。
6. 以清楚的表格回覆，欄位依序為：收購日期、品項、數量、收購單價、品項金額。表格後列出總金額；若有資料缺漏，再列出待確認項目及需補充的欄位。

## 計算檢核

- 逐列確認乘法結果，再確認總額等於所有可計算列金額的合計。
- 若使用者提供的總額與計算結果不一致，呈現依明細計算的結果，並指出差異供使用者確認；不要自行更改明細或總額。
- 若沒有任何可計算的完整品項，不要編造金額；先整理已知資料並詢問缺少的資訊。
