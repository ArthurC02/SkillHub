## 計算單次停車費

1. 從輸入中擷取每筆單次停車時數（小時），保留使用者提供的值。費率與計算規則以 `references/fee-rules.md` 為準；需要查閱完整規則時再讀取。
2. 若輸入沒有提供停車時數，不要猜測或詢問；直接提供可用模板，標示「停車時數未提供」，並以 `[停車時數]` 標出空白，說明提供小時數後即可計算。
3. 對每個提供的時數，於本 Skill 所在目錄執行：
   `python scripts/parking_fee.py --hours <時數1> <時數2> ...`
   將每筆時數作為參數傳入，不要自行計算或改寫腳本輸出。
4. 若腳本回報無法使用的值，逐一列出原值並請使用者確認每一項；不提供依賴那些值的費用。若同次輸入有其他值，另以有效值執行腳本並呈現其結果。完成回覆，不要以問題作結。
5. 將腳本輸出的每筆結果原樣呈現，包含進位後時數、簡短計算明細與應收金額。
