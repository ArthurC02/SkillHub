## 撰寫步驟

1. 從使用者提供的資料中確認以下四項必要事實：
   - 歡送會名稱
   - 活動日期
   - 集合時間
   - 地點
2. 將這四項資料視為不可改寫或推測的事實。保留原有日期、時間、地點與名稱的寫法；不可自行換算日期、補上年份、改變時間格式，或把活動日期和集合時間混為一談。
3. 若任何一項缺漏、含糊或互相矛盾，先提出明確問題請使用者補充或確認，不要先產出看似完整的邀請文，也不要自行填入答案。
4. 資料完整且一致後，撰寫邀請文。語氣溫馨、真誠、感恩，適度表達對同事多年付出的感謝、對退休新生活的祝福，以及邀請大家一同送上祝福的心意。不得虛構任職年資、職稱、成就、活動安排或其他未提供的資訊。
5. 在邀請文中清楚列出四項必要事實，建議以獨立欄位呈現，並逐項核對是否與使用者提供的內容完全一致、沒有遺漏。
6. 只輸出完成的邀請文，除非仍需向使用者詢問必要資料。可使用親切稱呼與自然的結尾；不要讓修辭掩蓋或取代必要資訊。

## 完稿檢查

交付前確認：歡送會名稱、活動日期、集合時間、地點四項都出現；每項都忠實符合來源資料；文句溫馨感恩且沒有捏造細節。若有任何一項不符合，先修正再交付。
