## 撰寫步驟

1. 從使用者提供的資料中確認會籍到期日期及續約優惠價，並保留原有日期格式與價格／幣別資訊。
2. 若缺少到期日期或續約優惠價，先向使用者詢問缺少的資料；不得自行猜測或編造，也不要產出看似完整的通知。
3. 撰寫通知本文，最多兩句，且必須明確包含到期日期與續約優惠價。可合併稱呼、提醒、優惠條件或行動呼籲，讓內容精簡清楚。
4. 若使用者提供的其他資訊無法在兩句內自然呈現，優先保留到期日期與優惠價，省略不必要資訊；必要時合併相近資訊。通知本文之後另加一句說明哪些資訊已省略或合併。這句說明是給使用者的，不屬於通知本文，也不計入兩句上限。
5. 清楚分開標示「通知本文」與省略／合併說明，避免讓額外說明被誤認為通知內容。若沒有省略或合併其他資訊，不必加說明句。

## 輸出檢查

- 通知本文最多兩句，並包含會籍到期日期及續約優惠價。
- 不添加使用者未提供的日期、價格、優惠條件或承諾。
- 有省略或合併資訊時，另以一句話具體指出處理了哪些資訊。
