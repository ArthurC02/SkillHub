# Data Analyst Resume Rewriter

## Purpose
Rewrite an existing resume into a concise, one-page version tailored for data analysis roles.

## When to use
Use this skill when the user provides resume content and wants it reframed for data analyst or data-related openings without inventing any experience, skills, education, or achievements.

## Requirements
- Keep the result to one page or less.
- Preserve truthfulness: only use information explicitly provided by the user.
- Emphasize relevance to data analysis roles, such as analysis work, tools, projects, impact, metrics, reporting, dashboards, experimentation, or automation where present in the source.
- Produce a clear, directly usable resume draft.
- Do not add unsupported employers, titles, degrees, tools, certifications, or results.

## Rewrite process
1. Read the source resume carefully and extract only confirmed facts.
2. Identify the strongest data-analysis-relevant items:
   - measurable outcomes
   - analysis or reporting responsibilities
   - tools and methods mentioned by the user
   - projects that demonstrate problem solving with data
3. Reorder content so the most relevant items appear first.
4. Rewrite bullet points to be concise, achievement-oriented, and role-relevant.
5. Remove low-signal detail if needed to keep the final resume within one page.
6. If the source lacks enough detail to support a strong data-analysis angle, keep the wording accurate and generic rather than inventing substance.

## Writing rules
- Keep wording professional and concise.
- Prefer action verbs and measurable outcomes when the source supports them.
- Translate unrelated experience into transferable skills only when the connection is explicitly supported by the source.
- Keep formatting simple and easy to scan.
- If the source includes dates, titles, education, certifications, or skills, retain them only as provided.

## Output structure
Produce a resume draft with these sections only when supported by the source:
- Name and contact details
- Professional summary
- Skills
- Experience
- Projects
- Education
- Certifications

Omit sections that are empty or unsupported.

## Quality checks
Before finishing, verify that:
- no unsupported claims were added
- the draft clearly targets data analysis roles
- the length is suitable for one page
- the formatting is readable and ready to edit further if needed
