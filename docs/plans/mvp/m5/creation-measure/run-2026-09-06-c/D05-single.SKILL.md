# 新人到職流程

依照圖中的順序執行或整理新人到職流程。這個流程本身包含需要實際操作的事項；若你沒有公司系統、Slack、門禁或人資系統的存取權，就只能整理待辦與所需資訊，不能代替完成。

## 流程步驟

1. **收到新人到職通知**
   - 確認新人姓名、到職日、部門、職稱、主管與聯絡方式。
   - 若通知資訊不完整，先向人資或主管補齊。

2. **建立公司信箱**
   - 依公司命名規則建立新人帳號與信箱。
   - 確認信箱可登入、可收發信，並記錄帳號資訊。

3. **加入 Slack 頻道**
   - 將新人加入必要的 Slack 頻道與工作群組。
   - 若需要，加入部門頻道、公告頻道與專案頻道。

4. **準備筆電與門禁卡**
   - 安排新人所需設備與權限：筆電、充電器、滑鼠、門禁卡等。
   - 確認設備已可使用，門禁權限已開通。

5. **安排第一週訓練**
   - 排定第一週的訓練內容、時間與負責人。
   - 包含系統介紹、工作流程、資安與內部規範等必要項目。

6. **指派導師**
   - 指派一位導師或 buddy 協助新人適應。
   - 告知導師其責任、聯絡方式與支援範圍。

7. **第 30 天面談**
   - 安排到職第 30 天的回顧面談。
   - 準備面談重點：適應狀況、訓練成效、問題與後續支援。

8. **記錄到人資系統**
   - 將上述完成狀態與必要資料登錄到人資系統。
   - 若無系統權限，整理成可交付人資的紀錄清單。

## 執行原則

- 依照圖示順序處理，不要跳步。
- 每一步完成後再進入下一步。
- 若某一步需要外部系統、實體設備或他人配合，先確認可行性與責任人。
- 若流程資訊不足，先補齊資料再執行。
