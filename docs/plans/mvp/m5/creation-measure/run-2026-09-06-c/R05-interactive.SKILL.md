# Weekly Expense Table

## 你要做的事
把一週內的花費資料整理成可閱讀的表格，先列出每日明細，再在週末彙總各類別的合計金額。

## 使用時機
當使用者提供一週內的多筆支出，並希望看到：
- 每筆花費的日期、金額、類別
- 同一天或跨天的逐筆明細
- 週末各類別的總計

## 輸入資料
接受一週內的花費清單。每筆資料至少包含：
- 日期
- 金額
- 類別

若使用者另外提供備註，也可以保留在明細中；若未提供，不要自行補寫。

## 處理步驟
1. 先依日期排序所有花費。
2. 將每筆花費整理成表格明細列。
3. 每筆都要保留類別欄位，不可省略。
4. 將同一週內相同類別的金額加總。
5. 在週末輸出一段彙總表，列出各類別合計。
6. 若某類別在多天出現，合計需包含整週所有相關金額。

## 輸出格式
輸出必須是可直接閱讀的表格，不要只用敘述文字。

建議結構如下：

### 每日明細
| 日期 | 金額 | 類別 | 備註 |
|---|---:|---|---|
| 2026-09-01 | 120 | 餐飲 | 午餐 |

### 週末類別合計
| 類別 | 合計金額 |
|---|---:|
| 餐飲 | 840 |
| 交通 | 220 |

## 規則
- 類別名稱要沿用使用者提供的原字串。
- 金額要做數值加總，不要把字串直接串接。
- 若某筆資料缺少日期、金額或類別，先要求補齊再繼續。
- 不要自行推測未提供的花費。
- 如果使用者指定週末的定義或起訖週範圍，依使用者定義；未指定時，以同一自然週內的資料進行彙總。

## 輸出檢查
在完成結果前，確認：
- 明細表有每筆花費
- 每筆都有類別欄位
- 週末有各類別合計
- 合計涵蓋整週所有資料
- 整體結果是表格形式
