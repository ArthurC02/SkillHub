# 目的
將一週內的每日花費整理成清楚的表格，為每筆支出標註類別，並在週末彙總各類別合計。

# 適用情境
- 使用者提供一週的消費明細，要求整理成表格。
- 使用者希望每筆支出都加上類別標籤。
- 使用者要求在週末計算各類別總額。

# 工作流程
1. **先確認資料範圍**
   - 讀取使用者提供的日期、金額、品項或用途。
   - 若資料不足以判斷類別，先根據品項名稱推定；仍不確定時，標為「其他」並保留原始描述。
   - 若缺少日期，依使用者提供的順序視為一週內的每日紀錄。

2. **統一分類規則**
   - 為每筆花費指定一個類別，類別名稱保持一致，避免同義詞混用。
   - 若使用者未指定分類，可採用常見類別，例如：
     - 餐飲
     - 交通
     - 購物
     - 娛樂
     - 生活用品
     - 醫療
     - 住宿
     - 其他
   - 同一筆支出只歸入一個主要類別；若使用者要求多重分類，再另外拆分。

3. **建立每日明細表**
   - 以日期為列或區塊，列出每筆支出。
   - 每筆至少包含以下欄位：
     - 日期
     - 項目/用途
     - 類別
     - 金額
   - 若有備註或付款方式，也可加欄，但不要影響主要欄位的清楚性。

4. **計算每日小計**
   - 對每一天加總當日所有支出。
   - 若使用者需要，也可同時列出當日各類別小計，但至少要有每日總額。

5. **計算週末各類別合計**
   - 將整週所有支出依類別加總。
   - 週末合計表至少包含：
     - 類別
     - 合計金額
   - 若某類別沒有支出，不必列出。

6. **輸出格式**
   - 先輸出「每日明細表」。
   - 再輸出「週末類別合計表」。
   - 表格欄位名稱要簡潔一致，金額格式要統一。
   - 若使用者提供幣別，沿用該幣別；若未提供，保留原始金額格式，不自行假設幣別。

# 表格建議格式
## 每日明細表
| 日期 | 項目/用途 | 類別 | 金額 |
|---|---|---:|---:|
| 週一 | 早餐 | 餐飲 | 80 |
| 週一 | 公車 | 交通 | 30 |

## 週末類別合計表
| 類別 | 合計 |
|---|---:|
| 餐飲 | 560 |
| 交通 | 180 |

# 處理原則
- 保持原始資料忠實，不要任意補寫不存在的花費。
- 類別判斷以可讀性與一致性優先。
- 若同一筆資料含多個用途，優先依主要支出目的分類。
- 若使用者要求「週末算出各類別合計」，應以整週總計為準，而不是只算週六、週日。
