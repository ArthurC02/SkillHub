# Daily News Summarizer Emailer

## 目的
把使用者指定的 3 個新聞網站在每天早上整理成 5 條摘要，並寄送到指定電子郵件信箱。

## 何時使用
當使用者想要：
- 每天固定時間收到新聞彙整
- 從少量指定新聞網站提取標題資訊
- 產出簡短摘要並以電子郵件送達

## 必要輸入
在執行前，必須確認下列資訊：
1. 3 個新聞網站網址
2. 收件電子郵件地址
3. 每天早上的寄送時間
4. 摘要語言與風格要求；若未指定，預設使用中文、每條一句

若缺少任一必要輸入，先要求補齊，不要開始抓取或寄信。

## 執行流程
1. 讀取 3 個指定網站的最新標題。
2. 檢查每個網站是否可正常存取，以及標題是否可穩定擷取。
3. 從可用標題中挑選最重要的 5 則內容。
4. 將每則標題整理為 1 句摘要。
5. 在郵件中標示每條摘要的來源網站。
6. 寄送到指定信箱。

## 摘要規則
- 只根據網站標題與可直接取得的資訊摘要，不臆測內文。
- 優先保留新聞事件的主詞、動作、對象與時間線索。
- 5 條摘要應盡量涵蓋 3 個網站的內容。
- 若標題不足 5 則，明確標示可取得的數量與缺漏，避免補造內容。

## 錯誤與限制
- 若網站有付費牆、反爬限制、動態載入或版面不穩定，可能無法完整取得標題。
- 若無法取得足夠標題，仍應回報已成功擷取的內容與缺漏原因。
- 不要捏造新聞、標題或來源。
- 不對新聞真偽做判斷，只負責整理與摘要。

## 郵件內容建議格式
- 主旨：每日新聞摘要
- 內文：
  - 日期
  - 來源網站列表
  - 5 條摘要，每條附來源
  - 失敗或缺漏說明（如有）

## 驗收標準
- 取得 3 個有效新聞網站網址與收件信箱後，能產出一封可寄送的每日郵件草稿。
- 郵件內含 5 條中文摘要。
- 每條摘要可追溯到至少一個來源網站。
- 未提供必要輸入時，技能會先要求補齊資訊。
- 來源不足或抓取失敗時，技能會明確揭露缺漏而不編造內容。
