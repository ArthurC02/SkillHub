# 目標
將 Excel 中的客戶名單去除重複，並標記缺少電話的列。

# 執行步驟
1. **先確認欄位結構**
   - 找出哪一欄是客戶識別依據，通常是「姓名」、「公司」、「Email」或其組合。
   - 找出電話欄位名稱，通常是「電話」、「手機」或類似欄位。
   - 如果欄位名稱不明確，先查看前幾列資料判斷。

2. **備份原始資料**
   - 在原工作表保留原始資料不動。
   - 另存新工作表或複製一份工作表進行清理。

3. **去除重複資料**
   - 以最能代表同一客戶的欄位作為去重依據。
   - 若只有單一識別欄位，直接以該欄去重。
   - 若需要更準確，使用多欄組合去重，例如「姓名 + 公司」或「姓名 + 電話」。
   - 去重時保留第一筆出現的資料，除非資料規則要求保留最新一筆；若沒有規則，預設保留第一筆。

4. **標記缺少電話的列**
   - 新增一欄，欄名可設為「電話缺失」或「缺少電話」。
   - 對電話欄為空白、只有空格、或內容無法辨識為電話的列，標記為「是」或「缺少」。
   - 其餘列標記為「否」或留白，依一致格式處理。

5. **檢查清理結果**
   - 確認重複列已移除。
   - 確認所有沒有電話的列都已被標記。
   - 檢查是否因去重而誤刪不同客戶資料；若有疑慮，回到原始資料比對。

6. **輸出結果**
   - 將清理後的名單另存為新檔，避免覆蓋原始檔。
   - 檔名可加上「去重後」或「cleaned」以便辨識。

# 注意事項
- 如果資料中有多個工作表，先確認要處理的是哪一個。
- 如果電話欄有不同格式（例如含國碼、分機、破折號），只要欄位內容非空即可視為有電話，除非任務另有規則。
- 若無法明確判定去重依據，先詢問使用者要以哪幾欄判定重複。
