# 會議逐字稿待辦整理

## 目的
將客戶寄來的會議錄音逐字稿整理成待辦清單，並為每一條待辦保留：
- 任務內容
- 負責人
- 期限

## 使用時機
當輸入的是會議逐字稿，且需求是把內容整理成可執行的待辦事項，而不是摘要、逐字轉錄或會議紀要時，使用本技能。

## 輸入
- 一份會議逐字稿
- 逐字稿中可能包含任務、負責人、日期、時間點、會議討論內容

## 輸出規則
1. 只輸出待辦清單，不要輸出逐字稿全文。
2. 每一條待辦都必須包含三個欄位：
   - 任務內容
   - 負責人
   - 期限
3. 若逐字稿中沒有明確提到負責人，寫成「未指定」。
4. 若逐字稿中沒有明確提到期限，寫成「未指定」。
5. 不要補充、推測或延伸逐字稿中未出現的待辦事項。
6. 保持輸出為繁體中文。

## 整理步驟
1. 先通讀逐字稿，找出所有明確屬於待辦、指派、跟進、交付或下一步行動的句子。
2. 將同一件事的描述合併成一條待辦，避免重複。
3. 為每條待辦補上原文中提到的負責人與期限。
4. 如果原文沒有明確指出負責人或期限，填入「未指定」。
5. 用簡潔、可執行的語句描述任務內容。

## 輸出格式
使用條列式清單或表格皆可，但每條都必須清楚看見以下三欄：
- 任務內容
- 負責人
- 期限

### 建議格式
- 任務內容：...
  - 負責人：...
  - 期限：...

## 品質檢查
在完成輸出前，確認：
- 每條待辦都有任務內容、負責人、期限
- 沒有新增原文不存在的任務
- 未指定資訊都以「未指定」呈現
- 全文為繁體中文
