## 目標
將英文使用手冊完整翻譯為繁體中文，保留原意、操作順序、警告與格式；所有專有名詞在第一次出現時以「中文（原文）」呈現，之後只用中文或依上下文維持一致。

## 翻譯原則
1. **完整性優先**：不得省略段落、步驟、表格、註解、警告、圖說、標題、頁首頁尾中的有效內容。
2. **忠實翻譯**：維持技術含義與操作指示，不自行改寫成更口語或更簡短的版本。
3. **繁體中文**：使用繁體字與繁體標點。
4. **專有名詞處理**：
   - 第一次出現時寫成「中文譯名（英文原文）」。
   - 若原文本身就是常見產品名、功能名、按鍵名、介面名稱或縮寫，仍需在首次出現時保留原文。
   - 後續出現時，使用已確定的中文譯名，保持一致。
5. **術語一致**：同一術語在全文使用同一譯法；若手冊內已有固定譯名，優先沿用。
6. **格式保留**：盡量保留原本的章節層級、編號、項目符號、表格結構、注意/警告區塊與圖示說明。
7. **單位與數值**：數字、型號、版本號、路徑、命令、按鍵組合、錯誤碼、URL、檔名通常保留原樣，只翻譯周邊說明文字。
8. **不可臆測**：遇到模糊、缺頁、掃描不清或術語無法確定時，不要自行補寫；保留可辨識內容並標註不確定之處。

## 工作流程
1. **先通讀全文**，辨識：
   - 文件主題與產品名稱
   - 章節結構
   - 重複出現的術語
   - 需要首次附原文的專有名詞
2. **建立術語一致性**：
   - 為全文中重複的關鍵術語選定固定譯法。
   - 若同一詞在不同語境有不同意思，依上下文分別翻譯，但保持一致規則。
3. **逐段翻譯**：
   - 先翻譯標題與小標。
   - 再翻譯正文、步驟、警告、表格與註解。
   - 保留原有順序，不重排內容。
4. **首次出現標記**：
   - 在每個專有名詞第一次出現的段落中加入原文。
   - 若同一專有名詞在不同章節首次出現，仍以全文第一次出現為準。
5. **校對**：
   - 檢查是否漏譯、重譯、術語不一致、編號錯亂或格式破壞。
   - 確認警告、注意事項與操作步驟沒有被弱化。

## 專有名詞判定
通常需要首次附原文的項目包括：
- 產品名稱、型號、系列名稱
- 功能名稱、模組名稱、介面名稱
- 按鈕、選單、頁籤、欄位名稱
- 公司名、標準名、協定名、技術名
- 縮寫與首字母縮略詞

不需要每次都附原文的項目通常包括：
- 一般名詞與普通動作詞
- 已在全文首次出現時標記過的重複術語
- 明顯不需翻譯的代碼、命令、檔名、路徑、變數名

## 輸出要求
- 只輸出翻譯後的繁體中文內容。
- 保留原文件的結構與層級。
- 若原文有表格，盡量以表格形式呈現；若無法維持，改為清楚的條列，但不得遺漏欄位資訊。
- 若原文有圖片說明或圖表標題，翻譯其文字說明；無法辨識的圖中細節不要猜測。

## 品質檢查清單
- [ ] 全文已翻譯，無明顯遺漏
- [ ] 專有名詞首次出現已附原文
- [ ] 術語前後一致
- [ ] 步驟、警告、注意事項完整保留
- [ ] 編號、項目符號、表格資訊未錯亂
- [ ] 使用繁體中文且語氣符合使用手冊
