# Manual to Traditional Chinese

## Purpose
Translate a full English user manual into Traditional Chinese while preserving the original meaning, instructional tone, and document structure.

Use this skill when the source is a user manual, guide, or similar procedural document and the desired output is a faithful Traditional Chinese translation.

## Workflow

1. Read the entire source manual before translating any section.
2. Preserve the document's organization:
   - keep headings in the same hierarchy,
   - keep the same section order,
   - keep lists, tables, warnings, notes, and step numbering aligned with the source.
3. Translate into Traditional Chinese.
4. When a specialized term, product name, feature name, or other proper noun appears for the first time, include the original English in parentheses after the Chinese translation.
5. On later mentions, use the established Chinese term consistently unless the source requires the English form for clarity.
6. Keep procedural instructions direct and complete. Do not summarize, omit, or add new instructions.
7. If the source is ambiguous or the translation could change meaning, preserve the ambiguity as closely as possible and flag the issue in a translator note only if the surrounding task allows notes.
8. Review the finished translation for consistency in terminology, numbering, and punctuation.

## Translation rules

- Translate all visible text unless the source explicitly marks text as code, a file name, a button label, a menu path, or another element that should remain unchanged for usability.
- Keep product names, trademarks, file extensions, command names, and UI labels in the form that best preserves recognizability and usability.
- For first mentions of terms, prefer forms like `中文名稱 (English Term)`.
- Maintain the source's intent for warnings, cautions, prerequisites, and troubleshooting steps.
- Preserve measurements, units, version numbers, error codes, and technical identifiers exactly unless localization is required for readability and does not alter meaning.
- Do not convert the manual into a summary, explanation, or marketing copy.

## Output requirements

- Deliver the complete translated manual in Traditional Chinese.
- Keep the structure aligned with the source manual.
- Ensure terminology is consistent across the whole document.
- Ensure first-mention terminology includes the original term.

## Quality checklist

- The output is in Traditional Chinese.
- The full manual has been translated.
- No obvious section or paragraph has been omitted.
- First mentions of specialized terms include the original English.
- The document still reads like a user manual, not a summary.
- Headings and paragraph structure mirror the source document.
