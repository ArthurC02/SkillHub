# 每日新聞標題摘要寄送流程

## 先確認可執行條件
1. 確認三個新聞網站的名稱或網址。
2. 確認收件信箱地址。
3. 確認執行時間是「每天早上」的具體時刻與時區。
4. 確認是否已提供可用的網路存取與寄信權限；如果沒有，不能實際抓取網站或寄出郵件，只能先整理流程與待辦資訊。

## 若沒有網路或登入權限
1. 明確告知目前無法直接完成即時抓取與寄信。
2. 請使用者提供以下任一項：
   - 三個網站的 RSS/新聞頁面網址，或
   - 已整理好的標題清單，或
   - 可用的抓取與寄信環境。
3. 在取得資料前，先準備摘要格式與郵件模板。

## 摘要整理規則
1. 從三個新聞網站收集當日標題。
2. 去除重複、過度相似或明顯無關的標題。
3. 依重要性、時效性與覆蓋面挑選 5 條摘要。
4. 每條摘要應簡短、清楚，盡量用一到兩句話概括標題群的共同主題。
5. 若三個網站的內容高度重疊，優先保留來源較權威或資訊較完整的標題。
6. 若當日可用標題少於 5 條，則：
   - 先保留所有可用且有價值的摘要；
   - 不要為了湊滿 5 條而捏造內容；
   - 在郵件中註明「今日可用標題不足 5 條」。

## 郵件內容格式
1. 主旨：`每日新聞摘要 - YYYY-MM-DD`
2. 內文建議包含：
   - 問候語
   - 5 條摘要清單
   - 每條摘要後附上來源網站名稱或標題來源
   - 如有必要，附上原始標題列表作為參考
3. 內文保持簡潔，避免長篇評論。

## 執行步驟
1. 取得三個新聞網站當日標題。
2. 彙整並去重。
3. 生成 5 條摘要。
4. 檢查摘要是否忠於原始標題，不加入未證實資訊。
5. 組成郵件主旨與內文。
6. 若具備寄信權限，將郵件寄到指定信箱。
7. 若無法寄送，保存完成的郵件草稿並回報缺少的權限或連線條件。

## 品質檢查
1. 每條摘要都應能對應到至少一個原始標題。
2. 不得編造新聞內容。
3. 不得混淆不同網站的來源。
4. 不得在未確認的情況下加入個人評論或推測。
5. 若來源網站格式變動導致無法抓取，先記錄失敗原因，再請求更新網址或替代來源。
