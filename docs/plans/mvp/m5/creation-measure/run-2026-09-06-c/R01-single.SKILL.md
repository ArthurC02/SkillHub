# 目標
將會議逐字稿整理成可執行的待辦清單，每一條都要包含：
- 待辦事項
- 負責人
- 期限

# 處理步驟
1. **先確認輸入內容是否為逐字稿**
   - 若內容不是會議逐字稿、資訊不足，或無法辨識說話內容，先明確指出無法可靠整理，並列出缺少的資訊。
   - 若逐字稿中有多位說話者，保留可辨識的說話者資訊以利判定責任歸屬。

2. **找出所有行動項目**
   - 只收錄明確可執行的事項，例如：要完成、要提供、要確認、要修改、要聯絡、要回覆、要安排。
   - 排除純討論、背景說明、重複確認、情緒性發言、與行動無關的內容。
   - 若同一事項被多次提及，合併成一條。

3. **判定每條待辦的內容**
   - 用簡短、具體、可執行的語句重寫。
   - 避免保留口語贅字，但不要改變原意。
   - 若一段話包含多個動作，拆成多條待辦。

4. **指定負責人**
   - 優先使用逐字稿中明確點名的人名、職稱或角色。
   - 若是「我」或「我們」：
     - 若能從上下文判定具體人名，寫出該人名。
     - 若無法判定，寫成「未指派」並在必要時註明來源不明。
   - 若是客戶、供應商、外部單位負責，仍要寫明其角色或名稱。
   - 不要憑空推測負責人。

5. **找出期限**
   - 優先擷取明確日期、時間、星期、相對期限（例如「本週五前」、「下週一」、「月底前」）。
   - 若只有模糊時間（例如「盡快」、「稍後」），保留原文並標示為模糊期限。
   - 若完全沒有期限，寫「未提及」。
   - 不要自行補日期或換算成實際日期，除非逐字稿已明確提供可直接使用的日期資訊。

6. **整理輸出格式**
   - 以清單或表格呈現。
   - 每條待辦都必須有三個欄位：
     - 待辦事項
     - 負責人
     - 期限
   - 若有必要，可另外加上「來源片段」方便追溯，但不要取代前三個必備欄位。

# 品質規則
- 保持忠於逐字稿，不要加入會議外的推論。
- 不確定時寧可標示「未指派」或「未提及」，不要猜測。
- 若逐字稿中出現衝突資訊，以最後明確確認的內容為準，並在輸出中保留必要的註記。
- 若同一待辦的負責人與期限分散在不同段落，應交叉比對後再整理成單一條目。

# 建議輸出範例格式
- 待辦事項：完成簡報修訂
  - 負責人：王小明
  - 期限：本週五前
- 待辦事項：寄出報價單
  - 負責人：未指派
  - 期限：未提及
