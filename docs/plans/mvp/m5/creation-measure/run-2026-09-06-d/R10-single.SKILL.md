## 目的
每週從指定的 3 個 Slack 頻道中，找出「尚未被回覆」的問題訊息，整理成清單並附上原始訊息連結。

## 先確認的資訊
在開始前，確認以下內容是否已提供：
1. 3 個 Slack 頻道名稱或連結。
2. 「未回覆」的判定範圍：
   - 只看原訊息下方是否有任何回覆串（thread replies）
   - 或也要排除只有表情回應、沒有文字回覆的情況
3. 週期範圍：通常是最近 7 天，或指定的週起訖日期。
4. 輸出語言與格式偏好：若未指定，使用與提問相同語言，採條列清單。

如果缺少頻道或日期範圍，先請使用者補齊，不要自行猜測。

## 判定規則
1. 只收錄「問題」：
   - 明確提問句，例如含有問號、疑問詞、請求協助、請確認、有人知道嗎。
   - 若內容只是公告、更新、閒聊，不列入。
2. 只收錄「未回覆」：
   - 原訊息沒有任何文字回覆，且若使用者要求嚴格判定，也沒有實質回應。
3. 若同一問題在 thread 中已有回覆，視為已回覆，不列入。
4. 若訊息內容不明確，先保守排除，除非上下文很明顯是在提問。

## 工作步驟
1. 逐一檢視 3 個指定頻道在指定週期內的訊息。
2. 找出符合「問題」定義的訊息。
3. 檢查每則問題是否有 thread 回覆。
4. 將未回覆者整理成清單。
5. 每筆都附上可直接開啟的 Slack 原始訊息連結。

## 輸出格式
使用以下格式輸出：

- 頻道名稱｜發言者｜日期時間｜問題摘要｜連結

若同一頻道有多則未回覆問題，依時間由新到舊排序。

## 補充原則
- 不要把已回覆的問題混進清單。
- 不要只列頻道層級的摘要，必須列到單則訊息。
- 若無法取得某則訊息的連結，標註「連結不可用」，但仍保留該項目。
- 若資料來源不足以判定是否回覆，明確標示「需人工確認」，不要假裝已判定。
