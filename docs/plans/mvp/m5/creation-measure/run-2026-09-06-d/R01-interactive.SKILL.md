# 會議逐字稿待辦清單整理

將客戶寄來的會議錄音逐字稿整理成待辦清單。輸出時，每一條待辦都必須包含：
- 事項
- 負責人
- 期限

若原文沒有明說負責人或期限，不要推測；直接標示為「待確認」。

## 適用時機
- 使用者提供會議逐字稿，要求整理成行動項或待辦清單
- 需要把零散討論轉成可執行的工作項目
- 需要保留來源資訊，避免臆測責任人或截止日

## 作業流程
1. 通讀逐字稿，先找出所有明確的行動句、承諾、決議、後續追蹤事項。
2. 只保留可轉成具體行動的內容；排除單純寒暄、背景說明、重複敘述。
3. 對每個待辦項目，從逐字稿中找出：
   - 誰負責執行
   - 何時完成、何時回覆、何時開會或交付
4. 如果負責人只出現暱稱、職稱或團隊名稱，依原文照寫；不要自行對應到真人姓名。
5. 如果期限是相對時間或事件條件，例如「下週前」、「會後兩天」、「等對方確認後」，照原文轉寫為期限。
6. 如果某項缺少負責人或期限，寫成「待確認」，不要補想。
7. 若同一事項在不同段落被反覆提及，只輸出一次，並合併可確認資訊。

## 輸出格式
使用繁體中文，輸出為條列式待辦清單。每條至少包含下列欄位：
- 事項：
- 負責人：
- 期限：

可選擇加上：
- 備註：補充來源語句或不確定處

範例格式：
- 事項：整理報價並寄給客戶
  - 負責人：Alex
  - 期限：週五下班前
  - 備註：逐字稿中提到「我今天內整理好」

- 事項：確認合約條款
  - 負責人：待確認
  - 期限：待確認

## 品質要求
- 不要輸出摘要、逐字稿重寫或長篇說明
- 不要增加原文沒有的任務
- 不要省略已明確出現的行動項
- 輸出中的待辦項目數量應對應逐字稿中可辨識的行動項
- 保持內容簡潔、可直接交辦
