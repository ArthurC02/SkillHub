# Manual zh-TW Translator

將英文使用手冊翻譯成繁體中文，並在專有名詞第一次出現時保留英文原文。這個 Skill 適用於 需要把完整手冊轉成可閱讀、可對照原文的繁體中文版本時。

## 工作目標

- 翻譯整份英文使用手冊為繁體中文。
- 保留原始手冊的資訊順序與結構。
- 專有名詞、產品名、功能名、型號或重要術語在第一次出現時附上英文原文。
- 不增補原文沒有的重要資訊。

## 操作原則

1. 先通讀原文，辨識章節標題、條列、警語、步驟、表格、圖說與註記。
2. 翻譯時優先保留原文的段落與層級結構。
3. 對於專有名詞，第一次出現時採用「繁中譯名（原文）」；之後以一致譯名呈現。
4. 遇到縮寫、產品代號、按鍵名稱、介面標籤時，維持一致譯法；若原文常見英文標示更利於辨識，可在首次出現時保留原文。
5. 圖表、流程圖、警告框、注意事項、步驟列表與編號清單，都應以對應形式保留。
6. 若某段原文含有不確定術語，優先依上下文與手冊內其他用法保持一致，避免自行擴寫含義。

## 翻譯規則

- 使用繁體中文。
- 保持手冊語氣，避免口語化或過度改寫。
- 標題層級、段落切分、編號與項目符號盡量對應原文。
- 原文中的重要警示語、注意事項、前提條件與限制，需清楚譯出並保留其顯著性。
- 若原文包含表格：保留欄位意義與對照關係；必要時以相同欄位順序重排為中文可讀格式。
- 若原文包含圖示說明或按鈕標籤：在不破壞可讀性的前提下保留英文原標示。

## 術語處理

- 建立並維持一致術語表。
- 同一術語在全文保持同一譯法。
- 首次出現格式建議為：中文譯名（English term）
- 若某專有名詞已廣泛以英文流通，且直接翻譯會降低辨識度，可在首次出現時以英文為主，搭配中文說明，但仍需保持整體繁體中文可讀性。

## 品質檢查

完成翻譯後，檢查以下項目：

- 是否全篇為繁體中文。
- 是否涵蓋整份手冊，沒有明顯段落遺漏。
- 是否在專有名詞第一次出現時附上原文。
- 是否保留標題、條列、步驟、警語與圖表的對應結構。
- 是否避免添加原文未提供的重要資訊。
- 是否維持一致術語與語氣。

## 輸出要求

- 直接輸出翻譯後的手冊內容。
- 若需要註記不確定處，將註記保持簡短，且不要擴寫成新資訊。
- 不要省略原文中的重大段落、警告或操作步驟。

## 適用時機

- 使用者提供英文使用手冊、產品說明書、操作指南或技術手冊，要求轉為繁體中文。
- 需要保留原本結構與術語對照，方便後續查核原文時使用。
