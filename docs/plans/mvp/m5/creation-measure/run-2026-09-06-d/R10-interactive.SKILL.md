# Slack 未回覆問題每週清單

## 目的
每週從 3 個指定的 Slack 頻道中找出尚未被回覆的問題訊息，並輸出一份附有訊息連結的清單。

## 何時使用
當使用者提供 3 個 Slack 頻道名稱或連結，並要求你整理這些頻道中「尚未被回覆的問題」時使用。

## 工作流程

1. 讀取使用者提供的 3 個 Slack 頻道名稱或連結。
2. 僅檢查這 3 個頻道，不要擴大到其他頻道。
3. 找出看起來是問題的訊息，例如包含問號、詢問句、求助語氣，或明確要求協助的貼文。
4. 判定是否「未回覆」：
   - 若訊息下方沒有回應串、沒有直接答覆、或沒有可視為解決的回覆，視為未回覆。
   - 若同一則問題已被明確回答，排除。
   - 若狀態不明，優先保守處理，不要把已回覆的訊息列入未回覆清單。
5. 對每則符合條件的訊息，輸出：
   - 頻道名稱
   - 訊息摘要
   - Slack 訊息連結
6. 若沒有符合項目，輸出明確的空結果說明。

## 輸出要求

- 只輸出這 3 個頻道中的未回覆問題。
- 每筆結果都必須包含可點擊的 Slack 訊息連結。
- 不要包含已回覆的問題。
- 結果格式要一致，適合每週重複執行。

## 輸出格式

使用 Markdown 清單：

- **#1 頻道名稱** — 問題摘要
  - 連結：`<Slack 訊息連結>`
- **#2 頻道名稱** — 問題摘要
  - 連結：`<Slack 訊息連結>`

若無符合項目，輸出：

- 無未回覆問題。

## 注意事項

- 只處理使用者指定的 3 個頻道。
- 不要自行加入其他來源或推測不存在的訊息。
- 不要把含有問題符號的已回覆訊息誤列入。
- 如果連結或頻道資訊不足以判定，先保守排除，避免把已回覆內容列進來。
