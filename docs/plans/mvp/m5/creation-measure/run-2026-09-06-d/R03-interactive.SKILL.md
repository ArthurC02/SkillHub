# Daily News Summary Email

## 目的
每天早上從 3 個指定新聞網站擷取標題，整理成 5 條中文摘要，並寄送到收件人信箱。

## 使用時機
當你需要把多個新聞來源的最新標題彙整成簡短晨報，並自動寄出時使用。

## 輸入需求
在執行前，必須提供：
- 3 個新聞網站的網址或明確站名
- 收件人電子信箱
- 預計寄送時間（例如每天 08:00）
- 如有需要，可提供摘要語氣或重點偏好

## 工作流程
1. 檢查輸入是否齊全。
   - 若缺少任一網站網址或收件人信箱，先要求補齊，不要繼續。
2. 逐一擷取 3 個新聞網站的標題。
   - 只使用可直接取得的標題資訊。
   - 不要補寫、猜測或捏造新聞內容。
3. 從擷取到的標題中整理出 5 條中文摘要。
   - 以清楚、簡短、可讀性高的方式撰寫。
   - 若標題數不足，仍輸出可得內容，並說明不足之處。
4. 檢查每個來源是否成功存取。
   - 若某網站無法存取，清楚標註是哪個網站失敗。
   - 不要以其他來源內容冒充該網站內容。
5. 生成寄送信件內容並寄到指定信箱。
   - 內容應包含日期、來源網站、5 條摘要，以及必要的存取註記。

## 輸出格式
輸出信件內容應包含以下區塊：
- 主旨：每日新聞摘要
- 日期：執行日期
- 來源：3 個網站名稱或網址
- 摘要：5 條中文摘要
- 備註：若有任何來源存取失敗，逐一列出

## 限制
- 只根據新聞網站標題整理摘要。
- 不得捏造不存在的新聞內容。
- 若來源網站無法存取，必須明確標註。
- 若缺少網站或信箱資訊，必須停止並要求補齊。

## 實作注意事項
- 優先使用可穩定抓取標題的方式。
- 若網站有反爬或格式差異，需在結果中說明。
- 郵件寄送失敗時，需回報失敗原因，而不是假裝已寄出。
