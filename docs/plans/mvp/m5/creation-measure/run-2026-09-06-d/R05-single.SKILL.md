# 目的
將一週內的每日花費整理成清楚的表格，為每筆支出標示類別，並在週末計算各類別合計與總計。

# 適用情境
- 使用者提供一週的花費明細，要求整理成表格。
- 使用者要求每筆支出都要標類別。
- 使用者要求在週末做各類別合計或週總結。

# 工作流程

## 1. 先確認資料是否足夠
檢查使用者是否提供以下資訊：
- 日期或星期幾
- 每筆花費金額
- 每筆花費內容或用途
- 若有需要，幣別

如果缺少關鍵資訊，先用最少問題補齊：
- 缺日期：請對方提供每天的花費或至少星期幾。
- 缺金額：請對方補上每筆金額。
- 缺用途：請對方說明每筆花費內容，才能分類。
- 缺幣別：若未指定，沿用使用者原文中的幣別；若原文也沒有，預設為「元」並在輸出中保持一致。

## 2. 為每筆花費標示類別
根據花費內容，將每筆支出歸入一個明確類別。若使用者未指定分類規則，採用常見類別，例如：
- 餐飲
- 交通
- 住宿
- 購物
- 娛樂
- 醫療
- 教育
- 生活用品
- 通訊
- 其他

分類原則：
- 以用途最接近的類別為準。
- 若無法判斷，歸入「其他」。
- 同一筆支出只標一個主要類別，避免重複計算。

## 3. 建立每日明細表
將資料整理成表格，至少包含以下欄位：
- 日期 / 星期
- 項目
- 類別
- 金額
- 備註（可選）

表格中每一筆花費都要列出，不要只寫每日總額。

## 4. 計算每日小計
若同一天有多筆花費，為每一天加上小計。
- 小計 = 該日所有花費金額加總
- 若使用者只要明細不需要每日小計，也可保留但不要省略明細

## 5. 週末彙總各類別合計
在週末或週結尾新增一個彙總區塊，按類別統計整週合計：
- 每個類別的合計金額
- 週總支出
- 若需要，可再列出各類別占比，但不是必要項

計算規則：
- 同類別的所有金額相加
- 週總支出 = 全部花費金額總和
- 類別合計加總應等於週總支出；若不相等，檢查是否有漏算或重複分類

## 6. 輸出格式
優先使用 Markdown 表格，清楚分成兩段：

### A. 每日花費明細
| 日期 | 項目 | 類別 | 金額 | 備註 |
|---|---|---:|---:|---|
| ... | ... | ... | ... | ... |

### B. 週末類別合計
| 類別 | 合計金額 |
|---|---:|
| 餐飲 | ... |
| 交通 | ... |
| ... | ... |
| 總計 | ... |

## 7. 品質檢查
輸出前確認：
- 每筆花費都有類別
- 金額格式一致
- 每日小計與週總計正確
- 類別合計沒有漏項
- 若資料有歧義，已在備註中簡短標示或先向使用者確認

# 回應原則
- 保持簡潔、可直接複製使用。
- 若資料不足，先提問，不要自行編造花費。
- 若使用者提供的是零散文字，先整理成結構化表格再計算。
