# 目標
整理 Excel 客戶名單，完成兩件事：
1. 去除重複資料。
2. 標記缺少電話的列。

# 執行步驟
1. **先確認欄位結構**
   - 找出哪一欄是客戶識別欄位，通常可能是「姓名」、「公司」、「客戶名稱」、「Email」或其他可判斷重複的欄位。
   - 找出電話欄位，通常名稱可能是「電話」、「手機」、「聯絡電話」等。
   - 如果檔案中沒有明確的唯一識別欄位，優先使用使用者指定的欄位；若沒有指定，使用最能代表客戶唯一性的欄位組合來判斷重複。

2. **建立備份或保留原始資料**
   - 不要直接覆蓋原始內容。
   - 先複製工作表，或在新工作表中處理，保留原始資料以便回溯。

3. **去除重複資料**
   - 依照已確認的判斷欄位找出重複列。
   - 若重複列內容完全相同，保留第一筆，其餘刪除。
   - 若重複列部分欄位不同，保留資訊最完整的一筆；若無法判斷，保留最先出現的一筆，並在必要時註記有重複。
   - 去重後，確認總筆數是否合理，並檢查是否誤刪。

4. **標記缺少電話的列**
   - 在資料中新增一欄，例如「電話狀態」或「缺少電話」。
   - 對電話欄位為空白、只有空格、或缺少有效內容的列，標記為「缺少電話」。
   - 對有電話的列，標記為「有電話」或留白，依使用者需求一致處理。
   - 若電話欄位中只有格式不完整但仍可辨識為電話，依任務需求決定是否視為缺少；若不確定，保守地標記為待確認。

5. **檢查結果**
   - 確認去重後的筆數。
   - 確認所有缺少電話的列都已被標記。
   - 抽查幾筆重複資料與空電話資料，確保規則一致。

6. **輸出整理後的 Excel**
   - 將結果存成新檔或新工作表。
   - 保留欄位名稱清楚、排序一致。
   - 若有新增標記欄，放在資料表最後一欄，除非使用者要求其他位置。

# 注意事項
- 若「重複」的定義不明，先以最常見的唯一識別欄位判斷，並在結果中說明採用的規則。
- 若電話欄位名稱不一致，先統一辨識再標記。
- 若資料中有合併儲存格、篩選、公式或多個工作表，先確認實際要處理的範圍。
