## 目標
將一份英文使用手冊完整翻譯為繁體中文，並在專有名詞第一次出現時保留原文，以便讀者對照。

## 執行原則
1. **完整翻譯**：不要省略段落、步驟、警告、註解、表格內容、圖說、標題、頁首頁尾或附錄中的文字。
2. **保留結構**：維持原文件的章節層級、編號、項目符號、表格欄位順序與流程步驟。
3. **專有名詞首次附原文**：
   - 第一次出現的產品名、功能名、按鈕名、選單名、介面標籤、技術名詞、縮寫、錯誤碼、法規名稱等，採「繁中譯名（原文）」或「原文（繁中譯名）」其中一種一致格式。
   - 同一名詞後續出現時，使用已確定的繁中譯名即可，不必重複原文。
4. **術語一致**：同一英文術語在全文使用同一繁中譯法；若原文有明確定義，優先沿用原文定義。
5. **不擅自改寫**：不要加入說明、摘要、評論或額外註解；只翻譯原文內容。
6. **保留格式標記**：若原文含有粗體、斜體、程式碼、連結、警告框、表格或清單，翻譯時保留其格式與用途。

## 翻譯流程
1. 先通讀整份手冊，辨識：
   - 文件結構（章、節、小節）
   - 重複術語
   - 專有名詞與縮寫
   - 需要保留的數字、單位、型號、路徑、命令、按鍵名稱
2. 建立一致的術語對照：
   - 為每個關鍵術語選定唯一譯法
   - 若有縮寫，第一次出現時寫全名加縮寫，例如「隨機存取記憶體（RAM）」
3. 逐段翻譯：
   - 先翻標題，再翻內文，再翻表格與註記
   - 步驟型內容保持動作順序與條列格式
4. 檢查首次出現規則：
   - 確認每個專有名詞第一次出現時都有原文
   - 後續出現保持簡潔一致
5. 校對：
   - 檢查數字、單位、版本號、錯誤碼、按鍵名稱是否正確保留
   - 檢查是否有漏譯、重譯或術語前後不一致

## 翻譯格式建議
- 標題、段落、清單、表格盡量對應原文位置。
- 若原文是操作步驟，使用繁體中文動詞開頭，保持清楚可執行。
- 若原文包含警告、注意、提示，翻譯時保留其語氣標記，例如「警告」、「注意」、「提示」。

## 需要特別保留的內容
- 產品型號、版本號、錯誤代碼
- 按鈕、選單、欄位、介面文字
- 指令、程式碼、檔案路徑、URL
- 單位、數值、時間格式
- 法規、標準、協定名稱

## 若遇到不確定術語
- 先依上下文選擇最貼切且一致的譯法。
- 若該術語是品牌、功能名或介面名稱，保留原文並加上繁中說明。
- 不要因不確定而省略原文。
