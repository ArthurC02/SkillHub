# 目的
將會議逐字稿轉成結構化待辦清單，每一條都要包含：
- 待辦事項
- 負責人
- 期限

# 適用情境
在收到會議錄音逐字稿、會議紀錄或口語對話內容時，使用此技能把零散討論整理成可追蹤的行動項目。

# 處理步驟
1. **先通讀全文**
   - 找出所有明確的行動、承諾、決議、後續跟進事項。
   - 排除純背景說明、重複討論、寒暄與沒有後續動作的內容。

2. **辨識待辦項目**
   - 將每個獨立任務拆成一條待辦。
   - 若同一句話包含多個動作，拆成多條。
   - 若內容只是「再討論」「再確認」，只有在能明確轉成行動時才列入。

3. **找出負責人**
   - 優先使用逐字稿中明確提到的人名、職稱或角色。
   - 若只有團隊或部門，寫成該團隊/部門。
   - 若完全沒有指派對象，標示為「未指派」，不要自行猜測。

4. **找出期限**
   - 擷取明確日期、時間、週期或相對期限，例如「本週五前」「下次會議前」「兩天內」。
   - 若只有模糊時間，例如「盡快」「稍後」，保留原文並標示為模糊期限。
   - 若沒有期限，標示為「未提及」。

5. **整理成一致格式**
   - 每條待辦都要簡短、具體、可執行。
   - 保留原意，不要擴寫成未在逐字稿中出現的內容。
   - 若同一任務有多個負責人，列出所有相關負責人；若無法判定主責，標示「共同負責」或「未指派」。

6. **處理不完整資訊**
   - 如果任務有內容但缺少負責人或期限，仍然列出。
   - 不要補造資訊；只根據逐字稿可見內容填寫。
   - 若整份逐字稿幾乎沒有可轉成待辦的內容，回覆「未找到明確待辦事項」，並簡述原因。

# 輸出格式
使用下列格式輸出，保持簡潔一致：

- 待辦事項：...
  負責人：...
  期限：...

# 品質檢查
在輸出前確認：
- 每條待辦都有負責人欄位
- 每條待辦都有期限欄位
- 沒有把背景資訊誤寫成待辦
- 沒有自行推測未提及的人名或日期
