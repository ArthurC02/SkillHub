## 目的
將使用者提供的履歷內容重寫為「資料分析職缺導向」的一頁版履歷，保留真實經歷，強化與資料分析相關的技能、成果與關鍵字。

## 先確認的資訊
如果使用者沒有提供以下內容，先請對方補充，再開始改寫：
- 原始履歷全文
- 目標職缺名稱或職缺描述（若有）
- 主要工具與技能（例如 Excel、SQL、Python、Tableau、Power BI）
- 代表性專案或工作成果
- 希望使用的語言版本（中文、英文，或雙語）

## 改寫原則
1. 內容必須真實，不新增未提供的學歷、工作經歷、證照或技能。
2. 以資料分析職缺常見需求為主軸重寫：資料整理、分析、報表、自動化、視覺化、商業洞察、跨部門溝通。
3. 優先保留可量化成果，例如提升效率、降低錯誤率、縮短報表時間、增加轉換率、改善決策品質。
4. 刪除與目標職缺關聯低、過度冗長或重複的內容。
5. 用動詞開頭描述經歷，句子簡潔，避免空泛形容詞。
6. 控制在一頁以內：通常約 300–600 字中文，或 400–700 字英文，視版面而定。
7. 若原始內容不足以支撐資料分析定位，保留原意並明確弱化，不要硬湊。

## 建議結構
依下列順序重寫：
1. **標題區**：姓名、聯絡方式、地點、LinkedIn/GitHub（若有）
2. **職涯摘要**：2–4 句，直接說明資料分析相關背景、工具、強項與目標
3. **核心技能**：列出與資料分析相關的技能群組
   - 資料處理：Excel、SQL、Python、R、ETL
   - 視覺化與報表：Tableau、Power BI、Looker Studio
   - 分析能力：統計分析、A/B test、指標設計、商業分析
   - 協作能力：需求訪談、跨部門溝通、簡報
4. **工作經歷**：每段 2–4 個條列，強調分析、報表、流程改善、洞察與成果
5. **專案經歷**：若有，補強資料分析作品集或專題
6. **學歷與證照**：保留與職缺相關者

## 改寫步驟
1. 先讀取原始履歷，找出所有與資料分析相關的內容。
2. 將每段經歷改寫成「動作 + 方法/工具 + 成果」格式。
3. 把一般職務描述轉成分析導向語言，例如：
   - 「整理資料」→「清理並整合多來源資料，建立可重複使用的分析流程」
   - 「製作報表」→「設計週/月報表，追蹤核心 KPI 並支援決策」
   - 「協助主管」→「提供數據洞察，協助主管制定營運策略」
4. 若有數字，優先保留並前置；若沒有數字，保留可驗證的具體內容。
5. 將不相關內容壓縮到最短，必要時合併或刪除。
6. 最後檢查整體是否仍然像一份履歷，而不是自傳或求職信。

## 輸出要求
- 直接輸出改寫後的履歷內容。
- 不要加上解釋、改寫說明或評語。
- 不要超過一頁的資訊量。
- 若資訊不足以完成一頁版，輸出最精簡且可用的版本，並在最少文字下保留真實性。
