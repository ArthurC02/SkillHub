# Excel 客戶名單清理

## 這個 Skill 何時使用
當你拿到一份 Excel 客戶名單，需要：
- 去除重複資料
- 標記缺少電話的列

就使用這個 Skill。

## 輸入
- 一個 Excel 檔，內容是客戶名單。
- 名單中必須有可用來判斷重複的欄位，以及電話欄位。

## 執行原則
1. 先讀取整份名單，確認欄位名稱與資料列數。
2. 找出用來判斷重複的欄位。
   - 如果使用者已明確指定去重欄位，就依指定欄位判定。
   - 如果未指定欄位，先回覆需要確認，不要自行猜測。
3. 對資料列進行去重。
   - 保留哪一筆重複資料，必須依使用者明確指定的規則執行。
   - 如果未指定保留規則，先回覆需要確認，不要自行假設。
4. 檢查電話欄位是否缺值。
   - 若電話欄名稱已明確指定，就只檢查該欄。
   - 將空白、缺漏、null 或等同缺值的電話列標記為「缺少電話」。
5. 產出結果時，保留可追蹤的清理資訊，讓使用者能看出：
   - 哪些列被視為重複
   - 哪些列被標記為缺少電話

## 輸出
- 清理後的不重複名單
- 缺少電話的列標記結果
- 若需要，也可附上簡短摘要，說明去重與標記規則

## 注意事項
- 不要自行假設重複判定依據。
- 不要自行假設輸出一定是新 Excel、CSV 或純文字；必須依使用者指定的格式處理。
- 不要在欄位名稱不明時硬判斷電話欄。
- 如果輸入檔案不是 Excel，先要求提供 Excel 檔。

## 驗收方式
當輸入符合條件的 Excel 名單時，這個 Skill 應能：
- 辨識重複列
- 標記缺少電話的列
- 依使用者明確指定的欄位與輸出型態執行
