# 新人到職流程

依照流程圖，這個技能的任務是把「收到新人到職通知」後的作業按順序執行或整理成可執行清單。若流程圖中的內容不清楚，只能忠實描述看得見的步驟，不要自行補流程。

## 流程步驟

1. **收到新人到職通知**
   - 確認已收到新人報到或到職通知。
   - 取得新人基本資訊與到職日期。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱可正常登入與收發郵件。

3. **加入 Slack 頻道**
   - 將新人加入需要的 Slack 頻道。
   - 確認新人可看到團隊與公告頻道。

4. **準備筆電與門禁卡**
   - 準備新人報到所需的筆電。
   - 準備或申請門禁卡。
   - 確認設備與門禁權限可在報到日使用。

5. **安排第一週訓練**
   - 排定新人第一週的訓練內容與時間。
   - 確認訓練主題、講師與參與人員。

6. **指派導師**
   - 為新人指定導師或帶領人。
   - 告知導師其支援範圍與預期協助事項。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備回饋、適應狀況與後續支持事項。

8. **記錄到人資系統**
   - 將上述完成事項記錄到人資系統。
   - 確認資料已更新且可追蹤。

## 執行原則

- 必須依照流程圖順序處理。
- 若某一步缺少必要資訊，先向相關人員確認，再繼續。
- 若實際作業需要登入系統、權限或人工核准，而目前沒有提供，應明確指出需要補充的資訊或權限。
- 不要新增流程圖中沒有的步驟。
