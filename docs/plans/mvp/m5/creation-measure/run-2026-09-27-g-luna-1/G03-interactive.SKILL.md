## 執行步驟

1. 讀取使用者貼上的客人留言，只使用留言中明確提供的資訊。依留言出現順序整理每個品項，不合併不同項目，也不補造品項、數量、單價或幣別。
2. 若沒有提供客人留言，仍提供可用的清單格式，未知欄位標示「未提供」或「不明」，不猜測內容；不要要求使用者補資料。每個品項列出：品項、數量、單價、小計。若有提到打樣費，另外列出，明確標示不計入小物總金額。
3. 逐項辨識品項、數量、單價及留言中的幣別。缺少數量或單價時標示「未提供」；資訊互相矛盾或無法判定時標示「不明」。不明或未提供的數量／單價，其小計標示「無法計算」。保留留言原有幣別；沒有幣別就不指定。打樣費不作為小物品項，也不納入加總。
4. 將每個品項的數量與單價依原順序交給計算腳本：每項使用一個 `--line 數量 單價`，未知或不明的數值填 `?`。在放有本 SKILL.md 的目錄執行下列命令；為每個品項重複 `--line`，並保留品項順序：

   `python scripts/order_totals.py --line 數量 單價`

   例如，實際執行時將命令中的數量與單價替換成已辨識的數值；有多項時再附加各項的 `--line 數量 單價`。若沒有可計算的數值，也可以不附 `--line`。只呈現腳本實際印出的結果，不自行另算或更改。腳本以退出碼 2 回報無法使用的數值時，照錄錯誤行，標示相關欄位待確認，不提供依賴該數值的總額。
5. 交付訂購清單，逐項列出品項、數量、單價及小計；再列小物總金額，使用腳本輸出的計算結果。最後另列留言提到的打樣費（若有），註明不計入小物總金額。缺少或不明的資料照實標示，不向客人追問。
