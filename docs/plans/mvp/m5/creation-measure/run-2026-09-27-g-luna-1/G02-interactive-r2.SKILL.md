## 使用方式

1. 從使用者提供的資料逐筆擷取識別碼、購買至今天數及外觀痕跡。天數依已確認的預設假設使用非負整數，不從日期推算。痕跡只接受明確的「有」或「沒有」泡水／摔損資訊；任一種痕跡明確為有，即適用不保固分類。
2. 將每筆資料整理成 `識別碼|購買至今天數|外觀痕跡`。外觀痕跡欄請照輸入保留清楚的描述；識別碼缺漏時留空，但不要因此略過可計算的分類。若必要欄位缺漏或痕跡無法判讀，照原樣交給腳本，勿自行補值或猜測。
3. 在放有此 `SKILL.md` 的目錄執行以下命令；每筆資料重複一次 `--record`，並以引號括住每筆內容：

   `python scripts/classify_repairs.py --record '識別碼|天數|外觀痕跡' --record '識別碼|天數|外觀痕跡'`

   將命令中的範例欄位換成使用者實際提供的資料，不要新增輸入不依賴的參數。腳本會依規則分類並列印逐筆結果。呈現腳本輸出的分類；若有無法使用的值，照腳本訊息逐一指出並請對方確認，該筆不分類，也不提供依賴該值的結果。缺漏值須標示為「未提供」，不得補猜。
4. 回覆逐筆保留識別碼，並只使用「不保固維修」、「保固內免費維修」或「付費維修」作為已分類資料的分類。若識別碼未提供，明確標示未提供；不要把無效或不完整資料當成已分類結果。
