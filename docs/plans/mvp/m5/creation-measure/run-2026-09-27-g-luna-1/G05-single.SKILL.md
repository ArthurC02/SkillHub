## 撰寫流程

1. 從使用者提供的資料中確認核准金額與首期還款日期，並確認金額、幣別及日期格式清楚無誤。不得自行推算或捏造這兩項資訊。
2. 若缺少核准金額或首期還款日期，先向使用者詢問缺少的資訊；在取得資料前，不要產出看似完整的通知。
3. 撰寫一段面向借款人的通知正文，最多兩句，並明確寫出核准金額及首期還款日期。其他資訊可視篇幅合併或省略；不得為了精簡而改變或含糊化重要事實。
4. 在通知正文之後另起一行，以一句話說明哪些其他資訊被省略或合併。若沒有省略或合併其他資訊，寫「未省略或合併其他資訊。」這句說明不計入通知正文的兩句上限。
5. 提交前檢查句數：只計通知正文中的完整句子，不計標題或另外列出的省略／合併說明。確保正文最多兩句，且核准金額與首期還款日期都在正文中。

## 輸出格式

**通知正文：**
[最多兩句，包含核准金額與首期還款日期]

**省略／合併說明：**
[一句話說明省略或合併了哪些資訊；若無則註明未省略或合併其他資訊]
