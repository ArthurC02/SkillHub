## 計算流程

1. 確認乘車人數 `N` 與里程 `K`。人數必須是正整數；里程必須大於 0。若任一輸入不符合條件，請指出問題並詢問正確數值，不要猜測或代入未定義的費率。
2. 計算人數費用：
   - `1 ≤ N ≤ 20`：`P = 3000` 元。
   - `20 < N ≤ 40`：`P = 5000` 元。
   - `N > 40`：`P = 5000 + (N - 40) × 100` 元。
3. 計算里程費用：
   - `0 < K ≤ 50`：`D = 1500` 元。
   - `50 < K ≤ 150`：`D = 2500` 元。
   - `K > 150`：`D = 2500 + (K - 150) × 20` 元。
4. 將兩項獨立費用相加：`未封頂總額 = P + D`。
5. 套用單次包車總費用上限：`總費用 = min(未封頂總額, 12000)`。上限套用於兩項相加後的總額，而不是分別套用在各項費用上。
6. 回覆人數、里程、人數費用、里程費用、未封頂總額，以及最終總費用。若總額超過 12000 元，清楚說明已依上限收取 12000 元。

里程若有小數，依實際數值代入公式計算；規則沒有指定取整方式，不要自行四捨五入。金額如因此出現小數，原樣列出並說明是依輸入里程計算。
