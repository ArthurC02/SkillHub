# 花店進貨驗收清單

依使用者提供的文字或表格整理進貨資料，逐筆列出日期、花材品項、數量、單價及金額，並計算總金額。不合併不同筆資料，不加入稅金、運費或其他費用，不做幣別換算。

1. 從輸入中逐筆擷取日期、品項、數量及單價；每一筆原始紀錄各自保留。不要補造資料。日期或品項缺漏時標示「未提供」；數量或單價缺漏時保留空欄，並標記「未提供」。
2. 若沒有進貨資料，直接提供可填寫的格式：`日期｜花材品項｜數量｜單價`，各欄以「（請填寫）」標示；不編造紀錄或金額。
3. 檢查每筆日期是否存在、數量與單價是否可用且非負，並留意輸入中同一欄位互相矛盾的值。若有無法使用或矛盾的值，逐一列出原值並請使用者確認；不要給出依賴這些值的金額或總額。日期、品項缺漏本身不妨礙數量與單價的計算。
4. 從含有此 `SKILL.md` 的目錄執行計算腳本；每筆資料以 `日期|品項|數量|單價` 傳入 `--row`，缺漏欄位留空。日期使用 `YYYY/MM/DD` 或 `YYYY-MM-DD`；數量與單價傳入數值。若輸入有共同幣別，將標籤傳給 `--currency`；未提供時省略，腳本會標示幣別未提供。範例命令形狀：

   ```sh
   python scripts/calculate_receiving.py --currency 'NT$' --row '2026/09/25|玫瑰|20|12' --row '2026/09/25|桔梗|8|35'
   ```

   只傳入使用者資料中的紀錄，不要照抄範例資料。若腳本以錯誤碼 2 結束，依錯誤訊息列出每個無法使用的值並請使用者確認；不提供依賴該值的金額或總額。
5. 將腳本輸出作為驗收清單呈現。若有數量或單價缺漏，保留可計算的逐筆結果，並照腳本標示總金額無法計算；不把部分小計說成總金額。未提供幣別時沿用腳本標示，不推測幣別。
