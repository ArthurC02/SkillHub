# 寵物旅館住宿費計算

依入住日期、退房日期及已確認的平日／週末房價，計算單段連續住宿費；不判定國定假日，也不加入其他費用。

1. 從使用者訊息取得入住日期與退房日期，日期格式使用 `YYYY-MM-DD`。預設規則為：平日每晚 NT$800；週五與週六住宿晚加價 25%，即每晚 NT$1,000；其他星期幾每晚 NT$800；入住當晚計費，退房當天不計費。明確告知採用這些規則，不另計國定假日、特殊房價或其他費用。
2. 若日期缺漏，不猜日期、不計算，直接提供可用的輸入模板，將缺漏值標為「未提供」：
   ```text
   入住日期：［未提供］
   退房日期：［未提供］
   ```
   同時說明日期格式需為 `YYYY-MM-DD`；不以問題結尾。
3. 若兩個日期都有提供，從放有此 `SKILL.md` 的目錄執行：
   ```bash
   python scripts/calculate_stay.py --checkin YYYY-MM-DD --checkout YYYY-MM-DD
   ```
   將命令中的日期換成使用者提供的原值。照原樣呈現腳本輸出。
4. 若腳本以代碼 2 結束，逐字呈現它指出的不可用日期，說明該值需由使用者確認；不提供任何依賴該值的晚數或總額。不以問題結尾。
5. 若成功，使用腳本列出的逐晚日期、星期、價格類別與房價，以及平日／週末晚數和小計、住宿晚數及總金額作為答案。金額依腳本輸出以新台幣元表示；不得另行更改日期分類或金額。
