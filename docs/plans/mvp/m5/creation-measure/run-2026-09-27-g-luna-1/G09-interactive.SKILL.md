# 大學畢業二十週年同學會邀請文

使用者需要大學畢業二十週年同學會邀請文時，依下列步驟一次完成。預設使用繁體中文，並採用適合 LINE／社群發布的短文語氣；如使用者明確指定其他發布管道，依指定調整篇幅與格式。

1. 從使用者提供的內容擷取同學會名稱、活動日期、集合時間與集合地點。將每項資料視為必須保留的原文，不改字、不改格式、不推算或查證。辨認並列出彼此衝突、格式無法判讀或明顯不可能的值；不可用這些值計算或撰寫成確定資訊。
2. 以溫馨、懷舊的語氣寫一則可直接發布的邀請文，邀請同學重逢或回憶往日情誼。只加入不含新活動事實的情感性文字；不補造流程、費用、報名期限、聯絡方式或其他細節。
3. 缺少任何指定資料時，仍寫出可用的邀請文模板，將該欄明確標為「未提供」，不猜測，也不以問題結尾。對無法判定或衝突的值，指出該值及需要確認之處，且不寫出依賴該值的確定資訊。即使名稱或其他標籤缺漏，也照常處理其餘已知資料。
4. 將完成的邀請文存為 `invitation.txt`。在檢查命令中，對每項已提供且可用的資料各加一個 `--require "原文"`；每項缺漏資料則加 `--require "欄位標籤：未提供"`。若輸入含有無法使用或互相衝突的值，不把它當成確定事實；在邀請文中標示需確認，並以 `--require` 檢查該標示。從放有本 SKILL.md 的目錄執行：

   ```sh
   python scripts/check_output.py --require "同學會名稱：原文或未提供" --require "活動日期：原文或未提供" --require "集合時間：原文或未提供" --require "集合地點：原文或未提供" invitation.txt
   ```

   將命令中的四個引數分別替換為邀請文必須逐字包含的完整資料或缺漏標示，並依實際情況為無法使用或衝突值加上檢查項。若未印出 `OK`，修正 `invitation.txt` 後重跑，直到印出 `OK`。
5. 回覆 `invitation.txt` 的內容，且只回覆該檔案內容。若有需確認的輸入值，將它的確認標示保留在檔案中；不要以問題結尾。
