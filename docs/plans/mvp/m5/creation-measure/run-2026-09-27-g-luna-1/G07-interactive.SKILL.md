# 管理費逾期催繳通知

依住戶資料判斷管理費是否逾期未繳滿 60 個日曆日。只為符合門檻的住戶產生催繳通知、簡訊文案與人工操作指引；不登入系統、不標記住戶，也不發送簡訊。

## 步驟

1. 從使用者提供的資料找出查核日，以及每筆住戶的戶別、姓名、管理費金額、到期日、繳費狀態與電話。不要從外部尋找或推測資料。缺少的欄位保留空白並視為「未提供」；沒有住戶資料時，建立一筆欄位留白的範本記錄。
2. 在包含本 `SKILL.md` 的目錄開啟 shell。每筆住戶使用一個 `--resident` 參數，欄位依序為「戶別|姓名|金額|到期日|狀態|電話」；缺少欄位就留空。金額去掉幣別符號及千分位逗號，日期使用 `YYYY-MM-DD`。狀態使用「未繳」或「已繳」。將使用者提供的資料代入並執行：

   ```sh
   python scripts/evaluate_overdue.py --check-date '查核日' --resident '戶別|姓名|金額|到期日|狀態|電話'
   ```

   多筆住戶時重複加入 `--resident '…'`。若未提供查核日，省略 `--check-date`；若沒有住戶資料，省略 `--resident`。不要把上方示意文字當成實際資料。
3. 逐字呈現腳本輸出，不自行改動門檻、天數或文案。腳本如以代碼 2 結束，將錯誤訊息原樣呈現，請使用者確認訊息點名的值；不要提供受該值影響的判定或通知。缺少的資料依腳本結果標示為「未提供」，不補造事實。
4. 對每一位已判定符合門檻的住戶，提供一般人工操作指引：由負責人依社區既有流程登入社區管理系統、找到該戶並標記為「欠繳戶」，再以簡訊文案通知住戶。系統畫面及操作路徑未提供，不臆造按鈕名稱或步驟。未達門檻或無法判定者，不提供催繳通知、簡訊文案或欠繳戶處理指引。
5. 答案結尾逐行列出無法代為完成的外部操作及負責人：
   - 無法從這裡登入或標記社區管理系統；由社區管理負責人依既有流程操作。
   - 無法從這裡發送簡訊；由社區管理負責人使用核准的管道發送。

只使用輸入資料；不添加輸入未提供的法律後果、費用或期限。
