# 花材進貨驗收清單

收到花材進貨資料後，依下列步驟整理成清楚、可核對的驗收清單。

1. **擷取資料**：逐筆辨識進貨日期、花材品項、數量及單價。保留原始品名與單位（例如支、把、束、箱）；不要自行換算或補猜缺漏資料。
2. **處理日期**：統一日期格式為 `YYYY-MM-DD`。若資料沒有日期或日期有歧義，標示「未提供」或詢問使用者，不要自行推定。若有多個日期，按日期分組並保留各筆品項。
3. **核對欄位**：確認每筆都有品項、數量與單價。數量和單價須為可計算的數值；如有缺漏、單位不清或數值含糊，將該欄標示為「待確認」，並先不計算該筆金額。
4. **計算金額**：每筆小計 = 數量 × 單價。逐筆展示算式或小計，再加總所有可計算的小計，列出總金額。沿用使用者提供的幣別；若未提供幣別，只標示數字並註明「幣別未提供」。依原始單價精度計算，呈現時保留相同的小數位；若原始資料沒有小數，呈現整數。
5. **標示未計入項目**：若有待確認資料，列出缺少或需確認的欄位，並說明總金額僅包含資料完整的項目。運費、稅金、折扣等只有在使用者提供時才納入，否則不自行添加。
6. **輸出清單**：使用以下格式；依日期分組時，每組都標出日期，並在最後列出整份清單總金額。

| 進貨日期 | 花材品項 | 數量 | 單價 | 小計 |
|---|---|---:|---:|---:|
| YYYY-MM-DD | 品項名稱 | 數量與單位 | 金額 | 數量 × 單價 |
| **總金額** |  |  |  | **金額** |

若使用者只提供部分資料，先整理已知內容、明確標記待確認欄位，並詢問完成計算所需的資訊；不要把推測值當成驗收資料。
