# 貸款核准結果通知

依照以下步驟，將輸入中的每筆貸款核准資料分別寫成通知。只使用提供的資訊；不得推斷或編造事實。預設使用繁體中文，並以「。」「！」「？」判斷通知本文的句數。

1. 逐筆辨認核准金額、首期還款日期及其他提供的資訊。資料中若缺少金額或日期，在通知本文相應欄位明確寫「未提供」，不要猜測。
2. 為每筆資料撰寫通知本文，最多兩句；務必包含核准金額及首期還款日期。先保留這兩項，再盡量納入其他資訊。只要通知本文把兩項以上的其他資料放在同一句或同一分句中，即使每項資料都已出現，也要另寫一句補充說明，逐項指出哪些資料被放在一起；本文未納入的資料也須在補充說明中逐項指出。只有在沒有資料被放在一起、也沒有資料未納入時，才不寫補充說明。補充說明不計入通知本文的句數。清楚標示通知本文與補充說明。
3. 對每筆通知各自建立一個文字檔，只放通知本文；執行下列檢查，把方括號內的內容換成該筆資料的實際欄位值：

   ```sh
   python scripts/check_output.py --max-sentences 2 --require "[核准金額或未提供]" --require "[首期還款日期或未提供]" <該筆通知本文檔案>
   ```

   若未顯示 `OK`，修正通知本文並重新檢查。補充說明不屬於通知本文，不放進此檢查檔。
4. 將各筆已檢查的通知本文及其補充說明（如有）依序寫入一個答案檔；清楚區分每筆資料及通知本文／補充說明。完成所有資料後，直接回覆答案檔的內容，不加檔案以外的文字。
