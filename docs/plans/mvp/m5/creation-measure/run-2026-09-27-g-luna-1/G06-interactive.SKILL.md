## 使用時機
收到汽車保養預約日期、時間與預估費用，要撰寫確認簡訊時使用。

## 步驟
1. 從輸入擷取日期、時間及預估費用。日期、時間照原文呈現；費用完整保留原有幣別與格式。不得推測或改寫資料。若有欄位未提供，將該欄位標為「未提供」，並在簡訊中明確呈現。
2. 用精簡文字組成一則簡訊，清楚表達預約確認，並納入日期、時間及預估費用。只寫簡訊本文，不加前言、說明或字數統計。若提供的內容長到無法同時滿足 32 字上限及必要資訊，保留 32 字硬限制，盡量保留必要資料，並在簡訊本文內用一行說明省略了什麼；不得另外附說明。
3. 將簡訊本文寫入目前目錄的 `sms.txt`，只寫本文，不加引號或額外換行。用單引號 heredoc 寫檔；選一個不會與本文任何一行相同的結尾標記，例如：
   ```sh
   cat > sms.txt <<'SMS_END'
   （在此寫入已完成的簡訊本文）
   SMS_END
   ```
   若本文含有此標記的整行，改用另一個不會出現在本文中的標記。
4. 從含有 `SKILL.md` 的目錄執行檢查器，要求本文不超過 32 字，並包含輸入中的日期、時間及預估費用；缺少的欄位則要求包含「未提供」。每個必要文字各用一個 `--require`，用引號保留原文：
   ```sh
   python scripts/check_output.py --max-chars 32 --require '日期文字' --require '時間文字' --require '費用文字' sms.txt
   ```
   將示例文字換成擷取出的原文；若欄位未提供，該欄改用 `--require '未提供'`。若未印出 `OK`，依檢查結果精簡或修正本文、重寫 `sms.txt`，再執行同一檢查，直到印出 `OK`。遇到必要資訊無法同時符合限制時，仍遵守 32 字上限，並依步驟 2 在簡訊本文內交代省略項目。
5. 最終回答只貼上 `sms.txt` 的內容，不附任何其他文字。
