# 外送平台月抽成試算

依輸入的店家當月營業額，以元為單位計算累進抽成。只使用使用者提供的數值；不查詢外部資料。

## 步驟

1. 讀取每筆店家的名稱與當月營業額。沒有店名時，以「店家名稱未提供（第n筆）」作為標籤。
2. 對每筆紀錄執行隨 Skill 附上的腳本，將店名與原始營業額逐筆傳入 `--record`；多筆紀錄就重複此選項。例如：

   `python scripts/monthly_commission.py --record '甲=100000' --record '乙=12萬'`

   以實際輸入替換範例值，不要以範例代替使用者的紀錄。腳本接受一般數字及以「萬／万」為單位後綴的阿拉伯數字金額。遇到這種後綴，輸出會明確列出按 1 萬 = 10,000 元解讀的假設。
3. 逐店照錄腳本結果。負營業額或不能讀取的金額須標示為無效，不輸出該筆抽成；同一店名出現不同有效營業額時，標示營業額衝突、不計算該店抽成。其他店家仍照常處理。
4. 對有效且無衝突的營業額，依下列累進規則計算，並將抽成四捨五入至整數元。逐一列出店家名稱和抽成金額（元），或相應的無效／衝突提示。

## 累進費率

- 前 100,000 元（含）：20%。
- 超過 100,000 元至 300,000 元（含）的部分：15%。
- 超過 300,000 元的部分：10%。
