# 外送延誤道歉訊息

依以下步驟逐筆處理使用者提供的訂單，並以繁體中文回答。

1. 讀取每筆訂單的編號、延誤分鐘數及補償金額。先執行平台提供的輸入檢查：`python scripts/check_input.py`。使用檢查後的值，不另行解析或驗證。若檢查指出某筆延誤分鐘數無效，指出該筆的訂單編號與無效值，請使用者更正；不要為該筆生成道歉訊息，也不要使用其補償金額。繼續處理其他已檢查的訂單。
2. 對每筆有效訂單執行 `python scripts/delay_apology.py --record 訂單編號 延誤分鐘數 補償金額顯示文字`。每筆重複一次 `--record`；分鐘數使用檢查後的正整數，補償金額顯示文字保留使用者提供的寫法。若金額未寫單位，依本 Skill 的輸入單位「元」顯示，並在回答中說明此單位是假設、可由使用者更改。呈現腳本產生的道歉訊息，不自行改寫其中的資料。
3. 延誤分鐘數至少 10 分鐘時，道歉訊息須包含訂單編號、分鐘數和補償金額；未滿 10 分鐘時只道歉，不提補償金額。若檢查將中文數字讀為數值，保留原輸入，並在回答中簡短說明採用的讀法。訊息最多兩句；使用「。」、「？」或「！」結尾各算一句。若使用者要求更多句，仍遵守兩句上限，並用一句簡短說明指出未採用較多句的要求。
4. 將每筆道歉訊息分別寫入檔案，執行 `python scripts/check_output.py --max-sentences 2 --require 訂單編號 --require 延誤分鐘數`；延誤至少 10 分鐘時，再加入 `--require 補償金額`。修正訊息並重跑，直到檢查輸出 `OK`。最後將所有訂單的訊息、無效值更正提示及必要的假設說明寫入回答檔案，確保每筆訊息只含該筆訂單的內容，並以檔案內容作答。

若本次請求提到任何需要登入、傳送、發布、排程、連網或變更外部系統的動作，準備好可供使用的內容，但不要聲稱已執行該動作；在回答最後逐項用一行說明該動作無法由本 Skill 執行，並指出應由提出請求的人或請求中指定負責的人執行。
