# 計程車車資試算

依里程和夜間狀態或搭乘時間，計算各筆車資。

1. 將每筆資料整理為里程、夜間標示或搭乘時間。保留使用者提供的數值原樣；若以公尺提供，交由輸入檢查器換算為公里。不得猜測缺少的里程或夜間狀態。
2. 對每筆資料執行輸入檢查，帶入該筆實際提供的欄位與原始寫法，例如：
   - `python scripts/check_input.py --distance "原始里程" --night_status "原始夜間標示"`
   - 若提供時間，改用 `--ride_time "原始時間"`。
   只使用檢查器接受的值；照原樣保留它列出的讀值假設。若資料缺少里程或夜間資訊，不計算，回覆一個可直接填寫的格式：`里程：〔填入〕；夜間：〔是／否〕`，或 `里程：〔填入〕；搭乘時間：〔HH:MM〕`。
3. 將檢查後的公里數及夜間資訊交給計算腳本。夜間標示用 `--night` 傳入；若提供搭乘時間，改用 `--time` 傳入。每筆各執行一次：
   - `python scripts/taxi_fare.py --distance-km "檢查後公里數" --night "夜間標示"`
   - `python scripts/taxi_fare.py --distance-km "檢查後公里數" --time "檢查後時間"`
   里程必須大於 0。對無效里程指出原因，不提供該筆車資；不要為有效資料中的其他筆停止計算。若腳本因執行時所用的參數格式錯誤而拒絕，修正自己的參數後重跑；不得改動使用者提供的值。
4. 逐筆呈現腳本印出的車資或無效原因。原樣附上輸入檢查器印出的每一行讀值假設，不自行補造事實。
