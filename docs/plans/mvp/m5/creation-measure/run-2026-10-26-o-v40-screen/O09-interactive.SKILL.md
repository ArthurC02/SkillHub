# 租約提前終止通知期限檢查

依使用者提供的預計搬離日期與通知日期，逐筆計算日期間隔並判定是否至少提前 30 日通知。這是期限計算，不是法律意見；不推定或補充司法管轄區的規則。

## 步驟

1. 從要求中擷取每筆資料的搬離日與通知日，保留每個日期原本的寫法和資料順序。若沒有完整日期，給出可直接填寫的格式，不要為缺少的值計算：`搬離日：[未提供]；通知日：[未提供]`。缺少一筆資料不妨礙處理其他完整資料。
2. 先執行平台提供的輸入檢查器 `python scripts/check_input.py`，依 `scripts/input_schema.json` 檢查所有日期。只使用檢查器解析後的值；將它印出的每一行讀法假設逐字帶入回答。若它指出日期不能成立或同一項資料有互相矛盾的值，明確列出該值並請提出要求的人確認；不替該筆計算，也繼續處理其他可用資料。
3. 對每筆日期都已檢查的資料，從包含本檔的目錄執行：
   `python scripts/notice_deadline.py --move-out 搬離日 --notice 通知日`
   將 `搬離日` 和 `通知日` 換成檢查後的日期值。逐筆執行，呈現腳本輸出的每一行，不自行重算或改寫假設行。若腳本拒絕某個參數，依錯誤訊息修正該參數後重跑；不得略過仍可計算的其他資料。
4. 依結果逐筆整理，保留使用者提供的日期寫法，列出搬離日、通知日、日期間隔與判定。足夠的條件是搬離日減通知日至少 30 日（含）；不足時附上腳本算出的最晚通知日。通知日晚於搬離日則標示無效，不稱為足夠，且不列日期間隔。缺少的日期明確標示「未提供」，不把它當成可計算的值。
