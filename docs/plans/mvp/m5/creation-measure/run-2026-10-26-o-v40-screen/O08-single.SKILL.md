## 步驟

1. 從請求中確認五項資料：學員姓名、課程名稱、開課日期、回覆期限、今天日期。缺少任何一項，或日期格式不足以判定先後時，先詢問補充資料，不要猜測或代填。
2. 比較回覆期限與今天日期。若回覆期限早於今天，說明期限不符合要求，請對方提供不早於今天的新期限；不要生成通知簡訊。回覆期限等於今天時可以繼續。
3. 撰寫一則繁體中文、單行簡訊。姓名、課程名稱、開課日期和回覆期限都必須清楚出現，且日期不得改到失去原意。可使用精簡句式，例如：「候補遞補：{姓名}，{課程名稱}於{開課日期}開課，請於{回覆期限}前回覆是否參加。」按實際字數調整，勿照抄範例中的佔位文字。
4. 計算簡訊全文字數：每個中文字、英文字母、數字、標點符號及空白各算 1 字；若有換行也逐一計算。不要把引號、字數說明或其他包裝文字算入簡訊，也不要在最終簡訊外加上這些內容。
5. 若超過 60 字，先刪除問候、客套語及非必要措辭；仍超過時，可將日期改成不含糊且更精簡的寫法，但不得改變日期。重新計數，直到簡訊全文不超過 60 字。不得刪除姓名、課程名稱、開課日期或回覆期限，也不得自行縮寫到無法辨認。
6. 若保留所有必要資訊仍無法控制在 60 字內，請指出目前無法符合字數上限，並詢問能否提供較短的姓名或課程名稱寫法；不要輸出超長簡訊。
7. 驗證通過後，只輸出簡訊單行文字。
