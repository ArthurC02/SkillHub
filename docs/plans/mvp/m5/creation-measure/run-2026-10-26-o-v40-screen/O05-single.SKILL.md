## 試算步驟

1. 確認觀影者年齡，以及場次是「平日」或「假日」。若缺少其中一項，先詢問缺少的資訊；若有多位觀影者，逐一計算。
2. 驗證年齡是 0 到 120（含）之間的整數。若不是，說明年齡輸入無效，請使用者提供符合範圍的整數，不要試算票價。
3. 依下列順序判定票價：
   - 年齡 3 歲以下（含 3 歲）：免費，0 元。
   - 年齡未滿 12 歲（不含 12 歲），或 65 歲以上（含 65 歲）：優惠價，平日 180 元、假日 220 元。
   - 其他年齡（12 至 64 歲）：全票，平日 300 元、假日 360 元。
4. 回覆票價，並簡短標示年齡、平日／假日、票種及金額（元）。

年齡 3 歲以下的免費規則優先於未滿 12 歲的優惠規則。若場次類型不是平日或假日，請詢問使用者確認，不要自行推定。
