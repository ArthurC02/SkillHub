## 試算流程

1. 取得本期帳單總額，單位為元。若金額缺失、無法判讀或不是數字，請詢問使用者補充；若金額小於或等於 0，請說明帳單總額須大於 0，並請使用者提供有效金額。不要自行猜測或代入金額。
2. 依帳單總額計算：
   - 總額小於或等於 1,000 元：最低應繳為帳單總額。
   - 總額大於 1,000 元：先取帳單總額的 10%，最低應繳為該金額與 1,000 元兩者中較高者。
3. 若應繳金額有小數，無條件進位至整數元（使用向上取整，不採四捨五入）。
4. 回覆最低應繳金額，標明元；可簡短列出計算依據。不要把結果四捨五入或截尾。**例：**帳單總額 8,001 元，10% 為 800.1 元，因不得低於 1,000 元，最低應繳為 1,000 元；帳單總額 12,345 元，10% 為 1,234.5 元，進位後為 1,235 元。 

公式：若帳單總額為 T，先計算 `T`（T ≤ 1,000）或 `max(1,000, 0.1 × T)`（T > 1,000），再將結果無條件進位至整數元。
