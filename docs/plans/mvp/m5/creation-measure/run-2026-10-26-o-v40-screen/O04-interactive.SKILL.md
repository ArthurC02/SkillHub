# 家電保固期判定

依照使用者提供的購買日期與報修日期，逐筆判定一年保固狀態。只依日期和此處規則計算；不判斷購買證明、產品資格或其他保固條款。

## 步驟

1. 找出使用者提供的每組購買日期和報修日期。一次處理一組；多組時逐組處理。日期格式須為有效的公曆 `YYYY-MM-DD`。不需要產品名稱或其他未要求的資料；未提供日期時，以「未提供」標示，該筆判定列為「未提供」。
2. 對每一組日期執行輸入檢查：
   ```sh
   python scripts/check_input.py --purchase-date '<購買日期>' --repair-date '<報修日期>'
   ```
   只使用檢查通過後的日期。若檢查拒絕某個值，列出該值並請提出請求的人確認；不要替換或推測日期。繼續處理其他通過檢查的組別。若檢查輸出任何假設讀值的行，在最終答案中逐字照抄該行。
3. 將檢查通過的日期逐筆交給計算腳本；多組日期重複加入 `--record`：
   ```sh
   python scripts/warranty.py --record '<購買日期>' '<報修日期>'
   ```
   ```sh
   python scripts/warranty.py --record '<購買日期>' '<報修日期>' --record '<購買日期>' '<報修日期>'
   ```
4. 依輸出逐筆回覆，保留每筆結果、保固最後一天及適用的過保天數。若報修日期早於購買日期，照腳本指出日期錯誤，不列保固狀態或過保天數。不得增添日期以外的保固判斷。
