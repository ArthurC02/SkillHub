# 電影院票價試算

依輸入的觀影者年齡和場次類型計算票價。只採用本 Skill 列明的票價規則，不推斷其他折扣或票種。

## 步驟

1. 讀取一筆或多筆觀影資料；每筆包含年齡及場次類型，保留原順序。年齡或場次未提供時，提供可直接填寫的格式：`年齡【未提供】；場次【未提供】`，不要因此停止處理其他資料。
2. 執行 `python scripts/check_input.py`，依 `scripts/input_schema.json` 檢查每筆年齡。只將檢查通過的年齡交給後續步驟；若有值被拒絕，指出原值及問題，請提出請求的人確認或更正該值，不替該筆計價，並繼續處理其他可計價資料。
3. 對每筆檢查通過的資料，使用 `--record '年齡|場次'` 傳入計算腳本；每筆資料各加一個 `--record`。使用檢查器輸出的已檢查年齡，不自行解析或再驗證。場次用原文傳入。
4. 從保存 `SKILL.md` 的目錄執行 `python scripts/calculate_fare.py --record '年齡|場次'`，並對其餘資料重複加入 `--record`。呈現腳本輸出的票價，依輸入順序保留每筆一行；照原樣複製腳本輸出的假設行。明確的平日或假日照其類型計價；「週末」按假日理解，並說明此假設。其他未明確辨識的場次按一般情況平日計，並照抄腳本列出的假設及可更改該值的參數說明。
5. 若腳本拒絕參數，依錯誤訊息更正該參數後重跑；不得因自己提供了無效參數而留空結果。最後只交付各筆票價和必要的假設或更正說明，標明元。
