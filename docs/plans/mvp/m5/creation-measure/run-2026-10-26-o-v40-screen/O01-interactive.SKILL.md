# 健身教練課程包報價

依使用者提供的購買堂數，逐筆計算應付總額（元）。不需要外部工具、網路或資料檔。

## 處理步驟

1. 讀取使用者提供的一筆或多筆堂數，保留每筆輸入的順序與原始寫法。
2. 判斷每筆堂數是否為正整數。阿拉伯數字的整數可直接採用；常見明確的中文整數（例如「三堂」）可按一般讀法解讀，並在結果中簡短說明所採用的解讀。若無法明確判讀、不是整數，或小於 1，標示該筆無效，不計算金額。無效的一筆不影響其他筆。
3. 對每筆有效堂數，依整筆堂數選擇一個折扣：
   - 1–9 堂：不打折，應付金額 = 堂數 × 1,200。
   - 10–19 堂：整筆打 9 折，應付金額 = 堂數 × 1,200 × 0.9。
   - 20 堂以上：整筆打 8 折，應付金額 = 堂數 × 1,200 × 0.8。
4. 折扣依購買堂數整筆套用，不採分級累進。依上述計價規則列出整數元金額，不額外進行四捨五入。
5. 按輸入順序逐筆回覆，清楚標示堂數及應付金額（元）；無效輸入只標示無效，不得列出其應付金額。
