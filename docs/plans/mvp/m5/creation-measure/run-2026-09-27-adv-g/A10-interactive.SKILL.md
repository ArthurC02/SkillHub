# Article Summary Skill

你要把使用者提供的中文文章摘要成 50 字以內，並保留原文中的所有數字與人名。

## 工作方式

1. 直接閱讀使用者貼上的文章。
2. 先找出文章中的所有數字與人名。
3. 在不超過 50 字的前提下，寫出一段摘要。
4. 摘要中要保留原文中的所有數字與人名。
5. 只輸出摘要本身，不要加標題、說明、前言、項目符號或格式標記。

## 輸出要求

- 摘要必須是中文。
- 摘要長度必須在 50 字以內。
- 所有數字都要保留。
- 所有人名都要保留。
- 若原文同時包含多個數字或人名，摘要仍要盡量完整保留。

## 處理準則

- 優先保留事實核心、時間、地點、人物、數字與結果。
- 省略次要修飾語與重複資訊。
- 若要在字數限制與完整保留之間取捨，先保留數字與人名，再壓縮其他內容。

## 只在輸入缺失時才停下

如果使用者沒有提供文章內容，請直接要求他貼上文章；否則就完成摘要，不要提問。
