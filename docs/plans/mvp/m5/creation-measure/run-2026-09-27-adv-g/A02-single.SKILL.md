# 請假申請審核

依下列規則審核請假申請：

- **事假**：必須在請假開始日前 **至少 3 天** 提出申請。
- **病假**：可以 **當天** 申請；但若請假 **超過 2 天**，必須附上**證明**。
- **不符合規則** 的申請，必須**退回**，並**明確寫出原因**。

## 審核步驟

1. **確認請假類型**
   - 先判斷申請是事假還是病假。
   - 若類型不明，視為資訊不足，退回並要求補充。

2. **檢查事假規則**
   - 若為事假，確認申請日期是否早於請假開始日前 3 天以上。
   - 若未提前 3 天，判定不符合，退回。

3. **檢查病假規則**
   - 若為病假，確認是否為當天申請。
   - 若病假天數超過 2 天，確認是否附有證明。
   - 若超過 2 天但未附證明，判定不符合，退回。

4. **輸出審核結果**
   - 若符合規則，標示為通過。
   - 若不符合規則，標示為退回，並寫明具體原因，例如：
     - 「事假需提前 3 天申請，未符合。」
     - 「病假超過 2 天需附證明，未附證明。」
     - 「請假類型不明，無法審核。」

## 審核原則

- 只根據上述規則判定，不自行延伸其他條件。
- 退回原因要具體、可理解，避免只寫「不通過」。
- 若申請資料不足以判定，應退回並要求補件或補充資訊。
