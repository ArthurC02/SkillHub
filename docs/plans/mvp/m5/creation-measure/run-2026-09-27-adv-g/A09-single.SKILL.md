# 目的
根據「這個月的出勤紀錄」計算每個人的加班時數，並標示加班時數超過 46 小時的人。

# 適用情境
- 輸入是本月的出勤紀錄、打卡紀錄、工時表、班表或類似資料。
- 需要按人彙總加班時數。
- 需要找出超過 46 小時的員工並清楚標記。

# 作業步驟
1. **確認資料範圍**
   - 只使用「這個月」的紀錄。
   - 若資料跨月，先排除非本月資料，或請求可辨識月份的欄位。

2. **辨識每筆紀錄的欄位**
   - 找出至少以下資訊：
     - 人員姓名或識別碼
     - 日期
     - 加班時數，或可推算加班時數的欄位
   - 若加班時數未直接提供，依資料中的規則計算；若規則不明，先說明無法可靠計算，並請求補充計算方式。

3. **統一單位與格式**
   - 將所有加班時數統一成「小時」。
   - 若有分鐘，換算成小數或以分鐘累計後再換算，但最後輸出要一致。
   - 保留合理精度；若原始資料有到分鐘，建議至少保留到小數點後兩位或以分鐘顯示。

4. **按人彙總**
   - 將同一人的所有本月加班時數加總。
   - 若同一人有不同姓名寫法或代碼，先確認是否為同一人，再合併。

5. **檢查超標**
   - 以 46 小時為門檻。
   - 若某人加班時數 **大於 46 小時**，標記為「超過 46 小時」。
   - 若等於 46 小時，不算超過，但可視需要註記為「未超標」。

6. **輸出結果**
   - 以清楚表格列出每個人：
     - 姓名/識別碼
     - 本月加班總時數
     - 是否超過 46 小時
   - 對超標者加上明顯標記，例如：`⚠ 超過 46 小時`。

# 輸出格式建議
| 人員 | 本月加班總時數 | 狀態 |
|---|---:|---|
| 王小明 | 48.5 小時 | ⚠ 超過 46 小時 |
| 李小華 | 42.0 小時 | 未超標 |

# 注意事項
- 不要把正常工時誤算成加班時數。
- 若資料缺漏導致無法計算某人總時數，明確列出缺少哪些欄位。
- 若同一筆紀錄有重複，先確認是否為重複輸入，再決定是否去重。
- 若使用者提供的是圖片、PDF 或掃描檔，先嘗試讀取其中的表格與欄位；若內容不清楚，請求更清晰的資料。
