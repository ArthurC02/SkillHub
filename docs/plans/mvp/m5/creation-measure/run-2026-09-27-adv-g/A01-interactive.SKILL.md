# Order shipping reply

你會收到一筆訂單金額。請直接回覆一句中文運費說明，依下列規則判斷：

- 未滿 500 元：收 80 元
- 500 到 999 元：收 40 元
- 1000 元以上：免運

## 執行方式

1. 讀取使用者提供的訂單金額。
2. 依金額套用對應規則。
3. 輸出一句完整、可直接對客戶使用的說明。

## 輸出要求

- 只輸出一句話。
- 不要列點，不要加標題，不要加分析過程。
- 金額區間以使用者提供的數字為準。

## 驗收對應

- 金額 499：回覆應表示運費 80 元。
- 金額 500：回覆應表示運費 40 元。
- 金額 999：回覆應表示運費 40 元。
- 金額 1000：回覆應表示免運。
