# 自我介紹撰寫流程

當使用者要寫自我介紹、個人簡介、about me、履歷自介、面試自我介紹、社群簡介或開場介紹時，依照以下步驟完成。

## 1. 先確認用途與語氣
先判斷自我介紹要用在哪裡，因為不同場景需要不同長度與語氣。

優先確認這些資訊：
- 使用場景：面試、課堂報告、社團、交友、社群平台、履歷、申請文件、活動開場等
- 語言：中文、英文，或雙語
- 長度：短版、中版、長版
- 語氣：正式、自然、親切、專業、活潑
- 是否要包含：姓名、年齡、學歷、工作經驗、興趣、專長、個性、目標、聯絡方式

如果使用者沒有提供足夠資訊，先用最少必要問題補齊；若對方只想要一篇通用版，就直接寫一篇中性、自然的版本。

## 2. 蒐集內容素材
從使用者提供的資訊中整理出可用素材，至少包含：
- 我是誰：姓名或稱呼
- 我做什麼：學生、上班族、自由工作者、轉職者等
- 我的背景：學校、科系、工作、經歷
- 我的特點：專長、個性、優勢
- 我的興趣：嗜好、關注領域
- 我的目標：想達成什麼、希望別人如何認識我

若資訊不足，不要編造；改用較通用的表述，或請使用者補充。

## 3. 組織成自然結構
依用途選擇合適結構。

### 通用結構
1. 開頭問候或自我姓名
2. 身分與背景
3. 專長或特點
4. 興趣或個性
5. 結尾收束，表達期待或感謝

### 面試/履歷版結構
1. 姓名與目前身分
2. 學經歷或工作背景
3. 核心能力與成果
4. 為何適合這個機會
5. 結尾表達期待

### 社群/交友版結構
1. 簡短自我定位
2. 興趣與生活風格
3. 個性描述
4. 想認識什麼樣的人或期待互動

## 4. 寫作原則
- 用自然、口語但不失禮的句子
- 避免空泛形容詞堆疊，盡量具體
- 不要過度誇大或捏造經歷
- 句子長度依場景調整：正式場合較完整，社群場合較輕鬆
- 若是中文，優先使用繁體中文，除非使用者要求其他語言
- 若使用者沒有指定，提供一版可直接使用的版本，必要時再附一版較正式或較口語的替代稿

## 5. 產出格式
根據使用者需求輸出以下其中一種：
- 單一完整版本
- 短版與長版
- 正式版與口語版
- 中文版與英文版

若使用者提供了個人資料，將其整合成順暢段落；若資料零散，可先整理成條列，再轉成完整自介。

## 6. 若資訊不足時的處理
如果缺少關鍵資訊，先提出最少必要問題，例如：
- 這篇自我介紹要用在哪裡？
- 希望多長？
- 想呈現正式還是親切的語氣？
- 有哪些一定要提到的經歷或特點？

如果使用者希望你直接先寫，也可以先提供一篇通用模板，並標示可替換的內容。

## 7. 最終檢查
在交付前確認：
- 是否符合使用場景
- 是否有明確的自我定位
- 是否語氣一致
- 是否沒有捏造資訊
- 是否讀起來順暢、像真人會說的話

## 8. 可直接套用的通用模板
當使用者沒有提供細節時，可用以下結構生成：

「大家好，我叫＿＿＿，目前是＿＿＿。我平常對＿＿＿很有興趣，也喜歡＿＿＿。我的個性比較＿＿＿，做事時重視＿＿＿。希望未來能在＿＿＿方面持續學習與成長，也很高興有機會認識大家，謝謝。」

依場景調整內容長短與正式程度。
