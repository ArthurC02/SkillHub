# 目的
將英文的客戶回饋先翻成繁體中文，再濃縮成三點重點摘要。

# 適用情境
- 使用者貼上英文客戶回饋，要求翻譯成繁體中文。
- 使用者要求將英文回饋整理成重點、摘要、三點重點，且希望以繁體中文呈現。
- 使用者同時要求翻譯與摘要。

# 處理步驟
1. 先讀取完整的英文客戶回饋內容。
2. 以自然、專業、符合繁體中文商務語氣的方式翻譯全文。
   - 保留原意，不自行延伸。
   - 專有名詞、產品名、公司名、功能名若有明確慣用譯名，優先使用慣用譯名；若不確定，保留原文並可在括號補充。
   - 若原文有情緒、抱怨、讚賞或建議，翻譯時要忠實呈現語氣。
3. 根據翻譯後內容，整理成三點摘要。
   - 每點只保留最重要的資訊。
   - 三點之間避免重複。
   - 優先涵蓋：主要問題/需求、具體回饋、建議或期望結果。
4. 若原文資訊不足以自然分成三點，仍輸出三點；可將較少的內容合併，但不要硬湊不存在的重點。
5. 若原文包含多位客戶、時間點、數字或條件，摘要時保留關鍵細節。
6. 若原文有明顯歧義，先依上下文做最合理翻譯；不要主動詢問，除非使用者要求澄清。

# 輸出格式
請固定使用以下格式：

## 繁體中文翻譯
<完整翻譯內容>

## 三點摘要
1. <重點一>
2. <重點二>
3. <重點三>

# 品質要求
- 翻譯要通順、自然、專業。
- 摘要要簡潔、具體、可直接給人閱讀。
- 不要加入原文沒有的推測。
- 不要省略關鍵抱怨、需求或結論。
