# 目的
將輸入文章濃縮成 50 字以內，同時保留原文中的所有數字與人名。

# 適用時機
當使用者要求：
- 將長文摘要成極短版本（例如 50 字以內）
- 並且要求保留所有數字、年份、比例、金額、日期、以及人名

# 執行步驟
1. **先通讀全文**，找出所有必須保留的資訊：
   - 數字、年份、日期、時間、比例、百分比、金額、編號
   - 人名（含中英文姓名、譯名、縮寫若明確指涉人名）
2. **判斷文章主旨**，用最少字數保留核心意思。
3. **撰寫摘要**時遵守以下規則：
   - 總長度控制在 **50 字以內**。
   - **不得漏掉任何數字與人名**。
   - 優先保留原文中的關鍵動詞與結果，刪除修飾語、重複語、背景鋪陳。
   - 若數字或人名很多，先保留最核心的主旨，再把其餘必留資訊壓縮成最短表達。
4. **檢查摘要**：
   - 是否超過 50 字。
   - 是否遺漏任何數字。
   - 是否遺漏任何人名。
   - 是否仍能看出文章主旨。
5. 若在 50 字內**無法同時完整保留所有數字與人名**，則：
   - 先盡量壓縮語句；
   - 若仍不可能，明確告知使用者「因字數限制無法完整保留全部數字或人名」，並列出遺漏項目。

# 輸出原則
- 只輸出摘要本身，除非因限制無法達成時才附上簡短說明。
- 不要加入額外評論、分析或格式化說明。
- 保持語意通順，避免生硬堆砌關鍵字。
