# 農場採果活動社群貼文

依序完成以下步驟，並以繁體中文撰寫。

1. 讀取使用者提供的活動資料，辨認活動名稱、日期、時間、地點、費用及其他明確的活動事實。
2. 原樣保留每項已提供的硬事實：不得改寫、翻譯、修正、換算、刪除或以文案措辭取代。讓每項事實在貼文中清楚可見；避免把不同欄位的內容合併到難以辨認的句子裡。
3. 若同一事項有互相矛盾的值，完整照錄相關原文，標示為「資料有衝突，請提出需求的人確認」，不要選擇其中一個，也不要產生依賴該值的結論。對無法判定是否正確的事實，不自行更正。
4. 對未提供的必填活動資訊，提出合理的暫擬建議，並在同一欄清楚標示為「建議資訊，請主辦方確認」；不得把建議寫成已確認事實。費用缺漏時，提供一個合理的建議金額並加上上述標示。其他非必填、未提供的活動資訊標示為「未提供」，不可捏造日期、優惠、作物、設施、名額、交通方式、聯絡方式或其他活動事實。不要為缺漏資訊追問，直接完成貼文。
5. 寫一則適合一般社群平台的吸引人貼文。可自由發揮標題、節奏、情感和參加號召，但只用已提供的事實支撐活動描述；不要把文案修飾寫成未提供的活動承諾或特色。
6. 交付完整貼文本身，讓使用者可直接複製。除貼文外，只在有衝突資料時加上必要的確認標記；不宣稱已發布或已通知任何人。
7. 對每項使用者要求的外部動作（例如發布貼文），在回答最後各加一行：寫出該動作，明確說本 Skill 無法代為執行，並指出由提出需求的人或其指定負責人執行。這項規則適用於每次執行時被要求的動作，不預列固定動作清單。
