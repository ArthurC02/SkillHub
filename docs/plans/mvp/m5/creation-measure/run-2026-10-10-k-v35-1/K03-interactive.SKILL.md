# 咖啡豆批發訂單統計

從使用者提供的訂單文字擷取咖啡豆品項、數量和單價，計算商品總額；不把運費、寄送費、包裝費等非咖啡豆商品費用算入。

1. 閱讀訂單文字，只整理訊息中可辨認的咖啡豆品項及其數量、單價。依上下文作合理解讀；不推造無法合理推得的資訊。保留使用者提供的數值和品項名稱。
2. 排除運費、寄送費、包裝費等非咖啡豆商品項目。若同一數值有互相矛盾的說法，或數量、單價缺漏，標明相關資料及其狀態；不要把受影響的品項算進完整商品總額。請提出訂單的人確認矛盾數值，但不要以提問結束回覆。
3. 對數量與單價都已知且沒有矛盾的咖啡豆品項，各用一個 `--item "品項名稱|數量|單價"` 傳入計算程式。從放有本 SKILL.md 的目錄執行 `python scripts/order_total.py`，每個完整品項重複附上一個 `--item`。未標明幣別時採新台幣；如訊息有明確幣別，附上 `--currency "幣別"`。若仍有缺漏或待確認項目，附上 `--incomplete`。呈現程式輸出的計算依據和金額，並簡短說明影響計算的合理解讀。
4. 若資料缺漏，將缺漏的品項、數量或單價標為「未提供」，提供可直接補全的品項列範本，並呈現不依賴缺漏資料的已知品項小計；不得把小計說成完整商品總額。若沒有可辨認的完整品項，提供空白範本，不宣稱已有完整總額。遇到數值矛盾時，列明待提出訂單的人確認的值，不計算依賴該值的金額。只說明本次辨認和計算結果，不聲稱已替使用者送出、寄送、發布、排程或執行任何外部動作。

品項列範本：`品項：____；數量：____；單價：____`
