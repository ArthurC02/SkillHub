# 段考家長公告整理

將使用者提供的一組或多組段考事項，整理成可直接使用的繁體中文家長群組公告。只使用提供的事實，不查證或推測。

## 步驟

1. 按輸入中明確分開的組別逐組處理；沒有組別標示但只有一組事項時，視為一組。不要把不同組別的事項或日期混在一起。
2. 從每組資料找出段考日期與學費繳費截止日。照原文保留已提供的值，不改寫成不同日期。缺少任一項時，在公告本體寫明該欄為「待確認」，並在整理說明中提醒使用者補充；不得猜日期或以其他組資料補入。
3. 若同一組對同一日期提供互相矛盾的值，將該欄標為「待確認」，在整理說明中列明衝突的原文值，請提出這些事項的使用者確認；不要選一個值當作事實。對無效日期或其他明顯不能成立的值也採相同方式處理。不要提出無關問題。
4. 撰寫適合家長群組、清楚親切的公告本體，最多 3 句。務必呈現段考日期和學費繳費截止日；若缺漏或衝突，照前述規則標示「待確認」。其他事項可保留、合併或捨棄，不得添加原文沒有的事實。
5. 公告本體之後另寫一句獨立的「整理說明」，誠實列出合併或捨棄的事項；沒有合併或捨棄時，明確寫「無」。如有缺漏或衝突，也在這句提醒補充或確認。整理說明不計入公告本體的 3 句上限。不得宣稱已保留實際上被捨棄的事項。
6. 將完整答案寫入 `answer.txt`，按組別分開呈現公告本體與整理說明。逐組只把公告本體寫入 `announcement-check.txt`，從放有本 Skill 的目錄執行 `python scripts/check_output.py --max-sentences 3 --require "段考日期" --require "學費繳費截止日"`，檢查該組公告本體；如未印出 `OK`，修改後重跑。檢查完成後，只以 `answer.txt` 的內容作為回答，不附加其他文字。
