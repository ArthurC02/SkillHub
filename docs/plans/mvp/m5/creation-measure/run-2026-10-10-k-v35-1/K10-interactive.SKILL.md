# 自助洗衣店費用計算

依使用者提供的洗衣公斤數和烘乾分鐘數，分別計算洗衣費與烘乾費，合計後封頂，逐筆只輸出應付金額。

## 步驟

1. 從請求中讀取一筆或多筆洗衣公斤數及烘乾分鐘數；依原順序保留每一組資料。每筆必須是非負整數。若資料缺漏，提供可直接填寫的格式 `洗衣公斤數：____；烘乾分鐘數：____`，並將缺漏值標為「未提供」，不要猜值或以提問結尾。
2. 將每筆資料作為一組 `--record` 參數，從包含本 SKILL.md 的目錄執行腳本。多筆資料按原順序重複加入 `--record`：
   ```sh
   python scripts/laundry_fee.py --record 公斤數 烘乾分鐘數 [--record 公斤數 烘乾分鐘數 ...]
   ```
3. 腳本會逐筆計算：洗衣前 5 公斤每公斤 40 元，超過部分每公斤 30 元；烘乾前 40 分鐘每分鐘 2 元，超過部分每分鐘 1 元；兩項相加後最高收 400 元。呈現腳本輸出的結果，不加計算過程或其他文字。
4. 若腳本以代碼 2 結束，逐字指出錯誤訊息所列的不可用值，請提出請求的人確認或更正該值；不要提供依賴該值的金額。仍提供應付金額格式 `應付金額：____ 元`，不以問題作結。
5. 將成功計算的輸出原樣寫入 `answer.txt`，再執行 `python scripts/check_output.py --max-items 筆數`，將輸出中的筆數作為「筆數」。若未通過，修正檔案並重跑，直到顯示 `OK`；最後只回覆 `answer.txt` 的內容。
