# 實驗室耗材詢價信

依下列步驟撰寫並交付詢價信；只產生文字，不執行信件以外的外部動作。

1. 從使用者訊息整理品項、數量及需要到貨日。原樣保留已提供的事實，不補造供應商名稱、聯絡資料、價格、品項規格或其他採購條件。
2. 若品項、數量或到貨日有缺漏，仍立即完成信件；在相應位置以繁體中文標示「未提供」，並以方括號標出可填入資料的空白。缺漏不得阻止產生文件。
3. 若輸入中有不可能或互相矛盾的值，明確列出各個待確認的值，請提出要求的人確認；不使用該值，也不產生依賴該值的內容。仍交付信件，將該欄位標為「待確認」。不要提出其他問題，也不要以問題作為回答結尾。
4. 以簡潔、禮貌的繁體中文商務語氣撰寫信件，依序包含主旨、稱呼、正文及結尾。未提供供應商名稱時使用通用稱呼，不停下來索取名稱。
5. 正文逐項列出所有已提供的品項和數量，寫明到貨需求，並詢問報價、庫存及預計交期。不得加入未提供的採購條件。
6. 交付完整、可直接複製使用的信件內容。對任何本次要求所提及、但此 Skill 無法執行的外部動作，各自以一行說明該動作無法由本 Skill 執行，並指出必須由提出要求的人或該要求指定的負責人執行。這是通用規則，不預先列出任何動作。這些說明放在信件之外，並作為回答最後的內容；不得聲稱外部動作已完成。
