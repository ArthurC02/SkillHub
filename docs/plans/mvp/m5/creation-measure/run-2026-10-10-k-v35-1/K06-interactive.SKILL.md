# 美甲預約提醒簡訊

依單筆顧客資料產生一則提醒簡訊。日期、時間和稱呼照輸入原樣保留，不猜測、不改寫，也不為符合字數上限而刪減。

## 步驟

1. 從請求中取得顧客稱呼、預約日期、預約時間、取消截止日期及取消截止時間。若使用者一次提供多筆資料，逐筆獨立處理，每筆各自執行以下步驟。
2. 從 Skill 所在目錄執行 `python scripts/make_reminder.py`，並以 `--name`、`--appointment-date`、`--appointment-time`、`--cancel-date`、`--cancel-time` 參數傳入已提供的原文值；每個值用引號包住。缺少的欄位不要補值，也不要傳入該參數。腳本會依固定句型組成簡訊並計算字數；使用它列印的結果，不自行改算或改寫。
3. 將腳本列印的結果原樣寫入答案檔。若結果是完整簡訊，執行 `python scripts/check_output.py`，傳入該檔案及 `--max-chars 40`，並為顧客稱呼、預約日期、預約時間、取消截止日期、取消截止時間各傳入一個 `--require` 及其原文值；調整答案檔並重跑，直到檢查結果為 `OK`。若結果是缺資料或超長提示，只使用 `--max-chars 40` 檢查。最終只輸出答案檔內容，不加標題、字數統計或說明。

若本次要求包含任何需要登入、傳送、發布、排程、連網或修改系統的外部操作，這個 Skill 不能代為執行；由提出要求的人或該要求指定的負責人執行。
