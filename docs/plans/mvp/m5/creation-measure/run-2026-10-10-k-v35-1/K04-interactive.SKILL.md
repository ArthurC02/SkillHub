# 水電維修報價

依使用者提供的案件資料計算報價。每小時工時費為 800 元；晚上 10 點後出勤時，夜間加成為工時費的 50%，只加在工時費上；材料費不加成。不另加其他費用、稅金或折扣。金額以新台幣元表示。

## 步驟

1. 從請求中逐筆辨認案件，記下工時、是否晚上 10 點後出勤及材料費；保留使用者提供的案件名稱與數值原樣。名稱不是計算必要資料，未提供時以案件順序標示。
2. 對已提供的值做檢查：工時與材料費不可為負數，夜間出勤須能判斷為是或否。若同一項有不同值，包括後來的說法改變先前數值，將每個無法採用的值逐一指出，請提出請求的人確認；不計算依賴該值的總額，也不追問其他事項。
3. 對資料齊全且可採用的案件，在包含此 `SKILL.md` 的目錄執行一次指令；每筆案件重複一個 `--case`，欄位依序為名稱、工時、夜間出勤（是／否）、材料費。名稱缺漏時填 `-`。例如：

   ```sh
   python scripts/quote.py --case 案件A 2 否 500 --case 案件B 3 是 700
   ```

4. 將腳本列印的工時費、夜間加成、材料費及報價總額逐筆呈現。腳本若指出無法採用的值，指出該值並請提出請求的人確認；不呈現依賴它的總額。未提供的工時、夜間出勤或材料費標示為「未提供」，並給出可直接補填的格式：`案件〔名稱〕：〔工時〕小時，晚上 10 點後出勤〔是／否〕，材料費〔金額〕元`。不得把未提供的值當成零，也不得把可由已知資料算出的值標成未提供。

對任何請求中提到、但此 Skill 執行環境不能完成的外部動作，答案最後各用一行說明該動作無法由此 Skill 執行，並指出應由誰完成：提出請求的人，或請求中指定負責的人。
