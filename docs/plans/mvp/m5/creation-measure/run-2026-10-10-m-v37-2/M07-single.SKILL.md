# 登山社行前通知信撰寫

根據使用者提供的出團資訊，撰寫清楚、實用、可直接使用的繁體中文行前通知信本文。只整理與撰寫文字，不聲稱或暗示已代為寄信、聯絡團員、查詢網站或完成其他外部操作。

## 步驟

1. **整理已提供的資料**：辨認活動名稱與日期、目的地與路線、集合時間地點、交通方式、行程安排、領隊或聯絡人、費用與付款方式、餐食與飲水、裝備、天候或安全提醒，以及報名者需回覆或準備的事項。
2. **檢查資料是否足以成信**：不得自行猜測日期、時間、地點、路況、天氣、費用、裝備規格、聯絡方式或其他行程細節。若關鍵資訊缺漏且會影響團員能否集合或安全參加，先向使用者詢問最必要的問題。若可先完成大部分內容，便先寫出不依賴缺漏資訊的版本，並在信件外另列「待確認資訊」；不要把待填欄位、方括號或臆測內容放進可直接寄出的信件本文。
3. **依實際行程選擇內容**：納入與該次活動相關的資訊，不要硬套不適用項目。徒步活動可整理衣物與鞋襪、背包、飲水與行動糧、雨具、照明、個人藥品、證件或其他明確要求的裝備。若使用者沒有提供某項要求，不要把它寫成主辦方的規定。
4. **編排通知信本文**：使用清楚的稱呼與簡短開場，接著以易讀段落或條列說明集合資訊、行程與交通、裝備與餐食、安全提醒、費用及需回覆事項。最後以友善語氣收尾。可以加入主旨，但不要捏造寄件者姓名、電話或社群連結。
5. **處理安全與天候資訊**：只引用使用者提供的資訊。若需提醒團員留意天氣、身體狀況或依領隊指示行動，可用一般性提醒，不要宣稱已查過預報、路況或官方公告，也不要保證活動一定成行或安全無虞。
6. **處理使用者要求的外部動作**：若使用者要求寄信、打電話、登入網站、查詢或聯絡他人，明確說明這些動作無法由本 Skill 完成、需由人接手；不可說成已完成。仍應依現有資料寫好通知信本文交付。若文字中提到外部動作，只能將它寫成待由主辦者執行的事項，不得冒稱已執行。
7. **輸出前檢查**：確認內容與已知資料一致、沒有杜撰或未填欄位，集合時間地點等資訊醒目，語氣親切且不含糊。預設只輸出通知信本文；若有重要缺漏或外部動作限制，再在本文之外用簡短區塊說明，避免收件人誤把內部備註當成信件內容。

## 輸出原則

- 使用繁體中文，措辭自然、明確、適合登山社團員閱讀。
- 不要把缺少的資訊補成看似確定的事實，也不要過度承諾。
- 若使用者提供的資料彼此矛盾，先指出矛盾並詢問應採用哪一項；不要自行選邊。
- 只有在資訊足夠時才給出可直接寄送的完整本文；否則提供不含虛構內容的草稿，並清楚列出需確認事項。
- 對寄送、電話、登入或查詢等要求，說明需由人接手，同時完成可做的文字撰寫工作。
