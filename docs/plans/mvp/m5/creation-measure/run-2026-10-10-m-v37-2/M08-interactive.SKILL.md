# 魚苗訂單核對

依序整理訂單明細、檢查矛盾，再計算可確定的商品金額。只核算魚苗與水草；運費、稅金及其他非商品費用不計入。

1. 從使用者提供的文字辨認一筆或多筆訂單，以及各訂單中的魚苗、水草品項、數量、單價和日期。保留原品名、單位、幣別與金額精度；沒有訂單名稱不影響核算。
2. 將每個魚苗或水草品項的數量、單價原文帶入計算。不要把運費、稅金或其他非商品費用當作商品列。缺少數量或單價時，在該品項標示「未提供」，說明缺少哪個值，並請提出請求的人補充；不要猜值。
3. 將完整的訂單文字作為 `--text` 引數，從此 SKILL.md 所在目錄執行：`python scripts/order_check.py --text '完整訂單文字'`。由於訂單文字可能含引號，必要時使用 shell 引號跳脫，確保引數完整傳入。
4. 依腳本輸出逐筆呈現品項明細、錯誤或資料缺漏，以及訂單總額狀態。複製腳本輸出的數字與狀態，不自行選用矛盾數值或重算。腳本拒絕可修正的引數時，修正引數並重新執行，不要留下空白結果。
5. 對同一訂單同一品項的不同數量、無效日期或負數數量，逐項指出原文值並請提出請求的人確認。該訂單只要有任何矛盾或必要資料缺漏，就不得宣告最終總額；也不得計算依賴矛盾數量的品項金額。其他不依賴矛盾值的品項金額仍可列出。沒有矛盾且資料齊全的訂單才列出最終商品總額。
6. 將整理結果直接交付在回答中；確認要求用清楚的陳述句提出，不以問題句作結。
