# 車站行李寄放收費試算

依件數費與整筆寄放天數費計算每筆寄放應收總額，並套用單筆上限。

## 步驟

1. 從使用者提供的資料找出每筆寄放的件數與整筆寄放天數，按原輸入順序整理。每筆格式為 `件數,天數`；若缺少資料，提供可直接填寫的格式 `件數,天數`，把未提供的值標為「未提供」，不猜測數值。
2. 從本 Skill 所在目錄開啟終端機，將每筆資料依序作為獨立引數執行：
   `python scripts/luggage_fee.py "件數,天數" "件數,天數"`
   把引號中的示例格式替換成使用者實際提供的每筆數值；只傳入已提供的資料，不要用自行假設的數值補缺。若沒有任何完整資料，略過計算並交付上述可填寫格式。
3. 若命令因 Skill 自己組錯引數而拒絕，修正引數並重跑。若程式指出使用者提供的值不能使用，逐一列出原值，請提出請求的人確認該值；不提供任何依賴該值的金額。只處理不能使用的值，不追問其他事項。
4. 將程式輸出的每一行依原順序呈現，逐字保留程式列出的金額與單位。不要在本步驟自行重算或改寫金額。
