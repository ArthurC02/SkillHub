# 音樂教室試聽確認簡訊

將一筆或多筆試聽資料整理成可直接使用的繁體中文簡訊。每筆一則，本文最多 50 個 Unicode 字元；只輸出本文，不加標題、說明或字數統計。

## 步驟

1. 將使用者提供的資料分成試聽紀錄；保留每筆的試聽日期、時間、教室編號、試聽費及改期截止日。忽略備註、電話及其他非必要資料，不改寫或捏造已提供的必要值。
2. 未提供的欄位分別標示為「日期未提供」「時間未提供」「教室未提供」「費用未提供」或「改期截止日未提供」。日期、時間等可由明確輸入直接讀出的值照原樣使用，不自行補值。
3. 在本 Skill 所在目錄，將每筆原始紀錄各作為一個引數，執行：
   `python scripts/format_sms.py '完整的單筆原始資料' ...`
   腳本會逐筆產生一行簡訊；它會計算字元數，欄位全部放不進 50 字時輸出規定的固定本文「試聽資訊過長，請聯絡教室確認。」。不要自行替換或縮短任何已提供的值。
4. 若腳本因你組成的引數格式而拒絕輸入，修正引數並重跑。若原始資料本身有同一欄位的互相矛盾值或無法使用的值，指出該值並請提出請求的人確認；不產生依賴該值的簡訊。除此之外不提出問題。
5. 將腳本輸出存成答案檔。用平台提供的檢查程式驗證每行上限及資料筆數，例如：`python scripts/check_output.py --max-chars 50 --max-items <筆數> <答案檔>`；對非固定回覆的每則簡訊，另以 `--require` 帶入該筆五項必要值（缺漏欄位帶入 brief 指定的完整缺漏標示）檢查。固定回覆只檢查字數。修正後重跑，直到檢查程式輸出 `OK`。最後只輸出答案檔內容。
6. 如果本次請求還要求任何本地檔案與 shell 無法完成的外部動作，完成可準備的內容後，在答案結尾另用一行逐項寫明該動作本 Skill 無法執行，並指出應由提出請求的人或其指定負責人執行。
