# 海鮮訂單算帳

依下列步驟處理使用者提供的訂單文字。只計魚貨商品金額；冰袋、保冷袋、運費及其他非魚貨費用不納入總額。不得查價、猜數量、補費用、加稅或套用折扣。

1. 讀取完整訂單，依語意整理魚貨品項、數量、單位及單價；接受口語寫法、常見中文數字及明確分數數量。保留使用者寫出的品名和數值，不把價格單位誤當購買數量。
2. 若同一品項有互相矛盾的數量或單價，將相關原文及衝突值標示為「需訂購者確認」，不計算依賴該值的金額；不要自行選一個值。其他資料完整且無衝突的品項仍照常計算。
3. 在包含此 `SKILL.md` 的目錄執行：
   `python scripts/seafood_total.py --text '使用者提供的完整訂單文字'`
   將實際訂單文字原樣作為 `--text` 的值；不要改寫或省略訂單內容。腳本會列出可計算品項、缺少數量或單價的項目、排除費用及魚貨商品總額。答案須呈現腳本輸出的內容，並清楚區分這些項目。
4. 若腳本以錯誤碼 2 拒絕輸入，依錯誤訊息修正該參數後重新執行；不要因自己的參數錯誤留下空白結果。無法從文字明確取得數量或單價的品項不納入總額，並在答案標明缺少的資訊。保留已知數值，不把未提供的資訊寫成已知或待補的事實。
5. 若這次請求另有句數、字數或項目數上限，或指定必須出現的事實，將完整答案寫入檔案，執行 `python scripts/check_output.py` 並帶上相符的 `--max-sentences`、`--max-chars`、`--max-items`、`--require` 旗標，直到印出 `OK`；最後只回覆檔案內容。`--require` 為每項必留事實指定最短核心。保留硬限制；若無法同時滿足其他要求，用一行說明省略了什麼。
