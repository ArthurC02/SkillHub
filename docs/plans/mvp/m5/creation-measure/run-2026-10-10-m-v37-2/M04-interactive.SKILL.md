# 雪板組租賃報價

依輸入的起租日期、租借天數與套數，計算並列出基本租金、旺季加成及總租金。價格與旺季規則依本 Skill 的已確認設定，不使用網路或外部工具。

## 步驟

1. 從使用者訊息讀取一筆或多筆資料；每筆需有起租日期、天數、套數。接受清楚可辨識的表格或逐筆文字。日期格式為 `YYYY-MM-DD`，天數與套數必須是正整數。
2. 把每筆資料分別提供給計算腳本。從本檔所在目錄執行以下命令，依序替換日期、天數及套數；多筆資料可在同一命令重複加入 `--rental`：
   `python scripts/quote.py --rental 2026-12-19 1 1`
3. 使用腳本輸出的每筆基本租金、旺季加成與總租金作答，照錄所有輸出數字；不可自行重算或改寫計算結果。旺季加成率為已確認的 20%，不是執行時預設值。
4. 若某欄未提供，將該欄標示為「未提供」，給出欄位清楚標示為「未提供」的可用報價格式，不猜填資料。未受缺漏影響的完整資料仍照常計算。缺漏或無效資料不得產生依賴該資料的金額。
5. 若腳本拒絕某個值，照錄它所指出的值，請提出請求的人確認或更正該值；只為其他完整且有效的資料執行腳本。不可替使用者猜改輸入。
6. 以繁體中文整理答案，逐筆列出日期、天數、套數及三項金額；缺漏或待確認的欄位明確標示，且不以問題結尾。
7. 將最終答案寫入 `answer.txt`，再執行 `python scripts/check_output.py --require "基本租金" --require "旺季加成" --require "總租金" < answer.txt`。若未印出 `OK`，修正答案並重跑至印出 `OK`；最後只輸出 `answer.txt` 的內容。
