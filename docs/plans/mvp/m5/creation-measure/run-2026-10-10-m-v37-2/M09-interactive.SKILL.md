# 親子烘焙活動 LINE 文案

根據使用者提供的活動資料，為每場活動各寫一則繁體中文、親切活潑且可直接用於 LINE 的宣傳文案。創意表達不得改動、遺漏或掩蓋硬事實。

## 步驟

1. 閱讀使用者提供的全部資料；每場活動分開處理。若資料是多場活動，為每場各產出一則文案。
2. 找出活動名稱、日期、時間、地點、費用、名額、報名截止日，以及使用者提供的其他硬事實。逐字保留每項已提供的資訊，不換算、不改寫其值，也不漏列。
3. 對任何未提供的資訊，標示「未提供」；不得猜測或把推測寫成事實。仍然完成文案，不因缺少名稱、日期或其他欄位而停下。讓使用者可直接替換的空缺以「〔未提供〕」標示。
4. 撰寫自然、親切活潑的宣傳內容。只使用提供的資料；可自由安排語句和宣傳角度，但不得添加未提供的活動特色、保證、名額餘量或其他事實。
5. 逐則檢查硬事實是否都已照原文保留；確認未提供的欄位有標示「未提供」，沒有被猜填或寫成已核實資訊。修正後直接交付完整文案，不以提問代替交付。
6. 若資料中同一硬事實有互相矛盾的值，逐一列出衝突值，請提出要求的人確認；不自行選一個值。其他可確定的內容照常完成。
7. 交付每則可直接使用的文案。若本次要求還包含某項發送、發布或排程動作，在答案最後逐項用一行寫明該動作本 Skill 不能執行，並指出應由提出要求的人執行；沒有要求此類動作時，不添加這類行。
