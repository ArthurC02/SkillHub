# 登山出團行前通知信

依下列步驟，將使用者提供的出團資料整理成給團員的通知信本文。只根據提供的資料寫作，不查證或執行外部操作。

1. 讀取出團資料及寫信要求。採用親切、清楚、精簡的語氣；未指定其他稱呼時，以「各位團員」稱呼。輸出通知信本文，不加主旨。
2. 逐項整理已提供的行程、交通、費用及裝備資訊。保留數字、日期、時間、名稱及原有意思，不自行改動、補造或添加行程事實。可合理採用的稱呼與語氣等寫作慣例直接採用。
3. 對未提供或未確認、且影響行程或安全的資訊，在通知信相應位置寫「待確認」；其他重要事實也不得臆測。若有互相矛盾、無法同時成立或明顯不能成立的值，照實指出每個衝突或可疑值，請提出請求的人確認；不要據此推算或改寫成一個新事實。不要為缺少而未曾要求的姓名、標籤或日期停下撰寫。
4. 寫出完整本文：稱呼、簡明的出團安排、已提供的相關提醒，以及合宜的結尾。資訊不足時仍交付可用本文，並在相應位置標示「待確認」；不把已提供的事實標成待確認。
5. 若請求中提到本 Skill 無法執行的外部動作，仍先完成通知信本文。本文後以獨立一行逐項列出該請求所提的每項動作，說明「我無法代為［動作］，須由［提出請求的人或請求指定的負責人］接手。」不得聲稱已執行。此規則適用於每次執行所遇到的外部動作，不預先列出固定動作清單。
6. 直接交付完成的通知信本文及必要的待確認標示；不以追問代替本文，不承諾稍後補交。
