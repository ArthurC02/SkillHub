# 小劇場票券退票試算

依輸入案例計算各自的退款總額（元）。每筆案例各自計算，不合併不同案例。

## 步驟

1. 從使用者資料辨認每筆案例的名稱、單張票價、張數、開演日期、申請日期及主辦方是否取消。保留使用者提供的事實原樣，不改寫或補造。
2. 將每筆案例整理為下列格式；欄位用 `|` 分隔，未提供的欄位留空。若資料含有互相矛盾的值，指出無法使用的值並請提出者確認；不要計算依賴該值的退款。對尚缺資料的案例，仍列出已知事實，將缺少的值標為「未提供」，並給可直接補填的格式，不以缺漏阻止其他可計算案例。

   `案例名稱|單張票價|張數|開演日期(YYYY-MM-DD)|申請日期(YYYY-MM-DD)|主辦方取消(是/否)`

   日期須為有效日期，申請日不得晚於開演日；申請日晚於開演日不在本 Skill 的適用範圍。不要把沒有給出的取消狀態猜成是或否。
3. 在含有 `SKILL.md` 的目錄，對每筆案例使用一個 `--case` 參數執行腳本，例如：

   `python scripts/calculate_refunds.py --case '案例名稱|票價|張數|開演日期|申請日期|是或否'`

   把每筆案例的實際資料放入各自的參數；多筆案例就重複 `--case`。資料缺漏時也可保留空欄傳入。若沒有案例資料，執行 `python scripts/calculate_refunds.py` 取得可填寫格式。
4. 檢視腳本輸出。取消為「是」者全額退款，優先於其他規則；其餘依日期差套用規則。腳本會計算日曆天數差、各筆退款與整元四捨五入（恰為 .5 時進位）。逐行呈現腳本印出的案例及退款額，不要自行改算或合併案例。若腳本指出輸入值無法使用，指出該值並請提出者確認；照常交付其他已能確定的案例。
5. 對本次請求若另有任何需要登入、傳送、發布、排程或更改外部系統的動作，先備妥可供使用的內容；本 Skill 執行環境不能代做該動作，須由提出者或其指定負責人完成。
