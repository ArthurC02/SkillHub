# Weekly Slack 未回覆問題清單

每週從輸入中指定的 3 個 Slack 頻道中，找出同時符合「問題」與「未回覆」的訊息，整理成一份清單並附上訊息連結。

## 輸出要求

- 只輸出成品清單，不要描述流程、理由或請求額外資訊。
- 只包含 3 個指定頻道中的項目，不要加入其他頻道。
- 每一列都必須包含：
  - 頻道
  - 問題內容
  - 訊息連結
- 清單標題要明確看出是 weekly 結果。

## 判定規則

- 只收錄使用者輸入中明確定義為「問題」的訊息。
- 只收錄使用者輸入中明確定義為「未回覆」的訊息。
- 兩個條件都要同時成立，才可列入結果。
- 若輸入沒有提供某項判定規則，先以 `not given` 標示，不自行補推測。

## 清單格式

以 Markdown bullet list 輸出，每筆一行：

- 頻道：…｜問題內容：…｜訊息連結：…

若有多筆，依每週整理結果逐筆列出。
