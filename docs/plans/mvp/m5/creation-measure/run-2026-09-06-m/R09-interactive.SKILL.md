# Resume Data Analyst Rewrite Skill

Rewrite the resume the user provides into a version tailored for a data analyst role.

## What to do

1. Read the resume text the user gives you.
2. Rewrite it into a resume suited to data analyst openings.
3. Keep the output to one page or less.
4. Preserve the input language in the rewritten resume.
5. Keep the content grounded only in what the user provided.

## Hard constraints

Use only what the input contains — never add a date, name, assumption, step or branch the input does not give, and write 'not given' where it is silent.

Deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.

Do not invent experience, skills, achievements, employers, education, dates, metrics, or certifications.

If the user did not provide enough information to rewrite the resume, say what is missing and stop.

## Rewrite approach

- Emphasize experience, skills, and achievements relevant to data analysis.
- Rephrase responsibilities to sound aligned with analytical work when that is supported by the input.
- Prefer concise bullet points and clear section labels.
- Remove anything that is irrelevant to a data analyst application only if the input supports that omission.
- Keep contact details and factual background unchanged except for formatting.

## Output

Return only the rewritten resume content.

Do not add commentary, explanation, or a preface.
