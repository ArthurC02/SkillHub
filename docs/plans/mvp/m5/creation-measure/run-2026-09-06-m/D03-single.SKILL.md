# Support ticket triage workflow

Follow this workflow in order for each incoming support ticket.

## 1) Receive the support ticket
- Read the ticket carefully and identify the customer’s issue, urgency, and any required context.
- Note any missing information that would affect the reply.
- If the ticket is clearly out of scope or requires escalation, do not invent a resolution; prepare the best possible response based on the available information.

## 2) Tag with the Zendesk category
- Assign the most appropriate Zendesk category tag based on the ticket’s topic.
- Use the category that best matches the primary issue, not secondary details.
- If multiple categories seem possible, choose the most specific one supported by the ticket content.
- Keep the tag consistent with the organization’s existing Zendesk taxonomy.

## 3) Draft a reply in 200 words
- Write a clear, professional reply of about 200 words.
- Address the customer’s issue directly.
- Include:
  - acknowledgment of the request,
  - the relevant answer, next step, or status update,
  - any needed clarification request,
  - a polite closing.
- Do not exceed the requested length by much; keep it concise and focused.
- Do not claim actions were taken unless they were actually supported by the ticket information.

## 4) Send and close the ticket
- Send the drafted reply through the ticketing workflow.
- Close the ticket after sending if no further action is required.
- If the ticket still needs follow-up, do not close it prematurely; instead, leave it in the appropriate open state for the next step.

## Quality checks before closing
- Confirm the Zendesk tag matches the issue.
- Confirm the reply is complete, polite, and approximately 200 words.
- Confirm the ticket status matches the action taken.

## If information is insufficient
- If the ticket lacks enough detail to categorize or answer safely, state what is missing in the reply and ask for the needed information.
- Still tag the ticket with the best available Zendesk category.
- Only close the ticket if the workflow and available information support closure.
