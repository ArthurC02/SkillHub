# 新人到職流程

依照流程圖，按順序執行以下步驟：

1. **收到新人到職通知**
   - 確認已收到正式的新進人員到職通知。
   - 若通知內容不完整，先向相關窗口補齊必要資訊。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認帳號可正常登入，並記錄必要的帳號資訊。

3. **加入 Slack 頻道**
   - 將新人加入需要的 Slack 頻道。
   - 確認新人能接收團隊與部門相關訊息。

4. **準備筆電與門禁卡**
   - 準備新人報到所需的筆電與門禁卡。
   - 檢查設備可用性與門禁卡是否已完成設定。

5. **安排第一週訓練**
   - 規劃新人第一週的訓練內容與時程。
   - 確認訓練項目、時間與負責人已安排完成。

6. **指派導師**
   - 為新人指定一位導師或帶領人。
   - 確認導師知道自己的角色與支援範圍。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 事先確認面談時間、參與者與討論重點。

8. **記錄到人資系統**
   - 將以上完成事項與關鍵資訊記錄到人資系統。
   - 確保紀錄完整、可追蹤，作為後續查核依據。

## 執行原則
- 必須依照流程圖順序進行，不可跳步。
- 每一步完成後再進入下一步。
- 若某一步缺少必要資訊或資源，先補齊再繼續。
- 最後一定要完成人資系統紀錄。
