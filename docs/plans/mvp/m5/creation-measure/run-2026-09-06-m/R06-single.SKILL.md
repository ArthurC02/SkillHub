## 目標
將一份英文使用手冊完整翻譯為繁體中文，保留原意、操作順序、警告與格式結構；所有專有名詞在第一次出現時以「繁體中文（Original）」呈現，之後只用繁體中文。

## 處理原則
1. **完整翻譯，不摘要**：不得省略段落、步驟、注意事項、表格、標題、圖說或警告。
2. **保留結構**：維持原手冊的章節層級、編號、項目符號、表格欄位與順序。
3. **術語一致**：同一術語在全文使用一致譯法；若原文有固定產品名、功能名、按鍵名、介面名，首次出現時附原文。
4. **首次出現標註原文**：
   - 專有名詞、產品名稱、功能名稱、介面名稱、按鍵名稱、縮寫，第一次出現時寫成「繁體中文（Original）」。
   - 之後若不影響理解，只保留繁體中文。
5. **保留不可翻譯內容**：型號、版本號、命令列指令、程式碼、路徑、URL、錯誤碼、按鍵組合、單位與數值格式應維持原樣或僅做必要中文化。
6. **圖片與圖表說明**：若手冊包含圖片、流程圖或表格，翻譯其標題、註解與說明文字；若無法讀取圖片內容，保留可見文字並註明「圖中其餘內容不清晰」。

## 翻譯步驟
1. **先掃描全文**，找出：
   - 產品/功能/介面/按鍵等專有名詞
   - 重複出現的術語
   - 標題層級與段落結構
2. **建立術語對照**：為全文選定一致譯法，避免同詞多譯。
3. **逐段翻譯**：按原順序翻譯每一段，保持語氣清楚、自然、符合繁體中文技術文件風格。
4. **首次出現加註原文**：在第一次翻譯到專有名詞時加入原文括號；若同一名詞在不同章節再次首次出現，仍以全文第一次出現為準。
5. **檢查一致性**：確認標題、步驟編號、警告語氣、按鍵名稱、單位與符號前後一致。
6. **校對完整性**：確認沒有漏譯段落、列表項、表格列、註腳或注意事項。

## 輸出要求
- 只輸出繁體中文譯文，不要附翻譯說明、過程記錄或雙語對照，除非使用者另外要求。
- 保留原手冊的版面邏輯；若原文是 Markdown、HTML、Word 轉出的結構化文字，請維持相同結構。
- 若遇到無法判定的專有名詞，先採音譯或直譯中較符合文件語境者，並保留原文。
- 若原文含有明顯錯字或語病，翻譯時以可理解且忠於原意為準，不自行擴寫。
