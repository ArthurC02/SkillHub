# Excel 客戶名單清理

此技能用於處理 Excel 中的客戶名單，目標是：
1. 去除重複資料。
2. 標記缺少電話的列。

## 執行步驟

1. **確認資料範圍與欄位**
   - 找出客戶名單所在的工作表。
   - 確認哪一欄是用來判斷重複的主要識別欄位，通常是「客戶名稱」、「姓名」、「Email」或其他唯一鍵。
   - 確認電話欄位名稱，例如「電話」、「手機」或「聯絡電話」。

2. **先保留原始資料**
   - 在原工作表上操作前，先複製一份工作表或另存新檔，避免覆蓋原始資料。

3. **去除重複資料**
   - 以確認過的識別欄位作為去重依據。
   - 如果只有一個欄位可判斷重複，就以該欄位去重。
   - 如果需要更精準，可用多欄組合判斷，例如「姓名 + 電話」或「姓名 + Email」。
   - 去重時保留第一筆出現的資料，除非資料規則明確要求保留最新一筆。

4. **標記缺少電話的列**
   - 檢查電話欄是否為空白、只有空格，或是缺值。
   - 在新增欄位中標記，例如「電話狀態」或「缺少電話」。
   - 對缺少電話的列填入明確標記，例如「缺少電話」；有電話的列可填入「正常」或留白，依需求一致處理。

5. **檢查結果**
   - 確認去重後的筆數是否合理。
   - 確認所有空白電話列都已被標記。
   - 抽查幾筆資料，確認沒有誤刪正常資料。

6. **輸出整理後的檔案**
   - 將結果儲存為新檔，保留原始檔不變。
   - 若需要交付，提供去重後且已標記缺少電話的 Excel 檔。

## 注意事項

- 如果無法判斷哪個欄位代表「重複」，先詢問使用者要以哪一欄或哪些欄位作為去重依據。
- 如果電話欄名稱不明，先掃描標題列找出最可能的欄位名稱。
- 若資料中有合併儲存格、空白列或多個標題列，先整理成單一標題列再進行去重與標記。
