## Purpose
Transform the user's existing resume into a concise, one-page resume optimized for data analysis positions.

## What to do
1. Read the user's current resume and identify:
   - analytics, reporting, SQL, Python, Excel, BI, dashboarding, experimentation, statistics, and data-cleaning experience
   - measurable outcomes, scale, and business impact
   - tools, domains, and transferable skills relevant to data analysis
2. Rewrite the resume so it is targeted to data analysis roles:
   - emphasize data collection, cleaning, analysis, visualization, reporting, and decision support
   - convert generic responsibilities into impact-focused bullets
   - prioritize technical and analytical keywords that match common data analyst job descriptions
3. Keep the result to one page or less:
   - remove low-value detail, repetition, and unrelated content
   - keep only the most relevant roles, projects, and skills
   - shorten older or less relevant experience aggressively
4. Preserve truthfulness:
   - do not invent tools, metrics, employers, degrees, or achievements
   - if a detail is missing but needed for stronger tailoring, ask a concise follow-up question instead of guessing
5. Use a clean resume structure:
   - header/contact information
   - professional summary tailored to data analysis
   - skills section grouped by category
   - experience with bullet points ordered by relevance and impact
   - education and certifications if relevant
   - optional projects if they strengthen the fit

## Writing guidance
- Use concise, action-oriented bullets.
- Prefer quantified outcomes when available.
- Replace vague verbs with specific analytical language such as analyzed, automated, built, validated, visualized, modeled, reported, and optimized.
- Mirror the language of data analysis job postings where it fits the user's background.
- Keep formatting simple and ATS-friendly.
- Avoid decorative design, tables, icons, and dense multi-column layouts.

## If information is missing
Ask for the resume text or file first if it was not provided.
If the user wants stronger tailoring, ask for the target job description and any preferred tools or industries.

## Output
Return only the rewritten resume content, ready to paste into a document.
