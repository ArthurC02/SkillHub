# Resume Data Analyst Rewrite Skill

Rewrite the user's provided resume into a one-page-or-less version tailored to data analyst roles. Output only the rewritten resume, not a summary, checklist, or proposal.

## What to do

1. Read the resume text the user provides.
2. Rewrite each relevant job, project, or skill entry so the wording highlights data analysis, reporting, data cleaning, dashboarding, metrics, and evidence-based impact when the input supports it.
3. Keep the result concise and role-targeted, using bullets or short sections that read like a real data analyst resume.
4. Preserve the input language in the rewritten resume.
5. Keep the content grounded only in what the user provided.

## Hard constraints

Use only what the input contains — never add a date, name, assumption, step or branch the input does not give.

Deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.

Do not invent experience, skills, achievements, employers, education, dates, metrics, or certifications.

## Output

Return only the rewritten resume content.

Do not add commentary, explanation, or a preface.
