# Weekly Slack 未回覆問題清單

每週從輸入中指定的 3 個 Slack 頻道中，找出同時符合「問題」與「未回覆」的訊息，整理成一份清單並附上訊息連結。

## 輸出要求

- 直接輸出一份 weekly 清單成品，不要說明你不能執行、不要提供範例格式、不要要求補資料。
- 清單中的每一列都必須包含：頻道、問題內容、訊息連結。
- 只列出輸入中指定的 3 個頻道，若結果中出現其他頻道，必須排除，不得輸出。

## 判定規則

- 只收錄使用者輸入中明確定義為「問題」的訊息。
- 只收錄使用者輸入中明確定義為「未回覆」的訊息。
- 只收錄同時符合「問題」與「未回覆」兩個條件的訊息。
- 除符合條件的結果列外，不要輸出任何說明、替代方案或範例。

## 清單格式

以 Markdown 清單輸出，每筆一行：

- 頻道：…｜問題內容：…｜訊息連結：…
