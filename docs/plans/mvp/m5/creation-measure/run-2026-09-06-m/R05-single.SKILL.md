# 目的
將一週內的每日花費整理成清楚的表格，逐筆標示類別，並在週末彙總各類別合計與總計。

# 適用情境
- 使用者提供一週的花費明細，要求整理成表格。
- 使用者希望每筆支出都加上類別標籤。
- 使用者要求在週末或週結時，計算各類別合計。

# 處理流程
1. **確認資料範圍**
   - 先辨識資料是否涵蓋一週（7 天）或使用者指定的週期。
   - 若日期不完整，仍依現有資料整理，但不要自行補資料。

2. **整理每日明細**
   - 將每筆花費拆成獨立列。
   - 每列至少包含：日期、項目、金額、類別。
   - 若使用者未提供類別，根據項目名稱推定最合理的類別；若無法判定，標為「其他」。

3. **統一類別名稱**
   - 將相近類別合併為一致名稱，例如：
     - 餐飲、吃飯、外食 → 「餐飲」
     - 交通、車資、捷運、公車 → 「交通」
     - 購物、日用品、雜貨 → 「購物／日用品」
   - 若使用者已有固定分類，優先沿用使用者的分類。

4. **建立每日表格**
   - 以日期分組，列出當日所有花費。
   - 若同一天有多筆，逐筆列出，不要合併成單筆，除非使用者要求。
   - 表格欄位建議為：日期｜項目｜類別｜金額。

5. **計算週末各類別合計**
   - 將整週所有花費依類別加總。
   - 輸出每個類別的合計金額。
   - 同時提供整週總花費。
   - 若使用者明確指定「週末」只看週六、週日，則只對週六與週日資料做類別合計；否則預設為「一週結算」的類別合計。

6. **檢查數字一致性**
   - 確認各類別合計加總後等於總花費。
   - 若有四捨五入或格式化，保留一致的小數位數。

# 輸出格式
## 1. 每日花費表
使用表格呈現，例如：

| 日期 | 項目 | 類別 | 金額 |
|---|---|---:|---:|
| 週一 | 早餐 | 餐飲 | 60 |
| 週一 | 捷運 | 交通 | 30 |

## 2. 週末／週結類別合計
使用另一個表格呈現，例如：

| 類別 | 合計 |
|---|---:|
| 餐飲 | 420 |
| 交通 | 180 |
| 購物／日用品 | 250 |
| 其他 | 50 |
| 總計 | 900 |

# 注意事項
- 不要自行捏造不存在的花費。
- 若資料缺少日期、金額或項目，先標示缺漏，再依可用資訊整理。
- 若同一筆支出可能屬於多個類別，選擇最主要的一個類別，必要時在備註中說明。
- 若使用者要求特定分類規則，應以使用者規則為準。
