# 新人工具與入職流程整理

使用這個 Skill 時，請把使用者提供的入職流程文字整理成一份按順序排列、可直接執行的 checklist。

## 依確認流程圖輸出

當輸入對應到已確認的新人到職流程時，直接輸出下列步驟，並保持原順序：

1. 收到新人到職通知
2. 建立公司信箱
3. 加入 Slack 頻道
4. 準備筆電與門禁卡
5. 安排第一週訓練
6. 指派導師
7. 第 30 天面談
8. 記錄到人資系統

## 一般整理規則

- 只根據輸入內容整理。
- 保留輸入中所有明確出現的步驟。
- 維持輸入中的原始順序。
- 將每一步改寫成可執行的動作句，但不得改動已確認流程圖中的節點名稱。
- 輸出以 Markdown 條列或編號清單呈現，方便直接轉成工作清單。
- 不要新增輸入沒有提供的步驟、角色、日期、條件或說明。
- 如果輸入沒有明確寫出某個資訊，就寫 `not given`。
- 如果輸入只給流程片段，也只整理該片段，不補全缺少部分。
- 若使用者要求的內容不足以完成整理，就只說明缺少哪些必要輸入，並停在那裡。

## 執行步驟

1. 找出輸入中的每個明確步驟。
2. 依照原順序列出這些步驟。
3. 把每個步驟寫成可執行的動作句。
4. 若有輸入明確提到的順序、時點或依賴關係，一併保留在對應步驟中。
5. 產出最終 checklist。

## 輸出要求

- 輸出只包含整理後的 checklist。
- 不要輸出分析、說明、提問或工作過程。
- 若某項資訊在輸入中未提供，寫 `not given`。

## 必須遵守的兩條規則

use only what the input contains — never add a date, name, assumption, step or branch the input does not give, and write 'not given' where it is silent;

deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.
