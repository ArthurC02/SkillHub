---

## 處理步驟

1. 從訂購訊息中擷取出貨日期，以及各品項的數量。只接受以下品項與固定單價：
   - 蜂蜜 250ml：每瓶 180 元
   - 蜂蜜 500ml：每瓶 320 元
   - 蜂蠟蠟燭：每支 90 元
2. 檢查日期是否明確且在日曆上存在。若未提供日期、日期格式無法判讀，或日期不存在，列出問題並請使用者確認；不要自行補上今天或其他日期。未確認前，不要出具已完成的正式出貨單。
3. 檢查每個品項的數量：
   - 數量必須明確且為非負數；負數、不完整或無法判讀的數量都要指出並請使用者確認。
   - 若同一品項在訊息不同處出現不同數量，視為矛盾。列出該品項及所有互相衝突的數字，請使用者確認；不要挑選其中一個，也不要自行相加或平均。
   - 若同一品項重複出現但數量相同，不要擅自判定是重複記載或兩筆訂購；請指出並確認應如何處理。
4. 對缺少數量、無法對應到上述品項，或品項名稱／容量不明確的內容，逐項提出澄清問題。不要將其他蜂蜜容量或商品套用成已知品項。
5. 只有在某品項的數量明確、有效且沒有矛盾時，才計算該品項小計（數量 × 單價）。只有所有訂購品項的數量都已釐清時，才計算並標示訂單總額。若有未解決的數量問題，明確說明總額尚不能計算；可以列出不受該問題影響的已確認小計，但不可把它稱為訂單總額。
6. 日期問題不影響品項金額的算術：若數量都已確認，可列出已確認金額，同時標明出貨日期待確認，且不要把文件呈現為已完成的出貨單。
7. 以繁體中文回覆。資料完整時使用以下格式：

   **出貨單**
   - 出貨日期：YYYY-MM-DD（使用原訊息中可確認的日期）

   | 品項 | 數量 | 單價 | 小計 |
   |---|---:|---:|---:|
   | 蜂蜜 250ml | … 瓶 | 180 元 | … 元 |
   | 蜂蜜 500ml | … 瓶 | 320 元 | … 元 |
   | 蜂蠟蠟燭 | … 支 | 90 元 | … 元 |
   | **總額** |  |  | **… 元** |

   只列出有訂購的品項。資料有問題時，先簡要整理已能確認的內容，再列出具體矛盾或缺漏，以及需要使用者確認的問題；不得填入猜測值或計算依賴未確認數量的總額。
