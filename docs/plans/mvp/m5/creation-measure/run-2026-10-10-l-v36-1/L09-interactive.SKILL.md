# 陶藝工作室 Instagram 活動貼文

依序處理使用者貼上的活動資訊，直接產出貼文，不先詢問或等待補充。

1. 從輸入中辨認活動名稱、日期（含星期）、時間、地點、費用、報名截止日。將每個已提供的值連同其中的字詞、數字、標點、空格與符號原樣保留；不要改寫、校正、換算或推算。不要加入輸入未提供的活動事實。
2. 若資訊另含其他活動事實，撰寫時也不得改變其意思或捏造補充。以繁體中文寫一則簡短、輕鬆親切、適合 Instagram 閱讀的宣傳貼文；可加不構成新事實的親切引言或報名提醒。將六項指定資訊清楚列出，使用易讀的分行與標籤，不要把硬事實改寫成另一種說法。
3. 若任一指定資訊沒有提供，在貼文相應欄位標示「未提供」，不要自行填入或把可由已知資料直接得出的值標成未提供。缺少未被要求的名稱、標籤或日期，不得因此停下撰寫。若輸入內同一事項有互相矛盾的值，逐一指出衝突的原文值，請提出請求的人確認；不選擇其中一個，也不使用依賴衝突資訊的結果。仍要交付可用貼文，在該欄標出待確認的空白，不要把已提供的值描述成未提供。
4. 將完整回答寫入工作目錄中的 `answer.txt`：先放可直接使用的貼文；貼文後如本次請求提到 Skill 無法執行的外部動作，逐項用一行說明該動作、清楚說明本 Skill 無法代做，並指出由提出請求的人或請求中指定負責的人執行。這是對每次請求所提外部動作的通則，不要預先列出本次未提到的動作。
5. 對每項實際提供的指定資訊，各以一個 `--require` 參數附上該值的原文，執行 `python scripts/check_output.py answer.txt --require "<活動名稱原文>" --require "<日期原文>" --require "<時間原文>" --require "<地點原文>" --require "<費用原文>" --require "<報名截止日原文>"`。實際執行時，把尖括號及其內容換成輸入中的原文，並對每個值正確加上 shell 引號；未提供的欄位不要求該不存在的值。若檢查未印出 `OK`，修正 `answer.txt` 並重跑檢查，直到印出 `OK`。最後只輸出 `answer.txt` 的內容。
