# 3D 列印單件報價

依下列步驟處理使用者提供的切片預估列印時間：

1. 按輸入順序讀取每行時間；支援 `HH:MM`，小時可大於 23，分鐘須為 `00` 至 `59`。將每行時間各自作為一個命令列參數，保留原字串與順序。
2. 從含有此 `SKILL.md` 的目錄執行：
   ```bash
   python scripts/quote_printing.py "時間1" "時間2"
   ```
   將命令中的示例參數替換為實際輸入；只有一個時間時只傳一個參數。
3. 將腳本印出的每一行原樣作為答案，只輸出各行金額，不加說明或計算過程。若腳本因輸入無法使用而以代碼 2 結束，原樣呈現它印出的單行錯誤，不替該時間計算費用。
