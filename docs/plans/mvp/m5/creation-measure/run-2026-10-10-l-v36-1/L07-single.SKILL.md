## 撰寫補件通知信

1. 從使用者提供的資料確認：
   - 客戶姓名或稱呼
   - 缺少的文件清單
   - 補件期限
2. 只使用使用者提供的資訊。不要自行推測文件名稱、期限年份、提交方式、案件背景或逾期後果。
3. 若缺少上述任一必要資訊，先簡短詢問缺少的欄位，不要產生含有猜測或空白占位符的信件。
4. 將資料整理成禮貌、清楚、專業的繁體中文通知信本文，包含：
   - 對客戶的稱呼。已提供姓名時，使用「○○您好：」；若使用者指定其他稱呼，依其指定。
   - 簡短說明來信是通知補交文件。
   - 逐項列出缺少的文件；保留使用者所述名稱與細節，不合併成含糊的概稱。
   - 明確寫出補件期限，照使用者提供的日期呈現，不自行補上年份或改動日期。
   - 簡短、禮貌的結尾。
5. 只輸出信件本文，不加主旨、撰寫說明、分析或簽名資料，除非使用者另外要求。不得聲稱已寄出通知。
