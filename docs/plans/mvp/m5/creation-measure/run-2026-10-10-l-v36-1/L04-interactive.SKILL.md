# 冷氣清洗報價

使用者提供一次或多次清洗的台數及加急狀態時，依已確認價目計算各次明細與合計。只準備報價內容；不可聲稱已寄送、發布、預約、排程或執行其他外部操作。

## 步驟

1. 從使用者訊息逐次整理分離式台數、窗型台數及加急狀態。保留提供的事實，不增添或改寫事實；不同次清洗分開計價，不跨次合併判斷折扣。
2. 未標示是否加急時，按不加急處理；加急比例未另行提供時，採用 20%。不得為取得這些設定而停下來追問。若使用者明確提供不同加急比例，將它交給腳本計算。
3. 將每次清洗依序編成一個 `--job` 參數，格式為 `分離式台數,窗型台數,加急狀態`；加急狀態用 `yes` 或 `no`，例如 `2,1,yes`。未提供某項台數時，在對應位置留空，例如 `,1,no`；省略第三欄或留空代表未標示加急。每次清洗各用一個 `--job`，不要把不同次清洗合併。從本 Skill 目錄執行，例如：

   ```sh
   python scripts/quote.py --job '2,0,no' --job '2,1,yes' --job '0,1,yes'
   ```

   如使用者提供了另一個整數加急百分比，加上 `--rush-percent 百分比`；否則不提供此參數，讓腳本採用 20% 預設值。
4. 把腳本輸出作為各次清洗明細及合計的計算結果。逐字複製腳本中每一行說明所採用預設值的文字，並將輸出整理成使用者可直接使用的報價內容。金額以新台幣整數元表示。
5. 若台數缺漏，保留腳本標示的「未提供」，附上可填寫的台數格式；不要計算依賴缺漏台數的折扣或總價。若輸入有負台數、無法使用的數值，或同一項目出現互相矛盾的值（包括後文改動前文的數值），指出該值並請提出請求的人確認；不得計算依賴該值的總價。只指出需要確認的問題，不追問其他事項。其餘資料仍可用時，照常交付不依賴該值的報價明細。若資料不足以填入台數，可提供此格式，空格明確標示「未提供」：`分離式：___ 台；窗型：___ 台；加急：___`。
6. 若要求的限制無法與必須呈現的資料同時滿足，遵守硬性限制，並用一行說明省略了什麼。交付完整報價內容，不以計畫、問題或等待確認作結。若本次請求另外提及寄送、發布、預約、排程或其他外部操作，最後逐項列出該操作，明說本代理不能代為執行，並指出由誰負責（提出請求的人，或請求中指定的負責人）。
