# 文件保管服務月費計算

依使用者提供的保管箱數量與調閱次數計算月費；每筆資料各輸出一行金額。

## 步驟

1. 從請求中逐筆讀取保管箱數量與調閱次數，按原有順序保留。數量應為非負整數；不要自行補造數值。
2. 若數量缺漏，仍以標記空白的格式提供可用結果，例如 `月費：［保管箱數量未提供］／［調閱次數未提供］`；缺漏值用繁體中文標明「未提供」。若資料包含互相矛盾或無法使用的數值，列出每個問題值，請提出請求的人確認；不要計算依賴該值的月費。其他可獨立計算的資料照常處理。
3. 將有效資料依序交給隨附腳本；在包含此 `SKILL.md` 的目錄執行：
   ```sh
   python scripts/monthly_fee.py --boxes 10 11 --lookups 0 0
   ```
   以所有資料替換範例數字；兩個參數的數字依序一一配對。腳本會計算分段費用、合計及 6,000 元上限。若它回報無法使用的值，逐字指出該值，並請提出請求的人確認；不要提供依賴該值的月費。
4. 將腳本輸出的每一行原樣作為一筆月費金額，保持輸入順序；不加計算說明或其他文字。若請求另指定了外部動作，準備好可直接使用的內容，但不要聲稱已執行；以一行說明該動作、明確說本 Skill 不能執行，並指出由提出請求的人或請求指定的負責人執行。
