# 證照考前簡訊

依以下步驟處理使用者貼上的考試資訊，並在同一則回覆交付完整草稿。

1. 擷取輸入中提供的考試日期、報到時間、考場地點、應攜物品，以及交通、停車、置物、午餐、規定和其他提醒。只用輸入中的事實；逐字保留每項事實的內容，不自行補充、查證或改寫成不同事實。
2. 檢查同一項資訊是否有互相矛盾的值，包括後文更正前文的情形。逐項指出衝突值，請提出請求的人確認；不採用任一衝突值，也不寫出依賴該值的內容。仍立即交付草稿，將不能確定的必要欄位標為「未提供」，並在草稿中以「［請確認：項目］」標示衝突，不要以問題結尾。不得把任何已提供事實標為待補。
3. 一次完成，不等待補充資料。未提供的必要資訊標為「未提供」，並在可直接使用的簡訊草稿中以「［未提供：項目］」作為醒目的空格；缺少非必要姓名、標籤或日期不得阻止草擬。不得把可由已知資訊確定的值標為未提供，也不得捏造缺漏事實。
4. 撰寫通知本文：最多 3 句，以「。」「！」「？」計句，並原樣保留輸入提供的考試日期、報到時間及考場地點；明確提醒攜帶身分證和准考證。若輸入未提供其中某項，標為「未提供」並放入醒目空格，不要自行填值。以繁體中文和自然、簡潔的簡訊語氣撰寫。
5. 在本文之後另起一行，以一句話誠實交代哪些資訊被合併、哪些被捨棄；本文保留或合併的資訊不可說成已捨棄，不得漏報確實捨棄的資訊。盡量保留其他實用資訊，可合併相關項目；必要時為滿足句數限制而取捨。若沒有合併或捨棄，明確寫「未捨棄或合併其他資訊」。
6. 將完整回覆寫入檔案，內容依序為通知本文、資訊處理說明，最後依請求中提到的每項外部動作各加一行：明確說明此 Skill 無法執行該動作，並指出須由提出請求的人或請求指定的負責人完成；不可聲稱已執行。若請求沒有提到外部動作，不加此類行。因本文至多 3 句，而說明與動作行也會出現在檔案中，撰寫時讓完整回覆總句數不超過 3 句；動作行使用清楚的陳述語句但不加句末標點。對每項已提供的必備事實各加一個 `--require "事實原文"` 參數，執行 `python scripts/check_output.py 回覆檔案 --max-sentences 3 --require "考試日期原文" --require "報到時間原文" --require "考場地點原文" --require "身分證" --require "准考證"`，並按需加入其他已提供且必須出現的事實之 `--require` 參數；依檢查結果修改檔案並重跑，直到輸出 `OK`。只回覆檔案內容，不附加其他文字。

對此類請求，只準備可供使用的通知文字；不發送簡訊、不登入、不張貼、不排程、不連網，也不修改任何系統。
