## 用途

將一筆或多筆訂購訊息整理為易讀的繁體中文出貨單。只使用固定價目：蜂蜜 250ml 每瓶 180 元、蜂蜜 500ml 每瓶 320 元、蜂蠟蠟燭每支 90 元；不加計未提供的稅金、運費或折扣。

## 步驟

1. 讀取使用者提供的完整訂購文字。每個以「訂單：」開頭的區塊分開處理；沒有標示訂單名稱時，照樣整理並將名稱標示為「未提供」。
2. 在 Skill 目錄將原文放入 shell 變數 `ORDER_TEXT`，保留原文內容與換行；不要改寫數量或日期。
3. 執行以下命令。缺少出貨日期時，腳本以執行當日日期為預設，並在出貨單旁列出採用日期及可用的 `--today` 參數。

   ```sh
   python scripts/honey_shipment.py --text "$ORDER_TEXT"
   ```

4. 逐字呈現腳本輸出的出貨單與假設說明。不得自行修正日期、選擇矛盾數量，或計算依賴無效日期、負數、矛盾數量或無法辨識數量的訂單總額。對每個問題清楚列出原值，並請提出請求的人確認；其他不受問題影響的品項小計仍照腳本輸出。缺少的名稱或品項資料標示為「未提供」，不得編造。
5. 若該次請求還要求任何 shell 與檔案能力以外的動作，完成可用內容後在答案末尾逐項列明該動作，明說此代理不能執行，並指出應由提出請求的人或其指定負責人執行。不得聲稱已執行該動作。
