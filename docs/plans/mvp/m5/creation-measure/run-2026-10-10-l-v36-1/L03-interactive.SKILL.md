# 活動外燴報價整理

將使用者提供的訂餐訊息整理成繁體中文的新臺幣報價。只根據訊息抽取資訊；不查外部資料、不猜價格、不加稅或推測未提到的費用。

## 步驟

1. 閱讀訂餐訊息，辨識每個品項、明示的數量和單價。把口語數量轉成對應數值；不改動使用者給的事實。新臺幣是報價幣別。
2. 將明確由客戶直接支付給場地方的場地清潔費分開，作為不列入我方報價的費用。其他列出的品項或費用都納入我方報價。
3. 對每個可計價品項計算數量乘單價。若單價未提供，保留品項與數量，將單價和小計標示為「待確認」，不把它納入目前可計算的總額。清潔費不納入總額。
4. 對已辨識的項目執行下列命令，從本 SKILL.md 所在目錄執行。每個 `--item` 的格式為 `品項名稱|數量|單價`；單價未知時用 `?`。每個 `--excluded` 的格式為 `費用名稱|金額`。依訊息加入所有一般品項；清潔費只在符合步驟 2 時加入 `--excluded`。例如：

   ```bash
   python scripts/quote_totals.py --item '迷你漢堡|24|85' --item '水果盒|10|?' --excluded '場地清潔費|900'
   ```

   將腳本輸出的表格與總額作為報價內容；逐字保留它輸出的總額狀態與數字。可計算總額若有任何待確認單價，須標為暫估。清潔費須註明由客戶直接支付給場地方、不列入我方報價。
5. 交付完整報價表，至少包含品項、數量、單價、小計及新臺幣總額，並清楚區分待確認品項與不列入報價的費用。若訊息本身缺少資料，提供可用的報價格式並把缺少的值標為「未提供」；不因此停止整理。若某個值無法成立、同一事項出現互相矛盾的值，列明該值並請提出需求的人確認；不計算依賴該值的總額。即使有待確認事項，也交付目前可完成的報價，不以問題或後續承諾作結。

若需求同時要求彼此無法兼顧的內容，保留明確的硬性限制，並用一行說明因此省略的內容。任何執行此類工作流程要求的動作（例如登入、傳送、發布或排程），本 Skill 只能準備可直接使用的內容，不能代為執行；在答案末尾各用一行說明該動作無法由本 Skill 執行，並指出須由提出需求的人或其指定負責人執行。
