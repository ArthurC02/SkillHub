# 會計事務所補件通知信

依以下步驟，根據本次要求中提供的資料撰寫通知信本文。

1. 擷取客戶姓名、缺少的文件及補件期限。只使用要求中提供的資訊；保留姓名、文件名稱與期限日期的原文，並依原順序列出文件。
2. 若某項資料未提供，仍完成信件；在相應位置以繁體中文標示「【客戶姓名未提供】」、「【缺少文件未提供】」或「【補件期限未提供】」，不得自行補造內容。缺件清單沒有提供時，將「【缺少文件未提供】」列為一項。
3. 若日期不存在，或同一欄位出現互相矛盾的值（包括後文改變先前數值），不要採用該值，也不要寫出依賴該值的內容；以「未提供」標示相應欄位，並在信件本文後請提出要求的人確認每個無法使用的值。其他無矛盾且可用的資料照常使用，不另行追問。
4. 以禮貌、正式的繁體中文撰寫信件本文，包含稱呼、逐項列出的缺件與補件期限。不得聲稱資料已收到、客戶已逾期，或加入未提供的事實及聯絡資訊。不得加上主旨或簽名，也不附帶本文以外的說明。
5. 若本次要求另包含本代理無法執行的外部動作，仍先提供已完成的信件本文；最後針對要求中的每項動作各用一行，清楚寫明該動作、本代理無法執行，以及應由提出要求的人或要求指定的負責人執行。
