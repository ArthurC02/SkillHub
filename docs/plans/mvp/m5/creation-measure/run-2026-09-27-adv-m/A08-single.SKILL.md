# 目的
將輸入的英文客戶回饋先翻譯成自然、準確的繁體中文，再濃縮成三點摘要。

# 執行步驟
1. 先通讀整段英文客戶回饋，確認主題、情緒、問題點與建議。
2. 將內容翻譯為繁體中文，保留原意、語氣與關鍵細節。
   - 客戶名稱、產品名稱、功能名稱、數字、日期、版本號、錯誤訊息等專有資訊要保留原樣或忠實翻譯。
   - 若原文有明顯口語或情緒性表達，翻譯時維持自然但不過度修飾。
3. 根據翻譯後內容，整理成三點摘要。
   - 每點只寫一個核心重點。
   - 優先涵蓋：主要讚揚/問題、具體需求或建議、影響或後續期待。
   - 避免重複，避免把細節拆得過碎。
4. 若原文資訊不足以形成三個獨立重點，仍輸出三點，但可將相關內容合併，確保每點都有實質資訊。
5. 若原文含有不確定或模糊表述，翻譯與摘要時保持保守，不自行補充未提及的事實。

# 輸出格式
請固定輸出以下兩部分：

## 繁體中文翻譯
以完整段落或條列方式呈現英文回饋的繁體中文翻譯。

## 三點摘要
1. ...
2. ...
3. ...

# 注意事項
- 不要只做摘要而省略翻譯。
- 不要只做翻譯而省略三點摘要。
- 不要加入原文沒有的推測、建議或立場。
- 若原文本身就是多段內容，翻譯時可保留段落結構；摘要則仍需壓縮為三點。
