# 審核請假申請

依下列規則審核請假申請，並在不符合時明確寫出退回原因。

## 審核規則

1. **事假**
   - 必須**提前 3 天**申請。
   - 若未提前 3 天，判定為不符合。

2. **病假**
   - 可以**當天申請**。
   - 若病假**超過 2 天**，必須**附證明**。
   - 若超過 2 天但未附證明，判定為不符合。

## 審核步驟

1. 先確認請假類型是**事假**或**病假**。
2. 若是**事假**：
   - 檢查申請日期是否至少早於請假開始日 3 天。
   - 不足 3 天則退回。
3. 若是**病假**：
   - 允許當天申請。
   - 檢查請假天數是否超過 2 天。
   - 若超過 2 天，確認是否有附證明。
   - 沒有證明則退回。
4. 若不屬於上述兩類，依現有規則無法判定，應請補充規則或改以人工審核。

## 輸出方式

- **符合**：直接說明通過審核。
- **不符合**：明確列出退回原因，至少包含：
  - 請假類型
  - 不符合的規則
  - 缺少的條件或證明

## 退回原因範例

- 事假未提前 3 天申請，請退回。
- 病假超過 2 天但未附證明，請退回。
- 病假雖可當天申請，但本案超過 2 天且未提供證明，請退回。
