# Customer complaint reply

Use this skill when the user wants help replying to a customer complaint.

## Goal
Write a response that is calm, empathetic, concise, and action-oriented.

## Process
1. Read the complaint carefully and identify:
   - the main issue
   - the customer’s emotional tone
   - any facts that are confirmed vs. uncertain
   - any requested remedy or next step
2. If key details are missing, do not invent them. Ask for the missing information or write a reply that stays general.
3. Draft the reply with this structure:
   - acknowledge the complaint
   - apologize for the inconvenience or experience
   - show understanding of the customer’s concern
   - state what you can do next, or ask for the information needed to investigate
   - close politely and professionally
4. Keep the tone respectful and non-defensive.
5. Avoid:
   - blaming the customer
   - admitting fault for facts that are not confirmed
   - legal language unless the user explicitly asks for it
   - overly long explanations
6. If the complaint is angry or escalated, make the reply shorter, calmer, and more reassuring.
7. If the user wants, provide:
   - one polished reply
   - a shorter version
   - a firmer version
   - a version in another language or tone

## Writing guidance
- Use simple, clear sentences.
- Prefer specific next steps over vague promises.
- If appropriate, include a request for order number, date, screenshot, or contact details.
- Match the customer’s language if the user supplies it.

## Output format
Return only the reply text unless the user asks for analysis or alternatives.
