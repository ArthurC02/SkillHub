# 自我介紹撰寫流程

## 1. 先確認用途與語氣
在開始寫之前，先判斷這篇自我介紹要用在哪裡，因為不同情境需要不同長度與語氣。若使用者沒有說明，先詢問以下重點：
- 使用情境：面試、課堂報告、社群平台、活動報名、履歷、網站關於我
- 目標讀者：主管、老師、同學、一般大眾、客戶
- 語氣：正式、自然、親切、專業、活潑
- 長度：短版 50–100 字、中版 150–300 字、長版 300 字以上
- 語言：繁體中文、簡體中文、英文或雙語

## 2. 蒐集必要內容
若使用者尚未提供資料，請引導他補充以下資訊：
- 姓名或稱呼
- 目前身分：學生、上班族、自由工作者、轉職者等
- 所在領域或主修
- 重要經歷、專長、成就
- 個人特質或優勢
- 興趣、價值觀、目標
- 想讓讀者記住的重點

若資訊不足，先用最少問題補齊，不要一次問太多。

## 3. 組織內容結構
依情境選擇合適結構：

### 通用版
1. 開頭：姓名與身分
2. 主體：背景、專長、經歷
3. 補充：個人特質、興趣或價值觀
4. 結尾：目標、期待或聯絡意圖

### 面試版
1. 自我稱呼與目前背景
2. 相關經歷與能力
3. 與應徵職位相關的優勢
4. 對未來的期待

### 社群/網站版
1. 一句話定位自己
2. 專長或工作內容
3. 個人特色或興趣
4. 行動呼籲或聯絡方式

## 4. 寫作原則
- 內容要真實，不要捏造經歷、學歷或成就。
- 用具體描述取代空泛形容，例如寫「曾負責社群經營，三個月內提升互動率 20%」，不要只寫「很有能力」。
- 避免過度自誇，保持自然、清楚、可信。
- 依情境調整第一人稱與第三人稱。
- 若使用者提供的資訊很少，寫成通用且安全的版本，不補編不存在的細節。

## 5. 產出方式
先根據已知資訊直接寫出一版完整自我介紹；若資訊不足，先提出最少必要問題，再等待補充。

若使用者要求多版本，提供例如：
- 正式版
- 親切版
- 精簡版
- 面試版

## 6. 品質檢查
完成後檢查：
- 是否符合指定情境與長度
- 是否有明確的開頭、主體、結尾
- 是否避免空話與過度誇飾
- 是否保留使用者提供的關鍵資訊
- 是否語氣一致、通順自然

## 7. 若資訊不足時的回覆方式
如果無法直接完成，請用簡短問題引導使用者提供資料，例如：
- 你想把自我介紹用在哪個場合？
- 你希望語氣偏正式還是親切？
- 你有哪些經歷、專長或興趣想放進去？

在取得資訊後，再寫出完整版本。
