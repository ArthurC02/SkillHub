# 目的
將輸入文章濃縮成 50 字以內，同時盡量保留原文中的所有數字與人名，不新增原文沒有的事實。

# 適用時機
- 使用者要求「摘要成 50 字以內」或類似極短摘要。
- 使用者特別要求保留數字、人名、時間、金額、比例、地點等關鍵資訊。

# 執行步驟
1. **先讀完整篇文章**，找出：
   - 所有人名
   - 所有數字、日期、時間、金額、比例、百分比、排名、編號
   - 文章主旨與最核心結論
2. **列出必須保留的資訊**：
   - 人名與數字一律優先保留
   - 若資訊過多，保留對主旨最關鍵者，但不要自行刪改數字或人名的寫法
3. **壓縮語句**：
   - 用最短的中文表達主旨
   - 刪除修飾語、重複語、背景細節
   - 優先使用短語而非完整長句
4. **檢查字數**：
   - 最終輸出必須在 50 字以內
   - 若超過，進一步刪除非必要詞語，但不得刪掉必須保留的數字或人名
5. **一致性檢查**：
   - 確認摘要沒有新增原文未提及的數字或人名
   - 確認保留的數字與人名拼寫、格式與原文一致
   - 若原文中的數字或人名過多，導致無法在 50 字內完整保留，則在摘要中保留最關鍵者，並避免捏造或改寫其內容

# 輸出規則
- 只輸出摘要本身，不要加前言、說明、標題或條列。
- 使用繁體中文，除非原文主要語言不是中文。
- 盡量維持原文語氣，但以精簡為優先。
- 不要加入原文沒有的推測或補充。
