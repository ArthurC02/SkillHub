# 目的
根據「這個月的出勤紀錄」計算每個人的加班時數，並找出加班時數超過 46 小時的人。

# 適用情境
- 使用者提供本月出勤紀錄、打卡資料、工時表或可計算加班的明細。
- 需要輸出每個人的加班總時數。
- 需要標示哪些人超過 46 小時。

# 執行步驟
1. **確認資料範圍**
   - 只使用「這個月」的紀錄。
   - 若資料跨月，先排除非本月資料，或請使用者確認要採計的月份。

2. **辨識每筆紀錄中的加班資訊**
   - 找出每個人的姓名或識別欄位。
   - 找出每筆紀錄中的加班時數欄位；若沒有直接提供加班時數，則依資料中的上下班時間、休息時間與規則計算。
   - 若資料格式不一致，先統一成同一種單位（建議以小時，保留到小數點後兩位或依原始資料精度）。

3. **彙總每個人的加班總時數**
   - 將同一人的本月所有加班時數加總。
   - 若同一人有多筆紀錄，全部納入。
   - 若資料中有缺漏或無法判定的紀錄，先標記為待確認，不要自行補值。

4. **判斷是否超過 46 小時**
   - 對每個人的加班總時數與 46 比較。
   - 大於 46 小時者標記為「超過 46 小時」。
   - 等於或小於 46 小時者不標超標。

5. **輸出結果**
   - 以清楚表格列出：
     - 姓名／員工編號
     - 本月加班總時數
     - 是否超過 46 小時
   - 對超標者加上明顯標記，例如「超標」或「⚠ 超過 46 小時」。

# 輸出格式建議
| 姓名 | 本月加班總時數 | 是否超過 46 小時 |
|---|---:|---|
| A | 48.5 | 是（超標） |
| B | 42.0 | 否 |

# 注意事項
- 不要把正常工時誤算成加班時數。
- 若使用者提供的是圖片、PDF 或掃描檔，先從內容中讀出姓名與加班數據，再進行加總。
- 若規則不明確（例如加班是否四捨五入、是否扣除休息時間），先依資料中明示規則處理；沒有規則時，請先向使用者確認。
