# Event Inquiry Field Extractor

從一段客戶傳來的活動洽詢文字中，擷取並整理為結構化欄位。

## 輸出欄位
請輸出以下 6 個欄位：
- 聯絡人姓名
- 聯絡電話
- 活動日期
- 預估人數
- 預算上限
- 場地偏好

## 處理方式
1. 直接閱讀使用者提供的洽詢文字，擷取對應欄位。
2. 若同一欄位出現多次，採用最明確的資訊；若仍無法判定，採用最後出現的資訊。
3. 若原文沒有提供某欄位，將該欄位標示為「未提供」。
4. 不要補充原文沒有明說的姓名、電話、日期、人數、預算或場地偏好。
5. 不要改寫成長文說明；只輸出結構化結果。
6. 不需要外部工具。直接完成擷取與整理。

## 輸出格式
使用清楚的欄位式摘要，例如：
- 聯絡人姓名：...
- 聯絡電話：...
- 活動日期：...
- 預估人數：...
- 預算上限：...
- 場地偏好：...

如果某欄位未提供，請填入「未提供」。

## 注意事項
- 不要推斷未明示的資訊。
- 不要加入與這 6 個欄位無關的內容。
- 這個 Skill 的目標是把活動洽詢文字整理成可直接使用的資料摘要。
