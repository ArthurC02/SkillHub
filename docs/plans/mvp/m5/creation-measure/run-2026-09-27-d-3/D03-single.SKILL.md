# 目的
將活動洽詢訊息中的關鍵資訊整理成固定欄位，方便後續建檔、回覆或轉交。

# 適用情境
當輸入是一段客戶來訊、Email、聊天紀錄或備註文字，且需要抽取以下欄位時使用：
- 聯絡人姓名
- 聯絡電話
- 活動日期
- 預估人數
- 預算上限
- 場地偏好

# 處理原則
1. 只根據輸入文字抽取資訊，不要自行補寫、推測或編造。
2. 若同一欄位出現多個候選值，優先採用最明確、最新、或最完整的表述。
3. 若欄位未明確出現，填寫 `未提及`。
4. 若資訊有歧義但可從上下文合理判定，保留最保守的判讀；仍不確定時填 `未提及`。
5. 保留原文中的日期、金額、地點偏好等表述，不要自行換算成其他格式，除非原文已明確提供可直接整理的格式。
6. 不要輸出分析過程，只輸出整理後結果。

# 擷取步驟
1. 通讀整段訊息，先找出是否有明確的聯絡人姓名與電話。
2. 再找活動日期，注意可能是單一日期、日期區間、或相對日期描述。
3. 找預估人數，注意可能寫成「約 30 人」、「30-40 位」、「大概 50 位」等。
4. 找預算上限，注意可能寫成「預算 10 萬內」、「上限 20,000 元」、「希望控制在…以下」。
5. 找場地偏好，包含地區、室內/戶外、風格、設備需求、交通條件等明確偏好。
6. 若訊息中有多個聯絡方式或多個姓名，優先選擇與活動洽詢直接相關、最像主聯絡人的資訊。

# 輸出格式
請固定輸出為以下欄位，順序不可變：
- 聯絡人姓名
- 聯絡電話
- 活動日期
- 預估人數
- 預算上限
- 場地偏好

# 輸出範例
聯絡人姓名：王小明
聯絡電話：0912-345-678
活動日期：2026/05/12
預估人數：50 人
預算上限：10 萬元內
場地偏好：台北市、室內、可容納投影設備

# 缺值處理
若某欄位找不到，仍要保留欄位並填寫：
- 聯絡人姓名：未提及
- 聯絡電話：未提及
- 活動日期：未提及
- 預估人數：未提及
- 預算上限：未提及
- 場地偏好：未提及
