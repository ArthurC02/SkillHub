# 自助倉儲入倉資格審核

用這個 Skill 來審核申請人是否符合自助倉儲入倉資格，並輸出對應級別與處置。

## 輸入
請根據使用者提供的資料判斷以下三項：
- 信用分數
- 近一年逾期繳費次數
- 是否曾有毀損倉儲設施紀錄

## 判斷順序
1. 先檢查是否曾有毀損倉儲設施紀錄；一旦有，先輸出 D 級與拒絕承租，並註明此結果優先於其他條件。
2. 若沒有毀損紀錄，再依信用分數與近一年逾期繳費次數判斷。

## 規則
- 只要申請人曾有毀損倉儲設施紀錄，不論信用分數與逾期次數，一律列為 D 級，拒絕承租。
- 信用分數達 700 分以上（含 700），且近一年逾期繳費 0 次，列為 A 級，免押金。
- 信用分數達 700 分以上（含 700），但近一年逾期繳費 1 次以上，列為 B 級，押金為 1 個月租金。
- 信用分數未滿 700 分，列為 C 級，押金為 2 個月租金，且需要連帶保證人。

## 輸出要求
輸出時請直接給出：
- 級別：A、B、C 或 D
- 處置：免押金、押金為 1 個月租金、押金為 2 個月租金且需要連帶保證人，或拒絕承租

## 直接套用規則
- 若有毀損倉儲設施紀錄：輸出 D 級；處置為拒絕承租；並加註「毀損紀錄優先於其他條件」。
- 否則若信用分數 >= 700 且近一年逾期繳費次數 = 0：輸出 A 級；處置為免押金。
- 否則若信用分數 >= 700 且近一年逾期繳費次數 >= 1：輸出 B 級；處置為押金為 1 個月租金。
- 否則：輸出 C 級；處置為押金為 2 個月租金且需要連帶保證人。

## 注意事項
- 只根據使用者提供的資料判斷，不自行推測其他財務、法務或信用資訊。
- 若使用者同時提供多位申請人，請逐一列出每位申請人的級別與處置。
