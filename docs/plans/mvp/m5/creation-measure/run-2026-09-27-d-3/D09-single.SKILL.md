# 冷藏食材到貨驗收判定

依下列規則判定冷藏食材到貨驗收結果。此 Skill 只處理**冷藏食材**的到貨判定；若不是冷藏食材，先確認是否適用本規則。

## 輸入資訊
判定前先取得兩個資訊：
1. **到貨溫度**（°C）
2. **效期距到貨日的天數**

若資訊不完整，先補齊再判定。

## 判定順序
必須依以下順序判定：

### 1) 先看到貨溫度
- **若到貨溫度超過 7°C**（不含 7°C），一律判定為：**拒收退回**
- 此時**不需要再看效期**

### 2) 若到貨溫度在 7°C 以下或等於 7°C
再看效期距到貨日的天數：
- **超過 2 天**：判定為 **合格**
- **2 天以内（含 2 天）**：判定為 **警示**，並註記 **需優先當天用完**

## 判定規則整理
- **溫度 ≤ 7°C 且效期 > 2 天** → **合格**
- **溫度 ≤ 7°C 且效期 ≤ 2 天** → **警示（需優先當天用完）**
- **溫度 > 7°C** → **拒收退回**

## 輸出格式
回覆時請直接給出判定結果，必要時附上簡短原因：
- **合格**
- **警示：需優先當天用完**
- **拒收退回**

## 注意事項
- 「7°C 以下」在本規則中包含 **7°C**。
- 「超過 2 天」表示 **大於 2 天**。
- 「2 天以内」表示 **小於等於 2 天**。
- 若溫度不合格，效期條件不影響結果。
