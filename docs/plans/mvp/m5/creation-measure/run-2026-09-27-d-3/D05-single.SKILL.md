# 目的
撰寫一封保險理賠結果通知信，必須同時滿足以下格式限制：
- 一定要包含五項資訊：理賠案號、核定金額、核定日期、不服核定的申訴管道、申訴期限。
- 每一項資訊都要獨立成一句。
- 不可用逗號或頓號把兩項資訊塞進同一句。
- 整封信最多只能有 3 句話。

# 核心規則
1. 先確認是否已知五項資訊的具體內容。
2. 若五項資訊都已知，優先用最少句數完成。
3. 因為最多只能有 3 句話，但必須獨立呈現 5 項資訊，所以每一句可以包含多個短句；但每個短句只能表達一項資訊，且短句之間不得使用逗號或頓號。
4. 不要把兩項資訊寫在同一個短句中。
5. 不要加入與五項資訊無關的內容，避免超過 3 句。

# 寫作方式
- 以正式、清楚、通知式語氣撰寫。
- 每個資訊點都用完整句號結尾。
- 句與句之間可用句號分隔，或用換行分隔成不同句。
- 若需要在同一句內放入多個資訊點，必須以分號或句號分隔成獨立短句，且每個短句只放一項資訊。
- 不要使用條列式超過 3 點，因為條列項目通常會被視為超過 3 句的風險。

# 建議結構
可採用以下 3 句結構：
1. 第一句：說明理賠案號。
2. 第二句：說明核定金額與核定日期，但要拆成兩個獨立短句，不能用逗號或頓號連接。
3. 第三句：說明不服核定的申訴管道與申訴期限，但要拆成兩個獨立短句，不能用逗號或頓號連接。

# 產出檢查清單
在輸出前逐項確認：
- [ ] 有理賠案號。
- [ ] 有核定金額。
- [ ] 有核定日期。
- [ ] 有不服核定的申訴管道。
- [ ] 有申訴期限。
- [ ] 每項資訊都是獨立短句。
- [ ] 沒有用逗號或頓號把兩項資訊放進同一句。
- [ ] 全文不超過 3 句話。

# 若資訊不足
如果使用者沒有提供五項資訊中的某些內容，先列出缺少的項目並請使用者補齊，再撰寫通知信。不要自行編造理賠案號、金額、日期、申訴管道或期限。
