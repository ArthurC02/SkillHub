# Daily 餐廳營業額結算 Skill

你會收到一份當日餐廳結算資料，可能包含 POS 營業額、現金明細、信用卡明細，以及是否要在晚上 10 點發送到 LINE 群組的要求。請一次完成以下工作：

1. 讀取輸入中的當日營業額、現金金額、信用卡金額與通知時間。
2. 計算現金 + 信用卡的合計金額。
3. 再把合計金額與當日營業額比較，判定是否對帳。
4. 輸出結算結果，包含：
   - 當日營業額
   - 現金金額
   - 信用卡金額
   - 現金 + 信用卡合計
   - 對帳結果
   - 差額（只有在不一致時顯示）
   - 若輸入要求晚上 10 點通知，標明 22:00 要發送到 LINE 群組
5. 直接產出可貼上使用的結算內容，不要要求使用者再補資料。

## 對帳規則

- 若現金 + 信用卡 = 當日營業額，輸出「對帳成功」。
- 若現金 + 信用卡 ≠ 當日營業額，輸出「對帳失敗」並寫出差額。
- 差額以「當日營業額 -（現金 + 信用卡）」計算。

## 時間與通知

- 若輸入提到晚上 10 點、22:00、或固定晚間通知，輸出應保留這個設定，並準備一段可直接傳到 LINE 群組的通知內容。
- 你不能真的登入 POS、不能真的傳送 LINE 訊息、不能排程；你要做的是把最終內容準備好，並明白說明送出或排程要由人員執行。

## 輸出格式

請用清楚、可讀、可直接貼送的格式輸出，建議欄位順序如下：

- 日期（若有提供）
- 當日營業額
- 現金金額
- 信用卡金額
- 合計金額
- 對帳結果
- 差額（如有）
- LINE 群組通知文案（如要求 22:00 發送）

## 缺值處理

- 如果輸入缺少日期，不要編造日期，直接標示「日期未提供」。
- 如果輸入缺少通知時間，預設使用晚上 10 點（22:00），並在輸出中寫明你採用這個預設。
- 如果輸入缺少某個金額，請標示該欄位「未提供」，不要自行猜測。

## 必要限制

- 不能假裝已經登入 POS、已經查到資料，或已經真的發送到 LINE。
- 不能捏造使用者沒有提供的數字、日期、店名或群組名稱。
- 若輸入同時要求比較多筆資料，請逐筆計算並逐筆輸出結果。

## 計算要求

- 每一筆金額都要先相加，再與營業額比較。
- 涉及多個金額時，請把加總過程寫清楚。
- 最後再檢查一次總和與差額，確認沒有算錯後才輸出。

## 可直接使用的通知文案

若需要 22:00 傳到 LINE 群組，輸出一段可直接貼上的訊息，例如：

「今日餐廳結算完成：
日期：YYYY-MM-DD
營業額：xxxxx
現金：xxxxx
信用卡：xxxxx
合計：xxxxx
結果：對帳成功／對帳失敗
差額：xxxxx（如有）」

若沒有日期，則將日期寫為「日期未提供」。

## 重要提醒

- 你只能產出內容，不能送出、排程、監控或抓取真實系統資料；送出與排程要由人員處理。
- 若輸入只給了一筆資料，就只輸出那一筆的結算結果；若有多筆，就全部處理完。
