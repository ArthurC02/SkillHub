# 社團出席登記與統計

這個 Skill 用來把每次上課的簽到名單整理成一致格式，並在學期末計算每位學生的出席次數與出席率。

## 你要先確認的資料

在開始整理前，先確認是否已具備以下資訊：

1. **學生名單**
   - 學生姓名
   - 若有同名，請加上學號、班級或其他識別資訊

2. **每次上課的簽到資料**
   - 日期
   - 第幾次上課或課程週次
   - 簽到名單
   - 缺席、遲到、請假等狀態（若有）

3. **統計規則**
   - 出席是否只算「到場」
   - 遲到是否算出席
   - 請假是否排除在出席率分母之外
   - 缺席是否算入分母

如果規則不明確，先用以下預設：
- 到場 = 出席
- 遲到 = 出席
- 請假 = 不算出席，但仍算在總上課次數中
- 缺席 = 不出席，且算在總上課次數中

## 處理流程

### 1. 整理每次簽到紀錄

把每次上課資料整理成同一格式，至少包含：
- 日期
- 課次
- 學生姓名
- 狀態：出席 / 遲到 / 請假 / 缺席

若原始資料只有簽到名單，沒有缺席名單，則：
- 簽到名單中的學生標記為「出席」
- 學生名單中未出現者標記為「缺席」

若有請假或遲到資訊，依原始資料標記，不要自行推測。

### 2. 建立學生總表

以學生名單為基礎，建立每位學生的統計欄位：
- 姓名
- 出席次數
- 遲到次數
- 請假次數
- 缺席次數
- 總上課次數
- 出席率

### 3. 累計每次上課結果

對每一堂課逐筆更新統計：
- 出席 +1
- 遲到 +1（若規則視為出席，則同時計入出席次數）
- 請假 +1
- 缺席 +1
- 總上課次數 +1

若規則指定請假不計入分母，則在計算出席率時排除請假次數；否則請假也算入總上課次數。

### 4. 計算出席率

依統一規則計算：

- **若請假算入分母**：
  - 出席率 = 出席次數 ÷ 總上課次數 × 100%

- **若請假不算入分母**：
  - 出席率 = 出席次數 ÷（總上課次數 - 請假次數）× 100%

若分母為 0，出席率記為 0% 或標示為「無資料」，並說明原因。

### 5. 檢查資料一致性

在輸出前檢查：
- 是否有學生姓名拼寫不一致
- 是否有同名不同人未區分
- 是否有某次課程的簽到人數超過學生名單
- 是否有缺漏日期或課次
- 是否有重複簽到紀錄

若發現問題，先列出疑點，再進行統計，不要直接假設。

## 輸出格式

### A. 每次上課簽到表

每次課程輸出一張表，欄位建議如下：
- 日期
- 課次
- 姓名
- 狀態
- 備註

### B. 學期總表

每位學生輸出一列，欄位建議如下：
- 姓名
- 出席次數
- 遲到次數
- 請假次數
- 缺席次數
- 總上課次數
- 出席率

### C. 摘要說明

在總表前或後補上一段摘要：
- 本學期總共上課幾次
- 使用的出席率計算規則
- 是否有資料缺漏或異常

## 實作原則

- 保持學生姓名一致，不要自行改名
- 原始資料不完整時，先標示缺漏，不要補寫不存在的資訊
- 若同時收到多次簽到資料，先按日期排序再統計
- 若使用者要求特定格式，優先配合其格式，但仍保留完整統計欄位
- 若資料量很大，先分批整理，再合併總表

## 當資料不足時要怎麼做

如果缺少以下任一項，先向使用者確認：
- 學生名單
- 每次上課日期
- 簽到名單
- 出席率計算規則

如果使用者只提供部分資料，仍可先整理已知部分，並清楚標示尚缺哪些資料。
