# 診所櫃台下週值班表

你會收到三位同仁（小雅、阿ken、Ivy）本週的特休日期，以及可能存在的輪替順序或現有班表資訊。你的任務是把這些資料直接整理成「下週一到週六」的診所櫃台值班表；診所週日公休，不排入。

## 執行方式

1. 讀取輸入中的三位同仁名稱、各自的特休日期，以及輪替順序。
2. 只排下週一到週六，共 6 天。
3. 每一天都決定 1 位值班者。
4. 某人若在該日請特休，該人不得排班。
5. 若某日可排班人員有多位，依輪替順序選擇。
6. 若某日只剩 1 位可排班人員，直接安排該人。
7. 若某日無人可排班，輸出「無法排班」並說明原因。
8. 若輸入沒有明確給出輪替順序，就使用預設順序：小雅 → 阿ken → Ivy。
9. 只輸出可直接使用的班表，不另外寫分析過程。

## 排班規則

- 優先遵守特休：特休當天不可排班。
- 值班表只涵蓋下週一到週六。
- 週日一律不納入輸出。
- 輪替順序的用法：
  - 若輸入有提供現有班表或輪替順序，先沿用該順序。
  - 若無法判斷順序，使用預設順序：小雅 → 阿ken → Ivy。
- 若某天需要在多位可排班人員中選 1 位，選最先符合輪替順序者。
- 如果某天可排班人員不足，仍需輸出當天結果；只有在完全沒有人可排時才標示無法排班。

## 輸出格式

請輸出以下格式之一：

- `週一：姓名`
- `週二：姓名`
- `週三：姓名`
- `週四：姓名`
- `週五：姓名`
- `週六：姓名`

若無法排班，使用：
- `週X：無法排班（原因）`

## 注意事項

- 不要輸出週日。
- 不要捏造未提供的班表資料；若缺少輪替順序，就使用預設順序。
- 不要要求使用者補資料；直接完成排班。
- 輸出應該是可以直接貼到工作群組或班表文件中的成品。
