# 目的
根據本週收到的特休申請，為診所櫃台人員排出下週一到週六的值班表，並盡量避免與休假衝突、維持公平分配。

# 適用範圍
- 人員固定為：小雅、阿ken、Ivy。
- 排班區間為：下週一到週六；診所週日公休，不排班。
- 輸入包含：
  - 每位人員本週提出的特休日期
  - 班表規則或限制（例如：每天需要幾人、是否可連續上班、是否有固定班別）
- 若資訊不足，先整理缺口並提出需要補充的問題，不要自行猜測。

# 工作流程

## 1. 先整理輸入
把收到的資訊整理成三欄：
- 人員姓名
- 特休日期
- 其他限制或偏好

確認以下事項：
- 特休日期是否都落在排班週內
- 是否有日期格式不一致
- 是否有重複或衝突的申請
- 是否有未提供的必要規則，例如每天需要幾位櫃台人員

## 2. 建立排班基準
先列出下週一到週六的日期清單，作為排班骨架。

對每一天標記：
- 可排班人員：未請特休者
- 不可排班人員：當日請特休者

若某天可排班人數不足以滿足需求，先標示為缺口日，並回報需要人工決策。

## 3. 套用排班規則
依照提供的規則排班；若未提供明確規則，採用以下原則：
- 優先避開特休日期
- 盡量平均分配三人的班數
- 避免同一人連續過多天上班
- 若每天只需一人，優先讓當週已排班較少的人補位
- 若每天需多人，先排最少人數滿足需求，再補備援或輪替

若有固定班別或特殊限制，必須優先遵守。

## 4. 解衝突與補位
當某天可排班人員不足或分配不均時，依序處理：
1. 檢查是否有可調整的非必要偏好
2. 檢查是否可交換前後日期的班次
3. 若仍無法滿足，明確標示缺口並說明原因

不要把請特休的人排進當日班表。

## 5. 產出班表
輸出時請包含：
- 週次與日期範圍
- 每日值班人員
- 每位人員本週排班次數統計
- 與特休衝突的日期檢查結果
- 若有缺口，列出缺口日期與原因

建議格式：

| 日期 | 星期 | 值班人員 | 備註 |
|---|---|---|---|
| YYYY-MM-DD | 一 | 小雅 |  |

再附上統計：
- 小雅：X 班
- 阿ken：X 班
- Ivy：X 班

# 品質檢查
在完成前，逐項確認：
- 下週一到週六都有排到
- 週日沒有排班
- 沒有人被排到自己的特休日
- 排班數量盡量平均
- 若有缺口，已清楚標示而非隱藏

# 若資訊不足時的處理
如果缺少以下任一項，先詢問使用者，不要自行補齊：
- 下週的實際日期
- 每天需要幾位櫃台人員
- 是否有固定班別或不可排時段
- 三人的特休日期清單

# 輸出原則
- 以繁體中文回覆
- 先給結果，再給簡短說明
- 若有衝突或缺口，直接指出，不要粉飾
- 若可行，提供一版可直接貼到群組或表格的班表
