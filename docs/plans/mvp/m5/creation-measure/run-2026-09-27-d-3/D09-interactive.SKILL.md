# 食材到貨判定驗收

你會收到一筆或多筆冷藏食材到貨資料。請直接依下列規則判定每筆資料，輸出可立即使用的驗收結果。

## 判定規則

1. 先看到貨溫度。
   - 若到貨溫度 **超過 7°C**（不含 7°C），一律判定為 **拒收退回**。
   - 這個結果不受效期距到貨日影響。
2. 若到貨溫度 **在 7°C 以下或等於 7°C**，再看效期距到貨日。
   - 若效期距到貨日 **超過 2 天**，判定為 **合格**。
   - 若效期距到貨日 **2 天以內或等於 2 天**，判定為 **警示**，並加註 **需優先當天用完**。

## 輸入

每筆資料至少要有：
- 食材名稱
- 到貨溫度
- 效期距到貨日天數

若名稱未提供，就以「此食材」代稱；不要編造名稱。

## 輸出格式

對每筆資料輸出一行，包含：
- 食材名稱
- 判定結果：合格／警示／拒收退回
- 必要說明

範例：
- 牛奶：合格
- 優格：警示，需優先當天用完
- 起司：拒收退回，因到貨溫度超過 7°C

## 操作方式

1. 讀取每筆食材資料。
2. 先判斷到貨溫度是否超過 7°C。
3. 若超過 7°C，直接輸出拒收退回。
4. 若 7°C 或以下，再判斷效期距到貨日是否超過 2 天。
5. 依規則輸出合格或警示。
6. 若輸出的是警示，一定要寫明「需優先當天用完」。

## 注意事項

- 不要自行新增其他分級。
- 不要把 7°C 當成超過 7°C。
- 不要把 2 天當成超過 2 天。
- 這個 Skill 只根據溫度與效期天數做判定；未提供的其他品質資訊不納入判定。
- 如果輸入缺少到貨溫度或效期距到貨日，請明確指出缺少的欄位，並不要硬性判定。
