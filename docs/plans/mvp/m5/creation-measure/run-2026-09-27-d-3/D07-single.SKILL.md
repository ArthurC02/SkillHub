# 目的
將藥局回報的藥品資料整理成表格，並篩出「從今天起算 30 天內（含第 30 天）會過期」的藥品，供優先使用或退回。

# 適用時機
當輸入包含每筆藥品的：
- 品名
- 批號
- 效期
- 庫存數量

且需要做有效期限盤點、即期品提醒、優先使用/退回清單時，使用此 Skill。

# 處理原則
1. 以「今天」為基準日。
2. 將效期與今天比較，找出效期在今天起算 30 天內（含第 30 天）的藥品。
3. 若效期格式不明確，先嘗試判讀為常見日期格式；若仍無法判讀，標記為「效期格式不明，需確認」。
4. 若資料缺少品名、批號、效期或庫存數量，保留該筆資料並標記缺漏欄位，不要自行補值。
5. 不要推測藥品用途或法規要求；只根據日期與庫存資料整理。

# 操作步驟
1. 讀取所有藥品資料。
2. 逐筆確認欄位是否完整：
   - 品名
   - 批號
   - 效期
   - 庫存數量
3. 將效期轉成可比較的日期。
4. 計算每筆資料的效期距今天數。
5. 篩出距今天數介於 0 到 30 天之間的資料；若效期早於今天，也一併列入即期/逾期提醒區，並標示為「已過期」。
6. 依效期由近到遠排序；若效期相同，可再依品名排序。
7. 輸出成表格，至少包含以下欄位：
   - 品名
   - 批號
   - 效期
   - 庫存數量
   - 距今天數
   - 狀態（已過期／30天內即將過期／正常）
   - 建議（優先使用／退回／持續觀察）
8. 在表格下方加上一段簡短提醒，指出哪些品項應優先使用或退回。

# 狀態判定
- 效期 < 今天：已過期，建議退回或依院內流程處理。
- 今天 ≤ 效期 ≤ 今天 + 30 天：30天內即將過期，建議優先使用或先行調撥。
- 效期 > 今天 + 30 天：正常，持續觀察。

# 輸出格式
使用清楚的表格呈現，並保持欄位名稱一致。若有多筆即期品，請全部列出，不要只保留最早一筆。

# 注意事項
- 若使用者提供的是多行文字、CSV、Excel 轉貼內容或條列資料，都要先整理成一致欄位再判讀。
- 若日期格式含年/月/日以外的分隔符號，先轉換成標準日期再比較。
- 若同一品名有多個批號或不同效期，需分開列示，不可合併。
