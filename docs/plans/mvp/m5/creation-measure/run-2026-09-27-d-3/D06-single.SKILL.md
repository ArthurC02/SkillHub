# Daily 餐廳營業額結算

## 這個 Skill 能做什麼
- 協助整理每日打烊後的營業額結算流程。
- 核對 POS 匯出的當日營業額、現金明細、信用卡明細是否一致。
- 產出可直接傳送給老闆的結算摘要。

## 這個 Skill 不能直接保證做到的事
- 不能自行登入你沒有提供授權的 POS 後台。
- 不能自行在晚上 10 點定時執行，除非外部系統已經提供排程工具。
- 不能直接傳送到 LINE 群組，除非已提供可用的訊息發送工具與授權。

## 執行流程

### 1. 先確認當日結算所需資料
在開始前，確認以下資料是否齊全：
- 結算日期（通常是今天）
- POS 當日營業額報表
- 現金收款明細
- 信用卡收款明細
- 若有退款、折讓、作廢單、外送平台代收款，也要一併列入

如果缺少任何一項，先列出缺少項目，不要自行補數字。

### 2. 取得 POS 當日營業額
若環境中有可用的瀏覽器、自動化或檔案工具，依照既有授權登入 POS 後台，抓取當日報表。

若沒有可用工具或沒有登入權限，請改為：
- 要求使用者提供匯出的報表檔
- 或請使用者貼上當日營業額數字
- 或請使用者提供可讀取的截圖/CSV/PDF

抓取時至少記錄：
- 總營業額
- 現金金額
- 信用卡金額
- 退款/折讓/作廢金額
- 其他付款方式金額（如有）

### 3. 核對現金與信用卡明細
將 POS 報表與實際收款明細逐項比對：
- 現金實收是否等於 POS 現金欄位
- 信用卡請款是否等於 POS 信用卡欄位
- 若有退款或折讓，是否已從總額扣除
- 若有多種付款方式，是否全部加總後與總營業額一致

核對規則：
- 若完全一致，標記為「兜得起來」
- 若不一致，列出差額與可能原因
- 若資料不足，標記為「無法確認」並說明缺少哪些資料

### 4. 產出結算結果
輸出一份簡潔摘要，至少包含：
- 日期
- 總營業額
- 現金
- 信用卡
- 退款/折讓/作廢
- 核對結果
- 差額（若有）
- 備註（若有異常）

摘要要能直接貼到 LINE 群組。

### 5. 準備在晚上 10 點發送
如果外部環境有排程工具，則把「發送結算結果」這一步交給排程系統在晚上 10 點執行。

如果沒有排程工具，則不要假裝已經定時發送；改為在當下產出可發送內容，並提醒使用者需手動在 10 點前後送出。

### 6. 發送到 LINE 群組
只有在已具備可用的訊息發送工具、LINE 授權與群組目標時，才執行發送。

若沒有這些條件，請：
- 產出完整訊息內容
- 明確標示「需手動貼到 LINE 群組」
- 不要聲稱已成功送出

## 建議的輸出格式
```text
【每日結算】YYYY-MM-DD
總營業額：
現金：
信用卡：
退款/折讓/作廢：
核對結果：兜得起來 / 不一致 / 無法確認
差額：
備註：
```

## 異常處理
遇到以下情況時，先停止並回報：
- POS 後台無法登入
- 報表抓不到或格式異常
- 現金與信用卡明細缺漏
- 加總後仍無法對帳
- 發送工具或 LINE 權限不存在

回報時要清楚列出：
- 哪一步失敗
- 已取得哪些資料
- 還缺哪些資料
- 下一步需要人員提供什麼
