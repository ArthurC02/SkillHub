# 目的
將「自費醫材同意書」的公文式內容，改寫成病人容易理解的說明信，同時**完全保留**指定不可變更的資訊。

# 適用情境
- 原文是診所或醫療院所的自費醫材同意書。
- 需要把語氣改得較口語、清楚、親切，方便病人閱讀。
- 內容中包含以下資訊時，必須逐字保留，不可改寫、不可增刪、不可換算、不可改順序：
  - 醫材品名
  - 自費金額
  - 健保給付上限
  - 病人簽署期限

# 核心原則
1. **先辨識不可變更資訊，再改寫其他文字。**
2. **不可變更資訊必須原樣保留**，包含數字、單位、標點、全形半形、英文大小寫、括號內容、品名專有名詞。
3. **只改語氣，不改事實。** 不新增醫療效果、風險、保證、建議或法律效果。
4. **若原文資訊不完整或有歧義，先提出需要確認的地方，不要自行補寫。**

# 工作流程
## 1. 先抽出不可變更資訊
從原文中找出並記錄以下項目：
- 醫材品名
- 自費金額
- 健保給付上限
- 病人簽署期限

處理時要注意：
- 若同一項資訊在文中出現多次，全部都要一致保留。
- 若有中英文混寫、型號、規格、單位、貨幣符號、日期格式，全部視為不可變更的一部分。
- 不要把數字改成國字，也不要把國字改成數字。

## 2. 改寫成口語說明信
把原本較正式、制式、命令式的句子，改成：
- 直接對病人說明
- 句子較短
- 用詞清楚、白話
- 保留必要的醫療與行政資訊

可改寫的部分包括：
- 開頭稱呼與引言
- 說明目的的句子
- 程序說明
- 提醒病人閱讀與簽署的語句
- 結尾致意

## 3. 保持內容一致
改寫後仍需維持原意，尤其是：
- 這份文件是在說明自費醫材相關事項
- 病人需要了解內容後再決定是否簽署
- 任何期限、金額、品名、上限都不能被改動

## 4. 檢查不可變更資訊是否完全一致
輸出前逐項核對：
- 醫材品名是否一字不差
- 自費金額是否一字不差
- 健保給付上限是否一字不差
- 病人簽署期限是否一字不差

若發現改寫後有任何差異，必須修正到完全一致。

# 輸出規則
- 只輸出改寫後的說明信內容。
- 不要附加分析、註解、修改說明或比對表。
- 不要加上你自行推測的醫療內容。
- 若原文有標題，可保留但改成較親切的標題。
- 若原文有落款或院所資訊，除非使用者要求，通常可保留原樣。

# 風格建議
- 語氣親切、清楚、尊重病人。
- 避免過度法律化或官樣文章。
- 避免艱深術語；若必須保留專有名詞，則搭配簡單說明，但不得改動不可變更資訊本身。

# 例外處理
- 如果原文中找不到上述四類不可變更資訊，先回覆需要提供完整原文，不能直接改寫。
- 如果原文同時出現多組金額、期限或品名，且無法判斷哪一組才是要保留的內容，先請使用者確認，不要自行選擇。
- 如果原文包含明顯錯字，但錯字出現在不可變更資訊中，也不得自行更正。
