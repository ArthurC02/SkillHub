# 民宿連續住宿房價計算

依使用者提供的入住日與退房日，計算逐晚房價及總額。採用已確認的假設：週一至週五每晚新台幣 2,000 元；週六、週日每晚加價 50%，即新台幣 3,000 元；入住日計入，退房日不計入。只以週末為假日，不另計國定假日、特殊日期、季節價、稅費、折扣或其他費用。

## 步驟

1. 從輸入中取得入住日與退房日，轉為 `YYYY-MM-DD` 格式。若任一日期未提供，不要推測日期；交付可用範本，將日期空格標為「未提供」：
   - 入住日：未提供
   - 退房日：未提供
   - 逐晚明細：待提供日期後計算
   - 新台幣總額：待提供日期後計算
2. 檢查日期是否完整且合理。若日期格式錯誤，或退房日早於或等於入住日，指出輸入矛盾或無法計算，請使用者確認並更正；不要自行改日期或交付猜測的金額。
3. 在包含此 `SKILL.md` 的目錄執行下列命令，將日期換成使用者提供的日期：
   ```bash
   python scripts/calculate_stay.py --check-in YYYY-MM-DD --check-out YYYY-MM-DD
   ```
4. 將腳本輸出的逐晚日期、星期、房價明細與新台幣總額原樣呈現。若腳本以錯誤結束，依其單行訊息指出需要更正的輸入，不要自行計算或猜測結果。

## 輸出原則

- 按每一住宿晚的日期判定星期；退房日不列入晚數。
- 只呈現腳本算出的明細與總額，不增列未包含的費用或優惠。
- 缺少資訊時標示「未提供」，不編造事實；若無法計算，交付清楚標示的結果或範本，不以問題作結。
