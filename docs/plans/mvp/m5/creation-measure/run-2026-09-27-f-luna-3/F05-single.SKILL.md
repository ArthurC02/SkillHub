## 步驟

1. 從使用者提供的資料中確認案號，以及下一次開庭的日期和時間。這三項資訊都是通知本文的必要內容；不得自行猜測、補造或以未確認的資料代替。
2. 若案號、開庭日期或開庭時間有任何一項缺漏或不明確，先詢問使用者補充或確認；在取得資料前，不要產出看似完整的通知本文。
3. 將必要資訊寫入通知本文，並依需要納入其他使用者提供的資訊。可以合併相關資訊或省略不必要的細節，以符合簡訊長度。
4. 檢查通知本文的句數：最多 3 句，且必須清楚包含案號及下一次開庭日期與時間。以句號、問號或驚嘆號等句末標點判斷句子；避免用分行或標點拆分來規避上限。
5. 若有省略或合併使用者提供的其他資訊，在通知本文之外另附一句話，簡要說明哪些資訊被省略或合併。這句說明不算入通知本文的 3 句上限。若沒有省略或合併，不必加註說明。
6. 輸出時清楚分開「通知本文」與額外說明，避免讓額外說明被誤認為簡訊內容。保持語氣清楚、正式、精簡，不添加使用者未提供的事實。
