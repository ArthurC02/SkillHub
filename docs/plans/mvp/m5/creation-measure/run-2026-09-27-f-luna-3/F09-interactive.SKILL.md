# 畫廊開幕邀請文

依使用者提供的資料撰寫繁體中文、正式優雅且可直接使用的畫廊展覽開幕邀請文。只整理措辭，不查證外部資料，也不增添未提供的具體事實。

## 步驟

1. 從輸入擷取展覽名稱、展期起日、展期迄日、開幕茶會日期與時間、地點。保留原有字詞、數字、日期及地址；不得推算或改正。
2. 一次檢查必填事實是否齊全且前後一致。若有缺項，使用明確標示的空白欄位製作可用範本，並在相應欄位標示「未提供」，不可猜填。若資料互相矛盾或不可能，勿自行裁定；在輸出中列明衝突欄位與原始資料，說明需確認後才能定稿，不以有衝突的資料冒充已確認事實。
3. 撰寫一則正式優雅的邀請文。可加入不改變事實的禮貌邀請語；不得自行增加報名方式、費用、主辦人、其他活動時間或任何未提供的具體資訊。不得省略四項必填事實；欠缺時依步驟 2 標示。
4. 將完整輸出寫入工作目錄中的 `invitation.txt`。依實際提供的資料，為每項已提供的必填事實各加一個 `--require "原始文字"` 參數；每個未提供欄位則加 `--require "未提供"`。從放有本 Skill 的目錄執行以下命令，並依檢查結果修訂檔案，直到命令印出 `OK`：

   ```sh
   python scripts/check_output.py --require "展覽名稱原始文字" --require "展期起日原始文字" --require "展期迄日原始文字" --require "開幕茶會日期與時間原始文字" --require "地點原始文字"
   ```

   若有缺項，以相應欄位的 `--require "未提供"` 取代該欄位的原始文字參數。不可把範例文字當成實際資料。
5. 命令印出 `OK` 後，只以 `invitation.txt` 的內容作答。
