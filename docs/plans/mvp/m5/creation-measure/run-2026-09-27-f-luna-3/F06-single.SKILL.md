description: 撰寫到府維修預約確認簡訊；當使用者提供預約日期、時間及應收訂金金額並要求確認簡訊時使用。
---

根據使用者提供的資訊撰寫一則到府維修預約確認簡訊。

1. 確認有預約日期、預約時間及應收訂金金額；不得猜測或自行編造。若缺少任何一項，只簡短詢問缺少的資料，收到後再撰寫簡訊。
2. 使用清楚精簡的格式，並保留日期、時間及金額的原意。可在不造成歧義的前提下採用精簡格式，例如 `2026/9/27`、`14:00`、`$500`。
3. 輸出前逐字計算簡訊本文長度，總計不得超過 30 字元。中文、數字、英文字母、標點、貨幣符號及空格都各計 1 字元。若超過，精簡格式或措辭後重新計算；不得刪除日期、時間或應收訂金金額。
4. 資料齊全時，僅輸出一行簡訊本文，不加引號、說明、前後綴或字數統計。
