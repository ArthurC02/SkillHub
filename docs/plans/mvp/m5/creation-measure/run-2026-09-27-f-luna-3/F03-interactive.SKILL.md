# 書店訂書留言整理

處理使用者提供的訂書留言，整理各筆書籍的書名、數量、單價、小計、已知單價書籍的總金額，以及另列的運費。只根據留言，不查價或猜價格。

## 步驟

1. 從留言逐筆辨認書籍；不同書籍各列一筆，不合併。保留留言中的書名、數量、單價及幣別。若書名或數值無法確定，在輸出中標示「待確認」，不要自行判定。若未提數量，記為缺少；若未提單價，記為缺少。
2. 辨認留言提到的運費及其幣別；沒有提到運費，就標示「未提及」。運費不加入書籍總金額。不要把其他費用當作運費。
3. 將辨認結果整理成 JSON，交給計算腳本。格式為一個物件，包含 `items` 陣列和 `freight` 陣列。每筆書籍使用 `title`、`quantity`、`unit_price`、`currency` 欄位；缺少或無法確定的數值用 `null`，幣別未提供用空字串。`freight` 每筆使用 `amount`、`currency` 欄位；沒有運費時用空陣列。保留原始幣別，不要轉換。從放置此 SKILL.md 的目錄執行：

   ```sh
   python scripts/calculate_order.py --data '<JSON>'
   ```

   將 `<JSON>` 替換為第 3 步整理出的單行 JSON。若文字中的引號或特殊字元會影響 shell 引號，改用 shell 安全的引用方式，確保 JSON 原樣傳入。

4. 依腳本輸出製作繁體中文表格，列出每筆書籍的書名、數量、單價、小計。缺少單價要寫「未提供」，其小計寫「無法計算」；未寫數量採用腳本給出的預設值。書籍總金額使用腳本結果，並在有缺少單價的書籍時註明「只計入已知單價的書籍」。若留言有運費，另列腳本結果中的運費，不併入書籍總金額。
5. 在表格或備註中標出待確認的書名或數值；不確定的項目不得當成已知資訊計算。回覆整理後的訂購清單及金額，不聲稱已下單、聯絡客人或完成其他外部動作。
