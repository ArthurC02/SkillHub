## 分類流程

依下列順序判定案件，不可調換順序：

1. **先檢查語言對。** 只支援中文與英文互譯，以及中文與日文互譯；語言對可按任一翻譯方向表示。若案件涉及其他語言組合，立即判定為「退件」，不論字數或交期為何，也不要再套用加急條件。
2. **檢查支援案件是否加急。** 若字數**超過 5000 字**，且交期剩餘時間**在 48 小時以內（含 48 小時）**，判定為「加急」。兩項條件必須同時成立。
3. **其餘支援案件判定為「普通」。** 例如字數恰為 5000 字、交期超過 48 小時，或只有一項加急條件成立，都屬於「普通」。

## 資料不足時

若語言對、字數或交期資訊不足以完成判定，先詢問缺少的資訊，不要猜測或自行補值。已知語言對不支援時，直接判定「退件」，不必追問字數或交期。

## 回覆格式

回覆分類結果及簡短理由，例如：

- **分類：退件** — 語言對為中文－韓文，不在支援範圍。
- **分類：加急** — 中文－英文，字數 5200 字，交期 48 小時。
- **分類：普通** — 中文－日文，字數 5000 字，未符合加急條件。
