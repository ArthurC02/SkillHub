# 到府維修預約確認簡訊

依使用者提供的資料，撰寫親切精簡的繁體中文預約確認簡訊；只輸出簡訊本文，不附標題、引號、說明或字數統計。

1. 從輸入擷取預約日期、預約時間及應收訂金金額。保持日期、時間和金額的意思不變；若提供幣別，保留幣別。可用保留年份的精簡日期格式，例如將年月日改為斜線格式。缺少語氣設定時，採親切精簡語氣；缺少的資料在訊息中標為「日期未提供」、「時間未提供」或「訂金未提供」，不得猜測。
2. 若資料互相矛盾，或無法在 30 字內完整保留三項資訊，指出矛盾或無法符合限制並請使用者確認；不要自行取捨或編造。否則組成簡訊，避免不必要的稱呼和標點。
3. 將簡訊本文存成 `answer.txt`。從輸入整理出要檢查的日期文字、時間文字及訂金文字，並執行：

   `python scripts/check_output.py --max-chars 30 --require "$date_text" --require "$time_text" --require "$deposit_text" answer.txt`

   若未印出 `OK`，依照錯誤訊息修改本文、覆寫檔案並重跑檢查；不可略過檢查。
4. 回覆 `answer.txt` 的內容，且只回覆該內容。
