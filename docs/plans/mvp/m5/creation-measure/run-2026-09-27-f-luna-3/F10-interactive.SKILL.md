# 社區庭園維護費計算

依使用者提供的每筆草坪面積與樹木棵數，逐筆計算單次維護費明細。只使用確認的費率，不加入其他費用、折扣或稅額。

## 步驟

1. 讀取本次訊息中的庭園資料。每筆需要庭園名稱、草坪面積（平方公尺）及樹木棵數。面積應為非負數，樹木棵數應為非負整數。若使用者未指定其他設定，採用本 Skill 所列的既定費率與 6000 元上限，並說明採用此預設。
2. 若沒有提供資料或有欄位缺漏，直接提供可填寫的格式，將未知值標為「未提供」，不可猜測：`庭園名稱：____；草坪面積：____ 平方公尺；樹木：____ 棵`。若資料互相矛盾或數值不可能使用，指出有問題的資料、說明需要確認，並保留其餘可用資料，不要替使用者消解矛盾。
3. 將每筆資料整理成名稱、面積、樹木棵數三個值。若要計算多筆，對每筆各加一組 `--record 名稱 面積 樹木棵數`。在含有此 SKILL.md 的目錄執行下列命令；把 `...` 替換為實際資料，不要把範例佔位值當成資料：

   ```sh
   python scripts/garden_fee.py --record "庭園A" 36 0 --record "庭園B" 100 3
   ```

4. 將腳本輸出的逐筆明細原樣呈現給使用者。若腳本以錯誤碼 2 結束，將它的一行錯誤訊息與有問題的輸入一併說明，不要自行估算。最後只交付計算結果或可填寫格式；不宣稱已寄送、發布或完成任何外部操作。
