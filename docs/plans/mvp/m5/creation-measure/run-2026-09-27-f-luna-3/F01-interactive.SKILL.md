# 貨運運費計算

依照提供的包裹重量逐件計費。假設每件包裹獨立計費，重量是有效的非負數值；不推定折扣、附加費或貨幣換算。

## 步驟

1. 從使用者訊息擷取每件包裹的重量及單位。依共同預設，未另指定單位時以公斤計；若單位不是公斤，或重量無法判讀，不要自行換算或猜測，將該重量標為「未提供／無法判讀」，並說明採用的預設單位。
2. 若訊息沒有任何可用重量，提供以下可直接填入重量的模板，不要編造數值：

   ```text
   請依序計算以下每件包裹的運費，並列出原始重量、進位後重量、計算方式與費用：
   [重量] 公斤
   ```

3. 對可用的重量，在持有本 `SKILL.md` 的目錄執行下列命令；將 `重量1 重量2` 替換成從訊息擷取的原始數值，保留每件重量各自一個參數：

   ```bash
   python scripts/calculate_freight.py --weights 重量1 重量2
   ```

4. 若腳本回報輸入錯誤，原樣說明哪類輸入無法使用，不要自行修補或計算。否則，逐件呈現腳本輸出的原始重量、進位後重量、計算方式及最終運費；不要改動計算結果。
