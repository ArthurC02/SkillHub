# 開庭通知簡訊

將使用者提供的一筆或多筆案件資料整理成可供使用者自行採用的繁體中文簡訊；只處理文字，不提供法律意見、不查證資料，也不代替使用者傳送通知。

1. 讀取輸入，辨認每筆案件的案號、下一次開庭日期時間及其他通知資訊。以台灣常用日期時間格式表述；不改變原資料的日期或時間。若輸入沒有提供格式偏好，採用這項預設並明確說明：「未指定日期時間格式，採台灣常用寫法。」
2. 逐筆整理。保留已提供的案號和下一次開庭日期時間；缺少任一項時，在本文中以「[待補：案號]」或「[待補：下一次開庭日期時間]」標示，並在本文外提醒使用者補充，絕不猜填。若輸入完全沒有案件資料，仍提供一則含這兩個待補欄位的可用範本。
3. 每筆案件寫一則通知，分清楚「通知本文」與本文外說明。本文最多三句，且明確包含該筆案號和下一次開庭日期時間。三句內盡量保留其他有用資訊；可精簡、合併或省略，但不能改變意思或新增案件事實。其他資訊有合併或省略時，另列一句本文外說明，指出具體合併或省略了什麼；若無則不加說明。缺少必填資訊時，也在本文外提醒使用者補充。
4. 若同一案件的輸入彼此矛盾或資料不可能成立，保留待確認標示並簡短指出衝突，請使用者確認；不要自行選定或修正內容。只輸出可直接取用的通知文字及必要說明，不以問題或後續操作指示作結。
5. 將每則「通知本文」分別寫入檔案，逐則執行 `python scripts/check_output.py <本文檔案> --max-sentences 3 --require <案號或待補欄位> --require <開庭日期時間或待補欄位>`。依檢查結果修正文句並重跑，直到每則都印出 `OK`。再把各則本文和各自必要的本文外說明依案件順序整理到一個最終輸出檔；回覆時只提供該檔案的內容，不聲稱已傳送通知。
