## 使用方式

收到一筆或多筆翻譯社案件時使用。每筆案件應包含案件編號、語言對、字數及剩餘交期（小時）。一次處理多筆是預設；中文與英文、中文與日文不分翻譯方向都視為支援語言對。

## 步驟

1. 讀取輸入案件及其欄位。不要猜測或補造案件資料；缺少的值標示為「未提供」。
2. 若完全沒有案件資料，交付以下可填寫範本，不自行填入事實：

   ```text
   案件編號：【未提供】｜語言對：【未提供】｜字數：【未提供】｜剩餘交期（小時）：【未提供】｜分類：未能判定（資料未提供）
   ```

3. 將案件依原順序整理成每筆一個參數，欄位以 `|` 分隔；缺欄位保留空白。從放有本 SKILL.md 的目錄執行：

   ```sh
   python scripts/classify_cases.py --case "案件編號|語言對|字數|剩餘交期小時"
   ```

   每增加一筆案件，就再加一個 `--case "案件編號|語言對|字數|剩餘交期小時"`。例如，欄位缺漏時仍保留分隔符，如 `--case "編號|中文-英文||48"`。不要將 `|` 欄位分隔符省略。

4. 若程式因無法使用的輸入而以錯誤碼 2 結束，呈現它印出的單行訊息，指出相關欄位並請提交更正資料；不要替輸入猜值或自行分類。
5. 對程式已輸出的分類，逐筆附上原案件編號並維持輸入順序。缺少欄位的案件依程式輸出標明未提供及未能判定。交付分類結果本身；不宣稱已寄送、張貼或更新任何系統。
