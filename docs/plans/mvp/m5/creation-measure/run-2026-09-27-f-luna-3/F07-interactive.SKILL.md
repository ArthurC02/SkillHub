# 缺席警告信

根據使用者提供的資料，判斷哪些學生本學期缺席達 3 次或以上，為達標者準備家長信，並提醒使用者自行標記「留意名單」。本 Skill 不登入教務系統、不修改名單，也不宣稱已完成標記。

## 步驟

1. 從輸入擷取學期，以及每位學生的姓名、家長稱謂和本學期缺席次數。缺席次數視為使用者已確認的數字；門檻固定為 3 次或以上。不得補造原因、校規、聯絡方式或系統操作細節。
2. 檢查資料是否完整且一致。若缺少必要資料，直接提供可用的結果格式或信件範本，將缺少的事實標成「未提供」，並保留明確空格供使用者補入；不要猜測。若資料互相矛盾或不可能，指出矛盾並註明須由使用者確認後才能判斷，不要自行裁決，也不要以問題句結尾。
3. 若資料完整，從本 Skill 所在目錄執行以下命令；將實際擷取的學期放在 `--term` 後，每位學生各提供一個 `--student`，格式為 `姓名|家長稱謂|缺席次數`。對每個值使用 shell 引號，保留輸入原文：

   `python scripts/absence_warning.py --term "學期" --student "姓名|家長稱謂|缺席次數"`

   有多位學生時，重複加入 `--student "姓名|家長稱謂|缺席次數"`。若腳本回報輸入不能使用，原樣呈現其單行訊息，不要自行猜改資料。
4. 將腳本輸出逐位交付，不增添輸入未提供的事實。達標學生的人工標記提醒只表示使用者需自行將該生標記為「留意名單」；未達標者不得附警告信或標記提醒。
