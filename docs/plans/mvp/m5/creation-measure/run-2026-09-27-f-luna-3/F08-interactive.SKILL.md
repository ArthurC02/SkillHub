# 獸醫診所收費整理

整理使用者提供的看診收費資料，保留每筆資料為獨立項目，依日期分組並計算小計、每日總額及全部日期總額。不推測醫療資訊、價格、稅額或折扣。

## 步驟

1. 從使用者訊息擷取每筆資料的看診日期、看診項目、數量及單價。支援以表格或清楚分隔的逐筆資料表示。未指定幣別時使用新台幣（NT$），並在輸出中說明此預設。數量或單價的計算方式未另行指定時，按輸入數值計算，不增添費用或折扣。
2. 若資料缺漏，列出缺少的欄位並標示「未提供」，提供可直接補填的收費資料模板；不要猜測。若輸入互相矛盾、日期或金額無法使用，說明受影響的資料及需要確認之處；不要自行消解矛盾。仍能獨立整理的資料可照常計算。
3. 將每筆資料轉成一個 `--row` 引數，格式為 `日期|項目|數量|單價`。從放有此 `SKILL.md` 的目錄執行以下命令；重複加入 `--row` 以涵蓋所有資料。對含空白或特殊字元的值使用 shell 引號：

   ```sh
   python scripts/charge_summary.py --row '日期|項目|數量|單價' --row '日期|項目|數量|單價'
   ```

4. 將腳本輸出的各筆小計、日期分組金額及全部日期總額整理成易讀的繁體中文清單。保留相同項目的不同輸入列，不合併；金額標示為新台幣（NT$）。不得加入輸入中沒有的費用。若腳本以錯誤結束，照實說明無法計算的原因，並標示需要確認的欄位，不要猜值。
5. 交付整理好的清單；若有缺漏或需確認的資料，一併明確標示。不要聲稱已送出、登錄或更新任何外部系統。
