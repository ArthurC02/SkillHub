## 觸發條件
學生本學期缺席紀錄累計達 3 次時，執行以下流程。先確認學期範圍，以及校方如何計算缺席（例如請假是否計入、半日或單節如何折算）；不得自行假設計算規則。若規則不明，先詢問負責教職員或依校方正式規定核實。

## 流程
1. **核對學生與紀錄**
   - 確認學生身分及目前學期，避免同名學生混淆。
   - 核對出缺席紀錄，確認累計確實達 3 次，並依校方規則處理已核准請假、遲到或其他例外。
   - 若紀錄不完整、互相矛盾，或無法確認是否達標，暫停後續處理並詢問校方負責人；不要推測或補造紀錄。

2. **準備家長警告信**
   - 只使用已核實且提供給你的資料，例如學生姓名、家長稱謂、缺席日期、學校聯絡方式及寄送管道。
   - 清楚說明本學期已核實的缺席次數、日期（若可提供），並以關懷、客觀、不指責的語氣提醒家長與校方聯絡。
   - 不要臆測缺席原因、添加未核實的後果，或透露其他學生的資料。
   - 若沒有寄信授權或沒有安全的寄送管道，只提供信件草稿，明確註明尚未寄出。

   **信件草稿格式**

   主旨：本學期缺席情形提醒

   親愛的家長您好：

   我們注意到【學生姓名】本學期截至【核對日期】累計缺席【次數】次（日期：【已核實日期；若不適用則省略】）。為了了解學生的出席情形並提供適切協助，敬請您與【校方聯絡人／單位】聯絡。若上述紀錄有誤，或您希望說明相關情況，也歡迎與我們聯繫。

   謝謝您的協助。

   【學校／聯絡人】
   【聯絡方式】

   3. **處理教務系統標記**
   - 只有在你具有明確授權，且當前環境提供可用的教務系統存取方式時，才登入系統。不得索取、猜測或代為保存密碼，也不得嘗試繞過登入或權限限制。
   - 在系統中再次核對學生身分與學期，再確認該生尚未被標記為「留意名單」。若已標記，不要重複建立項目；記錄其已存在即可。
   - 若系統可用且權限允許，依系統提供的正式流程將該生標記為「留意名單」，確認變更成功後才回報完成。不得更改無關資料。
   - 若無法登入、沒有權限、找不到正確學生或標記操作失敗，停止操作，告知負責教職員需要其處理；不可聲稱已完成標記。

4. **回報狀態**
   簡潔回報已核實的缺席次數、警告信是草稿或已依授權寄出，以及系統標記是已完成、原已存在，或因無法存取／權限不足而未完成。只向有權處理此事的人提供必要資訊。不得在未實際執行的情況下表示已寄信或已標記。
