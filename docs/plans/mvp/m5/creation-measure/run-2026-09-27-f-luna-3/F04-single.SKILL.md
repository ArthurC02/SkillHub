## 計算步驟

1. 確認入住日期與退房日期。住宿晚數只計入住日到退房日前一日；退房當天不計費。
2. 平日每晚基準價固定為 2000 元。
3. 確認假日加價規則：
   - 假日如何定義，例如週六、週日、指定國定假日，或由使用者提供的日期。
   - 每晚加價金額，或假日每晚總房價。
   - 若規則只說「假日會加價」而未提供金額，先詢問，不要自行設定價格。
4. 若週末與國定假日可能重疊，確認是否只套用一次加價，或依使用者規則計算；未說明時按一次假日價格計，不重複加價，並在結果中註明此假設。
5. 逐晚列出住宿日期並分類為平日或假日。遇到年份、假日日期或分類依據不明，請向使用者確認；不要假裝已查證未提供的國定假日資料。
6. 計算各類晚數與總額：
   - 平日小計 = 平日晚數 × 2000 元。
   - 假日小計 = 假日晚數 × 使用者提供的假日每晚房價（或依其提供的加價方式計算）。
   - 總金額 = 平日小計 + 假日小計。
7. 回覆入住日期、退房日期、總晚數、逐晚分類或各類晚數、使用的單晚價格、各項小計與總金額。金額以元呈現，避免只給總數而不交代算法。

## 日期檢查與缺漏處理

- 日期需有效，且退房日期必須晚於入住日期。若相同日期或退房早於入住日期，指出問題並請使用者修正，不要產生負數或虛構住宿晚數。
- 若只有日期區間但沒有年份，而年份會影響日期星期或假日判定，先詢問年份。
- 若入住日期與退房日期相同，說明依「退房當天不算一晚」的規則，住宿為 0 晚；確認使用者是否輸入正確。
- 如使用者明確表示所有週末、指定日期或其他日期皆視為假日，依該定義計算。沒有明確定義時，不要默認週末或國定假日的範圍。
- 本 Skill 只根據使用者提供的價格和假日規則計算，不代替確認房況、訂房或額外費用（例如清潔費、稅金、押金）。如使用者提到這些費用，詢問金額並分項列入，或清楚標示目前總額未包含。
