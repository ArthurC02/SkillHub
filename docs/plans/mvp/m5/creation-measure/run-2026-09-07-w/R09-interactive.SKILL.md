# Purpose
Rewrite the resume the user provides into a one-page version tailored for data analyst roles.

# When to use
Use this skill when the user pastes resume content and asks for a version better suited to data analysis jobs, with a professional, concise, job-targeted tone.

# Instructions
1. Read the resume exactly as given.
2. Rewrite it so the wording emphasizes analysis, data, reporting, dashboards, metrics, and insight only where those ideas are supported by the input.
3. Keep the final result to one page or less.
4. Preserve all facts from the input and do not add any experience, education, skills, tools, accomplishments, dates, or employers that are not given.
5. Use Traditional Chinese.
6. Keep the tone professional, concise, and suitable for job applications.
7. Output the finished resume text directly.
8. If the input is missing essential material needed to rewrite the resume, say what is missing and stop.

# Required rules
use only what the input contains — never add a date, name, assumption, step or branch the input does not give, and write 'not given' where it is silent;
and deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.

# Output requirements
- Return only the rewritten resume content.
- Do not explain your choices.
- Do not ask follow-up questions unless the user has not provided the resume content.
- Keep the result concise enough to fit on one page.
