# Resume to Data Analyst One-Pager

## Purpose
Rewrite a user-provided resume into a concise version tailored for data analyst roles, keeping the result to one page or less when formatted normally.

## When to use
Use this skill when the user supplies resume content and wants it reframed for data analysis applications, especially when they want stronger emphasis on analytics, reporting, SQL, Python, Excel, BI tools, dashboards, metrics, or evidence of data-driven work.

## Core principles
- Stay truthful. Do not invent jobs, degrees, tools, metrics, titles, or achievements.
- Prefer evidence of analysis work over generic responsibility statements.
- Keep the final version compact enough for a one-page resume layout.
- If essential information is missing, ask focused follow-up questions before rewriting.
- Preserve the user's real experience, but rewrite it to match data analyst expectations.

## Required inputs
At minimum, the user should provide:
- The full current resume content

Helpful optional inputs:
- Target job posting or role summary
- Preferred language or locale
- Key experiences to emphasize or de-emphasize
- Existing resume format constraints

## Workflow
1. Read the entire resume and identify:
   - education
   - work experience
   - projects
   - tools and technical skills
   - measurable outcomes
2. Check whether the user has provided enough information to rewrite safely.
   - If not, ask a short list of precise questions.
   - Ask only for what is necessary to avoid guessing.
3. Rewrite the resume with data analyst relevance:
   - prioritize analytics, reporting, dashboards, business insight, automation, and measurable impact
   - keep only experiences that support the target role or the user's strongest evidence
   - shorten or remove unrelated details
4. Keep the format compact:
   - use tight bullets
   - avoid long paragraphs
   - prefer one-line role summaries and outcome-focused bullets
5. Return a polished resume draft ready for use.

## Content guidance
### Include
- Relevant summary or profile statement only if it adds focus
- Education if it supports the application
- Work experience rewritten with analysis-oriented language
- Projects showing data handling, reporting, visualization, or experimentation
- Skills such as Excel, SQL, Python, Power BI, Tableau, BI tools, statistics, or reporting systems when provided by the user

### Prefer wording that shows
- tracking, analyzing, consolidating, comparing, visualizing, automating, reporting
- business impact, efficiency gains, decision support, trend analysis
- dashboards, monthly reports, KPI monitoring, data cleaning, ad hoc analysis

### Avoid
- exaggeration
- unsupported claims of seniority or expertise
- generic self-praise
- filler phrases that do not strengthen the application
- adding certifications or tools not mentioned by the user

## Rewrite rules
- Keep the user's facts intact.
- Convert vague responsibilities into concrete, analytical phrasing only when the source content supports it.
- If a bullet has no analytics value, shorten it or omit it.
- If numbers are available, keep them. If no numbers are available, do not invent them.
- Use concise bullets rather than narrative paragraphs.
- Optimize for readability in one page.

## Missing-information handling
If the resume lacks important details needed for a safe rewrite, ask brief questions such as:
- Which role or job description are you targeting?
- Which experiences should be emphasized most?
- Do you want the output in Traditional Chinese or English?
- Are there any tools, projects, or metrics you want preserved?

Do not ask more than necessary. If enough information is present, proceed directly.

## Output shape
Provide only the rewritten resume content unless the user asks for commentary.
Use a clean, professional resume structure with sections such as:
- Title or profile
- Summary
- Skills
- Experience
- Projects
- Education

Keep the final text concise enough for a one-page layout.
