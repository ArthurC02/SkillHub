# 目的
清理 Excel 客戶名單：去除重複資料，並標記缺少電話的列。

# 適用情境
當使用者提供一份 Excel 名單，要求你整理重複客戶、找出缺少電話的資料時，使用此技能。

# 執行步驟
1. **確認資料範圍與欄位**
   - 找出包含客戶名單的工作表與資料範圍。
   - 確認哪些欄位可用來判斷重複，通常優先使用：
     - 客戶名稱
     - 電話
     - Email
     - 其他唯一識別欄位
   - 若使用者未指定重複判斷規則，先以「客戶名稱 + 電話」作為主要比對依據；若電話也缺失，則以可用欄位組合判斷。

2. **建立備份或保留原始資料**
   - 在原工作表旁建立一份副本，或先另存新檔。
   - 原始資料不要直接覆蓋，除非使用者明確要求。

3. **去除重複資料**
   - 依照確認的判斷欄位，找出重複列。
   - 保留第一筆出現的資料，刪除後續重複列；若資料有明顯較完整的一筆，優先保留資訊較完整者。
   - 若無法判定哪筆應保留，採用一致規則：保留最先出現的列。
   - 若你無法安全判斷重複依據，先向使用者確認，不要自行猜測。

4. **標記缺少電話的列**
   - 檢查電話欄是否為空白、只有空格、或明顯不是有效電話內容。
   - 新增一個標記欄位，例如：`電話缺失`、`缺少電話` 或 `Phone Missing`。
   - 對電話缺失的列標記為 `是`、`Y`、`缺少` 或其他一致值；其餘列標記為 `否`。
   - 若使用者希望直接篩選，也可另外套用篩選條件，但仍應保留標記欄位。

5. **檢查結果**
   - 確認重複列已移除，且資料筆數符合預期。
   - 確認所有電話缺失的列都已被標記。
   - 檢查是否有因空白、格式不同、前後空格、數字與文字格式差異而漏判的重複資料。

6. **輸出整理後的檔案**
   - 將整理後的工作表另存為新檔，或在新工作表中提供結果。
   - 若有需要，附上簡短摘要：
     - 原始筆數
     - 移除的重複筆數
     - 缺少電話的筆數

# 注意事項
- 不要在未確認規則時，擅自刪除可能不是重複的資料。
- 若電話欄位格式不一致，先統一格式再判斷是否缺失。
- 若資料中有多個電話欄位，先詢問使用者要以哪一欄為準；若無法詢問，優先使用最明確的主要電話欄。
