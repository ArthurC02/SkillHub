# 目的
收到客戶退貨申請時，判斷申請是否在 7 天內，並輸出可直接寄出的標準回覆信件。

# 使用時機
當你拿到一則退貨申請，需要根據申請日與退貨基準日（例如購買日或到貨日）快速判斷是否在 7 天內，並回覆「受理」或「不符合 7 天條件」的正式信件時使用。

# 處理步驟
1. 讀取輸入中的退貨申請內容。
2. 找出以下資訊：
   - 申請日期
   - 退貨基準日期（若有提供購買日或到貨日，依輸入可用的基準日期判斷）
   - 訂單或聯絡所需的基本資訊（例如訂單編號、客戶姓名）
3. 若缺少無法判斷 7 天內所需的日期資訊，先不要猜測。
   - 明確列出需要補充的欄位。
   - 回覆內容要簡潔、可直接請對方補件。
4. 若日期資訊完整，計算申請日與基準日的差距。
   - 差距不超過 7 天：使用「受理」版本的標準信件。
   - 差距超過 7 天：使用「不符合 7 天條件」版本的標準信件。
5. 信件內容只根據已提供資訊撰寫，不要自行新增退貨政策、例外條款、折扣、補償或未提到的承諾。

# 輸出要求
- 輸出必須是完整信件，而不是只有一句判斷結果。
- 信件需明確呈現處理結果：
  - 7 天內：明確表示已受理或可依規定進一步處理。
  - 超過 7 天：明確表示未符合 7 天條件，無法依本次申請受理。
- 若資訊不足，輸出必須列出需要補充的欄位，避免做出未經驗證的判斷。
- 保持語氣專業、清楚、禮貌。

# 建議信件結構
- 稱呼或開頭問候
- 判斷結果段落
- 後續處理說明或補件需求
- 結尾致意

# 注意事項
- 不要引入未提供的政策內容。
- 不要假設時區、營業日或特殊計算規則；若原始資料未定義，僅依輸入中的日期直接判斷。
- 若申請日或基準日格式不明，先要求補上可判讀的日期格式。
