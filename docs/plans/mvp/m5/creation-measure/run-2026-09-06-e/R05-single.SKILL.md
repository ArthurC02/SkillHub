# 目的
將一週內的每日花費整理成清楚的表格，為每筆支出標示類別，並在週末計算各類別合計。

# 適用情境
- 使用者提供一週的花費明細，要求整理成表格。
- 使用者希望每筆支出都有類別標記。
- 使用者要求在週末或週結時，統計各類別總額。

# 工作流程
1. **收集資料**
   - 取得一週內每筆花費的日期、金額、內容/用途。
   - 若使用者未提供類別，根據內容推定最合適的類別；若無法判斷，使用「其他」。
   - 若日期不完整，先依使用者提供的週起訖範圍整理；若仍不明確，請先詢問。

2. **建立每日明細表**
   - 以日期為主軸列出每筆花費。
   - 每筆至少包含：日期、項目、類別、金額。
   - 若同一天有多筆，逐筆列出，不要合併，除非使用者明確要求合併。

3. **標示類別**
   - 為每筆花費指定單一類別。
   - 類別名稱要一致，避免同義詞混用。
   - 若使用者已有固定分類，優先沿用使用者的分類名稱。

4. **週末彙總**
   - 在週末新增「類別合計」區塊。
   - 將整週所有花費依類別加總。
   - 若使用者要求，也可同時提供總支出。

5. **輸出格式**
   - 先輸出每日明細表。
   - 再輸出週末類別合計表。
   - 表格欄位建議如下：
     - 每日明細：`日期 | 項目 | 類別 | 金額`
     - 類別合計：`類別 | 合計`

# 整理規則
- 金額以使用者原始幣別呈現；若同一表內有多種幣別，需分開統計，不可直接相加。
- 若有退款、折扣或負數金額，保留原始數值並在類別合計中一併計入。
- 若某筆支出可歸入多個類別，選擇最主要用途作為類別。
- 若使用者提供的資料有重複或疑似漏項，先標註疑點，不要自行補齊。

# 回覆要求
- 內容要簡潔、可直接閱讀。
- 表格要能直接複製使用。
- 若資料不足以完成分類或週末合計，先列出缺少的資訊並提出需要補充的項目。
