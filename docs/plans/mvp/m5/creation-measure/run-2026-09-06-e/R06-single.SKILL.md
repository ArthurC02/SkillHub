## 目的
將一份英文使用手冊完整翻譯為繁體中文，並在每個專有名詞第一次出現時附上原文，之後可只用中文譯名。

## 工作原則
- 保留原意、語氣、警告等級與操作順序，不自行增刪內容。
- 以繁體中文為主，術語一致、用詞自然、符合說明書語氣。
- 專有名詞、產品名、功能名、按鍵名、介面名稱、縮寫等，第一次出現時採「中文譯名（原文）」；若原文本身常作為品牌或型號使用，可保留原文並在前後文中補上中文說明。
- 若同一專有名詞在不同章節重複出現，第一次出現後維持一致譯法，不必重複附原文，除非該章節是獨立文件或讀者可能從中途開始閱讀。
- 圖表、按鈕標籤、選單名稱、錯誤訊息、程式碼、命令列指令、變數名、檔名、路徑、URL、單位與數值格式要準確保留。

## 翻譯步驟
1. 先通讀全文，辨識文件結構：標題、章節、步驟、注意事項、表格、圖說、附錄、索引。
2. 建立術語表：
   - 找出所有專有名詞、產品元件、功能名稱、縮寫與關鍵術語。
   - 決定一致的繁中譯法。
   - 標記首次出現位置，準備加上原文。
3. 逐段翻譯：
   - 保持段落、編號、項目符號與表格結構。
   - 操作步驟用清楚、直接的命令式語氣。
   - 警告、注意、提示等標示要對應翻譯，且語氣明確。
4. 處理專有名詞首次出現：
   - 格式建議為「繁中譯名（Original Term）」。
   - 若句子中有多個專有名詞，依自然閱讀順序處理。
   - 若原文已是中文或混合語言，保留可辨識的原文形式並補足說明。
5. 保留技術內容：
   - 數字、版本號、型號、單位、時間格式、快捷鍵、路徑、代碼區塊、命令與錯誤碼不得任意改寫。
   - 若原文有明確格式要求，盡量維持相同格式。
6. 檢查一致性：
   - 同一術語前後譯名一致。
   - 首次出現的原文標註完整。
   - 步驟順序、條件句與否定句沒有翻錯。
   - 表格欄位與圖說對應正確。

## 輸出要求
- 只輸出翻譯後的繁體中文內容，不加額外說明。
- 保留原文件的章節層級與排版結構，除非為了中文可讀性需要微調。
- 若原文含有無法辨識的專有名詞或縮寫，保留原文並在上下文中以最保守方式翻譯，不要臆測。
