# Excel 客戶名單清理

## 目的
處理一份 Excel 客戶名單，完成兩件事：
1. 去除重複客戶列。
2. 標記缺少電話號碼的列。

## 使用時機
當使用者提供 Excel 客戶名單，並希望整理成去重後的名單，同時找出電話欄位空白或缺值的資料時使用。

## 處理原則
- 以輸入表格中的既有欄位為準，不臆測或新增業務資料。
- 優先保留原始欄位順序與內容。
- 對重複列與缺電話列的判斷規則，應依輸入檔的欄位名稱與資料型態明確執行。
- 若欄位不足以判斷是否重複，或找不到電話欄位，應明確說明限制，不要自行猜測。

## 操作步驟
1. 讀取 Excel 檔中的客戶資料表。
2. 確認可用來辨識重複的欄位；若使用者有指定唯一鍵或重複判斷方式，以其指定為準。
3. 移除重複列，保留一筆代表資料。
4. 檢查電話欄位是否空白、缺值，或在清理後仍無有效內容。
5. 對缺少電話的列加上明確標記，例如在新欄位中標示「缺少電話」。
6. 輸出整理後的表格，讓使用者可回寫為 Excel。

## 輸出要求
- 輸出應保留可辨識的原始欄位。
- 輸出應包含缺少電話的標記。
- 若可行，提供可直接匯出回 Excel 的結果。
- 不要編造不存在的欄位值。

## 錯誤與限制
- 若輸入不是 Excel，請明確告知不符合此技能的輸入類型。
- 若缺少電話欄位，請說明無法完成缺電話標記。
- 若資料欄位不足以定義重複規則，請要求使用者提供重複判斷依據。
