# Excel 訂單轉入 Shopify 流程

依照下列流程處理客戶訂單。這個技能只涵蓋可由代理完成的資料整理與操作步驟；如果你沒有 Shopify 後台權限、無法開啟檔案，或系統要求登入而你未被提供憑證，請先回覆需要人工協助，不要自行假設或編造資料。

## 流程

1. **收到客戶 Excel 訂單**
   - 取得客戶提供的 Excel 檔案。
   - 先確認檔案可開啟，且內容看起來是訂單資料。
   - 若檔案損毀、格式異常或不是訂單，先回報問題並請對方重新提供。

2. **轉成 CSV 格式**
   - 將 Excel 檔另存或匯出為 CSV。
   - 優先保留原始欄位名稱與資料順序。
   - 若有多個工作表，先確認哪一個是要匯入的訂單表。
   - 匯出後檢查 CSV 是否成功產生，且內容沒有明顯亂碼或欄位錯位。

3. **檢查缺漏欄位**
   - 檢查匯入 Shopify 所需的必要欄位是否齊全。
   - 常見要檢查的內容包括：客戶姓名、Email、商品名稱或 SKU、數量、收件資訊、地址、電話、備註，以及任何系統要求的欄位。
   - 找出空白、格式不正確、重複或不一致的資料。
   - 若缺少必要欄位，先整理出缺漏清單，必要時回覆客戶補資料；不要自行補填未提供的資訊。

4. **匯入 Shopify 後台**
   - 使用可用的 Shopify 後台匯入流程上傳 CSV。
   - 上傳前再次確認欄位對應正確，避免把資料匯到錯誤欄位。
   - 若系統顯示預覽或驗證結果，先檢查是否有錯誤或警告。
   - 若出現匯入失敗，根據錯誤訊息回到前一步修正 CSV，再重新匯入。
   - 若需要登入但沒有可用憑證，停止並請求人工登入協助。

5. **回覆客戶已入單**
   - 匯入成功後，確認 Shopify 中已建立對應訂單或資料列。
   - 記錄匯入結果、時間與任何需要追蹤的異常。
   - 回覆客戶訂單已完成入單；若有缺漏或例外，也要一併說明。

## 檢查原則

- 不要猜測缺少的訂單資訊。
- 不要在未確認前修改客戶原始資料。
- 若 CSV 欄位名稱與 Shopify 匯入格式不一致，先做欄位對照再匯入。
- 若流程中的任何一步無法完成，明確指出卡在哪一步，以及需要什麼補充資料或權限。
