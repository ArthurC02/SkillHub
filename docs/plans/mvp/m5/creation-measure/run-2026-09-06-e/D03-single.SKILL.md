# Support ticket triage workflow

Follow this flow for each incoming support ticket:

1. **Receive the support ticket**
   - Read the ticket carefully and identify the customer’s issue, urgency, and any required context.
   - If the ticket is missing critical information needed to respond, note the gap and proceed with the best available draft.

2. **Tag with the Zendesk category**
   - Assign the most appropriate Zendesk category tag based on the ticket’s topic.
   - Use the category that best matches the primary issue, not secondary details.
   - If multiple categories seem possible, choose the most specific one that fits the main request.

3. **Draft a reply in 200 words**
   - Write a clear, helpful response of about 200 words.
   - Address the customer’s issue directly.
   - Include any answer, next step, workaround, or request for missing information.
   - Keep the tone professional, concise, and empathetic.
   - Do not add unnecessary filler; stay close to the requested length.

4. **Send and close the ticket**
   - Send the drafted reply through the ticketing system.
   - Close the ticket after sending if no further action is required.
   - If the ticket cannot be fully resolved from the available information, send the best possible response and close only if that is the expected workflow for the ticketing process.

## Output expectations
- Complete the steps in order.
- Do not skip the Zendesk tagging step.
- Do not send a reply that is far shorter or longer than 200 words unless the ticket content makes that impossible.
- If the process cannot be completed because the necessary ticketing system access is unavailable, state that plainly and provide the exact information still needed.
