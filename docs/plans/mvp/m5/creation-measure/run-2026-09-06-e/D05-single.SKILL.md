# 新人到職流程

依照流程圖，按順序執行以下步驟：

1. **收到新人到職通知**
   - 確認已收到新進人員到職通知。
   - 若通知內容不完整，先向相關窗口補齊必要資訊。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認帳號可正常登入與收發信件。

3. **加入 Slack 頻道**
   - 將新人加入需要的 Slack 頻道。
   - 確認其可存取團隊與入職相關頻道。

4. **準備筆電與門禁卡**
   - 準備新人報到所需的筆電與門禁卡。
   - 確認設備可用、權限設定正確。

5. **安排第一週訓練**
   - 規劃新人第一週的訓練內容與時程。
   - 與相關人員確認訓練安排。

6. **指派導師**
   - 為新人指定一位導師或帶領人。
   - 明確告知導師其支援範圍與責任。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備面談重點，例如適應狀況、訓練進度與問題回饋。

8. **記錄到人資系統**
   - 將以上完成情況與關鍵資訊記錄到人資系統。
   - 確認資料已保存且可供後續追蹤。

## 執行原則
- 必須依照流程圖順序進行，不可跳步。
- 每一步完成後再進入下一步。
- 若某一步需要外部資訊或權限，先取得必要資料再繼續。
