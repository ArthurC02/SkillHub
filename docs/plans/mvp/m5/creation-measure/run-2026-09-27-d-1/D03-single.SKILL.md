# 目的
將活動洽詢訊息中的關鍵資訊整理成固定欄位，方便後續建檔、回覆或分派。

# 適用情境
當輸入是一段客戶來訊、Email、表單備註、聊天紀錄或其他非結構化文字，且需要抽取以下欄位時使用：
- 聯絡人姓名
- 聯絡電話
- 活動日期
- 預估人數
- 預算上限
- 場地偏好

# 處理原則
1. 只根據輸入文字抽取資訊，不要自行補寫、推測或編造。
2. 若某欄位未明確出現，填寫 `未知`。
3. 若同一欄位出現多個候選值，優先採用：
   - 明確標示為該欄位的內容
   - 最近出現且語意最完整的內容
4. 保留原文中的日期、金額、電話格式；不要自行轉換成其他格式，除非原文已明確提供標準格式。
5. 若文字中有明顯的否定或排除條件，應反映在「場地偏好」中，例如「不要戶外」、「不需要包廂」。
6. 若資訊彼此衝突，保留最明確、最新或最具體的一筆，並在必要時於欄位值中簡短註記衝突，例如「2026/05/12（另提到 5/13，待確認）」。

# 擷取步驟
1. 通讀整段訊息，先找出是否有姓名、電話、日期、人數、預算、場地偏好相關字句。
2. 逐欄位擷取：
   - 聯絡人姓名：找稱呼、署名、簽名檔、或自我介紹中的姓名。
   - 聯絡電話：找手機、市話、分機、WhatsApp/LINE 聯絡號碼等。
   - 活動日期：找活動舉辦日期、時間區間、檔期需求。
   - 預估人數：找參加人數、桌數、席次、賓客數等。
   - 預算上限：找總預算、每人預算、上限金額；若只有每人預算，仍原樣記錄並註明。
   - 場地偏好：找地點、室內/戶外、包廂、交通、風格、設備、座位形式等偏好。
3. 若欄位資訊是間接表達，將其整理成最短且完整的可讀文字。
4. 若完全找不到某欄位，填 `未知`。
5. 輸出時只保留這六個欄位，不要加入額外分析或評論。

# 輸出格式
請輸出為固定欄位清單，依序如下：
- 聯絡人姓名：
- 聯絡電話：
- 活動日期：
- 預估人數：
- 預算上限：
- 場地偏好：

# 範例
輸入：
「您好，我是林怡君，電話 0912-345-678，想詢問 6/18 的生日派對，約 30 人，預算上限 5 萬，希望室內有包廂。」

輸出：
- 聯絡人姓名：林怡君
- 聯絡電話：0912-345-678
- 活動日期：6/18
- 預估人數：30 人
- 預算上限：5 萬
- 場地偏好：室內、有包廂

# 注意事項
- 不要把推測當成事實。
- 不要省略原文中明確提到的重要限制條件。
- 若電話或日期格式不完整，照原文保留並盡量維持可辨識性。
