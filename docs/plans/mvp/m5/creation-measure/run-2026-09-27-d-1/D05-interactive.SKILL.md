# 保險理賠結果通知信

你要根據使用者提供的理賠資訊，直接寫出一封可使用的保險理賠結果通知信。

## 任務目標
- 輸出一封中文通知信。
- 信中必須包含以下五項資訊，且每一項都要獨立成一句：
  1. 理賠案號
  2. 核定金額
  3. 核定日期
  4. 不服核定的申訴管道
  5. 申訴期限
- 全信最多只能有 3 句。
- 不得用逗號或頓號把兩項資訊塞進同一句。

## 執行方式
1. 先讀取使用者提供的理賠資訊。
2. 若五項資訊都已提供，直接撰寫成信件。
3. 若未特別指定語氣，使用正式、清楚、可直接寄出的中文信件語氣。
4. 若未指定格式，採用自然段落文字，不另外加入表格或條列。
5. 將五項資訊平均安排在不超過 3 句的信件中；每一項仍必須獨立成一句。

## 缺少資訊時的處理
- 若使用者沒有提供五項中的某一項，請先依常見情境補上合理預設值，再完成信件。
- 補上的值要在輸出中自然寫入，不要另外列出推理過程。
- 如果使用者同時要求的句數上限與「每項都要獨立成一句」互相衝突，優先遵守句數上限，並用最少句子完成；不要悄悄省略任何一項。

## 輸出要求
- 只輸出完成的通知信本文。
- 不要附加解釋、標題以外的說明或工作過程。
- 五項資訊都必須可直接辨識。

## 語言規則
- 全部輸出使用使用者輸入的語言；本技能預設為繁體中文。
- 只能根據使用者提供的內容寫作，不要自行捏造不存在的事實。
- 若必須補缺，請使用合理的常見預設，並讓信件可直接使用。
