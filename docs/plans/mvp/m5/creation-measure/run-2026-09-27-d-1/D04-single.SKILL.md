# 目的
根據小雅、阿ken、Ivy 三位人員本週提出的特休申請日期，排出診所下週一到週六（週日公休）的櫃台值班表。

# 使用前先確認
1. 取得「本週」的定義：是以目前日期所在週，還是使用者指定的某一週。
2. 取得三位人員各自的特休日期清單。
3. 取得排班規則：
   - 每天需要幾位櫃台值班人員。
   - 是否允許同一人連續排班。
   - 是否有固定不可排班日、固定班別、或優先順序。
4. 若資訊不足，先列出缺少的項目並請使用者補齊，不要自行假設。

# 排班原則
1. 只排下週一到週六，週日不排班。
2. 任何人的特休日期不得排入值班。
3. 若某天需要多人值班，優先平均分配三人的班數。
4. 若有衝突或人力不足，先標示缺口，再提出可行替代方案。
5. 若三人都無法排某日，明確標記為「缺班」或「待補人力」。

# 排班步驟
1. 列出下週一到週六的日期。
2. 將每位人員的特休日期對照到這些日期，標出不可排班日。
3. 依每天需求人數，從可排班的人員中分配班次。
4. 優先讓每人班數平均，並避免不必要的連續排班。
5. 檢查結果：
   - 是否有人被排到特休日。
   - 是否每天都滿足需求。
   - 是否有人班數明顯過多或過少。
6. 若有問題，回到分配步驟調整，直到符合規則或明確指出無法完全符合的原因。

# 輸出格式
請輸出一份清楚的值班表，建議格式如下：

| 日期 | 星期 | 值班人員 | 備註 |
|---|---|---|---|
| YYYY-MM-DD | 一 | 小雅 / 阿ken | 無 |

若有缺班或特休衝突，備註欄需明確寫出原因，例如：
- 小雅特休
- 人力不足
- 待補班

# 例外處理
1. 如果使用者沒有提供特休日期，先要求提供三人的日期清單。
2. 如果沒有提供每天需要幾位值班人員，先要求確認需求。
3. 如果日期格式不一致，先統一成 YYYY-MM-DD 再排班。
4. 如果使用者要求的規則彼此衝突，先指出衝突並請對方決定優先順序。

# 注意事項
- 不要自行編造特休日期。
- 不要把週日排進值班表。
- 不要忽略任何人的特休限制。
- 若無法完全自動完成，請輸出目前可確定的排班結果與待補資訊。
