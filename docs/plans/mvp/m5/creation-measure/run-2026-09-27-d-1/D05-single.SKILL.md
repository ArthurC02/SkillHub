# 目的
撰寫保險理賠結果通知信，並嚴格符合格式限制：信中必須包含五項資訊，且每項資訊都要獨立成一句；整封信最多只能有 3 句話。

# 必要資訊
信件必須包含以下五項，且不得遺漏：
1. 理賠案號
2. 核定金額
3. 核定日期
4. 不服核定的申訴管道
5. 申訴期限

# 寫作規則
- 每一項資訊都必須獨立成一句。
- 不可用逗號、頓號或其他連接方式把兩項資訊塞進同一句。
- 全信最多只能有 3 句話。
- 若要同時滿足「五項資訊各自成句」與「最多 3 句」，只能將每句設計成包含多個完整句子，並以句號分隔；但每個完整句子仍只能表達一項資訊。
- 不要加入與五項資訊無關的內容，避免超過句數限制。
- 若使用敬語或收尾語，必須計入句數，且不得造成任何一句包含兩項資訊。

# 產出步驟
1. 先確認是否已取得五項資訊的具體內容。
2. 若缺少任一項，先向使用者索取缺少的資料，不要自行補寫。
3. 收到完整資料後，依下列順序安排內容：
   - 第 1 句：理賠案號
   - 第 2 句：核定金額
   - 第 3 句：核定日期
   - 第 4 句：不服核定的申訴管道
   - 第 5 句：申訴期限
4. 因為整封信最多只能有 3 句，輸出前必須重新整理成不超過 3 個句號分隔的句子，同時確保每個資訊仍是獨立句子；若無法同時滿足，應明確告知限制衝突，請使用者放寬其中一項限制。

# 檢查清單
輸出前逐項檢查：
- 是否包含理賠案號
- 是否包含核定金額
- 是否包含核定日期
- 是否包含不服核定的申訴管道
- 是否包含申訴期限
- 是否每項都獨立成句
- 是否沒有用逗號或頓號合併兩項資訊
- 是否整封信不超過 3 句

# 重要提醒
這個需求存在內在衝突：五項資訊都要各自成句，代表至少需要 5 句；但同時又要求整封信最多 3 句，兩者無法同時完全滿足。當遇到這種情況時，不要硬寫出違規內容，應直接說明無法同時符合，並請使用者調整限制。
