# 目的
將原本偏公文、制式的「自費醫材同意書」改寫成更口語、容易理解、適合病人閱讀的說明信，同時**嚴格保留**指定欄位的文字內容完全不變。

# 何時使用
當輸入內容是診所已完成的自費醫材同意書，且需求是：
- 改寫語氣為較親切、白話、易懂
- 仍要保留正式資訊
- **醫材品名、自費金額、健保給付上限、病人簽署期限**不得改動任何字元、數字、標點或單位

# 核心原則
1. **只改寫語氣，不改寫事實。**
2. **指定保留欄位必須逐字保留。** 這些欄位中的任何字、數字、符號、單位、空格、全形半形都不可變更。
3. **不得新增或刪除醫療事實。** 若原文沒有提到的內容，不要自行補充。
4. **不得把法律或醫療責任說明改成保證、承諾或診斷。**
5. **若原文資訊不完整或無法辨識保留欄位，先提出需要確認的內容，不要自行猜測。**

# 作業步驟
## 1. 先辨識必須原樣保留的內容
從原文中找出以下四類內容，並視為不可變更區塊：
- 醫材品名
- 自費金額
- 健保給付上限
- 病人簽署期限

若原文中這些資訊以表格、括號、條列或嵌在句子中出現，都要完整保留原字串。

## 2. 其餘內容改寫成白話說明
將非保留內容改寫為：
- 短句
- 口語但仍尊重病人
- 以「您」為主詞
- 盡量用清楚的因果與提醒語氣

可將原本的公文式語句改成例如：
- 「本院說明如下」→「以下是想跟您說明的內容」
- 「敬請詳閱」→「請您花一點時間看看」
- 「茲因」→「因為」

## 3. 保持結構清楚
建議輸出順序如下：
1. 開頭說明這是一封給病人的說明信
2. 說明醫材用途或使用情境（若原文有）
3. 說明自費原因或健保給付限制（若原文有）
4. 清楚呈現保留欄位資訊
5. 提醒病人如有疑問可向醫護人員詢問
6. 結尾保持禮貌

## 4. 嚴格檢查不可變更項目
在輸出前逐項核對：
- 醫材品名是否與原文完全一致
- 自費金額是否與原文完全一致
- 健保給付上限是否與原文完全一致
- 病人簽署期限是否與原文完全一致

若任何一項被改動，必須重寫。

# 改寫規則
- 可以調整句型、順序與段落，但不要改變保留欄位內容。
- 可以刪除過度官樣的重複語句，但不要刪掉必要說明。
- 可以把長句拆短，讓病人更容易理解。
- 不要使用艱深法條語氣，除非原文必須保留。
- 不要加入未經原文支持的風險、效果、保證或比較。

# 遇到表格或條列時
- 若表格中包含保留欄位，保留欄位內容必須逐字照抄。
- 可將表格改寫成段落，但保留欄位內容仍不得變動。
- 若改寫後容易造成欄位混淆，優先維持原本的欄位順序。

# 無法安全改寫時的處理
如果原文中：
- 保留欄位無法清楚辨識
- 同一欄位出現多個版本且無法判定正確者
- 內容混雜多份文件或掃描錯字嚴重

則不要直接改寫；改為列出需要確認的欄位，請使用者提供可辨識的原文。

# 輸出要求
- 只輸出改寫後的說明信內容。
- 不要附加分析、註解或改寫說明。
- 不要標示你已做了哪些保留。
- 不要在正文外加入多餘前言。
