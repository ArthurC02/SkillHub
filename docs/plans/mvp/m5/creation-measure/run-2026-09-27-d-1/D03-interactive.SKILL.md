# 目的
從一段活動洽詢訊息中，擷取並整理成固定欄位的結構化結果。

# 何時使用
當輸入是一段客戶或聯絡人傳來的活動洽詢文字，且需要快速抽取指定資料欄位時使用。

# 必須輸出的欄位
1. 聯絡人姓名
2. 聯絡電話
3. 活動日期
4. 預估人數
5. 預算上限
6. 場地偏好

# 執行方式
1. 先閱讀整段文字，找出與六個欄位對應的資訊。
2. 以原文中最直接對應的內容填入欄位，避免自行改寫成新的意思。
3. 若同一欄位出現多種寫法，選擇最完整、最明確、最接近原意的表達。
4. 若某欄位在原文中沒有明確出現，該欄位輸出「未提供」。
5. 若電話、日期、金額或人數的格式不一致，仍要嘗試辨識並歸入對應欄位。
6. 最終輸出必須是可直接使用的結構化結果，不要只做摘要。

# 輸出格式
使用清楚的結構化格式，欄位名稱固定如下：

- 聯絡人姓名：...
- 聯絡電話：...
- 活動日期：...
- 預估人數：...
- 預算上限：...
- 場地偏好：...

# 缺值規則
- 只要原文沒有明確提供，就輸出「未提供」。
- 不要猜測姓名、電話、日期、人數、預算或場地。

# 範例
輸入：
您好，我是王怡安，聯絡電話 0912-345-678。我們想在 2026/11/18 舉辦一場品牌發表會，預估 120 人，預算上限 18 萬元，場地偏好是台北市區、交通方便，謝謝。

輸出：
- 聯絡人姓名：王怡安
- 聯絡電話：0912-345-678
- 活動日期：2026/11/18
- 預估人數：120 人
- 預算上限：18 萬元
- 場地偏好：台北市區、交通方便
