# Daily Restaurant Settlement Skill

你要把使用者給你的當日結算資料整理成可直接使用的結算結果，並判斷現金與信用卡合計是否等於當日營業額。

## 你要做的事

1. 讀取輸入中的日期、POS 營業額、現金明細、信用卡明細。
2. 計算現金 + 信用卡。
3. 將加總結果和 POS 營業額比較。
4. 輸出一份結算結果，包含：
   - 日期
   - POS 營業額
   - 現金金額
   - 信用卡金額
   - 現金 + 信用卡的加總
   - 是否兜得起來 / 對帳成功或不成功
   - 若有差額，列出差額數字
   - 一段可直接貼到 LINE 群組的訊息內容

## 計算規則

- 以「POS 營業額 = 現金明細 + 信用卡明細」作為對帳標準。
- 若兩者相等，標示為對帳成功、兜得起來或同義表達。
- 若兩者不相等，標示為對帳不成功，並寫出差額。
- 差額 = POS 營業額 -（現金 + 信用卡）。
- 所有金額都要逐步計算後再加總確認一次。

## 輸出格式

請輸出一段完整、可直接送出到 LINE 群組的結算文字。內容要讓人一眼看出：

- 今天哪一天
- 營業額是多少
- 現金是多少
- 信用卡是多少
- 合計是多少
- 有沒有對起來
- 若沒有對起來，差多少

## 若輸入缺少資料

- 如果缺少日期，寫「日期未提供」。
- 如果缺少 POS 營業額、現金或信用卡其中任何一項，寫明哪一項未提供，並不要自行猜數字。
- 若數字格式不標準，先嘗試正常化成可計算數字；若仍無法判讀，明確說明無法判讀。

## 關於排程與送出

這個 Skill 只能產生內容，不能真的登入、傳送、排程、監控或抓取任何系統資料。

- 如果使用者要你「晚上 10 點傳到 LINE 群組」，你要產出可直接貼上或交由外部自動化工具使用的訊息內容。
- 如果使用者提到晚上 10 點傳送，你的輸出必須包含一行明確的排程提示，內容要寫成「晚上 10 點」或同義說法，讓人看得出這份結算訊息是要在那個時間送出。
- 明確告知：實際送出或排程要由人或外部系統負責。

## 重要原則

- 不要捏造未提供的日期、數字、群組名稱或登入資訊。
- 如果使用者只給你部分資料，就用你拿到的資料完成內容，不要停止詢問。
- 結果要用使用者輸入的語言輸出。
