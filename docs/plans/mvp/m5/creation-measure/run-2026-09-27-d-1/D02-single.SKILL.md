# 自助倉儲入倉資格審核

依照以下規則審核申請人，輸出等級與處置結果。

## 審核順序

1. **先檢查是否曾有毀損倉儲設施紀錄**
   - 只要有任何毀損紀錄，直接判定為 **D級**。
   - **處置：拒絕承租**。
   - 此規則優先於所有其他條件，不再看信用分數或近一年逾期繳費次數。

2. **若無毀損紀錄，再檢查信用分數與近一年逾期繳費次數**
   - **A級**：信用分數 **700分以上（含700）**，且近一年逾期繳費 **0次**。
     - **處置：免押金**。
   - **B級**：信用分數 **700分以上（含700）**，且近一年逾期繳費 **1次以上**。
     - **處置：押金為1個月租金**。
   - **C級**：信用分數 **未滿700分**。
     - **處置：押金為2個月租金，且需要連帶保證人**。

## 判定規則細節

- 「700分以上（含700）」表示 **700、701、702…** 都屬於符合條件。
- 「近一年逾期繳費1次以上」表示 **1次、2次、3次…** 都屬於 B 級條件。
- 若資訊不完整，先向使用者補齊以下必要資料再判定：
  - 信用分數
  - 近一年逾期繳費次數
  - 是否曾有毀損倉儲設施紀錄
  - 若需計算押金，還要有月租金金額

## 輸出格式

回覆時請明確列出：
- 等級：A / B / C / D
- 判定依據：簡述觸發的條件
- 處置結果：免押金 / 1個月租金 / 2個月租金且需連帶保證人 / 拒絕承租

## 範例

- 信用分數 720、近一年逾期 0 次、無毀損紀錄 → **A級，免押金**
- 信用分數 710、近一年逾期 2 次、無毀損紀錄 → **B級，押金為1個月租金**
- 信用分數 650、近一年逾期 0 次、無毀損紀錄 → **C級，押金為2個月租金且需要連帶保證人**
- 只要有毀損倉儲設施紀錄 → **D級，拒絕承租**
