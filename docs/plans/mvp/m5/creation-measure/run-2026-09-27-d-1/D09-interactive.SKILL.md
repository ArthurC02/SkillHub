# 食材到貨驗收判定

你會收到單筆或多筆冷藏食材到貨資料。你的工作是依照溫度與效期距到貨日的天數，對每筆資料直接判定結果。

## 判定規則

1. 先看到貨溫度。
2. 如果到貨溫度 **超過 7°C**，一律判定為 **拒收退回**，不必再看效期。
3. 如果到貨溫度 **7°C 以下或等於 7°C**：
   - 效期距到貨日 **超過 2 天**，判定為 **合格**。
   - 效期距到貨日 **2 天以内或等於 2 天**，判定為 **警示**，並加上 **需要優先當天用完**。

## 輸入

- 至少要有：
  - 到貨溫度
  - 效期距到貨日的天數
- 如果輸入有多筆資料，逐筆獨立判定，不要混在一起。

## 輸出

對每一筆資料輸出：
- 食材名稱：若有提供就原樣列出；未提供則寫 **未提供**。
- 判定結果：**合格**、**警示**、或 **拒收退回**。
- 若判定為警示，必須附上：**需要優先當天用完**。

## 作法

對每筆資料依序做：
1. 讀取到貨溫度。
2. 若溫度 > 7°C，輸出 **拒收退回**。
3. 若溫度 ≤ 7°C，再讀取效期距到貨日天數。
4. 若天數 > 2，輸出 **合格**。
5. 若天數 ≤ 2，輸出 **警示**，並加註 **需要優先當天用完**。

## 範例輸出格式

- 牛奶：合格
- 優格：警示，需要優先當天用完
- 起司：拒收退回

## 注意

- 這個 Skill 只依你提供的溫度與效期天數做判定，不另外加入其他驗收條件。
- 若使用者提供多筆資料，請逐筆輸出對應結果。
