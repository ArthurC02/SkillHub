# Excel 客戶名單清理

當任務是處理 Excel 名單、去除重複資料，並標記缺少電話的列時，依照以下流程執行。

## 先確認欄位
1. 打開工作表，確認哪一欄是「客戶識別欄」：通常是姓名、客戶編號、Email、電話，或可唯一識別客戶的欄位。
2. 確認哪一欄是電話欄。
3. 如果沒有明確的唯一識別欄，優先使用客戶編號；若沒有，再依使用者指定的欄位組合判斷重複。

## 去除重複
1. 先備份原始資料到新工作表，避免直接覆蓋。
2. 以整列資料或指定的識別欄判斷重複。
3. 保留第一筆出現的資料，刪除後續重複列。
4. 若重複列之間的電話或其他欄位內容不同，先保留原始第一筆，並在結果中註記有重複資料曾被移除。

## 標記缺少電話的列
1. 在電話欄旁新增一欄，例如「電話狀態」或「缺少電話」。
2. 對每一列檢查電話欄：
   - 若電話欄為空白、只有空格、或是無法辨識為電話的內容，標記為「缺少電話」。
   - 若有有效電話，標記為「有電話」或留空，依使用者需求一致處理。
3. 若資料中有多個電話欄位，先確認哪一欄是主要電話欄；若需要，也可將任一電話欄有值視為未缺少。

## 驗證結果
1. 檢查去重後的筆數是否少於或等於原始 200 筆。
2. 隨機抽查幾筆重複資料，確認只保留一筆。
3. 篩選「缺少電話」標記，確認所有空電話列都已被標出。

## 輸出
1. 儲存清理後的 Excel 檔。
2. 若需要交付說明，附上：
   - 原始筆數
   - 去重後筆數
   - 缺少電話的筆數
   - 使用的去重欄位

## 注意事項
- 如果無法確定哪一欄應用來判斷重複，先詢問使用者，不要自行猜測。
- 如果電話欄格式混亂，先以「是否有內容」判斷，再視需要進一步標準化格式。
