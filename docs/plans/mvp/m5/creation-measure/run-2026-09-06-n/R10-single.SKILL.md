## 目的
每週從指定的三個 Slack 頻道中，找出尚未回覆的問題，整理成可直接分享的清單，並附上每則訊息的連結。

## 適用範圍
- 只處理三個已指定的 Slack 頻道。
- 只列出「問題」且「尚未回覆」的項目。
- 輸出要能讓人快速點開原始訊息或討論串。

## 作業步驟
1. 先確認本週的時間範圍。
   - 若沒有另外指定，使用最近 7 天。
   - 若工作環境有固定週期，依該週期切分，不要自行延伸到更早。

2. 逐一檢查三個頻道。
   - 只看頻道內的原始貼文與其討論串。
   - 找出內容明確是在提問、求助、請人確認、請人決定的訊息。
   - 排除純公告、閒聊、已完成、已解決、只是分享資訊的訊息。

3. 判定是否「未回覆」。
   - 視為未回覆：原始問題下沒有任何回應，或只有表情符號、已讀、非實質回答。
   - 視為已回覆：有人提供了實質答案、建議、確認、或問題已在串內被處理。
   - 若串內有回覆但仍未解決，仍不要列入，除非明確要求列出「未解決」而非「未回覆」。

4. 為每個符合條件的項目收集資訊。
   - 頻道名稱
   - 發問者
   - 發問時間
   - 問題摘要：用一句話濃縮原意，不要改寫成新的問題
   - 連結：優先使用該訊息或討論串的永久連結

5. 去重與整理。
   - 同一則問題若被轉貼或重複貼出，只保留最早且最完整的一則。
   - 同一討論串內的後續追問，不要拆成多筆，合併成同一項。
   - 依時間由新到舊排序，除非使用者要求其他排序。

## 輸出格式
用清單輸出，每筆一行，格式如下：
- [頻道] 發問者｜問題摘要｜連結

## 品質檢查
- 每筆都必須能點開原始訊息。
- 不要把已回覆的問題列進來。
- 不要加入推測或主觀判斷；只根據 Slack 內容判定。
- 若三個頻道都沒有符合項目，輸出「本週沒有未回覆的問題。」
