# Support ticket workflow

Follow this sequence for each incoming support ticket:

1. **Receive the support ticket**
   - Read the ticket carefully and identify the customer’s issue, context, and any required action.
   - If the ticket is missing essential information, note that in your draft reply and ask for the minimum needed details.

2. **Tag the ticket with the Zendesk category**
   - Assign the appropriate Zendesk category tag based on the ticket’s topic.
   - Use the most specific category available from the ticket content.
   - If the category is unclear, choose the best fit from the available information and keep the reply neutral.

3. **Draft a reply in 200 words**
   - Write a concise, helpful response of about 200 words.
   - Address the customer’s issue directly.
   - Include any needed clarification, next steps, or request for more information.
   - Keep the tone professional, clear, and courteous.
   - Do not exceed the requested length by much; aim for roughly 200 words.

4. **Send and close the ticket**
   - Send the drafted reply.
   - Close the ticket after sending, unless the ticketing system requires a different final status.

## Quality checks
- Confirm the ticket has been tagged before drafting the reply.
- Confirm the reply is complete and appropriate before sending.
- Ensure the ticket is closed only after the response has been sent.

## Limits
- This workflow does not include escalation, approval, or follow-up branching.
- If the ticket requires actions outside this flow, note the limitation in the reply and proceed only with the steps above.
