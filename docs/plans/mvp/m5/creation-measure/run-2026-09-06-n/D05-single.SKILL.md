# 新人到職流程

依照圖中的順序執行新人到職作業。這是一個線性流程，沒有分支判斷；每一步完成後再進入下一步。

## 流程步驟

1. **收到新人到職通知**
   - 確認已收到正式到職通知。
   - 取得新人姓名、到職日、部門、職稱與聯絡方式。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱可正常登入與收發郵件。

3. **加入 Slack 頻道**
   - 將新人加入公司必要的 Slack 頻道。
   - 至少包含部門、公告與新人成員相關頻道。

4. **準備筆電與門禁卡**
   - 準備新人報到所需的筆電與門禁卡。
   - 確認設備可用、權限設定正確、可於到職日交付。

5. **安排第一週訓練**
   - 排定新人第一週的訓練內容與時程。
   - 包含系統、流程、團隊介紹與必要工作說明。

6. **指派導師**
   - 指派一位導師或帶領人協助新人適應。
   - 明確告知導師其支援範圍與責任。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備回饋重點：適應狀況、工作進度、支援需求與後續目標。

8. **記錄到人資系統**
   - 將以上完成事項記錄到人資系統。
   - 確保資料完整、可追蹤，並保留必要的備註。

## 執行原則

- 按照圖示順序處理，不要跳步。
- 每一步完成後再進入下一步。
- 若某一步缺少必要資訊，先向相關人員確認，再繼續。
- 完成後確認人資系統中的紀錄已更新。
