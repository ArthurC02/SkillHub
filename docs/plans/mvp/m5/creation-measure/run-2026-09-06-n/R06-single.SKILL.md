## 目標
將一份英文使用手冊完整翻成繁體中文，保留原有章節、標題、列表、表格與警示格式；所有專有名詞在第一次出現時需附上原文，之後統一使用譯名。

## 翻譯原則
1. **忠實完整**：不刪減、不增寫說明、不改寫成摘要。
2. **繁體中文**：使用繁體中文用語與標點。
3. **結構保留**：維持原手冊的章節順序、層級、編號、項目符號、表格欄位與註記。
4. **專有名詞處理**：
   - 第一次出現時採「譯名（原文）」或「原文（譯名）」其中一種，全文一致。
   - 若原文本身是品牌、型號、介面名稱、按鈕名稱、功能名稱，優先保留原文並加上中文說明。
   - 同一術語後續出現時只用固定譯名，不重複附原文。
5. **術語一致**：同一英文詞在全文使用同一中文譯法；若有多義，依上下文固定一種譯法並保持一致。
6. **格式保留**：
   - 標題層級、粗體、斜體、程式碼、連結、警告框、注意事項、步驟編號都要保留。
   - 若原文有圖說、按鈕標籤、UI 文案，翻譯時保留其功能語氣與位置。
7. **數字與單位**：數字、型號、版本號、路徑、命令、代碼、單位與符號保持原樣；必要時補上中文單位說明，但不要改動數值。
8. **不可推測**：原文不清楚時，不自行補充內容；保留原意並盡量直譯。

## 工作步驟
1. 先通讀整份手冊，辨識：章節結構、重複術語、專有名詞、UI 名稱、警告與注意事項。
2. 建立術語一致性：為主要術語決定固定譯法，並在全文沿用。
3. 逐段翻譯，優先保留原格式與語氣。
4. 對首次出現的專有名詞加註原文；若同一頁或同一段落內已出現過，後續只用譯名。
5. 檢查是否有：
   - 標題遺漏
   - 編號錯亂
   - 表格欄位對不齊
   - 警示語氣被弱化
   - 專有名詞未在首次出現時附原文
6. 完成後做一致性校對：同一術語、按鈕名稱、功能名稱、錯誤訊息與命令列文字是否前後一致。

## 輸出要求
- 只輸出翻譯後的繁體中文手冊內容。
- 不加入翻譯說明、註解或額外摘要。
- 若原文包含英文標題或術語，依規則在首次出現時保留原文，其後使用中文譯名。
