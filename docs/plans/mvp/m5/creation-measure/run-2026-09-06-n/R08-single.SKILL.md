## 目的

當收到客戶退貨申請時，先判斷是否在購買後 7 天內，再依結果回覆對應的標準信件。

## 處理步驟

1. 先確認退貨申請所需資訊：
   - 購買日期
   - 退貨申請日期
   - 訂單編號或可識別的交易資訊
   - 客戶是否提供退貨原因（如有）

2. 計算是否在 7 天內：
   - 以購買日期為起點，計算到退貨申請日期的天數。
   - 若申請日期在購買後第 7 天當天或之前，視為「7 天內」。
   - 若超過第 7 天，視為「超過 7 天」。

3. 依結果選擇標準信件：
   - **7 天內**：回覆同意受理退貨，並說明後續退貨流程。
   - **超過 7 天**：回覆無法受理退貨，並禮貌說明已超過退貨期限。

4. 回覆內容要求：
   - 語氣保持禮貌、清楚、簡潔。
   - 直接使用標準信件，不自行延伸承諾或修改政策。
   - 若資訊不足以判斷是否在 7 天內，先請客戶補充必要日期資訊，再暫不下結論。

## 標準信件

### A. 7 天內：同意退貨

主旨：您的退貨申請已受理

內文：

您好，

我們已收到您的退貨申請，並確認目前仍在購買後 7 天內，因此可以協助您辦理退貨。

請依照以下流程進行後續處理：
1. 將商品妥善包裝。
2. 保留完整配件、贈品與發票（如適用）。
3. 依我們提供的退貨方式寄回或交回商品。

完成後請回覆我們您的退貨資訊，我們會盡快協助您處理。

謝謝您。

客服團隊

### B. 超過 7 天：拒絕退貨

主旨：您的退貨申請未能受理

內文：

您好，

我們已收到您的退貨申請。經確認，您的申請時間已超過購買後 7 天，因此目前無法受理退貨。

若您對商品有其他問題，或需要進一步協助，歡迎回覆此信與我們聯繫，我們會盡力提供協助。

謝謝您的理解。

客服團隊

## 注意事項

- 不要自行更改 7 天規則。
- 不要在未確認日期前先判定結果。
- 若客戶提供的日期格式不清楚，先整理成可計算的日期再判斷。
