# 週花費記錄表

依照使用者提供的一週每日花費資料，整理成表格，並在每筆支出後標示類別；最後在週末彙總各類別合計。

## 執行步驟

1. **確認資料範圍**
   - 先找出一週的日期範圍，通常是 7 天。
   - 若資料不足 7 天，仍照現有資料整理，不要自行補資料。
   - 若日期順序混亂，先按日期排序。

2. **辨識每筆花費**
   - 將每一筆支出拆成可記錄的欄位：
     - 日期
     - 項目/用途
     - 金額
     - 類別
   - 類別應盡量一致，例如：餐飲、交通、購物、娛樂、生活、醫療、其他。
   - 若使用者已指定類別，優先沿用使用者的分類。
   - 若某筆無法明確分類，歸入「其他」，並保持一致。

3. **建立每日表格**
   - 以日期為主軸列出每日花費。
   - 每筆花費都要標示類別。
   - 若同一天有多筆支出，分列多行，或在同一日期下逐筆列出。
   - 表格至少包含以下欄位：
     - 日期
     - 項目
     - 類別
     - 金額

4. **計算週末各類別合計**
   - 將整週所有支出依類別加總。
   - 週末摘要只列出有出現的類別。
   - 若需要，也可同時列出總支出，但重點是各類別合計。

5. **輸出格式**
   - 先輸出每日明細表。
   - 再輸出週末類別合計表。
   - 金額格式保持一致，避免混用不同貨幣或小數位。

## 建議表格格式

### 每日花費明細

| 日期 | 項目 | 類別 | 金額 |
|---|---|---:|---:|
| 週一 | 早餐 | 餐飲 | 50 |
| 週一 | 公車 | 交通 | 30 |

### 週末類別合計

| 類別 | 合計 |
|---|---:|
| 餐飲 | 350 |
| 交通 | 120 |
| 購物 | 480 |

## 注意事項

- 不要把不同類別混在同一筆合計中。
- 不要遺漏任何已提供的花費。
- 若使用者提供的是文字敘述而非結構化資料，先整理成表格再加總。
- 若金額有退款或負數，照原值計入合計。
