# 每日新聞摘要寄送

這個技能用來把三個新聞網站的標題整理成 5 條摘要，並準備成可寄送到信箱的內容。

## 先確認可行性

- 如果目前沒有可用的網路抓取能力、排程能力或寄信能力，直接說明無法自動完成「每天早上寄到信箱」這件事。
- 在這種情況下，改為產出：
  - 需要追蹤的三個新聞網站名稱
  - 每日執行時間
  - 收件信箱
  - 可手動貼上的 5 條摘要格式
- 如果有可用工具可讀取網頁與寄信，則繼續執行。

## 執行流程

1. **取得來源**
   - 確認三個新聞網站的網址或名稱。
   - 若使用者未指定，先詢問要追蹤哪三個網站。

2. **抓取標題**
   - 逐一讀取每個網站首頁或新聞列表頁。
   - 擷取最新、最重要的標題。
   - 避免重複標題；若同一事件在多站重複出現，只保留一次。

3. **整理成 5 條摘要**
   - 從所有標題中挑出最重要的 5 則。
   - 每條摘要要短、清楚、可直接讀給人看。
   - 優先保留：重大政策、國際事件、財經、科技、社會重大新聞。
   - 若標題過於零碎，合併成同一主題的一條摘要。

4. **撰寫郵件內容**
   - 主旨建議：`每日新聞摘要 - YYYY-MM-DD`
   - 內文格式：
     - 開頭一句簡短說明來源與日期
     - 接著列出 5 條摘要
     - 最後附上來源網站名稱

5. **寄送或準備寄送**
   - 如果有寄信工具：將郵件寄到使用者指定信箱。
   - 如果沒有寄信工具：輸出完整郵件草稿，讓使用者可直接複製寄出。

## 摘要寫法規則

- 每條摘要盡量控制在 1 句。
- 不要加入未在標題中或正文中確認過的細節。
- 不要評論、不要立場化措辭。
- 若資訊不足，保守寫成「某事件發生／某政策公布」這類中性表述。

## 每日執行注意事項

- 這個任務需要每天早上重複執行；若沒有排程能力，需明確告知無法自動定時。
- 若來源網站改版或無法讀取，先回報哪個網站失敗，再用可取得的來源完成其餘摘要。
- 若三個網站的標題數量不足 5 則，則用現有標題整理成少於 5 條，並註明來源不足。
