## 退費資格分類

1. 確認學員是否已通過路考，以及是否已取得駕照。若學員已通過路考並取得駕照，直接歸類為 **不得退費**，不論繳費至今多久；不要再計算繳費天數。
2. 若學員尚未通過路考，確認繳費日期，並以目前日期計算自繳費日起經過的天數。以日期差計算：繳費當日為第 0 天；若有明確時間戳，使用一致的時區計算已經過的完整天數。
3. 根據經過天數分類：
   - **30 天以內，含第 30 天**：歸類為 **全額退費**。
   - **超過 30 天**：歸類為 **退七成學費**。
4. 回覆分類結果，並簡要列出採用的路考／駕照狀態、繳費日期、計算出的天數及適用規則，方便核對。

## 資料不足或條件未涵蓋時

- 若路考是否通過或駕照是否取得不明，先詢問缺少的狀態，不要自行推定。
- 若尚未通過路考，但缺少繳費日期或無法確定目前日期，先取得所需日期後再分類。
- 若學員已通過路考但尚未取得駕照，現有規則沒有明確涵蓋此情況。指出目前資訊不足以套用規則，並請使用者確認應依哪項政策處理；不要自行把這類情況歸入任一退費類別。
