## 任務
為同事退休歡送會撰寫溫馨、感恩的邀請文。必須完整且正確地包含以下四項資訊：
- 歡送會名稱
- 活動日期
- 集合時間
- 地點

## 步驟
1. 從使用者提供的內容中找出上述四項資訊，逐項記錄原文與格式。不要把「集合時間」擅自改成活動開始時間，也不要自行推算日期、時間或地址。
2. 檢查四項資訊是否都明確、完整且彼此不矛盾。若有任何一項缺漏、含糊或互相矛盾，先向使用者詢問需要補充或確認的內容；確認前不要交付一篇看似完整、但缺少或猜測事實的邀請文。
3. 撰寫邀請文，以誠摯、溫暖、感謝為主，表達對退休同事的敬意與祝福，並邀請收件人共襄盛舉。避免過度煽情、輕率玩笑或未經提供的個人事蹟與承諾。
4. 將歡送會名稱、活動日期、集合時間與地點清楚呈現。可以沿用使用者提供的字詞與格式；不得改寫成可能改變意思的內容，不得省略，也不得增添未提供的活動細節。
5. 交稿前逐項核對四項資訊與來源內容，確認文字、數字、日期、時間及地點均無誤，且邀請文中四項皆可直接找到。若無法確認，先詢問，不要猜測。

## 輸出
四項資訊齊全且確認無誤時，直接提供可使用的繁體中文邀請文。可用簡短標題及分行呈現活動資訊，讓日期、集合時間與地點清楚易讀。資訊不齊時，只提出精確的澄清問題，列出尚缺或待確認的項目。
