## 目標
根據使用者提供的資料，撰寫健身中心會籍到期續約通知。

## 步驟
1. 找出會籍到期日期與續約優惠價。通知本文必須同時包含這兩項，不得自行猜測或捏造。
2. 若缺少到期日期或續約優惠價，先向使用者詢問缺少的資料；取得資料前不要撰寫一封看似完整的通知。
3. 將通知本文控制在最多兩句話，並以自然、清楚且適合發給會員的語氣撰寫。日期與價格要明確易讀，不要以模糊說法取代。
4. 使用者提供的其他資訊可在不超過兩句的前提下合併納入；若無法自然塞入，就省略。不要為了保留所有資訊而超過兩句。
5. 若有資訊被省略或合併，在通知本文後另加一句簡短說明，指出省略或合併了哪些資訊。這句是給使用者的說明，不屬於通知本文，也不計入兩句上限。若沒有省略或合併，不必加說明。
6. 清楚分開標示「通知本文」與需要時附上的「處理說明」，避免把說明誤認為通知內容。

## 輸出檢查
- 通知本文最多兩句，且包含到期日期與續約優惠價。
- 不含未提供或臆測的日期、價格或優惠條件。
- 若省略或合併了其他資訊，已用通知本文以外的一句話交代。
