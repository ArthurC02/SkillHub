# 裝潢工程報價提案書

協助屋主把已提供的資料整理成清楚、可核對的工程報價提案。不可自行捏造尺寸、工法、單價、工期、師傅的回覆或採購結果。電話聯絡和登入供應商系統涉及即時外部操作；若目前沒有可用且經授權的電話或系統工具，只能準備聯絡內容、核對清單與待辦，不得聲稱已聯絡、已約定或已下單。

## 1. 蒐集並整理需求

先閱讀屋主提供的資料，按下列項目整理已知資訊、缺漏資訊及互相矛盾之處：

- 屋主聯絡方式、工程地址及方便聯絡時段（只在任務需要時收集）。
- 屋型、屋齡、坪數或可供估算的尺寸、現況照片或圖面。
- 施工範圍、各空間需求、指定材料、品牌、型號、顏色及施工品質要求。
- 預算範圍、希望開工及完工時間、是否有人居住、搬運或施工限制。
- 既有設備拆除、廢料清運、保護工程、水電或其他相關需求。

把資料標記為「屋主已確認」、「待屋主補充」或「需現場丈量／師傅確認」。尺寸不足時，不要將概估寫成精確數量或固定價格。先提出影響估價與施工的關鍵問題，再依已取得資訊製作可行版本；缺漏仍未解決時，明確列出假設及待確認事項。

## 2. 確認丈量安排

準備一份丈量聯絡摘要，至少包含工程地址或區域、希望丈量的空間與工程範圍、可配合日期時段、聯絡人及聯絡方式。向屋主確認可提供給師傅的聯絡資料，並取得聯絡師傅或安排丈量的授權。

若有經授權且可用的電話工具，聯絡師傅時確認：

1. 師傅是否承接此類工程及是否需要先看照片或圖面。
2. 可到場的日期、具體時段、預估所需時間及集合方式。
3. 屋主是否需要在場，以及丈量前要準備或清空什麼。
4. 丈量是否收費、費用如何計算，以及丈量後何時可提供估價。
5. 是否有其他必須先確認的現場條件。

重述日期、時間、地址和費用以核對理解，並記錄師傅姓名、聯絡結果及待辦。只有在師傅明確確認後才標記為「已約定」；否則記為「待師傅回覆」並請屋主選擇或補充可配合時段。沒有可用電話工具或未獲授權時，不得致電；改為提供可直接傳送的訊息草稿與待問事項。

## 3. 編製報價提案

以表格逐項呈現工程，欄位至少包括：項次、空間／工程項目、工作內容與工法、規格或材料、單位、數量、單價、小計、備註及價格狀態。只填入來源明確的數值。若數量、單價或價格尚待丈量／供應商報價，填「待確認」或「概估」，不可用看似確定的數字掩飾不確定性。

提案至少包含：

1. **提案基本資料**：提案日期、屋主或案件名稱、工程地址（若已提供）、版本及報價有效期限（只有在有依據時列出）。
2. **需求摘要與施工範圍**：逐空間說明包含的工程及交付內容。
3. **工程報價明細**：分項列數量、單位、單價、小計及估算依據；列出小計、稅費、折扣與總計，並說明是否含稅。僅在資料足以計算時加總，避免重複計入。
4. **材料規格**：品牌、型號、尺寸、顏色、數量及替代品規則。尚未選定或供貨未確認的材料標為待確認。
5. **工期與付款方式**：只採用屋主或承包方已確認的條件；未確認則列為待協議，不自行訂立承諾。
6. **不包含項目與現場假設**：清楚列出未包含工程、未知現況可能造成的變更，以及增減項須經雙方確認後才調整費用或工期。
7. **待確認事項與下一步**：列出丈量、材料選樣、供應商供貨確認及需屋主決定的事項。

用清楚、務實的繁體中文撰寫，不把提案說成正式契約或保證報價。清楚區分「固定報價」、「概估」與「待確認」。若資訊不足以形成可信報價，提供分項估價框架及待補資料，不製造數字。

## 4. 準備材料採購

依提案建立採購清單，逐項核對供應商、品名、品牌、型號／規格、顏色、數量與單位、可接受替代品、交貨地址、收貨人、希望到貨日、運費、稅額及付款條件。材料數量應以已確認的丈量或核准清單為準；若仍有損耗率或備料量待決定，先標明計算依據並請屋主／師傅確認，不擅自加量。

登入供應商採購系統及送出訂單會造成外部交易。若沒有可用且經授權的系統工具，或尚未取得屋主對供應商、品項、數量、價格、付款及交貨條件的明確核准，不得登入或下單。改為整理可供人工輸入的訂購資料，並列出缺漏及需核准事項。

若環境提供已授權的採購工具且屋主已明確核准下單，送出前再次核對品項、數量、單價、總額、稅運費、交貨資訊、付款方式及替代品條款；任何差異都先暫停並詢問。送出後只根據系統實際回傳記錄訂單編號、狀態、金額及預計交期，不推測成功與否。

## 5. 交付前檢查

- 分項範圍與屋主需求一致，排除重複、遺漏或含糊項目。
- 所有價格、尺寸、工期及材料規格都有來源，或明確標為概估／待確認。
- 小計與總計計算正確，稅費及包含／不包含範圍說明清楚。
- 丈量只在師傅明確確認後記為已約定，並保留待確認事項。
- 採購只在授權與核准條件齊備後進行；未執行的聯絡或訂購明確標示為待辦。
- 最後提供可直接交給屋主的提案，以及簡短的待補資料、待確認事項和下一步清單。
