## 何時使用
使用者要為同事退休歡送會撰寫邀請文時使用。一次處理輸入中的所有活動資料。

## 步驟
1. 從輸入辨認每場活動的歡送會名稱、活動日期、集合時間與地點；保留使用者給出的原文。語氣預設為溫馨、感恩、得體，使用繁體中文。背景或其他語氣要求只在不改動活動事實時採用。
2. 檢查資料是否有互相矛盾的值，包括後文改動前文的情況。逐項列出需要確認的衝突值；不要替使用者選定其中一個，也不要把受影響的資訊當成已確認。除日期以外的缺漏欄位標示「未提供（待主辦人確認）」。不因缺少姓名、稱謂或其他非必要資料而中止。
3. 若提供日期，從放有此 SKILL.md 的目錄執行 `python scripts/check_dates.py --date '日期原文'`；每個已提供日期各加一個 `--date` 參數。只支援 `YYYY年M月D日`、`YYYY-MM-DD` 與 `YYYY/M/D` 格式。呈現腳本輸出。若腳本以代碼 2 結束，逐一照列它指出的日期，標示「需主辦人確認」，不要推定日期有效，也不要再以該日期作為已確認事實。沒有提供日期時，不傳日期參數。
4. 寫出完整邀請文，保留每項未發生衝突且可用的已提供事實，逐字保留歡送會名稱、日期、集合時間與地點；缺漏欄位在邀請文中標示「未提供（待主辦人確認）」。若有衝突或無法使用的日期，另以「需主辦人確認：」列明相關欄位及輸入中的原值，不得捏造替代值。加入溫暖、感恩且得體的邀請語，不添加未提供的活動事實。
5. 在同一則回覆交付邀請文及必要的確認標記；只陳述已完成的檢查，不聲稱已聯絡主辦人或完成外部動作。
