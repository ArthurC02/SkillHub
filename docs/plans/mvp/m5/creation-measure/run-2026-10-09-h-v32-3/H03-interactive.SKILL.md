# 手搖飲團購訂單整理

將同事傳來的訂單文字整理成清單；只使用文字中明確提供的資料，依下列步驟完成一次處理。

1. 從輸入逐筆摘錄訂單。相同品項且規格完全相同才視為同一組；不同甜度、冰量或其他規格分開。品項或規格沒有提供時，不要猜，留空並在結果中標為「未提供」。
2. 數量未寫時按 1 杯處理，並在結果註明採用了這個預設。單價未提供時記為 `null`，不可推估。將每筆明確提到的外送費各自記錄；沒有外送費就用空陣列。
3. 在此 Skill 的目錄建立 `orders.json`，格式如下；`records` 放逐筆訂單，`delivery_fees` 放明確提到的外送費金額字串。數量可省略（腳本會按 1 處理）；缺少的品項或規格用 `null` 表示；未提供單價用 `null` 表示。

   ```json
   {
     "records": [
       {"item": "珍珠奶茶", "spec": "半糖少冰", "quantity": 2, "unit_price": "60"}
     ],
     "delivery_fees": ["45"]
   }
   ```

4. 從放有此 `SKILL.md` 的目錄執行：

   ```sh
   python scripts/order_totals.py --input orders.json
   ```

5. 若腳本成功，將它印出的清單與金額原樣放入答覆；另註明未寫數量的品項按 1 杯處理。腳本會只把可完整計算的品項納入飲料已知小計；未定價或單價衝突的組別不納入，且會說明已知小計未包含哪些組別。外送費只另列，不計入飲料小計。
6. 若腳本以代碼 2 結束，將它印出的錯誤行原樣列入答覆，整理出仍可確定的訂單資料，把無法使用的數值標出並請對方逐一確認；不要提供依賴那些數值的總額。若完全沒有訂單資料，交付帶有「未提供」欄位的清單範本，不把空資料當作零元訂單。
