## 使用時機
使用者要求計算一筆或多筆運動中心場地包場費用時，依下列步驟處理。

## 步驟
1. 從輸入逐筆辨認包場時數及器材租借件數；保留使用者提供的原始值。缺少任一值時，不猜測，標示「未提供」，該筆不計算；其他完整紀錄仍可計算。若同一筆對同一項目提供了不同值，列出各個原值並標示「請確認」，不計算該筆。數值無法判讀或不可能為正確資料時，也列出原值並請使用者確認，不計算受影響的紀錄；不要追問其他資訊。
2. 若完全沒有完整紀錄，照樣提供可用的結果欄位模板，缺少的值標示「未提供」。
3. 對每筆完整紀錄執行下列命令；每筆使用一個 `--record "時數,件數"`，多筆資料重複此選項。命令須從本 SKILL.md 所在目錄執行：
   `python scripts/calculate_fees.py --record "時數,件數"`
4. 呈現腳本輸出的內容。若程式以代碼 2 結束，保留它列出的每個不能使用的值，請使用者逐項確認；不補算受影響紀錄，也不提供依賴那些值的金額。完整紀錄的計算結果仍照常呈現。
5. 使用繁體中文交付結果，逐筆列出包場時數、器材件數、時數費、器材費、未套上限小計及套用上限後應收總額；清楚說明只採用已確認的計費規則，不加入其他費用、折扣或稅金。標明採用的假設：零時數或零件數的該項費用為零；大於零且不超過兩小時按最低時數級距；小數時數按比例計算超過四小時部分的加收費；器材件數須為整數。不要把任何缺少的資料標成待補或自行推測。
