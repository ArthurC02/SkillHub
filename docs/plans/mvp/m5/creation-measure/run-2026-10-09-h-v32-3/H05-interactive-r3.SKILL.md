## 使用步驟

1. 從使用者當次訊息擷取一位會員的稱呼、會籍到期日、續約優惠價及其他資訊。保留每個值的原有文字和格式，不補造事實。若未指定語氣，採用親切、簡潔的語氣，不另加語氣預設說明。
2. 若同一欄位出現多個值（包括後文更正前文），將每個原值依出現順序分別傳入下列命令；缺少的欄位不傳參數。日期與價格都沒有重複時，各傳一次。日期只接受 `YYYY年M月D日` 或 `YYYY-MM-DD` 格式供有效性檢查；通知仍保留輸入原文。

   ```sh
   python scripts/check_facts.py --expiry '輸入中的到期日' --price '輸入中的優惠價'
   ```

   依實際輸入替換引號中的文字；重複值以重複旗標傳入，例如再次加入 `--expiry '另一個到期日'`。沒有到期日或優惠價時，省略該旗標。若命令回報無法使用的值，不把它用作通知事實；在通知外逐一照錄該值，寫明無法使用的原因，並請使用者確認。仍交付通知草稿，無效或衝突欄位以 `【到期日期未能採用】` 或 `【續約優惠價未能採用】` 標示，不以猜測值替代。
3. 撰寫一則繁體中文通知。若有提供會員稱呼，納入稱呼；通知正文必須包含可用的到期日期與續約優惠價。缺少必填值時使用 `【到期日期未提供】` 或 `【續約優惠價未提供】`，稱呼未提供時使用 `【會員稱呼未提供】`。不得把缺少的資料當作已知，也不得因稱呼或其他非必填資料缺漏而停止撰寫。
4. 先盡量保留其他資訊，並依其在輸入中的順序呈現。正文空間不足時，只合併輸入順序中相鄰的相關資訊，並把合併內容留在該組資訊原本的位置；不得把較後面的資訊併入稱呼、到期日或優惠價等前置欄位，也不得移到較早資訊之前。仍無法容納時，依輸入順序省略資訊。所有提供的事實都須在通知或通知外的說明中照錄；被省略的資訊列於說明，被合併的資訊也明確指出。若沒有省略或合併，不加這項說明。只要有合併或省略，就必須在正文外用一句說明，逐項點明哪些資訊被合併、哪些被省略；不可只說明語氣或概括處理方式。
5. 將通知正文單獨寫入 `notice-body.txt`，以繁體中文列出兩句以內；若有額外說明、預設或無法使用值的確認事項，放在正文之外。從輸入原文取得已提供的稱呼、到期日和優惠價，依序執行下列命令；未提供的必填資料以相應的 `【…未提供】` 標記作為 `--require` 值。若某個已提供值因無法使用而沒有放進正文，使用步驟 2 的未能採用標記作為該值的 `--require` 值。

   ```sh
   python scripts/check_output.py notice-body.txt --max-sentences 2 --require '會員稱呼或相應標記' --require '到期日或相應標記' --require '優惠價或相應標記'
   ```

   若未印出 `OK`，按錯誤修正文案並重跑，直到印出 `OK`。將正文與適用的正文外說明一併寫入 `notice.txt`，執行 `cat notice.txt`，並且只以該檔案內容作為回答；不得聲稱已傳送通知。
