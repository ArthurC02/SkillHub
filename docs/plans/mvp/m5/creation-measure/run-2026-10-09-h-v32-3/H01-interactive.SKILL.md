# 停車場計費

依使用者提供的停車時數逐筆計費，將不足一小時的部分無條件進位至整數小時，套用費率及單次 300 元上限。

## 步驟

1. 從輸入擷取每筆停車時數，保留其原始寫法；若一筆也沒有提供，直接交付以下可填寫的計算結果格式，並將未知內容標為「未提供」，不詢問使用者：

   ```text
   原始時數：未提供
   進位後時數：未提供
   計算明細：未提供
   應付金額：未提供
   ```

2. 從目前工作目錄（其中放有本檔案）執行 `python scripts/parking_fee.py`，並將每筆原始時數各自作為一個位置參數，使用引號保留原始數值文字。只傳入計算所需的時數，不要求其他資料。
3. 若指令退出碼為 2，照原樣交付指令印出的單行訊息，並告知使用者需確認其中列出的值後再提供可用時數；不計算或呈現依賴該值的金額。否則直接將指令輸出的逐筆結果作為答覆，不另改寫或加入未提供的事實。

費率及進位方式由腳本計算；只有需要了解或修改該計算規則時，才閱讀 [計費規則參考](references/rates.md)。
