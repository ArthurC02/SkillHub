## 計費步驟

1. 確認單次停車的實際時數。若提供入場與離場時間，先計算兩者相差的時數；若只提供時數，直接使用該數值。若資訊不足以算出時數，先詢問缺少的資料。
2. 將實際時數中不足一小時的部分無條件進位至整數小時：使用 `進位後時數 = ceil(實際時數)`。例如 1.2 小時進位為 2 小時，3 小時整則仍為 3 小時。
3. 依進位後時數計算未套上限的費用：
   - 進位後時數為 1 小時以下（含 1 小時）：50 元。
   - 超過 1 小時且在 3 小時以下（含 3 小時）：120 元。
   - 超過 3 小時：120 元，加上超過 3 小時的每小時 40 元，即 `120 + (進位後時數 - 3) × 40` 元。
4. 將計算結果套用單次停車費用上限：若未封頂費用超過 300 元，收費改為 300 元；否則收取未封頂費用。
5. 回覆實際停車時數、進位後時數、費率計算與最後應付金額。保持金額為整數元。

## 輸入檢查

- 時數必須是非負數。若輸入為負數、時間順序不合理，或資料彼此矛盾，請指出問題並要求更正，不要猜測。
- 若停車時數為 0，依進位後時數 0 屬於「1 小時以下」處理，收 50 元。

## 計算示例

- 1.2 小時 → 進位為 2 小時 → 120 元。
- 3 小時 → 進位為 3 小時 → 120 元。
- 3.1 小時 → 進位為 4 小時 → 120 + (4 - 3) × 40 = 160 元。
- 8 小時 → 進位為 8 小時 → 120 + (8 - 3) × 40 = 320 元 → 套用上限後收 300 元。
