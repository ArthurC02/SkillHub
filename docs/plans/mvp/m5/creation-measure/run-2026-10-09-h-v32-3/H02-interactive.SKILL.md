# 駕訓班學費退費資格分類

依提供的學員資料逐筆分類退費資格。只套用此處列明的規則，不推算日期、不計算退款金額，也不作其他法律判斷。

## 步驟

1. 從輸入辨識每筆學員資料的識別名稱、是否已通過路考並取得駕照，以及繳費至今天數。保留已提供的名稱和數值原樣。接受明確的「是／否」和非負整數天數；若同一學員的同一欄位有互相矛盾的值（包括後文改動先前數值），視為需確認的無效輸入，不自行選一個值。
2. 若完全沒有學員資料，直接交付以下可填寫格式，不要猜測資料：

   ```text
   學員名稱：〔未提供〕｜已通過路考並取得駕照：〔未提供〕｜繳費至今：〔未提供〕天
   ```

   若只有部分資料缺漏，將缺少的欄位標為「未提供」；不要用未完整的欄位執行分類。完整且有效的其他資料仍照下一步處理。
3. 對完整且有效的資料，每筆以 `名稱|是或否|天數` 格式傳入腳本；每筆使用一個 `--student`，名稱與欄位以 `|` 分隔。從包含本 SKILL.md 的目錄執行：

   ```bash
   python scripts/classify_refund.py --student '學員甲|是|5' --student '學員乙|否|30'
   ```

   上例只示範命令格式；實際執行時，將每筆參數換成輸入中提供的原值。直接呈現腳本印出的逐筆分類結果，不另行改寫標籤或自行計算。
4. 若腳本回報無法使用的值或互相矛盾的資料，呈現其錯誤訊息，不提供依賴該值的分類結果；逐一請對方確認訊息所列的值。對其他完整有效的學員資料仍可另行執行腳本並呈現結果。不要追問無關資料。
5. 若缺少名稱但分類所需的兩個欄位完整，仍執行分類；名稱欄標為「未提供」。不得把未提供的事實寫成已知。
