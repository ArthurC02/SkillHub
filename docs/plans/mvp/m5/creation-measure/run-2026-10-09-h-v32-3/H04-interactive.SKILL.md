## 用途與限制
依每筆訪視的開始日期、開始時間及國定假日標記，計算應收費用並逐筆列出。日期與時間以台灣當地時間解讀；國定假日標記由使用者提供。本技能不查詢或推斷假日、不計算訪視時長，也不處理其他折扣或費用。

## 步驟
1. 從使用者訊息辨認一筆或多筆訪視。每筆需要日期、開始時間，以及是否為國定假日。保留使用者提供的事實原樣，不自行更正或推斷。
2. 遇到缺少的必要欄位，在該筆輸出標示「未提供」，應收費用標示「未計算」，並附上可直接補填的日期、開始時間、國定假日標記欄位。沒有任何訪視資料時，也提供一筆這樣的可用空白範本。未要求的姓名或標籤不會阻止計算。
3. 若同一筆資料有互相矛盾的值（包括後來的敘述改動先前數值），或日期、時間、假日標記無法使用，列出每個原始值並請使用者確認；不計算依賴該值的費用。不要提出其他問題，也不要把任何已提供事實標成待提供。
4. 對欄位齊全且無衝突的訪視，從本 SKILL.md 所在目錄執行下列命令。每筆訪視使用一個 `--visit`，格式為 `日期,時間,是否國定假日`；日期用 `YYYY-MM-DD`、時間用 `HH:MM`，假日標記用 `是` 或 `否`。將實際值代入引號內，不要把尖括號或範例值當成資料。

   ```sh
   python scripts/calculate_fee.py --visit '2026-10-13,14:00,否' --visit '2026-10-14,06:59,否'
   ```

5. 使用腳本印出的逐筆結果作答，保留每筆日期、時間、假日標記與金額；不要另加總不同訪視。平日基本費是新台幣 1,500 元；夜間加成後總費用是新台幣 1,800 元；國定假日加成後總費用是新台幣 2,250 元。夜間為每日 21:00（含）至隔日 07:00（不含）；國定假日為當日 00:00 至 24:00。任何一個加成時段符合即適用加成費用，金額取代基本費；夜間與國定假日重疊時只採國定假日費用。
