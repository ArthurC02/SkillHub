## 用途與界線

依輸入製作可供屋主確認和使用的裝潢工程報價提案、丈量聯絡訊息草稿與建材採購清單。只整理和計算已提供的資料；不打電話、不登入供應商系統、不下單，也不宣稱這些事已完成。

## 步驟

1. 從屋主提供的內容擷取工程需求、尺寸與數量、施工單價、總價項目、幣別與稅率，以及材料、供應商、師傅聯絡方式、丈量時段和地址。保留輸入中每項事實的原樣與單位；同一資料有不同說法時，包括後文改動前文數值，逐一列為「待確認」，不得自行選一個值。
2. 檢查數值、日期和資料一致性。負數數量、不存在的日期或互相矛盾的數值都列出原值，標示「待確認」，請提供資料的人逐項確認；不計算任何依賴這些值的金額。不要追問其他事情。缺少的資訊寫「未提供（待確認）」；不因缺少姓名、標籤或日期而停止可獨立完成的計算或提案。
3. 將可計算的施工項目整理成 `名稱|數量|單位|單價` 格式的 `--work-item` 參數；一式總價整理成 `名稱|金額` 格式的 `--work-lump` 參數。材料逐項整理成 `名稱|數量|單位|單價` 格式的 `--material-item` 參數。資料缺少時保留空欄，不補值。僅在屋主提供稅率時傳入 `--tax-rate`；不自行假設稅率或幣別。
4. 在含有本檔的目錄執行 `python scripts/quote_totals.py`，附上步驟 3 組成的參數，並使用它列出的工程與材料金額。腳本回報無法使用的數值時，逐字記下該值並列為「待確認」，請屋主確認；不要用該值或任何依賴它的金額。計算只依輸入精度，不自行四捨五入。沒有提供的稅率、費用或價格不得補算。工程報價與材料採購金額必須分開；材料金額不得併入工程報價總額。
5. 以繁體中文交付完整提案，清楚分節並用表格呈現：
   - **工程範圍與報價**：列出各工程項目、輸入的數量、單位、單價和腳本結果。區分完整小計、已知項目小計與因缺值待確認的金額；若提供稅率，列出稅額及含稅總額。稅率未提供時寫明「未提供」，不套用稅率。幣別未提供時寫明「未提供」，不指定幣別。
   - **待確認事項**：列出缺少的施工日期、付款條件、保固條件、規格、交易條件，以及步驟 2 找到的異常或矛盾值。逐項指出須由屋主或相關人員確認的內容，不把缺值寫成已知事實。
   - **丈量聯絡訊息草稿**：依輸入寫給師傅的訊息，包含已提供的姓名、電話、地址與可丈量時段。多個時段尚未確認時，保留各選項並註明「尚未確認」；不可表示已撥打或已約定。未提供的聯絡資訊標為「未提供（待確認）」。
   - **建材採購清單（與工程報價分開）**：逐項列出已提供的材料名稱、數量、單位、單價、小計及採購金額結果。未提供的供應商、品牌、規格、帳號、運送費、供貨日期或其他交易條件標為「未提供（待確認）」；不得推定價格包含未提供的費用或稅額，也不得表示已登入或已送出訂單。
6. 直接在本次答覆交付完整提案、訊息草稿及清單，不只提供計畫或索取資料。最後各用一行說明未能代辦的對外行動及須由誰執行：電話聯絡由使用者自行處理；供應商系統登入及下單由使用者自行處理。
