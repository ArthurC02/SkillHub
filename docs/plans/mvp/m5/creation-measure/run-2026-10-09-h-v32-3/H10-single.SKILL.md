## 計算步驟

1. 確認包場時數 `h` 與器材租借件數 `n`。時數不得為負數，件數須為非負整數；若資料缺漏、無效或互相矛盾，先詢問或指出需要修正的欄位。
2. 計算場地費：
   - `h = 0`：0 元。
   - `0 < h ≤ 2`：800 元。
   - `2 < h ≤ 4`：1400 元。
   - `h > 4`：`1400 + 300 × (h - 4)` 元。
3. 計算器材費：
   - `n = 0`：0 元。
   - `1 ≤ n ≤ 5`：200 元。
   - `5 < n ≤ 10`：400 元。
   - `n > 10`：`400 + 50 × (n - 10)` 元。
4. 將場地費與器材費相加，得到未套上限的小計。兩項費用獨立計算，不互相抵扣或合併級距。
5. 單次總費用為 `min(小計, 3000)`。若小計超過 3000 元，收費仍為 3000 元。
6. 回覆時列出輸入的時數與件數、場地費、器材費、小計，以及套用上限後的應付總額。若上限生效，明確說明原小計及總額已封頂為 3000 元。

## 未明訂情況

若時數含小數，且超過 4 小時的部分不是整數小時，規則未說明應按比例計費或不足一小時進位。不要自行假設；先詢問計費方式。若使用者尚未提供答案，可說明採按比例計算與按不足一小時進位計算時的不同結果，並標示為待確認，不要把任一種當成確定收費。整數時數可直接依公式計算。
