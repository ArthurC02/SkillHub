## 整理收購驗收清單

1. 從使用者提供的文字或單據資料中擷取每筆收購的日期、品項、數量及收購單價。只整理已提供的資訊，不推測品項、數量、單價或驗收結果。
2. 將日期統一為 `YYYY-MM-DD`；若原始日期缺少年份或有歧義，先保留原寫法並詢問使用者，不要自行猜測。
3. 依收購日期分組；同一天同一品項只有在數量和單價明確可合併時才合併，否則分列保留原始紀錄。
4. 對每筆資料計算金額：`數量 × 收購單價`。逐筆核對乘算，再加總各日期小計及全部日期的總金額。
5. 保留使用者提供的貨幣單位及精度。若貨幣單位未提供，不要假定幣別；在金額旁註明「幣別未提供」。
6. 若數量或單價缺漏、格式不清或彼此矛盾，列出可確認的資料並明確標記待確認欄位；不要把缺漏值當成零，也不要將未確認的項目納入確定總額。可另列已確認項目的暫計金額。
7. 以清楚的表格回覆，欄位依序為：收購日期、品項、數量、收購單價、金額。表格後列出各日期小計及總金額；若存在待確認資料，將暫計金額與尚未計入的項目分開說明。
8. 最後檢查每筆金額與加總是否一致。除非使用者提供相關資料並要求整理，勿自行新增成色、品牌、品況判定或其他驗收標準。
