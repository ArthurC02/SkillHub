# 二手服飾收購驗收清單

依照輸入製作逐筆收購清單。每筆紀錄各列一行，相同日期或品項不合併；不推測缺漏資料、不換算幣別。

1. 從使用者訊息擷取每筆收購紀錄及其日期、品項、數量、收購單價。保留原文事實與日期、幣別表示；未提供的欄位在清單標為「未提供」。依輸入中的更正辨識同一欄位互相矛盾的值；不得自行選一個值。
2. 檢查可辨識的日曆日期、數量與單價。將數字值交由腳本檢查及計算；腳本能檢查的日期格式包括 `YYYY-MM-DD`、`YYYY/MM/DD`、`MM/DD/YYYY`、`DD/MM/YYYY`。其他日期格式照原文保留，不自行改寫。負數數量、無效日期或無法解析的數字不得拿來計算；逐一列出原值並註明「需確認」，不提出其他問題，也不計算依賴該值的金額。矛盾值也全部原樣列出並註明「需確認」，不計算依賴該欄位的金額。其他有效紀錄仍可計算。
3. 對可計算的完整紀錄，在目前目錄（含此 `SKILL.md` 的目錄）執行腳本。每筆紀錄使用一組 `--record`，依序傳入日期、品項、數量、單價；品項或其他文字含空白時加上引號。數字參數只傳入數字，不含幣別符號；結果中的原始值仍按輸入呈現。
   ```sh
   python scripts/calculate_intake.py --record '2026-10-01' '牛仔褲' '2' '150' --record '2026-10-01' '襯衫' '3' '80'
   ```
   依腳本輸出製作各筆金額及合計。若有未提供、矛盾或無效的數字欄位，只把其餘可計算紀錄交給腳本，將腳本合計標示為「可計算明細小計」，並說明未能計算整批總金額的原因；不得把小計稱為整批總金額。沒有可計算紀錄時，不執行腳本，也不列總金額。
4. 直接交付完成的 Markdown 清單：欄位為日期、品項、數量、收購單價、該筆金額；每筆輸入紀錄保留一列。缺少的欄位寫「未提供」，含矛盾或無效值的欄位保留原值並註明「需確認」，其金額寫「未計算」。在表格下列出腳本算出的合計；有不能納入合計的紀錄時改列可計算明細小計，並簡述未計入原因。未指定幣別時不加幣別符號。若需使用者確認，以「需確認：」逐項列明值與原因，最後直接交付清單，不以問題或待辦承諾結尾。
