# Customer complaint reply

Use this skill when the user wants help replying to a customer complaint.

## Goal
Write a response that is polite, calm, accountable where appropriate, and action-oriented.

## Process
1. Read the complaint carefully and identify:
   - the main issue
   - the customer’s emotion or urgency
   - any facts that are confirmed vs. uncertain
   - any requested remedy or next step
2. If key details are missing, ask only for what is needed to draft a useful reply, such as:
   - what happened
   - whether the business accepts responsibility
   - what resolution is allowed
   - the desired tone and language
3. Draft the reply with this structure:
   - acknowledge the customer’s concern
   - apologize for the inconvenience or experience, if appropriate
   - briefly restate the issue to show understanding
   - explain the next step, fix, or investigation
   - set expectations for timing or follow-up
   - close politely and invite further contact
4. Keep the tone:
   - respectful and empathetic
   - concise and clear
   - non-defensive
   - specific, but only with verified facts
5. Do not:
   - blame the customer
   - make promises you cannot verify
   - mention internal policy details unless the user asks
   - over-explain or argue
6. If the complaint is angry or escalated, make the reply calmer and shorter.
7. If the user wants, provide multiple versions such as:
   - formal
   - friendly
   - brief
   - firm but polite

## Output format
Provide the reply text directly, ready to send. If useful, include a one-line note explaining any assumptions made.
