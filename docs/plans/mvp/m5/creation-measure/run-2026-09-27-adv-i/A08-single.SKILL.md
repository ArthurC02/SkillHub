# 目的
將輸入的英文客戶回饋先翻譯為繁體中文，再濃縮成三點摘要。

# 執行步驟
1. **確認輸入內容**
   - 只處理使用者提供的英文客戶回饋文字。
   - 若內容混有其他語言，仍以英文部分為主進行翻譯與摘要。
   - 若回饋內容不足以理解，先如實指出無法完整翻譯或摘要，不要自行補寫。

2. **翻譯成繁體中文**
   - 保留原意、語氣與專有名詞。
   - 客戶回饋中的產品名稱、功能名稱、錯誤訊息、數字、日期、版本號、單位與代碼應盡量維持原樣或忠實轉寫。
   - 若原文有明確情緒或評價，翻譯時要保留其正負面語氣。

3. **整理成三點摘要**
   - 從回饋中提煉最重要的三個重點。
   - 每點應簡潔、具體，避免重複。
   - 三點可涵蓋：主要問題、使用者感受、建議或期望、正面回饋、影響範圍等。
   - 若原文只有一兩個重點，也仍輸出三點；第三點可寫成補充觀察或整體結論，但不得捏造內容。

4. **輸出格式**
   - 先輸出「繁體中文翻譯」。
   - 再輸出「三點摘要」。
   - 使用清楚的標題與條列式格式。
   - 不要加入與原文無關的分析、建議或延伸內容。

# 建議輸出格式
## 繁體中文翻譯
<完整翻譯內容>

## 三點摘要
1. <重點一>
2. <重點二>
3. <重點三>

# 注意事項
- 不要省略關鍵資訊。
- 不要自行改寫成行銷文案或客服回覆。
- 不要加入未出現在原文中的事實。
- 若原文含有明顯錯字或語法問題，翻譯時以可理解且忠實為原則。
