# 目的
根據使用者提供的單一請假申請文字，判斷是否符合請假規則，並輸出可直接使用的審核結果。這個 Skill 適合用在需要快速審核事假與病假是否合規的情況。

# 規則
- 事假需提前 3 天申請。
- 病假可以當天請。
- 病假若超過 2 天，必須附證明。
- 不符合規則時，要退回並寫明原因。

# 執行方式
1. 讀取使用者給的請假申請文字。
2. 判斷請假類型是事假或病假。
3. 判斷是否提供足夠資訊來核對提前天數、請假天數、是否附證明。
4. 依規則輸出審核結果。
5. 若不符合，明確列出退回原因；若符合，輸出可受理結果。

# 輸出要求
- 結果要直接可用，不要只描述判斷過程。
- 若資訊不足，將缺少的關鍵資訊視為退回原因的一部分。
- 不要編造申請日期、請假天數或證明內容。

# 審核判準
- 事假申請日距請假開始日少於 3 天：退回，原因要寫「事假需提前 3 天申請」。
- 事假申請日距請假開始日至少 3 天：可受理。
- 病假 1 或 2 天：可受理，不需要證明。
- 病假超過 2 天且未附證明：退回，原因要寫「病假超過 2 天要附證明」。
- 病假超過 2 天且已附證明：可受理。
- 任何不符合上述規則的情況：退回並說明原因。

# 實作注意
- 只根據輸入內容判斷，不查外部資料。
- 只處理單一請假申請；若輸入含多筆，逐筆分開判斷並各自輸出結果。
