# 目的
根據「這個月的出勤紀錄」計算每個人的加班時數，並標示出加班時數超過 46 小時的人。

# 適用情境
- 輸入是本月的出勤紀錄、打卡紀錄、工時表、班表加班欄位，或可由紀錄推算加班的資料。
- 需要按人彙總加班時數。
- 需要找出超過 46 小時的名單。

# 處理步驟
1. **確認資料範圍**
   - 只使用「這個月」的紀錄。
   - 若資料跨月，先篩出本月資料再計算。
   - 若資料中有多個工作地點、部門或專案，先確認是否要合併計算；若未特別說明，按人合併。

2. **辨識可用欄位**
   - 找出每筆紀錄中的人員識別資訊，例如姓名、員工編號。
   - 找出加班時數欄位；若沒有直接欄位，依資料規則計算加班。
   - 若同一人有多筆紀錄，準備加總。

3. **計算每筆加班**
   - 若資料已提供加班時數，直接採用。
   - 若需由上下班時間推算，依資料中的規則計算加班，不要自行假設未提供的制度。
   - 若有缺漏或格式不明，先標記為「需確認」，不要硬算。

4. **按人彙總**
   - 將同一人的本月加班時數加總。
   - 保留小數位時，依原始資料規則處理；若沒有規則，維持原始精度，不要任意四捨五入到整數。

5. **判定是否超過 46 小時**
   - 對每個人的總加班時數做比較。
   - **超過 46 小時**者標記為「超標」。
   - **等於 46 小時**不算超過。

6. **輸出結果**
   - 以清楚表格列出：
     - 人員名稱/編號
     - 本月加班總時數
     - 是否超過 46 小時
   - 另外列出超標名單。

# 輸出格式建議
| 人員 | 本月加班時數 | 是否超過46小時 |
|---|---:|---|
| A | 48.5 | 是 |
| B | 46.0 | 否 |

超標名單：
- A（48.5 小時）

# 注意事項
- 不要把正常工時誤算成加班。
- 不要把跨月資料混入本月總計。
- 若資料不足以判定加班，先列出缺少哪些欄位或哪幾筆需要補資料。
