# 目的
將輸入文章濃縮成 50 字以內，同時盡量完整保留原文中的所有數字與人名。

# 執行步驟
1. 先通讀全文，找出：
   - 所有數字（含阿拉伯數字、百分比、日期、時間、金額、序號、範圍等）
   - 所有人名（含中文姓名、外文姓名、譯名、帶稱謂的人名）
2. 判斷文章核心主旨，只保留最重要的一句意思。
3. 撰寫摘要時遵守以下規則：
   - 總長度控制在 50 字以內。
   - 所有已辨識出的數字與人名都要保留在摘要中。
   - 若原文數字或人名過多，優先保留與主旨最相關者；若無法全部納入，需在摘要前先確認是否允許超出 50 字，或是否接受部分保留。
   - 不新增原文沒有的數字或人名。
   - 不加入多餘解釋、評語或引申內容。
4. 若原文中數字或人名彼此衝突、重複或難以辨識，先以原文最明確、最常見的寫法為準。
5. 交付前檢查：
   - 字數是否在 50 字以內
   - 是否已保留所有可辨識的數字與人名
   - 是否仍清楚表達文章主旨

# 輸出格式
只輸出摘要本身，不要加標題、說明或條列。
