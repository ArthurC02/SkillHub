# 自我介紹撰寫

## 目的
協助使用者寫出一篇適合特定情境的自我介紹。若資訊不足，先補問關鍵內容；若使用者未指定情境，先提供通用版，再可依用途改寫。

## 工作流程
1. **確認用途與語氣**
   - 先判斷自我介紹要用在哪裡：面試、課堂報告、社群簡介、活動開場、履歷、申請文件、其他。
   - 確認希望的語氣：正式、自然、親切、專業、活潑、簡短。
   - 確認長度：一句話、短版、標準版、長版。

2. **蒐集必要資訊**
   若使用者沒有提供，依情境詢問以下內容：
   - 姓名或稱呼
   - 身分／職業／學校／年級
   - 主要專長或興趣
   - 重要經歷、成就或作品
   - 想讓對方記住的重點
   - 介紹對象是誰、使用場合是什麼

3. **整理內容結構**
   依常見順序組織：
   - 開頭：姓名與身分
   - 中段：專長、經歷、興趣或特色
   - 結尾：目前目標、期待、聯絡或收尾句

4. **撰寫原稿**
   - 用清楚自然的句子，不要堆砌形容詞。
   - 內容要貼合用途：
     - 面試：強調能力、經歷、成果、職涯目標
     - 學校／課堂：強調學習背景、興趣、個人特色
     - 社群／個人頁：強調風格、興趣、標籤式重點
     - 活動開場：強調簡潔、好記、口語化
   - 避免過度空泛，例如「我是一個很努力的人」；改寫成具體事例。

5. **優化與校對**
   - 檢查是否符合指定字數與語氣。
   - 刪除重複資訊，讓句子更順。
   - 若有敏感或不必要的個資，提醒使用者可省略。

## 輸出方式
- 先直接給出可用版本。
- 若適合，附上 2 到 3 個不同風格版本，例如：正式版、口語版、精簡版。
- 若資訊不足，先列出最少需要補充的問題，不要直接編造內容。

## 可用模板
### 通用版
大家好，我叫＿＿＿，目前是＿＿＿。我主要對＿＿＿有興趣，也累積了＿＿＿方面的經驗。平常我喜歡＿＿＿，這些經歷讓我更了解自己的優勢與目標。希望未來能在＿＿＿持續學習與成長，謝謝大家。

### 面試版
您好，我是＿＿＿，目前擁有＿＿＿背景，主要專長是＿＿＿。過去我曾參與＿＿＿，負責＿＿＿，並達成＿＿＿成果。我對＿＿＿領域特別有興趣，也希望未來能在＿＿＿持續發揮所長，為團隊創造價值。

### 簡短版
大家好，我是＿＿＿，目前從事／就讀＿＿＿，平常喜歡＿＿＿，也專注在＿＿＿。很高興認識大家。

## 注意事項
- 不要替使用者捏造學歷、經歷、職稱或成就。
- 若使用者要求「幫我寫一篇自我介紹」但沒有提供任何背景，先詢問最少必要資訊。
- 若使用者只想要範例，提供可直接套用的通用範本。
