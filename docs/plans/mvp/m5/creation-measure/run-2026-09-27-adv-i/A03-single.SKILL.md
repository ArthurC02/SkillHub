# 目的
將客服信箱中「上週」收到的客訴信整理成分類統計表，並保留可追溯的分類依據。

# 適用範圍
- 只處理已提供給你的郵件內容、匯出檔或對話紀錄。
- 不主動登入信箱、不抓取網路資料、不執行任何需要額外權限的動作。
- 若沒有提供郵件內容或匯出資料，先請使用者提供可讀取的郵件清單或匯出檔。

# 作業步驟
1. **確認資料範圍**
   - 只納入「上週」收到的客訴信。
   - 若資料中沒有明確日期，先用郵件日期欄位判定是否屬於上週。
   - 若「上週」定義不明，請先詢問使用者以哪個時區與哪段日期為準。

2. **建立分類規則**
   - 先從郵件內容中找出可重複出現的客訴主題。
   - 常見分類可包含：
     - 商品瑕疵 / 品質問題
     - 配送延誤 / 未送達
     - 退貨 / 退款
     - 訂單錯誤 / 缺件
     - 服務態度 / 客服回應
     - 帳務 / 付款問題
     - 網站 / 系統問題
     - 其他
   - 若資料中出現更明確且高頻的主題，優先使用資料本身的分類名稱。
   - 每封信只歸入一個主要分類；若內容同時涉及多項問題，以最主要、最直接的抱怨為準。

3. **逐封信標記**
   - 讀取每封客訴信的主旨、內文與日期。
   - 為每封信指定：
     - 郵件日期
     - 寄件者（若可見）
     - 主旨
     - 主要分類
     - 簡短判定理由
   - 若內容不足以判定，標記為「待確認」或「其他」，並註明原因。

4. **統計數量**
   - 依分類計算：
     - 件數
     - 佔總客訴信比例
   - 若資料足夠，也可補充：
     - 每類最常見的關鍵字
     - 代表性案例數量

5. **輸出分類統計表**
   - 先輸出總覽，再輸出明細。
   - 建議表格欄位：
     - 分類
     - 件數
     - 佔比
     - 代表內容摘要
   - 再附上逐封信明細表，欄位建議：
     - 日期
     - 寄件者
     - 主旨
     - 分類
     - 理由

# 輸出格式
## 總覽
- 總客訴信件數：X
- 統計期間：YYYY-MM-DD 至 YYYY-MM-DD

## 分類統計表
| 分類 | 件數 | 佔比 | 代表內容摘要 |
|---|---:|---:|---|
| ... | ... | ... | ... |

## 逐封明細
| 日期 | 寄件者 | 主旨 | 分類 | 理由 |
|---|---|---|---|---|
| ... | ... | ... | ... | ... |

# 品質要求
- 分類名稱要一致，不要同義詞混用。
- 佔比以總客訴信件數為分母，四捨五入到小數點後一位即可。
- 若有重複信件、轉寄信或同一事件多封追蹤信，先依使用者需求決定是否合併；若未指定，預設逐封計數，但在備註中說明可能重複。
- 不要臆測郵件內容；看不清楚的地方要標示不確定。

# 無法直接完成時
如果沒有提供可讀取的郵件資料，或資料不足以判定日期與內容，請明確說明需要使用者提供：
- 上週客訴信的匯出檔、截圖或文字內容
- 時區與「上週」的日期範圍
- 是否要合併重複信件或追蹤信
