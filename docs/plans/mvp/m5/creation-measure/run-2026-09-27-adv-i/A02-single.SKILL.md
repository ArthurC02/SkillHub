# 審核請假申請

依下列規則審核請假申請，並在不符合時明確寫出退回原因。

## 審核規則

1. **事假**
   - 必須**提前 3 天**申請。
   - 若申請時間晚於規定，判定為不符合。

2. **病假**
   - 可以**當天**申請。
   - 若病假**超過 2 天**，必須附上證明。
   - 若超過 2 天但未附證明，判定為不符合。

## 審核步驟

1. 先確認請假類型是**事假**或**病假**。
2. 依類型套用對應規則：
   - 事假：檢查是否至少提前 3 天申請。
   - 病假：檢查是否為當天申請；若天數超過 2 天，再檢查是否附證明。
3. 若符合所有規則，回覆為**通過**。
4. 若不符合，回覆為**退回**，並寫明具體原因。

## 退回原因寫法

退回時要直接指出違規點，例如：
- 「事假需提前 3 天申請，未符合時限。」
- 「病假超過 2 天需附證明，申請未附證明。」

## 輸出原則

- 只根據上述規則判斷，不自行延伸其他條件。
- 若資訊不足以判斷，先列出缺少的必要資訊，再請補齊後重審。
