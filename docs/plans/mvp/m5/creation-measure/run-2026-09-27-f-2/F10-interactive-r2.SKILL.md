# 社區庭園維護費用計算

輸入草坪面積（平方公尺）與樹木棵數，輸出單次服務總費用。

## 計算順序
1. 先把草坪面積無條件進位到最接近的 10 平方公尺。
每筆輸出都必須先寫出進位後的草坪面積，再寫出基本費、樹木費與總費用，讓讀者可直接看出每一步的計算結果。
2. 依進位後面積計算草坪基本費，並在輸出中明確標示所屬級距：
   - 100 平方公尺以下（含 100）：2000 元
   - 超過 100、300 平方公尺以下（含 300）：3500 元
   - 超過 300 平方公尺：3500 元，且超過 300 的部分每 10 平方公尺加收 100 元
   輸出時要同時寫出進位後面積與所用級距。
   當進位後面積超過 300 時，輸出必須另外列出超過 300 的部分換算成幾個 10 平方公尺單位，以及這部分加收多少元。
3. 計算樹木修剪費：前 3 棵已包含在基本費內，第 4 棵起每棵加收 300 元。
4. 先計算未封頂總額，再明確檢查是否超過 6000 元；只要超過 6000 元，最後輸出一定是 6000 元，且結果中要保留『已套用上限』的說明。
5. 輸出最後總費用。

## 輸入要求
- 需要提供草坪面積與樹木棵數。
- 若輸入缺少其中一項，輸出「未提供草坪面積或樹木棵數」。
- 若面積或棵數不是可計算的數字，輸出「輸入格式無法使用」。

## 輸出要求
- 每筆結果要列出進位後面積、草坪基本費、超過 3 棵的樹木加收費，以及總費用；若某一項為 0，也要明寫為 0 元。
- 每筆輸出格式固定為：進位後面積、草坪基本費、樹木加收費、未封頂總額、封頂後總費用；各欄位都要有明確數值。
- 輸出總費用，單位為元。
- 若輸入有多筆，逐筆計算並分行輸出。
- 不要改寫規則，也不要自行推測未提供的費用項目。
