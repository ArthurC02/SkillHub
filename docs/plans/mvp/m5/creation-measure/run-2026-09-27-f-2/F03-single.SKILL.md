# 目的
將客人傳來的訂書留言整理成結構化的訂購清單，包含：
- 書名
- 數量
- 單價
- 小計
- 書籍總金額（不含運費）
- 若有提到運費，另外列出運費，不併入書籍總金額

# 適用情境
當輸入是一段或多段客人留言、聊天訊息、備註文字，內容可能包含書名、數量、價格、運費、補充說明時，使用此 Skill 進行整理與計算。

# 處理原則
1. 只根據客人提供的文字整理，不自行補充不存在的資訊。
2. 若資訊不完整，保留已知內容，並明確標示缺漏。
3. 書籍總金額只計算書籍小計加總，不包含運費。
4. 運費若有提到，獨立列出；若未提到，標示「未提及」。
5. 若同一本書被分開提及，先判斷是否為同一項目：
   - 若書名相同且價格一致，可合併數量。
   - 若書名相同但價格不同，視為不同項目並保留原文差異。
6. 若留言中有折扣、贈品、代訂費、包裝費等非書籍費用，不要併入書籍總金額；可在備註中列出。

# 擷取規則
## 1. 辨識書籍項目
從文字中找出每一筆書籍訂購資訊。常見形式包括：
- 書名 + 數量 + 單價
- 書名 + 數量
- 書名 + 價格
- 多本書以逗號、頓號、換行、分號分隔

若數量未明示，預設為 1，但要在結果中註明「數量推定為 1」。
若單價未明示，標示為「未提供」，小計也標示為「無法計算」。

## 2. 計算小計
- 小計 = 數量 × 單價
- 金額以數字計算，保留原始幣別或貨幣符號（若有）
- 若幣別不明，沿用原文格式，不要擅自轉換

## 3. 計算書籍總金額
- 將所有可計算的小計加總
- 只加總書籍項目
- 不包含運費與其他非書籍費用

## 4. 處理運費
若文字中出現以下類型資訊，視為運費：
- 運費
- 物流費
- 郵資
- 寄送費
- 送貨費

將其獨立列出，並標示是否已知金額。

# 輸出格式
請輸出為清楚的摘要，建議順序如下：

1. 訂購清單
   - 逐項列出書名、數量、單價、小計
   - 若有缺漏，直接標示缺漏

2. 書籍總金額（不含運費）
   - 顯示加總結果
   - 若有無法計算的小計，註明「部分項目無法計算，總金額僅含可計算項目」

3. 運費
   - 若有提到，獨立列出金額或說明
   - 若未提及，寫「未提及」

4. 備註
   - 列出不影響金額計算但值得保留的資訊，例如：缺貨、改版、到貨時間、折扣、聯絡方式等

# 計算與整理步驟
1. 先通讀整段留言，找出所有書籍項目與非書籍費用。
2. 將每個書籍項目拆成：書名、數量、單價。
3. 對每項計算小計；無法計算者保留原因。
4. 加總所有可計算的小計，得到書籍總金額。
5. 檢查是否有運費，若有則獨立列出。
6. 整理成最終摘要，避免把運費算進書籍總金額。

# 注意事項
- 不要把「運費」誤算進書籍總金額。
- 不要把折扣後金額與原價混淆；若原文同時出現兩者，優先保留原文並在備註說明。
- 若客人只寫「幫我訂這幾本」但未列出書名，應明確指出無法整理。
- 若文字含有多種幣別，分別保留，不要自行換算。
- 若金額格式不清楚（例如 1,200 / 1200 / 1.200），依原文語境判斷；若仍不確定，標示為不明。
