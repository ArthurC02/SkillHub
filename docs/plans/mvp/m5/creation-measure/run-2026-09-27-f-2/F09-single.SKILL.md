# 目的
產出一段適合畫廊開幕邀請的正式、優雅文案，同時**必須完整保留且正確呈現**以下四項事實：
- 展覽名稱
- 展期（起訖日期）
- 開幕茶會時間
- 地點

# 使用時機
當使用者要你撰寫畫廊、展覽、藝術活動的開幕邀請文，且要求語氣正式、優雅，並明確要求上述資訊不能寫錯、不能省略時，使用此 Skill。

# 核心原則
1. **不得改寫事實**：展覽名稱、日期、時間、地點必須與使用者提供內容一致。
2. **不得省略事實**：即使文案篇幅較短，也要把四項資訊全部寫出。
3. **不得自行補充未提供的事實**：若缺少任一必要資訊，先詢問補齊，不要猜測。
4. **語氣正式優雅**：可使用典雅、莊重、溫和的邀請語氣，但避免過度浮誇或口語化。

# 工作流程
## 1. 檢查必要資訊
先確認是否已取得以下內容：
- 展覽名稱
- 展期起訖日期
- 開幕茶會時間
- 地點

若任一項缺漏，先向使用者詢問缺少的資訊，並明確指出需要補齊哪些項目。

## 2. 保留原始事實
撰寫時，將使用者提供的展覽名稱、日期、時間、地點原樣保留或僅做最小必要格式整理，不得更動數字、日期順序、地名、時間格式的實質內容。

## 3. 組織文案結構
建議採用以下順序：
- 開場邀請語
- 展覽名稱
- 展期
- 開幕茶會時間
- 地點
- 結尾敬邀語

## 4. 文風要求
- 用詞正式、優雅、得體
- 可使用「誠摯邀請」「敬邀蒞臨」「歡迎撥冗參與」等表達
- 避免過度冗長、重複堆疊形容詞
- 避免加入與活動無關的推測性內容

# 寫作規則
- 展覽名稱必須清楚可辨識，最好單獨成句或以標題形式呈現。
- 展期必須同時包含起始與結束日期。
- 開幕茶會時間必須明確到使用者提供的粒度，不可自行補時段。
- 地點必須完整呈現，不可簡化到造成辨識困難。
- 若使用者提供的是中英混合名稱，照原樣保留。
- 若使用者要求特定格式（例如海報文案、邀請卡內文、社群貼文），在不改動事實的前提下配合格式。

# 建議輸出範例結構
可輸出為一段完整邀請文，例如：

誠摯邀請您蒞臨「展覽名稱」開幕茶會。
本展展期為 YYYY/MM/DD 至 YYYY/MM/DD，開幕茶會將於 YYYY/MM/DD HH:MM 舉行，地點為 XXX。
敬邀您撥冗參與，共同感受展覽的藝術風采。

# 品質檢查
在完成前，逐項確認：
- 展覽名稱是否完整且未改動
- 展期起訖日期是否都出現且正確
- 開幕茶會時間是否出現且正確
- 地點是否出現且正確
- 整體語氣是否正式優雅
- 是否沒有加入未提供的事實
