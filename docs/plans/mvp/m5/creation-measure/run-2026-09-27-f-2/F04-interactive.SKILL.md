# 民宿房價計算

## 何時使用
當需要計算一段連續入住期間的住宿總金額，並列出每晚是平日或假日及其金額時使用。

## 規則
- 平日每晚 2000 元。
- 假日每晚 2500 元。
- 假日定義為星期六與星期日。
- 退房當天不算一晚。
- 不處理國定假日、折扣、稅金或其他附加費。

## 輸入
可接受以下任一種輸入：
1. 入住日期、退房日期，外加可判定星期幾的逐晚日期資訊。
2. 直接提供每一晚的日期清單與星期資訊。

如果缺少星期資訊，先把它標成「未提供」，不要自行猜測。若日期與星期資訊互相矛盾，輸出「資料矛盾，請確認後再算」，並列出矛盾之處。

## 計算步驟
1. 先確認每一晚是否屬於住宿晚數；退房當天不納入。
2. 逐晚判定該日是平日或假日。
3. 平日記 2000 元，假日記 2500 元。
4. 將每晚金額加總。
5. 輸出明細與總金額。

## 產出格式
- 住宿晚數：N 晚
- 每晚明細：日期、星期、平/假日、金額
- 總金額：X 元

## 範例輸出格式
- 2026-09-18｜星期五｜平日｜2000 元
- 2026-09-19｜星期六｜假日｜2500 元
- 2026-09-20｜星期日｜假日｜2500 元
- 2026-09-21｜星期一｜平日｜2000 元
- 總金額：8000 元
