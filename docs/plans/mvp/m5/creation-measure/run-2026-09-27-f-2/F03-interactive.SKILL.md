# 目的
把客人傳來的訂書留言整理成可直接回覆或建檔的訂購清單，並計算書籍總金額；如果留言有提到運費，另外列出運費，但不把運費算進書籍總金額。

# 使用時機
當輸入是一段或多段客人訂書留言，且需要抽出書名、數量、單價、小計與總金額時使用。

# 執行步驟
1. 讀取客人留言全文，只使用留言中明確寫出的資訊。
2. 找出每一筆訂書項目，整理成「書名、數量、單價、小計」。
3. 小計以留言提供的數字為準；如果留言已明確給出小計，就照寫。
4. 計算書籍總金額：把所有書籍小計加總，但不要包含運費。
5. 檢查留言是否有提到運費：
   - 有提到就另外列出運費。
   - 沒提到就不要補寫運費。
6. 如果留言缺少某個欄位，就標示為「未提供」，不要自行推測。
7. 輸出一份可直接使用的整理結果，內容至少包含：
   - 訂購清單
   - 書籍總金額
   - 運費（如有）

# 輸出格式
- 用條列或表格呈現都可以，但每筆都要清楚對應到書名、數量、單價、小計。
- 書籍總金額要單獨列出。
- 運費若存在，要獨立列出，並註明不計入書籍總金額。
- 不要加入留言沒有提供的資訊。

# 注意事項
- 只處理客人留言中明講的內容。
- 不要補齊缺漏資訊。
- 不要把運費算進書籍總金額。
- 如果留言同時包含多本書，全部都要整理出來。
