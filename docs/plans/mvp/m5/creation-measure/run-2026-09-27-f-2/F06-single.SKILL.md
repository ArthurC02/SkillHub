# 目標
產出一則「到府維修預約確認簡訊」，且**只能輸出簡訊本文**。

# 必要條件
- 總字數（含標點與英數字）**不超過 30 字**。
- 必須包含以下三項：
  1. 預約日期
  2. 預約時間
  3. 應收訂金金額
- 不可附加任何說明、標題、字數統計、前後綴文字。

# 寫作規則
1. 先確認是否已提供日期、時間、訂金金額。
2. 若三項資訊齊全，直接組成簡訊。
3. 句子要極短，優先使用最精簡格式，例如：
   - `預約3/8 14:00 訂金$500`
   - `3/8 14:00 訂金500元`
4. 若要保留更高可讀性，仍須確保總字數不超過 30 字。
5. 不要加入稱呼、問候、結尾敬語、表情符號或多餘標點。

# 資訊不足時
- 若缺少日期、時間或訂金金額，先向使用者索取缺少的資訊。
- 在資訊未齊前，不要自行補寫內容。

# 輸出格式
- 只輸出一行簡訊本文。
- 不要使用 Markdown。
- 不要輸出任何解釋文字。
