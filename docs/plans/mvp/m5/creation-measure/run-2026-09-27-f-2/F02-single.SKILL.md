# 目的
依照案件的語言對、字數、交期，將翻譯社案件分類為：**退件**、**加急**、或**普通**。

# 判定順序
必須依照以下順序判定，前一步已確定結果時，不再往下看：

1. **先檢查語言對是否支援**
   - 只有以下兩種語言對可接受：
     - **中文-英文**
     - **中文-日文**
   - 只要不是上述兩種之一，**一律判定為「退件」**。
   - 不論字數多少、交期多短，都不能改判。

2. **若語言對支援，再檢查是否為加急**
   - 當案件同時符合以下兩個條件時，判定為 **「加急」**：
     - **字數超過 5000 字**
     - **交期在 48 小時以內（含 48 小時）**
   - 「含 48 小時」表示 **48 小時也算加急**。

3. **其餘支援案件判定為普通**
   - 只要語言對支援，但不符合加急條件，就判定為 **「普通」**。

# 實作步驟
收到一個案件時，依序做以下檢查：

1. 讀取案件的**語言對**。
2. 如果語言對不是 **中文-英文** 或 **中文-日文**，直接輸出 **退件**。
3. 如果語言對支援，再讀取**字數**與**交期**。
4. 若 **字數 > 5000** 且 **交期 ≤ 48 小時**，輸出 **加急**。
5. 其他所有支援案件，輸出 **普通**。

# 注意事項
- 語言對判定優先於其他條件。
- 只要語言對不支援，就不要再看字數或交期。
- 加急條件必須同時成立，缺一不可。
- 交期判定以小時為單位；48 小時本身屬於加急範圍。
