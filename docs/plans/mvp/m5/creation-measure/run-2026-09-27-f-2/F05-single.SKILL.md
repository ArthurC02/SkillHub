# 開庭通知簡訊 Skill

## 目的
當使用者要你撰寫「開庭通知簡訊」時，依照以下規則產出可直接傳送的簡訊內容：
- 正文最多 3 句話。
- 正文一定要包含：**案號**、**下一次開庭日期時間**。
- 若其他資訊無法塞進 3 句話，可省略或合併。
- 另外再加 **1 句說明**，專門告知哪些資訊被省略或合併；這一句**不算在 3 句話上限內**。

## 執行步驟
1. 先確認使用者提供的資訊中，是否有以下兩項必備內容：
   - 案號
   - 下一次開庭日期時間
2. 若缺少任一必備內容，先回覆需要補充缺少的資訊，不能自行編造。
3. 將可用資訊整理成簡短、正式、清楚的中文簡訊。
4. 控制正文最多 3 句話；句號、驚嘆號、問號結尾都算一句。
5. 必須在正文中明確寫出案號與下一次開庭日期時間。
6. 其他資訊若太多：
   - 優先保留對收件人最有用的資訊，例如法院名稱、庭別、地點、注意事項。
   - 其餘資訊可省略，或合併進同一句中。
7. 在正文後面另外加上一句說明，格式可用：
   - 「已省略／合併：XXX、YYY。」
   - 若沒有省略或合併，可寫：「未省略其他資訊。」
8. 不要加入與通知無關的內容，不要解釋規則，不要超過限制。

## 產出格式
請直接輸出兩部分：
1. **簡訊正文**：最多 3 句話，必含案號與下一次開庭日期時間。
2. **省略／合併說明**：1 句，說明哪些資訊被省略或合併。

## 範例結構
- 正文：
  - 「案號：XXX。下一次開庭日期時間：YYYY/MM/DD HH:MM。請準時出庭。」
- 說明：
  - 「已省略／合併：法院地址、承辦股別。」

## 注意事項
- 若使用者要求的內容會讓正文超過 3 句，必須自行壓縮成 3 句內。
- 若資訊不足以完成通知，先請使用者補資料，不要硬寫。
- 保持語氣正式、簡潔、適合簡訊。
