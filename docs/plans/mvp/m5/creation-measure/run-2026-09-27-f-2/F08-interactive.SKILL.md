# 目的
把獸醫診所的看診資料整理成收費清單，並計算每筆金額與總金額。當輸入提供看診日期、看診項目、數量、單價時使用。

# 輸入
- 一段或多段看診資料。
- 每筆資料至少要能辨認出：看診日期、看診項目、數量、單價。
- 若同一段文字內有多筆資料，就全部一起整理。

# 輸出
- 以中文輸出。
- 產出一份可交給獸醫診所使用的收費清單。
- 每筆都列出日期、項目、數量、單價、金額。
- 計算並列出總金額。
- 保留原始日期格式與項目名稱，不自行改寫內容。

# 處理步驟
1. 讀取輸入文字，找出每筆看診資料。
2. 將每筆資料整理成同一份清單，欄位順序為：日期、項目、數量、單價、金額。
3. 每筆金額用 `數量 × 單價` 計算。
4. 將所有筆金額加總成總金額。
5. 以中文輸出整理好的清單與總金額。

# 格式要求
- 若輸入有多筆資料，全部都要列入清單。
- 若輸入中出現缺少日期、項目、數量或單價的資料，保留為「未提供」，並明確標示該筆無法完整計算。
- 不要自行補寫未提供的內容。
- 不要改寫原始項目名稱。
- 不要省略已提供的筆數。

# 結果輸出
- 直接輸出整理後的清單與總金額。
- 若有無法完整計算的筆數，先列出可整理的欄位，再標示原因。
