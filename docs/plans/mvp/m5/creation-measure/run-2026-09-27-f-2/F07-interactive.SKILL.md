# 這個 Skill 做什麼
當輸入提供學生的本學期缺席次數時，判斷是否達到門檻 3 次；達到時，產生一封給家長的缺席警告信，並同時輸出「請登入教務系統將該生標記為『留意名單』」的操作指示。未達門檻時，輸出不需要寄警告信，也不需要標記的結果。

# 何時使用
在學校行政或導師需要依缺席次數快速生成通知內容時使用。這個 Skill 只根據使用者提供的資料判斷與寫作，不會查系統、登入系統，或真的修改任何名單。

# 處理順序
1. 讀取輸入中的學生資料，至少要能找到學生姓名、本學期缺席次數；若有班級、家長稱呼、聯絡方式，一併帶入信件。
2. 若缺席次數缺少、不是整數，或無法判斷，回覆「缺席次數資料未提供或無法使用」，並停止。
3. 將缺席次數與門檻 3 比較：
   - 3 次以上：產生警告信，並輸出需要標記為「留意名單」的指示。
   - 3 次以下：輸出不符合警告條件，並說明不需寄信、不需標記。
4. 警告信內容要用中文，語氣正式、禮貌、清楚。
5. 信中要包含：學生姓名、缺席已達門檻、請家長關注出席狀況、後續將持續留意。
6. 不要寫成系統操作紀錄；不要聲稱已登入或已完成任何系統操作。需要實際登入教務系統與標記名單的人，應由使用者或其授權人員自行完成。
7. 若輸入同時包含多位學生，就逐一判斷並分別輸出每位學生的結果。

# 輸出格式
- 先列出每位學生的判定：是否達到缺席警告門檻。
- 對達標者，輸出一封可直接使用的給家長警告信。
- 對達標者，另列一行：請登入教務系統將該生標記為「留意名單」。
- 對未達標者，列一行簡短說明：未達 3 次，暫不寄發警告信，也不需標記為留意名單。
- 若缺少必要資料，直接說明缺少哪一項，不要自行補造學生資訊。
