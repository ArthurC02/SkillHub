# 缺席警告信與留意名單處理

## 適用情境
當學生在本學期缺席次數達到 3 次時，使用此技能來：
1. 產出一封給家長的缺席警告信。
2. 將該生在教務系統中標記為「留意名單」。

## 先決條件
- 你必須已經確認該學生本學期缺席次數確實達到 3 次。
- 你必須知道學生姓名、班級、學號（若有）、本學期缺席日期或次數統計。
- 若需要登入教務系統，必須已經有可用的帳號與權限。若沒有登入權限或無法寫入系統，不能自行繞過，應改為回報無法完成並請使用者提供可用權限或代為處理。

## 處理步驟

### 1. 驗證缺席條件
- 確認統計範圍是「本學期」。
- 確認缺席次數已達 3 次。
- 若未達 3 次，不要寄出警告信，也不要標記留意名單；改為回覆目前尚未達門檻。

### 2. 蒐集必要資訊
在撰寫信件與更新系統前，整理以下資訊：
- 學生姓名
- 班級 / 座號（若有）
- 學號（若有）
- 本學期缺席次數
- 缺席日期清單（若可取得）
- 家長稱呼或收件人資訊（若學校格式需要）
- 學校名稱與聯絡方式（若信件格式需要）

### 3. 撰寫給家長的缺席警告信
信件內容應包含：
- 主旨：學生本學期缺席達 3 次之提醒
- 開頭：禮貌說明來信目的
- 事實陳述：指出學生本學期缺席已達 3 次，並列出日期或次數統計
- 提醒：請家長留意出缺席狀況，並與學生溝通
- 後續建議：如有特殊原因，請與導師或學校聯繫
- 結尾：感謝配合，並保留學校聯絡資訊

信件語氣要正式、客觀、避免指責。

### 4. 登入教務系統並標記為「留意名單」
- 使用可用的合法登入方式進入教務系統。
- 找到該學生的資料頁面。
- 將學生狀態標記為「留意名單」。
- 儲存變更後，確認系統已成功更新。
- 若系統有備註欄，可簡短記錄原因，例如「本學期缺席達 3 次」。

### 5. 無法登入或無法更新時的處理
如果遇到以下任一情況：
- 無法登入
- 找不到學生資料
- 沒有編輯權限
- 系統更新失敗

則不要猜測或重試繞過限制；應回報具體失敗原因，並請求可用權限、正確學生識別資訊或人工協助。

## 建議輸出格式
當任務成功時，回覆應包含：
- 已完成的狀態說明
- 警告信正文
- 已標記為「留意名單」的確認

當任務未能完成時，回覆應包含：
- 失敗原因
- 還需要哪些資訊或權限

## 信件範本

主旨：關於貴子弟本學期缺席次數達 3 次之提醒

敬愛的家長您好：

您好。茲通知貴子弟【學生姓名】同學，本學期截至目前缺席次數已達 3 次（缺席日期：{日期清單}）。

為維護學生學習進度與出席狀況，敬請家長協助關心並提醒學生準時到校。如學生有特殊情況或需協助之處，歡迎與導師或學校聯繫。

感謝您的配合與支持。

敬祝
平安順心

【學校名稱】
【聯絡方式】

## 注意事項
- 不要在未確認達門檻前發送警告信。
- 不要在沒有權限時嘗試規避教務系統限制。
- 所有內容應以學校正式紀錄為準。
