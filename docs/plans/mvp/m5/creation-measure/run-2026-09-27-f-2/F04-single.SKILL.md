# 目的
計算民宿某一段**連續入住期間**的住宿總金額。規則是：
- 平日每晚 2000 元
- 假日每晚依規則加價
- 以「晚」為單位計算，**退房當天不算一晚**

# 先確認必要資訊
在開始計算前，先確認使用者是否提供以下資訊：
1. **入住日期**
2. **退房日期**（或總晚數）
3. **每一天是平日還是假日**，或可判定假日的規則
4. 若「假日加價」沒有明確數字，必須先向使用者詢問假日加價金額或假日房價

# 計算原則
1. 只計算入住期間內的每一個夜晚。
2. 退房當天不計費。
3. 每一晚依當天屬性套用對應房價：
   - 平日：2000 元
   - 假日：使用者提供的假日價格，或平日加價後的價格
4. 總金額 = 所有晚數的房價加總。

# 操作步驟
## 情況 A：使用者直接提供每晚的平假日分類
1. 列出入住期間內每一晚。
2. 逐晚判斷是平日或假日。
3. 平日每晚記 2000 元。
4. 假日每晚記使用者提供的假日價格。
5. 加總得到總金額。
6. 回覆時同時列出：
   - 總晚數
   - 平日晚數與金額
   - 假日晚數與金額
   - 總金額

## 情況 B：使用者只提供日期，但沒有假日規則
1. 不要自行猜測假日定義。
2. 先詢問使用者：
   - 哪些日期算假日，或
   - 假日加價多少，或
   - 假日房價是多少
3. 等資訊完整後再計算。

## 情況 C：使用者只提供總晚數，沒有日期
1. 先詢問每一晚的平假日分布，或至少詢問假日晚數。
2. 若使用者只想估算，則明確說明這是估算，並依其提供的假日晚數計算。

# 計算格式
若已知平日與假日價格，使用以下公式：
- 平日金額 = 平日晚數 × 2000
- 假日金額 = 假日晚數 × 假日每晚價格
- 總金額 = 平日金額 + 假日金額

# 回覆格式
請用簡潔明確的方式回覆，建議格式如下：

- 入住期間：YYYY/MM/DD ～ YYYY/MM/DD
- 總晚數：X 晚
- 平日：X 晚 × 2000 = XXXX 元
- 假日：X 晚 × XXXX = XXXX 元
- 總金額：XXXX 元

# 注意事項
- 不要把退房當天算進住宿晚數。
- 若資訊不足，先提問，不要自行補假日價格。
- 若使用者提供的假日加價規則與 2000 元平日價衝突，依使用者最新提供的明確規則計算。
