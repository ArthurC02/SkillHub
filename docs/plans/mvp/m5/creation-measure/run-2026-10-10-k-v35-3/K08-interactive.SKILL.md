## 用途與原則

依使用者貼上的租借清單，檢查租借日期、天數及桌子、椅子、投影機數量，逐項計算金額與總額。固定日單價為桌子每張 200 元、椅子每張 30 元、投影機每台 1500 元；總額為數量乘日單價後加總，再乘租借天數。

每次執行都直接處理收到的資料，不等待補充才交付結果。只使用使用者提供的事實；不得猜測或改選互相矛盾的值。缺少必需欄位時標明「未提供」，在答案中給可直接補填的範本。能由輸入算出的值自行計算。列出每個無法使用的值，請提出請求的使用者確認；受問題影響的總額不得輸出。即使需要確認，仍在同一則回覆交付已能完成的檢查與內容，結尾不以問題作結。

## 執行步驟

1. 將使用者訊息原文寫入 Skill 目錄下的 `input.txt`，保留清單分隔、原有數字與文字，不改寫資料。
2. 從含有本檔的目錄執行 `python scripts/rental_total.py --input input.txt`。
3. 對每份清單照腳本輸出呈現：列出收到的欄位、固定日單價、各器材金額及總額；若有衝突、不合理值或無法辨識的器材，逐項照列並說明須由提出請求的使用者確認，不輸出依賴該值的總額。日期不參與金額計算，因此只缺日期或日期無效時，仍呈現不依賴日期的有效金額；天數或任何一種必需器材數量無法使用時，不呈現該清單總額。
4. 對每個未提供的必需欄位，在答案中標明「未提供」，並附上可填寫範本：`租借起日：____；租借天數：____；桌子：____ 張；椅子：____ 張；投影機：____ 台。` 日期以西元 `YYYY-MM-DD` 檢查；天數須為正整數，數量須為非負整數。清單未列某項器材時，不把它默認為零。
5. 如清單標出名稱，逐份以原名稱回報；未標示名稱時不要求補名稱。若同一訊息有多份清單，逐份分開檢查與計算。金額以整數新台幣元呈現。
