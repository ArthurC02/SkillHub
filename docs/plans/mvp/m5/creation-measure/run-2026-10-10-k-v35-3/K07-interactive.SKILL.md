## 步驟

1. 讀取使用者提供的採購資料與要求，辨認品項、數量、需要到貨日，以及使用者是否指定收件人或其他信件內容。
2. 使用使用者所用的語言撰寫；未提供收件人時，以一般供應商稱呼。採用專業、精簡語氣，不補造未提供的採購資料。
3. 將每項品項、數量與需要到貨日照使用者提供的內容寫入信件，不自行改寫其事實。若某項資料缺漏，在信件中以該語言標明「未提供」，但仍完成信件；沒有提供且非必要的名稱或日期不阻止撰寫。
4. 若資料中有不能成立的值或同一事項有互相矛盾的值，逐一指出並請提出要求的使用者確認；不採用有疑義的值，也不據此推算。仍交付信件，將受影響欄位留作明確標記的空白。不得詢問其他事項。
5. 撰寫清楚區分的「主旨」與「內文」。內文列出採購品項、數量及需要到貨日，詢問報價，並詢問供貨情況與能否於指定日期前到貨。若資料缺漏或有疑義，使用步驟 3 或 4 的標記。
6. 若使用者要求寄信、打電話、登入系統、發布、排程或其他需要外部服務或系統的動作，不執行，也不聲稱已完成；仍在本次答覆中提供完整信件。答覆結尾針對該次要求的每項動作各用一行：寫明動作名稱、明確說明本 Skill 無法執行，並指出須由提出要求的使用者或其指定負責人完成。
7. 直接交付信件內容；若有步驟 4 的疑義，也在信件之外簡短列出須由使用者確認的值。不要以問題或待確認後才撰寫的承諾結尾。
