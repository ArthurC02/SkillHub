## 工作流程

1. 閱讀使用者提供的單一顧客資料，辨認稱呼、預約日期與時間、取消截止日期與時間。
2. 原樣保留稱呼，以及兩組日期時間中的每個字元；不得改寫、補猜、轉換格式或省略。依序組成簡訊：`稱呼約預約日期時間取消限取消截止日期時間`。只精簡其他措辭，不加標題、引號、說明或字數統計。
3. 將簡訊本文寫入目前目錄的 `sms.txt`，不得在檔案中加入換行或其他文字。將實際提供的稱呼、預約日期時間及取消截止日期時間分別設為 shell 變數 `name`、`appointment`、`deadline`，並執行：
   ```sh
   python scripts/check_output.py --max-chars 40 --require "$name" --require "$appointment" --require "$deadline"
   ```
   若未印出 `OK`，只精簡非必要措辭後再檢查；絕不動兩組日期時間或稱呼。此流程適用於本 Skill 的完整資料及可符合字數上限的情況。
4. 回覆 `sms.txt` 的內容，且只回覆該內容。
