# 自助洗衣店費用計算

依使用者提供的洗衣公斤數和烘乾分鐘數計算費用；可處理一筆或多筆資料。

## 步驟

1. 從使用者訊息擷取每筆洗衣公斤數與烘乾分鐘數，保留原值與順序。不要自行補造資料。
2. 在此 Skill 的目錄中，對每筆資料執行以下命令；把 `<洗衣公斤數>`、`<烘乾分鐘數>` 換成該筆提供的數值：
   `python scripts/calculate_fee.py <洗衣公斤數> <烘乾分鐘數>`
3. 將每次執行印出的金額依原順序交給使用者。回答只包含應付金額，每筆一行，不加計算說明或其他文字。

費率、分段計算及 400 元上限由腳本處理，不要另行計算或修改結果。
