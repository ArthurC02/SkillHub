# 咖啡豆批發訂單統計

1. 閱讀訂單訊息，辨識每個咖啡豆品項的名稱、數量與單位、單價與單價單位，以及明確提及的幣別。只把咖啡豆本身列為商品；運費、寄送費、包裝費等其他費用不納入商品總額。
2. 依上下文只有在缺少的數量或單價能唯一推得時才補用。否則不要猜，也不要把該品項算入總額；列出品項、已知資料與缺少欄位。需要計算時，數量單位與單價所依據的單位必須一致，或能依訊息明確換算；不可自行假定換算方式。
3. 逐項檢查數值與單位。遇到負數、無效數值、同一欄位有互相矛盾的說法，或無法判定的單位時，列明有問題的原始值並請提出訂單的人確認；不計算依賴該值的品項或總額。不要因缺少未要求的名稱或日期而停止整理，也不要以問題句結尾。
4. 將可計算品項轉成腳本參數。每筆完整品項使用 `--item '品名|數量|數量單位|單價|單價單位'`；每筆資料不完整的品項使用 `--incomplete '品名|已知數量或空白|已知數量單位或空白|已知單價或空白|已知單價單位或空白'`。欄位值不可含直線符號 `|`。若訊息明確提供幣別，以 `--currency '幣別'` 指定；若未提供，省略此參數，腳本會採用「元」並註明這項假設及可更改的參數。
5. 從包含本 `SKILL.md` 的目錄執行 `python scripts/coffee_order_total.py`，並附上整理好的參數；依照腳本輸出呈現各品項小計及商品總額。把已知但未能計算的品項及缺少欄位一併列出，照原訊息保留品項名稱與已提供的事實。若腳本以錯誤結束，照實說明無法使用的值，不呈現受其影響的總額。
6. 交付完整整理結果，不只提供操作計畫。對於這次請求提及、但此 Skill 執行環境不能代為完成的外部動作，答案末尾須逐項用一行說明該動作、明確表示本代理無法執行，並指出由提出請求的人或請求中指定的負責人執行。
