## 工作步驟

1. 閱讀使用者提供的段考事項，只依據其中的事實撰寫；採親切、清楚的家長群組語氣。
2. 找出段考日期與學費繳費截止日。公告必須保留這兩項；照原文呈現日期，不補年份、不改寫日期資訊，也不添加來源未提供的安排或事實。
3. 若必保留的事實未提供，在公告相應位置明確寫「未提供」，並以標示空格提供可用版本；不要因此停止撰寫。其他未提供的事實也不得自行補造。
4. 檢查日期等值是否不存在或同一事項有互相矛盾的說法，包括後文改動前文數值。將每個有問題的值原樣列出，請提出需求的人確認；不要替對方選值，也不要把無法確認的值標成已確認。其他未提供的名稱、標籤或日期不妨礙撰寫。
5. 將其他事項合併或取捨，使「公告」本體最多三句。保留哪些內容由清晰、精簡和家長需要理解事項決定；不可因此省略段考日期或學費繳費截止日。若相互衝突的事實不能同時成立，遵守三句上限，並用一句話說明因此省略了什麼。
6. 公告後另寫一句「處理說明」，如實列出合併或捨棄的事項；若都沒有，明確寫「沒有合併或捨棄事項」。此句不計入公告三句上限。若有待確認的衝突，在這句中列出衝突的原文值，並請提出需求的人確認。
7. 完成稿件，包含「公告」與「處理說明」標示，以及各自完整文字，寫入 `answer.txt`。逐句確認公告不超過三句，必保留事實照原文出現且沒有增添事實。將兩項必保留事實的完整原文值設為 `EXAM_DATE`、`FEE_DATE`；若來源未提供其中一項，該變數改用輸出中的「未提供」標示。從存放此 `SKILL.md` 的目錄執行：

   ```sh
   python scripts/check_output.py --max-sentences 5 --require "$EXAM_DATE" --require "$FEE_DATE" < answer.txt
   ```

   五句上限涵蓋最多三句公告、一句處理說明及以下一行操作限制；仍須另外確認公告本體不超過三句。若未印出 `OK`，修正 `answer.txt` 並重跑，直到印出 `OK`。最後只用 `answer.txt` 的內容作答。

群組張貼：本代理無法替你張貼，請提出需求的人自行貼到家長群組。
