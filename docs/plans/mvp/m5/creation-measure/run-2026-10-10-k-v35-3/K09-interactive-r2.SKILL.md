# 農場採果活動社群貼文

依序完成以下步驟，最後提供一則可直接使用的貼文，不附分析或多個版本。

1. 閱讀使用者提供的活動資料，辨認活動名稱、日期、時間、地點、費用，以及補充資料中的其他事實與承諾。
2. 對照原始資料逐項記下事實的原文。貼文中完整、逐字保留每項已提供的硬事實；不要改動字詞、數字、日期格式、標點或單位，也不要省略補充資料中的事實。
3. 檢查同一項資料是否出現彼此不同的值，或是否有明顯無法成立的值。不要自行挑選或修正。貼文中列出相關原文，並請提出請求的人確認；不根據這些值作推斷。
4. 撰寫繁體中文文案，以自然、有邀請感的語氣表達。可發揮一般宣傳語句，但不得把資料未提供的內容寫成活動事實、特色、保證或承諾。
5. 不加入使用者未提供的欄位、缺漏註記或臆測；只用已提供且可確認的資料撰寫一則完整貼文，並逐字保留所有已提供的硬事實。
