# 目標
把一週內的每日花費整理成清楚的表格，為每筆支出標上類別，並在週末計算各類別合計。

# 適用情況
- 使用者提供一週的支出明細、日記式記錄、聊天訊息、或零散條目。
- 使用者想要把資料整理成「每日花費表」並做「類別彙總」。

# 工作流程
1. **先確認資料是否完整**
   - 檢查是否包含：日期、金額、用途/品項。
   - 若缺少日期或金額，先向使用者追問；不要自行補值。
   - 若只有部分資訊但仍可整理，先依現有資料建立表格，並把缺漏欄位標示為「未提供」。

2. **統一資料格式**
   - 將每筆支出拆成以下欄位：
     - 日期
     - 項目/用途
     - 金額
     - 類別
   - 若同一天有多筆支出，保留為多列，不要合併。
   - 金額以數字表示，保留原幣別或在表頭註明幣別。

3. **為每筆支出標類別**
   - 依用途判斷類別，若使用者未指定分類規則，採用常見類別：
     - 餐飲
     - 交通
     - 購物
     - 生活用品
     - 娛樂
     - 醫療
     - 住宿
     - 其他
   - 若用途無法明確歸類，標為「其他」。
   - 若同一筆支出可能屬於多類，選最主要用途作為類別，必要時在備註說明。

4. **建立每日花費表**
   - 以日期排序，從週一到週日排列。
   - 表格欄位建議如下：
     - 日期
     - 項目/用途
     - 類別
     - 金額
   - 若同一天有多筆，逐筆列出。
   - 若使用者希望，也可在每日區塊下加上「當日小計」。

5. **計算週末各類別合計**
   - 將整週所有支出依類別加總。
   - 輸出一個彙總表，欄位建議如下：
     - 類別
     - 合計金額
   - 若需要更完整，可再加：
     - 筆數
     - 佔總支出比例
   - 總計應等於所有每日支出的加總。

6. **檢查一致性**
   - 確認每日明細加總 = 類別合計總和。
   - 若有四捨五入或幣別問題，明確註明。
   - 若資料跨多週，先依週分組，再分別整理。

# 輸出格式
使用 Markdown 表格輸出，至少包含兩部分：

## 1. 每日花費明細
| 日期 | 項目/用途 | 類別 | 金額 |
|---|---|---:|---:|
| 週一 | 早餐 | 餐飲 | 50 |
| 週一 | 公車 | 交通 | 30 |

## 2. 週末類別合計
| 類別 | 合計金額 |
|---|---:|
| 餐飲 | 350 |
| 交通 | 120 |
| 其他 | 40 |

# 注意事項
- 不要自行捏造不存在的支出。
- 若使用者提供的是圖片或掃描文字，先根據可辨識內容整理；無法辨識的部分標示為「無法辨識」。
- 若使用者要求特定分類規則，優先遵循使用者規則。
- 若資料不足以完成週合計，先列出已知資料並說明缺少哪些欄位。
