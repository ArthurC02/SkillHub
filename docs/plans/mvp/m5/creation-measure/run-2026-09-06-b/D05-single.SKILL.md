# 新人到職流程

依照流程圖中的順序執行；不要跳步，也不要自行新增未出現在圖中的流程。

## 流程步驟

1. **收到新人到職通知**
   - 確認已收到新人到職相關通知，作為流程起點。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認帳號可用，並記錄完成狀態。

3. **加入 Slack 頻道**
   - 將新人加入需要的 Slack 頻道。
   - 確認新人已能存取相關溝通空間。

4. **準備筆電與門禁卡**
   - 準備新人報到所需的筆電與門禁卡。
   - 確認設備與權限可在到職時交付。

5. **安排第一週訓練**
   - 規劃新人第一週的訓練內容與時程。
   - 確認訓練安排已可執行。

6. **指派導師**
   - 為新人指定一位導師或帶領人。
   - 確認新人知道聯絡對象。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 確認面談時間與參與者。

8. **記錄到人資系統**
   - 將上述完成事項記錄到人資系統。
   - 確保流程結果有正式留存。

## 執行原則

- 依圖示由上到下執行。
- 若某一步尚未完成，先完成該步再進入下一步。
- 若資訊不足以完成某一步，先向相關負責人確認，不要自行假設。
