# Excel 客戶名單去重與缺電話標記

當你收到一份 Excel 客戶名單，需要**去除重複資料**並**標記缺少電話的列**時，依照以下流程處理。

## 1. 先確認欄位
- 找出哪一欄是客戶識別依據，通常是：姓名、電話、Email、公司名，或它們的組合。
- 找出電話欄位名稱，確認哪些儲存格代表「缺少電話」：
  - 空白
  - 只有空格
  - 文字如「無」、「N/A」、「未提供」等
- 如果檔案中沒有明確可用來判斷重複的欄位，先回報需要使用者指定去重規則，不要自行猜測。

## 2. 建立處理前備份
- 先複製原始工作表，保留一份未修改版本。
- 在新工作表或新檔案中進行清理，避免覆蓋原始資料。

## 3. 去除重複資料
- 依照已確認的去重規則檢查每一列。
- 若重複判斷是以單一欄位為準，例如電話或 Email：
  - 保留第一筆出現的資料。
  - 刪除後續重複列。
- 若重複判斷是以多欄組合為準，例如「姓名 + 電話」：
  - 以該組合完全相同者視為重複。
  - 保留第一筆，刪除其餘重複列。
- 若同一客戶有多筆資料但內容不完全相同，先不要自動合併；改為保留並標記為可能重複，除非使用者明確要求合併。

## 4. 標記缺少電話的列
- 在電話欄位旁新增一欄，例如「電話狀態」或「缺電話標記」。
- 對每一列檢查電話欄：
  - 若電話為空白、空字串、只有空格，或屬於預先定義的缺值文字，標記為「缺少電話」。
  - 若電話有值，標記為「有電話」或留白，依使用者需求一致處理。
- 若使用者要求直接醒目提示，也可用底色、字體顏色或篩選條件標示缺電話列，但不要只靠顏色，最好保留文字標記欄。

## 5. 檢查結果
- 確認去重後的筆數是否合理，並記錄：
  - 原始筆數
  - 刪除的重複筆數
  - 保留筆數
  - 缺少電話的筆數
- 抽查幾筆資料，確認重複列已移除、缺電話列已正確標記。

## 6. 輸出
- 將結果另存為新 Excel 檔。
- 檔名可清楚表示已清理，例如在原檔名後加上「_去重_缺電話標記」。
- 若使用者需要，也可另外提供一份只列出缺少電話的清單，方便後續補資料。

## 7. 若資訊不足時要先詢問
在開始前，如果無法從檔案判斷以下內容，先向使用者確認：
- 以哪幾欄判斷重複
- 電話欄位名稱
- 缺值要如何定義
- 是否要保留第一筆、最後一筆，或依其他規則保留

## 8. 不可自行假設的情況
- 不要在沒有規則時自行合併不同列的資訊。
- 不要刪除看起來相似但無法確認重複的資料。
- 不要把缺電話列直接刪除，除非使用者明確要求。
