# 目的
把會議逐字稿轉成結構化待辦清單，並確保每一條都包含：
- 待辦事項
- 負責人
- 期限

# 適用範圍
使用於已經有會議逐字稿文字內容的情況。若只有音檔、沒有逐字稿，先請使用者提供逐字稿或可讀文字內容；這個技能不負責轉錄音檔。

# 處理步驟
1. **先通讀全文**
   - 找出所有明確的行動項、承諾、後續跟進、待確認事項。
   - 排除純討論、背景說明、重複內容、寒暄。

2. **辨識每個待辦**
   - 將一句話中可能包含的多個任務拆開。
   - 每個待辦只保留一個可執行動作，避免把多件事混在同一條。

3. **指定負責人**
   - 優先使用逐字稿中明確提到的人名、職稱或團隊。
   - 若只有「我」「你」「我們」等代稱，根據上下文推定最可能的負責人；若仍無法判定，標示為「未明確」並在備註說明原因。
   - 不要憑空編造人名。

4. **整理期限**
   - 優先擷取明確日期、時間、星期、相對期限（例如「本週五前」「下週一」）。
   - 若只有模糊時間詞（例如「盡快」「稍後」「這兩天」），保留原文並標示為「期限不明確」。
   - 若完全沒有期限，填寫「未提及」。

5. **補足必要上下文**
   - 若待辦內容需要對象、文件、版本、專案名稱等才能理解，簡短補在描述中。
   - 保持精簡，不要把整段逐字稿搬進待辦。

6. **去重與合併**
   - 相同任務若在不同段落重複提到，只保留一條。
   - 若同一任務有更新期限或負責人，以最後一次明確說法為準。

7. **輸出格式**
   - 以清單或表格輸出。
   - 每條至少包含以下欄位：
     - 待辦事項
     - 負責人
     - 期限
   - 建議再加上：
     - 來源片段（簡短引用）
     - 備註（如期限不明確、負責人推定）

# 輸出原則
- 保持忠實，不要自行補寫不存在的承諾。
- 不確定時明確標示不確定，而不是猜測。
- 用繁體中文輸出，除非逐字稿本身主要使用其他語言。
- 若逐字稿中完全沒有可執行待辦，輸出「未找到明確待辦事項」，並簡述原因。
