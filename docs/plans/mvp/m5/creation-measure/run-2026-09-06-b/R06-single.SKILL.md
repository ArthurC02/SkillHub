## 目的
將一份英文使用手冊完整翻譯為繁體中文，並在專有名詞第一次出現時保留原文。輸出應忠實、自然、術語一致，且維持原手冊的章節、標題、列表、表格與警示格式。

## 工作原則
1. 先通讀全文，辨識文件結構、重複術語、產品名稱、功能名稱、按鈕名稱、錯誤訊息與警示語。
2. 專有名詞第一次出現時，採用「繁體中文譯名（Original Term）」；之後只用繁體中文譯名，除非原文在該段落中再次強調或需要避免歧義。
3. 若某專有名詞已有常見繁中譯法，優先採用一致且自然的譯法；若無明確譯法，保留原文並在前面加上最貼切的中文說明。
4. 保留原手冊的語氣與用途：說明文保持中性、操作步驟保持命令式、警告與注意事項保持明確嚴謹。
5. 不要自行增刪內容，不要補寫原文沒有的說明；若原文含糊，翻譯時也要保留其含糊性，不要擅自解釋。

## 翻譯步驟
1. 先建立術語表：
   - 找出產品名、功能名、介面元件、技術名詞、縮寫、單位、錯誤碼。
   - 決定每個詞的固定譯法。
   - 同一詞在全文必須一致。
2. 逐章翻譯：
   - 保留章節順序、標題層級、編號、項目符號與縮排。
   - 操作步驟用清楚的繁體中文動詞表達，例如「按下」、「選取」、「輸入」、「確認」。
   - 若原文有條件句、警告、提示、註解，維持其獨立性與醒目程度。
3. 表格與清單：
   - 保留欄位順序與資料對應關係。
   - 表格內文字要簡潔，避免破壞版面。
   - 若表格欄名是專有名詞，第一次出現仍需附原文。
4. 圖示、按鈕、選單與介面文字：
   - 介面上可見的英文按鈕或選單名稱，翻譯時保留原文於首次出現。
   - 若原文明確表示是畫面上的文字，翻譯時可用引號或括號標示其介面屬性。
5. 單位、數字、格式：
   - 數字、版本號、型號、路徑、代碼、URL、檔名通常保留原樣。
   - 單位可翻譯，但不得改變數值。
   - 日期、時間、百分比、範圍等格式要與原文一致，除非原文格式本身需要轉寫成繁中慣例且不影響準確性。

## 專有名詞處理規則
1. 第一次出現：中文譯名後加原文括號，例如「裝置管理員（Device Manager）」。
2. 後續出現：只用中文譯名，例如「裝置管理員」。
3. 若同一詞在標題中首次出現，標題也要遵守首次出現規則。
4. 縮寫若原文先寫全名再寫縮寫，首次出現時可寫成「完整譯名（Original Full Name，縮寫）」；後續只用縮寫或中文譯名，依全文一致性決定。
5. 若專有名詞是品牌、產品型號或不可翻譯名稱，保留原文，必要時在前面加中文說明。

## 品質檢查
1. 檢查是否有漏譯、重譯、錯譯或章節遺漏。
2. 檢查專有名詞首次出現是否都有附原文。
3. 檢查術語是否前後一致。
4. 檢查步驟順序、警告、注意事項、表格欄位是否與原文對齊。
5. 檢查繁體中文用字是否一致、自然，避免混用簡體字。

## 輸出要求
- 只輸出翻譯後的繁體中文內容。
- 保留原手冊的結構與格式。
- 不要加入翻譯說明、註解或額外摘要。
