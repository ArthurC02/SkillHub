# Data Analyst Resume Rewriter

## When to use
Use this skill when a user provides an existing resume and wants it rewritten for a data analyst job application, especially when they want a one-page version that is more targeted to analytics roles.

## Goal
Rewrite the resume so it is easier for a hiring manager to scan, better aligned with data analyst expectations, and limited to the facts the user provided.

## Process
1. Read the source resume carefully and identify:
   - analytics-related experience
   - tools and methods
   - measurable outcomes
   - education and certifications relevant to analysis
2. Remove or downplay content that does not help a data analyst application unless it is needed for context.
3. Reorder content so the strongest job-relevant material appears first.
4. Rewrite bullets to be concise, impact-focused, and concrete.
5. Keep the final version to one page by compressing low-value detail.
6. Do not add any experience, tool, metric, employer, degree, or skill that the user did not provide.

## Writing rules
- Keep the tone professional and job-search appropriate.
- Prefer action verbs and outcome-oriented phrasing.
- Highlight analysis tools, reporting, dashboards, SQL, spreadsheets, Python, statistics, visualization, experimentation, or similar items only if they are supported by the source resume.
- If a bullet lacks a measurable result, rewrite it to show scope, method, or business value without inventing numbers.
- If the source resume is too long, trim in this order:
  1. old or less relevant experience detail
  2. generic responsibilities
  3. repeated skills
  4. non-essential hobbies or extras
- Preserve any names, dates, titles, and credentials exactly as provided unless the user explicitly asks for normalization.

## Output expectations
Produce a single rewritten resume suitable for a data analyst application.
- Keep it compact enough to fit on one page.
- Make the most relevant analytics content easy to spot.
- Do not include commentary unless the user asks for it.
- If the source information is insufficient to support a strong data-analyst framing, keep the wording neutral and factual rather than filling gaps.

## Quality check
Before finalizing, verify that:
- the result is clearly targeted to data analyst roles
- the length is plausibly one page or less
- every claim is supported by the user’s input
- the language sounds polished and professional
- nothing important for the target role was accidentally removed

## Recommended response shape
Return the rewritten resume as the main content. If the user asked for additional explanation, add a short note after the resume.
