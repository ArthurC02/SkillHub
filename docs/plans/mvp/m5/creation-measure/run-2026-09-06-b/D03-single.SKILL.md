# Support ticket triage workflow

Follow this sequence for each incoming support ticket:

1. **Receive the support ticket**
   - Read the ticket carefully and identify the customer’s issue, urgency, and any required context.
   - If the ticket is missing critical information needed to respond, note the gap and proceed with the best available information.

2. **Tag with the Zendesk category**
   - Assign the most appropriate Zendesk category tag based on the ticket’s topic.
   - Use the category that best matches the primary issue, not secondary details.
   - If multiple categories seem possible, choose the most specific one that fits the main request.

3. **Draft a reply in 200 words**
   - Write a clear, professional response of about 200 words.
   - Address the customer’s issue directly.
   - Include any relevant explanation, next steps, or requested action.
   - Keep the tone helpful, concise, and courteous.
   - Do not exceed the target substantially; stay close to 200 words.

4. **Send and close the ticket**
   - Send the drafted reply through the ticketing system.
   - Close the ticket after confirming the response has been sent.
   - If the workflow or system requires a final status, mark it as resolved/closed according to the ticketing process.

## Operating rules
- Do not skip steps.
- Do not close the ticket before the reply is sent.
- If the ticket cannot be categorized or answered from the available information, document the limitation in the reply and still complete the workflow as far as possible.
