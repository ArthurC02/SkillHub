# 每日新聞摘要寄送

## 你要做的事
把三個新聞網站當天早上的標題整理成 5 條摘要，並準備寄到使用者信箱的內容。

## 先確認可行性
- 這個任務需要**即時網路存取**來讀取新聞網站，還需要**可用的寄信能力**才能真正寄出。
- 如果目前沒有網路工具、沒有瀏覽工具、或沒有可用的郵件工具/授權，**不要假裝已完成**。
- 在這種情況下，改為提供：
  1. 需要的三個新聞網站網址
  2. 使用者信箱地址
  3. 寄送時間與時區
  4. 是否要固定每天寄送
  5. 是否有偏好的新聞分類或語言

## 執行流程
1. **取得來源**
   - 找出使用者指定的三個新聞網站。
   - 若使用者沒有指定，先詢問要用哪三個網站；不要自行假設來源。

2. **擷取標題**
   - 讀取每個網站首頁或新聞版面當天早上的主要標題。
   - 優先選擇最新、最重要、最具代表性的標題。
   - 避免重複、廣告、推薦內容、訂閱提示與非新聞項目。

3. **整理成 5 條摘要**
   - 將三個網站的標題合併後，濃縮成 5 條摘要。
   - 每條摘要應：
     - 簡短
     - 清楚
     - 盡量涵蓋不同主題
     - 不要捏造標題中沒有的事實
   - 若標題彼此重複或主題高度相近，合併成一條。

4. **撰寫郵件內容**
   - 主旨建議：`每日新聞摘要`
   - 內文包含：
     - 簡短問候
     - 5 條摘要
     - 每條摘要下方可附上來源網站名稱
   - 若有原始標題，保留可追溯性；若做了濃縮，避免加入未驗證細節。

5. **寄送前檢查**
   - 確認收件人信箱正確。
   - 確認內容沒有重複、空白或明顯錯誤。
   - 確認是否符合使用者要求的語言與格式。

## 如果要建立每日自動寄送
- 這需要外部排程或自動化系統，不是單靠這個技能就能完成。
- 你應該回覆使用者：
  - 目前已能整理出每日摘要格式
  - 若要每天早上自動寄送，還需要排程工具、郵件權限與來源網站存取
  - 請提供或確認這些條件後才能設定

## 輸出格式建議
- 先列出 5 條摘要
- 再附上來源網站
- 若無法寄送，明確說明原因，並提供可直接貼到郵件工具的內容
