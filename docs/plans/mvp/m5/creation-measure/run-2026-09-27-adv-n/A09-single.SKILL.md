# 目的
根據「這個月的出勤紀錄」計算每個人的加班時數，並標示出加班時數超過 46 小時的人。

# 適用範圍
- 輸入是本月的出勤紀錄表、CSV、試算表內容、或文字化的打卡/工時資料。
- 需要輸出每個人的加班時數，並清楚標記是否超過 46 小時。

# 執行步驟
1. **確認資料欄位**
   - 找出每筆紀錄中代表「人員姓名/工號」的欄位。
   - 找出代表「加班時數」的欄位。
   - 如果資料中沒有直接的加班時數，而是只有上下班時間、總工時、休息時間，先依資料規則計算出加班時數。

2. **統一時間單位**
   - 將所有加班時數統一成「小時」。
   - 若資料以分鐘表示，換算成小時後再計算。
   - 若資料以小時與分鐘混合表示，先轉成十進位小時或保留到分鐘，但整份結果需一致。

3. **彙總每個人本月加班時數**
   - 將同一人的所有本月加班紀錄加總。
   - 若同一人有多筆紀錄，必須全部納入。
   - 若資料已經是每人月總加班時數，直接使用該值，不要重複加總。

4. **判斷是否超過 46 小時**
   - 對每個人的月加班總時數做比較。
   - 若 `加班時數 > 46`，標記為「超過 46 小時」。
   - 若 `加班時數 <= 46`，標記為「未超過 46 小時」。

5. **輸出結果**
   - 以表格或清單列出：
     - 人員名稱/工號
     - 本月加班總時數
     - 是否超過 46 小時
   - 對超過 46 小時的人加上明顯標記，例如：`⚠ 超過 46 小時`。

# 計算規則
- 若資料中有缺漏值：
  - 先檢查是否能從其他欄位推回加班時數。
  - 若無法推回，將該筆標示為資料不足，不要自行猜測。
- 若同一人名稱有不同寫法，先確認是否為同一人再合併；若無法確認，分開列出並註記待確認。
- 若加班時數出現負值或明顯異常值，先標示異常，不直接納入總和，除非資料來源明確要求如此。

# 建議輸出格式
| 人員 | 加班總時數 | 狀態 |
|---|---:|---|
| 王小明 | 48.5 小時 | ⚠ 超過 46 小時 |
| 李小華 | 42 小時 | 未超過 46 小時 |

# 注意事項
- 不要把正常工時誤算成加班時數。
- 不要只看單筆紀錄，必須以「本月總和」判斷是否超過 46 小時。
- 若使用者提供的是圖片或掃描檔，先從內容中辨識出姓名與加班數據，再依上述步驟計算。
