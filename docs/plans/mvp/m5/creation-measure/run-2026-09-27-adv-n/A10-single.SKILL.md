# 目的
將輸入文章濃縮成 50 字以內，同時盡量完整保留原文中的所有數字與人名。

# 適用時機
- 使用者要求「超短摘要」「50 字以內」「一句話摘要」等。
- 使用者特別要求保留數字、年份、金額、比例、日期、統計值、專有名詞或人名。

# 執行步驟
1. **先讀完整篇文章**，找出：
   - 所有人名
   - 所有數字與數值表達（含年份、日期、時間、百分比、金額、排名、次數、比例、編號等）
   - 文章核心主旨
2. **判斷哪些資訊必須保留**：
   - 人名與數字優先保留
   - 若字數不足，優先保留最關鍵的人名與數字，再壓縮其他描述
3. **重寫成極短摘要**：
   - 只保留主旨、關鍵動作、結果
   - 盡量使用最少字詞連接資訊
   - 避免加入原文沒有的新資訊
4. **檢查字數**：
   - 最終輸出必須在 50 字以內
   - 若超過，刪除修飾語、重複語、次要背景，只保留必要資訊
5. **檢查保留項目**：
   - 對照原文，確認所有數字與人名是否都已保留
   - 若無法在 50 字內完整保留全部數字與人名，先保留最重要者，並在輸出前明確指出「因字數限制，無法完整保留全部數字/人名」；但仍以 50 字內為準
6. **輸出格式**：
   - 只輸出摘要本身
   - 不要附加解釋、標題、前言或分析

# 寫作原則
- 優先保留原文中的專有名詞與數字原樣
- 用最短語句表達因果、結果或結論
- 避免同義反覆與冗詞
- 不要捏造未出現的人名或數字
- 若原文資訊過多，摘要應以「核心事件 + 關鍵數字/人名」為主
