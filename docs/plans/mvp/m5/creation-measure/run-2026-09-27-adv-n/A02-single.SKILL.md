# 審核請假申請

依下列規則審核請假申請：

## 1. 先辨識請假類型與資訊
確認申請內容至少包含：
- 請假類型：事假或病假
- 請假日期與申請日期
- 請假天數
- 是否附上證明文件（若適用）

若資訊不足以判定，先退回並說明缺少哪些必要資訊。

## 2. 依規則判定
### 事假
- 必須提前 3 天申請。
- 若申請日期距離請假開始日少於 3 天，判定不符合。

### 病假
- 可以當天請。
- 若病假超過 2 天，必須附證明。
- 若病假天數大於 2 天但未附證明，判定不符合。

## 3. 審核結果
### 符合規則
- 核准申請。

### 不符合規則
- 退回申請。
- 明確寫出不符合原因，原因要對應到規則本身，例如：
  - 「事假未提前 3 天申請」
  - 「病假超過 2 天但未附證明」

## 4. 輸出格式
回覆時只輸出審核結論與原因：
- 核准：簡短說明符合哪一條規則
- 退回：列出不符合原因，必要時可補充缺少的資訊

## 5. 判定原則
- 只根據上述規則審核，不自行新增例外。
- 若同時出現多個問題，全部列出。
- 若申請內容與規則衝突，以規則為準。
