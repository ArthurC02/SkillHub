# 自我介紹撰寫

當使用者要你幫忙寫自我介紹、個人簡介、面試自介、課堂報告自我介紹、社群簡介或開場介紹時，使用這個技能。

## 目標
產出一篇符合情境、語氣自然、長度合適的自我介紹。

## 執行步驟
1. **先確認用途與情境**
   - 這篇自我介紹要用在哪裡：面試、上台報告、課堂、社群平台、交友、申請文件，或其他場合。
   - 需要的語氣：正式、半正式、親切、活潑、專業、簡短。
   - 需要的長度：一句話、100 字內、300 字左右、1 分鐘口說版、長版。

2. **蒐集必要資訊**
   若使用者沒有提供，主動詢問以下重點：
   - 姓名或稱呼
   - 身分／職業／年級／科系
   - 主要背景或經歷
   - 專長、興趣、個人特色
   - 想強調的優勢或成就
   - 這次介紹的目的
   - 希望對方留下的印象

3. **整理內容結構**
   依情境安排順序，通常可用以下架構：
   - 開頭：姓名與身分
   - 中段：背景、經歷、專長或興趣
   - 重點：個人特色、成就、價值
   - 結尾：目的、期待、收尾句

4. **撰寫時的原則**
   - 用自然、清楚、符合中文表達的句子。
   - 避免空泛形容詞，盡量加入具體內容。
   - 若是正式場合，避免過度口語；若是輕鬆場合，可更親切。
   - 不要捏造經歷、學歷、職稱或成就；缺少資訊時，用可保留的中性寫法。

5. **可提供多版本**
   若情境不明確或使用者可能需要不同用途，可同時提供：
   - 正式版
   - 口語版
   - 精簡版
   - 1 分鐘版

6. **輸出格式**
   - 直接給出可使用的自我介紹正文。
   - 若有需要，可在正文前簡短標註適用情境。
   - 若資訊不足，先列出你需要的關鍵問題，再等待補充。

## 範例寫法方向
- 面試：強調背景、能力、工作態度、與職缺相關的優勢。
- 學校報告：強調姓名、科系、興趣、參與經驗。
- 社群簡介：強調個人風格、興趣、生活感。
- 口說自介：句子要短，節奏自然，方便朗讀。

## 注意事項
- 不要替使用者編造身份或經歷。
- 不要寫成模板感太重的空話。
- 若使用者只說「幫我寫一篇自我介紹」，先用最少問題補齊情境，再開始寫。
