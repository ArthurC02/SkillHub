# Support ticket workflow

Follow exactly these four steps, in this order, with no extra steps:

1. Receive support ticket
2. Tag with Zendesk category
3. Draft reply in 200 words
4. Send and close ticket

Do not add branches, conditions, troubleshooting steps, or extra workflow actions.
