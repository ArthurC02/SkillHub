# 管理費逾期催繳

依輸入資料判斷每筆管理費是否符合催繳條件，並準備可供人工使用的通知與簡訊草稿。此 Skill 只產生內容，不會登入系統、修改住戶狀態或傳送訊息。

## 步驟

1. 讀取基準日期及每筆資料：資料標籤、戶別、住戶姓名、費用期別、金額、到期日、繳費狀態、手機號碼。標籤、戶別、姓名、期別、金額或手機號碼缺漏時，輸出中標為「未提供」；不要因此跳過日期與狀態可判定的資料。若沒有收到任何資料，直接提供一筆可填寫的資料格式：`資料標籤｜戶別｜住戶姓名｜費用期別｜金額｜到期日｜繳費狀態｜手機號碼`，各欄空白標示「未提供」，並依此格式說明需要的資料，不要捏造住戶事實。
2. 將基準日期及每筆資料轉成下列命令格式，在放有此 SKILL.md 的目錄執行。每筆 `--record` 欄位順序固定為 `資料標籤|戶別|住戶姓名|費用期別|金額|到期日|繳費狀態|手機號碼`；缺漏欄位留空。若未提供基準日期，省略 `--as-of`，採用腳本執行當日，並在答案明說採用了執行當日作為基準日期。

   ```sh
   python scripts/fee_overdue.py --as-of "YYYY-MM-DD" --record "標籤|戶別|姓名|期別|金額|YYYY-MM-DD|未繳|手機號碼" --record "標籤|戶別|姓名|期別|金額|YYYY-MM-DD|已繳|手機號碼"
   ```

   以實際收到的資料替換命令中的欄位與日期；`--record` 可重複使用。若資料本身含有 `|`，不得自行拆解猜測，將該筆標示為無法判定並請資料提供者確認欄位。
3. 使用腳本輸出的逐筆判定與逾期天數，不自行重算。逾期日數從到期日翌日起算；只有明確標示「未繳」且已逾期至少 60 個日曆日的資料符合條件。「已繳」不催繳；其他狀態不視為明確未繳。列出每筆的標籤、判定及理由。遇到腳本回報的無效或互相衝突值，逐項照錄並說明須由資料提供者確認；不對受影響資料作判定。其他有效資料仍照腳本結果處理。
4. 對每筆符合條件的資料，按原始資料提供正式催繳通知，包含姓名、戶別、費用期別、金額及到期日。缺少的欄位寫「未提供」，不可補造。只請住戶儘速繳納，不得自行加上罰款、法律後果或未提供的期限。另提供簡訊草稿，包含住戶、戶別及欠繳金額；欠缺的事實標為「未提供」。
5. 對每筆符合條件的資料，提供人工指引：請社區管理人員依內部流程在管理系統將該戶標記為「欠繳戶」，並請住戶服務人員核對號碼及內容後人工發送簡訊。不得聲稱已登入、標記或發送。最後逐行說明：系統標記無法由此處執行，須由社區管理人員處理；簡訊無法由此處發送，須由住戶服務人員人工處理。
