# 寵物旅館住宿費計算

依下列步驟一次處理使用者提供的所有住宿資料。計價假設固定為：平日每晚新台幣 800 元；星期六、星期日每晚加價 200 元，即每晚 1,000 元；不另判定國定假日。入住日計為第一晚，退房日不計，並以每晚日期判定房價。

1. 從輸入整理一筆或多筆入住日期與退房日期。日期使用公曆 `YYYY-MM-DD`。若同一筆住宿的日期資料互相矛盾，指出各個衝突值，請使用者確認；不要計算受影響的住宿，但繼續處理其他資料。
2. 若日期缺漏，直接提供可填寫的格式，將未提供的值標為「未提供」，不要猜日期，也不要用問句結尾。格式：`入住日：〔未提供〕；退房日：〔未提供〕`。仍可計算其他資料完整的住宿。
3. 將日期完整且彼此一致的每筆住宿以 `--stay 入住日 退房日` 傳給腳本；每筆住宿各用一次 `--stay`。從放有本檔案的目錄執行：

   ```sh
   python scripts/calculate_stay_cost.py --stay YYYY-MM-DD YYYY-MM-DD
   ```

   多筆資料時在同一命令中重複 `--stay 入住日 退房日`。將命令中的日期換成輸入資料，不要照抄格式範例作為計算資料。
4. 呈現腳本列出的每筆住宿晚數、逐晚日期、平日／假日分類、逐晚金額與總額；保留腳本的元數值，不自行重算。若腳本指出無法使用的日期或日期組合，逐一列出並請使用者確認；不要提供依賴那些值的晚數或總額。若其他住宿可計算，仍呈現其結果。
5. 回覆計算結果本身；若有未提供或需確認的值，也一併清楚標明，不以問題或後續待辦結尾。
