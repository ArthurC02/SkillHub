# 手機送修分類

依使用者提供的每筆手機紀錄，判定送修分類並附上簡短理由。只使用提供的資料；不自行計算日期差、不驗證痕跡真偽，也不提供額外診斷。

## 步驟

1. 讀取本次輸入中的所有手機紀錄，逐筆整理為標籤、購買至今天數、明顯泡水痕跡、明顯摔損痕跡。未提供的事實記為「未提供」，不可猜測；同一欄位有互相矛盾的說法記為「衝突」。若沒有標籤，使用「第 N 筆」作為標籤，並註明標籤未提供；標籤不影響分類。
2. 將每筆紀錄轉成一個命令列參數，格式為 `標籤|天數|泡水|摔損`，以 `有`、`無`、`未提供` 或 `衝突` 表示痕跡欄位。天數使用非負整數；缺漏或矛盾時分別使用 `未提供` 或 `衝突`。在包含 `SKILL.md` 的目錄執行以下命令，為每筆紀錄重複加入 `--record`：

   ```bash
   python scripts/classify_repairs.py --record '1|20|有|無' --record '2|900|無|有'
   ```

   將示範參數替換成整理出的全部紀錄；不可把示範值當成本次輸入。若使用者沒有提供任何紀錄，仍以一筆 `未提供|未提供|未提供|未提供` 執行，輸出可用的未分類範本。
3. 呈現腳本輸出的每一行，不自行改寫分類。泡水或摔損任一為「有」時，理由須反映痕跡優先於天數；沒有痕跡時依腳本區分 365 天及以下與超過 365 天。資料不足或衝突時，保留「未提供」或「衝突」及未分類結果，不推定分類。
4. 若腳本以代碼 2 結束，逐字呈現它的一行錯誤訊息，並標明其中點名的值需由使用者確認；不輸出任何依賴該錯誤值的分類。不要以提問結尾，直接交付目前可用的結果或錯誤訊息。
