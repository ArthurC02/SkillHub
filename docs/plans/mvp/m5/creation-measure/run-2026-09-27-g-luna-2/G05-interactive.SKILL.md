## 用途
依使用者提供的資料，撰寫繁體中文貸款核准結果通知。只使用輸入中有根據的事實，不查詢外部資料、不推測，也不替任何人發送通知。

## 步驟
1. 從輸入辨識核准金額、首期還款日期及其他貸款或通知資訊。欄位名稱不同但意思明確時，按其含義整理；缺少名稱或標籤不妨礙整理其他資料。
2. 一次檢查資料是否有明顯不能成立或互相矛盾的值，例如不存在的日期，或同一項資料出現兩個不同值。逐項列出有問題的值，標明需要使用者確認；不要採用這些值，也不要寫出依賴它們的內容。不要以提問結尾。
3. 若核准金額或首期還款日期未提供，採用常見預設：不猜測、不代填，將該欄標示為「未提供」，並在通知中保留可辨識的空白欄位，讓使用者可直接補上。若其他設定缺少，採用保守且不新增事實的寫法，並指出採用的預設。
4. 撰寫通知本文，明確列出核准金額及首期還款日期；保留輸入中的金額與日期，不自行換算或改寫其值。通知本文最多兩句。先精簡或合併其他資訊；仍放不下時可省略，但在本文以外另寫一句，說明哪些資訊被省略或合併及其處理方式。若沒有資訊被省略或合併，不必添加說明句。
5. 若無法同時符合所有要求，保留兩句的硬性上限，並用一句說明指出因此省略的資訊。對缺少的事實標示「未提供」，不把它改寫成已知事實。
6. 將完整答案寫入 `notification.txt`，以「通知本文：」標示本文，另以「省略／合併說明：」標示需要的說明句；有需確認的問題值時，也在本文之外逐項列明。另將通知本文本身寫入 `notification-body.txt`，逐一以金額及日期的實際輸入值執行以下檢查；若必要值缺失，對本文中明確標出的「未提供」空白欄位不要求不存在的值。從持有此 SKILL.md 的目錄執行：
   ```sh
   python scripts/check_output.py --max-sentences 2 --require "核准金額" --require "首期還款日期" < notification-body.txt
   ```
   若有提供實際金額或日期，也分別以額外的 `--require "實際輸入值"` 參數檢查，直到指令輸出 `OK`。若缺少必要值，確認本文含有標示其未提供的空白欄位。最後只輸出 `notification.txt` 的內容，不附加檔案內容以外的文字。
7. 結尾分行指出不能從此處完成的外部動作及負責者：若需要實際送出通知，明確說明無法從此處送出，須由使用者或其授權的通知發送人處理；不需要送出時，不聲稱通知已送出，也不添加此行。
