# 喜餅小物訂單整理

將客人提供的訂購留言整理成繁體中文清單；打樣費另列，不計入小物總金額。只使用留言中的資訊，不查外部資料。

## 步驟

1. 閱讀留言，逐項擷取品名、數量、單價、明確寫出的品項總價，以及打樣費。保留留言中的單位與幣別；留言未提供的標為「未提供」。
2. 只有在留言能明確支持推算時才補出資訊，例如數量與品項總價能整除時推得單價。算不出或有歧義的值標為「待確認」，不猜測。若同一資訊有互相衝突的值，列出各值供客人確認，該列不採用衝突值計算。品名缺漏時以「未命名品項」列出，不因此略過可用數字。
3. 將可確認的資料傳給腳本計算。從放有本檔案的目錄執行；每個 `--item` 格式為 `品名|數量|單價`，每個 `--line-total` 格式為 `品名|數量|品項總價`。未知欄位填 `?`；沒寫幣別時不要自行指定。打樣費有提及時傳入 `--proofing-fee`，未知金額填 `?`；未提及則省略。每筆訂購列只用一個參數，不要把打樣費當作品項。例如：

   ```sh
   python scripts/order_totals.py --item '品名|數量|單價' --line-total '另一品名|數量|品項總價' --proofing-fee '金額'
   ```

4. 若腳本以代碼 2 結束，依它的一行錯誤訊息指出無法使用的值；把受影響的值列為待確認，不提供依賴該值的金額，並以修正後可用的資料重跑。不得把錯誤輸入當成有效數字。
5. 用腳本輸出作為每項小計與小物金額的唯一計算結果。以留言中的幣別呈現金額；若幣別未提供，標示「幣別未提供」。總額未包含任何待確認的小計時，清楚指出哪些項目未計入、總額因此不完整。打樣費另列，明確註明不計入小物總金額。列出矛盾值等候確認，但以整理好的清單與金額作答，不以問題結尾。
6. 交付訂購清單本身，逐項呈現品項、數量、單價、小計，再呈現小物總金額與打樣費（若有提及）。
