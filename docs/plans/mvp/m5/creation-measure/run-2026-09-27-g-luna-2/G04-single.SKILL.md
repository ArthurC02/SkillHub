## 計算流程

1. 確認入住日期與退房日期，並確認年份。住宿晚數是入住日至退房日前一日的每一晚；退房當天不計費。若日期不完整或日期順序不合理，先請使用者補正。
2. 確認假日加價規則。平日基準價為每晚 800 元，但假日加價金額或計算方式尚未指定。請詢問是每晚固定加價、百分比加價，或假日每晚總價；不可自行假設。若使用者尚未提供，也可先列出各晚日期與平日／假日分類，並標明總額待補加價規則。
3. 確認哪些日期算假日。若使用者未說明，詢問假日是指週六、週日、國定假日，還是旅館自訂日期；不可把週末或國定假日定義默認為對方的規則。若對方提供假日清單，依清單判斷。
4. 逐晚列出計費日期，從入住日期開始，直到退房日前一日。每晚各自分類，因為同一次住宿可能跨平日與假日。
5. 計算住宿總額：
   - 平日費用 = 平日晚數 × 800 元。
   - 假日費用依使用者提供的加價規則逐晚計算。
   - 總額 = 平日費用 + 假日費用。
   若假日規則是百分比，先確認百分比的基準是加在 800 元上，還是另有指定基準；如有小數或進位問題，依使用者規則，否則明確呈現未進位的計算結果。
6. 回覆列出入住與退房日期、總晚數、逐晚日期與分類、平日及假日費用的計算方式，以及總金額。清楚標示幣別為元。不要把其他未提供的費用、折扣或稅金加進去。

## 資料不足時

若缺少日期、年份、假日定義或加價規則，只詢問計算所需的缺項。若入住與退房同日，按零晚處理並說明住宿費為 0 元；若退房早於入住，請使用者更正日期。日期計算若有不確定之處，說明不確定並請使用者確認，不要編造假日或費率。
