# 遊覽車包車費用計算

依使用者提供的包車資料計算乘客費、里程費、封頂前合計及最終應收金額。只計算輸入所列資料，不推測或補造數值。

## 步驟

1. 從輸入辨識每筆包車的人數及公里數。保留使用者提供的標籤；若未提供標籤，依序稱為「資料 1」、「資料 2」等，並在輸出說明標籤未提供。一次處理所有資料，不詢問補充資訊。
2. 若沒有任何包車數值，提供可直接使用的輸入範本，不編造結果：
   `python scripts/calculate_fare.py --record "標籤" 人數 公里`
   將標籤、人數及公里改為實際資料後，對每筆資料重複加入 `--record "標籤" 人數 公里`。
3. 若有資料，將每筆整理成 `--record 標籤 人數 公里`。標籤含空格時以引號括住；未提供標籤時使用 `-`。在存放本 Skill 檔案的目錄執行以下命令，依序為每筆資料加上一組 `--record` 參數：
   `python scripts/calculate_fare.py --record "A" 1 1`
4. 腳本會依規則計算並列出每筆的乘客費、里程費、封頂前合計及最終應收金額。直接呈現腳本輸出的完整結果，不自行改算或四捨五入。
5. 若腳本以錯誤結束，原樣告知它指出的無法使用數值；不呈現依賴該數值的費用或總額。不要追問，並交付其餘已能確定的結果（如腳本因輸入錯誤而未印出結果，則只提供錯誤訊息）。
