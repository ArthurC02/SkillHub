# 管理費逾期催繳流程

1. **確認住戶與帳務資料**
   - 確認社區、戶號、住戶稱呼，以及要處理的是哪一期管理費。
   - 查核該期應繳金額、繳款期限、目前已入帳的款項、未分配款項、折抵或更正紀錄，以及是否已有繳款協議或帳務爭議。
   - 只使用經授權可查閱的帳務與住戶聯絡資料。不要在一般對話中索取或揭露登入密碼、驗證碼等憑證。

2. **判斷是否已逾期滿 60 天**
   - 依社區帳務系統或正式規定採用的逾期日數算法，計算截至處理當日的逾期天數。
   - 只有在逾期至少 60 天，且核對後仍有該期管理費未繳，才繼續執行催繳、標記及通知。
   - 若期限、日數算法、入帳狀態或欠款金額有歧義，先暫停，不要標記或發送；向有權確認帳務的人員詢問。若已繳清，也不要處理。

3. **檢查是否已處理**
   - 查看該戶是否已標記為「欠繳戶」、是否已有同一期催繳通知，以及是否已發過簡訊。
   - 避免重複標記或重複催繳。若紀錄不完整或無法判斷是否已通知，先確認後再進行。

4. **撰寫催繳通知**
   - 使用中性、清楚且不帶威脅或羞辱的語氣。僅列出已核實資料，不自行補造金額、日期、規章依據、罰則或法律後果。
   - 通知應包含：住戶稱呼、戶號、欠費期別、核實的未繳金額、原繳款期限、通知日期、付款方式或聯絡窗口，以及如已付款請提供資料以便核帳。
   - 可依下列格式起草並填入已核實內容：

     > **管理費繳納提醒**  
     > [住戶稱呼] 您好：  
     > 經查，您戶 [戶號] 的 [期別] 管理費尚有 [金額] 元未入帳，原繳款期限為 [期限]。敬請於 [經確認的日期或社區規定的期限] 前完成繳納，或與 [管理室／聯絡窗口] 聯繫核對。若您已完成付款，請提供繳款日期及可供核對的資料。謝謝。  
     > [社區名稱／管理單位]　[通知日期]

   - 若沒有正式規定或核准期限，不要自行承諾或設定新的付款期限；先向管理單位確認。不要把尚未核實的罰款或處置寫進通知。

5. **更新管理系統（僅限具備授權存取時）**
   - 透過已核准的社區管理系統登入方式進入該戶帳務頁面；不要嘗試繞過登入、權限或驗證機制。
   - 再次核對戶號、期別與未繳狀態，然後依要求將該戶標記為「欠繳戶」。若系統要求備註，填入可核實的欠費期別、逾期天數、金額及處理日期，不記錄多餘個資。
   - 儲存後確認狀態確實更新，並記下系統回報的結果。若無權限、系統無法使用或更新失敗，不要聲稱已完成；記錄原因並交由有權人員處理。

6. **發送簡訊（僅限具備授權傳送能力時）**
   - 使用核實且允許用於帳務通知的住戶手機號碼。發送前確認收件人、戶號、期別及金額；若號碼不確定或有隱私疑慮，先暫停確認。
   - 簡訊只放必要資訊，避免揭露敏感帳務細節，尤其不要在可能由他人共用或查看的訊息中列出不必要的個人資料。可採用：

     > [社區名稱]提醒：[戶號] [期別]管理費尚有[金額]元未入帳，原期限為[期限]。請聯繫[管理室電話／窗口]核對或辦理；若已付款，請提供資料以便查帳。

   - 僅在確認發送成功後記錄發送時間及結果。若簡訊服務不可用、收件號碼未確認或傳送失敗，不要宣稱已通知。

7. **回報處理結果**
   - 清楚列出逾期天數、核實的未繳期別與金額，以及通知文案。
   - 分別回報系統標記與簡訊的狀態（已完成、失敗或未執行）及原因。若目前環境沒有社區系統登入權限或簡訊發送工具，明確說明無法代為登入或發送，提供可供授權人員使用的通知內容與待辦清單；不要要求使用者在聊天中提供密碼或驗證碼。未能核實的欄位標為待確認，不可猜測。
