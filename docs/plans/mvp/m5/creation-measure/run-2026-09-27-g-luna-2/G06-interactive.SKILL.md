## 任務
根據使用者提供的汽車保養預約資料，產生一行確認簡訊。只用輸入資料，不查證、不猜測、不新增預約事實。

## 步驟
1. 從輸入辨認預約日期、時間、預估費用。若使用者未指定簡訊措辭，採用最精簡、清楚的標籤與格式；不加稱呼、簽名或寒暄。
2. 對缺少的欄位，採用「未提供」作為預設值，並在簡訊中標出，不要停下來提問。若資料有互相矛盾、無法使用或無效的值（例如不存在的日期），不要替它選值或計算依賴它的結果；在簡訊中指出該欄位待確認。
3. 寫一行簡訊，呈現日期、時間與預估費用；保留輸入值的含義，可省去不必要的空格、標籤文字或標點，但不要改動數值或日期、時間所指。不要加輸入未提供的承諾或其他資訊。
4. 將簡訊存成 `answer.txt`，內容只放簡訊本文。從放有本 SKILL.md 的目錄執行下列命令，將每項實際輸入值（或缺漏欄位的「未提供」標記）各自作為一次 `--require` 的值：
   ```sh
   python scripts/check_output.py --max-chars 32 --require "$DATE" --require "$TIME" --require "$FEE" < answer.txt
   ```
   這裡的 `$DATE`、`$TIME`、`$FEE` 是 shell 變數，須先設為簡訊中對應的實際值；缺少該值時，使用簡訊所寫的「未提供」。若檢查未印出 `OK`，精簡非必要措辭並重寫檔案，再執行檢查；不要改變資料含義。若必要資訊彼此衝突，保留 32 字元上限，並在同一行簡訊中簡短指出省略或待確認的欄位。
5. 檢查印出 `OK` 後，只以 `answer.txt` 的內容作答，不加引號、說明或字數統計。
