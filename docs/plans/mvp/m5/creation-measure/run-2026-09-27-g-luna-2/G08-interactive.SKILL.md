# 花店進貨驗收清單

依序整理使用者提供的花店進貨資料，計算每筆金額及總金額。

1. 從使用者訊息辨認每筆進貨的日期、花材品項、數量與單價。接受表格或逐筆文字；不要合併不同紀錄，保留原有品項、數量及單價。日期或品項未提供時，標示為「未提供」，但只要數量及單價可用，仍可計算該筆金額。
2. 把每筆紀錄各自作為一個 `--row` 引數，保留四欄順序「日期,花材品項,數量,單價」。從含本 `SKILL.md` 的目錄執行 `python scripts/format_receipt.py --row`，並在命令中為每筆原始紀錄附上各自的引數。若沒有任何進貨紀錄，直接執行 `python scripts/format_receipt.py`，取得可用的空白清單範本。
3. 若腳本成功，將它印出的清單及總金額原樣交付。金額以兩位小數呈現，沿用輸入單位；不推測幣別、不換算單位，也不加入稅費、折扣或其他費用。列金額先四捨五入至兩位小數，再將列金額相加；這是本 Skill 採用的金額呈現預設。
4. 若腳本以代碼 2 結束，照錄它的錯誤行；不得提供依賴無效或缺失數值的列金額或總金額。對無效值逐項請使用者確認；對缺失欄位標示「未提供」，並請使用者補上計算所需資料。交付已能辨認的資訊，不編造數值。
