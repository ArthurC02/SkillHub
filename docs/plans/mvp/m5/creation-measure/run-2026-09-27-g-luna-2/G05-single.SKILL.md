## 撰寫步驟

1. 從使用者提供的資料中確認核准金額及首期還款日期。只使用已提供且明確的資訊，不推測、不編造。
2. 若缺少任一必要項目，先詢問缺少的資料；在取得資料前，不要寫成已完成的核准通知。
3. 撰寫繁體中文通知正文，最多兩句。正文必須清楚寫出核准金額和首期還款日期；可將其他重要資訊合併在同一句，或在篇幅不足時省略。不得為了塞入更多內容而超過兩句。
4. 將通知正文與說明分開標示。通知正文以句號、問號或驚嘆號結束的完整句子最多兩句；標題不算正文句子。
5. 在正文之外另加一句說明，指出省略或合併了哪些其他資訊。若沒有省略或合併，說明「未省略或合併其他資訊。」這句不計入通知正文的兩句上限。
6. 提交前再次檢查：核准金額與首期還款日期均出現在正文中，正文不超過兩句，且額外說明只有一句並與正文清楚區隔。
