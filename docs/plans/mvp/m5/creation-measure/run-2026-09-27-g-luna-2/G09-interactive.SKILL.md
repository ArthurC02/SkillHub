## 用途
根據輸入撰寫一篇或多篇繁體中文大學畢業二十週年同學會邀請文。只使用提供的事實；缺漏欄位依下列預設填補並標示「假設，請確認」。無法驗證實際活動安排，不能把假設寫成已確認的事實。

## 步驟
1. 逐則辨認同學會名稱、活動日期、集合時間與地點；有多則資料時分開處理，不要混用不同則的欄位。保留已提供文字的原樣，包括日期、時間、地點的寫法，不要改寫成另一個值。
2. 檢查每個欄位是否出現互相矛盾的不同值。若有，記下該欄位所有不同值，不替它選值、不套用缺漏預設，並在邀請文相應位置標為「待確認」；在成品後列出須由主辦方確認的欄位與值。相同值重複出現不算矛盾。
3. 處理沒有矛盾的缺漏欄位：
   - 日期缺漏：在本 Skill 所在目錄執行 `python scripts/next_saturday.py`，採用程式印出的日期，並標為「假設，請確認」。
   - 日期有提供：將原始日期字串設為 shell 變數 `EVENT_DATE`，執行 `python scripts/next_saturday.py --date "$EVENT_DATE"`。程式印出原始字串時照原樣使用。若程式以代碼 2 結束，照抄它的一行錯誤訊息，不使用該日期，在邀請文標示「日期待確認」並列出原值，交由主辦方確認。
   - 集合時間缺漏：使用 `17:30`，標為「假設，請確認」。
   - 地點缺漏：使用「母校校園內的活動場地」，標為「假設，請確認」。不要自行編造校名、場地名稱或地址。
   - 名稱缺漏且無法由輸入明確推得：使用「二十週年同學會」，標為「假設，請確認」。
4. 為每則資料撰寫一篇溫馨懷舊的邀請文，加入對校園時光、同窗情誼或多年後重逢的真摯情感。這些內容只寫成一般邀請與情感表達，不虛構個人回憶或活動安排。逐項核對名稱、日期、集合時間和地點：完整保留每個有效提供值；每項假設緊接著標明「（假設，請確認）」；有衝突或無效的值則明確標「待確認」，不得呈現成已確認的事實。
5. 直接交付邀請文。若有須確認的欄位，在邀請文後用簡短清單列出欄位及原值，並說明由主辦方確認；不要以問題作結。
