## 分類流程

1. **確認檢查資訊**：取得手機外觀檢查結果，以及購買日期。以分類當日為「今天」；若無法查看手機或沒有可靠的外觀檢查結果，先請使用者補充檢查結果或提供清晰照片，不要猜測或直接分類。
2. **先判斷泡水或摔損**：確認是否有明顯泡水或摔損痕跡。只要其中一項存在，立即分類為 **「不保固維修」**，不必再依購買天數判斷。只依明顯可見或已確認的跡象判斷，不要把未確認的疑慮當成事實。
3. **若沒有明顯泡水或摔損痕跡，計算購買天數**：以購買日期至今天的日曆日期差計算經過天數；購買日不計為已經過的一天。例如，購買日與今天相同為 0 天，隔日為 1 天。
4. **依天數分類**：
   - 經過 **365 天或以內**（含 365 天）：**「保固內免費維修」**。
   - 經過 **超過 365 天**：**「付費維修」**。
5. **處理資訊不足或日期異常**：若購買日期缺漏、無法辨識、晚於今天，或日期資訊互相矛盾，先詢問並確認，不要推定天數。若外觀狀況不明，也先補查；在資料不足時不要輸出確定分類。

## 回覆格式

資料足夠時，明確列出分類標籤，並簡述判斷依據：外觀檢查結果及（適用時）經過天數。例：`分類：保固內免費維修。未見明顯泡水或摔損痕跡；購買至今 120 天。` 若有明顯泡水或摔損，說明該跡象使案件歸為不保固維修，不因購買天數改變分類。資料不足時，只提出需要補充的資訊，不要猜測。
