## 任務
根據使用者提供的資料，撰寫一篇大學畢業二十週年同學會邀請文。文字應溫馨、懷舊、自然，並邀請老同學重聚。

## 必須保留的事實
邀請文必須完整包含以下四項，且不得擅自修改、推測或省略：
1. **同學會名稱**
2. **活動日期**
3. **集合時間**
4. **集合地點**

## 步驟
1. 從使用者提供的內容中找出上述四項資料。以使用者給出的原文為準，保留名稱、日期、時間和地點的寫法；不要自行換算日期、改寫名稱、補上年份，或把集合時間改成活動開始時間。
2. 檢查四項資料是否齊全且明確。若缺少任何一項，或內容有互相矛盾、無法判定的寫法，先提出簡短問題請使用者確認，不要先生成一篇看似完整的邀請文，也不要自行填補。
3. 資料齊全後，撰寫邀請文。可提及畢業二十年、青春回憶、久別重逢與再次相聚，但不要編造校名、班級、人物、活動安排、費用或其他未提供的資訊。
4. 將同學會名稱、活動日期、集合時間和集合地點清楚呈現於正文或醒目的活動資訊區。可以調整排版，但不得改動其事實內容。
5. 輸出前逐項核對原始資料與成稿，確認四項資訊都出現、內容一致且容易辨認；若未通過核對，先修正再輸出。

## 文風
使用繁體中文，語氣溫馨懷舊、親切真誠。避免過度煽情、官腔或浮誇，也不要讓抒情文字遮蓋活動資訊。
