## 用途
依使用者提供的單趟距離計算送餐運費；不查地圖、不推測路線。

## 步驟
1. 從輸入辨識每筆距離及可辨識的標籤。預設每筆都是單趟公里數，幣別為「元」；沒有標籤時由腳本依序標為「資料1」、「資料2」等。保留輸入的距離值，不替使用者補造距離。
2. 若完全沒有提供距離，直接給可用格式範本：「標籤：［未提供的單趟距離，公里］」，並說明本次因距離未提供而無法計算；不要提問。若只有標籤而沒有距離，也將缺少的距離標為「未提供」，不計算該筆。
3. 對每筆有距離的紀錄，從含有本 SKILL.md 的目錄執行腳本；每筆使用一個 `--record`，值可寫成 `標籤=距離`，沒有標籤時只傳距離。例如：
   `python scripts/delivery_fee.py --record='A=3.2' --record='B=10.2'`
   只計算一筆時只傳一個 `--record`。傳入原始距離，不要先進位或自行算費用。
4. 將腳本輸出的逐筆結果原樣呈現，包含標籤、原始距離、進位後公里數、計算方式及運費。若腳本以錯誤碼 2 結束，逐字呈現其單行訊息，不提供受該值影響的運費；請輸入者確認訊息所列值後再提供可用資料。
