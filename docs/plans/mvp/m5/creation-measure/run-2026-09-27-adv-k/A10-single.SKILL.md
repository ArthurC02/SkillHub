# 目的
將一篇文章壓縮成 50 字以內，同時保留原文中所有數字與人名。

# 適用時機
當輸入是一篇文章、新聞、報告或長文，且使用者要求：
- 摘要很短（50 字以內）
- 必須保留文中的所有數字與人名

# 執行步驟
1. **先通讀全文**，找出所有需要保留的資訊：
   - 數字：阿拉伯數字、百分比、日期、時間、金額、編號、比例、範圍等。
   - 人名：中文姓名、英文姓名、譯名、帶稱謂的人名。
2. **判斷文章主旨**，用最少的字概括核心意思。
3. **撰寫摘要時優先保留數字與人名**：
   - 不可刪除原文中的任何數字。
   - 不可刪除原文中的任何人名。
   - 若數字或人名很多，先保留它們，再壓縮其他描述。
4. **控制長度在 50 字以內**：
   - 先寫出最短可用版本。
   - 若超過 50 字，刪除修飾語、重複語、背景說明，只保留主旨與必要數字、人名。
5. **檢查摘要是否符合要求**：
   - 字數是否在 50 字以內。
   - 是否保留了原文所有數字。
   - 是否保留了原文所有人名。
   - 是否仍能表達文章核心。
6. **若無法同時滿足**（例如原文數字或人名過多，導致 50 字內無法完整保留）：
   - 明確告知無法在 50 字內完整保留全部數字與人名。
   - 提供兩個選項：
     - 優先保留全部數字與人名，字數可能超過 50。
     - 嚴格限制 50 字內，但可能無法保留全部數字與人名。

# 輸出原則
- 只輸出摘要本身，除非遇到無法同時滿足的情況。
- 不要加入額外解釋、標題或前言。
- 保持語句精簡、自然、可讀。
- 優先使用原文中的關鍵詞，避免改寫造成數字或人名遺漏。

# 自我檢查
輸出前逐項確認：
- [ ] 字數 ≤ 50
- [ ] 所有數字都已保留
- [ ] 所有人名都已保留
- [ ] 摘要仍表達文章主旨
