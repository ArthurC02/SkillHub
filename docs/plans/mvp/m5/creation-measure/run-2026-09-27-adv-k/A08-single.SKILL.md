# 目的
將輸入的英文客戶回饋先忠實翻譯為繁體中文，再濃縮成三點重點摘要。

# 適用情境
- 使用者貼上英文客戶回饋，要求翻成繁體中文。
- 使用者希望同時得到簡短摘要，方便快速閱讀或轉述。

# 處理步驟
1. **辨識內容**
   - 先確認輸入是否為英文客戶回饋或包含可翻譯的英文意見、評論、回覆、抱怨、建議。
   - 若內容混有少量非英文，仍以英文部分為主進行翻譯。

2. **忠實翻譯成繁體中文**
   - 保留原意、語氣與關鍵細節，不自行補充未提及的資訊。
   - 專有名詞、產品名稱、功能名稱若有明確中文慣用譯法，優先使用慣用譯法；若不確定，保留原文並可在括號補充。
   - 若原文有明顯情緒或評價，翻譯時要保留其正負面語氣。

3. **整理成三點摘要**
   - 將回饋濃縮為三個重點，每點只保留最核心資訊。
   - 三點可依下列方向整理：
     - 主要問題或痛點
     - 使用者需求或期待
     - 建議、建設性意見或正面回饋
   - 若原文內容不足以自然分成三點，仍輸出三點；可將相近內容合併，避免重複。

4. **輸出格式**
   - 先輸出「繁體中文翻譯」
   - 再輸出「三點摘要」
   - 摘要使用條列式，清楚標示 1、2、3

# 輸出規則
- 只輸出翻譯與摘要，不要加入額外分析、評論或延伸建議，除非使用者要求。
- 若原文含有不完整句子、口語或錯字，翻譯時以可理解且忠實為原則，不要擅自修正成不同意思。
- 若遇到無法確定的詞句，保留原文並以最保守方式翻譯。
- 若輸入內容不是英文客戶回饋，而是其他語言或完全無法辨識，先簡短說明無法依此流程處理，再請使用者提供英文內容。
