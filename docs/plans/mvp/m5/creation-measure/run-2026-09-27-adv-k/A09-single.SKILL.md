# 目的
根據「這個月的出勤紀錄」計算每個人的加班時數，並標示出加班時數超過 46 小時的人。

# 適用情境
- 使用者提供當月出勤表、打卡紀錄、工時明細、班表或類似資料。
- 需要按人彙總加班時數。
- 需要找出超過 46 小時的名單。

# 作業步驟
1. **確認資料範圍**
   - 只使用「這個月」的出勤紀錄。
   - 若資料跨月，先排除非本月資料，或請使用者確認要採用的月份。

2. **辨識每筆紀錄的欄位**
   - 找出每個人的識別資訊，例如姓名、員工編號、部門。
   - 找出加班時數欄位；若沒有直接提供加班時數，則依資料中的規則計算。
   - 若資料同時有正常工時與加班工時，僅彙總加班工時。

3. **整理每個人的加班時數**
   - 將同一人的所有本月加班紀錄加總。
   - 若同一人有多筆紀錄，全部納入。
   - 若資料單位不是小時，先換算成小時後再加總。
   - 若有分鐘，統一換算為小數小時或以分鐘累加後再轉回小時，前後保持一致。

4. **檢查資料完整性**
   - 若某筆紀錄缺少姓名、日期或加班時數，先標記為缺漏。
   - 不要自行猜測缺漏值；必要時列出需要補資料的項目。

5. **判定是否超過 46 小時**
   - 對每個人計算出的本月加班總時數，與 46 小時比較。
   - 超過 46 小時者標示為「超標」。
   - 等於 46 小時者不算超過。

6. **輸出結果**
   - 以表格或清單呈現每個人：
     - 姓名/員工編號
     - 本月加班總時數
     - 是否超過 46 小時
   - 對超標者另外列出一份名單，方便快速查看。

# 建議輸出格式
| 姓名 | 員工編號 | 本月加班總時數 | 是否超過46小時 |
|---|---:|---:|---|
| 王小明 | A001 | 48.5 | 是 |
| 陳小華 | A002 | 42.0 | 否 |

# 超標名單
- 王小明：48.5 小時
- ...

# 注意事項
- 只根據提供的出勤紀錄計算，不要加入未提供的假設。
- 若資料格式不清楚，先整理出可辨識的欄位，再進行加總。
- 若使用者提供的是圖片、PDF 或掃描檔，先從內容中辨識出每筆紀錄再計算。
