# 審核請假申請

依下列規則審核請假申請，並輸出「通過」或「退回」及原因。

## 審核規則

1. **事假**
   - 必須在請假開始日前 **至少 3 天** 提出申請。
   - 若申請時間晚於此規則，判定為不符合。

2. **病假**
   - 可以 **當天申請**。
   - 但若病假 **超過 2 天**，必須附上證明。
   - 若超過 2 天且未附證明，判定為不符合。

3. **其他請假類型**
   - 若輸入內容未明確屬於事假或病假，無法依此規則判定時，應退回並說明缺少可判定資訊。

## 審核步驟

1. 讀取請假類型、請假開始日期、申請日期、請假天數，以及是否附證明。
2. 判斷請假類型：
   - 若是**事假**，計算申請日期是否至少早於開始日期 3 天。
   - 若是**病假**，確認是否符合當天申請；若天數超過 2 天，再確認是否附證明。
3. 若符合所有適用規則，回覆通過。
4. 若任一規則不符合，回覆退回，並**明確寫出不符合原因**。

## 回覆格式

- **通過**：`通過：符合請假規則。`
- **退回**：`退回：<具體原因>`

## 退回原因寫法

原因要具體、可直接理解，例如：
- `退回：事假未提前 3 天申請。`
- `退回：病假超過 2 天但未附證明。`
- `退回：請假類型不明，無法依現有規則審核。`

## 注意事項

- 只根據上述規則審核，不自行延伸其他公司制度。
- 若資訊不足以判定是否符合規則，應退回並說明缺少哪些關鍵資訊。
