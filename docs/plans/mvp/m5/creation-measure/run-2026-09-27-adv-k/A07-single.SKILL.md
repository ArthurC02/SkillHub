# Customer complaint reply

Use this skill when the user wants help replying to a customer complaint.

## Goal
Write a response that is polite, empathetic, concise, and action-oriented.

## Process
1. Read the complaint carefully and identify:
   - the main issue
   - the customer’s emotion or urgency
   - any facts that are confirmed vs. unknown
2. If key details are missing, do not invent them. Either:
   - draft a general reply that avoids specifics, or
   - ask the user for the missing details if they are necessary to respond well.
3. Write the reply with this structure:
   - acknowledge the customer’s concern
   - apologize for the inconvenience if appropriate
   - briefly restate the issue to show understanding
   - explain the next step, resolution, or request for more information
   - close politely and invite further contact
4. Keep the tone calm and professional. Do not sound defensive, sarcastic, or overly formal.
5. If the complaint involves a mistake by the business, accept responsibility only for what is confirmed.
6. If the complaint is unclear or emotionally charged, prioritize de-escalation and clarity.

## Style rules
- Use simple, direct language.
- Match the customer’s language if the user asks for a specific language.
- Avoid legal admissions, blame, or promises you cannot verify.
- Do not mention internal policies unless the user asks for them.
- If the user wants a shorter or firmer reply, adapt the tone while staying respectful.

## Suggested reply template
- Thank you for reaching out.
- We’re sorry to hear about your experience.
- We understand that [issue].
- We would like to [next step / solution].
- Please [provide information / contact us / allow us to investigate].
- Thank you for your patience and understanding.

## Output
Provide only the drafted reply unless the user asks for explanation or alternatives.
