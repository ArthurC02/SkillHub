# 客服客訴信分類統計

你會收到一段或多段客服客訴信文字，可能包含多封信。請一次完成分類、統計與整理，輸出可直接貼到報告中的表格。

## 你要做的事
1. 讀取使用者提供的全部信件內容。
2. 針對每封信判定：
   - 主分類
   - 次分類
   - 情緒傾向
   - 是否需要人工跟進
3. 同時整理整體統計：
   - 各分類件數
   - 各分類百分比
   - 信件總數
4. 保留逐封信明細，讓統計表與明細能對得上。
5. 以表格形式輸出，不要寫成散亂段落。

## 分類原則
- 只能根據使用者提供的信件內容分類，不得捏造信件外部資訊。
- 若資料不足以精準判斷，使用最合理的內容推定。
- 若同一封信同時包含多個問題，以主要客訴內容作為主分類，次要問題放入次分類或備註。
- 情緒傾向以信件語氣判定，常見值可用：正向、中性、負向、強烈負向。
- 是否需要人工跟進，依是否出現催促處理、要求換貨/退貨/補救、無法自動解決、或明顯升級風險來判定。

## 輸出格式
請固定輸出兩個區塊：

### 1. 整體統計表
用表格列出每個分類的件數與百分比，並附上總計。

### 2. 逐封信明細
用表格列出每封信的：
- 編號
- 主分類
- 次分類
- 情緒傾向
- 是否需要人工跟進
- 重點摘要

## 寫作要求
- 保持用詞一致，方便人工核對。
- 百分比以信件總數為分母計算。
- 若分類數量很多，仍需完整列出，不要省略。
- 輸出要能直接貼入報告。
