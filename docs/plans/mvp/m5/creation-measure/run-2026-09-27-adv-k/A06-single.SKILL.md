# 自我介紹撰寫流程

## 目標
根據使用者提供的資訊，撰寫一篇符合指定情境、語氣與長度的自我介紹。

## 先確認需求
如果使用者沒有提供足夠資訊，先用最少必要問題補齊以下項目：
1. 使用情境：面試、課堂報告、社群貼文、履歷、活動報名、其他。
2. 語言：中文、英文，或雙語。
3. 長度：短版、中版、長版，或字數範圍。
4. 語氣：正式、自然、親切、活潑、專業。
5. 必要內容：姓名或稱呼、學歷、工作/科系、專長、經歷、興趣、個人特色、想達成的目標。

## 撰寫原則
- 先寫最重要的資訊，再補充背景與特色。
- 內容要真實、具體、簡潔，不要捏造經歷。
- 依情境調整第一人稱與正式程度。
- 若是面試或履歷，強調能力、成果與與職位相關的經驗。
- 若是社群或活動自介，可加入個性、興趣與互動感。
- 避免空泛形容詞，盡量用可驗證的事實或例子。

## 建議結構
### 通用版
1. 開頭：姓名/稱呼與一句總述。
2. 背景：學歷、工作、科系或目前身份。
3. 能力：專長、技能、代表經驗。
4. 個人特色：興趣、價值觀、風格。
5. 結尾：目前目標、期待或一句收尾。

### 面試版
1. 我是誰。
2. 我做過什麼。
3. 我擅長什麼。
4. 我能為對方帶來什麼。
5. 我想應徵/加入的原因。

## 產出方式
- 直接提供可使用的完整自我介紹稿。
- 若資訊不足，先列出需要補充的問題，再等待使用者回答。
- 若使用者要求多版本，提供例如：正式版、口語版、精簡版。
- 若使用者未指定情境，先給一篇通用版，並附上可調整方向。

## 品質檢查
完成後確認：
- 是否符合指定情境與語氣。
- 是否有明確主題與結尾。
- 是否避免過度冗長。
- 是否沒有加入未提供的虛構資訊。

## 回覆格式
- 若資訊足夠：直接輸出自我介紹正文。
- 若資訊不足：先用條列式提出最少必要問題。
