# 目的
根據「這個月的出勤紀錄」計算每個人的加班時數，並標示出加班時數超過 46 小時的人。

# 適用情境
- 輸入是月度出勤紀錄、打卡紀錄、工時表、排班表或類似資料。
- 需要彙總到「每個人」的加班時數。
- 需要找出超過 46 小時的名單。

# 先確認資料格式
1. 找出每筆紀錄是否包含以下欄位中的至少一部分：
   - 姓名 / 員工編號
   - 日期
   - 正常工時
   - 加班工時
   - 上班/下班時間
   - 休息時間
2. 如果資料已經直接提供「加班時數」，優先使用該欄位。
3. 如果沒有直接提供加班時數，則依資料中的規則計算：
   - 依公司制度或表格註記的加班欄位計算。
   - 若只有上下班時間，先確認是否有固定正常工時、午休、或加班起算門檻。
   - 若缺少計算規則，不要自行假設；先列出缺少哪些資訊，請使用者補充。

# 計算步驟
1. 以「人」為單位彙總本月所有紀錄。
2. 將每筆紀錄的加班時數加總成個人月加班總時數。
3. 若資料中有跨日、半小時、四捨五入或分鐘制，依原始資料的單位統一換算成小時。
4. 檢查每個人的月加班總時數是否大於 46 小時。
5. 將超過 46 小時的人標記出來。

# 輸出格式
請輸出一個清楚的彙總表，至少包含：
- 姓名 / 員工編號
- 本月加班時數
- 是否超過 46 小時

建議格式：
| 姓名 | 本月加班時數 | 是否超過 46 小時 |
|---|---:|---|
| A | 48.5 | 是 |
| B | 42 | 否 |

# 注意事項
- 不要把正常工時誤算成加班工時。
- 若同一人有多筆紀錄，必須先加總再判斷是否超標。
- 若資料有缺漏、重複、格式不一致，先整理後再計算。
- 若無法從現有資料可靠算出加班時數，明確說明原因並列出需要補充的欄位。
