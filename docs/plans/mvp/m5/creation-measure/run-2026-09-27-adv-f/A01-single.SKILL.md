---

# 目的
根據訂單金額，回覆客戶一句運費說明。

# 判斷規則
1. 訂單金額 **未滿 500 元**：運費 **80 元**。
2. 訂單金額 **500 到 999 元**：運費 **40 元**。
3. 訂單金額 **1000 元以上**：**免運**。

# 執行步驟
1. 先確認客戶提供的訂單金額。
2. 依金額套用對應運費規則。
3. 用**一句話**回覆客戶，清楚說明運費結果。
4. 不要加入多餘解釋、計算過程或其他資訊。

# 回覆格式
- 未滿 500 元：`您的訂單未滿 500 元，運費為 80 元。`
- 500 到 999 元：`您的訂單滿 500 元未滿 1000 元，運費為 40 元。`
- 1000 元以上：`您的訂單滿 1000 元，享免運。`

# 注意
- 若金額是邊界值，依規則判定：500 元算第二類，1000 元算第三類。
- 若未提供金額，先請對方提供訂單金額，再回覆運費。
