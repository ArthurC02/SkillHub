# 自我介紹撰寫

## 目的
協助使用者寫出符合用途的自我介紹。這個技能不直接編造個人資料；若資訊不足，先向使用者蒐集，再根據情境撰寫。

## 使用時機
當使用者提出以下需求時啟用：
- 「幫我寫自我介紹」
- 「幫我寫面試自介」
- 「幫我寫履歷上的簡介」
- 「幫我寫社群/課堂/活動的自我介紹」

## 工作流程
1. **確認用途與場合**
   - 先判斷自我介紹要用在哪裡：面試、課堂報告、社群貼文、活動開場、履歷、網站關於我等。
   - 若使用者沒有說明，先詢問用途，因為不同場合語氣與長度不同。

2. **蒐集必要資訊**
   至少確認以下項目：
   - 姓名或稱呼
   - 身分/職業/學校科系
   - 目前狀態或主要背景
   - 想強調的能力、經歷或特質
   - 介紹用途與預計長度
   - 語氣偏好：正式、自然、親切、活潑、專業

3. **補充可選資訊**
   視情境詢問：
   - 興趣、專長、成就
   - 工作經驗、專案、社團、比賽、證照
   - 未來目標或想加入的原因
   - 是否需要第一人稱或第三人稱
   - 是否要口語版、書面版、短版、長版

4. **整理內容結構**
   依用途安排順序：
   - **基本版**：我是誰 → 目前背景 → 主要特質/能力 → 興趣或目標
   - **面試版**：我是誰 → 學經歷 → 相關能力 → 成就 → 為何適合
   - **履歷版**：專業背景 → 核心技能 → 代表成果 → 職涯方向
   - **活動/社群版**：簡短身份 → 個性亮點 → 興趣 → 互動邀請

5. **撰寫原則**
   - 使用使用者提供的事實，不自行捏造經歷、學歷、職稱或成就。
   - 若資訊不足，先提出問題，不要硬寫。
   - 文字要自然、清楚、符合場合。
   - 避免過度空泛，例如「我很努力、很認真」若沒有例子支撐，應改寫得更具體。
   - 若使用者要求，提供多個版本供選擇。

6. **輸出格式**
   - 先給出一版可直接使用的自我介紹。
   - 若適合，再附上：
     - 精簡版
     - 正式版
     - 口語版
     - 更有自信/更親切的改寫版

## 可直接詢問的問題
若資訊不足，可一次詢問以下內容：
- 這份自我介紹要用在哪裡？
- 你希望多長？（例如 30 秒、1 分鐘、100 字、300 字）
- 你的姓名/稱呼、身分、背景是什麼？
- 想強調哪些經歷、能力或特質？
- 你希望語氣偏正式、自然還是活潑？

## 注意事項
- 不要替使用者編造個人資料。
- 若使用者只說「幫我寫一篇自我介紹」但沒有提供任何背景，先請對方補充基本資訊。
- 若使用者明確要求「直接幫我寫」，且資訊仍不足，則提供一個可填寫的結構化草稿，並標示需要補上的內容。
