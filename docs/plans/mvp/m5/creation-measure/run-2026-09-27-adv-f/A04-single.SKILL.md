# 每週業績寄送與 Slack 公告

此任務涉及定期寄信與發 Slack 訊息；若沒有已授權的郵件與 Slack 存取權，代理人不能直接完成發送，只能整理內容、確認收件名單與公告格式，並提示需要哪些權限或整合。

## 先確認的資訊
1. 本週業績數字的來源：報表、試算表、BI 儀表板或資料庫匯出。
2. 「全部門」的定義：部門清單、群組信箱、Slack 頻道名稱或成員名單。
3. 寄送時間與時區：每週五下午的具體時間。
4. 郵件主旨與 Slack 公告格式是否有固定模板。
5. 是否需要附檔、圖表或只貼摘要數字。
6. 是否需要包含上週比較、目標達成率、備註或行動項目。

## 執行流程
1. 取得本週業績數字，並確認統計區間是本週一到本週五，或依組織定義的週期。
2. 檢查數字是否完整、可追溯，必要時保留來源連結或截圖作為備查。
3. 整理成兩個版本：
   - 郵件版：較完整，適合部門內轉寄與存檔。
   - Slack 版：精簡，重點放在數字、結論與必要連結。
4. 產生一致的內容，避免郵件與 Slack 數字不一致。
5. 若有權限與整合：
   - 以郵件寄給全部門指定收件者或群組信箱。
   - 同步在指定 Slack 頻道公告。
6. 若沒有發送權限：
   - 輸出可直接貼上的郵件草稿與 Slack 草稿。
   - 明確列出需要人工送出的目標對象與頻道。

## 建議格式
### 郵件主旨
`[每週業績] YYYY/MM/DD 週報`

### 郵件內文
- 本週總業績：
- 與上週比較：
- 達成率：
- 重要觀察：
- 備註：

### Slack 公告
- 一句話摘要
- 3 個以內重點數字
- 如有需要，附上報表連結

## 品質檢查
1. 數字是否與來源一致。
2. 日期與週期是否正確。
3. 收件者與 Slack 頻道是否為「全部門」的正確對象。
4. 內容是否避免洩露不該公開的個人或敏感資訊。
5. 郵件與 Slack 是否使用相同的核心數字。

## 失敗或限制處理
- 若找不到本週業績來源，先回報缺少資料，不要猜測。
- 若無法存取郵件或 Slack，說明無法直接發送，並提供可複製的草稿。
- 若部門名單或頻道不明，先請求確認，不要自行選擇替代對象。
