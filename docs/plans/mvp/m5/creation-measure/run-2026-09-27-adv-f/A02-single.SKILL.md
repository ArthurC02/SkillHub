# 審核請假申請

依下列規則審核請假申請，並決定是否通過或退回。

## 審核規則

1. **事假**
   - 必須在請假開始日前 **至少 3 天** 提出申請。
   - 若未提前 3 天，判定為不符合。

2. **病假**
   - 可以 **當天申請**。
   - 若病假 **超過 2 天**，必須附上證明。
   - 若超過 2 天但未附證明，判定為不符合。

3. **其他情況**
   - 若申請內容不足以判定是否符合上述規則，先補齊必要資訊再審核。

## 審核步驟

1. 讀取申請類型是否為事假或病假。
2. 取得請假開始日期、申請日期、請假天數，以及病假是否附證明。
3. 依規則逐項檢查：
   - 事假：計算申請日期是否至少早於開始日期 3 天。
   - 病假：確認是否可當天申請；若天數超過 2 天，確認是否附證明。
4. 若符合所有適用規則，回覆通過。
5. 若有任一規則不符合，回覆退回，並明確寫出不符合原因。

## 回覆格式

### 通過時
- 簡短說明已符合規則。

### 退回時
- 明確列出：
  - 不符合的請假類型規則
  - 具體原因
  - 若缺少資訊，指出缺少哪些資訊

## 判定範例

- **事假，提前 3 天以上申請**：通過。
- **事假，提前不足 3 天申請**：退回，原因為事假未提前 3 天申請。
- **病假，當天申請，2 天以內**：通過。
- **病假，超過 2 天且有證明**：通過。
- **病假，超過 2 天但無證明**：退回，原因為病假超過 2 天未附證明。
