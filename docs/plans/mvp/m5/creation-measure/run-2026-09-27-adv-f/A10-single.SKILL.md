# 目的
將一篇文章壓縮成 50 字以內，同時保留原文中所有數字與人名。

# 適用時機
當輸入是文章、報導、長文或段落，且使用者要求：
- 摘要很短（50 字以內）
- 必須保留所有數字
- 必須保留所有人名

# 執行步驟
1. 先通讀全文，找出所有需要保留的資訊：
   - 數字：阿拉伯數字、百分比、日期、時間、金額、編號、比例、範圍等。
   - 人名：文中出現的所有人物姓名、譯名、外文名、縮寫式姓名。
2. 先判斷文章主旨，只保留最核心的一句意思。
3. 重新組織成一句極短摘要，優先使用原文關鍵詞，避免加入新資訊。
4. 將所有數字與人名完整保留，不得改寫、刪除、合併或用代稱替換。
5. 檢查字數是否在 50 字以內：
   - 若超過，先刪除非必要修飾語、連接詞、背景描述。
   - 仍超過時，改用更精簡的語序，但不可刪除任何數字或人名。
6. 若原文數字或人名過多，導致無法在 50 字內同時保留全部內容，仍以保留為優先，並在輸出中盡量壓縮其他文字；不要主動省略數字或人名。
7. 輸出只給摘要，不要附加解釋、標註、前言或條列。

# 注意事項
- 不要把人名改成職稱、代號或「他／她／該名人士」。
- 不要把數字改寫成中文數字、阿拉伯數字或近似值；維持原文形式。
- 不要加入原文沒有的新數字或新人物。
- 不要輸出超過 50 字的多句摘要；以單句為主。
