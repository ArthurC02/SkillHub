# 目的
根據使用者需求，產出一份可直接使用的客戶滿意度調查問卷。

# 何時使用
當使用者要你「做一份客戶滿意度調查問卷」、「設計問卷」、「寫 CSAT/NPS 問卷」或類似需求時，載入此技能。

# 工作原則
- 先判斷問卷用途：整體滿意度、單次服務體驗、產品使用回饋、客服評價、NPS，或混合型。
- 若資訊不足，先用合理預設完成一版可用問卷；必要時再列出可調整項目。
- 問卷內容要簡潔、可填寫、避免引導性措辭。
- 題目應涵蓋：整體滿意度、具體體驗、問題點、改進建議、再次購買/推薦意願。

# 產出步驟
1. 先確認或推定問卷情境
   - 若使用者未指定，預設為「一般客戶滿意度調查」。
   - 若可從上下文推知產業或場景，將題目語氣調整為相符版本。

2. 建立問卷結構
   - 開頭說明目的與填答時間。
   - 基本題：整體滿意度。
   - 體驗題：產品/服務/客服/流程等。
   - 開放題：最滿意之處、最需改善之處。
   - 結尾題：再次購買或推薦意願。

3. 選擇適當題型
   - 滿意度題：5 點量表（非常不滿意到非常滿意）或 1–10 分。
   - NPS 題：0–10 分推薦意願。
   - 多選題：用於了解接觸管道、問題類型、改善優先項目。
   - 開放題：用於收集具體建議。

4. 撰寫題目
   - 每題只問一件事。
   - 避免雙重問題、專業術語與模糊詞。
   - 若需要，可加入「不適用」選項。
   - 題目順序由易到難、由一般到具體。

5. 補上填答說明
   - 說明匿名性、資料用途、預估填答時間。
   - 若問卷用於內部改善，明確寫出。

# 建議問卷模板
## 開頭說明
感謝您撥冗填寫本問卷。本問卷旨在了解您對我們產品/服務的滿意程度，作為持續改善的依據。填寫時間約 3–5 分鐘，您的回饋將協助我們提供更好的服務。

## 題目範例
1. 整體而言，您對本次服務/產品的滿意程度為何？
   - 非常不滿意 / 不滿意 / 普通 / 滿意 / 非常滿意

2. 您對以下項目的滿意程度如何？
   - 產品品質
   - 服務態度
   - 回應速度
   - 問題解決能力
   - 購買/使用流程
   （每項使用 5 點量表）

3. 本次體驗中，您最滿意的部分是什麼？
   - 開放式回答

4. 本次體驗中，您認為最需要改善的部分是什麼？
   - 開放式回答

5. 您是否願意再次購買/使用我們的產品或服務？
   - 非常不願意 / 不願意 / 普通 / 願意 / 非常願意

6. 您有多大可能推薦我們給親友或同事？
   - 0–10 分

7. 請問您還有其他建議嗎？
   - 開放式回答

# 交付格式
- 直接輸出完整問卷。
- 若使用者未指定格式，使用標題、說明、題目編號與選項清單。
- 若使用者指定語氣或對象，調整為正式、親切或品牌化版本。

# 注意事項
- 不要假設使用者已提供產業資料；若沒有，就用通用版本。
- 不要加入無法由問卷直接收集的內容。
- 若使用者要求的是「分析問卷結果」而非「設計問卷」，此技能不適用。
