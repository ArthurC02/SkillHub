# 目的
把會議記錄整理成清楚、可執行的待辦事項清單，並為每一項補上：
- 負責人
- 期限

## 適用情境
當輸入是會議紀錄、逐字稿、討論摘要、決議紀錄，且使用者要你整理成待辦事項時，使用此技能。

## 處理原則
1. **只根據會議內容整理**，不要自行腦補不存在的任務、負責人或日期。
2. **優先保留原文資訊**：若會議記錄已明確寫出負責人或期限，直接沿用。
3. **資訊不足時要標示缺漏**：
   - 負責人不明：寫「未指派」或「待確認」
   - 期限不明：寫「未訂」或「待確認」
4. **合併重複事項**：同一件事若在多處重複提到，整理成一項。
5. **拆分複合事項**：若一段話包含多個可獨立執行的任務，拆成多項。
6. **保留可執行性**：待辦事項要寫成動作導向的句子，避免只寫主題詞。
7. **若有明確決議但沒有行動內容**，不要硬轉成待辦；只有能執行的事項才列入。

## 整理步驟
1. 通讀整份會議記錄，找出：
   - 明確指派的工作
   - 決議後需要跟進的事項
   - 會後要完成的交付物
   - 被要求補資料、確認、聯繫、修改、安排的事項
2. 對每個事項確認三個欄位：
   - **事項內容**：用一句話描述要做什麼
   - **負責人**：誰負責執行
   - **期限**：何時完成
3. 若原文只有相對時間，轉成原文可理解的期限表述，例如：
   - 「下週一前」
   - 「本月底」
   - 「會後兩天內」
4. 若原文沒有負責人或期限，保留缺漏標記，不要猜測。
5. 最後輸出成條列清單或表格，讓人可以直接拿去追蹤。

## 建議輸出格式
使用下列格式之一，保持一致即可。

### 格式 A：條列清單
- 待辦事項：……
  - 負責人：……
  - 期限：……

### 格式 B：表格
| 待辦事項 | 負責人 | 期限 |
|---|---|---|
| …… | …… | …… |

## 品質檢查
輸出前確認：
- 每一項都有負責人欄位
- 每一項都有期限欄位
- 沒有把推測當成事實
- 沒有漏掉會議中明確提到的待辦
- 沒有把純討論內容誤列為待辦

## 若資訊不足
如果會議記錄太簡略，無法可靠整理出待辦事項，先列出你能確認的事項，並明確標示缺少的資訊，例如：
- 需要補充完整會議記錄
- 需要確認每項任務的負責人
- 需要確認每項任務的截止日期

不要自行編造。
