# 發票整理與核銷流程

## 適用情境
當任務是把一批發票資料整理成可核銷的格式，並上傳到公司的記帳／核銷系統時使用。

## 先確認可執行範圍
- 如果你沒有公司系統的登入權限、上傳權限，或無法直接操作該系統，先明確說明這一點。
- 你仍然可以完成：
  - 整理發票資料
  - 檢查欄位完整性
  - 分類與彙總
  - 產出可上傳的清單或核銷草稿
  - 列出缺漏與待確認事項
- 不要假設你已經有權限；若缺少必要資訊，先收集再繼續。

## 工作步驟

### 1. 收集與盤點資料
先把所有發票逐筆列出，至少確認以下欄位：
- 發票號碼
- 開立日期
- 金額
- 稅額或含稅／未稅狀態
- 供應商／店家名稱
- 品項或用途
- 對應部門、專案或費用類別
- 是否已付款、是否可核銷
- 附件是否齊全（發票影本、收據、明細、簽核單等）

如果資料來源分散，先合併成單一清單，再進行後續整理。

### 2. 檢查完整性與一致性
逐筆檢查：
- 發票號碼是否重複
- 日期是否落在本月或指定核銷期間
- 金額是否與明細一致
- 稅額計算是否合理
- 抬頭、統編、品名是否符合公司規範
- 是否有缺件、模糊、塗改或無法辨識的項目

把有問題的項目標記出來，先不要送出。

### 3. 依公司規則分類
依公司常見核銷邏輯整理，例如：
- 交通費
- 差旅費
- 餐飲費
- 辦公用品
- 招待費
- 其他費用

若公司有指定科目、成本中心、專案代碼或部門代碼，依規則對應；若不確定，先列為待確認。

### 4. 彙總成核銷清單
建立一份可提交的整理表，建議欄位如下：
- 序號
- 發票號碼
- 日期
- 供應商
- 費用類別
- 專案／部門／成本中心
- 金額
- 稅額
- 備註
- 附件狀態
- 核銷狀態（可送出／待補件／待確認）

同時計算：
- 本次核銷總金額
- 各類別小計
- 待補件金額
- 不可核銷金額

### 5. 處理例外項目
對以下情況單獨列出：
- 缺少發票號碼或日期
- 金額不一致
- 重複報銷
- 超過核銷期限
- 不符合公司政策的支出
- 附件不完整

對每筆例外項目，寫明需要補什麼資料或需要誰確認。

### 6. 準備上傳資料
如果你有系統操作權限：
- 依公司系統要求輸入或匯入資料
- 上傳前再次核對欄位對應是否正確
- 確認附件檔名、格式與大小符合要求
- 上傳後檢查是否成功建立單據或批次
- 保存系統回傳的單號、批次號或截圖紀錄

如果你沒有系統權限：
- 產出一份可直接交給有權限人員上傳的整理檔
- 附上待確認清單與缺件清單
- 明確標示哪些項目可以先送、哪些不能送

### 7. 完成核銷前的最終檢查
送出前確認：
- 所有可核銷項目都已分類完成
- 金額加總正確
- 重複項目已排除
- 缺件項目已標記
- 附件已齊備
- 專案／部門／科目代碼正確
- 已符合公司核銷規範

## 輸出格式建議
最後交付以下內容之一或多個：
- 核銷整理表
- 待補件清單
- 例外項目清單
- 本月核銷總結
- 可直接上傳的資料檔說明

## 注意事項
- 不要自行補寫不存在的發票資訊。
- 不要把不確定的資料當成已確認資料。
- 若公司規則不明，先提出需要確認的問題，再繼續整理。
- 若任務要求你實際登入或上傳到外部系統，但你沒有相應權限或工具，必須明確說明無法直接完成，只能協助整理與準備資料。
