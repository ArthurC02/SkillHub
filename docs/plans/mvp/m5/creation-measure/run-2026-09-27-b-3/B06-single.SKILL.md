# 供應商報價比價表整理

## 目標
將三家以上供應商的報價整理成一份可比較的比價表，並標示每個品項的最低價供應商。

## 適用情境
- 使用者提供了報價單、截圖、PDF、表格或貼上的文字內容。
- 需要把不同供應商的品項名稱、規格、單位、數量、單價與總價整理到同一張表。
- 需要找出每個品項誰最便宜，並指出是否有條件差異導致不可直接比較。

## 工作步驟

### 1. 先確認可比性
在開始整理前，檢查每份報價是否包含以下資訊：
- 供應商名稱
- 品項名稱或料號
- 規格/型號
- 單位
- 數量
- 單價
- 總價
- 幣別
- 稅別或是否含稅
- 交期、運費、最低訂購量等影響價格的條件

如果缺少關鍵資訊，先列出缺漏項目，並在結果中標註「資料不足，無法直接比較」。

### 2. 標準化品項
把不同供應商對同一品項的不同寫法統一成同一列：
- 以料號、規格、尺寸、材質、型號判斷是否為同一品項。
- 若名稱相近但規格不同，不要直接合併；改為分開列出並註明差異。
- 若同一品項有不同包裝數量或單位，先換算成一致單位後再比較。

### 3. 統一比較基準
比較前先統一以下條件：
- 幣別一致時直接比較；幣別不同時先標示不可直接比較，除非使用者提供匯率。
- 稅別一致時直接比較；若一方含稅、一方未稅，需分開標示。
- 若有運費、安裝費、加工費、折扣、回饋或其他附加費用，應納入總成本或至少註明未納入原因。
- 若報價是階梯價或依數量不同而變動，使用使用者指定數量；若未指定，採報價單中的對應數量並註明。

### 4. 建立比價表
輸出一張清楚的表格，建議欄位如下：
- 品項
- 規格/型號
- 單位
- 數量
- 供應商 A 單價
- 供應商 B 單價
- 供應商 C 單價
- 最低價供應商
- 價差
- 備註

若有更多供應商，增加對應欄位。

### 5. 判定每個品項誰最便宜
對每個品項：
- 比較可直接比較的價格。
- 找出最低價供應商。
- 若最低價有並列，標示「並列最低」。
- 若價格差異來自不同稅別、不同單位、不同包裝或不同條件，務必在備註說明。

### 6. 補充總結
在表格後提供簡短摘要：
- 哪一家供應商整體最低價品項最多。
- 哪一家總金額最低（若條件可比且資料完整）。
- 哪些品項因規格或條件不同而無法直接比較。

## 輸出原則
- 保持數字精確，不要自行四捨五入，除非原始資料已四捨五入。
- 若原始資料有歧義，先保留原文並加註疑點。
- 不要自行補齊不存在的價格。
- 若報價內容是圖片或掃描檔，先盡量辨識文字，再整理成表。
- 若有無法辨識的字或數字，明確標示「無法辨識」。

## 建議回覆格式
1. 先列出資料來源與缺漏。
2. 再給比價表。
3. 最後給每個品項的最低價結論與整體摘要。
