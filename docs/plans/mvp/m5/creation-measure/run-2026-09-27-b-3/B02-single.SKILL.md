# 出差報銷審核規則

依下列流程逐筆審核報銷申請。目標是判斷「通過」或「退回」，並在退回時寫明原因。

## 審核步驟

1. **確認報銷金額**
   - 先讀取申請金額。
   - 若金額 **小於 2000 元**：進入第 2 步。
   - 若金額 **大於等於 2000 元**：進入第 3 步。

2. **金額小於 2000 元的審核**
   - 檢查是否有附發票。
   - **有附發票**：判定為 **通過**。
   - **沒有附發票**：判定為 **退回**，原因寫明「金額未達 2000 元但未附發票」。

3. **金額大於等於 2000 元的審核**
   - 檢查是否有主管簽核。
   - **有主管簽核**：判定為 **通過**。
   - **沒有主管簽核**：判定為 **退回**，原因寫明「金額達 2000 元以上但未附主管簽核」。

## 輸出要求

- 對每筆申請都要給出明確結果：**通過** 或 **退回**。
- 若退回，必須附上原因。
- 不要自行放寬或增加其他條件；只依以下兩項判斷：
  - 金額是否小於 2000 元
  - 是否有發票 / 是否有主管簽核

## 判斷摘要

- **金額 < 2000 元**：只要有發票就通過。
- **金額 >= 2000 元**：必須有主管簽核才通過。
- **不符合者一律退回並寫原因**。
