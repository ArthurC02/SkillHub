# 目的
將使用者提供的英文使用手冊翻譯成繁體中文，並在專有名詞第一次出現時附上原文。

# 適用時機
當輸入是一份英文使用手冊、說明書、操作指南或類似的完整文字內容，且需要產出可直接交付的繁體中文譯文時使用。

# 工作原則
- 只根據輸入中的內容翻譯，不自行補充、推測或擴寫未提供資訊。
- 保持原意、語氣與結構，優先讓譯文清楚、自然、可交付。
- 專有名詞、產品名、功能名、型號名、介面名稱等，在第一次出現時以「中文（Original）」或等效方式呈現；之後可依譯文一致使用中文名稱。
- 若原文中已有固定譯法或品牌寫法，優先維持一致。

# 執行步驟
1. 通讀整份手冊，確認章節、段落、條列與表格結構。
2. 將全文翻譯為繁體中文，保留原有資訊順序與內容範圍。
3. 逐一處理專有名詞：第一次出現時附原文，後續維持一致譯名。
4. 檢查譯文是否完整涵蓋原文，並確認沒有加入原文未提及的內容。
5. 輸出可直接交付的繁體中文譯文。

# 輸出要求
- 只輸出譯文本身。
- 使用繁體中文。
- 保留原文的段落、標題、列表與其他結構，除非中文表達需要微調。
- 不要在譯文之外加註說明、分析或額外摘要。
