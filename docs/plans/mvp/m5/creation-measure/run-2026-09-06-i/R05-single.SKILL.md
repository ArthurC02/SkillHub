# 目的
將一週內的每日花費整理成清楚的表格，為每筆支出標示類別，並在週末計算各類別合計與總計。

# 適用情境
- 使用者提供一週的花費明細、收據摘要、聊天紀錄或零散筆記。
- 使用者想要把每日支出變成可讀的週報表。
- 使用者要求依類別統計週末合計。

# 工作流程
1. **先整理輸入資料**
   - 找出每一筆支出的日期、金額、內容/用途。
   - 若日期不完整，依使用者提供的星期順序或上下文推定；若仍無法判定，先列為「未指定日期」並提醒使用者補充。
   - 若金額格式不一致，統一成同一貨幣與數字格式。

2. **為每筆支出標示類別**
   - 依內容判斷最合適的類別，例如：餐飲、交通、購物、娛樂、生活用品、醫療、住宿、其他。
   - 類別要一致，避免同義不同名；若無法歸類，使用「其他」。
   - 若使用者有指定類別清單，優先採用使用者的分類。

3. **建立每日明細表**
   - 以「日期」為主軸列出每日花費。
   - 每筆支出至少包含：日期、項目、類別、金額。
   - 若同一天有多筆支出，逐筆列出，不要合併，除非使用者要求彙總。

4. **計算週末各類別合計**
   - 將整週所有支出依類別加總。
   - 同時計算整週總支出。
   - 若同一類別跨多天出現，合併為同一合計。

5. **輸出格式**
   - 先輸出每日明細表。
   - 再輸出週末彙總表，列出各類別合計與總計。
   - 表格欄位建議如下：
     - 每日明細表：日期｜項目｜類別｜金額
     - 週末彙總表：類別｜合計
   - 若需要更清楚，可在每日明細表中加入「備註」欄，但不要影響主要欄位。

# 計算規則
- 同一類別的金額直接相加。
- 若有退款、折讓或負數金額，保留原符號並納入合計。
- 若有重複紀錄，先確認是否為重複輸入；無法判定時，保留並註記可能重複。
- 金額四捨五入規則要一致；若原始資料有小數，保留到原始精度或依使用者要求格式化。

# 品質檢查
- 確認每筆支出都有日期、類別與金額。
- 確認週末各類別合計與總計一致。
- 確認表格中的金額加總後，與明細筆數相符。
- 若資料不足以完成分類或日期判定，明確列出缺漏，不要自行捏造。
