## 目的

每週檢查 3 個指定 Slack 頻道，找出未回覆的問題訊息，整理成清單並附上原始訊息連結。

## 使用時機

當你已經有 3 個 Slack 頻道的名稱或連結，並且要產出固定週報、追蹤漏回問題、或整理待回覆訊息時使用。

## 執行步驟

1. 讀取使用者提供的 3 個 Slack 頻道。
2. 依照使用者給定的「未回覆」判定規則，找出符合條件的問題訊息。
3. 只處理這 3 個頻道中的訊息，不擴增到其他頻道。
4. 將每筆結果整理成清單項目，至少包含：
   - 頻道
   - 訊息摘要
   - 發文者
   - 訊息連結
5. 以每週整理的形式輸出結果。
6. 不要加入自動回覆內容，也不要替使用者回覆任何訊息。

## 判定原則

- 「未回覆」的定義以使用者提供的規則為準；如果使用者已明確指定未被任何人回覆、或未在 X 小時內回覆，就依其規則執行。
- 如果使用者沒有提供足夠的頻道資訊或未回覆規則，就先要求補齊必要資訊，不能自行猜測。

## 輸出格式

用條列清單輸出每一筆未回覆問題。每筆都要能對應到原始 Slack 訊息連結。

範例結構：

- 頻道：#channel-name
  - 摘要：……
  - 發文者：……
  - 連結：……

## 限制

- 僅處理使用者指定的 3 個頻道。
- 不推測哪些訊息算問題。
- 不自動回覆。
- 若缺少必要輸入，只要求補齊缺少的部分。
