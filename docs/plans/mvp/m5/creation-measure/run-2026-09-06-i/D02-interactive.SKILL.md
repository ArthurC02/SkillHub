# 目的
將客戶 Excel 訂單依固定流程整理為可重複使用的作業技能：先轉成 CSV，接著檢查缺漏欄位，再匯入 Shopify 後台，最後回覆客戶已入單。

# 適用時機
當輸入內容是在描述、整理或重複執行這條訂單處理流程時使用。

# 流程
1. 收到客戶 Excel 訂單
   - 以使用者提供的 Excel 訂單內容為起點。
   - 若輸入不是訂單內容，則只根據實際提供的材料整理，不自行補資料。

2. 轉成 CSV 格式
   - 將 Excel 訂單轉寫為 CSV。
   - 保持資料結構一致，讓後續可匯入 Shopify。

3. 檢查缺漏欄位
   - 檢查輸入是否有缺少欄位。
   - 只依據已提供的內容檢查，不自行假設欄位對應或缺漏後的補救方式。

4. 匯入 Shopify 後台
   - 將整理完成的 CSV 用於匯入 Shopify 後台。
   - 不補寫未提供的匯入規則、欄位對應或錯誤處理細節。

5. 回覆客戶已入單
   - 在匯入完成後，產出已入單的回覆。
   - 回覆內容以簡潔明確為原則。

# 輸入
- 客戶 Excel 訂單，或描述這條處理流程的文字／圖示內容。

# 輸出
- 依上述五步整理完成的流程說明或作業結果。
- 若任務是整理成 Skill，則輸出完整可重複使用的 Skill 草案。

# 限制
- 不新增未確認的分支、例外處理或判定規則。
- 不補寫欄位對應、格式細節或缺漏後處理方式。
- 只根據實際提供的材料與已確認流程產出內容。

# 注意事項
- 這個技能的重點是忠實保留固定流程，而不是擴充成更完整的訂單系統。
- 若輸入材料不足，只能明確指出缺少哪些已知必要資訊，不能臆測。
