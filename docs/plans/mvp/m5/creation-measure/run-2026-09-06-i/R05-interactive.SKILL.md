# weekly-expense-table

把一週花費明細整理成表格，為每筆標示類別，並在週末彙總各類別合計。

## 何時使用
當使用者提供一週內的花費文字明細，且明細中能讀出日期或星期、金額與類別時，使用這個技能。

## 輸入處理
1. 讀取使用者提供的每筆花費。
2. 將每筆資料整理成同一張明細表。
3. 為每筆花費保留日期或星期、項目、金額與類別。
4. 依類別累加整週金額。

## 輸出方式
- 先輸出明細表。
- 明細表之後，輸出週末各類別合計。
- 若同一類別出現多次，合併加總後再列出。

## 約束
- 只使用使用者提供的那一週資料。
- 不補寫未提供的日期、金額、項目或類別。
- 不把其他週的資料混入結果。
