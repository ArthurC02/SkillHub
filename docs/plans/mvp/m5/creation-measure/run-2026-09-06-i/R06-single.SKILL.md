## 目的
將一份英文使用手冊完整翻譯為繁體中文，保留原意、操作順序、警告與格式結構；專有名詞在第一次出現時附上原文。

## 處理原則
1. **完整翻譯，不摘要、不改寫用途**：保留所有段落、標題、列表、表格、註解、警告、注意事項、按鈕名稱、介面文字與編號步驟。
2. **繁體中文為主**：輸出以繁體中文呈現，語氣自然、清楚、符合說明文件風格。
3. **專有名詞首次出現附原文**：
   - 第一次出現時寫成「中文譯名（Original Term）」或「Original Term（中文譯名）」；全文後續統一使用中文譯名。
   - 若原文本身就是品牌、型號、功能名稱、按鍵名稱、錯誤碼或不可翻譯的術語，保留原文並在首次出現時加上必要說明。
4. **術語一致**：同一術語在全文使用相同譯法；若手冊內有術語表、索引或定義，優先與其一致。
5. **格式對齊**：盡量維持原手冊的章節層級、項目符號、表格欄位、步驟編號與提示框類型。
6. **不可省略內容**：頁首頁尾、版權聲明、版本資訊、圖說、腳註、URL、型號、警示符號旁的文字都要翻譯或保留。

## 翻譯步驟
1. **先通讀全文**，辨識：
   - 章節結構
   - 重複術語
   - 專有名詞、產品名、功能名、按鍵名、介面名
   - 表格與圖說
   - 警告、注意、提示、危險等語氣標記
2. **建立術語對照**：
   - 為全文選定一致譯法。
   - 若某術語在不同語境下有不同意思，依上下文固定最合適譯法，避免前後不一致。
3. **逐段翻譯**：
   - 保留原段落順序與邏輯。
   - 操作步驟用清楚、短句、命令式表達。
   - 若原文有條件句、例外情況或前提，務必完整保留。
4. **處理專有名詞首次出現**：
   - 在首次出現處加上原文。
   - 若同一名詞在標題中首次出現，也要在標題中處理，除非會破壞版面，可在標題下第一句補上。
5. **保留格式元素**：
   - 標題層級照原文對應。
   - 清單、表格、警示框、程式碼區塊、按鍵序列、路徑、命令列內容維持可讀性。
   - 若表格翻譯後欄寬受限，仍以內容完整為優先。
6. **檢查一致性與完整性**：
   - 確認沒有漏譯段落。
   - 確認首次出現的專有名詞都有附原文。
   - 確認數字、單位、型號、錯誤碼、快捷鍵未被誤改。

## 翻譯規則
- **按鍵與介面文字**：若是 UI 上顯示的文字，翻譯時保留原文一次，後續可只用中文；若是實際按鍵名稱或快捷鍵，保留原樣。
- **品牌、產品型號、檔名、路徑、命令**：通常保留原文，不強行翻譯。
- **警告與注意**：語氣要明確，不可弱化風險。
- **單位與數值**：保留原單位與數字，不自行換算，除非原文同時提供換算。
- **圖表與截圖說明**：翻譯圖說與標註文字；若圖中內容無法辨識，明確註明無法從提供內容確認。

## 輸出要求
- 只輸出翻譯後的繁體中文手冊內容。
- 保留原有章節順序與結構。
- 不加入與原文無關的說明、註解或摘要。
- 若原文缺頁、圖像不清或內容不完整，僅在相應位置標示缺漏，不自行補寫。
