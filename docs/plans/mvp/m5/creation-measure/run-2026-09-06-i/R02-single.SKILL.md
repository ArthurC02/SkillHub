# Excel 客戶名單去重與缺電話標記

當你收到一份 Excel 客戶名單，需要**去除重複資料**並**標記缺少電話的列**時，使用這個技能。

## 先確認資料規則
1. 找出工作表中哪一欄是客戶識別依據，通常是：
   - 客戶名稱
   - 電話號碼
   - Email
   - 或以上欄位的組合
2. 如果沒有明確規則，優先採用以下順序：
   - **以電話號碼判定重複**，因為電話通常最具唯一性
   - 若電話也可能重複或缺失，再改用「姓名 + 電話」組合
3. 確認「缺少電話」的判定方式：
   - 空白儲存格
   - 只有空格
   - 文字如「無」、「N/A」、「-」也視為缺少電話

## 去除重複
1. 先保留原始檔案副本，避免直接覆蓋原資料。
2. 在 Excel 中選取整個資料範圍，包含標題列。
3. 使用資料去重功能，依照確認好的欄位判定重複。
4. 去重時採用以下原則：
   - **保留第一筆出現的資料**，除非使用者另有指定
   - 刪除後續重複列
5. 去重完成後，檢查剩餘筆數是否合理，並確認沒有誤刪重要欄位。

## 標記缺少電話的列
1. 在電話欄旁新增一欄，例如：`電話狀態` 或 `缺電話標記`。
2. 對每一列檢查電話欄：
   - 若電話為空白或無效值，標記為 `缺少電話`
   - 若電話存在，標記為 `正常`
3. 若需要更醒目，可使用條件格式將缺少電話的列標成不同顏色。
4. 若資料中有多個電話欄位，先確認哪一欄是主要電話欄，再依主要欄位標記。

## 驗證結果
1. 隨機抽查幾筆資料，確認：
   - 重複資料已移除
   - 缺電話的列都有被標記
2. 檢查是否有以下常見問題：
   - 電話欄含公式但顯示空白
   - 電話欄含格式化字元，如空格、連字號，導致判定不一致
   - 同一客戶以不同寫法出現，是否需要人工確認是否算重複

## 若無法直接操作檔案
如果目前環境無法直接編輯 Excel，請先整理出：
- 重複判定欄位
- 缺電話判定規則
- 需要標記的欄位名稱
- 預期保留規則

然後再依這些規則在 Excel 中手動執行去重與標記。
