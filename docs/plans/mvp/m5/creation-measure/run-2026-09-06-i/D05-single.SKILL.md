# 新人到職流程

依照流程圖，按順序執行或整理新人到職作業。此流程沒有分支判斷，必須逐步完成每一項後再進入下一項。

## 流程步驟

1. **收到新人到職通知**
   - 確認已收到正式到職通知。
   - 取得新人姓名、到職日、部門、職稱與聯絡方式。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱可正常登入，並記錄帳號資訊。

3. **加入 Slack 頻道**
   - 將新人加入必要的 Slack 頻道。
   - 至少包含部門、團隊與公告相關頻道。
   - 確認新人可存取並收到頻道訊息。

4. **準備筆電與門禁卡**
   - 安排新人所需的筆電與門禁卡。
   - 確認設備已可交付，門禁權限已設定完成。

5. **安排第一週訓練**
   - 規劃新人第一週的訓練內容與時程。
   - 包含必要的系統介紹、工作流程與部門導覽。

6. **指派導師**
   - 為新人指定一位導師或帶領人。
   - 明確告知導師其支援範圍與對接方式。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備回饋重點：適應狀況、訓練進度、問題與支援需求。

8. **記錄到人資系統**
   - 將以上完成狀態與關鍵資訊登錄到人資系統。
   - 確保紀錄完整、可追蹤，並作為後續管理依據。

## 執行原則

- 嚴格依照上述順序處理。
- 每一步完成後再進行下一步。
- 若某一步缺少必要資訊，先向相關人員確認，再繼續。
- 最終以人資系統紀錄作為流程完成標記。
