# 目的
把已確認的新人到職流程圖整理成一個可重複使用、可直接執行的 Skill。

# 使用範圍
只處理已確認的新人到職流程內容。只能依照已確認的節點順序撰寫，不新增未確認的條件、分支、步驟或角色。

# 執行方式
依序處理下列步驟，且每一步都必須保留原本的節點名稱與順序：

1. 收到新人到職通知
   - 先確認已收到新人到職通知，作為後續流程的起點。

2. 建立公司信箱
   - 接著建立新人所需的公司信箱。

3. 加入 Slack 頻道
   - 再將新人加入所需的 Slack 頻道。

4. 準備筆電與門禁卡
   - 接著準備新人入職所需的筆電與門禁卡。

5. 安排第一週訓練
   - 然後安排新人第一週的訓練。

6. 指派導師
   - 接著指派導師給新人。

7. 第 30 天面談
   - 在流程後段安排第 30 天面談。

8. 記錄到人資系統
   - 最後將結果記錄到人資系統。

# 輸出要求
輸出一份結構清楚的新人到職流程整理結果，並保持與已確認流程圖一致的順序與內容。
