# 目的
將會議逐字稿整理成一份清楚、可執行的待辦清單。每一條待辦都必須包含：
- 事項內容
- 負責人
- 期限

# 適用情境
在收到會議錄音逐字稿、會議紀錄草稿、或口語化討論內容時使用。此技能只負責整理與結構化，不負責補寫未出現的事實。

# 處理原則
1. **只根據逐字稿內容整理**：不要自行推測未提及的任務、負責人或日期。
2. **優先抓取明確行動項**：例如「請 A 在週五前寄出報價」、「B 負責確認規格」。
3. **保留原意**：將口語、重複、插話整理成簡潔可執行的文字。
4. **負責人必填**：
   - 若逐字稿有明確人名、職稱或角色，填入最合理的負責人。
   - 若只有「我」、「你」、「我們」等代稱，依上下文判斷；若仍無法確定，標示為「未明確」。
5. **期限必填**：
   - 若有明確日期、時間、相對期限（如「本週五前」、「兩天內」），直接寫出。
   - 若只有「盡快」、「再跟進」等模糊說法，標示為「未明確」。
6. **避免重複**：同一事項若在逐字稿中被多次提及，合併成一條。
7. **區分待辦與資訊**：純資訊、背景說明、結論但無行動要求的內容，不列入待辦。

# 操作步驟
1. 通讀逐字稿，先標記所有可能的行動句、決議句、指派句。
2. 將每個行動項拆成單一任務；若一段話包含多個任務，分開列出。
3. 為每個任務補上：
   - 任務描述：用動詞開頭，清楚說明要做什麼。
   - 負責人：從逐字稿中找出被指派的人。
   - 期限：從逐字稿中找出日期或時間；若沒有，寫「未明確」。
4. 檢查是否有遺漏的明確指派事項。
5. 輸出成整齊的待辦清單。

# 輸出格式
使用下列格式之一，保持一致：

## 格式 A：條列式
- [ ] 任務內容｜負責人：XXX｜期限：YYYY-MM-DD 或 原文期限
- [ ] 任務內容｜負責人：XXX｜期限：未明確

## 格式 B：表格
| 待辦事項 | 負責人 | 期限 |
|---|---|---|
| ... | ... | ... |

# 品質檢查
輸出前確認：
- 每條待辦都有負責人
- 每條待辦都有期限
- 沒有把背景資訊誤寫成待辦
- 沒有加入逐字稿之外的新資訊
- 文字簡潔、可直接執行
