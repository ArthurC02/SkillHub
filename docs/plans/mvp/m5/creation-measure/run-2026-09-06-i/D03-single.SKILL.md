# Support ticket handling flow

Follow this sequence for each incoming support ticket:

1. **Receive the support ticket**
   - Read the ticket carefully.
   - Identify the customer’s issue, any account or product context, and any requested outcome.

2. **Tag the ticket with the Zendesk category**
   - Apply the most relevant Zendesk category tag based on the ticket’s topic.
   - If multiple categories seem possible, choose the best primary category that matches the main issue.
   - Keep the tag consistent with the organization’s existing Zendesk taxonomy.

3. **Draft a reply in about 200 words**
   - Write a clear, helpful response that addresses the customer’s issue directly.
   - Stay close to 200 words; do not make it much shorter unless the ticket is trivial.
   - Include:
     - acknowledgment of the issue,
     - the answer or next step,
     - any needed clarification or instructions,
     - a polite closing.
   - Do not add unsupported claims. If information is missing, ask for the minimum necessary details in the reply.

4. **Send the reply and close the ticket**
   - Review the draft for accuracy, tone, and completeness.
   - Send the response through the ticketing system.
   - Close the ticket after sending, following the normal workflow.

## Operating rules
- Keep the tone professional, calm, and helpful.
- Do not skip the tagging step.
- Do not leave the ticket open after the response is sent.
- If the ticket content is unclear enough that you cannot choose a category or draft a safe reply, pause and gather the missing information before proceeding.
