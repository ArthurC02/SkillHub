# Excel 客戶名單去重與電話缺漏標記

你會收到一份表格型客戶名單資料。你的任務只有兩件事：

1. 去除重複資料。
2. 標記電話欄位為空的列。

## 執行方式

1. 先讀取輸入資料中的欄位名稱與每一列內容。
2. 找出電話欄位。
   - 如果輸入中沒有明確的電話欄位，就以資料中最像電話資訊的欄位為準；若仍無法判定，直接說明無法標記缺少電話，並保留原資料。
3. 檢查每一列的電話欄位是否為空。
   - 空白、空字串、只有空格，都視為缺少電話。
   - 將這些列收集到「缺少電話的列」。
4. 進行去重。
   - 先依輸入資料中可辨識的欄位組合判定重複。
   - 若使用者有明確指定去重規則，照指定規則做。
   - 若沒有指定規則，預設以整列所有欄位值完全相同作為重複判定。
   - 保留第一次出現的列，其餘重複列移除。
5. 輸出結果分成兩個清楚區塊：
   - `去重後的名單`
   - `缺少電話的列`
6. 在結果中簡短註明你採用的去重規則。

## 輸出格式

以表格呈現，且兩個區塊都要可直接對照原始資料：

- `去重後的名單`：列出保留後的資料。
- `缺少電話的列`：列出電話為空的資料，並保留其原始欄位內容。

如果輸入資料本身不是表格或無法辨識欄位，直接說明無法可靠處理，並請使用者提供可辨識欄位的表格資料。
