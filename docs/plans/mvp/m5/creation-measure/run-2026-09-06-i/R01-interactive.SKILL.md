# 會議逐字稿待辦整理

## 目的
將客戶提供的會議錄音逐字稿整理成待辦清單。此 Skill 用在你收到一段會議逐字稿、需要把其中的待辦事項抽取成可執行清單時。

## 輸入
- 一段會議錄音逐字稿文字。
- 逐字稿中若有明確提到事項、負責人、期限，就以原文資訊整理。
- 若逐字稿沒有明說負責人或期限，不要臆測；保留為待確認資訊。

## 輸出
輸出一份待辦清單。每一條待辦都必須包含：
- 事項
- 負責人
- 期限

## 做法
1. 通讀逐字稿，找出所有明確可執行的待辦事項。
2. 為每個待辦事項擷取原文中明示的負責人。
3. 為每個待辦事項擷取原文中明示的期限。
4. 以清單形式輸出，每條各占一行或一則。
5. 不新增逐字稿中沒有說明的事項、負責人或期限。
6. 若某條資訊未在逐字稿中明確出現，就保留為待確認資訊，而不要自行推斷。

## 輸出格式
使用一致的條列格式呈現，每條至少包含以下欄位：
- 事項：
- 負責人：
- 期限：

## 準則
- 只整理原文明示內容。
- 不改寫成新的任務。
- 不把推測當作事實。
- 對每一條待辦都要完整列出事項、負責人與期限。
