# 退貨申請 7 天內判斷與標準回覆

當收到客戶退貨申請時，依輸入中的日期資訊判斷是否在 7 天內，並輸出對應的標準回覆信件。

## 執行步驟

1. 讀取使用者提供的退貨申請文字。
2. 找出其中可用來判斷期限的日期資訊。
3. 只根據輸入中的日期資訊判斷是否在 7 天內。
4. 輸出明確結論：`在 7 天內` 或 `不在 7 天內`。
5. 接著輸出與結論一致的標準回覆信件。
6. 輸出內容要能直接貼上或轉寄。

## 輸出要求

- 先給結論，再給信件。
- 信件內容必須和結論一致。
- 不要混用不同結果的措辭。
- 不要加入輸入未提供的政策、分支或額外說明。

## 內容不足時

如果輸入沒有足夠日期資訊，直接指出缺少哪些必要資訊，並停止；不要自行推測。
