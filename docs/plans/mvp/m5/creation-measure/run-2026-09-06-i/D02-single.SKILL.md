# Excel 訂單匯入 Shopify 流程

依照圖中的流程執行：收到客戶 Excel 訂單 → 轉成 CSV 格式 → 檢查缺漏欄位 → 匯入 Shopify 後台 → 回覆客戶已入單。

## 執行步驟

1. **接收並確認 Excel 訂單**
   - 先確認檔案可開啟，且內容確實是客戶訂單。
   - 檢查工作表名稱、欄位標題、資料列數是否合理。
   - 若檔案損毀、無法讀取，或不是訂單格式，先回報並請對方重新提供。

2. **轉成 CSV 格式**
   - 將 Excel 另存或匯出為 CSV。
   - 優先保留原始欄位順序與欄位名稱，避免改動資料內容。
   - 若有多個工作表，只處理實際要匯入的訂單工作表。
   - 匯出後再次開啟 CSV，確認分隔符號、編碼與中文內容沒有亂碼。

3. **檢查缺漏欄位**
   - 對照 Shopify 匯入所需欄位，逐列檢查是否有缺值、空白或格式錯誤。
   - 特別留意常見必要資訊，例如：客戶姓名、Email、商品名稱或 SKU、數量、地址、電話、付款/配送相關欄位。
   - 若發現缺漏：
     - 先標記缺少的欄位與對應列號。
     - 若可由其他欄位推得，補齊後再繼續。
     - 若無法補齊，先停止匯入並回覆需要補資料。

4. **匯入 Shopify 後台**
   - 依 Shopify 後台可接受的匯入方式，將 CSV 上傳到對應功能。
   - 匯入前再次確認欄位對應正確，避免資料進錯欄。
   - 匯入後檢查系統回饋：
     - 成功筆數
     - 失敗筆數
     - 錯誤原因
   - 若有失敗列，修正 CSV 後重新匯入，直到完成。

5. **回覆客戶已入單**
   - 確認訂單已成功建立或匯入後，再通知客戶已入單。
   - 回覆內容應包含：
     - 已收到並處理訂單
     - 訂單已建立/已匯入完成
     - 若有缺漏或異常，說明後續需要客戶補充的資訊

## 注意事項

- 不要在未檢查缺漏欄位前直接匯入。
- 不要修改客戶原始資料的意義；若需修正，應保留可追溯性。
- 若 Shopify 後台匯入格式與 Excel 欄位不一致，先做欄位對應再匯入。
- 若此流程需要登入 Shopify 後台，而目前沒有登入權限或無法存取，應先說明限制並請求可用的存取方式。
