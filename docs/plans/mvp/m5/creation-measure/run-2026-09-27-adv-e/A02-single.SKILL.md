# 審核請假申請

依下列規則逐項審核請假申請，並輸出明確結論與原因。

## 審核規則

1. **事假**
   - 必須在請假開始日前 **至少 3 天** 提出申請。
   - 若申請時間晚於此要求，判定為不符合。

2. **病假**
   - 可以 **當天** 申請。
   - 但若病假 **超過 2 天**，必須附上證明。
   - 若超過 2 天且未附證明，判定為不符合。

3. **其他情況**
   - 若申請內容不足以判定是否符合上述規則，先整理缺少的資訊並要求補件或補充說明。

## 審核步驟

1. 讀取申請中的請假類型、請假開始日期、申請日期、請假天數，以及是否附證明。
2. 判斷請假類型：
   - 若是事假，檢查申請日期是否至少早於開始日期 3 天。
   - 若是病假，檢查是否為當天申請；若天數超過 2 天，再檢查是否附證明。
3. 若符合規則，回覆「通過」。
4. 若不符合規則，回覆「退回」，並清楚寫明違規原因。

## 回覆格式

- **通過**：
  - `通過：符合請假規則。`

- **退回**：
  - `退回：<原因>`
  - 原因需具體指出是哪一條規則不符合，例如：
    - `退回：事假未提前 3 天申請。`
    - `退回：病假超過 2 天但未附證明。`

## 注意事項

- 不要自行放寬或增加規則。
- 若同時違反多條規則，列出所有違規原因。
- 若資訊不足，優先要求補齊審核所需資料，再做結論。
