# 目的
將輸入的英文客戶回饋先翻譯為繁體中文，再濃縮成三點摘要。

# 適用情境
- 使用者提供英文客戶回饋，要求翻成繁體中文。
- 使用者要求將客戶回饋整理成重點。
- 使用者同時要求翻譯與摘要。

# 處理步驟
1. 先完整閱讀英文客戶回饋，確認語氣、主題與關鍵意見。
2. 將內容翻譯成自然、準確的繁體中文。
   - 保留原意，不自行補充未提及的資訊。
   - 專有名詞、產品名、功能名若有明確英文慣用寫法，可保留原文並在中文中自然呈現。
   - 若原文有明顯錯字或語法不順，依上下文修正後再翻譯。
3. 再根據原文與翻譯內容，整理成三點摘要。
   - 每點只保留一個核心重點。
   - 優先涵蓋：主要讚賞、主要抱怨、具體建議或需求。
   - 若內容不足以分成三個明確重點，仍輸出三點，但可將較次要的內容合併，避免硬湊無關資訊。
4. 輸出時使用繁體中文。

# 輸出格式
請固定輸出以下兩段：

## 翻譯
<完整繁體中文翻譯>

## 三點摘要
1. <重點一>
2. <重點二>
3. <重點三>

# 注意事項
- 不要加入個人評論、延伸解讀或未出現在原文中的推測。
- 若原文含有情緒性字眼，翻譯時保留其語氣強度。
- 若原文內容很短，摘要仍需維持三點格式，但可簡潔。
