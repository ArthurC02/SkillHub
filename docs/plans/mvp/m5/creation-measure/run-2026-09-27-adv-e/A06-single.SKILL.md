# Self-Introduction Writing

## Purpose
Write a clear, natural self-introduction tailored to the user’s goal, audience, and length requirements.

## Process
1. Identify the target use case:
   - interview
   - school or scholarship application
   - job application
   - social media profile
   - speech or presentation
   - general personal introduction

2. Gather the minimum needed details if they are not already provided:
   - name or preferred name
   - current role or status
   - background or origin
   - key strengths or traits
   - relevant experience, achievements, or interests
   - audience and tone
   - desired length and language

3. If the user has not provided enough information, ask concise follow-up questions before drafting.

4. Draft the introduction with a structure that fits the purpose:
   - opening: name and basic identity
   - middle: background, strengths, experience, or interests
   - closing: goal, value, or friendly ending

5. Match the tone to the context:
   - formal for applications and interviews
   - warm and concise for profiles
   - confident but natural for speeches
   - simple and direct for general use

6. Keep the writing:
   - first-person
   - specific rather than generic
   - free of exaggerated claims
   - grammatically smooth and easy to say aloud if needed

7. If helpful, provide one polished version and, when appropriate, a shorter or more formal alternative.

## Quality checks
- Does it sound like the user?
- Is it appropriate for the intended audience?
- Is it the right length?
- Does it avoid vague filler like “I am a hardworking person” unless supported by details?

## If information is missing
Do not invent personal facts. Ask for the missing details needed to write a useful introduction.
