# 目的
根據「這個月的出勤紀錄」計算每個人的加班時數，並標示出加班時數超過 46 小時的人。

# 適用情境
- 使用者提供當月出勤紀錄、打卡資料、工時表、班表或類似表格。
- 需要按人彙總加班時數。
- 需要找出超過 46 小時的員工並清楚標記。

# 執行步驟
1. **確認資料範圍**
   - 只使用「這個月」的出勤紀錄。
   - 若資料跨月，先排除非本月資料，或請使用者確認要採計的月份。

2. **辨識每筆紀錄的加班時數來源**
   - 若表格已直接提供「加班時數」，就直接採用。
   - 若只有上下班時間、休息時間、標準工時，則依資料中的規則計算加班。
   - 若缺少計算加班所需的欄位，先列出缺少哪些欄位並請使用者補資料，不要自行猜測。

3. **按人彙總**
   - 以員工姓名、工號或資料中可唯一識別的人員欄位分組。
   - 將同一人的所有本月加班時數加總。
   - 若同一人有多筆紀錄，保留明細以便核對。

4. **檢查超過 46 小時**
   - 對每個人的加班總時數與 46 小時比較。
   - 超過 46 小時者標記為「超標」或以明顯符號標示。
   - 等於 46 小時不算超過。

5. **輸出結果**
   - 先列出每個人的加班總時數。
   - 再單獨列出超過 46 小時的人員清單。
   - 若需要，可附上每人的明細加總過程，方便稽核。

# 建議輸出格式
| 人員 | 本月加班時數 | 是否超過 46 小時 |
|---|---:|---|
| 王小明 | 42.5 | 否 |
| 李小華 | 48.0 | 是 |

超標名單：
- 李小華：48.0 小時

# 注意事項
- 不要把正常工時誤算成加班。
- 不要把跨月資料混入本月統計。
- 若資料單位是分鐘，先換算成小時後再加總。
- 若資料有四捨五入規則，依原始資料或使用者指定規則處理，並保持一致。
- 若同一人有缺漏或異常紀錄，先標註異常，再視情況請使用者確認後計算。
