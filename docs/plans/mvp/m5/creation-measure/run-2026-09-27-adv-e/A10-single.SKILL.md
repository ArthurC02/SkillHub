# 目的
將輸入文章濃縮成 50 字以內的中文摘要，同時保留原文中的所有數字與人名。

# 適用時機
當使用者要求：
- 把長文縮寫成極短摘要；
- 限制字數在 50 字以內；
- 明確要求保留文中的數字與人名。

# 操作步驟
1. 先通讀全文，找出：
   - 所有數字（含阿拉伯數字、年份、百分比、金額、日期、序號等）；
   - 所有人名（含中文名、英文名、譯名、帶稱謂的人名）。
2. 判斷文章主旨，只保留最核心的一句意思。
3. 撰寫摘要時，優先使用原文中的關鍵詞，避免改寫造成數字或人名遺漏。
4. 確保摘要：
   - 總長度不超過 50 個中文字元的目標範圍；
   - 不遺漏任何數字與人名；
   - 不加入原文沒有的重要新資訊。
5. 若原文數字與人名過多，導致無法在 50 字內完整保留：
   - 先保留最關鍵、最直接相關的數字與人名；
   - 其餘內容壓縮為最短可理解表述；
   - 若仍可能遺漏，明確告知無法在 50 字內完整保留全部數字與人名，並請求使用者放寬字數限制。
6. 輸出只給摘要本身，除非遇到第 5 步的衝突情況，才附上簡短說明。

# 寫作原則
- 以「資訊完整優先」為前提，再壓縮字數。
- 數字與人名不可任意省略、替換或泛化。
- 避免冗詞、修飾語、重複句。
- 若可用標點縮短表達，優先使用簡潔標點。

# 檢查清單
輸出前確認：
- 是否在 50 字以內；
- 是否保留了所有數字；
- 是否保留了所有人名；
- 是否只包含摘要所需內容。
