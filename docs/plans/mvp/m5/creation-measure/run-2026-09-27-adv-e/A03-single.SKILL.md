# 目的
將「客服信箱上週收到的客訴信」整理成可讀的分類統計表，並保留可追溯的彙總依據。

# 適用範圍
- 只處理使用者已提供的郵件內容、匯出檔或可直接讀取的郵件資料。
- 若沒有提供郵件內容、匯出檔、或可存取的郵件清單，先說明無法直接完成，並列出需要的資料。
- 不要假設能登入信箱、抓取郵件或連線到外部服務；若缺少資料，請請使用者提供匯出結果。

# 輸入資料優先順序
1. 郵件匯出檔（CSV、XLSX、EML、MBOX、PDF、純文字）
2. 已貼上的郵件清單或內容
3. 截圖或掃描文件（若文字可辨識）

# 處理步驟
1. **確認時間範圍**
   - 以「上週」為準，若資料跨週，僅保留上週內收到的客訴信。
   - 若郵件時間格式不一致，先統一成同一時區與日期格式。

2. **辨識客訴信**
   - 只納入明確表達不滿、申訴、要求補償、要求退費、服務失誤、產品瑕疵、配送問題、帳務爭議等內容的郵件。
   - 若一封信同時包含客訴與一般詢問，仍可納入，但要標記為「混合內容」。

3. **建立分類規則**
   - 先依內容主題分類，再依需要加上次分類。
   - 建議主分類：
     - 產品品質
     - 配送/物流
     - 退款/退貨
     - 帳務/付款
     - 服務態度/客服
     - 網站/系統問題
     - 訂單/出貨錯誤
     - 其他
   - 若資料量大，允許一封信有一個主分類與一個次分類；主分類以最主要抱怨點為準。

4. **抽取統計欄位**
   - 每封信至少記錄：
     - 收件日期
     - 寄件者或匿名代號
     - 主題/摘要
     - 主分類
     - 次分類（如有）
     - 嚴重度（低/中/高）
     - 是否已處理（是/否/未知）
   - 嚴重度判定原則：
     - 低：單一問題、語氣一般、未要求立即處理
     - 中：明確不滿、要求回覆或補救
     - 高：大量損失、法律/消保威脅、公開投訴、強烈負面情緒、重複催促

5. **彙總統計**
   - 計算：
     - 客訴總數
     - 各主分類件數與占比
     - 各嚴重度件數與占比
     - 已處理/未處理/未知件數
     - 若可辨識，列出重複來信或同一案件多封信的合併數
   - 若資料足夠，可再加：
     - 每日件數趨勢
     - 主要關鍵字
     - 最常見問題前 3 名

6. **去重與合併規則**
   - 若同一寄件者、同一訂單號、相近日期、相同問題重複來信，視情況合併為同一案件。
   - 合併時保留原始信件數，並在備註中說明合併依據。

7. **輸出格式**
   - 先給一段簡短摘要，說明總數與最主要的分類。
   - 再輸出統計表，至少包含：分類、件數、占比。
   - 若有明細資料，再附一張明細表。
   - 若資料不足以可靠分類，明確標示「無法判定」或「需人工確認」。

# 品質檢查
- 確認總件數等於各分類加總。
- 確認占比加總約為 100%（四捨五入誤差除外）。
- 若有合併案件，明確標示原始信件數與合併後案件數。
- 不要捏造未提供的郵件內容或統計數字。
