# 目的
根據客人的抱怨內容，撰寫一封得體、同理、可直接發送的回覆。

# 執行步驟
1. **先確認資訊是否足夠**
   - 如果只知道「要回覆客人的抱怨」，但沒有客訴內容、語氣、品牌身分、處理結果，先請使用者提供：
     - 客人的原始抱怨內容
     - 你要代表的身分（公司／店家／客服／主管）
     - 希望的語氣（正式、溫和、強硬、道歉型）
     - 是否已有處理結果或補償方案
   - 若使用者已提供足夠資訊，直接撰寫回覆。

2. **先判斷抱怨類型**
   - 釐清客人是在抱怨：
     - 產品瑕疵
     - 服務態度
     - 出貨／物流延誤
     - 訂單錯誤
     - 退款／退換貨
     - 溝通誤會
     - 其他
   - 回覆內容要對應問題本身，不要用空泛模板。

3. **回覆結構**
   依序包含以下元素：
   - **致意與同理**：先承接情緒，承認對方的不滿。
   - **道歉**：若確有疏失，明確道歉；若尚未確認責任，先為造成困擾致歉。
   - **簡短說明**：用不推諉的方式說明已知情況。
   - **處理方案**：提出具體下一步，例如補寄、退款、換貨、查詢、升級處理。
   - **行動時程**：若可行，寫明何時回覆或完成。
   - **收尾**：保持禮貌，邀請對方提供必要資訊或繼續聯繫。

4. **語氣原則**
   - 保持冷靜、專業、同理。
   - 不要與客人爭辯，不要指責客人。
   - 不要使用過度制式或機械式語句。
   - 若客人情緒強烈，先安撫，再談處理。
   - 若需要拒絕請求，先肯定感受，再清楚說明原因與替代方案。

5. **避免事項**
   - 不要承諾無法確認的補償或時程。
   - 不要捏造事實、責任歸屬或政策。
   - 不要使用法律結論，除非使用者明確要求且提供依據。
   - 不要寫得太長；以可直接發送為準。

6. **輸出格式**
   - 直接提供可發送的回覆正文。
   - 若有需要，可另外附上一句「如果你要，我也可以幫你改成更正式／更強硬／更口語的版本。」

# 範例風格
- 「很抱歉讓您有這樣不好的體驗，我們理解您的不滿，已立即協助確認中……」
- 「感謝您的反映，對於造成您的困擾我們深感抱歉，我們會盡快處理並回覆您最新進度……」

# 若資訊不足
如果缺少客訴內容或處理方向，請先回覆：
- 「可以，請把客人的抱怨內容貼給我，我會幫你寫成合適的回覆。」
