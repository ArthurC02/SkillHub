# 新人到職流程

依照流程圖，按順序執行以下步驟；不要跳步，也不要自行改變順序。

1. **收到新人到職通知**
   - 確認已收到正式到職通知。
   - 取得新人姓名、到職日、部門、職稱與聯絡方式。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱可正常登入，並記錄帳號資訊。

3. **加入 Slack 頻道**
   - 將新人加入需要的 Slack 頻道。
   - 至少包含部門、團隊與新人成員常用的溝通頻道。

4. **準備筆電與門禁卡**
   - 準備新人使用的筆電。
   - 準備門禁卡或其他必要的出入權限。
   - 確認設備與權限可在到職日使用。

5. **安排第一週訓練**
   - 排定新人第一週的訓練內容與時程。
   - 確認訓練主題、講師或負責人、時間與地點。

6. **指派導師**
   - 為新人指定導師或帶領人。
   - 明確告知導師其支援範圍與聯絡方式。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 確認面談時間、參與者與討論重點。

8. **記錄到人資系統**
   - 將以上完成事項記錄到人資系統。
   - 確認資料完整、可追蹤，並保留必要備註。

## 執行原則
- 以流程圖順序為準：收到通知 → 建立信箱 → 加入 Slack → 準備設備與門禁 → 安排訓練 → 指派導師 → 第 30 天面談 → 記錄人資系統。
- 若某一步缺少必要資訊，先補齊資訊再繼續。
- 若流程圖只用於整理文件而非實際執行，則輸出上述步驟作為標準作業流程。
