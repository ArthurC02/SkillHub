# 目的
把會議逐字稿整理成清楚、可執行的待辦清單。每一條待辦都必須包含：
- 具體行動
- 負責人
- 期限

# 處理步驟
1. **先通讀逐字稿**
   - 找出所有明確的決議、指派、承諾、追蹤事項、待確認事項。
   - 忽略純討論、背景說明、重複內容與寒暄，除非其中包含可執行事項。

2. **辨識待辦項目**
   - 將同一件事的多段描述合併。
   - 把模糊描述改寫成可執行動作。
   - 若一段內容同時包含多個動作，拆成多條待辦。

3. **找出負責人**
   - 優先使用逐字稿中明確點名的人名、職稱或團隊。
   - 若只有「我」「你」「我們」等代詞，依上下文判斷並寫成最明確的負責單位。
   - 若無法判定，標記為「未指派」並保留原文線索，避免自行臆測。

4. **找出期限**
   - 優先擷取明確日期、時間、週次、里程碑或相對期限（例如「本週五前」「下次會議前」）。
   - 若只有事件依賴關係，寫成「待確認」或「依 XXX 完成後」並保留原文。
   - 不要自行補日期；若逐字稿沒有期限，就明確標示「未提及」。

5. **整理成待辦清單**
   - 每條待辦使用一致格式。
   - 建議格式：
     - `- [ ] 待辦內容｜負責人：XXX｜期限：YYY`
   - 若需要，可在同一條後面補充簡短背景，但不要讓背景蓋過行動內容。

6. **去除重複與合併相近項目**
   - 若多位與會者重複確認同一事項，只保留一條。
   - 若同一事項有不同期限或不同負責人，拆成多條或註明主要負責人與協作人。

7. **保留不確定性**
   - 對於聽不清、指涉不明、期限模糊的內容，直接標示不確定，不要猜測。
   - 可用註記：`（原文不清）`、`（負責人待確認）`、`（期限待確認）`。

# 輸出要求
- 只輸出整理後的待辦清單，除非使用者另外要求摘要或分類。
- 每條都必須有負責人與期限；若原文沒有，就明確寫「未提及」或「待確認」。
- 保持原文語言風格一致，若逐字稿是中文，輸出也用中文。
- 優先忠實反映逐字稿內容，不要加入會議中未提到的推測。
