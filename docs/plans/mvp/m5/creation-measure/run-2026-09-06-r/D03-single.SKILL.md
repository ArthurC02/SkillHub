# Support ticket workflow

Follow these steps in order for each received support ticket.

1. **Receive the support ticket**
   - Read the customer’s message carefully.
   - Identify the main issue, request, or question.
   - Note any key details needed for categorization or response.

2. **Tag with the Zendesk category**
   - Assign the most appropriate Zendesk category tag based on the ticket’s topic.
   - Use the category that best matches the primary issue.
   - If multiple topics are present, choose the dominant one.

3. **Draft a reply in 200 words**
   - Write a clear, helpful response of about 200 words.
   - Address the customer’s issue directly.
   - Include any needed explanation, next steps, or request for missing information.
   - Keep the tone professional, concise, and courteous.
   - Do not exceed the requested length by much; aim for roughly 200 words.

4. **Send and close the ticket**
   - Send the drafted reply.
   - Close the ticket after sending, if the workflow allows it.
   - Ensure the ticket status reflects completion.

## Notes
- If the ticket lacks enough information to answer fully, still draft the best possible reply using the available details and ask for the missing information.
- Do not skip the tagging step.
- Do not close the ticket before the reply is prepared and sent.
