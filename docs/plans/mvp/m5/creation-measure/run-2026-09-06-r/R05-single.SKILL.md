# 目的
將一週內的每日花費整理成清楚的表格，為每筆支出標註類別，並在週末彙總各類別合計。

# 適用情境
- 使用者提供一週的花費明細，要求整理成表格。
- 使用者希望每筆支出都有類別標記。
- 使用者要求在週末或週結時，計算各類別總額。

# 處理流程
1. **確認資料範圍**
   - 先辨識是否涵蓋完整一週，或是使用者指定的起訖日期。
   - 若日期不完整，仍依使用者提供的日期順序整理，不自行補資料。

2. **整理每日明細**
   - 將每筆花費拆成至少以下欄位：
     - 日期
     - 項目/用途
     - 金額
     - 類別
   - 若使用者未提供類別，根據項目名稱推定最合理的類別；若無法判定，標為「其他」。
   - 類別名稱保持一致，避免同義不同名造成統計分散。

3. **建立表格**
   - 以日期為主排序，必要時同一天內依時間或輸入順序排序。
   - 表格至少包含：日期、項目、類別、金額。
   - 若有多筆同日支出，逐筆列出，不合併明細。

4. **計算週末各類別合計**
   - 將整週所有支出依類別加總。
   - 若使用者明確指定「週末」只要週六、週日的合計，則只統計週六與週日；若語意是「週結」，則統計整週各類別合計。
   - 在輸出中清楚標示統計範圍，避免混淆。

5. **輸出格式**
   - 先輸出每日明細表。
   - 再輸出類別合計表。
   - 若需要，也可附上總支出。

# 類別標註原則
- 優先使用使用者原本提供的類別。
- 若未提供，依常見消費類別歸納，例如：
  - 餐飲
  - 交通
  - 生活用品
  - 娛樂
  - 醫療
  - 住宿
  - 通訊
  - 教育
  - 其他
- 同一類別的名稱要統一，例如「吃飯」「午餐」「晚餐」可統一為「餐飲」。

# 統計原則
- 同類別金額直接相加。
- 若有退款、折扣或負數金額，照原值計入，並在表格中保留符號。
- 金額單位要一致；若來源混用不同幣別，先分開列示，不可直接相加。

# 建議輸出範例結構
## 每日花費明細
| 日期 | 項目 | 類別 | 金額 |
|---|---|---:|---:|
| 週一 | 早餐 | 餐飲 | 50 |
| 週一 | 公車 | 交通 | 30 |

## 類別合計
| 類別 | 合計 |
|---|---:|
| 餐飲 | 50 |
| 交通 | 30 |

# 注意事項
- 不要自行捏造未提供的花費。
- 若資料缺少日期、金額或項目，先標示缺漏並請使用者補充。
- 若使用者要求更細的分類，依其指定優先調整。
