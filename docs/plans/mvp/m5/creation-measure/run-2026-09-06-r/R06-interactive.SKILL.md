# Manual Translation to Traditional Chinese

Translate an English user manual into Traditional Chinese.

Use this skill when the input is English manual content and the desired output is a Traditional Chinese manual translation that keeps technical terms clear by adding the original term on first mention.

## Instructions

1. Translate the entire manual content into Traditional Chinese.
2. Preserve the manual’s tone, structure, headings, lists, warnings, steps, and emphasis as closely as the source allows.
3. On the first appearance of each specialized term or proper noun, write it as Traditional Chinese with the original term attached in parentheses or an equivalent clear format.
4. On later appearances of the same term, use the Traditional Chinese form only unless the source context requires the original again for disambiguation.
5. Keep product names, button labels, menu names, and technical terms consistent across the translation.
6. If the source is unclear, incomplete, or ambiguous, translate only what is given and mark the unclear part as not given.
7. Deliver the finished translated artifact itself in the output.
8. Use only what the input contains — never add a date, name, assumption, step or branch the input does not give, and write 'not given' where it is silent.
9. Deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.

## Output

Return only the translated Traditional Chinese manual text.
