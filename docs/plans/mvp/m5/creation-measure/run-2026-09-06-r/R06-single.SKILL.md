## 目標
將一份英文使用手冊完整翻譯為繁體中文，保留原意、結構與可讀性；專有名詞在第一次出現時以「中文（原文）」呈現，之後可只用中文譯名。

## 處理原則
1. **完整翻譯**：不要省略、摘要或改寫成說明文；保留所有段落、標題、列表、表格、警告、註解與頁面順序。
2. **繁體中文**：輸出一律使用繁體中文用字。
3. **專有名詞首次標註原文**：
   - 人名、產品名、功能名、介面名稱、按鈕名稱、技術術語、縮寫、型號、法規名等，第一次出現時寫成「中文譯名（原文）」。
   - 若該詞沒有自然中文譯名，可保留原文，格式為「原文」或「原文（如需補充說明）」；之後維持一致。
4. **一致性**：同一術語、按鈕、選單、錯誤訊息與警告語句，全文用同一譯法。
5. **格式保留**：
   - 標題層級、編號、項目符號、表格欄位順序、粗體、斜體、程式碼區塊、URL、檔名、路徑、按鍵符號與單位格式盡量維持原樣。
   - 若原文有截斷、缺頁或掃描錯字，翻譯時忠實反映，不自行補寫不存在的內容。
6. **數字與單位**：數字、版本號、日期、時間、型號、錯誤代碼、快捷鍵與單位通常保留原格式；必要時可在中文中補上自然語序，但不要改變數值。
7. **警告與注意事項**：保留原本的語氣強度；若原文有 WARNING / CAUTION / NOTE，翻成對應的繁中標示並維持醒目。

## 翻譯步驟
1. 先快速掃描全文，辨識：
   - 標題結構
   - 重複出現的術語
   - 產品/功能/介面名稱
   - 表格與清單
2. 建立一致譯名：
   - 第一次出現時採「中文（原文）」。
   - 後續同詞統一使用中文譯名。
3. 逐段翻譯：
   - 先保留原有段落與順序，再翻成自然的繁體中文。
   - 若句子過長，優先維持技術準確性，再兼顧可讀性。
4. 檢查完整性：
   - 確認沒有漏譯標題、註腳、表格列、項目符號或警告。
   - 確認首次出現的專有名詞都有附原文。
5. 最後校對：
   - 檢查術語一致、標點自然、繁簡字形正確。
   - 若原文有英文縮寫，確認是否需要在首次出現時展開或保留原縮寫；以原文為準，不擅自新增內容。

## 輸出要求
- 直接輸出翻譯後的繁體中文內容。
- 保留原手冊的章節與排版結構。
- 不要加入與原文無關的說明、註解或譯者備註。
- 若遇到無法辨識的專有名詞或圖片中的文字，盡量依上下文翻譯；若仍無法判定，保留原文並維持格式。
