## 目的
收到客戶退貨申請時，先判斷是否在 7 天內，再回覆對應的標準信件。

## 處理步驟
1. 先確認兩個日期：
   - 客戶提出退貨申請的日期
   - 客戶收到商品的日期，或系統定義的起算日期
2. 計算申請是否在 7 天內：
   - 以起算日的隔天算第 1 天，或依公司既有規則計算；若系統已有固定算法，優先遵循系統規則。
   - 若無法確定起算日或日期資訊不足，先要求補齊必要資訊，不要直接判定。
3. 判定結果：
   - 若在 7 天內，使用「可受理退貨」的標準信件。
   - 若超過 7 天，使用「超過退貨期限」的標準信件。
4. 回覆時只輸出對應的標準信件內容；不要自行加寫額外政策、補充說明或個人化承諾，除非標準信件本身要求。
5. 若標準信件需要填入日期、訂單編號或其他欄位，先從已知資料中帶入；缺少欄位時，明確列出需要補充的資訊。

## 信件選擇原則
- 7 天內：語氣應確認受理、說明後續退貨流程。
- 超過 7 天：語氣應婉拒受理、簡要說明已超過期限。
- 兩種信件都應保持一致的客服口吻與公司既定格式。

## 注意事項
- 不要自行改寫成新的政策內容。
- 不要在日期判斷不明確時猜測。
- 若客戶提供的資訊與系統紀錄不一致，先以可驗證的系統紀錄為準，並在必要時請求人工確認。
