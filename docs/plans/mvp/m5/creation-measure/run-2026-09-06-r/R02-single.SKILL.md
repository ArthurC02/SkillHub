# Excel 客戶名單去重與缺電話標記

當你收到一份 Excel 客戶名單，需要**去除重複資料**並**標記缺少電話的列**時，依照以下流程處理。

## 先確認資料規則
1. 找出工作表中哪一欄是客戶識別依據，通常是：
   - 客戶名稱
   - 電話號碼
   - Email
   - 或以上欄位的組合
2. 如果沒有明確規則，優先使用**電話號碼**判斷重複；若電話也可能重複但代表不同人，改用**客戶名稱 + 電話**組合判斷。
3. 確認哪一欄是電話欄，後續用來標記缺漏。

## 去除重複
1. 先保留原始檔案副本，避免誤刪。
2. 在 Excel 中選取整個資料範圍，包含標題列。
3. 使用「資料」→「移除重複項目」。
4. 勾選用來判斷重複的欄位：
   - 若以電話判斷，就只勾電話欄。
   - 若以多欄組合判斷，就勾選所有相關欄位。
5. 執行後，確認 Excel 顯示移除的重複筆數。
6. 檢查保留下來的資料是否符合預期；若需要保留最新一筆或最完整一筆，先依日期或完整度排序，再執行去重。

## 標記缺少電話的列
1. 在電話欄旁新增一欄，例如「電話狀態」或「缺電話標記」。
2. 在第一筆資料列輸入判斷公式：
   - 若電話欄是 B2，可用：`=IF(TRIM(B2)="","缺少電話","")`
   - 若要把空白與只有空格都視為缺漏，這個公式可直接使用。
3. 向下填滿整欄，套用到所有資料列。
4. 篩選「缺少電話」即可快速找出缺漏列。

## 驗證結果
1. 確認去重後的筆數是否合理，且沒有誤刪不同客戶。
2. 確認所有電話空白的列都已被標記。
3. 若資料中有格式不一致的電話（例如含空格、破折號、國碼），先統一格式再判斷重複，避免漏掉相同客戶。

## 交付前檢查
- 保留原始檔與處理後檔案。
- 標題列未被刪除。
- 重複判斷欄位一致。
- 缺電話列已清楚標記。
