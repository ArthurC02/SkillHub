# 目的
收到客戶退貨申請時，先判斷是否在 7 天內，再直接回覆對應的標準信件。

# 適用情境
用在使用者提供一則退貨申請文字，且文字中包含足以判斷時效的日期資訊時。

# 執行規則
1. 只使用輸入中提供的日期資訊進行判斷。
2. 先找出可作為基準的日期與申請日期，計算兩者差距是否在 7 天內。
3. 如果輸入缺少足以判斷的日期資訊，回覆缺少哪些資訊；不要自行補日期或推測。
4. 直接輸出可寄出的完整中文標準信件，不要只輸出判定結果。
5. 信件內容要明確表達結果是「在 7 天內」或「超過 7 天」，並使用對應語氣。
6. 不要加入輸入沒有提供的假設、條件、背景或補充說明。

# 標準信件寫法
## 若在 7 天內
- 表達可以受理或協助後續退貨流程。
- 語氣維持清楚、禮貌、直接。

## 若超過 7 天
- 表達因超過退貨時效而無法受理，或依公司標準流程處理。
- 語氣維持清楚、禮貌、直接。

# 輸出要求
- 產出一封完整信件，可直接作為客服回覆使用。
- 信件中需包含判斷結果與對應說明。
- 若資訊不足，僅說明缺少的日期資訊，並停止。
