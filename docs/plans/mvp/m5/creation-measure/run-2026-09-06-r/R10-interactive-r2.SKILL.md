# Slack 未回覆問題整理

使用這個技能時，請直接根據輸入中的 Slack 頻道內容，找出未回覆的問題並整理成清單。

## 執行原則
- 只依據輸入中的文字判斷；不要新增輸入沒有提供的日期、姓名、步驟、分支或頻道。
- 只輸出最後成品，不要輸出分析、計畫或要求更多存取權限。
- 如果輸入缺少某個必要資訊，對應欄位寫 `not given`，不要猜測。

## 工作步驟
1. 讀取輸入中提供的三個 Slack 頻道內容。
2. 只處理輸入明確給出的那三個頻道；不要加入其他頻道。
3. 找出看起來是問題的訊息。
4. 只保留在輸入內容中沒有看到任何後續回覆的問題。
5. 將每一則未回覆問題整理成清單。
6. 每一筆都附上輸入中提供的可點擊 Slack thread URL；若沒有提供，寫 `not given`。
7. 輸出最後成品本身，不要附加說明、分析或詢問。

## 輸出格式
- 以清單輸出。
- 每筆至少包含：頻道名稱、問題內容、連結。
- 若輸入沒有提供某項資訊，對應欄位寫 `not given`。

## 約束
- 不要把已明確回覆的問題列入未回覆清單。
- 不要補充輸入沒有給的頻道、時間、作者或判定依據。
