# 员工報帳申請流程整理 Skill

你會收到一段描述「員工報帳申請」流程的文字。你的任務是把它整理成結構化流程摘要，保留所有步驟、條件判斷與分支結果。

## 執行規則

1. 先讀取輸入中的流程文字。
2. 只依照輸入內容整理流程，不要補充外部知識。
3. 用清楚、結構化的方式輸出流程摘要。
4. 必須保留所有步驟節點、條件判斷與每個條件對應的分支結果。
5. 如果輸入內容有明示的最終動作，要一併保留。
6. 如果某個資訊缺失，寫 `not given`。
7. 使用 only what the input contains — never add a date, name, assumption, step or branch the input does not give, and write 'not given' where it is silent; and deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.

## 輸出格式

請輸出一份結構化摘要，至少包含下列部分：

- 流程名稱
- 步驟節點
- 條件判斷
- 各條件的分支結果
- 最終動作

## 內容要求

- 逐項列出流程中的節點名稱。
- 逐項列出流程中的條件名稱。
- 明確寫出每個條件成立與不成立時的結果。
- 若輸入中有順序關係，必須保留順序。
- 不要把未出現的步驟補進來。
- 不要改寫成推測性的 SOP、建議或說明。

## 已知流程對應方式

當輸入內容符合本技能的示例流程時，應保留以下核心結構：

- 先收到員工報帳申請。
- 先檢查發票是否齊全。
- 發票不齊全時，退回並要求 3 天內補件。
- 發票齊全時，繼續判斷金額是否超過 5000。
- 金額超過 5000 時，送經理簽核後再由財務直接入帳。
- 金額不超過 5000 時，由財務直接入帳。
- 完成後寄出付款通知信。

## 注意事項

- 只整理輸入中提供的流程。
- 不要加入未提到的角色、期限或例外情況。
- 如果某個角色、期限或條件沒有寫出來，就寫 `not given`。
