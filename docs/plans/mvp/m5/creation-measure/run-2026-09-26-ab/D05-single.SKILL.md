# 新人到職流程

依照流程圖中的順序執行或整理新人的到職作業。此流程是線性的，沒有分支判斷；每一步完成後再進入下一步。

## 流程步驟

1. **收到新人到職通知**
   - 確認已收到新人報到或到職通知。
   - 取得新人姓名、到職日、部門、職稱與聯絡方式。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱可正常登入，並記錄帳號資訊。

3. **加入 Slack 頻道**
   - 將新人加入公司內部需要的 Slack 頻道。
   - 至少包含部門、公告或新人成員相關頻道。

4. **準備筆電與門禁卡**
   - 準備新人報到所需的筆電與門禁卡。
   - 確認設備可用、權限已設定、可於到職日交付。

5. **安排第一週訓練**
   - 規劃新人第一週的訓練內容與時程。
   - 包含必要的系統介紹、工作流程與部門導覽。

6. **指派導師**
   - 指派一位導師或帶領人協助新人適應。
   - 明確告知導師其支援範圍與聯絡方式。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備回饋問題，確認適應狀況、學習進度與支援需求。

8. **記錄到人資系統**
   - 將以上完成狀態與相關資訊記錄到人資系統。
   - 確保資料完整、可追蹤，並保留必要備註。

## 執行原則

- 嚴格依照上述順序進行。
- 若某一步尚未完成，先補齊再往下走。
- 若需要對外通知或交付，優先確認資訊正確與可追蹤。
- 若流程圖只是要你整理成作業流程，則直接輸出以上步驟即可。
