# Support ticket triage workflow

Follow this workflow for each incoming support ticket.

1. **Receive the support ticket**
   - Read the ticket carefully.
   - Identify the customer’s issue, any urgency signals, and any missing information.

2. **Tag with the Zendesk category**
   - Assign the most appropriate Zendesk category tag based on the ticket content.
   - If multiple categories seem possible, choose the best primary match from the ticket’s main issue.
   - Keep the tag consistent with the organization’s existing Zendesk taxonomy.

3. **Draft a reply in 200 words**
   - Write a helpful, professional response of about 200 words.
   - Address the customer’s issue directly.
   - Include any needed clarification, next steps, or requested information.
   - Keep the tone polite, clear, and concise.
   - Do not exceed the requested length by much; aim for roughly 200 words.

4. **Send and close the ticket**
   - Review the tag and reply for accuracy and tone.
   - Send the reply to the customer.
   - Close the ticket after sending, if the workflow allows closure at this stage.

## Quality checks
- The ticket has exactly one best-fit Zendesk category tag.
- The reply is complete, professional, and approximately 200 words.
- The ticket is sent and then closed in the correct order.

## If information is missing
- If the ticket lacks enough detail to choose a category or draft a useful reply, note the missing information in the response and proceed with the best available classification.
- Do not invent facts that are not present in the ticket.
