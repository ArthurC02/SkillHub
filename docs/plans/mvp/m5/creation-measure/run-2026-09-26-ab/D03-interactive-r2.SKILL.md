# Instructions

Follow the five steps exactly as written, in this order, and do not add any conditions, alternatives, exceptions, or fallback handling.

1. Receive a support ticket.
2. Tag the ticket with a Zendesk category.
3. Draft a 200-word reply.
4. Send the reply.
5. Close the ticket.

Keep the workflow linear from start to finish and end after the ticket is closed.

## Output requirements

Return the five steps only, in order, as one direct path from ticket receipt through ticket closure.
