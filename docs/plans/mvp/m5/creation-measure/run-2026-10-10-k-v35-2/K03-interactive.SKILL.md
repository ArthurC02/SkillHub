# 咖啡豆批發訂單統計

整理客人以口語或雜亂文字提供的咖啡豆訂單，輸出品項明細及商品總額。只用訊息提供的資料，不查市場價格、不推測未提供的事實。

## 步驟

1. 閱讀完整訂單訊息，逐一辨認咖啡豆品項、數量、數量單位、單價與單價適用單位。可辨認的同一品項若分列多筆，保留原有各筆資料，不自行合併或改寫。
2. 排除運費、寄送費、包裝費及其他非咖啡豆商品費用；它們不進入商品總額。沿用規格假設：訊息中的金額使用同一貨幣，且單價適用於訊息所述的計量單位。
3. 檢查每筆咖啡豆資料。數量或單價未提供時，照原文保留已知資料，將缺少的值標為「未提供」；不要猜值。若單位不符、數值不合理，或同一欄位有互相矛盾的值（包含後文改動前文的值），逐一列出無法採用的值，並請提出請求的人確認；不要計算依賴該值的品項金額或總額。只處理確定無誤的其他資料，不追問無關資訊。
4. 對每筆數量、單位及單價均已知且可用的咖啡豆品項，從 `SKILL.md` 所在目錄執行腳本；每筆品項用一個 `--item`，格式為 `品項名稱|數量|數量單位|單價|單價單位`。

   ```sh
   python scripts/calc_order_total.py --item '品項名稱|數量|數量單位|單價|單價單位' --item '品項名稱|數量|數量單位|單價|單價單位'
   ```

   將腳本輸出的逐項金額與合計用於答案。腳本以精確十進位相乘、加總，不另行推定換算或四捨五入規則。如腳本以結束碼 2 回報無法使用的值，照實列出該值並請提出請求的人確認；不要呈現依賴它的金額。
5. 用繁體中文交付完整答案：列出每筆咖啡豆品項的數量、單價及品項金額；標明非咖啡豆費用已排除。只有所有咖啡豆品項的數量與單價都已知、可用時，才把腳本合計標為「商品總額」。若仍有缺值，標明缺少哪些值為「未提供」，不得把已知品項的小計冒稱為商品總額。保留每項已提供的事實；不需要的姓名、標籤或日期缺漏不妨礙整理。
