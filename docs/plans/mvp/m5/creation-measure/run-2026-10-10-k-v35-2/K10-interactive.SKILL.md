# 自助洗衣店費用計算

依照以下步驟處理每次計費請求：

1. 從請求中依序擷取每筆洗衣公斤數和烘乾分鐘數，配成一筆資料；保留原有順序。只使用請求明確提供的數值，不推測或補造數值。分數公斤、分鐘照原數值計算，不另行四捨五入。
2. 若某筆缺少公斤數或分鐘數，把缺少的欄位標為「未提供」，仍為該筆輸出應付金額空白模板；其他完整資料照常計算。若一筆資料對同一欄位有不同數值（包括後來更改先前數值），不採用衝突數值，也不計算該筆；在輸出中列明各個衝突值，請提出請求者確認。不要因為缺少未要求的姓名、標籤或日期而停止計算。
3. 將完整且非負的公斤數及分鐘數按輸入順序分別組成兩組命令列參數。從包含本 SKILL.md 的目錄執行 `python scripts/laundry_fee.py --load-kg`，其後接上依序排列的公斤數，再加上 `--dry-minutes` 及依序排列的分鐘數。若某一組完全沒有提供數值，省略該組旗標及其值；兩組都沒有時執行 `python scripts/laundry_fee.py`。例如，多筆資料的兩組數值各自以空格分隔，位置一一對應。
4. 讀取腳本輸出，按原順序逐筆提供金額；每筆只列應付金額，不附計算說明。缺少數值的筆數照原位置列出帶有「未提供」欄位名稱的空白金額模板。若腳本以代碼 2 結束，照樣呈現它列出的可計算結果，並逐字轉達錯誤訊息；不要提供依賴無效數值的金額。無效數值須由提出請求者確認。
5. 若輸入包含互相矛盾或不能成立的數值，明確指出每個數值並請提出請求者確認；不要計算依賴該值的金額。只處理洗衣與烘乾費，不推算其他服務或費用。
6. 若請求另要求任何外部動作，不執行該動作，也不聲稱已完成；先備妥可直接使用的內容，最後每個動作各用一行，寫明該動作、本 Skill 無法代為執行，以及應由提出請求者或其指定負責人完成。
