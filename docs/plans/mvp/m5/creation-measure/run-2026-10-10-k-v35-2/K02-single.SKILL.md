## 退費分類流程

對使用者提供的每筆申請，依序執行以下步驟：

1. **確認資料完整且可判讀**
   - 每筆必須能辨識購買日、申請日，以及是否已領取實體教材包。
   - 若有資料缺漏、日期格式含糊或無法判定教材包是否已領取，先詢問使用者補充或確認，不要猜測分類。
   - 若申請日早於購買日，指出日期矛盾並請使用者確認；確認前不要分類。
   - 若使用者提供多筆申請，分開處理，不能把一筆的資料套用到其他筆。

2. **先套用教材包優先規則**
   - 若已領取實體教材包，直接分類為「不可退費」，不論日期差幾天。
   - 此情況仍可計算並回報日期差，但不可讓天數規則改變分類。

3. **計算天數差**
   - 天數差 = 申請日 − 購買日，以兩個日期的日曆日差計算；購買當日申請的差為 0 天。
   - 若未領取實體教材包，依天數差分類：
     - 0 至 7 天（含 0、7）：**全額退費**
     - 8 至 30 天（含 8、30）：**退一半**
     - 31 天以上：**不可退費**

4. **回報結果**
   - 每筆分別列出購買日、申請日、天數差、教材包是否已領取、分類及簡短判定理由。
   - 使用分類名稱「全額退費」「退一半」「不可退費」，不要自行改成其他類別或增加未提供的規則。
   - 多筆申請可用表格呈現，並維持使用者提供的順序。
   - 若有尚未分類的申請，清楚列出缺少或需確認的資料，只詢問解決判定所需的內容。
