# 實驗室耗材詢價信

根據使用者提供的資料，撰寫一封繁體中文、禮貌精簡的供應商詢價信。只準備可供使用者使用的內容，不聲稱已執行任何外部操作。

## 步驟

1. 從需求中擷取每項耗材的品名、數量、包裝資訊及需要到貨日；照原文保留已提供的事實與數值，不自行改寫成不同規格或單位。
2. 一次檢查輸入。非必要資訊缺漏不妨礙撰寫；供應商未提供時使用「您好」等通用稱呼。必要資料缺漏時，照樣提供可用信件，並在相應位置標示「未提供」或清楚的方括號空格。若日期不存在、數量為負數、同一欄位有互相衝突的值，明確列出相關值並請提出需求者確認；不自行選擇，也不作依賴該值的推算。不要詢問其他問題。
3. 寫出「主旨」及「信件正文」。正文逐項列出耗材與數量；有包裝資訊就一併列出。詢問各項報價，並詢問供應商能否配合需要到貨日。未提供價格、規格、供應商資料或寄件者資料時，不得捏造。
4. 將完整詢價信直接放在回覆中。若需求提及任何需要登入、寄送、致電、張貼、排程或其他外部執行的動作，在信件後逐項加一行：寫明該動作、明確說本 Skill 無法代為執行，並指出由提出需求者或其指定負責人自行處理。仍須提供信件；不得聲稱已執行該動作。
