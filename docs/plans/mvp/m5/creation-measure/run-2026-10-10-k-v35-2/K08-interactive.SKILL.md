## 用途與規則

處理使用者貼上的一份或多份展覽器材租借清單。每份清單分開檢查；一份清單的問題不影響其他清單。只計算桌子、椅子、投影機，不估算其他費用。

固定單價：桌子每張每日 200 元、椅子每張每日 30 元、投影機每台每日 1500 元。未列出的器材數量按零計。租借起日須是有效的 `YYYY-MM-DD` 日曆日期；租借天數須為正整數；數量須為非負整數，零可接受。同一清單同一欄位出現不同值時視為矛盾。起日只驗證，不影響費率。

## 步驟

1. 從使用者訊息擷取清單原文，不改寫其中的事實。以「清單」開頭的標題分隔多份清單；沒有標題時，將全文當作一份清單。辨認「租借起日」、「租借天數」、「桌子」、「椅子」及「投影機」欄位。
2. 將原文逐字寫入暫存輸入檔：
   ```sh
   cat > /tmp/rental-input.txt <<'RENTAL_INPUT'
   （在此貼入使用者提供的完整清單原文）
   RENTAL_INPUT
   ```
3. 從含有此 `SKILL.md` 的目錄執行：
   ```sh
   python scripts/rental_total.py --input-file /tmp/rental-input.txt
   ```
   依腳本輸出逐份呈現檢查結果及計算結果。不要自行補值或改選矛盾值；有問題的清單不輸出總額。指出每個有問題的值，請提出請求的人逐項確認或修正；不要詢問其他事項。資料缺漏時標示「未提供」，並附上可直接填寫的欄位範本；不要因此跳過其他可用清單的結果。
4. 按腳本結果製作完整答案檔，保持使用者提供的每項事實原樣，包含固定單價及所有清單結果。執行以下檢查，直到印出 `OK`；答案只輸出答案檔的內容：
   ```sh
   cp /tmp/rental-report.txt /tmp/rental-answer.txt
   python scripts/check_output.py --require '桌子每張每日 200 元' --require '椅子每張每日 30 元' --require '投影機每台每日 1500 元' < /tmp/rental-answer.txt
   ```

遇到請求中提及的登入、傳送、發布、排程、網路存取或更改外部系統等動作，一律只準備可供使用的內容，不聲稱已完成該動作；答案末尾須為每項被提及的動作各加一行，明確說明本 Skill 無法執行，並指出須由提出請求的人或請求中指定負責的人完成。
