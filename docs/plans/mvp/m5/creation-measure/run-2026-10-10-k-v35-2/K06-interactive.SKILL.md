# 美甲店預約提醒簡訊

根據使用者提供的一筆或多筆顧客資料，逐筆產生預約提醒簡訊。只能使用輸入中的資料與本 Skill 明定的預設值；不能聲稱已核實預約。

## 步驟

1. 依輸入順序辨認每筆資料中的顧客稱呼、預約日期時間、取消截止日期時間，以及是否有後續更改預約的備註。略過「未提供」等明確表示缺值的欄位；不要把未提供的欄位當成事實。
2. 將每個已提供的日期時間以 `YYYY/MM/DD HH:MM` 傳給腳本。每個預約日期時間主張使用一次 `--appointment`；備註中的更改時間使用 `--changed-appointment`；已提供的取消截止日期時間使用 `--cancellation-deadline`。缺少稱呼時省略 `--name`，缺少的日期時間參數也省略。若有多筆顧客資料，逐筆執行一次。
3. 從本 SKILL.md 所在目錄執行下列命令，依欄位代入引號內的原始資料；沒有的可選參數不要加入：

   ```sh
   python scripts/reminder.py --name "林小姐" --appointment "2026/10/12 14:30" --cancellation-deadline "2026/10/11 14:30"
   ```

   使用腳本輸出的簡訊本文。預約日期或時間缺少，或不同主張互相矛盾時，採用腳本輸出的「預約日期時間待確認」，不可自行猜日期或時間。取消截止時間缺少時，使用腳本按預約前 24 小時計算的結果；同時留意腳本列出的預設值與可改變它的參數。
4. 將每筆簡訊依原順序各放一行，合併成最終答案，不加標題、說明、字數統計或其他文字。把每則簡訊分別寫入暫存檔，逐一執行 `python scripts/check_output.py <暫存檔路徑> --max-chars 40`；修正後重查，直到每次都輸出 `OK`。答案只輸出合併後的簡訊本文。

## 必須遵守

- 稱呼缺少時用「您好」；將日期格式化為月／日、時間格式化為 24 小時制。不得改動或遺漏輸入中明確且無歧義的日期與時間。
- 每則簡訊包含稱呼、預約日期時間（或待確認標示）及取消截止日期時間；全文含標點、空格與數字不得超過 40 字。
- 缺少取消截止時間時，採用預約時間前 24 小時，並遵守腳本對所用預設值的提示。不得把預設推算說成顧客已提供的資料。
- 每次執行只處理一筆資料；按輸入順序逐筆執行，不得合併不同顧客的資料。
- 若輸入提及需要登入、傳送、發布、排程或變更外部系統等動作，先備妥可直接使用的內容；答案最後另以一行逐項說明該動作本 Skill 無法執行，並指出由提出請求的人或請求中指定負責的人執行。
