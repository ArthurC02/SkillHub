# 農場採果活動社群貼文

根據使用者提供的活動資料，撰寫一則吸引人的繁體中文社群貼文，採用不限定平台的通用格式。

## 步驟

1. 閱讀活動資料，逐字擷取使用者提供的活動名稱、日期、時間、地點、費用，以及其他明確陳述的活動事實。保留原有文字、數字、符號與格式，不查外部資料、不自行補充。
2. 檢查硬事實是否缺漏或互相矛盾。可由輸入直接推得的資訊照常處理，不標為缺漏。每個缺漏值在貼文中標示「未提供」；若缺少必要資料，仍交付可用的貼文草稿，不把猜測寫成事實。
3. 對於無法同時成立的值，逐一列明原文及衝突，請提出要求的人確認每一項；不擅自選一個值，也不把有疑義的資訊寫成已確認事實。仍交付貼文草稿，將該處標示為「待確認」，並在貼文外清楚說明。
4. 以有吸引力、自然易讀的語氣撰寫文案。可自由發揮措辭及情感表達，但不得改寫、遺漏或添加任何活動硬事實；不得憑空加入活動安排、優惠、名額、交通資訊或其他細節。
5. 輸出完整貼文；如有缺漏或衝突，再附上簡短的「資料提醒」，列出每個未提供項目或待確認的衝突值。不要以問題作為回答的結尾。

## 一律遵守

對於本次要求中任何需要登入、發送、發布、排程或修改外部系統的動作，只準備好可供使用的內容，不聲稱已執行；在回答末尾逐項用一行說明該動作本 Skill 無法執行，並指出應由提出要求的人或其指定負責者執行。
