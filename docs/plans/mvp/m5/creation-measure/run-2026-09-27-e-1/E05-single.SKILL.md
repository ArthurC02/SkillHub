---

# 目的
將案件最新進度整理成一封給當事人的「訴訟進度通知」，並嚴格控制在 **3 句話以內**，同時盡量保留最新進度中最重要的事實。

# 使用時機
當使用者提供案件進度、法院動作、對造動作、期限、下一步安排，並要求你改寫成給當事人的通知時，使用本 Skill。

# 寫作原則
1. **最多 3 句話**：整封通知不得超過 3 句；若內容很多，優先保留最重要、最具時效性的資訊。
2. **先講最新進度**：第一句先交代最近發生的程序或結果。
3. **保留關鍵事實**：優先保留以下資訊：
   - 法院或機關的最新動作
   - 開庭、裁定、判決、送達、補正、期限
   - 對造或我方的重要回應
   - 下一步與預計時程
4. **刪除次要細節**：避免冗長背景、重複敘述、法律分析、內部備忘、過度修飾。
5. **語氣專業、清楚、可直接寄出**：用正式但易懂的中文，避免艱澀術語；必要時可用括號簡短補充。
6. **不確定就保守表達**：若資訊不足，不要自行補寫；改用「目前」、「尚待」、「預計」等保守措辭。
7. **不要加入未提供的內容**：不得自行推測案件結果、責任歸屬、勝敗機率或法律意見。

# 產出步驟
1. 讀取使用者提供的案件最新進度與背景。
2. 找出最重要的 1 到 3 個事實，依重要性排序。
3. 將內容濃縮成 1 到 3 句話。
4. 檢查是否超過 3 句；若超過，合併或刪減次要資訊。
5. 確認文字適合直接發給當事人。

# 建議格式
- 第 1 句：最新進度
- 第 2 句：影響或期限
- 第 3 句：下一步或提醒

# 範例寫法風格
- 「本案法院已於近日完成開庭，並要求雙方於○月○日前補充書狀。」
- 「目前案件仍在審理中，下一次程序預計於○月進行。」
- 「我們會持續追蹤進度，若有新通知會立即向您更新。」

# 注意事項
- 若使用者要求加入超過 3 句的內容，仍須壓縮到 3 句內。
- 若使用者提供的是多段進度，請整合成一則通知，不要逐段照抄。
- 若資訊不足以形成完整通知，請先指出缺少哪些關鍵資訊，而不是編造內容。
