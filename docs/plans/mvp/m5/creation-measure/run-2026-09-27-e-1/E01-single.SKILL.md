# 房仲成交服務費計算

依照成交價計算單筆交易的服務費，規則如下：

- 成交價未滿 1000 萬元：服務費 = 成交價 × 1%
- 成交價 1000 萬元以上、未滿 3000 萬元：服務費 = 成交價 × 1.5%
- 成交價 3000 萬元以上：服務費 = 成交價 × 2%
- 同一筆交易只套用一個級距，不可累加各段
- 服務費無條件捨去到千元

## 計算步驟

1. 取得成交價。
2. 判斷成交價落在哪個級距：
   - 小於 10,000,000：使用 1%
   - 大於等於 10,000,000 且小於 30,000,000：使用 1.5%
   - 大於等於 30,000,000：使用 2%
3. 用成交價乘上對應費率。
4. 將結果無條件捨去到千元：
   - 先除以 1000
   - 取不大於該值的整數
   - 再乘回 1000
5. 回傳最終服務費。

## 輸出格式

回覆時請清楚列出：

- 成交價
- 適用費率
- 原始計算結果
- 捨去到千元後的服務費

## 注意事項

- 這個 Skill 只負責依規則計算，不負責法律或契約解釋。
- 若使用者提供的成交價不是數字，先請對方提供可計算的金額。
