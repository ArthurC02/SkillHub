# 寵物店到店洗澡預約申請審核

依下列規則逐一審核每隻寵物，並輸出每隻寵物的結果與費用。

## 審核規則

1. **缺少狂犬病疫苗接種紀錄：退件**
   - 只要申請資料沒有附上狂犬病疫苗接種紀錄，就直接退件。

2. **有咬人紀錄：退件**
   - 只要寵物有咬人紀錄，就退件。
   - 這條規則優先於費用計算；即使有疫苗紀錄也一樣退件。

3. **體重 25 公斤以上（含）的大型犬：加收大型犬清潔費**
   - 若寵物通過前述退件條件，且體重 **≥ 25 公斤**，則視為大型犬。
   - 費用為：**洗澡費 800 元 + 大型犬清潔費 300 元 = 1,100 元**。

4. **其餘通過的寵物：只收洗澡費**
   - 若寵物通過且體重未達 25 公斤，費用為 **800 元**。

## 審核步驟

對每隻寵物依序執行：

1. 檢查是否有狂犬病疫苗接種紀錄。
   - 沒有：標記為「退件」，原因寫「未附狂犬病疫苗接種紀錄」。
2. 若有疫苗紀錄，再檢查是否有咬人紀錄。
   - 有：標記為「退件」，原因寫「有咬人紀錄」。
3. 若未退件，再檢查體重。
   - 體重 ≥ 25 公斤：標記為「通過」，應收費用 1,100 元。
   - 體重 < 25 公斤：標記為「通過」，應收費用 800 元。

## 輸出格式

逐一列出每隻寵物，建議使用以下格式：

- 寵物名稱／編號：
  - 結果：通過 或 退件
  - 原因：
    - 通過時可寫「符合規則」
    - 退件時寫明退件原因
  - 應收費用：
    - 通過：800 元或 1,100 元
    - 退件：不收費

## 注意事項

- 每隻寵物都要單獨判定，不可互相影響。
- 退件原因以最先命中的退件條件為準；若同時缺少疫苗紀錄且有咬人紀錄，仍可只列出主要退件原因，或同時列出兩項原因，但結果都必須是退件。
- 只有「通過」的寵物才需要列出應收費用；若要完整呈現，也可在退件項目標示「不收費」。
