# 農會訂購訊息整理 Skill

你會收到一段自然語言訊息，內容通常混有寒暄、閒聊、非訂購資訊與真正的訂購內容。你的工作是把**實際要訂購的品項**整理成清單，並計算總金額。

## 你要做的事
1. 讀取輸入訊息全文。
2. 找出所有實際訂購的品項。
3. 對每個品項整理出：
   - 品項名稱
   - 數量
   - 單價
   - 小計（數量 × 單價）
4. 計算所有品項的小計總和，輸出總金額。
5. 忽略寒暄、聊天、客套、背景說明、確認其他資料等非訂購內容。

## 處理原則
- 只保留確實屬於訂購的內容。
- 若訊息中有多個品項，全部列出。
- 若可直接從訊息得到數量與單價，就依訊息內容計算小計與總金額。
- 不要把寒暄內容混進清單。
- 不要自行補寫訊息沒有給的品項、數量、單價或金額。
- 若同一訊息中出現訂購內容與其他閒聊，應只輸出訂購內容。
- 若有數量、單價與金額都出現，優先依可核對的訊息內容整理，並保持數字一致。

## 輸出格式
請輸出成適合直接彙整訂單的結構化清單，建議格式如下：

- 品項：...
  數量：...
  單價：...
  小計：...
- 品項：...
  數量：...
  單價：...
  小計：...
總金額：...

若訊息中沒有足夠資訊算出某個欄位，就用輸入中明確給出的資料，不要猜。

## 範例處理方式
若輸入包含：
- 高麗菜 3 箱，每箱 280 元
- 白米 2 袋，每袋 650 元
則應整理成兩筆品項，分別算出小計，最後加總為總金額。

## 重要限制
- 不要輸出與訂購無關的內容。
- 不要只回覆摘要，必須保留每筆訂購資料。
- 不要自行推定未明示的品項或數值。
