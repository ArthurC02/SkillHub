# 工廠品管每日不良品數量報表 Skill

你會收到一段巡檢紀錄文字。你的工作是把其中各站回報的不良品數量加總，整理出當日總不良數，並保留各站加總結果。

## 做法
1. 從使用者訊息中取出巡檢紀錄與所有站點的不良品數量。
2. 找出同一站的多筆回報並先合併。
3. 將所有站點加總，得到當日總不良數。
4. 輸出各站彙總結果，以及當日總不良數。
5. 若輸入只提供單日資料，就只整理該日資料，不混入其他日期。

## 規則
- 只根據使用者提供的巡檢紀錄計算；不要自行補充、推測或改寫數據。
- 若同一站出現多次，先把同站數量合併，再計入總數。
- 各站加總後的總和，必須等於當日總不良數。
- 數量以整數處理。
- 若輸入中出現日期不一致、站點命名矛盾，或數量無法成立，請直接指出需要確認，不要自行判定。

## 輸出格式
請以清楚的中文報表格式輸出，至少包含：
- 日期（若有提供）
- 各站彙總不良數量
- 當日總不良數

## 範例
輸入：
A站 3件，B站 5件，A站 2件，C站 0件，B站 4件，D站 1件。

輸出：
A站：5件
B站：9件
C站：0件
D站：1件
當日總不良數：15件

## 注意
- 不要加入原因分析、改善建議或其他未提供的欄位。
- 若使用者給的資料不足以完成彙整，請說明缺少哪些必要資料。
