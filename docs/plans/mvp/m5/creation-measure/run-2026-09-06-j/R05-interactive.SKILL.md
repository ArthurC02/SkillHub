# 一週花費整理與彙總

收到使用者提供的一週花費記錄後，在同一次回覆中完成明細整理、分類及加總。只處理目前訊息中的記錄，不聲稱已儲存資料，也不補造任何支出。

## 輸入要求

每筆記錄應至少包含：

- 日期
- 支出項目
- 金額

使用者通常也會說明幣別。若未說明幣別，仍完成整理與計算，並將幣別標示為「未指定」，不要為此追問。只有在訊息完全沒有花費記錄，或所有記錄都缺少日期、項目或金額而無法處理時，才簡短要求使用者提供可計算的記錄。

## 處理步驟

1. 從目前訊息逐筆擷取日期、項目與金額；不得新增、猜測或刪除支出。
2. 依日期由早到晚排序。同一天有多筆記錄時，保留其原始出現順序。
3. 根據日期算出星期，使用「星期一」至「星期日」標示。
4. 根據項目語義為每筆記錄指定一個類別：
   - **餐飲**：早餐、午餐、晚餐、飲料、咖啡、餐廳、外送及其他飲食支出。
   - **交通**：捷運、公車、火車、計程車、加油、停車及其他交通支出。
   - **日用品**：超市日用品、清潔用品、衛生用品及其他日常消耗品。
   - **娛樂**：電影票、遊戲、展演、休閒活動及其他娛樂支出。
   - **其他**：無法合理歸入以上類別的支出，例如影印費。
5. 若項目可能屬於多個類別，依項目中最明確的用途分類；仍無法判斷時歸為「其他」。直接採用此預設並完成結果，不要向使用者提問。
6. 分別加總每個實際出現的類別。金額計算必須使用原始數值，不得因顯示格式而改變數值。
7. 將所有支出金額相加，得到全週總額。
8. 核對全週總額是否等於所有類別合計之和。若不相等，重新檢查逐筆歸類與算術，修正後再輸出。

## 輸出格式

依序輸出以下內容：

### 一週花費明細

輸出 Markdown 表格，欄位固定為：

| 日期 | 星期 | 項目 | 金額 | 類別 |
|---|---|---|---:|---|

每筆輸入記錄各占一行，不合併同類項目。日期使用 `YYYY-MM-DD` 格式；若原始日期資訊不足以轉換，保留原始日期文字。金額以數字呈現，並統一使用使用者指定的幣別。

### 類別合計

另輸出一張 Markdown 表格：

| 類別 | 合計 |
|---|---:|

每個實際出現的類別各占一行。類別排列順序固定為「餐飲、交通、日用品、娛樂、其他」，未出現的類別不必列出。

### 全週總額

以獨立一行清楚寫出：`全週總額：金額 幣別`。

若幣別為新台幣，使用「元」呈現，例如「全週總額：1495 元」。最後確認明細筆數與輸入記錄筆數一致，且類別合計之和等於全週總額。
