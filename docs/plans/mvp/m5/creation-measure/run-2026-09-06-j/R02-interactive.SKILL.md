# 客戶名單 CSV 清理

收到使用者提供的 CSV 客戶名單後，在同一次回覆中完成解析、去重、缺漏標記、統計與 CSV 輸出，不要求使用者確認處理規則。

## 輸入要求

- 輸入必須包含可直接讀取的 CSV 內容。
- CSV 至少要有名稱完全相符的「客戶姓名」與「電話」欄。
- 將標題列之後的每一列視為一筆輸入資料；空白行不計入資料列。
- 依 CSV 規則解析引號包住的欄位；不可直接以每個逗號切割引號內的內容。
- 若使用者只描述 XLSX 檔案、只提到資料位置，或未提供可讀取的表格內容，請簡短要求其貼上資料或匯出為 CSV。若缺少必要欄位，指出缺少的欄位並要求提供包含該欄位的 CSV。除此之外，不追問即可合理處理的細節。

## 處理步驟

1. 記錄輸入資料列總數，不包含標題列與空白行。
2. 依原始出現順序逐列處理。保留每個原始欄位值供最後輸出；正規化值只用於判斷重複與電話是否缺漏。
3. 建立姓名比較值：移除「客戶姓名」值的首尾空白，不改變中間字元、大小寫或其他內容。
4. 建立電話比較值：從「電話」值中移除空格、左括號 `(`、右括號 `)` 與連字號 `-`，不做國碼轉換，也不增刪其他字元。
5. 以「姓名比較值＋電話比較值」的組合作為重複鍵。首次出現的鍵保留；之後出現的相同鍵視為重複並移除。即使其他欄位內容不同，也保留最先出現的一列。
6. 對每一列保留資料判定電話狀態：電話比較值為空字串時填入「缺少電話」，否則填入空字串。
7. 保持保留資料列的原始順序，並保持所有原始欄位的順序與值。在欄位末尾新增「電話狀態」。輸出的電話仍使用最先保留列中的原始格式，不以電話比較值取代。
8. 計算移除的重複資料列數、輸出資料列數，以及輸出中標記為「缺少電話」的資料列數。

## 輸出格式

只要輸入完整，就直接輸出以下兩部分，不以問題結尾。

### 處理摘要

用簡短文字明確列出：

- 輸入資料列數
- 移除的重複資料列數
- 輸出資料列數
- 缺少電話資料列數
- 本次採用的規則：姓名去除首尾空白、電話移除空格／括號／連字號，並以正規化後的姓名加電話判斷重複，保留最先出現的一列

### 清理後 CSV

- 將完整結果放在標記為 `csv` 的程式碼區塊中，方便複製並匯回 Excel。
- 第一列是標題列：所有原始欄位依原順序排列，最後加上「電話狀態」。
- 每列欄位數必須與標題列一致。電話狀態為空時仍保留最後的空欄位。
- 依標準 CSV 規則輸出：含逗號、雙引號或換行的欄位必須以雙引號包住，欄位內的雙引號以兩個雙引號表示。
- 不加入索引欄、說明欄或其他未要求的欄位。

## 限制

- 不直接讀取或寫入 XLSX。
- 不聲稱保留 Excel 公式、儲存格格式、合併儲存格或多工作表結構。
- 不使用外部工具；只處理對話中實際提供且可讀取的 CSV 內容。
