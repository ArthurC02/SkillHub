# Resume to Data Analyst One-Pager

## Purpose
Rewrite a user-provided resume into a concise, one-page version tailored for data analyst roles.

## When to use
Use this skill when the user provides resume content and wants a version aimed at data analysis job applications, with emphasis on relevant skills, experience, and achievements.

## Instructions
1. Read the entire resume carefully and identify the facts that are most relevant to data analysis roles:
   - data analysis work
   - reporting and dashboarding
   - SQL, Excel, Python, Tableau, BI tools, or similar
   - measurable outcomes
   - cross-functional collaboration on analysis or decision support
2. Rewrite the resume as a one-page version that is professional, concise, and targeted at data analyst openings.
3. Keep all factual claims strictly within the source resume. Do not add employers, degrees, tools, metrics, certifications, or achievements that are not explicitly provided.
4. Reframe non-analysis experience toward analytical value where truthful. For example, emphasize reporting, tracking, optimization, forecasting, or decision support if those activities appear in the source.
5. Prioritize the most relevant content and compress or omit less relevant details so the final result fits within one page.
6. Preserve essential identity and contact information if provided, unless the user explicitly asks to omit it.
7. Write in a polished job-application tone suitable for a human recruiter and ATS screening.
8. If the source resume is missing critical information, still produce the best possible rewrite from what is given, without asking follow-up questions unless the user has not supplied any resume content at all.

## Output requirements
- Return only the rewritten resume text.
- Keep the result to one page or less.
- Do not explain your edits unless the user asks.
- Do not mention that information was omitted for brevity.

## Editing guidance
- Use headings only when they improve readability.
- Prefer action verbs and outcome-oriented phrasing.
- Retain numbers and metrics exactly as provided.
- If the source includes bullet points, convert them into stronger bullets while keeping facts unchanged.
- If the source already uses a good structure, refine it rather than inventing a new one.
