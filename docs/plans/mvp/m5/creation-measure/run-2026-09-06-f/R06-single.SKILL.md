## 目標
將一份英文使用手冊完整翻譯為繁體中文，保留原意、結構、編號、警告與格式；專有名詞在第一次出現時以「中文（原文）」呈現，之後只用中文或依上下文一致處理。

## 處理原則
1. **完整翻譯，不摘要、不改寫用途**：所有段落、標題、列表、表格、註解、警告、按鈕名稱、介面文字、圖說與腳註都要翻譯。
2. **保留文件結構**：維持原本的章節順序、標題層級、編號、項目符號、表格欄位與換行邏輯。
3. **專有名詞首次附原文**：
   - 產品名、功能名、公司名、技術名、介面元件、縮寫、法規名等，第一次出現時寫成「繁中譯名（原文）」。
   - 若原文本身是縮寫，第一次可寫成「中文全名（縮寫）」或「中文譯名（原文）」；之後保持一致。
4. **術語一致**：同一術語在全文使用同一譯法；若原文有多種寫法，先統一再翻譯。
5. **保留不可翻譯內容**：
   - 程式碼、命令列指令、變數名、檔名、路徑、URL、電子郵件、序號、型號、API 名稱、按鍵快捷鍵通常保留原樣。
   - 若需要說明，可在旁邊加中文解釋，但不要改動原始字串。
6. **數字與單位**：數字、版本號、日期、時間、單位、度量值照原文保留格式；必要時可補上中文單位名稱，但不要改變數值。
7. **警告與注意事項**：保留原本的語氣強度，像 WARNING / CAUTION / NOTE / IMPORTANT 要對應翻譯並維持醒目。
8. **圖表與截圖說明**：若文字提到圖號、按鈕、選單或畫面元素，翻譯其說明文字，但保留圖號與介面識別名稱的一致性。

## 翻譯流程
1. 先通讀整份手冊，辨識：
   - 文件結構
   - 重複術語
   - 專有名詞與縮寫
   - 不應翻譯的字串
2. 建立一致的譯名：
   - 先決定核心術語的中文譯法。
   - 若同一名詞在不同章節出現，沿用同一譯法。
3. 逐段翻譯：
   - 以自然、正式、清楚的繁體中文表達。
   - 避免逐字硬翻；但不得遺漏資訊。
4. 首次出現標註原文：
   - 在第一次出現的專有名詞後加上原文。
   - 若同一頁或同一段落重複出現，不必每次都附原文。
5. 最後檢查：
   - 是否有漏譯段落、表格欄位或註解。
   - 是否維持原始順序與格式。
   - 是否所有專有名詞首次出現都有原文。

## 輸出要求
- 輸出為完整繁體中文手冊內容。
- 保留原文件的章節與排版邏輯。
- 不要加入與原文無關的說明、註解或前言。
- 若遇到無法判讀的字句、掃描瑕疵或缺字，先依上下文做最保守翻譯，必要時以「[不清楚]」標示，避免自行補寫不存在的內容。
