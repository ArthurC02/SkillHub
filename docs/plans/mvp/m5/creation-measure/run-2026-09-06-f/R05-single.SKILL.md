# 目的
將一週內的每日花費整理成清楚的表格，為每筆支出標示類別，並在週末計算各類別合計。

# 適用時機
當使用者提供一週的花費明細，要求你：
- 整理成表格
- 為每筆支出加上類別
- 在週末做分類加總

# 處理流程
1. **先確認資料完整性**
   - 檢查是否有日期、金額、用途/品項。
   - 若缺少類別，根據用途推定最合理的類別；若無法判定，標為「其他」。
   - 若缺少日期，先依使用者提供的順序整理，並註明「日期未提供」。

2. **建立每日明細表**
   - 以一週為單位分組。
   - 每筆支出至少包含以下欄位：
     - 日期
     - 項目/用途
     - 類別
     - 金額
   - 若同一天有多筆支出，逐筆列出，不要合併，除非使用者明確要求合併。

3. **統一類別名稱**
   - 使用一致且簡潔的類別名稱，例如：
     - 餐飲
     - 交通
     - 生活用品
     - 娛樂
     - 住宿
     - 醫療
     - 學習
     - 其他
   - 若使用者已有指定類別，優先沿用使用者的分類。

4. **計算週末各類別合計**
   - 將整週所有支出依類別加總。
   - 若同一類別跨多天出現，合併計算。
   - 另外可計算整週總支出，若資料足夠也可計算每日小計。

5. **輸出格式**
   - 先輸出「每日花費明細表」。
   - 再輸出「週末類別合計表」。
   - 若需要，可附上「整週總計」。

# 建議表格格式
## 每日花費明細表
| 日期 | 項目/用途 | 類別 | 金額 |
|---|---|---:|---:|
| 週一 | 早餐 | 餐飲 | 50 |
| 週一 | 捷運 | 交通 | 30 |

## 週末類別合計表
| 類別 | 合計 |
|---|---:|
| 餐飲 | 350 |
| 交通 | 120 |
| 其他 | 80 |

# 計算規則
- 金額以數字加總，不要把貨幣符號算進去。
- 若有退款、折扣或負數金額，照實納入加總。
- 若同一筆支出可能屬於多個類別，依使用者最可能的主要用途歸類到單一類別。
- 若資料有歧義，先保留原始項目名稱，並在類別欄標示最保守的分類。

# 回覆原則
- 保持表格整齊、欄位一致。
- 不要省略任何使用者提供的支出項目。
- 若資料不足以完成分類，明確指出缺少哪些資訊，並先用「其他」暫代。
