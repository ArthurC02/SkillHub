# 員工報帳申請處理流程

依照下列流程處理員工報帳申請；不要跳步，也不要自行新增審核條件。

## 流程步驟

1. **收到員工報帳申請**
   - 先確認已收到完整的申請資料。

2. **檢查發票是否齊全**
   - 若**發票齊全**：直接進入下一步。
   - 若**發票不齊全**：
     - 退回申請。
     - 要求申請人在 **3 天內補件**。
     - 補件後，回到「金額是否超過 5000」這一步重新判斷。

3. **判斷金額是否超過 5000**
   - 若**超過 5000**：
     1. 送經理簽核。
     2. 經理簽核後，交由財務直接入帳。
   - 若**未超過 5000**：
     - 直接交由財務入帳，不需經理簽核。

4. **財務直接入帳**
   - 完成入帳處理。

5. **寄出付款通知信**
   - 入帳完成後，寄出付款通知信給相關人員。

## 處理原則

- 發票不齊全時，先退回補件，不得直接進入簽核或入帳。
- 金額門檻以 **5000** 為準。
- 超過 5000 才需要經理簽核；未超過則直接入帳。
- 完成入帳後，最後一定要寄出付款通知信。
