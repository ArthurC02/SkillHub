# Excel 客戶名單清理

此技能用於處理 Excel 中的客戶名單，目標是：
1. 去除重複資料。
2. 標記缺少電話的列。

## 執行步驟

1. **確認資料範圍與欄位**
   - 找出客戶名單所在的工作表。
   - 確認哪一欄是用來判斷重複的主鍵，通常是「客戶名稱」、「電話」、「Email」或其組合。
   - 確認電話欄位名稱，因為後續要檢查是否缺少電話。

2. **先備份原始資料**
   - 在原工作表複製一份，或另存新檔。
   - 保留原始 200 筆資料不變，以便需要回復。

3. **去除重複資料**
   - 依照資料內容選擇重複判斷方式：
     - 若有明確唯一識別欄位，使用該欄位判斷重複。
     - 若沒有唯一欄位，使用最能代表同一客戶的欄位組合判斷，例如「客戶名稱 + 電話」或「客戶名稱 + Email」。
   - 移除重複列時，保留第一筆出現的資料，除非資料規則要求保留最新一筆。
   - 去重後，確認剩餘筆數是否合理，並檢查是否有誤刪。

4. **標記缺少電話的列**
   - 在電話欄位旁新增一欄，例如「電話狀態」或「缺少電話」。
   - 對每一列檢查電話欄位：
     - 若電話欄為空白、只有空格、或是缺值標記，則標記為「缺少電話」。
     - 若有電話，則標記為「正常」。
   - 若需要，也可用醒目底色標示缺少電話的列，方便人工檢視。

5. **檢查結果**
   - 確認去重後資料沒有遺漏必要欄位。
   - 確認所有缺少電話的列都已被標記。
   - 如有需要，統計：
     - 原始筆數
     - 去重後筆數
     - 缺少電話筆數

6. **輸出整理後的檔案**
   - 將清理後的名單另存為新檔。
   - 保留原始檔案不變。

## 注意事項

- 如果「重複」的定義不明確，先詢問使用者要以哪些欄位判斷重複。
- 如果電話欄位名稱不一致，先找出實際使用的欄位再處理。
- 若資料中有合併儲存格、公式或篩選狀態，先確認不會影響去重與標記結果。
