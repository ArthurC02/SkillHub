# 目的

收到客戶退貨申請時，根據使用者提供的購買日期與申請日期，判斷是否在購買後 7 天內，並輸出一封可直接使用的標準回覆信件。

# 使用時機

在客服、電商營運或信件草擬場景中，當輸入是一筆退貨申請資料，且需要立即產生正式回覆時使用。

# 輸入

使用者會提供一筆退貨申請資料，至少包含：

- 購買日期
- 申請日期
- 退貨申請內容

若輸入內容中有訂單編號、客戶名稱、商品名稱或其他可直接用於信件的資訊，也一併納入信件。

# 工作流程

1. 讀取輸入中的購買日期與申請日期。
2. 計算申請日期是否落在購買日期後 7 天內。
   - 以日曆天計算。
   - 購買日當天不算入 7 天內的判定基準，依輸入日期直接比較兩者相差天數。
3. 依判定結果套用對應的標準回覆內容。
4. 只輸出最終信件，不輸出計算過程、分析或規則說明。

# 信件規則

- 內容必須是正式、清楚、可直接寄出的商務信件。
- 明確寫出是否屬於 7 天內申請。
- 若在 7 天內，信件需用肯定語氣說明符合 7 天內退貨申請的處理方式。
- 若超過 7 天，信件需用婉拒或不符合 7 天內規則的語氣說明處理方式。
- 以使用者提供的資訊為準，不自行補充未提供的例外條件、法規或公司政策。

# 輸出要求

- 只輸出一封信件。
- 不要加上條列分析、解題步驟、備註或額外說明。
- 若輸入中有客戶稱呼或訂單資訊，優先自然地帶入信件正文。
- 若未提供稱呼，使用中性且禮貌的開場。

# 寫作方式

- 先寫出結論，再補上簡短處理說明。
- 保持專業、禮貌、簡潔。
- 避免過度冗長。

# 範例結構

主旨：退貨申請回覆

您好，

感謝您的來信。經確認，您的退貨申請屬於購買後 7 天內提出，我們將依標準流程為您處理……

或

您好，

感謝您的來信。經確認，您的退貨申請已超過購買後 7 天內的申請期限，因此……

# 注意事項

- 不要捏造未出現在輸入中的訂單細節。
- 不要輸出多封信件。
- 不要加入分析、計算或內部判斷說明。
