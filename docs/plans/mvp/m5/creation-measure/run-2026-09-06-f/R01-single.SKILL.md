# 目的
將會議逐字稿轉成結構化待辦清單，確保每一條都包含：
- 具體行動內容
- 負責人
- 期限

# 處理原則
1. 只根據逐字稿內容整理，不要自行補充未提及的事實。
2. 若逐字稿中有明確的行動項，優先抽出為待辦。
3. 若同一件事有多個步驟，拆成可執行的獨立待辦，但避免過度切碎。
4. 若負責人或期限未明確出現，標記為「未指明」，不要猜測。
5. 若期限是相對時間（例如「下週五前」），保留原意並盡量轉寫成清楚格式。
6. 若同一句話同時包含決策與待辦，待辦只保留可執行部分。
7. 若內容只是討論、背景、意見交換，且沒有後續動作，則不要列入待辦。

# 整理步驟
1. 通讀逐字稿，找出所有明確的行動、交付、跟進、確認、修正、回覆、提供資料等語句。
2. 對每個行動項，抽取：
   - 待辦內容：用簡短動詞開頭，寫成可執行句。
   - 負責人：逐字稿中明示的人名、職稱或團隊。
   - 期限：逐字稿中明示的日期、時間、相對期限或會議後要求。
3. 若同一待辦有多個負責人，優先保留主要負責人；必要時可在內容中補充協作對象。
4. 若期限只說「盡快」「稍後」「再確認」，保留原詞並標記為未具體日期。
5. 若逐字稿中有明確的優先順序，按優先順序排列待辦。

# 輸出格式
輸出為條列式待辦清單，每條固定包含以下欄位：
- 待辦：
- 負責人：
- 期限：

範例格式：
- 待辦：整理報價單並寄給客戶
  負責人：王小明
  期限：2026-09-10

# 品質檢查
在輸出前確認：
- 每條都有負責人與期限；若缺失，明確寫「未指明」。
- 沒有把背景討論誤寫成待辦。
- 沒有加入逐字稿以外的新資訊。
- 用詞簡潔、可執行、可追蹤。
