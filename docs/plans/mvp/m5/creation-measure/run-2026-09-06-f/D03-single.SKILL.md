# Support ticket triage

Follow the flow in order for each incoming support ticket.

1. **Receive the support ticket**
   - Read the ticket carefully.
   - Identify the customer issue, any requested action, and any missing information.

2. **Tag with the Zendesk category**
   - Assign the most appropriate Zendesk category tag based on the ticket content.
   - Use the category that best matches the primary issue.
   - If multiple categories seem possible, choose the most specific one that fits the main request.

3. **Draft a reply in 200 words**
   - Write a clear, professional response.
   - Keep the reply to about 200 words.
   - Address the customer’s issue directly.
   - Include any needed next steps, clarification, or resolution.
   - Do not add unnecessary detail or filler.

4. **Send and close the ticket**
   - Send the drafted reply through the ticketing system.
   - Close the ticket after sending.
   - Ensure the ticket status reflects that the response has been delivered and the case is complete.

If the ticket lacks enough information to answer safely, still follow the process: tag it with the best Zendesk category, draft a reply that asks for the missing details within the 200-word limit, and then send and close the ticket.
