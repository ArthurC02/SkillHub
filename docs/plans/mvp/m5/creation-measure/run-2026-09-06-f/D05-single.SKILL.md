# 新人到職流程

依照流程圖，按順序執行以下步驟：

1. **收到新人到職通知**
   - 確認已收到新人報到或到職通知。
   - 取得新人姓名、到職日、部門、職稱與聯絡方式。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱可正常登入，並記錄帳號資訊。

3. **加入 Slack 頻道**
   - 將新人加入必要的 Slack 頻道。
   - 至少包含部門、團隊與新人成員需要的公告或協作頻道。

4. **準備筆電與門禁卡**
   - 準備新人報到所需的筆電。
   - 準備門禁卡或其他出入權限所需物品。
   - 確認設備與權限可在到職前或到職日交付。

5. **安排第一週訓練**
   - 規劃新人第一週的訓練內容與時程。
   - 包含必要的系統介紹、工作流程、團隊認識與基礎任務。

6. **指派導師**
   - 指派一位導師或 buddy 協助新人適應。
   - 明確告知導師支援範圍與聯絡方式。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備回饋問題，確認適應狀況、訓練進度與需要協助的事項。

8. **記錄到人資系統**
   - 將以上完成事項與關鍵資訊記錄到人資系統。
   - 確保資料完整、可追蹤，並作為後續管理依據。

## 執行原則
- 嚴格依照流程順序處理，不要跳步。
- 每一步完成後再進入下一步。
- 若某一步缺少必要資訊，先向相關人員確認後再繼續。
- 若無法實際執行某項動作，至少要整理出待辦清單與所需資訊，交由有權限的人完成。
