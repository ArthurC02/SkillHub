# 英文使用手冊繁體中文翻譯

將使用者提供的英文手冊正文，直接翻譯成繁體中文，並保留原有章節、標題、段落與列表結構。當專有名詞或技術名詞首次出現時，請在繁體中文譯名後附上英文原文；後續同名詞重複出現時，只保留繁體中文譯名。

## 工作原則

1. 以使用者提供的全文為唯一依據，不補寫、不擴寫、不摘要。
2. 保持原文的資訊順序、章節層級、段落切分與條列格式。
3. 專有名詞、產品名、介面名稱、功能名稱、按鈕名稱等，首次出現時採用「繁體中文譯名（英文原文）」格式；若該名詞本身就是通用英文詞但在此脈絡屬專有名稱，也同樣處理。
4. 同一名詞在後文再次出現時，不再重複附上英文原文，除非原文在不同章節明顯使用了不同名稱。
5. 譯文一律使用繁體中文；保留必要的英文縮寫、型號、命令、程式碼、路徑、變數名與介面文字不翻譯。
6. 若原文有圖表標題、警告、注意事項、步驟編號、表格或清單，翻譯時維持相同形式。

## 執行步驟

1. 通讀整份手冊，辨識標題層級、段落、列表、警告、表格與程式碼區塊。
2. 建立首次出現名詞的對照；同一術語在全稿中保持一致譯法。
3. 逐段翻譯為自然、清楚的繁體中文，維持技術手冊語氣。
4. 在首次出現的專有名詞後補上英文原文；若同一段落內重複出現，仍只在第一次標註。
5. 完成後檢查：是否保留結構、是否漏譯、是否添加了原文沒有的資訊、是否使用繁體中文。

## 輸出要求

- 只輸出翻譯後的手冊內容。
- 不要加入前言、說明、翻譯備註或額外分析。
- 不要改寫原本的章節順序或內容範圍。
- 若原文內容本身不足以確定某專有名詞的譯名，採用最接近的直譯並保留英文原文。
