# Shopify 訂單匯入流程

當收到客戶 Excel 訂單、需要轉成 CSV、檢查缺漏欄位，並準備匯入 Shopify 後台時，使用此 Skill。

## 目標

依照輸入的 Excel 訂單內容：
1. 整理出可匯入的 CSV 欄位。
2. 檢查是否有缺漏欄位。
3. 產出可執行的 Shopify 匯入步驟。
4. 生成可回覆客戶「已入單」的完成訊息。

## 執行步驟

### 1. 讀取訂單資料
先確認輸入中有哪些欄位與列資料。

### 2. 轉成 CSV 結構
將 Excel 欄位對應成 CSV 欄位。若輸入已提供欄位順序，直接採用；若未提供，依輸入欄位名稱建立一致的 CSV 欄位名。

### 3. 檢查缺漏欄位
檢查每一列是否有空白值，特別是輸入中明確指定為必填或用於匯入的欄位。
- 若有缺漏，清楚列出缺漏在哪一列、哪一欄。
- 若未提供必填規則，依輸入中的匯入需求與常見訂單資料欄位，優先檢查訂單編號、客戶姓名、Email、商品 SKU、數量、收件地址。

### 4. 產出 CSV 對應結果
輸出一個可直接作為 CSV 的欄位對應表或 CSV 內容草稿。
- 保持欄位名稱一致。
- 若輸入提供欄位順序，照順序輸出。
- 不自行新增未在輸入中出現的欄位。

### 5. 匯入 Shopify
根據輸入中的 Shopify 匯入需求，整理成執行步驟。
- 若輸入已說明使用 CSV 匯入功能，就寫成使用 Shopify 後台的 CSV 匯入流程。
- 若輸入未提供更細節的欄位對應，標示為待確認，但仍保留可執行的主流程。

### 6. 回覆客戶已入單
產出一段可直接使用的完成回覆，內容應包含：
- 已收到並整理訂單。
- 已完成 CSV 檢查與匯入準備。
- 已入單完成。

## 輸出格式
請依下列順序輸出：
1. 訂單欄位整理
2. 缺漏欄位檢查結果
3. CSV 對應或草稿
4. Shopify 匯入步驟
5. 客戶完成回覆

## 行為準則
- 只根據輸入內容與已確認需求工作，不要自行補齊流程圖未提供的分支或例外流程。
- 若欄位對應規則未提供，明確標示為待確認，不要假設。
- 不要把流程寫成抽象概念；要寫成可直接執行的操作內容。
- 保持輸出簡潔、可直接拿去使用。
