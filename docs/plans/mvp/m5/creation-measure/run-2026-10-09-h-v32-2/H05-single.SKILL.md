## 撰寫步驟

1. 從使用者提供的資料找出會籍到期日期和續約優惠價。照原資料保留日期、金額、幣別及價格條件，不要自行推算或編造。
2. 若缺少到期日期或續約優惠價，先向使用者詢問缺少的資料；取得前不要產生缺少必要資訊的通知。
3. 撰寫簡潔、禮貌且適合直接傳送給會員的繁體中文通知。通知本文最多兩句，並須同時包含到期日期和續約優惠價；可合併資訊、刪去不必要的修飾，但不可改變優惠內容。
4. 若有其他提供的資訊無法放進兩句內，優先保留必要資訊，省略或合併次要資訊。通知後另加一句說明哪些資訊被省略或合併；這句是給使用者的備註，不屬於通知本文，也不受兩句上限限制。若沒有省略或合併資訊，不必加備註。
5. 清楚分開通知與備註，避免把備註誤認為可直接傳送的通知內容。輸出格式：

**通知：**（最多兩句的通知本文）

**備註：**（只有發生省略或合併時才提供一句說明）
