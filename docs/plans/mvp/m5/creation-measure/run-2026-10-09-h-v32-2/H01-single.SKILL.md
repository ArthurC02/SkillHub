## 計費步驟

1. 確認單次停車的實際時長。可使用小時或分鐘；若以其他時間單位提供，先換算成小時。若時長缺漏、無法判讀或為負數，先詢問或釐清，不要猜測。
2. 將不足一小時的部分無條件進位為整數小時：`計費時數 = ceil(實際時數)`。例如 1.2 小時計為 2 小時；恰好 1 小時仍計為 1 小時。若時間以分鐘提供，按總分鐘數除以 60 後進位。
3. 按進位後的計費時數 `h` 計算未封頂費用：
   - `h ≤ 1`：50 元。
   - `1 < h ≤ 3`：120 元。
   - `h > 3`：`120 + 40 × (h − 3)` 元。
4. 單次停車費用不得超過 300 元：`應收費用 = min(未封頂費用, 300)`。
5. 回覆實際時長、進位後時數、計算方式及應收金額。金額以整數元呈現。

## 檢查例

- 1.2 小時 → 進位為 2 小時 → 120 元。
- 3 小時 → 120 元；3.1 小時 → 進位為 4 小時 → 160 元。
- 8 小時 → 未封頂為 320 元，套用上限後收 300 元。

不得將不足一小時的部分按比例收費，也不得在套用上限前先截掉超時部分。
