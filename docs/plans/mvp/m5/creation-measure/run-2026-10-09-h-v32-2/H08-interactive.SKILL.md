# 二手服飾收購驗收清單

把使用者提供的收購紀錄整理為清單，並以腳本計算金額。保留每筆紀錄，不合併相同品項；不加入稅金、折扣或其他費用，也不推測未提供的價格。

1. 從輸入整理每筆紀錄的日期、品項、數量及收購單價。保留使用者提供的事實與原有順序；若缺少其中一項，該欄標示「未提供」。若沒有任何紀錄，先輸出一筆帶有「【未提供】」欄位的可用表格範本，不要編造資料。
2. 若同一筆紀錄有明確互相矛盾的值（包括後文改動前文的數值），逐一列出需要使用者確認的值，不要自行選一個；把受影響的欄位標為「需確認」，且不計算依賴該值的金額或合計。不要把不同筆交易的不同價格當成矛盾。
3. 對可辨識的紀錄，依序用 `日期|品項|數量|單價` 傳入腳本；缺少的欄位留空。從含有此 SKILL.md 的目錄執行，例如：
   ```sh
   python scripts/calculate_totals.py --record '2026-10-01|牛仔外套|2|150' --record '2026-10-02|襯衫|4|50'
   ```
   對每筆輸入重複加入 `--record`。不含貨幣符號或千分位的單價最適合傳入；腳本也接受 `NT$` 前綴及千分位逗號。將腳本印出的結果用於清單，不自行另算。
4. 依腳本結果整理繁體中文表格，欄位為日期、品項、數量、收購單價、逐筆金額。按日期由早到晚排列，同一日期維持輸入順序。單價與金額以 `NT$` 表示；逐筆金額依數量乘單價。
5. 列出每個日期的小計及總金額。若輸入有任何缺漏欄位，腳本不會提供小計或總金額；不要補算或把不完整資料當成零，並在對應欄位標示「未提供」。若腳本以錯誤碼 2 結束，原樣呈現它指出的無法使用值，請使用者確認該值；不輸出依賴該值的金額或合計。若某欄因矛盾而需確認，依同樣方式不輸出受影響的金額或合計。
6. 直接在本次回覆交付完整清單；需要確認的值以陳述方式逐一列明，不要只提出問題，也不要把任何已提供事實標成待補。
