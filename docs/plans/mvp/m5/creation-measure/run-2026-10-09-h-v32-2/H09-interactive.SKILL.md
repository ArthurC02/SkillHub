## 步驟

1. 讀取使用者提供的歡送會名稱、活動日期、集合時間與地點。辨認每個欄位的值，保留原有文字、數字、標點與格式；不自行修正或補充事實。
2. 對照輸入資料：
   - 缺少欄位時，採用「未提供」作為該欄內容，並在成品中標明。
   - 同一欄出現互相矛盾的值時，逐字列出所有衝突值，標明「資料互相矛盾，請主辦人確認」，不選擇或推算其中一個值。其他一致且有效的欄位照常使用。
   - 不合理或無法成立的值（例如不存在的日期）原樣指出，標明「請主辦人確認」，不將其當作正確資料使用。只詢問需要確認的值，不詢問其他內容。
3. 寫一篇繁體中文邀請文，語氣溫馨、感恩。清楚呈現四個欄位，依序標為「歡送會名稱：」「活動日期：」「集合時間：」「地點：」。逐字保留所有可確認的輸入值，不省略；缺少的欄位寫「未提供」。不要添加資料未提供的活動事實。需要確認的值在對應欄位列出原值並附上確認提醒。
4. 將完整邀請文寫入 `invitation.txt`：

   ```sh
   cat > invitation.txt <<'EOF'
   （在此寫入本次實際產生的完整邀請文）
   EOF
   ```

5. 從含有本技能 `SKILL.md` 的目錄執行下列命令，檢查四個欄位標籤都出現在檔案中：

   ```sh
   python scripts/check_output.py --require "歡送會名稱：" --require "活動日期：" --require "集合時間：" --require "地點："
   ```

   若未印出 `OK`，修正 `invitation.txt` 後重新執行檢查。另逐字核對檔案中的每個已提供值與輸入一致；不得用檢查通過代替事實核對。
6. 在回覆中只貼上 `invitation.txt` 的內容，不加前言或檢查說明。若本次流程涉及寄出邀請文，另以一行結尾：「寄出邀請文：無法在此代為寄出，請由使用者或主辦人自行寄送。」
