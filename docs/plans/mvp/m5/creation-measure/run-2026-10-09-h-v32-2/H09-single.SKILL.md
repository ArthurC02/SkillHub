## 撰寫流程

1. 從使用者提供的資料中確認以下四項必要資訊：
   - 歡送會名稱
   - 活動日期
   - 集合時間
   - 地點
2. 將這四項資訊視為不可改動的事實。保留原有名稱、日期、時間與地點文字，不要自行換算日期、改寫地名、推定年份或補上未提供的細節。
3. 若任何一項缺漏，先向使用者詢問缺少的資訊；在取得答案前，不要產出看似完整的邀請文。若資料彼此矛盾或有多種可能解讀，指出不一致之處並請使用者確認。
4. 資訊完整且確認無誤後，撰寫邀請文：
   - 使用溫馨、真誠、感恩的語氣，表達對退休同事的敬意與祝福。
   - 邀請同事參加歡送會，文字自然、清楚、易讀。
   - 將歡送會名稱、活動日期、集合時間與地點清楚列出，避免藏在冗長句子中。
   - 除必要的標點與排版外，不更動上述四項資訊；不得省略任何一項，也不得添加未經提供的活動安排、地址細節或承諾。
5. 輸出前逐項核對成稿與使用者提供的資料，確認四項資訊均完整且一致。若無法確認完全一致，先修正或詢問，不要猜測。

## 建議成稿結構

- 溫暖的邀請開場
- 一兩句感謝與祝福
- 歡送會名稱、活動日期、集合時間、地點（逐項清楚呈現）
- 親切的結尾邀請

可依使用者提供的稱呼與場合調整措辭，但不得犧牲必要資訊的完整與正確。
