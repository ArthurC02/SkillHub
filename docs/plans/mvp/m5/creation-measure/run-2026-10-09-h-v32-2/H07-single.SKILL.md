## 目標與限制

根據屋主提供的資料，整理出清楚、可核對的裝潢工程報價提案書，並準備與師傅確認丈量時間及向建材供應商訂購所需的聯絡資訊、話術與核對清單。

不得宣稱已打電話、已確認丈量、已登入系統或已下單。若沒有提供可用且獲授權的通話或供應商系統工具，就只能準備資料與步驟，請使用者自行完成外部操作。不得自行編造尺寸、數量、單價、供應商報價、庫存、工期或已確認的安排。

## 步驟

1. **整理屋主需求**
   - 摘錄案場地址或區域、空間類型、屋主希望改善的問題、預計施工時間、預算範圍及聯絡方式。
   - 依空間與工種整理需求，例如拆除、泥作、水電、木作、油漆、地板、廚具、衛浴、門窗、清運及保護工程。只列出屋主提及或資料可支持的項目。
   - 記錄每項工程已知的規格、尺寸、數量、材料品牌／型號、顏色與施工方式。未知或矛盾之處列為「待確認」，不要自行補齊。

2. **盤點估價所需資料**
   - 檢查是否具備現況照片或圖面、各區域尺寸、材料規格、工程數量、搬運與施工限制、社區施工規範，以及清運或保護需求。
   - 若缺少會影響價格的資料，先向屋主提出精簡、具體的問題；優先詢問會改變工程範圍、數量或材料等級的項目。
   - 無法在未丈量或未取得供應商報價時確認的金額，標為「待現場丈量估價」或「待供應商確認」，不可呈現為已確認價格。

3. **整理丈量需求與聯絡話術**
   - 彙整師傅丈量前需要知道的地址、聯絡人、案場出入方式、要丈量的區域、現況照片／圖面及可配合時段。
   - 提供可直接使用的電話或訊息草稿，例如：
     > 您好，我是＿＿＿，想請您協助＿＿＿（地址／案場）的＿＿＿工程現場丈量。屋主希望處理的範圍是＿＿＿。目前可配合的時段為＿＿＿或＿＿＿，想請問您哪個時間方便到場？也請告知丈量前需要準備的資料，以及是否有丈量費用。謝謝。
   - 清楚標示「尚待使用者聯絡確認」。取得師傅回覆後，才可將日期、時間、到場人員及任何費用記錄為已確認；未取得回覆不得推定已排定。

4. **編製報價提案書**
   - 用繁體中文，以便屋主閱讀的格式呈現。建議包含：提案名稱、案場與日期、需求摘要、工程範圍、分項報價、估價依據、預估工期、付款條件、報價有效期限、保固或售後條件、排除項目、待確認事項及下一步。
   - 分項表格至少包含「工種／項目、施工內容與規格、單位、數量、單價、小計、備註」。只在資料足夠且有可信價格依據時填入數量與金額；否則填「待丈量」或「待報價」。
   - 清楚區分已知事實、估算假設與尚未確認事項。若提出假設，逐條標示，並說明確認後可能調整價格或工期。
   - 只有在單價與數量皆有依據時才計算小計與總價；列明稅金、運費、清運費等是否包含。不可默認含稅或把未確認費用算成確定總價。
   - 明確列出不包含的工程、可能追加費用的條件、材料替代須經屋主同意，以及施工前需由屋主確認的事項。
   - 將文件標示為「提案草稿」或「初步估價」，直到丈量、規格及價格均確認；不可將草稿描述成正式承諾或已核准報價。

5. **準備建材訂購資料**
   - 依屋主指定內容整理採購清單：供應商、品名、品牌／型號、規格、顏色、數量、計量單位、單價與報價來源、庫存狀態、交期、運費、送貨地址、收貨人與聯絡電話。
   - 對數量、規格、顏色、替代品、總價、付款方式或送貨時間有任何缺漏時，先列出待確認問題，不要猜測或代選。
   - 提交訂單前提供逐項核對清單，請使用者確認材料、數量、總價、送貨資訊與付款責任。未獲明確授權及可用的系統存取方式時，不登入、不操作帳號、不承諾庫存，也不提交訂單。
   - 提供可由使用者複製到供應商系統的訂單草稿，並標明「未送出，待使用者登入核對及提交」。若使用者回報已下單，再協助整理訂單編號、確認內容與預計到貨日；不可自行聲稱已完成採購。

6. **交付與指出下一步**
   - 交付報價提案草稿、待確認資料清單、丈量聯絡草稿及建材採購草稿。
   - 將後續事項分成「屋主需補資料」「使用者需聯絡師傅」「使用者需登入供應商系統確認／下單」及「取得丈量與供應商報價後需更新的金額」。
   - 若使用者要求立即完成通話或系統下單，明確說明目前無法代為執行，並提供可直接照做的話術、資料與核對步驟。
