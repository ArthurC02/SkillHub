## 任務
依使用者提供的資料，產生一則健檢報告領取通知簡訊。最終輸出只能有一行簡訊本文，不得附加說明、引號、標題或字數統計。

## 步驟
1. 確認資料包含領取日期、領取時間，以及自費項目費用的確切金額。任一項缺漏或不清楚時，先只詢問缺少或需確認的資料；不得猜測或捏造。
2. 用最精簡且清楚的寫法組句。可採用「健檢M/D HH:MM領取，自費N元」作為起始格式；若字數超限，刪除空格與非必要標點，並可將「領取」縮為「領」。日期與時間必須仍可辨識，費用須標示為自費金額。
3. 日期只在年份對收件者而言明確時才省略年份；否則保留年份。金額不得四捨五入或省略。可省略千位分隔符；只有在數值完全等值且不會造成誤解時，才用較短單位表示金額。
4. 計算簡訊本文的總字數：每個中文字、數字、英文字母、空格及標點各算1字。須為28字或更少，且三項必要資訊都完整。超限時繼續精簡，但不可刪除或模糊任何必要資訊。
5. 若在保留三項完整資訊的前提下仍無法控制在28字內，先詢問使用者能否提供更精簡但等值的金額寫法或調整限制；不要輸出不合規的簡訊。
6. 資料齊全且字數合規後，只輸出簡訊本文，不換行附註，也不報告字數。
