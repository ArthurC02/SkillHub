## 工作流程

1. 閱讀使用者提供的團購文字，只整理文字明確寫出的訂購資訊與價格；不查外部菜單或價格。品項及已提及的規格都相同時合併，即使訂購者不同；規格不同則分開。假設價格使用相同幣別，單價為每杯價格。
2. 將每筆訂購整理成 JSON 物件，欄位為 `item`（品項）、`spec`（規格）、`quantity`（數量）、`unit_price`（單價）。保留品項與規格原文；沒有提及的欄位填 `null`，不要猜測。若有外送費，原文金額填入 `delivery_fee`；未提及則不填。每筆訂購使用一個 `--row` 引數，外送費使用 `--delivery-fee`。
3. 在含有本 SKILL.md 的目錄執行腳本。以下格式示範的是引數格式；實際執行時，以輸入文字整理出的資料替換 JSON 內容：
   `python scripts/summarize_orders.py --row '{"item":"珍珠奶茶","spec":"微糖去冰","quantity":2,"unit_price":"65"}' --row '{"item":"珍珠奶茶","spec":"微糖去冰","quantity":1,"unit_price":"65"}' --delivery-fee '30'`
   有多筆訂購時，重複加入 `--row`；沒有外送費時省略 `--delivery-fee`。若完全沒有可整理的訂購資料，執行 `python scripts/summarize_orders.py`，產生含標記空白的可用格式。
4. 將腳本輸出作為清單與金額的依據，照原樣交付。小計為數量乘以單價；飲料總額為各項小計之和，不包含外送費。外送費若有提及，另行列出。未提供的欄位標示「未提供」；未提及外送費標示「未提及」。
5. 若腳本以錯誤碼 2 結束，將其單行訊息中的每個值列為「需確認」，並以原文列出受影響的訂購資料；不要計算依賴該值的金額或提供飲料總額。逐一寫明請確認的值，並仍交付清單格式與可確認的原文資料，不要只回覆問題。若任何訂購資料缺漏，照樣列出並標示「未提供」；不得猜值或把缺漏資料當成零。
