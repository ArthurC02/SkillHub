# 駕訓班學費退費資格分類

依輸入的考照狀態與繳費天數分類退費資格；不計算實際退款金額，也不查詢外部資料。

## 步驟

1. 從訊息中逐筆讀取學員代號、考照狀態與繳費至今天數。狀態必須是「已通過路考並取得駕照」或「尚未通過路考」；天數必須是非負整數。天數直接採用輸入值，不依日期推算。
2. 若沒有任何學員資料，直接提供可用的空白格式，並標明空白處為「未提供」：`學員代號｜考照狀態｜繳費至今天數`。不要猜填資料或分類。
3. 對資料完整且可用的每一筆，從本 Skill 所在目錄逐筆執行腳本。將實際欄位代入單一引數，保留三個欄位間的 `|`；在 shell 中妥善引用整個引數，避免欄位內容被當成命令：
   `python scripts/classify_refund.py --record '學員代號|考照狀態|繳費天數'`
4. 使用腳本印出的分類與理由，依輸入原順序整理成逐筆結果，列出學員代號、分類及簡短理由。不得自行改寫分類或計算退款金額。
5. 缺少必要欄位的資料不執行腳本；在結果中逐筆保留，缺少的欄位寫「未提供」，分類寫「未提供」，並說明缺少哪些資料，不能猜測分類。若腳本回報無法使用的值，逐一列出該值並請對方確認；不替該筆給分類。仍須交付其他可用資料的分類結果，不要只以確認事項結束回覆。
