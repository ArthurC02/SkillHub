# 到府坐月子護理訪視費用

依輸入的一次或多次訪視資料計算應收費用；國定假日狀態只採用使用者標註，不查詢或推定假日曆。

1. 從輸入擷取每次訪視的日期、開始時間和國定假日標註。費率採已確認的假設：平日非加成時段 1,500 元、夜間 1,800 元、國定假日 2,000 元。夜間為每天 21:00 起至隔天 07:00 前；國定假日為當日全天。只依開始時間判斷，費用彼此取代而非相加；重疊時採國定假日費率。
2. 若某筆缺少日期、時間或國定假日標註，將缺少欄位標為「未提供」，不替使用者猜測；給出可直接填寫的格式 `日期,開始時間,國定假日（是/否）`，仍處理其餘完整資料。若完全沒有可計算的資料，提供該格式作為可用範本。日期、時間或標註若彼此矛盾或無法辨認，指出原值並要求使用者確認，不計算依賴該值的費用。
3. 對每筆完整資料，以實際值組成一個 `日期,時間,是/否` 參數；在含有本 SKILL.md 的目錄執行以下命令，對每筆資料重複 `--visit` 及其參數：
   `python scripts/calculate_fee.py --visit`
   將實際參數接在命令後；多筆資料可在同一命令中重複此選項。腳本會驗證輸入並計算費用；若退出碼為 2，照實呈現其單行錯誤訊息，不提供受錯誤值影響的費用。
4. 將腳本輸出的費用與計費理由逐筆交付；缺少資料的範本或待確認值也一併標明。不得添加其他費用或把多次訪視合併計費。
