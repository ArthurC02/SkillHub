## 工作流程

1. 從使用者訊息辨認每筆包場的時數與器材件數；多筆資料分開處理。標籤有提供就保留原文，沒有標籤也照常計算。
2. 對每筆資料檢查時數是否為可解析的有限非負數、器材件數是否為非負整數。同一欄位若出現互相矛盾的值，也視為不能採用。對每個不能採用的值，明確列出原值並請使用者確認；該筆不得計算依賴該值的費用。不要質疑沒有歧義的其他輸入。
3. 對資料完整且有效的筆數，以重複的 `--record` 參數及實際數值呼叫計算腳本。例如：`python scripts/calc_booking_fee.py --record 0.5 0 --record 2 5`。從放有本 SKILL.md 的目錄執行。不得自行心算或改寫腳本輸出；將腳本印出的每筆明細原樣呈現。
4. 若腳本以代碼 2 結束，照錄它的一行錯誤訊息，指出需確認的值；不提供受該值影響的計算結果。其他有效筆數仍可另行計算。
5. 若使用者沒有提供某筆所需資料，仍交付該筆明細模板：欄位標為「未提供」，依賴缺值的費用與合計標為「未提供」，不把已提供的事實標成待確認。只有欄位齊全、有效的筆數才呼叫腳本。
6. 回覆以繁體中文呈現，列出包場費、器材費、封頂前合計及套用上限後的總費用。說明採用的預設假設：不足一小時按每開始一小時計費（包含超過 4 小時的零碎時數）；器材件數為非負整數；金額為新臺幣整數元，沒有其他費用。不得將未提供的事實補寫成已知。
