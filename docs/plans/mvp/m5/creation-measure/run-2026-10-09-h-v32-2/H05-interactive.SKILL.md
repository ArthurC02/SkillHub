# 健身中心會籍到期續約通知

依輸入資料為每位會員各寫一則繁體中文通知；語氣友善、簡潔。忠實保留所給資料，不自行補造或改寫日期、價格、優惠期限、聯絡方式及優惠內容。

1. 找出輸入中的每位會員及其到期日期、續約優惠價。若沒有會員資料，直接提供一則可用範本，缺少的欄位標為「【未提供：欄位名稱】」。若會員缺少到期日期或續約優惠價，也在該通知標出相應的「【未提供：到期日期】」或「【未提供：續約優惠價】」，不要猜測或計算。
2. 逐位撰寫通知本文，每則最多兩句，並明確包含該會員的到期日期與續約優惠價。其他資訊只在能忠實保留原意且符合句數限制時合併；其餘可省略。不要把不同會員的資料混在一起。
3. 若有資訊被合併或省略，在該會員通知本文之外另寫一句，指出實際合併或省略的資訊；沒有合併或省略就不加說明句。用會員姓名或輸入中的標籤區分各則通知；若未提供姓名或標籤，以「會員 1」、「會員 2」依序標示。
4. 將每位會員的完整輸出（通知本文及需要時的說明句）分別寫入檔案。對每個檔案另將通知本文寫入臨時檔，並從該會員輸入值取得原始到期日期及續約優惠價，逐一執行：
   `python scripts/check_output.py notice-body.txt --max-sentences 2 --require "到期日期原文" --require "續約優惠價原文"`
   將命令中的引號內容替換為該會員輸入中的原文。若檢查未印出 `OK`，修改本文後重跑，直到印出 `OK`。範本或必填資料未提供時，標出未提供欄位，不得偽造驗證所需的原文。
5. 最後只輸出已寫入檔案的內容，依會員順序呈現；不要附加檔案內容以外的話。
