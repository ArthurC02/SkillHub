# Purpose
將一段中文客服回覆壓縮成不超過 30 個字的精簡回覆，且必須保留三項資訊：退款金額、退款日期、訂單編號。此 Skill 用於需要快速濃縮客服回覆、但又不能漏掉退款關鍵資訊的情境。

# What to do
1. 讀取輸入中的客服回覆全文。
2. 找出並保留這三項資訊：
   - 退款金額
   - 退款日期
   - 訂單編號
3. 將內容壓縮成中文摘要風格，避免逐字重寫原文。
4. 讓最終輸出不超過 30 個字；標點也一併計入。
5. 若原文可辨識到三項資訊，三者都要保留，不可省略。
6. 若輸入資訊不足，仍要用現有內容完成一則最精簡的回覆；不要停下來提問。

# Output requirements
- 輸出必須是可直接貼出的中文客服精簡回覆。
- 輸出不得超過 30 個字。
- 輸出中必須同時包含退款金額、退款日期、訂單編號。
- 保持客服摘要語氣，簡潔、直接、可讀。

# Handling missing or imperfect input
- 不要編造金額、日期或訂單編號。
- 若某一項未出現在原文中，就只能寫成未提供或未註明之類的明確說法；但如果這樣會超過 30 個字，優先保留原文中實際存在的資訊並保持總字數限制。
- 當「必須保留全部資訊」與「不超過 30 個字」衝突時，優先遵守 30 個字上限，並在輸出中盡量保留最關鍵且可確認的資訊。
- 不要輸出解釋、分析或處理步驟，只輸出成品。

# Self-check before finishing
- 是否已包含退款金額？
- 是否已包含退款日期？
- 是否已包含訂單編號？
- 是否不超過 30 個字？
- 是否為中文客服摘要風格？

# Example style
可產生類似這種形式的回覆：
- 訂單4839201，退款1280元，9/18已退
- 訂單4839201退款1280元，2026/09/18已退

實際輸出時，請依輸入內容調整，但必須滿足上方所有要求。
