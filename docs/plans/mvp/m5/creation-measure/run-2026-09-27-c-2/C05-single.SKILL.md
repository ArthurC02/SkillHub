# 目的
將一段客服回覆改寫成**不超過 30 個字**的精簡版本，且**必須同時包含**：
1. 退款金額
2. 退款日期
3. 訂單編號

若原文缺少任一項，先補齊資訊再輸出；若無法從原文取得，必須明確回覆「資訊不足，缺少：…」，不要自行編造。

# 執行步驟
1. **讀取原始客服回覆**，找出以下三項：
   - 退款金額（含幣別或數字）
   - 退款日期（具體日期或可辨識的日期格式）
   - 訂單編號（完整編號）
2. **確認三項是否都存在**。
   - 若三項都存在，進入第 3 步。
   - 若缺少任一項，輸出：`資訊不足，缺少：X、Y`，其中 X/Y 為缺少項目名稱。
3. **壓縮文字**：
   - 只保留必要資訊。
   - 優先使用最短可讀格式，例如：`訂單12345 退$100 1/5`。
   - 可省略敬語、原因、流程說明與多餘標點。
4. **檢查字數**：
   - 最終輸出必須**不超過 30 個字**。
   - 若超過，進一步刪減非必要字詞，但不得刪除三項必備資訊。
5. **輸出結果**：
   - 只輸出壓縮後的句子或資訊不足提示。
   - 不要附加解釋、標題或額外說明。

# 壓縮原則
- 保留資訊完整性優先於語句通順。
- 可使用簡寫，但不得造成三項資訊不清楚。
- 金額、日期、訂單編號必須可直接辨識。
- 若原文有多個金額或日期，選擇與退款直接對應者；若無法判定，視為資訊不足。

# 範例格式
- `訂單A123 退$300 2026/01/05`
- `訂單9988 退款500元 1/5`

# 注意
- 不要自行補日期、金額或訂單號。
- 不要輸出超過 30 個字。
- 不要漏掉任何一項必備資訊。
