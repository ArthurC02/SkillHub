# 出差報帳明細核對

依照下列步驟核對員工出差報帳：

1. **讀取報帳資料**
   - 找出每一天的明細項目與金額。
   - 找出員工填寫的每日小計、整體總計，或兩者皆有時的欄位。
   - 若有幣別、稅額、折扣、匯率或四捨五入規則，先確認是否需要納入加總。

2. **整理每日明細**
   - 以「日期」為單位分組。
   - 將同一天的所有可計入費用逐筆列出。
   - 排除不應計入總額的項目，前提是報帳規則明確指出該項目不計入。

3. **計算每日加總**
   - 對每一天的可計入費用逐項相加。
   - 若有小數，依報帳規則處理；若未說明，保留原始精度後再做最終比較。
   - 記錄每一天的計算式，方便回查。

4. **比對每日小計**
   - 若員工有填每日小計，將計算結果與填寫值逐日比對。
   - 標記一致或不一致。
   - 若不一致，指出差額與可能出錯的明細項目。

5. **計算整體總計**
   - 將所有日期的每日加總再相加，得到整體總額。
   - 若表單已有整體總計，與員工填寫的總計比對。
   - 若表單同時有「每日小計加總」與「總計」，也要確認兩者彼此一致。

6. **處理常見差異來源**
   - 檢查是否有漏算、重複列算、日期歸類錯誤、幣別混用、稅額是否已含、以及四捨五入造成的差異。
   - 若差異僅為極小金額，先確認是否來自四捨五入規則。

7. **輸出核對結果**
   - 以清楚格式列出：
     - 每日明細與每日加總
     - 員工填寫的小計/總計
     - 差異金額
     - 是否一致
   - 若一致，明確寫出「核對一致」。
   - 若不一致，明確寫出「核對不一致」，並列出需要員工或審核者再確認的項目。

8. **資料不足時的處理**
   - 如果缺少日期、金額、幣別或總計欄位，先指出缺少哪些資訊。
   - 不要自行補值；改為請求補齊後再核對。

## 建議輸出格式

- 日期：YYYY-MM-DD
- 明細：項目名稱 × 金額
- 每日加總：
- 員工填寫小計：
- 差異：
- 結論：一致 / 不一致

## 核對原則

- 只根據提供的報帳資料計算，不自行推測未提供的金額。
- 若規則未說明，先按明細原值加總，再與填寫總計比較。
- 保留可追溯性：每個結論都要能回到對應的明細與計算。
