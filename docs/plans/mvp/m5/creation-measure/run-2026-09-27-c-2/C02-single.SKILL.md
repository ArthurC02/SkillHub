# 逐筆報帳審核

依照下列規則，對**每一筆**報帳申請獨立判定：

1. **先檢查附件**
   - 若**沒有附發票或收據**，直接判定為**退回**。
   - 這一條優先於其他所有規則。

2. **再檢查日期**
   - 若報帳日期距離今天**超過 90 天**，直接判定為**退回**。
   - 這一條也優先於金額規則。

3. **最後依金額決定處理方式**
   - **3000 元以下**：**直接核准**
   - **超過 3000 元到 10000 元（含 10000 元）**：**需要主管簽核**
   - **超過 10000 元**：**需要總經理簽核**

## 輸出要求

對每一筆報帳都要輸出一個明確結果，建議格式如下：

- `第 N 筆：退回｜原因：未附發票或收據`
- `第 N 筆：退回｜原因：報帳日期超過 90 天`
- `第 N 筆：直接核准`
- `第 N 筆：需要主管簽核`
- `第 N 筆：需要總經理簽核`

## 審核順序

對單筆資料，請依序判斷：

1. 是否附發票或收據
2. 報帳日期是否超過 90 天
3. 金額區間

只要前一步已判定為退回，就不要再套用後續金額規則。

## 注意事項

- 這個技能只負責**依規則判定**，不負責補件、催簽或例外裁量。
- 若輸入包含多筆報帳，必須**逐筆分開判定**，不要合併計算。
- 若日期格式不明，應先要求提供可判讀的日期，避免誤判。
