---

# 目的
將客戶訂購 email 內容整理成結構化清單，至少包含：
- 訂購品項
- 數量
- 單價
- 客戶指定的收件地址

# 使用時機
當輸入是一封或多封訂購 email 的正文、轉寄內容或截圖轉文字，且需要快速整理成可讀清單時使用。

# 處理原則
1. 只根據 email 內容整理，不要自行補充不存在的資訊。
2. 若同一封信有多個品項，逐項列出。
3. 若資訊不完整，保留已知內容，並明確標示缺漏欄位為「未提供」或「無法辨識」。
4. 若地址出現多個版本，以信件中明確標示為收件地址、送貨地址、ship to、deliver to、收件人地址者為優先。
5. 若單價或數量以不同格式出現（例如含幣別、含稅、折扣後價格），照原文記錄，必要時在備註中註明。
6. 若信件中有訂單編號、客戶姓名、聯絡方式，可一併保留在摘要中，但不要取代必要欄位。

# 作業步驟
1. 先通讀整封 email，找出所有與訂購相關的段落、表格、條列、附件文字轉錄內容。
2. 擷取每個品項的資訊：
   - 品名/品項名稱
   - 數量
   - 單價
3. 擷取收件地址：
   - 收件人
   - 地址全文
   - 若有電話或備註，可一併保留
4. 若有多筆品項，整理成表格或條列清單。
5. 檢查是否有重複品項、合併數量或拆分行項；若原文明顯是同一品項的多行描述，合併時要保留原始資訊，不要遺漏。
6. 若無法判斷某欄位，標示原因，例如「信件未提供單價」或「地址文字不完整」。

# 輸出格式
請用以下格式輸出：

## 訂購清單
| 品項 | 數量 | 單價 | 備註 |
|---|---:|---:|---|
| ... | ... | ... | ... |

## 收件地址
- 收件人：...
- 地址：...
- 電話：...
- 其他備註：...

## 補充說明
- 若有缺漏或歧義，在此列出。
- 若信件中有多個地址，說明你採用哪一個以及原因。

# 注意事項
- 不要猜測價格、數量或地址。
- 不要把發票地址、帳單地址誤當成收件地址，除非信件明確表示兩者相同。
- 若 email 內容包含簽名檔、法律聲明或無關文字，可忽略。
