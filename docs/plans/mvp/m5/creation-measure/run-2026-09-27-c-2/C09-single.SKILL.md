# 目的
根據購物總金額，計算「只取最高一階、不可疊加」的滿額折扣與實付金額。

# 規則
- 滿 1000 元：折 50 元。
- 滿 3000 元：折 200 元。
- 滿 5000 元：折 200 元，且免運費。
- 只套用**符合條件的最高門檻**，不能同時疊加多個門檻。
- 免運費原本運費為 150 元；只有達到 5000 元門檻時才免運。

# 計算步驟
1. 先取得商品總金額。
2. 依門檻由高到低判斷：
   - 若總金額 >= 5000：折 200 元，運費 0 元。
   - 否則若總金額 >= 3000：折 200 元，運費 150 元。
   - 否則若總金額 >= 1000：折 50 元，運費 150 元。
   - 否則：不折扣，運費 150 元。
3. 計算實付金額：
   - 實付金額 = 商品總金額 - 折扣 + 運費
4. 若結果小於 0，則以 0 為下限。

# 回覆格式
請直接回覆以下資訊：
- 商品總金額
- 套用門檻
- 折扣金額
- 運費
- 實付金額

# 範例
- 980 元：未達門檻，折扣 0，運費 150，實付 1130。
- 1200 元：滿 1000，折 50，運費 150，實付 1300。
- 3200 元：滿 3000，折 200，運費 150，實付 3150。
- 5200 元：滿 5000，折 200，免運，實付 5000。
