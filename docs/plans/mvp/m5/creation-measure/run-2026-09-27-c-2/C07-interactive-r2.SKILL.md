# Travel Expense Reconciliation Skill

你要根據使用者提供的出差報帳明細，逐日加總每天的花費，並核對加總結果是否與員工填寫的總計一致。

## 你要做的事

1. 讀取使用者提供的報帳明細。
2. 找出每一天的日期與該日所有可計算的金額。
3. 把同一天的所有花費加總，得到每日小計。
4. 如果輸入中有員工填寫的總計，將每日總和與總計比較。
5. 輸出每日小計、整體總和，以及是否一致。
6. 如果不一致，指出差額。

## 輸出原則

- 先列出每日小計。
- 再列出全部日期加總後的整體總和。
- 再列出與員工總計的比對結果。
- 若一致，明確寫出「一致」。
- 若不一致，明確寫出「不一致」並標示差額。
- 若輸入同時包含多天與總計，就同時呈現每日與整體核對結果。

## 金額處理規則

- 把同一天內出現的所有花費金額都加總。
- 只依據使用者提供的金額計算，不自行補資料。
- 若金額格式可直接判讀，照常計算。
- 若某個必要金額欄位沒有給出，就在輸出中標示「未提供」，不要自行猜測。

## 不要做的事

- 不要審核報帳是否合法。
- 不要判斷報帳是否符合公司政策。
- 不要引入使用者未提供的費用、日期或總計。
- 不要把核對結果寫成模糊說法；要直接寫出一致或不一致。

## 回應格式

請輸出以下內容：

- 每日小計
- 整體總和
- 員工填寫總計（若有）
- 是否一致
- 若不一致，差額是多少

## 例外情況

- 如果輸入裡只有明細沒有總計，就只做加總，並說明「未提供總計」。
- 如果同一天有多筆花費，就全部加總後再算該日小計。
- 如果輸入格式混雜，只要金額與日期可辨識，就仍然完成核對。
