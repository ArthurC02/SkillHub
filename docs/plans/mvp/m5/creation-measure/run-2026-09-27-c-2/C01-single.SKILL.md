# 目的
依照輸入的時薪與每天加班時數清單，計算當月應付的平日加班費總額。

# 適用規則
- 每日加班前 2 小時：以時薪的 1.34 倍計算。
- 每日第 3 到第 4 小時：以時薪的 1.67 倍計算。
- 每日加班最多只計 4 小時，超過 4 小時的部分不計薪。
- 每人每月加班總時數最多只計 46 小時，超過 46 小時的部分不計薪。

# 輸入
- 時薪：一個數值。
- 每天的加班時數清單：一串每日加班時數，順序代表月份中的日期順序。

# 計算步驟
1. 先確認時薪是有效數值，且每日加班時數清單中的每一筆都是非負數。
2. 逐日處理加班時數，並維護「已計入的月累計加班時數」。
3. 對每一天：
   - 先將該日加班時數限制在 4 小時以內。
   - 再檢查月累計是否已達 46 小時。
   - 若月累計已達 46 小時，當日剩餘時數全部不計薪。
   - 若尚未達 46 小時，只計入不超過剩餘月額度的部分。
4. 將當日可計薪時數拆成兩段：
   - 前 2 小時：乘以 1.34 倍時薪。
   - 超過 2 小時到 4 小時的部分：乘以 1.67 倍時薪。
5. 將所有日期的加班費加總，得到當月總加班費。

# 計算細則
- 若某日實際可計薪時數為 `h`：
  - `min(h, 2)` 小時按 `1.34 × 時薪`
  - `max(min(h - 2, 2), 0)` 小時按 `1.67 × 時薪`
- 若月累計剩餘額度為 `r`，則當日實際可計薪時數為 `min(該日原始加班時數, 4, r)`。
- 超過每日 4 小時或每月 46 小時的部分，一律視為不計薪。

# 輸出
- 回傳或輸出一個數值，表示當月應付的加班費總額。
- 若需要呈現中間結果，可同時列出：
  - 每日原始加班時數
  - 每日實際計薪時數
  - 每日加班費
  - 月累計加班時數
  - 月總加班費

# 執行時的注意事項
- 不要把超過 4 小時的單日加班時數直接拿去計算。
- 不要把超過 46 小時的月累計加班時數直接拿去計算。
- 若輸入清單中有小數時數，依照同一套分段規則按比例計算即可。
- 若輸入資料不足以判斷月份天數，仍以提供的清單逐筆計算，不自行補日期。
