# 每週五寄送週報給主管

這個 Skill 的目標是把「每週五寄週報」變成可重複執行的流程。它可以幫你：

1. 確認週報內容與收件資訊。
2. 整理成固定模板。
3. 規劃自動化排程方式。
4. 提供每週執行前的檢查清單。

## 先確認這件事是否能自動化

如果你目前沒有以下任一項，這個任務**不能由 Skill 直接完成**，只能先準備流程：

- 可用的電子郵件帳號與登入權限
- 可設定排程的郵件工具、工作流程工具，或自動化平台
- 主管的正確收件地址
- 允許自動寄信的公司政策

若缺少其中任何一項，先收集資訊，不要假設可以直接排程。

## 需要先蒐集的資訊

在建立流程前，先確認：

- 收件人：主管的電子郵件地址
- 副本/密件副本：是否需要寄給其他人
- 寄送時間：每週五的幾點
- 時區：以哪個時區為準
- 週報格式：純文字、HTML、附件、或兩者都有
- 內容來源：手動撰寫、從文件整理、或從系統匯出
- 主旨格式：例如「週報 - 姓名 - YYYY/MM/DD」
- 是否需要固定簽名檔
- 是否需要附檔
- 是否需要寄送前先預覽或人工確認

## 建立週報模板

把週報固定成可重複使用的格式。建議包含：

- 本週完成事項
- 進行中事項
- 遇到的問題與風險
- 下週計畫
- 需要主管協助的事項

範例結構：

```text
主旨：週報 - [姓名] - [YYYY/MM/DD]

主管您好，

以下是本週週報：

1. 本週完成事項
- 
- 

2. 進行中事項
- 
- 

3. 問題與風險
- 
- 

4. 下週計畫
- 
- 

5. 需要協助事項
- 

謝謝。
```

## 排程方式的選擇

依你可用的工具，選擇其中一種方式：

### 方式 A：郵件工具內建排程

如果郵件服務支援「排程寄送」：

1. 撰寫週報郵件。
2. 填入主管收件地址。
3. 設定主旨與內容模板。
4. 選擇每週五的寄送時間。
5. 儲存或啟用排程。
6. 測試一次，確認寄送時間與收件人正確。

### 方式 B：自動化平台排程

如果你使用自動化平台或工作流程工具：

1. 建立每週五觸發器。
2. 設定時區。
3. 連接郵件帳號。
4. 讀取週報內容來源。
5. 組合主旨與內文。
6. 寄送給主管。
7. 加入失敗通知或重試機制。

### 方式 C：半自動流程

如果無法完全自動化：

1. 每週五固定提醒你產生週報。
2. 先用模板整理內容。
3. 由你確認後再寄出。
4. 保留寄送紀錄。

## 每週執行流程

每週五執行以下步驟：

1. 收集本週完成事項。
2. 更新進行中事項。
3. 補上問題與風險。
4. 寫下下週計畫。
5. 檢查收件人與主旨。
6. 確認是否需要附件。
7. 寄出或讓排程自動寄出。
8. 保存寄送紀錄。

## 寄出前檢查清單

- 收件人正確
- 時區正確
- 主旨格式正確
- 內容完整
- 附件已附上
- 沒有敏感資訊誤寄
- 已確認主管今天需要收到
- 已保留副本或寄送紀錄

## 失敗處理

如果排程失敗或寄送失敗：

1. 先確認是否是登入失效。
2. 檢查收件地址是否錯誤。
3. 檢查郵件服務是否限制自動寄送。
4. 檢查排程時間與時區。
5. 重新測試一次。
6. 若仍失敗，改用半自動流程，避免漏寄。

## 這個 Skill 能做與不能做

### 能做

- 幫你整理週報模板
- 幫你列出排程所需資訊
- 幫你規劃自動化步驟
- 幫你建立每週檢查清單

### 不能做

- 不能直接登入你的郵件帳號
- 不能替你設定外部服務的排程
- 不能保證郵件服務一定支援自動寄送
- 不能在沒有工具權限時直接完成寄送

## 建議的下一步

先提供或確認以下資訊，再建立最終流程：

- 主管電子郵件地址
- 你使用的郵件服務
- 想要的寄送時間與時區
- 週報內容格式
- 是否需要附件
- 是否要完全自動或先人工確認
