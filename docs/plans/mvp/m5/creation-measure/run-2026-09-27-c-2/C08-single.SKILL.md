# 目的
協助撰寫「防颱停班停課」的內部公告信草稿，語氣正式、內容清楚，並且一定包含：
- 生效日期
- 恢復上班日期
- 需要留守的部門名稱

# 使用時機
當使用者要你代寫或整理公司／機構內部的防颱停班停課公告信時使用。若缺少必要資訊，先列出需要補齊的項目，不要自行編造日期或部門名稱。

# 寫作原則
1. 語氣正式、簡潔、明確。
2. 先講結論，再補充必要說明。
3. 必須清楚區分：
   - 停班停課的生效時間或日期
   - 恢復正常上班／上課的日期與時間
   - 需留守或維持運作的部門
4. 若有例外安排，應明確寫出適用對象與聯絡方式。
5. 不要加入未提供的政策內容、法規條文或公司制度細節。

# 撰寫流程
## 1. 先確認必要資訊
若資訊不足，先向使用者確認以下項目：
- 公告對象：全體員工、特定單位，或全校／全體同仁
- 生效日期與時間：例如「即日起」、「2026/09/27 18:00 起」
- 恢復上班日期與時間：例如「2026/09/28 08:30 恢復」
- 需留守部門名稱：例如「總務部、資訊部、客服中心」
- 是否有留守人員或值班聯絡方式
- 是否需要加上公告發布單位與日期

## 2. 內容結構
公告信建議包含以下段落：
1. 主旨
2. 開頭說明
3. 停班停課安排
4. 留守部門說明
5. 恢復上班日期
6. 結尾提醒

## 3. 主旨寫法
主旨要直接明確，例如：
- 防颱停班停課公告
- 【公告】防颱停班停課及留守安排
- 【重要通知】防颱停班停課與恢復上班時間

## 4. 內文寫法
內文必須明確寫出以下資訊：
- 因應颱風來襲，依規定或依公司決議，自何時起停班停課
- 預計何時恢復上班
- 哪些部門需留守或維持必要運作
- 如有緊急狀況，請聯絡誰或哪個窗口

## 5. 建議格式
可直接使用以下結構撰寫：

**主旨：** 防颱停班停課公告

各位同仁您好：

因應颱風影響，經評估後，本公司／本單位自【生效日期與時間】起實施停班停課。

預計於【恢復上班日期與時間】恢復正常上班。

另請【需留守的部門名稱】依排定人員留守，維持必要業務運作；如有緊急事項，請聯繫【聯絡窗口／方式】。

請各單位同仁留意後續通知，並注意自身安全。

敬祝 平安

【發布單位】
【發布日期】

# 品質檢查
在完成草稿前，確認是否已包含：
- 明確的生效日期／時間
- 明確的恢復上班日期／時間
- 明確的留守部門名稱
- 正式語氣
- 無自行捏造的資訊

# 若資訊不足時的回覆方式
若使用者未提供必要資訊，請直接列出需要補充的欄位，例如：
- 生效日期與時間
- 恢復上班日期與時間
- 留守部門名稱
- 是否需要附上聯絡窗口

並說明：補齊後即可代寫完整公告信。
