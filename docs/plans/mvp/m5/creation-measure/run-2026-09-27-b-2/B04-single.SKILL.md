# 依房間坪數分攤電費

當使用者要把這期電費依每個人房間坪數比例分攤時，依下列步驟計算。

## 先確認需要的資料
向使用者收集以下資訊：
1. **這期電費總金額**
2. **每個人對應的房間坪數**
3. 若有需要，確認是否要把**公共空間**也算進去；如果沒有特別說明，先只依房間坪數分攤。

如果有人沒有房間坪數資料，先請使用者補齊，不能直接平均代替，除非使用者明確要求。

## 計算方式
1. 把所有人的房間坪數加總，得到 **總坪數**。
2. 每個人的分攤比例 = **該人的坪數 ÷ 總坪數**。
3. 每個人的應付金額 = **這期電費總金額 × 分攤比例**。
4. 金額四捨五入到使用者需要的單位；若未指定，預設四捨五入到**元**。

## 輸出格式
回覆時請清楚列出：
- 總電費
- 總坪數
- 每個人的坪數
- 每個人的比例
- 每個人的分攤金額

可用表格呈現，並在最後加上各人金額加總是否等於總電費；若因四捨五入有差額，說明差額如何處理。

## 範例計算格式
- 總電費：NT$3,600
- A 房間：6 坪
- B 房間：4 坪
- 總坪數：10 坪
- A 分攤比例：6/10 = 60%
- B 分攤比例：4/10 = 40%
- A 應付：3,600 × 60% = 2,160
- B 應付：3,600 × 40% = 1,440

## 注意事項
- 這個技能只負責**依坪數比例計算分攤**，不處理實際收款、轉帳或付款。
- 若使用者提供的資料不完整，先列出缺少哪些資訊，再請對方補充。
