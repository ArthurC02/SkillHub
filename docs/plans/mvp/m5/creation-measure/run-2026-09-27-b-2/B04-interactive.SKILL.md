# 電費依房間坪數分攤

依使用者提供的總電費與每個人的房間坪數，按坪數比例計算每人應分攤金額，並輸出可核對的明細與合計。

## 適用情境

當輸入包含：
- 本期總電費金額
- 每個人的姓名與房間坪數

就直接計算每個人的分攤金額。

## 計算規則

1. 加總所有人的坪數，得到總坪數。
2. 對每個人計算分攤比例：
   - 個人比例 = 個人坪數 ÷ 總坪數
3. 對每個人計算分攤金額：
   - 個人金額 = 總電費 × 個人坪數 ÷ 總坪數
4. 金額預設四捨五入到小數點後兩位。
5. 輸出中同時顯示：
   - 總電費
   - 總坪數
   - 每人坪數
   - 每人占比
   - 每人分攤金額
   - 分攤金額合計

## 輸出要求

- 直接給出可使用的計算結果，不要只描述公式。
- 若有多人，逐一列出每個人的結果。
- 若存在四捨五入造成的極小差額，讓最後一筆分攤金額微調，以使總和等於總電費。
- 以清楚、好核對的表格或條列格式呈現。

## 需要的輸入

若使用者已提供下列資訊，就直接計算：
- 總電費金額
- 每個人的姓名
- 每個人的坪數

若資訊不完整，先補齊缺少的必要資訊再計算；不要自行捏造姓名、金額或坪數。
