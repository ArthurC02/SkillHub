# 發票整理與核銷上傳流程

## 適用情境
當任務是把一批發票資料整理成可核銷的格式，並上傳到公司的記帳／報銷系統時使用。若需要登入公司系統、使用即時網路、或完成實際提交，而目前沒有提供可用的登入與操作權限，則只能先完成整理、檢查與上傳前準備，不能假裝已經送出。

## 先確認可做與不可做
1. 檢查是否已提供：
   - 發票原始資料（圖片、PDF、表格、文字清單等）
   - 公司核銷規則或欄位要求
   - 記帳系統所需欄位名稱
   - 是否有可用的登入方式或可操作的系統介面
2. 若缺少任何關鍵資訊，先整理出缺口清單，向使用者索取。
3. 若沒有系統存取權限或登入資訊：
   - 可以完成資料整理、欄位對應、缺漏檢查、匯入檔準備
   - 不能實際登入、上傳或送出核銷

## 工作步驟
### 1. 收集與分類資料
- 將所有發票逐筆列出。
- 依日期、供應商、金額、幣別、用途、部門或專案分類。
- 若資料來源混雜，先分成：
  - 可辨識完整資料
  - 部分缺漏資料
  - 無法辨識資料

### 2. 擷取每張發票的必要欄位
對每筆資料整理以下欄位，若原始資料沒有就標記為缺漏：
- 發票日期
- 發票號碼／憑證號碼
- 供應商名稱
- 品項或摘要
- 金額
- 稅額（如適用）
- 幣別
- 用途／專案／部門
- 是否可核銷
- 備註

### 3. 驗證與清理
- 檢查日期格式是否一致。
- 檢查金額是否為數字，並確認小數位與幣別一致。
- 檢查是否有重複發票號碼或重複金額組合。
- 檢查是否有明顯不合理項目，例如：
  - 日期超出本月核銷範圍
  - 金額與稅額加總不一致
  - 發票抬頭或供應商名稱與規則不符
- 將疑點列入待確認清單，不要自行補寫不確定內容。

### 4. 對照公司核銷規則
- 若有公司規則，逐項比對：
  - 可報銷品項
  - 金額上限
  - 是否需要附件
  - 是否需要主管或專案代碼
  - 是否需要統編、抬頭、稅別資訊
- 將不符合規則的項目標記為：
  - 可修正
  - 需補件
  - 不可核銷

### 5. 整理成可上傳格式
- 依系統要求整理成表格或匯入檔。
- 若沒有明確格式，使用清楚的欄位表，至少包含：
  - 日期
  - 供應商
  - 發票號碼
  - 摘要
  - 金額
  - 稅額
  - 幣別
  - 部門／專案
  - 備註
- 保持欄位名稱一致，不要混用不同格式。

### 6. 產出核銷前檢查清單
在準備上傳前，列出：
- 已完成整理的發票數量
- 缺漏欄位的筆數
- 重複或疑似重複的筆數
- 需要人工確認的筆數
- 不可核銷的筆數與原因

### 7. 若有系統操作權限，才進行上傳
- 依公司系統流程登入。
- 先確認欄位對應是否正確，再匯入或逐筆輸入。
- 上傳後檢查系統回傳結果：
  - 成功筆數
  - 失敗筆數
  - 錯誤訊息
- 對失敗筆數只做記錄與整理，不要猜測修正。

### 8. 完成後回報
回報內容應包含：
- 本次整理的發票總數
- 已可核銷筆數
- 待補件筆數
- 不可核銷筆數
- 若已能上傳，提供上傳結果摘要
- 若無法實際上傳，明確說明原因與下一步需要的資訊

## 輸出建議格式
若要先交付整理結果，使用以下結構：

- 核銷摘要
- 發票明細表
- 缺漏與異常清單
- 待確認問題
- 上傳準備狀態

## 注意事項
- 不要自行編造發票號碼、日期、金額或供應商名稱。
- 不要把未確認的資料標成已核銷。
- 若資料來源是圖片或掃描檔，先以可辨識內容為準，無法辨識的部分標記為待確認。
- 若任務要求實際登入或提交，而目前沒有權限，必須停在準備階段並請使用者提供可操作的存取方式。
