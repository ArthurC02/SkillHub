# 目的
協助產生一則可直接回覆客戶的報價/交期說明，當客戶要求的交期與公司內規衝突時，先依規定判斷是否可承接，再用專業、清楚、不中傷客戶的方式回覆。

# 適用情境
- 客戶要求報價並指定交期。
- 交期與公司內部流程、法規、品管、產能或出貨條件衝突。
- 特別是「新口味／新產品」需要額外檢驗、試產或全檢時。

# 核心原則
1. 先確認是否能符合客戶要求。
2. 若公司規定要求出貨前必須完成固定天數的品管全檢，則不得承諾短於該天數的交期。
3. 回覆時要明確說明限制原因，但避免過度揭露內部敏感細節。
4. 提供可行替代方案，例如：調整交期、分批出貨、先提供其他已完成檢驗的品項。

# 操作步驟
## 1. 讀取客戶需求
整理以下資訊：
- 客戶要求的交貨天數或日期
- 產品是否為新口味／新產品
- 公司對該類產品的固定檢驗或出貨規定

## 2. 判斷是否可承接
- 若客戶要求的交期 **短於** 公司規定的品管全檢天數，判定為 **不可直接承諾**。
- 若客戶要求的交期 **等於或長於** 規定天數，仍需確認是否包含生產、檢驗、包裝與物流緩衝。

## 3. 擬定回覆方向
回覆內容應包含：
- 感謝詢問與確認需求
- 說明新口味需先完成固定天數的品管全檢
- 明確告知原要求交期無法配合，或需延後至可出貨時間
- 提出替代方案或請客戶確認是否接受調整後交期

## 4. 建議回覆語氣
- 專業、禮貌、簡潔
- 不要直接說「不能做」；改為「依公司流程目前無法在該期限內出貨」
- 若需要，可加上「為確保品質與穩定性」作為原因

# 可直接使用的回覆範本
## 範本 A：明確無法配合 7 天交期
您好，感謝您的詢問。

此品項為新口味，依公司規定出貨前需完成 14 天的品管全檢，因此目前無法配合 7 天內交貨。
若您方便，我們可以依 14 天檢驗流程後安排出貨，或再協助您評估其他可提前交付的方案。

謝謝您的理解。

## 範本 B：先說明限制，再請客戶確認是否接受調整
您好，感謝您的來信。

您詢問的品項屬於新口味，依內部品管規範，出貨前需完成 14 天全檢，因此 7 天交期無法配合。
若您可接受調整交期，我們可進一步為您安排報價與出貨時程。

謝謝。

# 注意事項
- 不要承諾違反內規的交期。
- 若客戶要求壓縮流程，不要自行同意，應改為請客戶接受標準流程。
- 若需要更正式的商務語氣，可將「品管全檢」改寫為「品質檢驗流程」。
- 若客戶希望加急，應先確認公司是否有正式的例外核准機制；若沒有，則維持標準流程。
