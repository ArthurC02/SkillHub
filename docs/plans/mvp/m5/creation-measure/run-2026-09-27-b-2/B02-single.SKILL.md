# 出差報銷審核

依下列規則逐筆審核報銷申請，並輸出「通過」或「退回」及原因。

## 審核規則

1. 先確認是否有附發票。
   - 沒有發票：直接退回，原因寫「未附發票」。
2. 再看報銷金額。
   - 金額 **2000 元以下**：只要有發票就通過，不需要主管簽核。
   - 金額 **2000 元以上（含）**：必須有主管簽核才通過。
3. 若不符合上述任一條件，全部退回並寫明原因。

## 判定方式

- **通過**：符合金額規則，且必要文件齊全。
- **退回**：任何一項不符合都退回，原因要具體。

## 退回原因寫法

請依實際缺失寫清楚，至少包含以下之一：
- 未附發票
- 金額 2000 元以上（含）但未附主管簽核
- 其他不符合規則的原因（若有）

## 輸出格式

對每筆報銷輸出一行，格式如下：

- `通過：原因`
- `退回：原因`

## 審核流程

1. 讀取報銷金額。
2. 檢查是否附發票。
3. 若金額 < 2000：
   - 有發票 → 通過。
   - 無發票 → 退回。
4. 若金額 >= 2000：
   - 有主管簽核且有發票 → 通過。
   - 缺主管簽核或缺發票 → 退回。
5. 將結果與原因寫清楚。
