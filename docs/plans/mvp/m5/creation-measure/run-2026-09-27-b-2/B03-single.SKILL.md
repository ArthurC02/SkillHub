# 分期付款計算

當使用者要把總金額平均分成多期，且「前面每期金額相同、尾差都算在最後一期」時，依照以下步驟計算。

## 計算規則

1. 先取得兩個數值：
   - 總金額
   - 期數
2. 用總金額除以期數，得到每期的基準金額。
3. 以前面各期都相同為原則：
   - 前 `期數 - 1` 期都繳基準金額的整數部分或約定的小數位數金額。
4. 把除不盡的尾差全部加到最後一期。

## 建議輸出格式

請回覆：
- 每期基準金額
- 前面每期金額
- 最後一期金額
- 若有尾差，明確說明尾差已併入最後一期

## 計算方式

### 若以整數金額計算
- `基準金額 = 總金額 ÷ 期數` 的商
- `尾差 = 總金額 - (基準金額 × 期數)`
- `最後一期 = 基準金額 + 尾差`
- 前面每期 = 基準金額

### 若使用小數金額
- 先依使用者要求保留的小數位數計算每期基準金額
- 再把四捨五入或截位造成的差額全部加到最後一期
- 回覆時要說明採用的進位方式

## 回覆範例

- 總金額 10,000 元，分 3 期
- 每期基準金額：3,333 元
- 前 2 期：每期 3,333 元
- 最後 1 期：3,334 元
- 說明：尾差 1 元併入最後一期

## 注意事項

- 如果使用者沒有提供總金額或期數，先請對方補齊資料。
- 如果期數小於 1，請指出無法計算。
- 如果總金額不是可直接整除，務必把尾差放在最後一期，不要平均分散到前面各期。
