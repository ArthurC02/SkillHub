# Customer Satisfaction Survey Questionnaire

Use this skill when the task is to create a customer satisfaction survey questionnaire for customers, clients, or users.

## Goal
Produce a survey that is easy to answer, measures satisfaction clearly, and can be used in a form, email, or interview.

## Process
1. **Identify the survey context**
   - Determine what the survey is about: product, service, support, delivery, store visit, website, or overall experience.
   - If the context is not provided, create a general customer satisfaction survey.

2. **Choose the survey length**
   - Default to a short survey with 8–12 questions.
   - If the user asks for a brief survey, keep it to 5–7 questions.
   - If the user asks for a detailed survey, include up to 15 questions.

3. **Use a balanced structure**
   Include these sections when relevant:
   - Overall satisfaction
   - Likelihood to recommend
   - Specific experience areas
   - Open-ended feedback
   - Customer profile or segmentation questions only if needed

4. **Write clear questions**
   - Use simple, neutral wording.
   - Ask one thing per question.
   - Avoid leading or double-barreled questions.
   - Prefer customer-facing language over internal jargon.

5. **Select response formats**
   Use common formats such as:
   - 1–5 satisfaction scale
   - 0–10 recommendation scale
   - Multiple choice
   - Yes/No
   - Open text

6. **Include standard satisfaction measures**
   When appropriate, include:
   - Overall satisfaction
   - Ease of use or ease of service
   - Quality of product/service
   - Speed or responsiveness
   - Value for money
   - Likelihood to recommend

7. **Add open-ended questions**
   Include at least one question such as:
   - What did you like most?
   - What could we improve?
   - Is there anything else you would like to share?

8. **Make the survey practical**
   - Start with easy questions.
   - Put sensitive or demographic questions at the end.
   - Keep the wording respectful and concise.
   - If the survey will be translated, avoid idioms and complex phrasing.

## Output format
Return the questionnaire in a clean, ready-to-use format with:
- A title
- A short introduction or instruction line
- Numbered questions
- Response options where needed
- Optional notes for the survey creator if useful

## Default questionnaire template
If the user does not specify details, generate this structure:
1. Overall satisfaction rating
2. Likelihood to recommend
3. Satisfaction with the main product/service
4. Satisfaction with speed/responsiveness
5. Satisfaction with staff/support
6. Ease of completing the process
7. What did you like most?
8. What could we improve?
9. Any additional comments?

## Quality checks
Before finalizing, verify that:
- The survey matches the requested context
- The questions are neutral and easy to answer
- The response scales are consistent
- The survey is not too long for the intended use
- The final result is ready to copy into a form or document
