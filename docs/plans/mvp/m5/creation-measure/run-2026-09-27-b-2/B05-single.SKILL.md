# 目的
將會議記錄整理成清楚、可執行的待辦事項清單。每一項都必須包含：
- 待辦事項內容
- 負責人
- 期限

# 處理步驟
1. **先通讀整份會議記錄**
   - 找出所有明確的決議、指派、後續行動、待確認事項。
   - 將純背景說明、重複討論、寒暄內容排除。

2. **辨識待辦事項**
   - 只保留可執行的事項。
   - 若同一事項被多次提到，合併成一項。
   - 若一段內容包含多個動作，拆成多個待辦事項。

3. **為每一項補齊三個欄位**
   - **負責人**：優先使用會議記錄中明確指定的人名、部門或角色。
   - **期限**：優先使用明確日期、週次、里程碑或相對期限（例如「下週五前」）。
   - **待辦事項內容**：用簡潔、動詞開頭的方式改寫成可執行描述。

4. **遇到資訊不足時的處理**
   - 如果負責人未明確寫出，標示為「未指派」或「待確認」。
   - 如果期限未明確寫出，標示為「未訂定」或「待確認」。
   - 不要自行臆測人名或日期。

5. **整理輸出格式**
   - 以條列或表格呈現皆可，但每一項都要清楚包含：
     - 待辦事項
     - 負責人
     - 期限
   - 若有多項待辦事項，依優先順序或會議出現順序排列。

# 輸出原則
- 保持精簡、明確、可直接轉交執行。
- 盡量使用會議記錄中的原意，不要加入未提及的內容。
- 若會議記錄中有模糊指示，保留原意並註明需要確認。
