---
name: typhoon-closure-announcement-draft
description: Drafts a formal internal announcement email for typhoon-related work/school suspension when you need a clear notice that includes the effective date, the resumption date, and the departments that must remain on duty.
---

# 目的
根據使用者提供的防颱停班停課資訊，撰寫一封正式、清楚的內部公告信草稿。

# 何時使用
當使用者要通知公司或組織內部成員：
- 防颱停班停課
- 生效日期
- 恢復上班日期
- 需要留守的部門名稱

# 執行步驟
1. 先確認必要資訊是否齊全：
   - 公告對象（全體同仁、特定單位、全公司等）
   - 生效日期與時間
   - 恢復上班日期與時間
   - 需要留守的部門名稱
   - 是否有其他補充事項（例如遠端辦公、聯絡窗口、緊急應變方式）

2. 如果缺少以下任一項，先向使用者追問，不要自行補寫：
   - 生效日期
   - 恢復上班日期
   - 留守部門名稱

3. 以正式、簡潔、明確的語氣撰寫公告信，內容必須包含：
   - 主旨：清楚點出防颱停班停課公告
   - 開頭：說明因應颱風或天候狀況，發布內部通知
   - 生效日期：明確寫出何時開始生效
   - 恢復上班日期：明確寫出何時恢復正常上班/上課
   - 留守部門：列出需要留守的部門名稱
   - 結尾：提醒同仁留意後續通知，並保持聯繫暢通

4. 寫作時遵守以下原則：
   - 用詞正式，不使用口語或情緒化表達
   - 日期與時間要寫完整，避免模糊
   - 留守部門名稱要獨立列示，避免埋在段落中不易辨識
   - 若使用者未提供其他細節，不要自行加入不存在的政策或規定

# 建議格式
- 主旨：防颱停班停課公告
- 內文：
  - 因應颱風影響，公告自【生效日期】起停班停課。
  - 預計於【恢復上班日期】恢復正常上班。
  - 需留守部門：
    - 【部門名稱 1】
    - 【部門名稱 2】
  - 請同仁留意後續通知，並保持聯繫暢通。

# 輸出要求
- 直接輸出可使用的公告信草稿。
- 若資訊不足，先列出需要補充的項目，再等待使用者提供。
