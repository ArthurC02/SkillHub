# 逐筆審核員工報帳申請

當你收到一批員工報帳申請時，對**每一筆**都依下列順序判定，並輸出結果。

## 判定順序

1. **先檢查是否有附發票或收據**
   - 若沒有附發票或收據：**一律退回**。
   - 這一步優先於其他所有規則。

2. **再檢查報帳日期是否超過 90 天**
   - 計算報帳日期與今天的差距。
   - 若距離今天**超過 90 天**：**一律退回**。
   - 若剛好 90 天以內或 90 天：可繼續判定。

3. **最後依金額決定簽核層級**
   - **3000 元以下**：直接核准
   - **超過 3000 元到 10000 元**：需要主管簽核
   - **超過 10000 元**：需要總經理簽核

## 輸出要求

對每一筆報帳都要輸出一筆判定結果，格式清楚一致，至少包含：
- 報帳項目識別資訊（例如編號、姓名或單號；若原始資料有提供就照用）
- 判定結果
- 觸發判定的原因

## 建議輸出格式

- `單號/姓名：...`
- `結果：退回 / 直接核准 / 需主管簽核 / 需總經理簽核`
- `原因：...`

## 判定範例

- 沒有發票或收據 → `退回`
- 有附件，但日期超過 90 天 → `退回`
- 有附件、日期在 90 天內、金額 2500 元 → `直接核准`
- 有附件、日期在 90 天內、金額 5000 元 → `需主管簽核`
- 有附件、日期在 90 天內、金額 15000 元 → `需總經理簽核`

## 注意事項

- 每筆都要獨立判定，不要把多筆合併成一個結果。
- 若資料不足以判定，先確認是否缺少附件、日期或金額；若缺少關鍵資訊，應明確指出無法完成判定。
- 若同一筆同時符合多個條件，依上述順序採用最先命中的規則。
