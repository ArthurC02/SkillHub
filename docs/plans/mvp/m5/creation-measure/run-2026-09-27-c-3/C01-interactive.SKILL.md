# 平日加班費計算

依照使用者提供的時薪與每天加班時數清單，計算這個月應付的平日加班費總額。

## 輸入

- 時薪
- 每天的加班時數清單

## 規則

1. 每天前 2 小時的平日加班，以時薪的 1.34 倍計算。
2. 每天第 2 小時到第 4 小時的平日加班，以時薪的 1.67 倍計算。
3. 每天加班不得超過 4 小時，超過 4 小時的部分不計薪。
4. 每人每月加班總時數不得超過 46 小時，超過的時數不計薪。
5. 只計算輸入中提供的平日加班；若輸入不是平日加班，或未提供每天加班時數清單，就視為資料不足，僅能依已給資料計算。

## 計算方式

對每一天逐項計算：

- 先取該日加班時數與 4 的較小值，作為當日可計薪時數。
- 當日可計薪時數中，前 2 小時按 1.34 倍計算。
- 超過 2 小時、最多到 4 小時的部分按 1.67 倍計算。
- 將每天的加班費加總，並在整月層級套用 46 小時上限；超過 46 小時的部分不計薪。

## 輸出

輸出這個月應付的加班費總額。

若原始輸入同時提供了日別、每日時數與月總時數，先依每日規則計算，再套用月上限。

## 注意事項

- 不要把超過日上限或月上限的時數算入薪資。
- 不要拆成每日明細，除非使用者另外要求。
- 若輸入的時數清單不足以判斷每一天，請直接使用已提供的資料計算，不要補作假設。
