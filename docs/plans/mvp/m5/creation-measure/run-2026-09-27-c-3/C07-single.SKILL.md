# 目的
用來檢查員工出差報帳明細是否算對：先把每天的花費加總，再把每日小計彙總成整體總額，最後比對員工填寫的總計是否一致。

# 適用情境
- 使用者提供出差報帳明細、每日費用表、或報帳單據整理表。
- 需要人工或半自動核對金額是否正確。
- 需要指出差異、缺漏、重複計算或算術錯誤。

# 工作流程
1. **確認資料範圍**
   - 找出每一天的費用項目、金額、幣別，以及員工填寫的總計。
   - 若有多種幣別，先不要混算；分幣別核對，或先依文件規則換算後再加總。
   - 若有稅金、服務費、代墊、補助、預支或扣款，確認是否應納入總計。

2. **逐日加總**
   - 對每一天的所有可計入項目逐筆相加。
   - 若同一天有分項小計，先核對分項小計，再核對當日總額。
   - 若有日期缺漏、空白列、或金額欄位不清楚，標記為待確認，不要自行猜測。

3. **彙總整體總額**
   - 將所有日期的每日總額加總，得到報帳明細的整體總額。
   - 若文件本身有「每日合計」與「全部合計」兩層，兩者都要核對。

4. **比對員工填寫的總計**
   - 將你算出的整體總額與員工填寫的總計逐一比對。
   - 若一致，明確回覆「一致」。
   - 若不一致，列出差額：
     - 算出總額
     - 員工填寫總計
     - 差額（算出總額 - 員工總計）

5. **檢查常見錯誤**
   - 重複列入同一筆費用。
   - 漏算某一天或某一項。
   - 小計與明細不一致。
   - 把不應計入的項目算進總計。
   - 四捨五入或小數位處理不一致。

6. **輸出結果**
   - 先給結論：一致 / 不一致 / 無法確認。
   - 再列出核對過程：
     - 每日金額
     - 每日小計
     - 整體總額
     - 員工填寫總計
     - 差額（如有）
   - 若有待確認項目，單獨列出需要補資料的地方。

# 建議輸出格式
- 結論：一致 / 不一致 / 無法確認
- 每日加總：
  - YYYY-MM-DD：A + B + C = X
- 整體總額：X
- 員工填寫總計：Y
- 差額：X - Y = Z
- 備註：重複、缺漏、幣別、稅費或其他異常

# 注意事項
- 不要自行補齊缺失金額。
- 不要把不明確的數字當成 0。
- 若文件格式混亂，先整理成日期、項目、金額三欄再計算。
- 若使用者只提供圖片或掃描檔，且數字無法辨識，應明確說明無法可靠核對，並請對方提供可讀文字或更清晰影像。
