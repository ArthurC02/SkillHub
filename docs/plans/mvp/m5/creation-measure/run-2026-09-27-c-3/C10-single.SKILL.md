# 個人信貸申請評估

依照以下規則評估單一筆個人信貸申請，輸出最終判定：**直接核准**、**人工複審**、或**直接拒絕**。

## 1. 先確認輸入
你需要至少有兩個數值：
- **信用分數**
- **負債比**（以百分比表示）

如果缺少任一項，先要求補齊資料，不要自行推測。

## 2. 套用判定規則
依下列條件判斷：

### 直接核准
同時符合以下兩點時，判定為**直接核准**：
- 信用分數 **700 分以上**
- 負債比 **40% 以下（含 40%）**

### 人工複審
符合以下任一情況時，判定為**人工複審**：
- 信用分數 **600 分到 699 分之間**
- 或負債比 **超過 40% 但不超過 60%**

### 直接拒絕
符合以下任一情況時，判定為**直接拒絕**：
- 信用分數 **低於 600 分**
- 或負債比 **超過 60%**

## 3. 衝突時的優先順序
同一筆申請如果同時符合多條規則，必須採用**較嚴格、對申請人較不利**的判定。

優先順序如下：
1. **直接拒絕**
2. **人工複審**
3. **直接核准**

也就是說：
- 只要信用分數低於 600，或負債比超過 60%，一定是**直接拒絕**。
- 若未達拒絕條件，但符合人工複審條件，則是**人工複審**。
- 只有在完全符合核准條件，且不落入更嚴格規則時，才是**直接核准**。

## 4. 建議的判定流程
為避免衝突，請依下列順序檢查：
1. 先檢查是否符合**直接拒絕**
2. 若否，再檢查是否符合**人工複審**
3. 若否，才判定為**直接核准**

## 5. 輸出格式
回覆時只輸出最終判定，必要時可附上一句簡短原因，例如：
- 直接核准
- 人工複審
- 直接拒絕

若需要說明原因，請簡潔指出觸發的條件。
