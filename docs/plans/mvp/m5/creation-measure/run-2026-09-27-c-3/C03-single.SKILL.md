# 目的
將客戶訂購 email 內容整理成結構化清單，至少包含：
- 訂購品項
- 數量
- 單價
- 收件地址

## 適用情境
當輸入是一封或多封訂購 email，內容可能是自由文字、條列、表格、轉寄內容或混合格式時，使用此技能。

## 處理步驟
1. **先辨識信件內容中的訂單資訊**
   - 找出所有明確提到的商品名稱、型號、規格或品項描述。
   - 找出每個品項對應的數量。
   - 找出每個品項對應的單價；若信件只提供總價，則不要自行推算單價，改為標示「未提供」。
   - 找出客戶指定的收件地址。

2. **處理不同寫法**
   - 若同一品項出現多次，合併為同一筆，並加總數量；若單價不同，保留原文中可辨識的價格資訊並註明不一致。
   - 若數量以「2箱」「3組」「1打」等單位表示，原樣保留單位，不要擅自換算。
   - 若價格含幣別，保留幣別；若未標示幣別，原樣記錄。
   - 若地址分散在多行，合併成完整地址。

3. **資訊不足時的處理**
   - 找不到品項、數量、單價或地址時，填寫「未提供」或「無法辨識」。
   - 不要根據常識補寫缺漏資訊。
   - 不要猜測收件人姓名、電話或地址細節。

4. **輸出格式**
   - 以清單方式輸出，每個品項一列。
   - 建議欄位順序如下：
     1. 品項
     2. 數量
     3. 單價
     4. 收件地址
   - 若同一封信有多個收件地址，先列出主要收件地址；若無法判定主要地址，列出全部地址並註明「需確認」。

## 輸出原則
- 只整理信件中明確存在的資訊。
- 保留原文中的關鍵字、數字、單位與地址格式。
- 若信件包含備註、交期、聯絡方式等非必要資訊，可忽略，除非它有助於判定品項或地址。
- 若內容混雜多筆訂單，分開整理成多個清單區塊，並標示各自來源。

## 建議輸出範例格式
- 品項：A 商品
  - 數量：2
  - 單價：NT$100
  - 收件地址：台北市信義區...
- 品項：B 商品
  - 數量：1
  - 單價：未提供
  - 收件地址：台北市信義區...
