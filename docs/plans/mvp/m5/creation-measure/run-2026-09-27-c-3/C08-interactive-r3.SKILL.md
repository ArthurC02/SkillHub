# 防颱停班停課內部公告信撰寫 Skill

## 目的
根據使用者提供的防颱停班停課資訊，直接撰寫一封可用於公司內部發布的正式公告信。當使用者要通知同仁停班停課、安排留守部門、說明生效日期與恢復上班日期時，使用這個 Skill。

## 你要做的事
1. 讀取使用者輸入中的決議內容、停班停課適用資訊、生效日期、恢復上班日期、需要留守的部門名稱，以及補充說明。
2. 產出一封中文、正式、清楚的內部公告信。
3. 信件中一定要明確寫出：
   - 生效日期
   - 恢復上班日期
   - 需要留守的部門名稱
4. 若使用者提供多個留守部門，必須全部列出。
5. 若使用者提供補充說明，將其自然整合進公告內容。
6. 若必要資訊缺少，先用使用者已提供的內容完成信件，並明確標示尚缺哪些必要資訊；不要編造未提供的日期、部門或決議細節。
7. 如果輸入缺少生效日期、恢復上班日期或需要留守的部門名稱，先列出已提供的內容，再用獨立一段明確標示缺少哪些必要資訊；缺少幾項就列幾項，且不得改寫成已提供。

## 寫作原則
- 語氣保持正式、內部公告、清楚可執行。
- 標題要像企業公告，不要口語化。
- 內文要簡潔，優先讓同仁快速看懂何時生效、何時恢復、哪些部門留守。
- 不要替使用者判定法規或政策正當性；只負責整理與撰寫公告文字。
- 不要加入未提供的事實；凡是缺少的日期、部門、決議內容，直接寫成「未提供」或「尚未提供」，並提示使用者補齊。

## 輸出格式
請直接輸出可發送的公告信正文，建議包含以下結構：

- 標題
- 稱呼或開頭
- 公告主文
- 生效日期說明
- 恢復上班日期說明
- 留守部門說明
- 補充提醒
- 結尾

## 內容處理規則
- 如果使用者提供的是「停止上班上課」或類似措辭，保留其意思並轉成正式公告語氣。
- 如果使用者只提供部分日期，先將已有資訊寫入公告，缺少部分在文末清楚列出。
- 如果使用者提供的日期格式不一致，維持原文或轉成一致、可讀的格式，但不要改動日期含義。
- 如果使用者提供多個部門名稱，使用頓號或逗號清楚分隔。
- 若有補充提醒，例如保持手機暢通、留意公司公告，可放在公告末段。

## 注意事項
- 不要問一串問題；直接產出可用公告。
- 不要臆測決議來源、發文單位、法規依據，除非使用者有明確提供。
- 若使用者要求的內容與現有資訊不足，先完成能完成的部分，再在文末以清單明確列出缺少的必要資訊；若缺少的是生效日期、恢復上班日期或需要留守的部門名稱，必須逐項指出。
- 這個 Skill 的目標是讓使用者能直接拿去發送，因此輸出要完整成稿，不要只給摘要或草稿提綱。
