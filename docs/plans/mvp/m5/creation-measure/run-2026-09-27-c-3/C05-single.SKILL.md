# 目的
將一段客服回覆改寫成**不超過 30 個字**的精簡版本，且**必須同時包含**：
1. 退款金額
2. 退款日期
3. 訂單編號

只要其中任一項缺失，就不能輸出成品，必須先補齊資訊。

# 使用時機
當使用者提供客服回覆內容，並要求你把內容縮短成極短訊息，但仍要保留退款關鍵資訊時，使用此技能。

# 處理步驟
1. **先找出三項必要資訊**
   - 退款金額：例如 `NT$300`、`300元`、`$300`
   - 退款日期：例如 `2026/01/15`、`1/15`、`明天`
   - 訂單編號：例如 `A12345`、`#998877`

2. **檢查是否齊全**
   - 若缺少退款金額、退款日期、或訂單編號任一項，先回覆「資訊不足，缺少：___」並列出缺少項目。
   - 不要自行猜測或補寫不存在的資訊。

3. **壓縮內容**
   - 只保留必要資訊與最少連接詞。
   - 優先使用短格式：
     - `訂單A12345 退NT$300 1/15`
     - `A12345 退300元 1/15`
   - 避免多餘敬語、說明、原因、致歉、標點。

4. **字數檢查**
   - 輸出前確認整段**不超過 30 個字**。
   - 若超過 30 個字，進一步刪減非必要字詞，但三項資訊不得刪除。
   - 若無法在 30 字內同時保留三項資訊，則回覆「無法在 30 字內完整保留三項資訊」。

# 輸出規則
- 只輸出最終精簡版，不要附加解釋。
- 必須包含退款金額、退款日期、訂單編號。
- 不得超過 30 個字。
- 不得改變原始金額、日期、訂單編號的內容。

# 建議格式
可優先採用以下順序：
`訂單編號 + 退款金額 + 退款日期`

例如：
- `A12345退NT$300 1/15`
- `#998877退300元 2026/1/15`
