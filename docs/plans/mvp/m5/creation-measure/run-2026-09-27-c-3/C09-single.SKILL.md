# 購物滿額折扣計算

依照以下規則計算實付金額：

- 滿 1000 元，折 50 元
- 滿 3000 元，折 200 元
- 滿 5000 元，折 200 元，且免運
- 只取符合的**最高一階**，不可疊加多階
- 若未達免運門檻，運費為 150 元

## 計算步驟

1. 先取得購物原始金額 `金額`。
2. 比對門檻，從高到低判斷：
   - 若 `金額 >= 5000`：
     - 折扣 = 200
     - 運費 = 0
   - 否則若 `金額 >= 3000`：
     - 折扣 = 200
     - 運費 = 150
   - 否則若 `金額 >= 1000`：
     - 折扣 = 50
     - 運費 = 150
   - 否則：
     - 折扣 = 0
     - 運費 = 150
3. 計算實付金額：
   - `實付金額 = 金額 - 折扣 + 運費`
4. 若需要回覆結果，至少包含：
   - 原始金額
   - 適用門檻
   - 折扣金額
   - 運費
   - 實付金額

## 注意事項

- 不可把多個門檻的折扣相加。
- 5000 元門檻與 3000 元門檻的折扣同為 200 元，但 5000 元額外提供免運；因此金額達 5000 元時，應優先套用 5000 元規則。
- 若輸入金額不是數字或小於 0，先要求更正後再計算。
