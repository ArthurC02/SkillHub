## 目的
每週從三個 Slack 頻道中找出「未回覆的問題」，整理成可追蹤的清單，並附上每則訊息的連結。

## 適用範圍
- 只處理使用者指定的三個 Slack 頻道。
- 只列出「問題」且「尚未回覆」的訊息。
- 若無法直接存取 Slack 或無法取得頻道內容，明確說明需要哪些頻道名稱、時間範圍或匯出資料，並停止，不要臆測。

## 判定規則
1. **問題**：訊息內容是在提問、請求協助、尋求確認、或明顯需要他人回應。
2. **未回覆**：該訊息下方沒有任何回應，包含：
   - 沒有 thread reply
   - 沒有明確的文字回覆
   - 沒有被同頻道內其他人直接回答
3. **排除項目**：
   - 已經有人回覆的問題
   - 純公告、純資訊分享、非提問內容
   - 只有表情符號反應、沒有文字回覆的訊息，仍視為未回覆
4. **重複問題**：若同一問題被多次貼出，保留最早且最完整的一則，其他可合併註記為重複。

## 作業步驟
1. 取得三個頻道的訊息內容與時間範圍。
2. 逐則找出符合「問題」定義的訊息。
3. 檢查每則問題是否有回覆：
   - thread 中是否有任何文字回應
   - 是否在後續訊息中已被明確回答
4. 只保留未回覆者。
5. 依時間由新到舊或依頻道分組整理；若使用者未指定排序，預設以時間由新到舊。
6. 為每則訊息附上可點擊連結；若原始資料沒有連結，則標示無法提供連結並說明原因。

## 輸出格式
使用清單格式，每則一行，包含以下欄位：
- 頻道名稱
- 發問者
- 發問時間
- 問題摘要
- 連結

範例格式：
- #channel-name｜@user｜2026-09-26 10:15｜如何重設部署環境？｜https://...

## 注意事項
- 不要把已回覆的問題列入。
- 不要自行補答案。
- 不要推測訊息意圖不明的內容；若無法判定是否為問題，先排除並在最後附上「待確認」項目。
- 若資料不足以判定是否回覆，將該項目列入「待確認」，不要直接當作未回覆。
