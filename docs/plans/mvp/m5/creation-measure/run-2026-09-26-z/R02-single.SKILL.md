# 目的
清理 Excel 客戶名單：去除重複資料，並標記缺少電話的列。

# 適用情況
當使用者提供的是 Excel 名單，且需求包含：
- 找出並移除重複客戶
- 標記電話欄位空白或缺失的列

# 執行步驟
1. **確認欄位結構**
   - 找出客戶名單中代表「客戶識別」的欄位，通常是姓名、公司名、Email、電話或其組合。
   - 找出電話欄位名稱，確認哪些儲存格屬於缺少電話。
   - 如果欄位名稱不明確，先根據表頭判斷；若仍無法判斷，回覆需要使用者指定哪一欄是電話欄。

2. **定義重複判斷規則**
   - 優先使用最能唯一識別客戶的欄位組合，例如：
     - Email
     - 電話
     - 姓名 + 公司名
   - 若資料中已有明確的唯一 ID，則以該欄為準。
   - 若無法安全判斷重複依據，先詢問使用者要以哪些欄位判定重複，避免誤刪。

3. **去除重複資料**
   - 依照已確認的重複判斷規則，找出重複列。
   - 保留第一筆出現的資料，或依使用者指定的保留規則保留最新/最完整的一筆。
   - 刪除其餘重複列，並確保表頭不受影響。

4. **標記缺少電話的列**
   - 在原表新增一欄，例如「電話狀態」或「缺少電話」。
   - 對電話欄為空白、只有空格、或明顯缺值的列，標記為「缺少電話」。
   - 其餘列標記為「正常」或留空，依使用者需求一致處理。

5. **檢查結果**
   - 確認重複列已移除。
   - 確認所有電話缺失的列都已被標記。
   - 檢查是否有因格式差異造成的誤判，例如：
     - 電話欄含空白字元
     - 同一客戶以不同大小寫或不同格式出現
     - 合併儲存格或空白列

6. **輸出整理後的檔案**
   - 保留原始資料結構與欄位順序，除非需要新增標記欄。
   - 若有新增標記欄，將其放在表格末端或電話欄旁邊，保持易讀。
   - 回覆時簡要說明：
     - 移除了多少筆重複資料
     - 標記了多少筆缺少電話的列

# 注意事項
- 不要在未確認重複規則前直接刪除資料。
- 若電話欄名稱不明、資料格式混亂，先請使用者確認欄位定義。
- 若只能提供操作建議而無法直接編輯檔案，請明確說明需要使用者上傳 Excel 檔或指定欄位。
