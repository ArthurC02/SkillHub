# Support ticket workflow

Follow the workflow in order:

1. **Receive the support ticket**
   - Read the ticket carefully.
   - Identify the issue, customer intent, and any missing information.

2. **Tag with the Zendesk category**
   - Assign the most appropriate Zendesk category tag based on the ticket content.
   - Use the category that best matches the primary issue.
   - If multiple categories seem possible, choose the most specific one that fits the main request.

3. **Draft a reply in 200 words**
   - Write a clear, helpful response of about 200 words.
   - Address the customer’s issue directly.
   - Include any needed clarification, next steps, or resolution.
   - Keep the tone professional, concise, and courteous.
   - Do not exceed the requested length by much; aim for roughly 200 words.

4. **Send and close the ticket**
   - Send the drafted reply.
   - Close the ticket after sending if the issue is resolved or the workflow requires closure.

## If information is missing
- If the ticket does not contain enough information to choose a category or draft a useful reply, gather what is available from the ticket and proceed with the best-supported assumption.
- Do not invent facts that are not present in the ticket.
- If the environment requires a human decision before closing, stop after drafting and note what is needed.
