## 目標
將一份英文使用手冊完整翻成繁體中文，並在專有名詞第一次出現時附上原文，之後維持一致譯法。

## 翻譯原則
1. 保留原手冊的章節順序、標題層級、編號、表格、清單、警告、註解與圖說格式。
2. 以繁體中文為主，語氣自然、清楚、符合說明文件風格。
3. 專有名詞、產品名稱、功能名稱、按鈕名稱、介面項目、縮寫與技術術語：
   - 第一次出現時寫成「中文譯名（原文）」或「原文（中文譯名）」；
   - 之後全文使用同一中文譯名；
   - 若原文本身就是品牌、型號或不可翻譯名稱，保留原文並在首次出現時補充必要說明。
4. 不要自行增刪內容；若原文含有不完整、模糊或疑似錯字，忠實翻譯並在必要時保留原貌。
5. 數字、單位、路徑、按鍵組合、錯誤訊息、命令列指令、程式碼、變數名稱與檔名：
   - 保留原樣；
   - 只翻譯周邊說明文字。
6. 若手冊中有安全警告、注意事項或法規聲明，需完整保留其語氣與重要性，不可弱化。

## 專有名詞處理
1. 先建立術語一致性：同一名詞在全文使用同一譯法。
2. 首次出現格式建議：
   - 中文譯名（Original Term）
   - 或 Original Term（中文譯名）
3. 若同一頁或同一段落重複出現，避免重複附原文，除非有助於消歧義。
4. 若遇到縮寫：首次出現先寫全名加縮寫，例如「隨機存取記憶體（RAM）」；後續只用縮寫或中文譯名，依原文慣例一致處理。

## 翻譯流程
1. 先通讀整份手冊，辨識：
   - 章節結構；
   - 重複術語；
   - 專有名詞；
   - 表格、步驟、警告與註解。
2. 建立術語對照，確保同一詞彙前後一致。
3. 逐段翻譯，優先保持原意與操作指示的準確性。
4. 翻完後檢查：
   - 是否保留所有標題與編號；
   - 是否所有首次出現的專有名詞都有附原文；
   - 是否命令、按鍵、路徑、型號未被誤譯；
   - 是否語句通順且符合繁體中文文件風格。

## 輸出要求
1. 只輸出翻譯後的繁體中文內容。
2. 不要加入額外說明、註解或翻譯策略說明。
3. 若原文有圖片標註、表格標題或腳註，也一併翻譯並維持位置與格式。
