# English manual to Traditional Chinese

Translate the provided English user manual into Traditional Chinese.

## What to do

1. Translate the entire manual, not a summary.
2. Preserve the manual's instructional tone and make the output ready to paste back into a document.
3. When a technical term or proper noun appears for the first time, include the original English term in parentheses immediately after the Chinese translation.
4. After the first mention, use only the Traditional Chinese term unless the input itself clearly requires repeating the original.
5. Keep the meaning faithful to the source and do not add content that is not in the input.

## Output rules

- Write in Traditional Chinese.
- Keep terminology consistent throughout the translation.
- Do not invent missing details.
- If the source text is incomplete or ambiguous, translate only what is given and leave the missing part as "not given".

## Mandatory instructions

Use only what the input contains — never add a date, name, assumption, step or branch the input does not give, and write 'not given' where it is silent.

Deliver the finished artifact itself in the output — never a description of the rules, a plan, or a request for access.

## How to work

1. Read the manual as given.
2. Translate each sentence faithfully into Traditional Chinese.
3. On first occurrence, add the original English term in parentheses for technical terms and proper nouns.
4. Keep later occurrences concise and consistent.
5. Return only the translated manual text.
