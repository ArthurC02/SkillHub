# 目的
將一週內的每日花費整理成清楚的表格，為每筆支出標上類別，並在週末計算各類別合計與總計。

# 適用情境
- 使用者提供一週的花費明細，要求整理成表格。
- 使用者要求每筆支出分類。
- 使用者要求週末做各類別加總、週報或週結算。

# 工作流程
1. **先確認資料是否完整**
   - 檢查是否有一週內每天的花費明細。
   - 若缺少日期、金額或用途，先列出缺漏項目並請使用者補充。
   - 若使用者沒有指定分類規則，依支出內容自行歸類，但要保持一致。

2. **建立每日明細表**
   - 以日期為主軸列出每筆花費。
   - 每筆至少包含：
     - 日期
     - 項目/用途
     - 金額
     - 類別
   - 若同一天有多筆支出，逐筆列出，不要合併。

3. **標註類別**
   - 依支出內容將每筆歸入最合適的類別。
   - 類別名稱要簡潔一致，例如：
     - 餐飲
     - 交通
     - 購物
     - 生活用品
     - 娛樂
     - 醫療
     - 其他
   - 若無法明確分類，使用「其他」，並在需要時註明原因。

4. **計算週末彙總**
   - 將整週所有支出依類別加總。
   - 同時計算：
     - 各類別合計
     - 全週總支出
   - 若有需要，也可補充每日小計，但重點是週末各類別合計。

5. **輸出格式**
   - 先輸出「每日明細表」。
   - 再輸出「週末類別合計表」。
   - 表格欄位建議如下：
     - 每日明細表：日期｜項目｜類別｜金額
     - 類別合計表：類別｜合計金額
   - 金額格式保持一致，必要時保留到整數或小數點後兩位。

# 規則
- 同一筆支出只能歸入一個主要類別，避免重複計算。
- 若使用者提供的分類名稱與常見類別不同，優先沿用使用者的分類名稱。
- 若資料跨越多週，只處理指定的一週；若未指定，先請使用者確認週期。
- 若金額單位不一致，先統一單位再計算。

# 建議輸出範例結構
## 每日明細
| 日期 | 項目 | 類別 | 金額 |
|---|---|---:|---:|
| 週一 | 早餐 | 餐飲 | 50 |
| 週一 | 公車 | 交通 | 30 |

## 週末類別合計
| 類別 | 合計金額 |
|---|---:|
| 餐飲 | 350 |
| 交通 | 120 |
| 其他 | 80 |
| **總計** | **550** |

# 注意事項
- 不要自行捏造不存在的花費。
- 若資料不足以完成分類或加總，先說明缺少哪些資訊，再請使用者補充。
