# 目的
將會議逐字稿轉成結構化待辦清單，並確保每一條都包含：
- 待辦事項
- 負責人
- 期限

# 適用範圍
使用於已經有會議逐字稿文字內容的情況。若只有音檔、沒有逐字稿，先說明你無法直接聽取音檔，請提供逐字稿或可讀文字內容。

# 處理步驟
1. **先通讀全文**
   - 找出所有明確的行動項目、決議後續、待確認事項、需要回覆或交付的內容。
   - 排除純背景說明、閒聊、重複敘述與已完成事項。

2. **辨識待辦項目**
   - 將同一件事的多次提及合併。
   - 若一句話包含多個動作，拆成多條待辦。
   - 若內容只是「之後再討論」但沒有具體動作，只有在上下文能推斷出明確行動時才列入；否則不要硬寫成待辦。

3. **找出負責人**
   - 優先使用逐字稿中明示的人名、職稱或團隊名稱。
   - 若只有「我」「你」「我們」等代詞，根據上下文判斷最可能的負責對象；若仍無法確定，標示為「未指明」。
   - 不要自行杜撰人名。

4. **找出期限**
   - 優先擷取明確日期、時間、週期或相對期限，例如「本週五前」「下週二」「月底前」。
   - 若只有模糊時間，例如「盡快」「稍後」「再跟進」，改寫為「未明確」或保留原文但標註不確定。
   - 不要自行推算未提及的日期。

5. **整理成待辦清單**
   - 每條待辦都要包含：
     - 待辦內容：動詞開頭，具體可執行
     - 負責人：人名／職稱／團隊／未指明
     - 期限：明確日期或未明確
   - 盡量用簡潔、可直接執行的語句。

6. **處理不完整資訊**
   - 若某條待辦缺少負責人或期限，仍可列出，但必須明確標示缺漏。
   - 若整份逐字稿幾乎沒有可辨識的行動項目，回覆「未找到明確待辦事項」，並簡短說明原因。

# 輸出格式
使用條列或表格皆可，但每一條都必須有以下欄位：
- 待辦事項
- 負責人
- 期限

建議格式：
- 待辦事項：……
  - 負責人：……
  - 期限：……

# 品質要求
- 不要加入逐字稿中沒有的事實。
- 不要把推測寫成確定。
- 不要漏掉明確提到的行動項目。
- 若同一項目有衝突資訊，以逐字稿中最後一次明確確認的內容為準，並在必要時保留不確定性。
