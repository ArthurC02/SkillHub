name: webpage-text-change-checklist
description: Use this skill when you need a checklist to compare a webpage’s current visible text against a known baseline and detect whether the page content has changed. It is suitable when the source page is provided but live verification or browsing may not be available.
---

# 目的
根據指定頁面的**實際可見文字**，整理一份可供人工比對的檢查清單，用來判斷頁面內容是否被改過。

# 先確認可行性
- 如果你**無法直接讀取該頁面的實際內容**，就不要假裝已經看過頁面。
- 這種情況下，先明確說明：需要先取得頁面目前的文字內容、截圖，或 HTML 來源，才能產出可用的比對清單。
- 如果已經提供了頁面文字、截圖或 HTML，則依可取得的內容整理清單。

# 產出原則
- 只根據頁面**實際出現的文字**寫清單，不要加入推測、背景知識或額外解讀。
- 清單要讓人能逐項核對「現在看到的內容」是否與基準一致。
- 優先保留頁面上的原文措辭、標題層級、段落順序、連結文字、按鈕文字、表格欄位名稱、列表項目。
- 若頁面有明顯區塊，按區塊分組，方便人工檢查。

# 製作步驟
1. 讀取頁面中所有可見文字。
2. 依內容結構分成幾個區塊，例如：
   - 頁首/導覽
   - 主標題與副標題
   - 主要段落
   - 清單
   - 表格
   - 按鈕/連結
   - 頁尾
3. 對每個區塊列出可核對項目，格式要具體，例如：
   - 標題文字是否仍為「…」
   - 第 1 段是否仍包含「…」
   - 按鈕文字是否仍為「…」
   - 連結文字是否仍為「…」
   - 表格欄位是否仍為「…、…、…」
4. 若頁面有數字、日期、價格、版本號、聯絡資訊、版權文字，務必單獨列出，因為這些最容易被改動。
5. 若頁面有重複出現的文字，標明位置或順序，避免比對時混淆。
6. 若頁面內容很少，就直接列出逐條核對項；若內容很多，就按區塊整理成層級式清單。

# 建議的清單格式
使用以下格式輸出，讓人容易勾選：

- [ ] 頁面標題仍為「…」
- [ ] 副標題仍為「…」
- [ ] 第一段文字仍包含「…」
- [ ] 第二段文字仍包含「…」
- [ ] 主要按鈕文字仍為「…」
- [ ] 導覽連結文字仍為「…」
- [ ] 表格欄位名稱仍為「…」
- [ ] 頁尾版權文字仍為「…」

# 判斷是否被改過時要注意
- 文字增刪
- 文字順序改變
- 標題層級改變
- 連結或按鈕文字改變
- 數字、日期、版本、價格改變
- 同一段文字被替換成不同措辭
- 區塊消失或新增

# 如果頁面內容無法辨識
- 直接說明頁面文字無法可靠辨識，無法產出精準比對清單。
- 建議改用：頁面文字擷取、HTML 原始碼、或清晰截圖後再整理。
