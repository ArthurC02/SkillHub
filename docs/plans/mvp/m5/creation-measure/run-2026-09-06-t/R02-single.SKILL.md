# Excel 客戶名單去重與缺電話標記

當你收到一份 Excel 客戶名單，需要**去除重複資料**並**標記缺少電話的列**時，依照以下流程處理。

## 1. 先確認欄位
- 找出哪一欄是「客戶識別欄位」：通常是姓名、公司名、Email、客戶編號，或多欄組合。
- 找出電話欄位名稱。
- 如果沒有明確指定去重依據，優先使用：
  1. 客戶編號
  2. Email
  3. 姓名 + 公司名
  4. 姓名 + 電話
- 若仍無法判定，先回覆需要使用者指定去重規則，不要自行猜測。

## 2. 建立處理前備份
- 先複製原始工作表，保留一份未修改版本。
- 在新工作表或新檔案中進行清理，避免覆蓋原始資料。

## 3. 去除重複
- 以確認好的去重依據判斷重複列。
- 若是單一欄位去重，保留第一筆出現的資料，刪除後續重複列。
- 若是多欄組合去重，只有當指定欄位組合完全相同時才視為重複。
- 去重後，確認剩餘筆數是否合理，並保留一份重複處理結果的記錄（例如重複列數量）。

## 4. 標記缺少電話的列
- 檢查電話欄是否為空白、只有空格、或是缺值。
- 在電話欄旁新增一欄，例如「電話狀態」或「缺電話標記」。
- 對缺少電話的列填入明確標記，例如：`缺少電話`。
- 對有電話的列可填入：`正常`，或留空，但整份檔案需一致。

## 5. 檢查資料品質
- 確認去重後沒有誤刪。
- 確認所有缺電話列都已標記。
- 若電話欄有格式不一致，僅在任務要求範圍內做最小必要整理，不要擅自改寫電話內容。

## 6. 輸出結果
- 交付已去重、且已標記缺電話的 Excel 檔。
- 若需要摘要，提供：
  - 原始筆數
  - 去重後筆數
  - 重複刪除筆數
  - 缺少電話筆數

## 7. 若資訊不足時要先詢問
在以下情況下，不要直接處理，先向使用者確認：
- 不知道要用哪個欄位或哪些欄位去重
- 電話欄位名稱不明
- 檔案中有多個工作表且不確定要處理哪一個
- 使用者要求保留重複資料但只做標記，或要求刪除重複的規則與上述不同
