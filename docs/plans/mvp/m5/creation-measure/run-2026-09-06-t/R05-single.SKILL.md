# 目標
將一週內的每日花費整理成清楚的表格，為每筆支出標上類別，並在週末計算各類別合計。

# 適用情境
- 使用者提供一週的支出明細、日記式記錄、聊天訊息或條列清單。
- 使用者要把零散花費變成可讀的週報表。
- 使用者要看每一天與每一類別的總花費。

# 處理流程
1. **先辨識資料範圍**
   - 找出是否涵蓋一週 7 天。
   - 若日期不完整，依使用者提供的日期順序整理；若沒有日期，依輸入順序視為一週內的記錄。
   - 若有金額但缺少日期、品項或類別，先保留原文並標記為待確認。

2. **抽取每筆花費**
   - 每筆記錄至少整理出：
     - 日期
     - 項目/用途
     - 金額
     - 類別
   - 若同一天有多筆支出，逐筆列出，不要合併成一筆，除非使用者明確要求。

3. **統一類別**
   - 將相近項目歸入一致類別，例如：
     - 餐飲：早餐、午餐、晚餐、飲料、外送、零食
     - 交通：捷運、公車、計程車、油錢、停車費
     - 生活：日用品、清潔用品、家用耗材
     - 娛樂：電影、遊戲、訂閱、聚會
     - 購物：衣物、配件、非日常採買
     - 醫療：看診、藥品、保健品
     - 其他：無法明確歸類者
   - 若使用者已有指定類別，優先沿用使用者的分類。
   - 若一筆支出可能屬於多個類別，選最主要用途；必要時在備註說明。

4. **建立每日明細表**
   - 以表格呈現，每列一筆支出。
   - 建議欄位：
     - 日期
     - 星期
     - 項目
     - 類別
     - 金額
     - 備註
   - 同一天的支出可依時間或輸入順序排列。

5. **計算每日小計**
   - 每一天加總當日所有支出。
   - 若資料中有退款、退費或負數金額，照原值計入，並在備註標示。

6. **計算週末各類別合計**
   - 將整週所有支出依類別加總。
   - 若需要，也可同時列出：
     - 各類別筆數
     - 各類別平均單筆金額
   - 若使用者只要求合計，至少提供各類別總額。

7. **輸出週總表**
   - 在每日明細後附上兩個摘要：
     - 每日總計表
     - 各類別週合計表
   - 若資料不足以完整計算，清楚指出缺漏項目與影響。

# 輸出格式
使用 Markdown 表格，保持欄位固定且易讀。

## 每日明細表
| 日期 | 星期 | 項目 | 類別 | 金額 | 備註 |
|---|---|---|---|---:|---|
| 2026-01-01 | 四 | 早餐 | 餐飲 | 60 |  |

## 每日總計表
| 日期 | 星期 | 當日合計 |
|---|---|---:|
| 2026-01-01 | 四 | 60 |

## 類別週合計表
| 類別 | 週合計 | 筆數 |
|---|---:|---:|
| 餐飲 | 420 | 7 |

# 計算規則
- 金額以數字計算，不要把貨幣符號混入數值欄位。
- 若輸入含不同幣別，先不要直接混算；分幣別列出並提醒使用者。
- 四捨五入規則要一致；若有小數，保留到小數點後兩位。
- 合計時要檢查是否有重複記錄或明顯異常值，必要時在備註提醒。

# 資料不完整時的處理
- 若缺日期：依輸入順序暫列，並標示「日期未提供」。
- 若缺類別：先歸入「其他」，並在備註寫出原始項目。
- 若缺金額：不要猜測，列為待確認。
- 若同一筆記錄含多個品項與總金額：可拆成多列，前提是使用者有提供可拆分依據；否則保留為單筆並註明。

# 回覆原則
- 先給整理好的表格，再給簡短摘要。
- 摘要只說明總花費、最大類別、缺漏資料與需要確認的地方。
- 不要省略原始資訊；整理時要保留可追溯性。
