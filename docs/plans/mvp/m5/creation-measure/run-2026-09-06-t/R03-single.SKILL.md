# 每日新聞摘要寄信

這個技能的目標是：把三個新聞網站的標題整理成 5 條摘要，並準備成可寄出的電子郵件內容。

## 先確認可行性

這個任務需要兩種外部能力：

1. **即時取得新聞網站內容**
2. **實際寄送電子郵件**

如果目前沒有可用的網路抓取工具、瀏覽工具、或郵件發送工具，請不要假裝已完成。改為：
- 明確說明無法直接完成即時抓取或寄信
- 收集使用者提供的三個新聞網站網址
- 收集收件信箱、寄件方式、寄送時間與時區
- 產出可手動寄送的摘要草稿

## 執行步驟

### 1. 確認輸入
向使用者確認以下資訊：
- 三個新聞網站名稱或網址
- 要抓取的時間範圍：例如「今天早上」或「過去 24 小時」
- 收件人信箱
- 寄件人名稱或寄件帳號顯示名稱
- 是否要固定每天早上寄送，以及具體時間與時區
- 摘要語言：預設使用使用者輸入的語言

如果使用者沒有提供三個網站，先請對方補齊。

### 2. 取得標題
對每個新聞網站：
- 找到首頁、新聞列表頁或最新消息頁
- 擷取可代表當日重點的標題
- 優先保留最新、重複度低、資訊量高的標題
- 若同一事件在多站重複出現，只保留最清楚的一則作為摘要素材

如果某網站無法讀取：
- 記錄原因
- 不要編造標題
- 以其他可讀網站的內容補足，但要在摘要中避免暗示已讀到該站內容

### 3. 整理成 5 條摘要
把三個網站的標題整合成 **5 條** 簡短摘要：
- 每條摘要應該是單一重點
- 優先涵蓋不同主題或不同事件
- 文字要像新聞重點，不要像評論
- 避免過度細節，保留關鍵人物、事件、地點、結果
- 若標題不足以形成 5 條，則用較高層次的主題合併，但不要捏造新事實

建議格式：
- 1 句 1 條
- 每條 15–30 字左右，視語言而定

### 4. 檢查品質
在輸出前檢查：
- 是否剛好 5 條
- 是否沒有重複
- 是否沒有把推測寫成事實
- 是否沒有包含未經確認的內容
- 是否保留了來源可追溯性（至少知道來自哪個網站）

### 5. 組成郵件內容
郵件主旨建議：
- `每日新聞摘要：YYYY-MM-DD`

郵件正文建議包含：
- 簡短開頭
- 5 條摘要
- 來源網站列表
- 若有網站無法讀取，附上簡短說明

範例結構：

```text
早安，以下是今天的新聞摘要：

1. ...
2. ...
3. ...
4. ...
5. ...

來源：
- 網站 A
- 網站 B
- 網站 C
```

### 6. 寄送或交付
- 如果有可用的郵件工具與授權，將郵件寄出
- 如果沒有，輸出完整郵件草稿，讓使用者可直接複製寄送
- 若使用者要求每天自動寄送，但目前沒有排程工具，請說明無法自行排程，並提供可設定排程的建議資訊

## 注意事項

- 不要捏造新聞內容
- 不要把標題改寫成與原意不同的內容
- 不要輸出超過 5 條摘要，除非使用者明確要求更多
- 若新聞網站有付費牆、登入牆或 robots 限制，尊重限制並改用可公開取得的內容
- 若使用者要求「每天早上」但未指定時間，請先詢問具體時間與時區

## 最終輸出
若無法直接寄信，請輸出：
1. 5 條摘要
2. 郵件主旨
3. 郵件正文
4. 來源網站
5. 無法自動寄送或抓取時的原因說明
