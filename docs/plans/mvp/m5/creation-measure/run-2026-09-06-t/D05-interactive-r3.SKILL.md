# 新人到職 onboarding Skill

## 目的
把已確認的新人到職流程整理成一份可重複使用、可直接執行的 Agent Skill。

## 使用時機
當你手上有一份新人到職流程的文字化內容，並且要把它轉成可操作的 Skill 草案時使用。

## 輸入
- 一份已確認的新人到職流程內容。
- 流程中出現的節點名稱與順序。

## 輸出
- 一份完整的 Skill 草案。
- 草案需包含目的、適用情境、輸入、輸出、步驟與限制。
- 草案需保留流程的原始順序。

## 執行步驟
1. 讀取已確認的新人到職流程內容。
2. 依照流程出現的順序整理主要節點。
3. 將每個節點改寫成可執行、可重複使用的 Skill 步驟。
4. 補上目的、使用時機、輸入、輸出與限制。
5. 檢查是否新增了原流程沒有明確表達的分支、例外、制度、時程或責任人。
6. 僅依已確認流程節點整理內容：收到新人到職通知、建立公司信箱、加入 Slack 頻道、準備筆電與門禁卡、安排第一週訓練、指派導師、安排第 30 天面談、記錄到人資系統；不得補寫任何未出現在已確認流程中的分支、例外、失敗、阻塞、升級、特殊權限或替代路徑。
7. 如有缺漏資訊，只能以最保守的一般性說明呈現，不可編造細節。

## 限制
- 不得新增流程圖沒有明確表達的分支、例外、失敗、阻塞、升級、特殊權限、身份類型或替代路徑。
- 不得編造具體制度、時程或責任人。
- 若資訊不足，採最保守的一般性描述。

## 流程節點
- 收到新人到職通知
- 建立公司信箱
- 加入 Slack 頻道
- 準備筆電與門禁卡
- 安排第一週訓練
- 指派導師
- 第 30 天面談
- 記錄到人資系統

## 輸出格式要求
- 先給出 Skill 草案本體。
- 使用清楚的小標題分段。
- 保持內容與已確認流程一致。
