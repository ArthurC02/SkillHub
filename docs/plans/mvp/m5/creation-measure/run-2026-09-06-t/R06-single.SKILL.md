## 目標
將一份英文使用手冊完整翻譯為繁體中文，保留原意、結構與操作順序；專有名詞在第一次出現時以「繁體中文（Original）」呈現，之後可只用中文譯名。

## 工作流程
1. **先確認輸入範圍**
   - 確認是否已提供完整 30 頁內容，或是否需要分批翻譯。
   - 若內容不完整，先請求缺少的頁面或段落，避免漏譯。

2. **保留文件結構**
   - 維持原本的章節、標題層級、編號、項目符號、表格、警告、注意事項與步驟順序。
   - 圖說、按鈕名稱、選單名稱、介面文字、錯誤訊息與欄位名稱都要翻譯；若是產品介面上的固定名稱，第一次出現時附原文。

3. **專有名詞處理**
   - 第一次出現的專有名詞、功能名稱、產品名稱、技術名詞、縮寫：寫成「繁體中文（Original）」。
   - 若縮寫有通用中文譯法，第一次可寫「繁體中文（Original, 縮寫）」或「繁體中文（Original）」；之後統一使用中文譯名或縮寫，保持一致。
   - 若原文本身就是品牌、型號或不可翻譯名稱，保留原文並在必要時加上簡短中文說明。

4. **翻譯原則**
   - 使用自然、正式、清楚的繁體中文，符合使用手冊語氣。
   - 不要逐字硬翻到不通順；優先確保操作說明易懂。
   - 保留數字、單位、型號、路徑、命令、代碼、網址與按鍵名稱的準確性。
   - 若原文有歧義，先依上下文選擇最合理譯法；若仍無法判定，保留原文並加註「原文不明」或請求更多上下文。

5. **一致性檢查**
   - 同一術語在全文使用同一譯名。
   - 檢查步驟編號、表格欄位、警告標示與引用是否完整。
   - 確認首次出現的專有名詞都有附原文。

## 輸出要求
- 只輸出翻譯後的繁體中文內容，不要加入額外說明、摘要或評論。
- 保留原文件的段落與格式；若原文是 Markdown、HTML、表格或條列，盡量維持相同結構。
- 若遇到無法辨識的掃描文字、缺頁或圖片內容無法讀取，明確標示缺失處，不要自行補寫。
