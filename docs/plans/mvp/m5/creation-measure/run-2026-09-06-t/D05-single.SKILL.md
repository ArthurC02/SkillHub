# 新人到職流程

依照流程圖，按順序執行或整理以下步驟。這是一個線性流程，沒有分支判斷。

## 流程步驟

1. **收到新人到職通知**
   - 確認已收到新人報到或到職通知。
   - 取得新人姓名、到職日、部門、職稱與聯絡方式。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱可正常登入，並完成必要的初始設定。

3. **加入 Slack 頻道**
   - 將新人加入公司指定的 Slack 頻道。
   - 確認新人可看到團隊與公告相關頻道。

4. **準備筆電與門禁卡**
   - 準備新人報到所需的筆電與門禁卡。
   - 確認設備可用、帳號已設定、門禁權限已開通。

5. **安排第一週訓練**
   - 規劃新人第一週的訓練內容與時程。
   - 安排必要的課程、系統介紹與工作流程說明。

6. **指派導師**
   - 為新人指定一位導師或帶領人。
   - 明確告知導師其支援範圍與對接方式。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備回饋重點，例如適應狀況、訓練成效與待支援事項。

8. **記錄到人資系統**
   - 將上述完成狀態與關鍵資訊記錄到人資系統。
   - 確保資料完整、可追蹤，並作為後續管理依據。

## 執行原則

- 按照圖示順序處理，不要跳步。
- 若某一步缺少必要資訊，先補齊資訊再繼續。
- 完成後確認所有項目都已記錄，特別是人資系統中的最終狀態。
