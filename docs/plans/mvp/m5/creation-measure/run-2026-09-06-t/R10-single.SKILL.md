## 目的
每週從三個指定的 Slack 頻道中，找出「有問題、但尚未被回覆」的訊息，整理成一份附連結的清單。

## 先確認的資訊
如果沒有明確提供以下資訊，先向使用者確認：
1. 三個 Slack 頻道名稱或連結。
2. 要統計的週期範圍，例如「上週一到週日」或「最近 7 天」。
3. 什麼算「未回覆」：
   - 完全沒有任何回覆
   - 或只有提問者自己補充、但沒有他人回覆
4. 輸出格式偏好：純清單、表格，或依頻道分組。

## 判定原則
1. 只收錄「明確是問題」的訊息，例如包含問句、請求協助、待確認事項。
2. 判定未回覆時，以該訊息下方是否有其他人的回覆為準。
3. 若同一串討論已被回覆，則不列入。
4. 若訊息內容不明確像問題，先排除，除非上下文明顯是在提問。
5. 若一則訊息有多個問題，仍只列一筆，並在摘要中簡述主要問題。

## 操作步驟
1. 逐一檢視三個指定頻道在指定週期內的訊息。
2. 找出符合「問題」且「未回覆」的訊息。
3. 對每則訊息記錄以下資訊：
   - 頻道名稱
   - 發訊者
   - 發訊時間
   - 問題摘要
   - 訊息連結
4. 若同一頻道有多則未回覆問題，依時間由新到舊或依使用者指定排序。
5. 若某頻道沒有未回覆問題，仍要在結果中標示「無」。

## 輸出格式
用清單輸出，每筆一行，格式如下：
- [頻道名稱] 發訊者｜時間｜問題摘要｜連結

若要依頻道分組，則使用：
### 頻道名稱
- 發訊者｜時間｜問題摘要｜連結

## 品質要求
1. 連結必須能直接定位到原始訊息。
2. 摘要要短，保留問題核心，不要改寫成長段落。
3. 不要把已回覆的討論誤列為未回覆。
4. 若無法判定是否回覆，標記為「待確認」，不要自行猜測。
