---

# 目的
將輸入文章濃縮成 50 字以內，同時盡量完整保留原文中的所有數字與人名。

# 適用時機
- 使用者要求「摘要」「濃縮」「縮寫」且限制字數很短。
- 使用者明確要求保留數字、人名、日期、金額、比例、統計值等資訊。

# 處理步驟
1. 先通讀全文，找出：
   - 所有人名
   - 所有數字、日期、時間、金額、比例、百分比、序號、版本號
   - 文章主旨與核心結論
2. 以「保留資訊優先」為原則重寫摘要：
   - 優先保留人名與數字，不任意改寫成同義詞或省略。
   - 若數字或人名很多，先保留最關鍵且最能代表原文重點者；若能全部保留且仍在 50 字內，則全部保留。
3. 壓縮語句：
   - 刪除背景鋪陳、重複描述、修飾語、例子與次要細節。
   - 使用最短且自然的中文表達。
   - 避免加入原文沒有的新資訊。
4. 檢查字數：
   - 最終輸出必須在 50 字以內。
   - 若超過 50 字，優先再刪除非必要連接詞與形容詞，但不得刪掉已保留的關鍵數字與人名。
5. 檢查保留項：
   - 對照原文，確認摘要中未漏掉應保留的人名與數字。
   - 若因字數限制無法全部保留，需保留最核心者，並讓摘要仍忠實反映原意。

# 輸出規則
- 只輸出摘要正文，不加標題、說明、項目符號或引號。
- 以繁體中文輸出，除非原文明顯使用其他語言。
- 不要附加分析過程。
- 不要編造未出現在原文中的人名或數字。
