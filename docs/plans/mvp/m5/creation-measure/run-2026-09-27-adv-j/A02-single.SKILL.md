# 請假申請審核

依下列規則審核請假申請，並輸出明確結果。

## 審核規則

1. **事假**
   - 必須在請假開始日前 **至少 3 天** 提出申請。
   - 若未提前 3 天，判定為不符合。

2. **病假**
   - 可以 **當天申請**。
   - 若病假 **超過 2 天**，必須附上證明。
   - 若超過 2 天但未附證明，判定為不符合。

3. **不符合時的處理**
   - 必須清楚寫明退回原因。
   - 若同時違反多項規則，需逐項列出。

## 審核步驟

1. 先確認請假類型是 **事假** 或 **病假**。
2. 取得以下資訊：
   - 申請日期
   - 請假開始日期
   - 請假天數
   - 是否附證明（僅病假超過 2 天時需要）
3. 依請假類型套用對應規則。
4. 判定結果：
   - **符合**：可通過。
   - **不符合**：退回並列出原因。

## 輸出格式

### 通過時
- `結果：通過`
- `原因：符合請假規則`

### 退回時
- `結果：退回`
- `原因：`
  - 逐條列出不符合項目

## 判定範例

- 事假申請日距離請假開始日少於 3 天：退回，原因寫明「事假需提前 3 天申請」。
- 病假 1 天或 2 天：可通過。
- 病假超過 2 天且未附證明：退回，原因寫明「病假超過 2 天需附證明」。
- 病假超過 2 天且已附證明：可通過。
