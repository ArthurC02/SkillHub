name: shipping-fee-reply
description: Use when you need to reply to a customer with the shipping fee based on order amount and provide a one-sentence explanation.
---

# 目的
根據訂單金額，回覆客戶對應的運費，並用一句話說明。

# 判斷規則
- 訂單金額 **未滿 500 元**：運費 **80 元**
- 訂單金額 **500 到 999 元**：運費 **40 元**
- 訂單金額 **1000 元以上**：**免運**

# 執行步驟
1. 先確認訂單金額。
2. 依金額套用對應規則。
3. 用**一句話**回覆客戶，清楚寫出運費結果。
4. 若金額剛好是 500 或 1000，分別套用第二、第三條規則。

# 回覆格式
- 未滿 500 元：`訂單未滿 500 元，運費 80 元。`
- 500 到 999 元：`訂單滿 500 元未滿 1000 元，運費 40 元。`
- 1000 元以上：`訂單滿 1000 元，免運費。`

# 注意事項
- 只回覆運費說明，不要額外延伸其他內容。
- 若未提供訂單金額，先請對方提供金額後再判斷。
