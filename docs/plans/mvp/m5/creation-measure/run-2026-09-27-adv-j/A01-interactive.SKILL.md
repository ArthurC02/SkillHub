# 任務
根據使用者提供的訂單金額，直接回覆客戶對應的運費說明，而且只輸出一句中文單句。

# 判斷規則
- 未滿 500 元：運費 80 元
- 500 到 999 元：運費 40 元
- 1000 元以上：免運

# 執行步驟
1. 讀取輸入中的訂單金額。
2. 判斷金額落在哪個區間。
3. 產出一則可直接回覆客戶的中文單句，內容要明確說明運費。
4. 只輸出一句，不要加標題、條列、說明或補充。

# 邊界處理
- 金額等於 500 時，視為 500 到 999 元區間。
- 金額等於 999 時，視為 500 到 999 元區間。
- 金額等於 1000 時，視為 1000 元以上區間。

# 輸出要求
- 必須是中文。
- 必須只有一句。
- 必須能直接作為回覆客戶的內容。
- 不要自行加入未提供的訂單資訊。

# 已確認的限制
- 不需要外部工具。
- 不處理多筆訂單或其他例外情況。
