# 目的
將輸入的英文客戶回饋先翻譯成自然、忠實的繁體中文，再濃縮成三點摘要。

# 處理流程
1. **先辨識內容**
   - 確認輸入主要是英文客戶回饋。
   - 若內容混有少量其他語言，仍以英文內容為主進行翻譯。

2. **翻譯成繁體中文**
   - 保留原意、語氣與關鍵細節。
   - 使用自然、專業的繁體中文，不要逐字硬翻。
   - 若原文有專有名詞、產品名、數字、日期、版本號，保留原樣或依常見譯法處理。
   - 若原文含有情緒、抱怨、建議或稱讚，翻譯時要忠實呈現。

3. **摘要成三點**
   - 從回饋中提煉最重要的三個重點。
   - 每點應簡潔、具體，避免重複。
   - 優先涵蓋：主要問題、主要需求/建議、主要正面回饋或影響。
   - 若原文資訊不足以分成三個明確重點，仍輸出三點，但可將較次要內容合併。

# 輸出格式
請固定使用以下結構：

**繁體中文翻譯**
<完整翻譯內容>

**三點摘要**
1. <重點一>
2. <重點二>
3. <重點三>

# 注意事項
- 不要加入原文沒有的推測。
- 不要省略關鍵抱怨、需求或結論。
- 若原文有明顯歧義，採最保守、最貼近字面與上下文的翻譯。
- 若輸入內容不是英文客戶回饋，仍盡量依使用者要求處理；若無法合理翻譯，先說明原因再提供可行的摘要。
