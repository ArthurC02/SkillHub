# 自我介紹撰寫流程

當使用者要寫自我介紹、個人簡介、about me、履歷自介、面試自我介紹、社群簡介或演講開場時，依下列步驟進行。

## 1. 先確認用途與限制
先判斷自我介紹要用在哪裡，因為不同場景長度與語氣不同。若資訊不足，先問最少必要問題：
- 用途：面試、課堂報告、社群貼文、交友、履歷、活動開場、申請文件等
- 語言：中文、英文或雙語
- 長度：短版 / 中版 / 長版，或字數範圍
- 語氣：正式、自然、活潑、專業、親切
- 是否要包含：姓名、年齡、學歷、工作經歷、興趣、專長、個性、目標、成就

如果使用者沒有提供足夠資訊，先提出精簡問題，不要直接編造個人資料。

## 2. 蒐集內容素材
請使用者提供可用資訊，或從既有對話中整理出以下項目：
- 基本資料：姓名或稱呼、身份、目前狀態
- 背景：學校、科系、工作、年資、專案經驗
- 能力：專長、技能、證照、語言能力
- 個人特質：優勢、做事風格、個性
- 興趣與動機：喜歡的事、為何選擇這個領域
- 目標：未來規劃、想達成的事
- 場景需求：是否要強調某些亮點或避免某些內容

若使用者只想要「幫我寫一篇」，可先請他提供 3 到 5 個關鍵資訊；若他希望你直接代寫，則用現有資訊寫出可編輯版本，並明確標示哪些地方可替換。

## 3. 選擇結構
依用途選擇合適結構：

### 通用版
1. 開頭問候或自我稱呼
2. 基本背景
3. 專長或經歷
4. 個人特質或興趣
5. 結尾與期待

### 面試版
1. 姓名與背景
2. 學經歷或工作經驗
3. 核心能力與成果
4. 為何適合此職位
5. 結尾表達期待

### 學生版
1. 姓名與年級/科系
2. 學習背景
3. 興趣與社團/活動
4. 個人特質
5. 未來目標

### 社群/短簡介版
1. 一句定位
2. 2 到 3 個亮點
3. 興趣或風格
4. 收尾一句

## 4. 撰寫原則
- 內容真實，不捏造經歷、學歷、職稱或成就
- 句子自然流暢，避免過度空泛
- 優先使用具體資訊，例如「負責社群經營」優於「很有能力」
- 若是正式場合，避免口語過重；若是輕鬆場合，可加入親切感
- 控制篇幅，避免重複
- 若資訊不足，保留可替換句，方便使用者修改

## 5. 產出方式
輸出時依情況提供以下其中一種或多種：
- 一篇完整自我介紹
- 兩到三個版本供選擇
- 精簡版與詳細版
- 可直接口說的版本
- 可貼到履歷、申請表或社群的版本

若使用者未指定風格，預設提供「自然、清楚、通用」版本，並可附上一個更正式版本。

## 6. 建議格式
可用以下格式回覆：

### 版本一：正式版
[完整自我介紹]

### 版本二：自然版
[較口語、親切的自我介紹]

### 可替換資訊
- [姓名]
- [學校/公司]
- [專長]

## 7. 品質檢查
完成後檢查：
- 是否符合用途與語氣
- 是否有不真實或過度誇大的內容
- 是否有明確的個人特色
- 是否長度合適
- 是否容易直接使用或稍作修改即可使用

## 8. 若資訊不足
如果使用者只說「幫我寫一篇自我介紹」，先回覆簡短提問，例如：
- 這篇自我介紹要用在哪裡？
- 你希望偏正式還是自然？
- 可以提供你的姓名、背景、專長和興趣嗎？

在取得足夠資訊前，不要硬寫成看似完整但其實空泛的內容。
