# 目的
根據「這個月的出勤紀錄」計算每個人的加班時數，並標示出加班時數超過 46 小時的人。

# 適用情境
- 輸入是當月出勤紀錄、打卡紀錄、工時表或類似資料。
- 需要按人彙總加班時數。
- 需要找出超過 46 小時的名單。

# 執行步驟
1. **確認資料範圍是當月**
   - 只使用本月的出勤紀錄。
   - 若資料跨月，先排除非本月資料，或請求明確的月份範圍。

2. **辨識每筆紀錄中的加班資訊**
   - 找出每個人的每日加班時數、加班分鐘數，或可推算加班的欄位。
   - 若資料只有上下班時間，先依規則計算加班；若沒有明確規則，先說明無法可靠計算，並請求加班計算規則。

3. **統一時間單位**
   - 將所有加班資料統一成「小時」或「小時與分鐘」。
   - 若有分鐘，計算時保留精度；最後可四捨五入或以原始格式呈現，但要一致。

4. **按人彙總**
   - 將同一人的所有當月加班時數加總。
   - 若同一人有多筆紀錄，全部納入。
   - 若姓名可能重複，優先使用員工編號或其他唯一識別欄位；若沒有，先提醒可能有重名風險。

5. **判斷是否超過 46 小時**
   - 對每個人的當月加班總時數，與 46 小時比較。
   - 超過 46 小時者標記為「超標」或同等明確標示。
   - 等於 46 小時不算超過，除非使用者另有規則。

6. **輸出結果**
   - 以清楚表格列出：
     - 人員名稱/編號
     - 當月加班總時數
     - 是否超過 46 小時
   - 另外列出超標名單，方便快速查看。

# 輸出格式建議
- 先給總表，再給超標清單。
- 若資料不足以計算，明確指出缺少哪些欄位，例如：
  - 每日加班時數
  - 上下班時間
  - 加班計算規則
  - 員工識別欄位

# 注意事項
- 不要把正常工時誤算成加班。
- 不要混入非本月資料。
- 若資料中有請假、補休、調班等會影響加班的欄位，先依既有規則處理；若沒有規則，先說明限制。
- 若加班時數是以分鐘提供，彙總後再換算成小時時，要保持一致的換算方式。
