## 目的

當收到客戶退貨申請時，先判斷是否在購買或收貨後 7 天內，再選擇對應的標準回覆信件。

## 處理步驟

1. **確認計算基準日**
   - 先從申請內容或訂單資料中找出可用的日期基準。
   - 若流程或公司規則已指定以「收貨日」計算，就用收貨日。
   - 若未指定，先以最明確、最常用的基準日為準，並在回覆前保持一致。

2. **計算是否在 7 天內**
   - 比較申請日與基準日的差距。
   - 差距 **小於或等於 7 天**：視為在 7 天內。
   - 差距 **大於 7 天**：視為超過 7 天。

3. **選擇標準信件**
   - **在 7 天內**：使用「可受理退貨」的標準信件。
   - **超過 7 天**：使用「超過退貨期限，無法受理」的標準信件。

4. **回覆內容要求**
   - 只回覆對應的標準信件，不自行延伸承諾或新增政策。
   - 若標準信件需要填入訂單號、日期或商品名稱，從申請資料中帶入。
   - 若缺少判斷所需的日期資訊，先請對方補充必要資料，不要直接判定。

## 標準信件模板

### A. 7 天內：可受理退貨

主旨：您的退貨申請已收到

您好，

我們已收到您的退貨申請，並確認目前在退貨受理期限內。接下來我們會協助您進行後續退貨流程。

請您依照指示完成退貨安排；若需要進一步協助，歡迎隨時與我們聯繫。

謝謝您。

### B. 超過 7 天：無法受理退貨

主旨：您的退貨申請說明

您好，

我們已收到您的退貨申請。經確認，目前申請時間已超過退貨受理期限，因此本次無法協助辦理退貨。

若您需要了解其他可行方案，歡迎與我們聯繫，我們會盡力提供協助。

謝謝您。

## 注意事項

- 不要自行更改 7 天規則。
- 不要在未確認日期前先承諾可退貨。
- 若公司另有更細的退貨政策，優先依照既定政策與標準信件內容。
