## 目標
將一份英文使用手冊完整翻譯為繁體中文，保留原有章節、段落、列表、表格與警示格式；所有專有名詞在第一次出現時需附上原文，之後可只用譯名。

## 翻譯原則
1. **忠實完整**：不刪減、不增寫、不改寫原意。
2. **繁體中文**：全文使用繁體中文，語氣自然、清楚、符合說明文件風格。
3. **專有名詞處理**：
   - 第一次出現時採「譯名（原文）」格式。
   - 若原文本身就是常見品牌、產品名、功能名或縮寫，仍需在首次出現時保留原文。
   - 後續出現可只用譯名；若上下文容易混淆，可再次保留原文。
4. **術語一致**：同一術語在全文使用同一譯法；先建立並維持一致的術語表。
5. **格式保留**：
   - 標題層級、編號、項目符號、表格、註解、警告、提示、程式碼區塊、按鍵標示、路徑與變數格式都要保留。
   - 不要把表格改寫成段落，也不要把段落拆成不必要的清單。
6. **數字與單位**：數字、版本號、型號、路徑、命令、錯誤碼、單位通常保留原樣；必要時加上中文說明，但不要改動技術內容。
7. **不可翻譯內容**：程式碼、命令列指令、API 名稱、檔名、URL、設定鍵、變數名、環境變數、標籤名稱通常保留原文。

## 工作流程
1. **先掃描全文**，找出：
   - 章節結構
   - 重複術語
   - 專有名詞、產品名、功能名、縮寫
   - 表格、警告、注意事項、步驟清單
2. **建立術語對照**：為重複出現的關鍵詞選定一致譯法。
3. **逐段翻譯**：按原順序處理，不重排內容。
4. **首次出現標註原文**：在第一次翻譯到專有名詞時加入原文。
5. **最後一致性檢查**：確認術語、格式、數字、標點與原文結構一致。

## 輸出要求
- 只輸出翻譯後的繁體中文內容。
- 不要附加說明、註解、翻譯策略或前言。
- 若原文有標題、頁首頁尾、圖表標號或附錄，應一併保留並翻譯。
- 若遇到無法判定是否為專有名詞的詞彙，優先保留原文一次，再在後文使用譯名。
