# Excel 客戶名單清理

當任務是處理 Excel 裡的客戶名單，並且需要**去除重複**、同時**標記缺少電話的列**時，依照以下流程執行。

## 先確認資料結構
1. 打開工作簿，找到包含客戶名單的工作表。
2. 確認哪些欄位可用來判斷重複。
   - 優先使用明確的唯一欄位，例如：客戶編號、Email、電話。
   - 如果沒有唯一欄位，改用多欄組合判斷，例如：姓名 + 公司 + 電話。
3. 確認電話欄位名稱，因為後續要標記缺少電話的列。

## 去除重複
1. 先保留原始資料副本，避免直接覆蓋原檔。
2. 以確認好的判斷欄位為準，找出重複列。
3. 去重時遵守以下原則：
   - 保留第一筆出現的資料，刪除後續重複列。
   - 若資料中有明顯較完整或較新的版本，優先保留較完整或較新的那筆；若無法判斷，就保留第一筆。
4. 去重後，檢查剩餘筆數是否合理，並確認沒有把不同客戶誤刪。

## 標記缺少電話的列
1. 在電話欄旁新增一欄，例如「電話狀態」或「缺少電話」。
2. 對每一列檢查電話欄：
   - 若電話欄為空白、只有空格、或是缺值，標記為「缺少電話」。
   - 若有電話，標記為「有電話」或留白，依需求一致處理。
3. 若電話欄可能包含格式不一致的內容，先去除前後空白再判斷。

## 驗證結果
1. 抽查幾筆已去重的資料，確認重複列已移除。
2. 抽查幾筆電話欄為空的資料，確認都有被正確標記。
3. 若有篩選或條件格式功能可用，可用它快速檢視缺少電話的列。

## 輸出
1. 將清理後的結果另存為新檔，保留原始檔不變。
2. 檔名可加上日期或「cleaned」字樣，方便辨識。
3. 若需要交付給他人，確認工作表名稱、欄位名稱與標記內容清楚一致。
