# 每日新聞標題摘要寄信流程

此技能用於把三個新聞網站的標題整理成 5 條摘要，並準備成可寄出的郵件內容。若執行環境沒有即時網路、網站存取權限或寄信權限，先明確說明限制，並改為產出可手動寄送的郵件草稿與所需資訊清單。

## 先確認必要資訊
1. 確認三個新聞網站的名稱或網址。
2. 確認收件信箱。
3. 確認寄送時間是「每天早上」的具體時段與時區。
4. 確認摘要語言與語氣，預設使用使用者輸入的語言，語氣簡潔中性。
5. 確認是否要保留每則新聞的來源連結。

## 收集標題
1. 依序查看三個新聞網站首頁或新聞標題頁。
2. 只擷取標題，不延伸撰寫未出現在標題中的事實。
3. 若同一事件在多個網站重複出現，合併為同一條摘要候選。
4. 若某網站無法讀取，記錄原因，並繼續處理其餘網站。

## 產出 5 條摘要
1. 從三個網站的標題中挑選最重要、最具代表性的 5 則。
2. 每條摘要以一到兩句話表達，優先保留：
   - 事件主題
   - 影響範圍
   - 任何明確的時間或地點資訊
3. 避免評論、推測與重複。
4. 若標題不足 5 則，則：
   - 先合併相近主題
   - 再以「今日標題較少」的方式誠實說明
   - 不要捏造新聞

## 郵件內容格式
1. 主旨建議：`每日新聞摘要 - YYYY-MM-DD`
2. 內文結構：
   - 問候語
   - 5 條摘要清單
   - 每條後面附來源網站名稱；若可取得連結，再附連結
   - 結尾加上簡短收尾
3. 內文保持精簡，方便早上快速閱讀。

## 寄送前檢查
1. 檢查是否真的只有 5 條摘要。
2. 檢查是否有把標題內容誤寫成未證實的細節。
3. 檢查收件信箱與日期是否正確。
4. 若無法直接寄信，輸出完整郵件草稿，讓使用者可直接貼到郵件工具中。

## 無法自動完成時的處理
如果目前環境不能：
- 存取新聞網站
- 取得即時標題
- 發送電子郵件

則不要假裝已完成。改為回覆：
1. 需要哪些網站網址
2. 需要哪個收件信箱
3. 需要哪個時區與寄送時間
4. 需要使用者提供的標題或可存取的資料來源
5. 一份可直接使用的郵件模板
