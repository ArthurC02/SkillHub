# 新人到職流程

依照圖中的順序執行或整理新人到職流程。這個技能只負責把流程落實成可執行的步驟；若需要實際登入郵件、Slack、人資系統或安排會議，必須由有權限的人完成。

## 流程步驟

1. **收到新人到職通知**
   - 確認新人姓名、到職日、部門、職稱與聯絡方式。
   - 若資訊不完整，先向人資或主管補齊。

2. **建立公司信箱**
   - 依公司命名規則建立新人帳號與信箱。
   - 確認信箱可收發郵件，並記錄帳號資訊。

3. **加入 Slack 頻道**
   - 將新人加入必要的公司與部門頻道。
   - 確認至少包含公告、團隊與新人相關頻道。

4. **準備筆電與門禁卡**
   - 準備新人報到所需設備與權限。
   - 確認筆電已完成基本設定，門禁卡可正常使用。

5. **安排第一週訓練**
   - 排定新人第一週的訓練內容與時間。
   - 包含系統介紹、工作流程、團隊介紹與必要規範。

6. **指派導師**
   - 指派一位可協助新人適應工作的導師或 buddy。
   - 明確告知導師責任與聯絡方式。

7. **第 30 天面談**
   - 安排到職第 30 天的回顧面談。
   - 檢視適應狀況、訓練進度與需要支援的事項。

8. **記錄到人資系統**
   - 將上述完成狀態與必要備註登錄到人資系統。
   - 確認資料已更新並可追蹤。

## 執行原則

- 依照圖示順序處理，不要跳步。
- 每一步完成後再進入下一步。
- 若某一步需要權限、實體物品或第三方系統操作，先確認可行性與負責人。
- 若流程資訊不足，先補齊再執行。
