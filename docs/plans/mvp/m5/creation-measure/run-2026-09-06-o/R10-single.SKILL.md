## 目的

從 Slack 的三個頻道中，整理出「看起來是問題、但尚未被回覆」的訊息，做成一份可交付的清單，並附上每則訊息的連結。

## 先確認的資訊

在開始前，先確認這三件事：

1. **三個頻道名稱**：若任務描述沒有明確寫出，先向使用者確認。
2. **時間範圍**：預設為「最近 7 天」或「本週」，若使用者有指定週期則依指定週期。
3. **什麼算未回覆**：
   - 預設規則：原訊息下方**沒有任何他人回覆**，且不是作者自己補充的續貼。
   - 若頻道使用 thread 很頻繁，則以 thread 中**沒有其他人回覆**為未回覆。

## 作業流程

1. **逐一查看三個頻道**
   - 只檢查指定時間範圍內的訊息。
   - 優先找出包含問句、求助、請求確認、請求協助、待處理事項的訊息。

2. **判斷是否為「問題」**
   - 收錄條件：
     - 有明確問句（例如含「嗎」、「怎麼」、「是否」、「可不可以」等）。
     - 明確請求協助或等待回覆（例如「請問」、「麻煩確認」、「需要誰處理」）。
     - 看起來是在等人回答的工作訊息。
   - 不收錄：
     - 純公告、純資訊分享、純閒聊。
     - 已經在 thread 或後續訊息中得到回覆的問題。

3. **判斷是否未回覆**
   - 檢查該訊息是否有 thread 回覆。
   - 若有回覆，確認是否只是作者自己補充，或是否已有他人回應。
   - 只有在**沒有他人回覆**時才列入。

4. **整理清單**
   - 每則列出：
     - 頻道名稱
     - 發訊者
     - 訊息摘要（簡短改寫，不要長篇複製）
     - 發送時間
     - 連結
   - 若同一人多則未回覆問題，仍逐則列出。

5. **排序方式**
   - 先依頻道分組，再依時間由新到舊排序。
   - 若使用者要求其他排序，依使用者要求。

## 輸出格式

用條列清單輸出，每則一行，格式如下：

- [頻道名稱] 發訊者｜訊息摘要｜時間｜連結

## 品質檢查

輸出前確認：

- 只包含三個指定頻道內的訊息。
- 只包含未回覆的問題。
- 每則都有可點擊的 Slack 連結。
- 摘要簡短、客觀，不加入推測。

## 限制

這個任務需要能查看 Slack 頻道內容與訊息連結；如果目前沒有 Slack 存取權限或無法開啟指定頻道，先說明無法直接完成，並請使用者提供匯出內容或可存取的訊息清單。
