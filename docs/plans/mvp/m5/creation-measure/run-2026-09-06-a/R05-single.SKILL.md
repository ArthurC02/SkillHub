# 目的
將一週內的每日花費記錄整理成清楚的表格，為每筆支出標示類別，並在週末計算各類別合計。

# 適用情境
- 使用者提供一週的花費明細，要求整理成表格。
- 使用者希望每筆支出都標上類別。
- 使用者要求在週末或週結時，統計各類別總額。

# 處理流程
1. **先確認資料是否完整**
   - 檢查是否有一週內每天的花費資料。
   - 若缺少日期、金額、品項或類別，先列出缺漏項目並請使用者補充。
   - 若使用者沒有先分好類別，根據品項內容推定最合理的類別，並在表格中保持一致。

2. **整理每日明細**
   - 以日期為單位列出每筆花費。
   - 每筆至少包含：日期、品項/用途、類別、金額。
   - 若同一天有多筆支出，逐筆列出，不要合併，除非使用者明確要求合併。

3. **建立週表**
   - 用表格呈現一週資料。
   - 建議欄位如下：
     - 日期
     - 品項/用途
     - 類別
     - 金額
     - 備註（可選）
   - 金額格式保持一致，必要時統一為同一幣別。

4. **標示類別**
   - 為每筆支出指定一個主要類別。
   - 若一筆支出可屬於多個類別，選最主要用途作為主類別。
   - 類別名稱要前後一致，避免同義不同名造成統計錯誤。

5. **週末彙總各類別合計**
   - 依整週所有支出，按類別加總。
   - 產出一個類別合計表，欄位至少包含：類別、合計金額。
   - 若需要，也可附上整週總支出。

6. **檢查加總正確性**
   - 確認各類別合計之和等於整週總支出。
   - 若不一致，回頭檢查是否有漏記、重複記錄或類別歸錯。

# 輸出格式
先輸出每日明細表，再輸出週末類別合計表。

## 每日明細表示例欄位
| 日期 | 品項/用途 | 類別 | 金額 | 備註 |
|---|---|---:|---:|---|

## 類別合計表示例欄位
| 類別 | 合計金額 |
|---|---:|

# 注意事項
- 不要自行捏造不存在的花費。
- 若資料不足以判定類別，先標記為「未分類」並提醒使用者補充。
- 若使用者指定了固定類別清單，優先使用該清單。
- 若有退款、折扣或負數金額，應如實記錄並納入加總。
