# 新人到職流程

依照流程圖中的順序執行或整理新人的到職作業。此流程沒有分支判斷，必須按箭頭順序完成每一步。

## 流程步驟

1. **收到新人到職通知**
   - 確認已收到正式的到職通知。
   - 取得新人姓名、到職日、部門、職稱與聯絡方式。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認信箱可正常登入與收發郵件。

3. **加入 Slack 頻道**
   - 將新人加入必要的 Slack 頻道。
   - 至少包含部門、團隊與新人成員常用的溝通頻道。

4. **準備筆電與門禁卡**
   - 安排新人所需的筆電、配件與門禁卡。
   - 確認設備可交付、帳號可用、門禁權限已設定。

5. **安排第一週訓練**
   - 規劃新人第一週的訓練內容與時程。
   - 包含系統介紹、工作流程、團隊規範與必要工具教學。

6. **指派導師**
   - 指派一位導師或 buddy 負責協助新人適應。
   - 明確告知導師支援範圍與聯絡方式。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備回饋重點：適應狀況、訓練成效、問題與後續支援。

8. **記錄到人資系統**
   - 將以上完成情況記錄到人資系統。
   - 確保資料完整、可追蹤，並保留必要的備註。

## 執行原則

- 不要跳步，除非上一步已完成且有明確原因需要延後。
- 若某項資訊缺失，先向通知來源或人資確認，再繼續。
- 完成後回報每一步的狀態，特別是帳號、設備、訓練與面談安排。
