## 目標
將一份英文使用手冊完整翻成繁體中文，保留原意、結構與操作順序；所有專有名詞在第一次出現時以「繁體中文（原文）」呈現，之後統一使用繁體中文譯名。

## 翻譯原則
1. 忠實翻譯，不增刪說明、不自行改寫流程。
2. 保留原手冊的章節、標題、編號、表格、警告、注意事項、清單與按鈕/選單層級。
3. 專有名詞、產品名、功能名、介面項目、縮寫：
   - 第一次出現時寫成「繁體中文譯名（原文）」；
   - 後續只用繁體中文譯名，除非原文在該處有助於辨識或避免歧義。
4. 若原文已有固定譯法，優先採用一致且常見的繁體中文譯法。
5. 技術詞彙要前後一致；同一術語不要在不同段落使用不同譯名。
6. 保留數字、單位、型號、路徑、命令、代碼、網址、按鍵名稱與變數名稱的原樣或依慣例轉寫，不要任意翻譯。
7. 若遇到無法確定的專有名詞，先依上下文給出最合理譯名，並在首次出現時保留原文以便對照。

## 處理步驟
1. 先通讀全文，辨識：
   - 文件結構（章節、子章節、附錄、索引）；
   - 專有名詞與術語；
   - 重複出現的固定詞彙；
   - 警告、注意、提示等特殊區塊。
2. 建立術語一致性：
   - 為主要術語選定唯一譯名；
   - 記住首次出現位置，之後維持同一譯法。
3. 逐段翻譯：
   - 先保留原有格式，再轉成繁體中文；
   - 長句可依中文語序重組，但不得改變操作步驟或條件關係；
   - 列表項目保持原順序。
4. 專有名詞首次出現時加註原文：
   - 例如：設定檔（configuration file）；
   - 若同一段落內多次出現，首次標註即可。
5. 檢查一致性與完整性：
   - 標題層級是否完整；
   - 步驟編號是否連續；
   - 表格欄位是否對齊；
   - 警告/注意內容是否未遺漏；
   - 術語是否前後一致。

## 輸出要求
1. 只輸出翻譯後的繁體中文內容。
2. 保留原文件的版面結構與閱讀順序。
3. 不要附加翻譯說明、註解、譯者備註，除非原文本身就有。
4. 若原文包含圖片標題、圖說、按鈕文字或 UI 標籤，也一併翻譯並保持一致。
