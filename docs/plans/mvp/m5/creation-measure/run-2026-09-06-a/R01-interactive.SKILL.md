# 會議逐字稿待辦清單整理

## 目的
將客戶提供的會議錄音逐字稿整理成一份待辦清單，方便後續追蹤執行。

## 使用時機
在你收到的是會議逐字稿文字內容，且需要把其中明確提到的行動項目轉成結構化待辦時使用。

## 輸入
- 一份會議逐字稿文字內容。

## 輸出
- 一份待辦清單。
- 每條待辦必須包含：
  - 待辦事項
  - 負責人
  - 期限

## 處理原則
1. 只整理逐字稿中明確提到的事項。
2. 不新增逐字稿外的待辦事項。
3. 若負責人或期限沒有在逐字稿中明確出現，請標示為「未明確」或留空。
4. 不可自行推測或補寫負責人、日期或其他細節。
5. 若同一事項被重複提及，合併為一條待辦即可。

## 建議輸出格式
使用表格最清楚：

| 待辦事項 | 負責人 | 期限 |
| --- | --- | --- |
| ... | ... | ... |

若內容較少，也可以用條列式，但每條都必須看得出三個欄位。

## 操作步驟
1. 通讀逐字稿，找出所有明確的行動項目。
2. 針對每個行動項目，確認是否有明確提到負責人與期限。
3. 將結果整理成待辦清單。
4. 檢查是否有任何推測、補寫或新增內容；如有，刪除。
5. 交付可直接追蹤的清單。
