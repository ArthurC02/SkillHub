# 目的
把會議逐字稿轉成結構化待辦清單，每一條都要包含：
- 待辦事項
- 負責人
- 期限

# 適用範圍
使用於：
- 客戶提供會議錄音逐字稿
- 需要整理出行動項目、決策後續、追蹤事項
- 需要輸出成可直接轉交團隊執行的清單

# 工作原則
1. 只根據逐字稿內容整理，不要自行補寫不存在的任務。
2. 優先抓取明確的行動語句，例如：
   - 「請 A 負責…」
   - 「由 B 在下週前完成…」
   - 「我們要再確認…」
3. 若逐字稿中有多個可能負責人，選擇最明確被指派的人；若仍不明確，標示為「未指派」並保留原文線索。
4. 若期限明確，直接寫出；若只有相對時間，換成逐字稿中的原始說法，例如「本週五前」、「下次會議前」。
5. 若完全沒有期限，標示為「未提及」。
6. 若任務內容含糊，先整理成可執行的描述，再保留必要上下文，避免過度推論。
7. 不要把討論中的想法、背景說明、重複確認句誤當成待辦。

# 整理步驟
1. 通讀逐字稿，標記所有可能的行動項目。
2. 對每個行動項目確認：
   - 具體要做什麼
   - 誰負責
   - 何時完成
3. 合併重複或同義的項目。
4. 將每條待辦改寫成簡潔、可執行的句子。
5. 若同一項目有多個子任務，拆成多條待辦，除非原文明確表示要合併。
6. 若有會議決議但未指定負責人或期限，仍列入待辦，並標示缺漏欄位。

# 輸出格式
以條列清單輸出，每條包含以下欄位：
- 待辦：
- 負責人：
- 期限：

範例格式：
- 待辦：確認新版報價單內容並回覆客戶
  負責人：王小明
  期限：本週五前

# 品質檢查
輸出前檢查：
- 每條待辦都有負責人
- 每條待辦都有期限；若原文沒有，明確寫「未提及」
- 沒有遺漏明確的行動項目
- 沒有把非行動內容混入待辦

# 注意事項
如果逐字稿內容不足以判定負責人或期限，不要猜測；如實標示「未指派」或「未提及」。
