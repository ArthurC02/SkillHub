# Resume-to-data-analyst-one-page

## What this skill does
Rewrite an existing resume into a concise Chinese version tailored for data analysis roles, limited to one page. Preserve only verifiable information from the source resume and emphasize skills, tools, projects, and results relevant to data analysis.

## When to use it
Use this skill when the user wants their resume rewritten for data analyst, business analyst, BI, or similar roles and wants a shorter, job-targeted version.

## Input requirements
Collect the following before drafting:
- The source resume text or bullets
- The target role or role family, if the user wants a narrower focus than general data analysis
- The preferred output format if specified by the user
- Any constraints such as one-page length, tone, or sections to keep

If the user has not provided enough detail, ask for the missing items instead of inventing them.

## Rewrite principles
1. Keep only facts that appear in the source resume or are explicitly confirmed by the user.
2. Reorder and rephrase content to foreground data analysis relevance:
   - SQL, Python, Excel, BI tools, statistics, A/B testing, reporting, dashboards, data cleaning, automation, stakeholder communication
   - projects with measurable outcomes
   - domain knowledge that supports analysis work
3. Prefer concise, results-oriented language.
4. If a fact is missing, leave a clear gap for the user to fill later rather than fabricating it.
5. Keep the final version to one page or as close as possible while preserving critical evidence.

## Drafting steps
1. Read the source resume and identify:
   - work history
   - education
   - projects
   - tools and methods
   - measurable outcomes
2. Select the most relevant items for the target role.
3. Rephrase each item with data-analysis framing while preserving meaning.
4. Remove duplicated or low-signal details.
5. Tighten wording until the result fits a one-page resume.
6. Check that no new employers, degrees, tools, metrics, or achievements were added.

## Suggested output structure
- Name and contact line if present in the source resume
- Professional summary focused on data analysis
- Skills section grouped by analysis tools and methods
- Experience section with concise impact bullets
- Projects section if it strengthens fit for the target role
- Education and certifications if relevant

## Output quality check
Before delivering, verify that:
- the output is in Chinese if the source and user request are Chinese
- the version clearly targets data analysis roles
- the length is one page or as compact as possible
- all achievements and metrics are supported by the source resume
- the tone is professional and suitable for job applications
