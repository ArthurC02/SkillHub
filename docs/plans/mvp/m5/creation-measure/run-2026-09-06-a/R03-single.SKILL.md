# 目的
將三個新聞網站的標題整理成 5 條摘要，並以電子郵件寄送給指定收件人。

# 先確認的資訊
在開始前，先確認以下內容是否已提供：
1. 三個新聞網站的網址或 RSS 來源。
2. 收件人的電子郵件地址。
3. 寄件方式是否已可用：
   - 已有可用的郵件工具或自動化環境，或
   - 需要先產出可手動寄送的摘要內容。
4. 摘要語言與風格：例如繁體中文、簡短條列、偏中性。
5. 寄送時間與時區：例如每天早上 8:00。

如果缺少任何一項，先向使用者詢問，不要自行假設。

# 可行性限制
- 這個任務需要取得即時新聞內容與寄送電子郵件。
- 若目前環境沒有網路存取、沒有可用的郵件寄送工具，或沒有登入/授權，則不能直接完成寄送。
- 在這種情況下，應改為：
  1. 整理出需要的資料清單；
  2. 產出可手動使用的摘要草稿；
  3. 明確指出還缺少哪些權限或工具。

# 執行流程
## 1. 蒐集新聞標題
對每個新聞網站：
1. 進入首頁、新聞列表頁或 RSS。
2. 擷取最新標題。
3. 保留來源名稱、標題、時間戳記（若有）。
4. 去除重複標題與明顯無關內容。

## 2. 彙整成 5 條摘要
1. 將三個來源的標題合併。
2. 找出重複主題、相近事件與最重要的新聞。
3. 以 5 條摘要呈現，每條摘要應：
   - 只包含一個主題；
   - 盡量涵蓋多個來源；
   - 用簡潔、客觀的語句；
   - 避免加入未被標題支持的推測。
4. 若標題不足以形成 5 條有意義的摘要，則少於 5 條也可以，但要說明原因。

## 3. 組成電子郵件內容
郵件主旨建議格式：
- `每日新聞摘要 - YYYY-MM-DD`

郵件內文建議包含：
1. 簡短開頭，說明這是今日三個新聞網站的標題摘要。
2. 5 條摘要條列。
3. 每條摘要後附上來源網站名稱，必要時可附原始標題。
4. 結尾可加上「如需完整標題清單可再提供」。

## 4. 寄送
- 若有可用郵件工具與授權，使用它寄出。
- 若沒有寄信能力，輸出完整郵件草稿，讓使用者可直接貼到信箱寄出。

# 品質檢查
寄出前檢查：
1. 是否確實來自三個指定網站。
2. 是否只有 5 條或更少且有理由。
3. 是否沒有捏造新聞內容。
4. 是否收件人、主旨、日期正確。
5. 是否語氣中性、清楚、可直接閱讀。

# 失敗處理
如果網站無法存取、內容被阻擋、或標題抓取不完整：
1. 記錄失敗原因。
2. 只使用可取得的標題。
3. 在郵件中註明資料不完整。
4. 不要編造缺失內容。
