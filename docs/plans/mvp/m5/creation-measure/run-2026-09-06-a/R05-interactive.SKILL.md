# Weekly Expense Table

將一週的每日花費記錄整理成表格，並在週末彙總各類別合計。

## 何時使用
- 使用者提供一週內的花費明細，想要整理成清楚的表格。
- 需要逐筆標示類別，並在週末加總各類別金額。

## 輸入要求
- 一週內的每日花費明細。
- 每筆支出至少應能辨識出日期、金額與類別。
- 若使用者未提供類別，先不要擅自補分類；改為保留未知或請使用者補充分類規則。

## 工作流程
1. 讀取所有花費明細，確認是否涵蓋一週。
2. 將每筆支出整理成表格列。
3. 為每筆支出保留或標示類別。
4. 按類別彙總全週金額。
5. 在輸出末尾加入週末合計區塊。

## 輸出格式
輸出一個 Markdown 表格，至少包含以下欄位：
- 日期
- 項目或摘要
- 金額
- 類別

在表格後面附上週末合計，例如：

- 餐飲：
- 交通：
- 購物：
- 其他：

如果輸入中存在未分類項目，請在合適位置保留 `未分類`，不要聲稱已自動正確分類。

## 規則
- 不要憑空新增不存在的支出。
- 不要將不同類別混在同一筆合計中。
- 若同一類別在多天重複出現，週末合計要加總全部金額。
- 若使用者指定了類別命名方式，優先沿用使用者的命名。

## 輸出檢查
完成後檢查：
- 是否每筆支出都有被放入表格。
- 是否每筆支出都有類別欄位。
- 是否有週末各類別合計。
- 是否沒有自行宣稱未知類別已被正確辨識。
