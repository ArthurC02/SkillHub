# Shopify 訂單匯入流程

## 用途
當收到客戶的 Excel 訂單，且需要依照既定流程轉成 CSV、檢查缺漏欄位、匯入 Shopify 後台並回覆客戶已入單時，使用此 Skill。

## 輸入
- 客戶提供的 Excel 訂單檔案
- 需要匯入 Shopify 的訂單資料

## 輸出
- CSV 格式的訂單檔案
- 已完成 Shopify 匯入的結果
- 回覆客戶已入單的通知內容

## 流程
1. 取得客戶 Excel 訂單。
2. 將 Excel 訂單轉成 CSV 格式。
3. 檢查資料是否有缺漏欄位。
4. 將資料匯入 Shopify 後台。
5. 回覆客戶已入單。

## 限制
- 只能依照已確認的流程執行，不得新增未出現在流程圖中的分支、例外或補救步驟。
- 缺漏欄位檢查後的處理方式未被定義時，不得自行補充。
- 不得聲稱已驗證任何未確認的工具或成功試跑。

## 實作準則
- 先確認輸入為可讀取的 Excel 訂單。
- 轉檔時保留可匯入 Shopify 所需的資料。
- 完成缺漏欄位檢查後，再進行 Shopify 匯入。
- 匯入完成後，再進行已入單回覆。

## 注意事項
- 若流程執行所需的欄位對應、工具或例外處理未被圖中定義，應停止擴充內容並僅保留已確認步驟。
