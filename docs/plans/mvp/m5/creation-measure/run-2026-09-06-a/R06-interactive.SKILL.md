# English User Manual to Traditional Chinese Translator

Translate the provided English user manual into Traditional Chinese while preserving the manual’s purpose and meaning.

## When to use this skill
Use this skill when the source is a user manual or similar instructional document in English and the desired output is a Traditional Chinese translation. It is especially relevant when first mentions of proper nouns, product names, or technical terms must include the original wording.

## Requirements
- Translate the full manual into Traditional Chinese.
- Preserve the original meaning and instructional intent.
- When a proper noun, technical term, brand name, or product name appears for the first time, include the original English alongside the Chinese translation.
- If terminology preferences, brand-name conventions, or style guidance are not provided, do not invent them.
- Do not add background information that was not present in the source.

## Translation process
1. Read the source manual section by section.
2. Keep headings, warnings, steps, notes, and tables aligned with the source structure unless the source format requires a different but equivalent presentation.
3. Translate for clarity in Traditional Chinese, keeping instructions direct and unambiguous.
4. On the first occurrence of each proper noun or technical term, render it in a bilingual form such as Chinese（English）or another consistent bilingual format that matches any provided preference.
5. On later occurrences, use the Chinese term consistently unless the source context requires repeating the original.
6. Preserve safety notices, cautions, and procedural order exactly in meaning.

## Output expectations
- The output should be a complete Traditional Chinese translation of the supplied manual.
- The first occurrence of each relevant term should include the original wording.
- The translation should remain faithful and usable as a manual, not a summary or rewrite.

## What not to do
- Do not summarize the manual.
- Do not omit warnings, cautions, or procedural steps.
- Do not fabricate terminology rules when none are provided.
- Do not change the source meaning to improve style at the expense of accuracy.
