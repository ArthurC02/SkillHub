# 目的
將 Excel 中的客戶名單去除重複，並標記缺少電話的列，保留可追溯的原始資料處理結果。

# 處理原則
- 不要直接覆蓋原始檔；先建立一份處理後版本。
- 去重前先確認「重複」是依哪些欄位判定，通常以客戶名稱、電話、Email 或其組合為準。
- 若欄位名稱不明，先掃描表頭並根據資料內容判斷最合理的去重鍵。
- 缺少電話的列要明確標記，不要刪除，除非使用者另外要求。

# 步驟
1. 開啟 Excel 檔案，確認資料所在工作表與表頭列。
2. 檢查欄位名稱，找出電話欄位；若有多個可能欄位，優先使用最明確代表聯絡電話的欄位。
3. 建立一個新的處理版本或新工作表，保留原始資料不變。
4. 先標記缺少電話的列：
   - 若電話欄位為空白、只有空格、或是無效占位值（例如 `N/A`、`-`、`無`），視為缺少電話。
   - 在新增欄位中標記，例如「電話狀態」填入「缺少電話」；有電話則填入「有電話」。
5. 去除重複資料：
   - 依資料內容選定去重鍵。
   - 若使用單一欄位去重，保留第一筆出現的資料。
   - 若使用多欄位組合去重，保留第一筆完整且最可信的資料。
   - 去重後保留一份結果，並記錄刪除或合併了多少筆重複資料。
6. 若需要同時保留稽核資訊，可新增欄位：
   - 「是否重複」：是/否
   - 「電話狀態」：有電話/缺少電話
   - 「處理備註」：例如「依姓名+電話去重」
7. 檢查結果：
   - 總筆數是否符合預期。
   - 是否仍有重複列殘留。
   - 是否所有缺少電話的列都已標記。
8. 儲存為新檔，檔名可加上 `deduped`、`cleaned` 或日期後綴，避免覆蓋原檔。

# 輸出要求
- 交付去重後的 Excel 檔。
- 若有標記欄位，保留在結果中。
- 若去重規則不明確，先回報可用欄位並請使用者確認去重依據，不要自行猜測造成資料誤刪。
