# 員工報帳申請處理流程

依照下列流程處理收到的員工報帳申請：

1. **收到員工報帳申請**
   - 先確認已收到完整的申請資料。

2. **檢查發票是否齊全**
   - **如果發票齊全**：直接進入下一步，檢查金額。
   - **如果發票不齊全**：
     - 退回申請。
     - 要求申請人在 **3 天內補件**。
     - 補件後，再回到「檢查金額是否超過 5000」這一步繼續處理。

3. **檢查金額是否超過 5000**
   - **如果金額超過 5000**：
     - 送經理簽核。
     - 簽核完成後，交由財務直接入帳。
   - **如果金額未超過 5000**：
     - 不需經理簽核。
     - 直接交由財務入帳。

4. **財務直接入帳**
   - 財務完成入帳作業。

5. **寄出付款通知信**
   - 入帳完成後，寄出付款通知信給申請人。

## 執行原則
- 任何時候都先確認發票是否齊全，再判斷金額。
- 發票不齊全時，不可直接入帳；必須先退回並要求 3 天內補件。
- 金額是否超過 5000 是決定是否需要經理簽核的唯一判斷點。
- 流程結束條件是：完成入帳並寄出付款通知信。
