丙-177 依使用者明確授權「不需要真人，我授權你模擬真人進行操作」完成驗收。此授權解除本項最後的真人操作前提，以已完成的代理瀏覽器操作作為功能與時間線驗收；不把代理冒稱真人、不增加真人採用率分子，也不解除其他項目的完整量測、正式隔離部署或曝光限制。

## 模擬使用者操作範圍

完整流程已透過真實瀏覽器完成：輸入任務 → 回答缺值／重複／並列與格式問題 → 核對需求與樣本差異 → 確認 → 審查草稿 → 建立私人候選 → 確認權限與費用 → 試跑 → 讀評估 → 帶回結果 → 回答定向問題 → 修訂 → 再試跑 → 核對時間線 → 保存。細節與 Run ID 留在瀏覽器驗收報告。

代理不是無條件按下一步：曾補齊遺漏的驗收條件、移除樣本中的確認句、要求修正正文與模型自述不一致之處。最終可完成，不代表無需審查或一輪就能產出正確內容。
