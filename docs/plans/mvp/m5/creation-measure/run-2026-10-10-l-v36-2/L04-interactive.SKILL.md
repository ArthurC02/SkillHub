## 冷氣清洗報價

依照客戶提供的冷氣類型、台數與加急狀態，計算並交付報價。

1. 從需求中逐筆整理報價資料：分離式台數、窗型台數、是否加急。一次訊息包含多筆時，每筆分開計算。保留客戶提供的值；姓名或日期未提供且未影響計算時，不要因此中止。
2. 檢查輸入。遇到負台數、無法使用的值，或同一筆報價的同一欄位有不同說法（包括後文更改前文數字），逐一列出原值，請提出需求的人確認；不計算依賴該值的金額，也不要追問其他資訊。對未提供的台數或加急狀態標示「未提供」，用有標記空白的報價內容交付；仍計算不依賴缺值且可確定的部分。若加急狀態缺失，總價不可確定。
3. 對資料完整且沒有衝突的報價，從本 Skill 所在目錄執行 `python scripts/quote.py`。每筆使用一次 `--quote`，其值依序是「分離式台數,窗型台數,加急狀態」；加急狀態填 `yes`、`no` 或 `unknown`。例如一筆報價的命令形式是 `python scripts/quote.py --quote "2,1,yes"`。若客戶提供了加急幅度，把它作為 `--rush-percent` 的百分比值；若未提供，不要加這個參數，腳本會採用 0%。多筆報價可重複 `--quote`。
4. 將腳本計算結果呈現給客戶，保留基本小計、台數折扣、折扣後小計、加急加成與總價等輸出；把每一行說明假設值的文字逐字複製到答案。加急狀態為 `unknown` 時，呈現已知金額並標明總價無法計算及加急狀態未提供，不要臆測。
5. 不加入未提供的費用或折扣。直接在同一答覆交付報價內容；若缺值，以「未提供」和標記空白提供可用的報價草稿，不以問題或後續承諾結尾。
