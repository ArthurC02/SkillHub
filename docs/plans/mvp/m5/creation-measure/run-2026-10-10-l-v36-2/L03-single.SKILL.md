# 活動餐點外燴報價整理

收到客戶的口語、零散或格式不一的訂購訊息時，依以下步驟整理報價。只使用訊息中明確提供的資訊；不自行猜測品項、數量、單價、折扣或費用。

## 1. 擷取訂購資訊

- 找出每個餐點及其他報價項目，辨認各自的數量、計價單位與單價。保留客戶使用的品名；若只需輕微整理用字，不要改變品項意思。
- 接受常見口語數量與金額寫法，例如「兩打」為 24 個、「一千二」在語境明確時為 NT$1,200。若數字或單位有多種合理解讀，先詢問客戶，不要擅自選一種。
- 將重複提及的同一品項合併數量，除非訊息顯示它們是不同規格或不同單價；單價不同時分列，避免錯誤合併。
- 將包、盒、份、桌等計價單位照原訊息記錄，不要自行換算成其他單位。

## 2. 辨認並排除場地清潔費

- 凡客戶提到的「場地清潔費」或明確指場地方收取、由客戶直接付給場地方的清潔費，均標記為「不列入我方報價」。
- 場地清潔費不論金額或算法，都不得納入餐點總額；如有金額，可在報價表後另列為「客戶另付場地方」，並清楚註明不計入我方總額。
- 只排除場地清潔費。其他費用或品項即使不是餐點，只要客戶有提出且不是場地清潔費，就納入報價計算；若它的性質或收款對象不清楚，先詢問，不要自行排除。

## 3. 核對金額並計算

- 對每個納入報價的項目計算「數量 × 單價」；若客戶已提供該項小計，核對它是否與計算結果一致。
- 若客戶只提供某項總價與數量，且可直接相除，得出單價並標示為「依總價換算」；若不能整除或可能涉及折扣、組合價等情況，保留已知總價並詢問，勿捏造單價。
- 若有數量但缺單價，或有單價但缺數量，列出缺少的資訊並請客戶補充。可以先整理已確認項目，但不得把不完整項目當作零元，也不得宣稱已確認最終總額。
- 將所有非場地清潔費項目的小計相加，得到我方報價總額。以新台幣表示，使用「NT$」或「新台幣」，並清楚列出加總；不要自行加入稅金、運費、折扣或其他未提供的金額。
- 若客戶提供的小計、折扣後金額或總額與逐項計算不一致，指出差異並請客戶確認；不要默默替客戶改價。

## 4. 回覆格式

使用繁體中文，提供精簡且可核對的明細表。欄位至少包含：品項、數量／單位、單價、小計。單價或小計未提供時標示「待確認」，不要留白或填零。

明細表後列出「我方報價總額（新台幣）」及加總式。若有場地清潔費，另列在總額之外，標示「客戶直接支付場地方，不計入我方報價」。若仍缺資料或金額有歧義，緊接著列出需要客戶確認的具體問題，並將總額標示為「暫計」或「待確認」，避免呈現成最終報價。
