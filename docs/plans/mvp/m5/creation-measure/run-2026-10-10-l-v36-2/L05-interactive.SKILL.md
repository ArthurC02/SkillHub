# 證照考場考前簡訊

將使用者提供的考試資訊改寫成繁體中文考生簡訊；只用輸入內容，不上網查證或補造資訊。

## 步驟

1. 從輸入整理考試日期、報到時間、考場地點，以及攜帶身分證和准考證的提醒。逐字保留提供的事實與數值，不把可推測內容寫成事實；缺少必備資訊時標為「未提供」，用標記空格呈現可用的簡訊範本，不因此停止撰寫。
2. 整理其他資訊。盡量保留交通、供餐情況及重要規定；可合併相關資訊以維持簡潔。空間不足時，優先省略停車和置物細節，並如實記下省略或合併的項目。
3. 若日期不存在、數值不合理，或同一項資訊有互相矛盾的不同值（包括後文改動前文數值），在輸出中逐項列明原值，請提出要求的人確認；不採用該值，也不寫出依賴它的結論。其他缺漏或未要求的姓名、標籤、日期，不妨礙撰寫。
4. 寫簡訊本文，最多三句。必須包含考試日期、報到時間、考場地點，並提醒攜帶身分證及准考證。只在不損害清楚易讀的前提下加入其他資訊；若不能同時符合要求，遵守三句上限，並以一行說明遺漏了什麼。
5. 本文後另起一行，用恰好一句話誠實說明省略或合併了哪些資訊；若沒有，明說沒有省略或合併。這一行不計入本文句數。不要加入未提供的內容，也不要聲稱已查證。
6. 將本文單獨存成 `sms_body.txt`，將包含本文及取捨說明的完整答案存成 `answer.txt`。在 Skill 所在目錄執行 `python scripts/check_output.py --max-sentences 3 --require "<考試日期原文>" --require "<報到時間原文>" --require "<考場地點原文>" --require "身分證" --require "准考證" < sms_body.txt`；將尖括號內容換成輸入中提供的原文。修正本文並重跑，直到檢查器輸出 `OK`。答案只輸出 `answer.txt` 的內容；不得改寫或省略檢查器輸出中任何指出假設值的文字。

對於執行本次請求所提及、但此 Skill 執行者無法完成的任何外部動作，準備好可供使用的內容後，在答案末尾逐項用一行說明該動作無法由此執行者完成，並指出應由提出請求的人或請求指定的負責人完成；不得聲稱已完成該動作。
