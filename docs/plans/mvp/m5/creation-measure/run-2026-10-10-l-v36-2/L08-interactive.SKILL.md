# 蜂蜜批發出貨單

依客戶貼上的訂購訊息，整理出貨單並計算固定價目下的品項小計與總額。

## 步驟

1. 將原始訂購訊息逐字存入此 Skill 所在目錄的 `orders.txt`。每張訂單以空白行分隔；保留訊息中的客戶、日期、品項與數量。若沒有訂購訊息，建立空白的 `orders.txt`，以輸出可用的空白出貨單範本。
2. 從此 Skill 所在目錄執行：
   `python scripts/packing_slip.py "$(cat orders.txt)"`
   若缺少日期，腳本使用當天日期並輸出可直接照抄的假設說明；要改用其他基準日期時，加入 `--today YYYY-MM-DD`。
3. 將腳本輸出的出貨單原樣交付，不另行猜測或改寫訂購資料。每張單列出客戶、出貨日期、品項、數量、單價、小計與總額；未提供的客戶標示「未提供」。固定單價為蜂蜜 250ml 每瓶 180 元、蜂蜜 500ml 每瓶 320 元、蜂蠟蠟燭每支 90 元，不另加稅金或運費。缺少品項或數量時標示「未提供」，不自行補猜；只有各部分都已知且沒有阻礙計算的問題時才列總額。
4. 若有數量矛盾、不存在的日期或負數數量，照輸出逐一指出資料及問題，請提出請求的人確認；不選擇數值、不猜日期，也不列出依賴問題資料的該筆訂單總額。不要以問題收尾；交付已完成的出貨單或範本及需確認的項目。
5. 若請求還提及此代理無法執行的外部動作，先備妥可直接使用的內容；在回答末尾為每項動作各寫一行，明確說明此代理無法執行該動作，並指出由提出請求的人或請求指定的負責者執行。
