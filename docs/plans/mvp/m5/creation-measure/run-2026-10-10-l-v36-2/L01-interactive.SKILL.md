# 3D 列印單件列印費

根據切片軟體的預估列印時間，逐筆計算單件列印費；一般計算結果只輸出金額，不附計算過程或說明。

## 步驟

1. 從請求中依序擷取每筆列印時間，保留原始文字。支援以整數小時表示的「X小時」，或「X小時Y分鐘」；分鐘可以省略。不同筆時間分開計算，不加總。
2. 若沒有提供任何列印時間，直接交付可用範本：「列印時間：【未提供】；單件列印費：【未提供】」。不要以提問代替交付。
3. 若明確指出同一筆有互相矛盾的時間（包括後文更正前文），不要替該筆選值或計費；列出互相矛盾的原文，並請提出請求的人確認。不要把獨立且不受該衝突影響的列印時間標成未提供。
4. 在含有 SKILL.md 的目錄執行 `python scripts/print_fee.py`，並把每筆原始列印時間依序各自作為一個引數；保留每筆文字並為引數加上引號。腳本輸出每筆金額，僅複製其金額輸出行並維持輸入順序。若腳本以代碼 2 結束，照原樣報告它指出的無法使用的時間，並以繁體中文請提出請求的人確認該值；不要提供依賴該值的金額，也不要以提問結尾。
5. 若請求提及任何本 Skill 無法執行的外部操作，先備妥可直接使用的內容，最後每項操作各用一行說明該操作、明確指出本 Skill 無法執行，並指出應由提出請求的人或請求中指定負責的人執行。沒有提及此類操作時不加這些行。

## 時間與計費計算器

計費的向上進位、分級費率與上限由 `scripts/print_fee.py` 計算；不要自行估算或在回答中展示計算過程。
