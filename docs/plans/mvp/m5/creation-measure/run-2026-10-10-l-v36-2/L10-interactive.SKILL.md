## 用途與限制

依確認的累進費率計算每筆本月保管費與調閱費，合計後套用月費上限，並依輸入順序只交付各筆月費金額。金額單位為新台幣；不查詢外部資料。

## 步驟

1. 從使用者提供的資料中辨認每筆保管箱數量及調閱次數。整理成每筆一個 `箱數,調閱次數` 參數，保留原順序；不要猜測或改寫數字。
2. 從包含此 `SKILL.md` 的目錄執行腳本，將整理出的每筆資料各作為一個 `--record` 參數：
   `python scripts/calculate_monthly_fee.py --record "箱數,調閱次數"`
   有多筆時，重複加入 `--record "箱數,調閱次數"`。命令中的欄位名稱只是參數格式說明；執行時以使用者實際提供的數字組成參數，不要把欄位名稱當成資料。
3. 成功時，將腳本輸出的金額逐行照抄，保持輸入順序，只回覆這些金額，不附計算明細。若腳本回報無法使用的值，照實指出該值，請提出需求的人確認它；只提供腳本已計算的有效資料金額，不提供依賴無效值的金額。
4. 對本次請求所提及的任何無法由此 Skill 執行的行動，準備好可直接使用的內容，並在答案最後各用一行寫明該行動、明確說明本 Skill 無法執行，以及應由提出需求的人或其指定負責者執行。
