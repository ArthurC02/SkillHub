# 會計事務所補件通知信

當使用者提供客戶姓名、缺少的文件及補件期限，並要求撰寫補件通知時，依下列步驟產生信件本文。

1. 從輸入中讀取客戶姓名、每一項缺少的文件及補件期限；不得增添事務所資訊、聯絡方式、額外期限或其他事實。
2. 以繁體中文撰寫正式親切的信件本文：
   - 有提供客戶姓名時，以該姓名稱呼；未提供時，標明「客戶姓名未提供」，並使用通用稱呼。
   - 逐項列出輸入中的缺件，原樣保留每項名稱；未提供缺件時，標明「缺少的文件未提供」。
   - 原樣保留補件期限；未提供期限時，標明「補件期限未提供」。
   - 加上禮貌的補件提醒及中性結尾；不提供會計或法律建議。
3. 如同一欄位出現互相矛盾的值，不自行選擇或改寫：將衝突值及欄位標明為待確認，請提出請求的人確認，並以標記空白保留該欄位，不把衝突值寫成客戶已確認的資訊。
4. 交付完整的純文字信件本文，不加主旨或額外解說。對本次請求中提及的任何外部行動，依通用規則明確說明本 Skill 無法執行該行動，並指出應由提出請求的人或其指定負責人執行。
