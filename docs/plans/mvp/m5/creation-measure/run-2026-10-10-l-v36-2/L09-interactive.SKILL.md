# 陶藝活動 Instagram 宣傳貼文

## 執行步驟

1. 閱讀使用者提供的活動資訊，擷取活動名稱、日期（含星期）、時間、地點、費用、報名截止日，以及其他明確提供的活動事實。只使用輸入中的資訊；不要上網查詢或自行補充事實。
2. 原樣保留每項事實的文字，包括數字、日期、星期、標點、大小寫、貨幣符號、空格及範圍符號。不要改寫、換算、校正或依常識推測；不要因缺少年份而自行核對星期。
3. 檢查同一事實是否有多個互相矛盾的值，或是否明顯無效。若有，逐一列出衝突或無效值，請提出要求的人確認；不要替對方決定，也不要把受影響的值寫成已確認事實。仍需交付完整貼文，將受影響欄位標成「待提出要求的人確認」，並原樣列出相關值。
4. 撰寫一則繁體中文 Instagram 貼文：以自然、輕鬆親切的開場及報名邀請串接資訊；清楚呈現所有已提供的活動事實，不讓修飾文字改變其意思。不要增加輸入沒有提供的活動事實。若資訊未提供，在相應欄位標「未提供」；不要因此停下撰寫。
5. 將完整貼文寫入 `instagram-post.txt`。用 `python scripts/check_output.py` 的 `--require` 參數逐一檢查每項已提供的硬事實字串；未提供的欄位則檢查其「未提供」標記。每個值各用一個 `--require`，例如：

   ```sh
   python scripts/check_output.py --require "<一項必須出現的原文>" --require "<另一項必須出現的原文>" < instagram-post.txt
   ```

   從存放此 `SKILL.md` 的目錄執行。若未印出 `OK`，修正貼文檔案並重跑檢查，直到印出 `OK`。回覆時只提供檔案內容。
6. 對本次要求中每一項需要在此 Skill 之外完成的動作，在檔案末尾各加一行，寫明該動作、本 Skill 執行者無法代為完成，以及應由提出要求的人或要求指定的負責人執行。這是適用於本次要求所提外部動作的通則；不要宣稱已完成該動作。加上這些行後，重新執行步驟 5 的檢查。
