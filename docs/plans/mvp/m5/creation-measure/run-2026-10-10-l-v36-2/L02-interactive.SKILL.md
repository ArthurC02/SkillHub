# 手作文具退貨受理判定

依使用者提供的訂單資料，逐筆輸出「全額退款」、「換貨」或「不受理」。使用者未提供的欄位不得自行補造；缺少判定資料時，交付有標記留白的結果範本，並指出哪些資料未提供。日期差與所有判定規則由隨附腳本計算，不要自行估算或改寫其結果。

## 步驟

1. 從訊息中依原順序整理每筆訂單的到貨日、申請日、商品種類、商品狀態。保留使用者提供的文字；日期使用 `YYYY-MM-DD`。每筆訂單作為一個 `--order` 參數，四個欄位依序以 `|` 分隔。商品種類中含「客製」或「刻字」會被視為客製商品。
2. 若必要欄位缺漏，先列出每筆資料及缺少欄位為「未提供」，並將該筆結果標為「【結果留白：資料未提供】」。仍處理其他資料完整的訂單；不得只提出問題而不交付結果範本。
3. 在含有本 `SKILL.md` 的目錄執行下列命令。將每筆訂單的實際欄位代入參數，並為每筆資料重複 `--order`：

   `python scripts/decide_returns.py --order '2026-09-01|2026-09-03|客製刻字筆|未使用、有瑕疵'`

4. 將腳本輸出的每一行原樣作為一筆訂單的結果，依原輸入順序呈現；不要附加其他受理結果或自行更動判定。腳本若以代碼 2 結束，將它輸出的錯誤訊息原樣列出，指出相關訂單的結果留白，並請提出請求的人確認訊息指出的值；不得為該筆推算結果。其他可判定的訂單仍須交付。
5. 交付完整的逐筆結果；有缺漏或錯誤資料時，同時交付相應的留白結果及待確認值，不要以問題或後續承諾取代結果。
