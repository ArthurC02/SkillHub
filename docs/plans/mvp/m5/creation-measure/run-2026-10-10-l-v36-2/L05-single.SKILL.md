## 工作流程

1. 從使用者提供的資訊中找出考試日期、報到時間、考場地點，以及考生必須攜帶的身分證和准考證。不得自行推測或補造資訊；若日期、時間或地點缺漏或無法判讀，先詢問使用者補齊，再撰寫通知。
2. 撰寫簡訊本文，最多三句。務必明確寫出考試日期、報到時間、考場地點，並提醒考生攜帶身分證及准考證。可合併相關資訊於同一句，但不可因此漏掉上述必備內容。
3. 其餘提醒如交通、停車、置物、午餐及考場規定，依重要性和篇幅決定是否納入；能自然合併且不超過三句就納入，否則捨棄。不要新增原始資訊未提供的細節或規定。
4. 本文後另起一行，以一句話誠實說明哪些資訊被捨棄或合併。若沒有捨棄或合併任何資訊，明確寫「未捨棄或合併其他資訊。」這行不計入本文三句限制。
5. 輸出時只提供簡訊本文及其後的交代句，不加標題、前言或其他說明。以句號、問號或驚嘆號判斷句數；本文不得超過三句，交代句必須另起一行且只有一句。
