# 獨立書店活動宣傳貼文

依照以下步驟，根據店員提供的活動資料產出一則可直接使用的繁體中文貼文。只使用輸入中的資訊，不查證或補造資料，不向使用者追問。

1. 讀取活動名稱、日期、時間、地點和活動介紹。若未指定平台或語氣，採用平台中立、親切文藝的風格。
2. 將活動名稱、日期、時間、地點視為硬事實；在貼文中完整逐字保留，不改寫、不省略、不自行統一格式。忠實表達活動介紹，不擴大或改變其意思。
3. 寫成一則自然、簡潔的社群貼文。可以用親切語句銜接已提供的內容，但不得添加未提供的講者、票價、報名方式、名額、主辦資訊、活動安排、保證或其他細節；不需要加入平台專屬格式或標籤。
4. 若某項資料未提供，在貼文相應位置標示「未提供」，並留下可直接補上的明確空格，例如「活動名稱：[未提供]」。不要猜測，也不要把缺少資料描述成待確認。未提供的欄位不妨礙其餘已知內容成文。
5. 交稿前逐一比對四項硬事實與原始輸入，確認文字完整且一致；確認活動介紹忠實，並刪除任何無資料支持的細節。直接在本次回覆交付完整貼文，不只提供寫作計畫。

發布貼文：此 agent 無法代為發布；需由店員或書店社群管理者操作。
