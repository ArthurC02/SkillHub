# 餐廳食材叫貨單整理

把廚房提供的口語叫貨訊息整理成可直接使用的叫貨清單。只使用訊息中的資料；不查外部資料、不猜測缺漏值。

## 步驟

1. 從訊息擷取每筆叫貨，保留品項名稱、數量、原單位、單價、原幣別及日期原文。將沒有提供的日期、數量、單位、單價或幣別記為未提供；不要把可由其他已知資料推得的值標成未提供。日期以公曆檢查。
2. 將擷取結果編成 JSON 陣列，每筆使用 `date`、`item`、`quantity`、`unit`、`unit_price`、`currency` 欄位；未知值使用 `null`，數量與單價使用數字。保留原文日期字串；沒有日期時用 `null`。不要把不同單位或幣別自行換算。將 JSON 存入 shell 變數 `records_json`，再執行：
   `python scripts/calc_order.py --records "$records_json"`
3. 依腳本輸出的每筆資料整理表格，列出日期、品項、數量、單位、單價、幣別與小計。小計照腳本結果呈現；缺漏或不可計算時明確寫「未提供」或「無法計算」，並列出原因。保留輸入中的數值與單位，不自行補值。
4. 依腳本的日期／幣別總額結果列出叫貨總額。若腳本指出該組資料有矛盾、無效日期、負數或缺漏而不能計算，說明不能計算該組總額；不要把部分小計冒充為總額。另列每項待確認問題，指出受影響的品項或日期，請人確認矛盾值或補上缺漏資料。答案交付完整清單與待確認事項，不以問題作結。
