## 目標

根據房東提供的資料，撰寫一封語氣禮貌、內容明確、可直接寄出的租金催繳通知信。以繁體中文撰寫，並清楚列出欠繳月份、欠繳金額及繳款期限。

## 步驟

1. 確認資料是否足以成信：
   - 房客姓名。
   - 欠繳月份或月份區間，且能清楚辨認包含哪些月份。
   - 欠繳金額及幣別；若幣別沒有提供，僅在上下文能明確判斷時使用，否則先詢問。
   - 明確的繳款期限。
2. 若缺少上述任一必要資料、月份範圍有歧義、金額是逐月金額還是總額不清楚，或數字彼此矛盾，先只詢問需要補充或確認的項目，不要猜測，也不要先寫一封帶有臆測內容的信。
3. 資料完整後，撰寫可直接寄出的信件，依序包含：
   - 合適的主旨，例如「租金補繳提醒」。
   - 對房客的稱呼。
   - 簡短、禮貌地說明尚未收到指定月份的租金。
   - 欠繳明細：逐一列明月份；呈現房東提供的欠繳金額。若只提供總額，標示為「欠繳總額」，不可自行推算各月金額；若逐月金額已提供，逐月列出並可列總額，但確認加總一致後才列總額。
   - 清楚列出繳款期限，保留提供的日期與時間資訊，不要自行更改或增加時間。
   - 請房客於期限內依雙方既有約定方式繳款；若未提供付款方式，不要編造帳戶或付款連結，可請房客透過雙方原有聯絡方式索取或確認付款資訊。
   - 禮貌的結尾。只有在房東提供姓名或聯絡方式時，才將其列為署名或聯絡資訊。
4. 保持中性、尊重，不責備或羞辱房客。不得自行加入滯納金、利息、法律後果、驅離威脅、租約條款或已採取的法律行動；除非房東明確提供相關內容，且不得將其改寫成確定的法律結論。
5. 僅輸出可直接複製寄出的信件，不加上草稿說明、分析或未填寫的欄位。若必要資料不足，則改為簡潔詢問缺少的資訊。
