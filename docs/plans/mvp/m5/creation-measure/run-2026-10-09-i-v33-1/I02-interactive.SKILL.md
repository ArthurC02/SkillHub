## 用途與限制

根據館員貼上的借閱紀錄逐筆分級，保留紀錄順序。只輸出「賠償」「停借」「提醒」「免處理」四種處理等級；不計算賠償金額，也不執行帳務或停借操作。

## 步驟

1. 讀取館員提供的全部紀錄。每筆應包含讀者、證別（兒童證／一般證）、逾期天數及已回報遺失狀態（是／否）。保留原始順序與已提供的事實，不補造或改寫資料。
2. 若沒有提供紀錄，直接交付可用模板，不要臆造判定：
   ```text
   讀者｜處理等級
   ［未提供］｜［未提供］
   ```
3. 若有紀錄，將每筆資料轉成 JSON 陣列，原樣保留讀者名稱；欄位名稱使用 `reader`、`card_type`、`overdue_days`、`reported_lost`。`overdue_days` 使用整數，其他欄位使用文字。把陣列寫入目前目錄的 `records.json`。缺少讀者名稱時，`reader` 可省略；不可猜測缺少的分類欄位。
4. 從放有本 `SKILL.md` 的目錄執行：
   ```sh
   python scripts/classify_overdue.py --records-json "$(cat records.json)"
   ```
   將腳本印出的結果原樣作為逐筆判定；腳本依輸入順序列出讀者與處理等級。
5. 若腳本以代碼 2 結束，逐字呈現它印出的單行訊息，不替無法判定的紀錄猜結果；請館員確認訊息指出的值，並在重新提供資料時更正。缺少的值標為「未提供」，不標為待確認；對缺少分類欄位的紀錄不給處理等級。
6. 交付判定後，分別附上以下操作限制聲明：
   - 實際賠償或帳務入帳：此代理無法執行；須由館員依圖書館帳務流程處理。
   - 實際停借或變更借閱權限：此代理無法執行；須由館員在圖書館借閱系統處理。
