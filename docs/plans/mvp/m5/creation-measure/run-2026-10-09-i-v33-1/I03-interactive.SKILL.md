## 整理花店訂單報價

1. 從客人提供的單則訊息逐項擷取品名、數量、單價，以及外送車資。只用該訊息，不查外部資料；保留訊息中的品名與金額，不補造事實。
2. 數量缺漏時按 1 件處理。將明確寫出的「一打」交給計算器換算為 12；其他清楚可辨識的數量也按原意整理。單價缺漏時不推測，標為「待確認」。免費品項的單價輸入「免費」；寫明 0 元的品項輸入 0。即使免費或 0 元，也保留該品項。
3. 若同一品項或車資的訊息中有互相矛盾的值，或明確值無法使用，不要自行挑選或計算依賴該值的金額；將該值標為「待確認」，並在輸出中列明需確認的項目。數量欄確實缺漏才用 1；明確但互相矛盾的數量不可當作缺漏。
4. 將擷取結果存為目前目錄中的 `quote-input.json`，格式如下：`{"items":[{"name":"品名","quantity":"數量","unit_price":"單價"}],"delivery_fee":"車資"}`。每個品項一個物件；數量可用整數或字串「一打」，單價可用數字字串、「免費」或 `null`。缺漏數量時省略 `quantity`；缺漏單價時省略 `unit_price`。無車資資料時省略 `delivery_fee`；車資值互相矛盾時設為「待確認」。
5. 從放置 `SKILL.md` 的目錄執行 `python scripts/quote.py --input quote-input.json`。保留計算器輸出的內容；若它報告無法使用的值，也在報價中逐一列出並標為待確認，不要用那些值計算。
6. 將計算器輸出的報價直接交付。只在計算器輸出之外補上確實存在的矛盾值確認事項；不要以問題結尾。若未提供任何訂單訊息，交付一份欄位標為「未提供」的空白報價範本，不猜測品項或金額。

計算器會計算可計算品項的小計與總額；待確認品項不計入總額。外送車資只在備註中列出，並註明由司機到府另收，不得納入品項總額。
