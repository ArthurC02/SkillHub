# 房租催繳通知信

根據使用者提供的資料，製作一封繁體中文、可直接貼上寄出的房租催繳通知信；只用已提供的事實，不引用特定法律，不虛構聯絡方式、付款方式或其他資料。

## 步驟

1. 從輸入擷取房客姓名、每個欠繳月份及其金額、繳款期限。逐字保留提供的資料；房東姓名未提供時，使用「房東 敬上」。其他缺少的欄位在信中標示「未提供」，需要填入的位置用清楚的方括號空格表示。不要為未提供的姓名、日期或標籤停止製作信件。
2. 將期限轉成腳本可辨識的 `YYYY年M月D日` 格式，例如 `2026年10月20日`；不要省略年月日標記。每筆欠繳資料以 `月份=金額` 整理，每筆使用獨立的 `--item` 引數，並以 shell 引號保護引數。
3. 在本 SKILL.md 所在目錄執行下列指令形式，僅加入實際有提供的 `--deadline` 及 `--item` 引數：
   `python scripts/rent_arrears_total.py [--deadline '年 月 日'] [--item '月份=金額']...`
   脚本會驗證可辨識的日期、月份與金額，並計算欠繳總額。依腳本輸出的結果呈現總額；若有未提供的金額，只能呈現已知金額小計，並明示欠繳總額尚無法確定；沒有可計算的資料時，不要製造總額。
4. 若腳本以狀態碼 2 結束，先檢查引數格式並以不改變房東原始資料的方式修正格式，再執行一次。若仍無法驗證，將相關輸入值原樣寫入信件，不填入空格或自行改值；不輸出腳本訊息、待確認事項或其他內部說明。
5. 撰寫信件：稱呼房客；簡短禮貌地說明有租金尚未繳清；逐項列出欠繳月份及輸入金額；呈現腳本計算出的總額（若不可計算則如實說明）；清楚列出繳款期限，並請房客於期限前繳清。以「房東 敬上」或已提供的房東姓名結尾。不要新增付款指示、聯絡資料、法律主張或輸入未提供的事實。
6. 只交付完整通知信，不在信件前後附加說明。若使用者另要求實際寄送，才明確說明本 Skill 無法代為寄出。
