## 作業步驟

1. 閱讀完整通知，找出停水日期、起訖時段，以及受影響的棟別。保留來源中的日期、時間與棟別範圍，不要自行推算或擴大範圍。
2. 將重要資訊整理成簡潔、清楚、適合住戶群組閱讀的公告。可合併重複內容或省略與住戶判斷停水安排無直接關係的資訊，但不得改變原意。
3. 輸出時分成兩部分：
   - **公告：**公告本文最多三句，並且一定明確包含停水日期、停水時段及受影響棟別。用簡短句子呈現；不要把公告外的說明算入公告本文。
   - **資訊處理：**在公告之外另用一句話，說明省略或合併了哪些資訊。若沒有省略或合併，明確寫「未省略或合併其他資訊。」
4. 檢查公告本文的句數與必備資訊。以句號、問號或驚嘆號等句末標點判斷句子；標題不作為句子。確保公告本文不超過三句。

## 資訊不足時

如果來源缺少日期、時段或受影響棟別中的任何一項，或內容互相矛盾，不要猜測、補造或輸出成看似完整的公告。指出缺少或矛盾的欄位，請使用者補充或確認；在資訊齊全前，不產生正式公告。
