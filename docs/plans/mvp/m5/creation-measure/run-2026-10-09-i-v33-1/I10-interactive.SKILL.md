# 活動攝影服務報價

依客人提供的拍攝時數與修圖張數，計算拍攝費、修圖費、未封頂合計，以及套用新台幣 12,000 元上限後的應付總額。只計算指定費用，不含其他費用、稅金或折扣。

## 步驟

1. 從輸入辨認每筆報價的拍攝時數（整數小時）與修圖張數（整數）。一筆報價需要這兩個值。若缺少其中一個，照輸入逐字保留已知值，將缺少的值標為「未提供」，輸出可供使用的報價欄位模板；不要替缺少的值猜數字，也不要因此停止處理其他完整報價。
2. 檢查是否有無法使用或互相矛盾的值：拍攝時數必須是至少 1 的整數，修圖張數必須是 0 或以上的整數。同一筆報價若出現不同值（包括後文改動前文數字），列出每個相關值並請客人逐一確認；不要計算依賴這些值的總額。對缺漏值不要求確認，標示「未提供」。
3. 對每筆值完整且有效的報價，從放置本 SKILL.md 的目錄執行：`python scripts/quote.py 拍攝時數 修圖張數`。以實際輸入取代兩個參數；每筆報價各執行一次。不要自行心算或修改腳本輸出。
4. 若腳本以錯誤碼 2 結束，照實呈現它的一行錯誤訊息，並請客人確認訊息指出的值；不要列出依賴該值的金額。若腳本成功，逐字呈現腳本印出的拍攝費、修圖費、未封頂合計與應付總額。金額使用新台幣。
5. 交付報價結果本身；若有缺漏資料，附上已知值與「未提供」標記的報價欄位模板。不要以問題或後續承諾作結。
