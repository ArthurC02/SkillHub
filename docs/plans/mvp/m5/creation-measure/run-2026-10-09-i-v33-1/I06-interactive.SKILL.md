# 牙醫回診提醒簡訊

依輸入資料準備一則繁體中文簡訊本文。只產生內容，不傳送簡訊。

## 步驟

1. 從使用者提供的資料辨認病患姓名、回診日期、回診時間、診所電話及其他備註；不要追問。缺少設定時採用下列預設並在簡訊中標示缺少的值：日期、時間或電話缺少時寫「日期未提供」「時間未提供」「電話未提供」；姓名或備註缺少時寫「姓名未提供」「備註未提供」。使用者完全沒有提供資料時，仍產生帶有欄位標記的可用範本。
2. 若日期採用 `YYYY/MM/DD` 或 `YYYY-MM-DD` 格式，檢查它是否為有效日期；若無效，不要猜測或計算，指出該日期值無法使用並請使用者確認。其他格式依原文處理。原樣保留所有已提供的日期、時間及診所電話；不要改寫、正規化或省略它們。
3. 在本 SKILL.md 所在目錄執行以下命令，將已有資料以參數傳入。省略未提供的參數；含空格的值以引號括住。命令會輸出簡訊本文：

   ```bash
   python scripts/reminder.py --name "林小姐" --date "2026/11/03" --time "14:30" --phone "02-2345-6789" --note "洗牙"
   ```

4. 確認訊息保留日期、時間及診所電話原文。若長度不足以容納所有內容，腳本先保留這三項，再依序納入姓名、備註；不改動必須原樣保留的值。訊息含標點及空格不得超過 70 個字元。若三項必留值本身無法符合上限，依腳本錯誤訊息指出無法使用的值並請使用者確認，不要輸出超限簡訊。
5. 將腳本輸出寫入檔案並執行字元數檢查：

   ```bash
   python scripts/reminder.py --name "林小姐" --date "2026/11/03" --time "14:30" --phone "02-2345-6789" --note "洗牙" > reminder.txt
   python scripts/check_output.py reminder.txt --max-chars 70
   ```

   這一步的第二個命令使用平台提供的 `scripts/check_output.py`。若檢查未通過，修正簡訊後重新執行兩個命令，直到檢查通過。
6. 回覆 `reminder.txt` 的內容，且只回覆簡訊本文；不附前言、說明或字數統計。
