# 翻譯報價計算

依客人提供的原文字數與交件期限，計算一般費用及急件加成，並交付可直接使用的報價明細。適用於一筆或多筆報價資料；資料不完整時也照已知資料產出明細與可用的空白欄位。

## 步驟

1. 從收到的內容辨識每筆報價的原文字數，以及距交件尚有幾小時。若未提供筆數標籤，不要因此停下；按內容出現順序編列。不要補造資料，並保留已提供的值。
2. 若同一筆資料對同一欄位給出互相矛盾的值（包括後文改動前文的數值），列出每一個衝突值，標示「需確認」，且不計算依賴該值的金額。不要質疑其他資料。
3. 對每筆沒有衝突的資料，在 Skill 目錄下執行以下命令；省略未提供的選項，將 `<字數>`、`<小時>` 換成實際值。若有多筆，逐筆執行：

   ```bash
   python scripts/quote.py --words <字數> --hours <小時>
   ```

   資料不完整時只帶入已知選項，例如只知道字數時執行 `python scripts/quote.py --words <字數>`；兩項都缺少時執行 `python scripts/quote.py`。照原樣呈現腳本輸出。腳本按一般件每字 2 元計價，交件期限小於或等於 24 小時列為急件，加收一般費用的 50%（每字 1 元）；超過 24 小時不加成。金額以元表示，不計稅、折扣或其他費用。
4. 若腳本回報無法使用的值，原樣指出該值並標示「需確認」；不提供依賴該值的金額。對其餘資料照常交付結果。輸出不可只留待確認事項：每筆缺少的欄位標示「未提供」，依已知資料給出能計算的部分；兩項輸入都未提供時，交付腳本產生的空白模板。
5. 交付完整報價明細。一般費用、急件加成及總額都已知時，列出三者；不得給出依賴未提供或需確認資料的總額。
