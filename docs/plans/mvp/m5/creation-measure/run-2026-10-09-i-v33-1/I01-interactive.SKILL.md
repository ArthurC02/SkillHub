# 共享會議室租借費計算

依櫃台提供的一筆或多筆實際使用分鐘數，逐筆計算應收費用。每一筆都是獨立租借，不合併計費。

## 步驟

1. 從輸入中辨認每筆租借的實際使用分鐘數；每行一筆。使用輸入提供的數值，不自行增補或改寫。若沒有提供任何分鐘數，繼續執行，產生含有標記空白的可用模板。
2. 在此 Skill 的目錄執行 `python scripts/calculate_fees.py --minutes 30 31`，將範例數字替換為輸入中的全部分鐘數；若沒有數值，直接執行 `python scripts/calculate_fees.py`。腳本會完成計費單位進位、分段費率計算及每筆上限處理。
3. 若腳本指出無法使用的分鐘數，原樣指出那些值，請提供者逐一確認；不要替它們計費，也不要提供依賴它們的費用。不要詢問其他資訊。
4. 將腳本輸出的逐筆結果直接呈現：包含實際分鐘數、計費單位數及應收費用。費用以元表示，不加入未提供的稅費或其他附加費；若腳本產生模板，原樣提供，不以問題結尾。

計費規則由腳本依輸入計算：每 30 分鐘為一單位，不足一單位無條件進位；第 1–4 單位每單位 300 元，第 5–8 單位每單位 240 元，第 9 單位起每單位 180 元；每筆最高收取 2,400 元。
