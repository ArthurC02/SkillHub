## 用途與輸出

將一份管委會停水通知改寫成住戶群組公告。以繁體中文輸出，分為「住戶群組公告」及公告外的一句「整理說明」。公告本文最多 3 句；整理說明不計入公告句數。

## 步驟

1. 從使用者貼上的通知擷取停水日期、停水時段及受影響棟別。照原文保留這些資訊，不自行改寫成原文沒有提供的內容。
2. 找出通知中的其他資訊。只在不改變原意的情況下合併相關資訊；其餘可省略。記下實際合併或省略的資訊，供整理說明使用。
3. 若必要資訊未提供，在公告中以「未提供」標示；不要猜測或補造。若同一項資訊出現互相矛盾的值，逐一列明衝突值並請使用者確認，不要自行選定。其他未提供的名稱、標籤或日期不妨礙整理。
4. 撰寫公告本文，明確呈現停水日期、時段與受影響棟別，並將其他保留資訊濃縮在最多 3 句內。即使通知內容缺失，也提供可用公告，將缺少的必要項目標示為「未提供」。
5. 在公告外寫一句整理說明，指出哪些資訊被省略或合併；沒有省略或合併時，明確寫「未省略或合併其他資訊」。如有需確認的衝突值，將確認要求併入這一句。不要以問題作結。
6. 將完整回覆寫入 `output.txt`，保留公告與整理說明的分段。從存放本 SKILL.md 的目錄執行以下命令；公告最多 3 句，加上整理說明最多 4 句。必要欄位標籤即使值為「未提供」也必須保留。檢查未通過時修改檔案並重跑，直到顯示 `OK`；最後只輸出 `output.txt` 的內容。

```sh
cat > output.txt <<'EOF'
住戶群組公告
（公告本文）

整理說明：（一句話說明省略或合併的資訊）
EOF
python scripts/check_output.py --max-sentences 4 --require '停水日期' --require '停水時段' --require '受影響棟別' < output.txt
cat output.txt
```
