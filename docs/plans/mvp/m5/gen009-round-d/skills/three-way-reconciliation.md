# 三方對帳差額找出流程

這個技能的目標不是「自動判定誰對誰錯」，而是把三份資料整理成可比對的結構，然後系統化找出：

- 銀行有、記帳軟體沒有
- 記帳軟體有、銀行沒有
- 收據本有、前兩者沒有
- 同一筆但金額、日期、摘要不一致
- 可能重複入帳或漏登

## 先確認三份資料的共同欄位
對每一筆交易，盡量整理出以下欄位：

- 日期
- 金額
- 收/付方向或正負號
- 摘要/對方名稱/用途
- 單號或備註（若有）

如果三份資料欄位不一樣，先做欄位標準化：

- 日期統一成同一格式
- 金額統一為數字，移除逗號與貨幣符號
- 正負號一致：收入為正、支出為負，或相反，但全程要一致
- 摘要保留原文，另外可加一欄「標準化摘要」

## 建議的比對順序
### 1. 先各自整理成三張清單
把三份資料各自變成一行一筆交易的清單：

- 銀行清單
- 記帳軟體清單
- 收據本清單

每行至少有：`日期｜金額｜摘要｜來源`

### 2. 先做「硬匹配」
優先找完全相同或幾乎相同的交易：

- 金額相同
- 日期相同，或在可接受誤差範圍內（例如前後 1–3 天，視業務習慣）
- 摘要/對方名稱相近

若你用表格工具，可先按金額排序，再用日期和摘要人工確認；若有程式處理，則先以金額為主鍵，再以日期與摘要做二次比對。

### 3. 再做「模糊匹配」
對於：

- 分批入帳
- 同一筆款項分成多筆收據
- 銀行摘要和收據名稱不一致
- 日期延遲入帳

用以下條件配對：

- 金額一致但日期不同
- 日期接近但金額有小差異
- 摘要相似但名稱不同

這一層的目的是把「可能是同一筆」先圈出來，不要直接下結論。

## 差額分類方式
把所有未成功配對的項目分成四類：

1. **銀行有，另外兩邊沒有**
   - 可能是漏記、尚未登帳、銀行手續費、扣款、利息

2. **記帳軟體有，另外兩邊沒有**
   - 可能是已登帳但未實際收付、重複輸入、或分類錯誤

3. **收據本有，另外兩邊沒有**
   - 可能是紙本收據尚未入系統、遺漏掃描、或交易未完成

4. **三邊都有但資訊不一致**
   - 日期不同
   - 金額不同
   - 摘要不同
   - 方向不同

## 實作成可操作的對帳表
建議建立一張「對帳總表」，每筆候選交易一列，欄位如下：

- 對帳編號
- 日期（銀行）
- 日期（記帳）
- 日期（收據）
- 金額（銀行）
- 金額（記帳）
- 金額（收據）
- 摘要（銀行）
- 摘要（記帳）
- 摘要（收據）
- 比對狀態
- 差異原因
- 處理結果

比對狀態可用：

- 已配對
- 待確認
- 銀行缺漏
- 記帳缺漏
- 收據缺漏
- 金額不符
- 日期不符
- 摘要不符

## 找差額的簡單規則
你可以先用這些規則快速篩選：

- **同金額優先配對**：同金額且日期接近者優先視為同筆
- **一對一配對**：一筆只配一筆，避免重複對到多筆
- **大額優先核對**：先確認大額交易，再處理小額
- **特殊項目單獨列出**：手續費、退款、轉帳、零用金、預付/分期

## 若你要用 Excel / Google Sheets
可依這個流程做：

1. 匯入三份資料到三個工作表
2. 標準化日期與金額
3. 建立一欄「匹配鍵」：例如 `金額 + 日期（或日期區間）`
4. 用 `XLOOKUP` / `VLOOKUP` / `FILTER` 找出其他表是否存在同鍵項目
5. 對找不到的資料做人工複核
6. 針對金額相同但摘要不同者，額外檢查

如果你不能靠單一鍵值配對，就改用「金額分組 + 日期排序 + 摘要人工確認」。

## 若你要用程式或半自動化
可採用這個邏輯：

1. 將三份資料轉成同樣欄位
2. 先以 `金額` 建索引
3. 在同金額群組中，比對 `日期差` 與 `摘要相似度`
4. 產出三個結果集：
   - 完全配對
   - 可能配對
   - 未配對
5. 對未配對與可能配對生成差額報表

## 最後要輸出的結果
至少輸出這三個清單：

- **已對上的交易**
- **未對上的交易**
- **待人工確認的交易**

未對上的交易再按來源分類，方便你知道是銀行、記帳、還是收據本哪一邊漏了。

## 注意事項
- 不要只看日期，會漏掉延遲入帳或跨日交易。
- 不要只看金額，容易把不同交易誤配對。
- 對於重複金額的小額交易，要特別小心。
- 如果收據本是手寫，先把交易日期和金額整理清楚，再做比對，否則很容易誤判。

## 如果資料很多
先抽一個月底區間做試跑：

- 先對 20–50 筆交易測試規則
- 調整日期誤差範圍與配對條件
- 確認錯配率後，再全量處理

這樣可以先找到最適合你帳務習慣的比對規則，再固定成每月流程。
