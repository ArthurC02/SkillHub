# 目的
將一批掃描文件中的表格內容先逐份擷取，再合併成一份可交付的整理結果。

# 適用情境
- 文件是掃描圖檔或掃描 PDF，無法直接複製文字。
- 每份文件都包含一張或多張表格。
- 需要在月底將多份表格合併成單一整理檔。

# 工作原則
1. **先抽取、再合併**：先把每份文件的表格獨立轉成結構化資料，再做跨文件彙整。
2. **保留來源**：每筆資料都要能追溯到原始文件與頁碼。
3. **不要猜測**：看不清楚、缺字、欄位不一致時，明確標註待確認，不自行補值。
4. **欄位一致化**：合併前先統一欄名、日期格式、數字格式與單位。

# 操作步驟
## 1. 建立文件清單
- 先列出所有收到的掃描檔。
- 為每一份文件建立唯一識別，例如：
  - 檔名
  - 收件日期
  - 頁碼範圍
- 如果同一份文件有多頁，記錄每頁內容是否包含表格。

## 2. 逐份擷取表格
對每一份文件依序處理：
- 判斷表格所在頁。
- 讀取表格的欄位名稱、列資料、註記與頁尾總計。
- 若表格跨頁，將跨頁內容接續為同一筆資料集。
- 若欄位因掃描品質不清楚，先依版面與相鄰欄位推定，但要標示為「需確認」。

### 擷取時至少保留
- 原始文件識別
- 頁碼
- 表格名稱或標題
- 每一列的原始內容
- 不確定文字
- 總計或小計（如果有）

## 3. 整理成結構化資料
- 把每份文件的表格轉成一致的欄位結構。
- 若不同文件欄名略有差異，先建立欄名對照表。
- 建議使用下列欄位層次：
  - 文件層：來源檔名、頁碼、日期、文件編號
  - 表格層：表格名稱、欄位清單
  - 列層：每一列資料、備註、是否需確認

## 4. 檢查資料品質
- 對照每份文件的總計與逐列加總，確認是否一致。
- 檢查缺漏欄位、重複列、明顯錯位欄。
- 檢查日期格式、金額格式、數量單位是否一致。
- 把所有異常列出來，作為後續人工確認清單。

## 5. 合併多份文件
- 以統一後的欄位結構合併所有表格。
- 若多份文件中有相同識別碼或重複資料，先保留重複判定規則：
  - 完全相同的列視為重複
  - 關鍵欄位一致但備註不同時保留兩筆並標註
- 合併結果中要保留來源資訊，避免無法回查。

## 6. 產出交付內容
輸出時建議包含兩部分：
- **彙總表**：所有文件合併後的主表
- **待確認清單**：所有模糊、缺漏、疑似錯位或總計不一致之處

# 建議輸出格式
若對方沒有指定格式，優先使用以下其中一種：
- **試算表結構**：一列一筆資料，適合月底彙整
- **JSON/CSV 風格資料**：適合後續系統匯入
- **文字摘要 + 附表**：適合人工審核

# 文字標記規則
- 看不清楚的內容：`[不清楚]`
- 缺漏欄位：`[缺漏]`
- 需人工確認：`[需確認]`
- 跨頁延續：`[跨頁續接]`

# 最後檢查
交付前確認：
- 所有掃描文件都已處理。
- 每份文件都有來源標記。
- 合併後欄位一致。
- 所有不確定處都有明確標示。
- 若有總計，已完成對帳或註記差異。

# 侷限
這項工作需要能讀取掃描檔內容的 OCR 或人工判讀能力；若環境沒有 OCR、影像讀取或文件檢視能力，先要求提供可讀取的影像/PDF或轉成文字後再進行。
