# 客戶名單外流前的個資欄位檢查

這個技能的目標是：在寄出客戶名單給外部合作廠商之前，先找出可能包含敏感個資的欄位，並明確標示哪些欄位需要特別處理。

## 你要做的事

1. **先看欄位名稱**
   - 找出任何看起來像以下內容的欄位：
     - 身分證字號 / ID / 身分證 / 統編（視情境判斷）
     - 手機 / 行動電話 / 電話 / 聯絡電話
     - 地址 / 通訊地址 / 郵寄地址 / 住址
     - Email / 電子郵件
     - 出生日期 / 生日
     - 姓名（若名單要外傳，通常也需要確認是否可提供）
     - 客戶編號、會員編號、帳號（若可回推到個人，也要標記）

2. **再看欄位內容**
   - 即使欄位名稱不明顯，也要掃描內容格式：
     - 身分證字號：通常是 1 碼英文字母 + 9 碼數字
     - 手機：常見為 09 開頭 10 碼，或含國碼格式
     - 地址：包含縣市、區、路、街、段、巷、弄、號、樓等文字
     - Email：包含 `@` 和網域
     - 其他可辨識個人的資料：生日、公司分機、社群帳號等

3. **把欄位分級標註**
   - 建議分成三類：
     - **高風險個資**：身分證字號、完整手機、完整地址、完整出生日期
     - **中風險識別資料**：姓名、Email、客戶編號、會員編號、帳號
     - **低風險或業務資料**：不直接識別個人的一般統計或商品資料

4. **輸出一份欄位清單**
   - 用簡短表格或條列方式回報：
     - 欄位名稱
     - 判定類型（身分證字號、手機、地址等）
     - 風險等級
     - 建議處理方式（遮罩、刪除、保留、需確認）

## 判斷原則

- **只要有可能直接識別個人，就先標記。**
- **若欄位名稱不清楚，但內容看起來像個資，也要標記。**
- **若同一筆資料可透過其他欄位回推到個人，仍視為需要注意。**
- **若無法確定是否可外傳，先標記為「需人工確認」**，不要直接假設可提供。

## 建議的回報格式

你可以這樣回：

- `姓名`：中風險識別資料，建議確認是否可提供
- `身分證字號`：高風險個資，建議遮罩或移除
- `手機號碼`：高風險個資，建議遮罩
- `地址`：高風險個資，建議移除或縮減到區域層級
- `Email`：中風險識別資料，建議確認用途
- `客戶編號`：中風險識別資料，若可回推個人需處理

## 如果你拿到的是檔案內容

- 先辨識欄位標題，再逐欄檢查。
- 如果是混在同一欄的自由文字，擷取可能的個資片段並標記所在欄位。
- 如果資料量大，先找最可能含個資的欄位，再抽樣確認內容格式。

## 重要限制

- 這個技能只能幫你**辨識與標記風險欄位**。
- 它不能代替法律、法遵或資安審核。
- 若名單要提供給外部廠商，最後仍應由有權限的人確認可否外傳、是否需要遮罩，以及是否需要簽署資料處理約定。
