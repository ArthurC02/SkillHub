# 目的
根據**人數**、**可玩時間**、**玩家對規則的熟悉度**，快速從桌遊清單中挑出少數幾個最合適的候選，減少臨場討論時間。

# 何時啟用
當使用者提供或想建立一份桌遊清單，並希望依下列條件快速篩選時啟用：
- 參與人數會變動（例如 4–9 人）
- 每次聚會可玩的時間有限
- 玩家可能有新手、熟手，或混合程度
- 可能需要考慮是否適合小孩

# 先確認的資訊
如果使用者沒有一次提供完整資訊，先用最少問題補齊：
1. **今天實際人數**：幾人會玩？
2. **可玩時間**：大約幾分鐘？
3. **規則熟悉度**：
   - 全部都熟
   - 大多數人熟
   - 混合，新手多
   - 幾乎都沒玩過
4. **是否有小孩**：有/沒有；若有，是否需要適合兒童參與或旁觀。
5. **是否偏好**：
   - 想要熱鬧互動
   - 想要策略
   - 想要輕鬆派對
   - 想要避免文字量太多、規則太複雜

# 若使用者有桌遊清單
將每款遊戲按以下維度快速評估：
- **適合人數**：是否落在當次人數範圍內，或是否有可調整的最佳區間。
- **教學成本**：是否能在幾分鐘內講完，或是否需要較長學習時間。
- **對新手友善度**：規則是否直觀、回合是否好理解。
- **遊戲時間**：是否符合當次可玩時間，並保留 10–15 分鐘緩衝。
- **小孩適配性**：是否有讀字量低、競爭壓力低、等待時間短、內容適齡。
- **玩家互動度**：是否適合多人同桌、是否容易在 8–9 人時拖慢。

# 篩選規則
## 1. 人數優先
- 先排除不支援當次人數的遊戲。
- 若遊戲人數上限剛好等於當次人數，標註為「可，但可能較擁擠」。
- 人數偏多時，優先保留：
  - 可支援大人數的派對遊戲
  - 觀眾等待時間短的遊戲
  - 回合可同時進行的遊戲

## 2. 時間優先
- 若總可玩時間短，優先選：
  - 教學快
  - 單局時間短
  - 可提早結束、容易收尾的遊戲
- 若是熟手且時間足夠，可保留較長的策略遊戲。

## 3. 熟悉度優先
- **新手多**：優先選規則少、即看即玩、失誤成本低的遊戲。
- **混合程度**：優先選「前幾回合新手也能跟上」的遊戲，避免複雜例外規則。
- **熟手多**：可保留中重度遊戲，但仍要符合人數與時間。

## 4. 有小孩時
- 優先選：
  - 規則簡單
  - 等待時間短
  - 不需要大量閱讀
  - 輸贏落差不要太大
- 若遊戲不適合小孩，直接標註原因，不要勉強推薦。

# 輸出格式
每次都輸出**3–5 個候選**，並按推薦順序排列。每個候選包含：
- 遊戲名稱
- 為什麼適合這次聚會
- 可能的風險或限制
- 建議的原因摘要（例如：人數合適、教學快、適合新手）

# 推薦用語模板
- 「最穩妥」：人數、時間、熟悉度都很合適。
- 「適合新手」：規則好講、上手快。
- 「適合多人」：人數多也不會拖。
- 「適合有小孩」：互動輕鬆、規則簡單、可一起參與。
- 「備用選項」：若主推遊戲無法成局，可立即改玩。

# 若沒有桌遊清單時
不要憑空編造完整庫存。改為：
1. 先根據條件列出適合的遊戲類型。
2. 再請使用者提供現有收藏或可借到的遊戲名稱。
3. 如果使用者要，你可以幫忙把清單整理成可重複使用的篩選表。

# 實際操作流程
1. 讀取當次人數、時間、熟悉度、小孩需求。
2. 對每款遊戲做快速篩選。
3. 去掉明顯不合格者。
4. 按「最適合」到「可當備案」排序。
5. 如有多個同分候選，偏向更好教學、更快開始的遊戲。
6. 最後附一句簡短結論：這場最推薦哪一款、為什麼。

# 注意事項
- 不要只給一款，除非候選本來就很少。
- 不要用模糊結論代替具體理由。
- 若資訊不足，先問關鍵問題，不要硬猜。
- 若使用者提供的遊戲名稱不足以判斷人數或時間，明確指出需要補哪些資訊。
