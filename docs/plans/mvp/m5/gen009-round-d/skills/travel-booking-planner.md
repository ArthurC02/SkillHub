# 旅行機票＋租車規劃

當使用者提出像「下個月去日本七天，想把機票和租車一起處理，預算有限，時間排得很滿」這類需求時，先把任務視為**行前規劃與資料整理**，不是直接完成訂購。

## 先確認必要資訊
在開始比較或產出方案前，確認以下資訊；若使用者尚未提供，先提出最少必要問題：

1. **出發地與目的地**
   - 從哪個城市/機場出發？
   - 日本要去哪個地區或城市？是否多點進出？

2. **日期與彈性**
   - 預計「下個月」的哪幾天出發與回程？
   - 日期是否可前後彈性 1–3 天？

3. **人數與行李**
   - 旅客人數、是否有小孩/長者？
   - 行李件數，是否需要較大車型？

4. **駕駛與租車需求**
   - 是否有人能在日本合法駕駛？是否已有國際駕照或可使用的駕照文件？
   - 自排/手排、車型大小、是否需要 ETC、導航、雪胎等。

5. **預算上限**
   - 機票、租車各自或合計預算上限。

6. **行程與用車情境**
   - 這 7 天中主要是在市區移動、跨城、還是郊區/景點自駕？
   - 哪些日子一定需要車，哪些日子可用大眾交通？

## 規劃原則
因為使用者「預算有限、時間很滿」，優先採用以下策略：

- **機票**：優先找直飛或少轉機、總旅行時間短的選項。
- **租車**：只租實際會用到的天數，不要整段 7 天都租，除非行程必須全程自駕。
- **機場與取還車點**：盡量選與航班銜接順、少繞路的方案。
- **費用結構**：除了票價/租金，也要把稅金、保險、異地還車費、兒童座椅、ETC、油費、停車費與可能的里程限制算進去。
- **時間成本**：若行程很滿，優先選少轉乘、少換飯店、少換車的方案。

## 工作流程

### 1. 先整理旅行限制
把使用者提供的資訊整理成這些欄位：
- 出發地
- 目的地
- 去程日期 / 回程日期
- 人數
- 行李量
- 預算
- 是否能開車
- 需要租車的天數
- 主要移動方式偏好

若資訊不足，先只補問最關鍵的 2–4 題，不要一次問太多。

### 2. 產出可行方案框架
至少提供 2 種方案方向：
- **方案 A：省錢優先**
- **方案 B：時間優先**

每個方案都要說明：
- 機票類型建議（直飛/轉機、早去晚回等）
- 租車天數建議
- 大致風險或代價（例如較長交通時間、較高成本）

### 3. 估算總成本
若沒有實際價格資料，也要用結構化方式估算：
- 機票費用區間
- 租車費用區間
- 保險與附加費
- 油費/停車費/過路費可能範圍
- 合計區間

如果使用者提供了候選航班或租車方案，幫他們比較**總成本**，不要只比單價。

### 4. 對時間緊湊行程做優化
檢查以下項目：
- 到達與取車時間是否太晚，會不會浪費第一天
- 回程前是否要提早還車，避免趕機
- 是否有不必要的換飯店或換取車點
- 行程中是否有某幾天其實不需要車，可以縮短租期

### 5. 給出明確下一步
結尾要提供可執行下一步，例如：
- 「如果你告訴我出發城市、日期、人數和預算，我可以幫你縮成 2–3 個最划算的機票＋租車組合。」
- 「如果你已經有候選航班/租車連結，可以貼給我，我幫你比總成本與時間成本。」

## 回答格式建議
優先用這種格式輸出：

1. **先判斷**：是否適合全程租車，或只租部分天數。
2. **推薦方案**：A / B 兩案。
3. **預算拆解**：機票、租車、保險、其他費用。
4. **時間風險**：哪些地方最容易卡時間。
5. **需要你補充的資訊**：列出最少必要項目。

## 注意事項
- 不要假設使用者一定能在日本合法駕駛；先確認駕照條件。
- 不要只看機票便宜就推薦；若轉機過多或到達時間太差，對「時間排得很滿」不適合。
- 若目的地主要在大城市，先評估是否其實不需要租車；若仍要租車，要說明停車與通行成本。
- 若任務需要即時票價、庫存或下單，必須提醒使用者：這部分需要實際網站查詢或他們提供現成報價，技能本身只能協助整理、比較與規劃。
