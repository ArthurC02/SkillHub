# CSV 轉 NDJSON

這個技能的目標是把 CSV 轉成 **NDJSON / JSONL**：
- 每一列 CSV 轉成一行 JSON 物件
- 欄位名稱 **完全保留**，不要改名、不要重排也可以，但值要對應正確
- 輸出檔案必須是 **一行一個 JSON 物件**，行與行之間用換行分隔

## 先確認輸入

1. 先確認原始檔確實是 CSV。
2. 檢查分隔符號是否真的是逗號；有些 CSV 其實可能是分號、Tab，若不是逗號就要依實際分隔符解析。
3. 確認第一列是不是欄位名稱。
   - 若第一列是欄名，直接保留作為 JSON key。
   - 若沒有欄位名稱，不能直接轉；先詢問使用者要怎麼命名欄位。

## 轉換規則

1. **每一筆資料列** 轉成 **一個 JSON 物件**。
2. JSON 物件的 key 使用 CSV 第一列的欄位名稱，**原樣保留**。
3. 值要正確處理：
   - 空白欄位轉成 JSON 的 `null` 或空字串，依原始資料語意決定；若無法判斷，優先保留空字串並註明。
   - 數字、布林值若已經明確是該型別，可轉成對應 JSON 型別；若不確定，保守地保留字串。
   - 含逗號、引號、換行的欄位要依 CSV 規則解析，不能手動切字串。
4. 輸出格式必須是 NDJSON：
   - 每行一個完整 JSON
   - 不要把所有物件包成陣列
   - 不要加多餘說明文字

## 輸出檢查

在交付前檢查：
- 欄位名稱是否完全一致
- 筆數是否與原 CSV 資料列數相同
- 是否每一行都是合法 JSON
- 是否沒有把資料包成 `[{...}, {...}]`
- 是否沒有漏列或多列

## 如果你需要實作而不是只交付結果

因為這個任務不需要登入、購買或外部網路，仍然可以由代理完成。若你手上有 CSV 內容，就直接按上述規則逐列轉換；若只拿到檔名但沒有內容，先向使用者索取 CSV 原文或上傳檔案。
