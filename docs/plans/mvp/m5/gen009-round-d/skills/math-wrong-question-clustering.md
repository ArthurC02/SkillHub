# 目標
把零散的國中數學錯題整理成「觀念分類表」，並找出全班最常錯、最值得下次先講的觀念。

# 這個技能能做什麼
- 依題目內容判斷對應的數學觀念
- 把多筆錯題歸到同一類
- 統計每個觀念出現頻率與分散程度
- 找出需要優先補救的核心觀念
- 產出適合課堂使用的整理結果

# 先確認你提供的資料
如果你只提供題號，通常**無法可靠分類**，因為題號本身不夠判斷觀念。請優先蒐集以下任一種資料：
1. 題目完整文字
2. 題目照片或截圖
3. 題號加上單元名稱、章節、出版社版本
4. 題目所屬講義/考卷的頁碼與題目敘述
5. 學生錯誤答案與正確答案

若資料不完整，先請對方補充題目內容，再進行分類。

# 分類流程
## 1. 先把錯題逐筆轉成可分析的資料
對每一題建立一列，至少包含：
- 學生姓名或代號
- 題目來源（小考名稱、單元、頁碼、題號）
- 題目內容摘要
- 正確答案
- 學生錯誤答案
- 你初步判斷的錯誤原因（若看得出來）

## 2. 以「觀念」而不是「題型表面」分類
分類時優先看題目考的是哪個核心觀念，例如：
- 整數、分數、小數運算
- 乘除法與分配律
- 一元一次方程式
- 比與比例
- 正負數運算
- 平面幾何與角度
- 圖形面積與體積
- 資料統計與平均數
- 因數倍數與質因數分解
- 數線、座標平面
- 應用題建模

如果一題同時涉及多個觀念，選**最主要導致失分的那個觀念**作主分類，其他列為副分類。

## 3. 為每題標記錯誤類型
除了觀念分類，也要記錄錯誤型態，方便教學：
- 觀念不懂
- 計算失誤
- 題意看錯
- 漏條件
- 單位錯誤
- 步驟不完整
- 公式誤用
- 解題策略錯誤

同一觀念若多數人都屬於「觀念不懂」，代表該觀念值得優先補。

## 4. 彙整同觀念的錯題
把相同觀念的題目聚在一起，觀察：
- 哪一觀念出現最多
- 哪一觀念分布在最多學生身上
- 哪一觀念重複出現在不同小考
- 哪一觀念常伴隨同一種錯誤型態

## 5. 排出下次上課優先順序
優先順序建議依下列規則：
1. 全班出現次數最多的觀念
2. 涉及基礎先備能力、會影響後面很多單元的觀念
3. 多數學生都屬於「觀念不懂」而非單純計算失誤
4. 同一觀念跨多次考試持續出錯
5. 你上課可以用短時間講清楚、立即改善的觀念

# 建議輸出格式
請輸出成以下四個區塊：

## A. 觀念分類表
每列包含：
- 題目來源
- 題目摘要
- 主要觀念
- 副分類
- 錯誤類型
- 備註

## B. 觀念統計
列出每個觀念：
- 出現次數
- 涉及學生數
- 重複出現的小考次數
- 主要錯誤型態

## C. 優先補救清單
依優先順序列出：
1. 觀念名稱
2. 為什麼優先
3. 建議先講的重點
4. 可以怎麼快速複習

## D. 教學提醒
整理出：
- 哪些觀念是基礎卡關點
- 哪些是題目閱讀問題
- 哪些只是粗心但反映熟練度不足

# 分類時的判斷原則
- 不要只看題目形式，要看學生到底卡在哪個數學概念。
- 題目若看似不同但本質相同，要合併分類。
- 題目若看似相同但考點不同，要分開。
- 若無法確定，先標為「待確認觀念」，並列出需要補充的資訊。

# 如果資料很多
當錯題數量很多時，先做這三步：
1. 先粗分成大單元
2. 再細分成觀念小類
3. 最後挑出出錯最多的前 3 到 5 類先處理

# 你可以直接這樣整理給我
若要我幫你分類，請把資料整理成類似以下格式：
- 小考1，第3題：……，學生A錯答……，正解……
- 小考1，第5題：……，學生B錯答……，正解……
- 小考2，第2題：……，學生A、C、D都錯在……

# 限制
如果只有題號、沒有題目內容，或沒有足夠上下文，無法可靠判斷觀念分類；此時只能先做「疑似單元整理」與「需要補資料清單」，不能直接下結論。
