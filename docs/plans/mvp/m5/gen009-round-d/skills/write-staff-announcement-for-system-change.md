# 目的
協助撰寫一封面向全體同仁的公告，說明請假系統即將更換的原因、時程與同仁需要配合的事項，語氣要清楚、好懂、像通知而不是法條。

# 寫作原則
- 先講重點，再補細節。
- 用短句、白話、段落分明的方式寫，避免過度正式或法律式措辭。
- 明確交代三件事：
  1. 為什麼要換
  2. 什麼時候換
  3. 同仁要做什麼
- 若資訊不足，先向發信者確認，不要自行編造日期、流程或責任單位。

# 撰寫步驟
1. 先整理公告必要資訊：
   - 新系統名稱
   - 上線日期、切換時間點
   - 舊系統停用時間
   - 更換原因（例如：操作更直覺、流程整合、手機可用、提升效率等）
   - 同仁需要做的事（例如：登入新系統、重設密碼、完成資料確認、在期限前送出申請等）
   - 若有暫停服務時段、影響範圍、聯絡窗口，一併確認

2. 用以下結構起草公告：
   - 標題：直接點出「請假系統更新通知」或類似說法
   - 開頭：一句話說明即將更換，讓大家先知道這件事
   - 第二段：用 2–3 點講清楚為什麼要換
   - 第三段：用清楚的時間線說明何時切換、何時停用舊系統
   - 第四段：列出同仁要完成的事項，最好條列
   - 結尾：提醒如有問題可找誰，並感謝配合

3. 寫作時注意：
   - 不要堆疊太多專有名詞
   - 不要用冗長被動句
   - 不要把重點藏在最後
   - 若涉及截止時間，請用明確日期與時點
   - 若有資安或帳號問題，提醒同仁留意官方管道，不要使用來路不明連結

# 建議語氣
- 親切、直接、尊重同仁時間
- 像「提醒大家」「請於○月○日前完成」這類表達，比「茲依規定」更適合
- 可以使用項目符號與小標題，提高可讀性

# 建議範本結構
## 標題
請假系統更新通知：

## 內文
各位同仁大家好：

為了【更換原因】，公司將於【日期時間】起啟用新的請假系統，並於【日期時間】停用舊系統。

這次更新主要是為了【原因 1】、【原因 2】、【原因 3】。

請大家於【日期】前完成以下事項：
- 【事項 1】
- 【事項 2】
- 【事項 3】

若在使用上有任何問題，請聯繫【單位／窗口／聯絡方式】。

謝謝大家的配合。

# 成品檢查清單
- 是否有說明換系統的原因
- 是否有清楚寫出切換時間
- 是否有列出同仁要做的事情
- 是否避免過度官腔與法律式語氣
- 是否容易快速掃讀

# 若資訊不足時的處理
如果缺少關鍵資訊，先向使用者確認以下內容再寫：
- 新系統名稱
- 上線與停用日期
- 更換原因
- 同仁需完成的步驟與截止時間
- 聯絡窗口

在未確認前，不要直接產出看似完整但其實含糊的公告。
