# 目的
當你被丟來一份「先看一下」的表格檔，且目前不知道內容、欄位意義或分析目標時，先做最小但有用的探索：確認檔案型態、大小、欄位數、資料型態、缺漏、重複與前幾列長相。

# 先做的事
1. **先確認檔案是什麼格式**：CSV、TSV、Excel、JSON、Parquet、文字表格等。
2. **先看整體輪廓**：
   - 列數、欄數
   - 欄位名稱
   - 每欄資料型態
   - 缺漏值分布
   - 重複列或明顯唯一鍵候選
3. **抽樣看內容**：
   - 前 5 列
   - 隨機 5 列
   - 最後 5 列（如果有順序意義）
4. **找出異常**：
   - 混合型態欄位
   - 日期/數值被存成字串
   - 看起來像 ID、時間、金額、分類、描述欄
   - 空白欄或幾乎全空欄

# 建議流程
## 1. 確認資料結構
先回答這些問題：
- 檔案總共有幾列、幾欄？
- 欄位名稱有哪些？是否有重複欄名？
- 是否存在索引欄或不必要的匯出欄（例如 `Unnamed: 0`）？
- 是否每列都是同一種紀錄？

## 2. 看欄位概況
對每個欄位整理：
- 資料型態
- 非空值數量
- 缺漏比例
- 唯一值數量
- 最常見值
- 範例值 3–5 個

這一步的目的是判斷欄位屬於：
- 連續數值
- 類別
- 日期時間
- 識別碼
- 自由文字

## 3. 看資料樣貌
輸出幾種樣本：
- 前幾列：看格式
- 隨機列：看是否有不同樣態
- 最後幾列：看是否有尾端摘要、合計列、附註列

## 4. 找出值得優先關注的欄位
優先標記：
- 缺漏最多的欄位
- 唯一值很多的欄位（可能是 ID）
- 唯一值很少的欄位（可能是分類）
- 名稱含 `date`、`time`、`id`、`code`、`amount`、`price`、`total`、`status`、`name`、`desc` 等字樣的欄位

## 5. 產出一份「先看一下」摘要
摘要至少包含：
- 檔案類型
- 列/欄數
- 欄位清單
- 每欄概略型態與缺漏情況
- 3–5 個你覺得最值得繼續追的欄位
- 任何明顯的清理問題或可疑點

# 如果你已經能讀檔
如果可用工具支援讀取檔案，就直接做探索性摘要，不要先假設資料內容。

# 如果你不能直接讀檔
就先回覆你需要的最基本資訊：
- 檔案格式
- 是否有分隔符號
- 前 20 列內容
- 欄位名稱（如果有）

然後告訴對方：你會先幫他判斷資料長相，再決定下一步怎麼看。
