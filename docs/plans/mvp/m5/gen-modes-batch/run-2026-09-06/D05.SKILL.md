# 新人到職流程

依照流程圖，這個技能的任務是把「收到新人到職通知」後的到職作業按順序執行或整理成可執行清單。不要自行增減流程；若某一步缺少必要資訊，只能先補齊資訊再往下做。

## 執行順序

1. **收到新人到職通知**
   - 確認通知內容包含新人姓名、到職日、部門、職稱、主管與聯絡方式。
   - 若資訊不完整，先向發送通知的人或 HR 補齊。

2. **建立公司信箱**
   - 為新人建立公司電子郵件帳號。
   - 確認帳號命名符合公司規則，並可正常收發信。
   - 記錄信箱資訊，供後續通知與系統設定使用。

3. **加入 Slack 頻道**
   - 將新人加入需要的 Slack 頻道。
   - 至少確認已加入團隊公告、部門與新人相關頻道。
   - 若 Slack 權限或邀請失敗，先排除帳號或權限問題。

4. **準備筆電與門禁卡**
   - 準備新人使用的筆電、必要配件與門禁卡。
   - 確認設備可開機、可登入、可連網，門禁卡可正常使用。
   - 若設備尚未到位，先追蹤採購或 IT 配發狀態。

5. **安排第一週訓練**
   - 安排新人第一週的訓練內容與時程。
   - 包含必要的系統介紹、工作流程、部門規範與安全事項。
   - 將訓練時間通知新人與相關講師。

6. **指派導師**
   - 指派一位導師或 buddy 協助新人適應。
   - 確認導師知道自己的角色、支援範圍與聯絡方式。
   - 將導師資訊告知新人與主管。

7. **第 30 天面談**
   - 安排新人到職第 30 天的面談。
   - 準備面談重點：適應狀況、工作進度、問題與支援需求。
   - 確認主管、導師與新人都知道面談時間。

8. **記錄到人資系統**
   - 將以上到職處理結果與關鍵資訊記錄到人資系統。
   - 確認資料完整、可追蹤，並保留必要的處理紀錄。

## 注意事項

- 必須依照流程圖順序執行，不可跳步。
- 若某一步需要外部資源或權限，先確認可用性，再進行下一步。
- 若流程圖與實際公司制度衝突，以公司正式制度為準，但仍需保留這個流程的順序作為基礎。
