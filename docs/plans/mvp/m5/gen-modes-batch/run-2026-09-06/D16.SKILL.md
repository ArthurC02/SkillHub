# 房客回報設備故障處理流程

依照下列流程處理房客回報的設備故障：

1. **接收回報**
   - 先確認房客回報的故障內容與位置。
   - 判斷是否屬於會**影響水電安全**的問題。

2. **判斷是否影響水電安全**
   - **如果是**：
     1. **24 小時內派人**處理。
     2. 安排後續維修。
   - **如果否**：
     1. **一週內安排維修**。

3. **維修後處理**
   - 維修完成後，**拍照記錄修繕結果**。
   - 將修繕情況與照片整理存檔。

4. **更新紀錄**
   - **更新房屋維修紀錄表**。
   - 確認紀錄包含：回報內容、是否影響水電安全、派工/維修時間、修繕結果與照片。

## 執行原則
- 若判斷不明確，先以是否可能影響住戶安全與供水供電穩定為優先考量。
- 所有案件都要完成「拍照記錄修繕結果」與「更新房屋維修紀錄表」兩個步驟。
