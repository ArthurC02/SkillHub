# 依照流程圖執行差旅費用流程

依照圖中的順序處理，不要跳步：

1. **確認出差日期**
   - 先確認出差的起訖日期與行程是否已定案。
   - 若日期未確定，先完成日期確認再往下進行。

2. **訂高鐵票**
   - 在出差日期確認後，安排高鐵車票訂購。
   - 訂票內容應與出差日期、班次需求一致。

3. **訂 2 晚飯店**
   - 依出差行程預訂 2 晚住宿。
   - 住宿日期應與出差期間相符。

4. **申請預支 8000 元**
   - 依流程提出預支申請，金額為 8000 元。
   - 申請時保留申請紀錄或核准資訊。

5. **保留所有收據**
   - 將交通、住宿及其他相關支出收據完整保存。
   - 收據需可對應到此次出差費用。

6. **回來 5 天內報帳**
   - 出差結束後，必須在 5 天內完成報帳。
   - 報帳時整理所有單據、收據與必要證明文件。

7. **歸還公司信用卡**
   - 報帳完成後，將公司信用卡歸還。
   - 若信用卡有簽帳或待結清項目，先確認已處理完畢再歸還。

## 執行原則
- 嚴格依照箭頭順序執行。
- 若前一步未完成，不要進入下一步。
- 若需要對外說明，使用與流程圖一致的簡短步驟描述。
