# Python 候選人篩選流程

依照流程圖執行以下步驟：

1. **收到履歷**
   - 先取得候選人的履歷並完成初步閱讀。

2. **判斷是否有 Python 經驗**
   - 檢查履歷中是否明確出現 Python 相關經驗、專案、工作內容或技能描述。
   - 只要能合理確認有 Python 經驗，就視為「是」。
   - 若無法確認，或履歷未顯示 Python 經驗，就視為「否」。

3. **如果答案是「是」**
   - 安排 **45 分鐘視訊面談**。
   - 面談後，**寄出作業題**。

4. **如果答案是「否」**
   - **寄出婉拒信**。

5. **執行原則**
   - 不要跳過判斷步驟。
   - 不要在「否」的情況下安排面談或寄出作業題。
   - 不要在「是」的情況下直接婉拒，除非後續另有明確流程要求。

如果履歷內容不足以判斷是否有 Python 經驗，先將其歸為「否」並寄出婉拒信。
