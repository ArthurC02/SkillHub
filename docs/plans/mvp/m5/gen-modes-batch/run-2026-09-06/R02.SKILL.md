## 目標
將 Excel 客戶名單去除重複，並標記缺少電話的列。

## 適用情況
- 來源是 Excel 工作表或可匯入 Excel 的表格資料。
- 需要保留唯一客戶資料，並找出電話欄位空白或缺值的列。

## 執行步驟
1. **先確認欄位結構**
   - 找出哪一欄是客戶識別依據，通常是「客戶名」、「公司名」、「Email」、「電話」或其組合。
   - 找出電話欄位名稱；若有多個電話欄位，先確認要檢查哪一個作為主要電話欄。
   - 若欄位名稱不明確，先根據資料內容判斷，再用最合理的欄位作為依據。

2. **備份原始資料**
   - 在不覆蓋原始工作表的前提下，先複製一份工作表或另存新檔。
   - 後續所有修改都在副本上進行。

3. **去除重複資料**
   - 以最能代表同一客戶的欄位組合作為去重依據。
   - 若只有單一明確識別欄位，使用該欄位去重。
   - 若單一欄位不足以判斷，優先使用「姓名 + 公司名」或「Email + 電話」等組合。
   - 去重前先確認是否要保留第一筆、最新一筆，或資料最完整的一筆；若無額外規則，保留第一筆出現的資料。
   - 去重後檢查筆數是否合理，並確認沒有把不同客戶誤刪。

4. **標記缺少電話的列**
   - 檢查電話欄是否為空白、只有空格、只有符號、或明顯不是有效電話內容。
   - 新增一欄，例如「電話狀態」或「缺少電話」，用來標記。
   - 對電話缺值的列標記為「缺少電話」或「是」；有電話的列標記為「正常」或「否」。
   - 若資料中有多種電話格式，僅要判斷是否有內容，不必強制格式化，除非使用者另外要求。

5. **檢查結果**
   - 確認去重後的總筆數。
   - 確認缺少電話的列數。
   - 抽查幾筆重複資料與缺電話資料，確認標記正確。

6. **輸出或保存**
   - 將結果保存為新的 Excel 檔或新的工作表。
   - 若需要回報，簡短說明：原始筆數、去重後筆數、缺少電話筆數。

## 注意事項
- 不要在未確認欄位意義前，直接以整列完全相同作為唯一去重方式；客戶名單常有部分欄位不同但仍屬同一客戶。
- 若資料中有空白列、合併儲存格或多層標題，先整理成單一標題列再處理。
- 若無法判斷哪個欄位代表電話，先列出可疑欄位並請求確認，而不要自行猜測。
