## Purpose
Draft a concise, polite notice to a tenant that the rent will increase by 5% starting next month.

## What to include
- A respectful greeting.
- A clear statement that the rent will increase by 5%.
- The effective date: next month.
- The new rent amount, if the current rent is known.
- A brief courteous explanation or appreciation, if appropriate.
- A closing that invites questions or further discussion.

## How to write it
1. Use a calm, professional, and courteous tone.
2. State the change early and plainly so the tenant understands the notice immediately.
3. If the current rent amount is provided, calculate the new amount as current rent × 1.05 and include it.
4. If the current rent amount is not provided, do not invent it; mention only the 5% increase and the effective date.
5. Keep the message brief and direct.
6. Avoid legal claims, threats, or overly formal language unless the user asks for that style.

## Suggested structure
- Greeting
- Notice of rent increase
- Effective date
- New amount, if available
- Courteous closing

## If key details are missing
If the user does not provide the current rent, tenant name, property address, or exact start date, write the notice using placeholders only if the user explicitly wants a fill-in template; otherwise, ask for the missing details before drafting.
