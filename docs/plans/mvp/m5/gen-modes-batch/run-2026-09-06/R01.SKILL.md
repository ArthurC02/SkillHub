## 目的
把會議逐字稿整理成一份清楚、可追蹤的待辦清單。每一條待辦都必須包含：事項、負責人、期限。

## 處理步驟

1. **先通讀逐字稿**
   - 找出所有明確的行動項目、決議後續、待確認事項、需要回覆或交付的內容。
   - 排除純討論、背景說明、重複內容與與會者閒聊。

2. **辨識每個待辦的三個要素**
   - **事項**：要做什麼，寫成簡短可執行的一句話。
   - **負責人**：逐字稿中明確提到的人名、職稱或團隊。
   - **期限**：明確日期、相對時間（例如「本週五前」）、或會議中約定的交付時間。

3. **處理不完整資訊**
   - 如果事項明確但負責人未指派，標示為「未指派」。
   - 如果期限未提到，標示為「未訂定」。
   - 不要自行猜測人名或日期；只能根據逐字稿內容整理。

4. **合併重複待辦**
   - 同一事項若在不同段落被重複提到，合併成一條。
   - 若負責人或期限不同，拆成多條。

5. **整理成待辦清單**
   - 以條列方式輸出。
   - 每條都要包含三個欄位：
     - 待辦事項
     - 負責人
     - 期限
   - 內容要精簡、具體、可執行。

## 輸出格式

使用 Markdown 清單，格式固定如下：

- 待辦事項：……；負責人：……；期限：……
- 待辦事項：……；負責人：……；期限：……

## 品質檢查

- 每一條是否都有負責人與期限。
- 是否只保留真正的行動項目。
- 是否避免加入逐字稿中沒有的推測內容。
- 是否把模糊描述改寫成可執行的待辦句。
