## 目的
每週從三個 Slack 頻道中找出「尚未回覆的問題」，整理成可直接分享的清單，並附上每則訊息的連結。

## 適用情境
- 需要做每週 Slack 問題盤點
- 需要從固定三個頻道中找出未被回覆的提問
- 需要輸出可點擊連結的整理結果

## 先確認的資訊
如果以下資訊未提供，先向使用者確認：
1. 三個 Slack 頻道名稱或連結
2. 統計週期的範圍（例如：上週一到週日，或最近 7 天）
3. 「未回覆」的判定方式：
   - 嚴格版：該訊息下沒有任何回覆串
   - 寬鬆版：回覆串中沒有實質回答，只是表情或確認
4. 輸出語言與格式偏好（若未指定，使用繁體中文）

## 判定規則
1. 只收錄「問題」：通常是問句、請求協助、徵詢意見、需要確認的訊息。
2. 只收錄「未回覆」：
   - 優先以訊息串是否有回覆判定
   - 若有回覆但都不是回答問題，依使用者指定的寬鬆版處理
3. 排除以下內容：
   - 明顯已被回答的問題
   - 純公告、純閒聊、純轉貼
   - 不是問題的陳述句
4. 若同一人連續發多則相近問題，保留每則獨立訊息，除非使用者要求合併。

## 作業步驟
1. 逐一檢視三個頻道在指定週期內的訊息。
2. 找出符合「問題」特徵的訊息。
3. 檢查每則問題是否有回覆串：
   - 沒有回覆串 → 收錄
   - 有回覆串但未解答 → 依規則與使用者偏好決定是否收錄
   - 有明確解答 → 不收錄
4. 為每則收錄項目整理以下欄位：
   - 頻道名稱
   - 發問者
   - 問題摘要
   - 發問時間
   - 訊息連結
5. 依頻道分組，或依時間排序；若使用者未指定，採時間由新到舊排序。

## 輸出格式
使用清單格式，每則一行，包含可辨識資訊與連結：

- [頻道名] 發問者｜問題摘要｜時間｜<連結>

若需要更清楚，可在每個頻道下分段：

### #頻道名
- 發問者｜問題摘要｜時間｜<連結>

## 品質檢查
- 確認每個連結都指向正確的 Slack 訊息
- 確認沒有把已回覆的問題誤列進來
- 確認摘要保留原意，不捏造答案
- 若某則訊息是否算「問題」不明確，標註為「待確認」而不是自行判定

## 限制
此技能只負責整理與判定，不負責登入 Slack、抓取資料或存取你沒有權限的內容。若沒有可用的訊息匯出、搜尋結果或已提供的訊息內容，先請使用者提供資料。
