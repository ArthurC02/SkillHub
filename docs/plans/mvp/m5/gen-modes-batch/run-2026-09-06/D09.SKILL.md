# Weekly leadership update

Follow the flow in order:

1. **Pull numbers from Google Sheets**
   - Open the relevant Google Sheet and identify the current week’s numbers.
   - Capture the matching numbers from last week so the comparison is consistent.
   - If the sheet has multiple tabs or sections, use the one designated for the weekly leadership metrics.

2. **Compare with last week**
   - Calculate the week-over-week change for each key metric.
   - Note whether each metric is up, down, or flat.
   - Focus on the most important changes, not every minor fluctuation.

3. **Write three bullet highlights**
   - Write exactly three concise bullets.
   - Each bullet should state one meaningful takeaway from the comparison.
   - Prefer bullets that mention direction, magnitude, and business meaning.
   - Keep the tone executive-friendly and brief.

4. **Attach the chart PNG**
   - Create or select the chart that best summarizes the weekly comparison.
   - Export it as a PNG file.
   - Ensure the chart is readable and clearly labeled before attaching it.

5. **Post in #leadership**
   - Prepare the final update with the three bullets and the chart PNG attached.
   - Post it in the #leadership channel.
   - If posting is not possible because the required app, permissions, or login are unavailable, stop and report that the final posting step cannot be completed.

## Output quality checks
- The update should be based on the latest sheet data and the immediately preceding week.
- The three bullets should be distinct and non-overlapping.
- The chart should support the bullets, not repeat them verbatim.
- Do not invent numbers; if data is missing, identify what is missing and ask for it before posting.
