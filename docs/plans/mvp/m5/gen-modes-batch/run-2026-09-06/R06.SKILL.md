## 目標
把整份英文使用手冊翻成自然、準確的繁體中文，保留原有結構、標題、編號、表格與警告格式；所有專有名詞在第一次出現時附上原文。

## 翻譯原則
1. **忠實優先**：先確保技術含義、操作步驟、警告與限制條件完全正確，再追求文句順暢。
2. **繁體中文**：全文使用繁體中文，不混用簡體。
3. **保留版面結構**：維持原手冊的章節、段落、清單、表格、註解、圖說、按鈕名稱與步驟順序。
4. **專有名詞首次附原文**：
   - 第一次出現時寫成「中文譯名（Original Term）」或「Original Term（中文譯名）」；全文後續統一使用中文譯名。
   - 若原文本身就是品牌、型號、介面名稱、功能名稱或不可翻譯的術語，保留原文，必要時加中文說明。
5. **一致性**：同一術語、按鈕、選單、錯誤訊息、單位與縮寫在全文保持一致。
6. **不可擅改內容**：不要自行補充未出現的資訊，不要刪減步驟，不要改變警告等級或操作順序。

## 工作流程
1. **先通讀全文**，辨識：
   - 章節結構
   - 重複術語
   - 專有名詞、產品名、功能名、介面名
   - 警告、注意、提示、前置條件
2. **建立術語對照**：
   - 找出全文重複出現的關鍵詞，先決定固定譯法。
   - 對於不確定是否應翻譯的詞，優先保留原文並加簡短中文說明。
3. **逐段翻譯**：
   - 句子要符合繁中技術文件語氣。
   - 操作步驟用清楚、直接的動詞。
   - 若原文是命令式，譯文也維持命令式。
4. **處理專有名詞**：
   - 第一次出現時加原文括註。
   - 若同一頁或同一節已出現過，後續只用中文譯名或原文固定形式。
5. **保留格式元素**：
   - 標題層級不變。
   - 編號、項目符號、表格欄位、程式碼區塊、按鍵標示、路徑、錯誤碼、單位與數值格式盡量維持原樣。
   - 若原文有 UI 路徑，翻譯時保留層級關係，例如「設定 > 網路 > Wi‑Fi」。
6. **檢查一致性與完整性**：
   - 確認沒有漏譯段落、表格列或註解。
   - 確認首次出現的專有名詞都有附原文。
   - 確認警告、注意事項與限制條件沒有被弱化。

## 專有名詞處理規則
- **產品/品牌/型號**：通常保留原文，必要時加中文說明，不強行翻譯。
- **功能/介面/選單名稱**：可翻譯，但首次出現需附原文。
- **技術術語**：若有通行譯法，採通行譯法；若無，保留原文並加說明。
- **縮寫**：首次出現時寫全名加縮寫，之後只用縮寫或固定譯名。

## 輸出要求
- 只輸出翻譯後的繁體中文手冊內容。
- 不要加入翻譯說明、註解、審校備註或額外摘要。
- 若原文有頁首頁尾、版權聲明或目錄，依原樣翻譯並保留位置與順序。
