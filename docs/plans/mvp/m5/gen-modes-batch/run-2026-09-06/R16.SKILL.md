## 目的
將 3 份供應商報價單整理成一張可直接閱讀的比較表，重點比較**單價**與**交期**，並根據比較結果提出建議。

## 適用情境
- 使用者提供 3 份供應商報價單（文字、圖片、PDF 內容摘要皆可）。
- 需要快速看出各供應商在單價與交期上的差異。
- 需要在表格後給出簡短、可執行的採購建議。

## 先確認的資訊
若報價單內容不完整，先整理並向使用者確認以下項目：
1. 品名／型號是否相同，是否可直接比較。
2. 單價的幣別與計價單位（例如：每件、每箱、每公斤）。
3. 交期的定義（例如：下單後幾天、工作天、自然日、現貨）。
4. 是否含稅、運費、包裝費、最低訂購量等會影響比較的條件。

若三份報價單的計價單位或交期定義不同，先註明差異，必要時不要直接下結論，改為說明「不可直接比較」或「需先換算後比較」。

## 比較步驟
1. 逐份讀取報價單，擷取：
   - 供應商名稱
   - 品名／型號
   - 單價
   - 幣別
   - 計價單位
   - 交期
   - 其他影響採購的條件（如稅、運費、MOQ、付款條件）
2. 若單價幣別不同，先保留原幣別；只有在使用者明確要求時才換算。
3. 若交期寫法不同，統一成同一種表述方式：
   - 例如「7 個工作天」、「14 天」、「現貨 2 天內出貨」。
4. 找出：
   - 最低單價
   - 最短交期
   - 是否存在單價低但交期長、或單價高但交期短的取捨
5. 根據比較結果提出建議，優先考量順序如下：
   - 若使用者未指定偏好，先以**總成本與交期平衡**為原則。
   - 若某供應商單價最低且交期也合理，優先推薦。
   - 若交期是關鍵，優先推薦交期最短者，即使單價略高，也要說明原因。
   - 若資訊不足以判斷，明確說明缺少哪些資料。

## 輸出格式
輸出一張比較表，欄位建議如下：
- 項目
- 供應商 A
- 供應商 B
- 供應商 C

列項目至少包含：
- 品名／型號
- 單價
- 幣別／單位
- 交期
- 其他條件
- 備註

## 建議寫法
表格後用 2 到 4 句話給出建議，內容要包含：
- 哪一家在單價上最有優勢
- 哪一家在交期上最有優勢
- 若兩者不同，說明取捨
- 若有風險或不確定性，提醒使用者再確認

## 注意事項
- 不要自行補齊報價單沒有提供的數字。
- 不要把不同規格、不同數量、不同交貨條件的報價直接當成完全可比。
- 若報價單內容有歧義，先標示「待確認」，不要硬下結論。
- 若使用者只提供部分資訊，先做已知部分的比較，再列出缺漏項目。
