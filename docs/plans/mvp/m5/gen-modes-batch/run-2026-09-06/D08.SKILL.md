# 目的
依照流程圖處理收到的英文 PDF：先判斷頁數是否超過 20 頁；若超過，先拆成多個段落分批處理；接著翻譯成繁體中文；最後檢查專有名詞表並輸出 Word 檔。

# 執行步驟
1. **接收英文 PDF 文件**
   - 確認輸入是英文 PDF。
   - 若不是 PDF、不是英文內容，或檔案無法讀取，先回報問題，不要直接翻譯。

2. **判斷頁數是否超過 20 頁**
   - 取得 PDF 總頁數。
   - 若頁數 **不超過 20 頁**，直接進入翻譯。
   - 若頁數 **超過 20 頁**，先拆分成多個可管理的段落或批次，再逐批處理。

3. **拆成多個段落分批處理（僅在超過 20 頁時）**
   - 依頁面順序切分，保持章節、表格、圖說與註腳的上下文。
   - 每批以能維持翻譯品質為準，不要切斷標題、表格或句子。
   - 為每批保留原始頁碼或段落對應，方便後續整合。

4. **翻譯成繁體中文**
   - 將全文翻譯為繁體中文。
   - 保留原文的結構、標題層級、列表、表格與引用格式。
   - 專有名詞、產品名、機構名、法規名、縮寫等先保持一致，不要任意改寫。
   - 若遇到無法確定的術語，先採用最保守且一致的譯法，並在後續專有名詞檢查時統一。

5. **檢查專有名詞表**
   - 建立或對照專有名詞表，確認全文譯名一致。
   - 檢查以下項目是否前後一致：
     - 人名、地名、公司名、產品名
     - 技術術語、縮寫、法規與標準名稱
     - 圖表標題、章節名稱、附註中的關鍵名詞
   - 若發現不一致，回到翻譯內容修正，直到一致為止。

6. **輸出 Word 檔**
   - 將完成的繁體中文內容整理成 Word 文件。
   - 保留原始文件的主要版面結構：標題、段落、清單、表格、註解與頁碼資訊（若可保留）。
   - 檔名應能辨識為「英文 PDF 的繁體中文譯本」或相近名稱。

# 產出要求
- 最終輸出為 **Word 檔**。
- 內容應為 **繁體中文**。
- 若文件超過 20 頁，必須先分批處理再整合輸出。
- 專有名詞需經過一致性檢查。
