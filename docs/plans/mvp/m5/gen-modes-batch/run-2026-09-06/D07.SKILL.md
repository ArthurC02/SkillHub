# 冰箱食材與採買流程

依照流程圖執行以下步驟：

1. **確認冰箱剩餘食材**
   - 先盤點冰箱內現有食材。
   - 記錄可用食材、數量與保存狀態。
   - 以即將過期或最需要優先使用的食材為優先。

2. **規劃一週 7 天菜單**
   - 根據現有食材安排 7 天的餐點。
   - 盡量讓菜單能消耗冰箱內食材，並補足不足的部分。
   - 確認每天需要的主食、蛋白質、蔬菜與調味材料。

3. **列出採買清單**
   - 將菜單中缺少的食材整理成採買清單。
   - 合併重複項目，標示數量與規格。
   - 優先列出必買項目，再列出可替代項目。

4. **到全聯採買**
   - 依採買清單購買所需食材。
   - 購買時核對數量、品質與保存期限。
   - 若現場缺貨，選擇可替代品或回頭調整菜單。

5. **分裝冷凍**
   - 將採買回來的食材依每餐或每次使用量分裝。
   - 標示內容、日期與份量。
   - 放入冷凍保存，方便後續依 7 天菜單取用。

如果無法確認冰箱食材、菜單需求或採買項目，先補齊這些資訊再繼續。
