# ADR-051：便宜 21 倍的那個模型產出更好——生成的預設改為 mini

- 狀態：Accepted
- 日期：2026-08-23
- 修訂：[ADR-047](./ADR-047-generation-path-rulings-retry-truncation-and-quota.md) 決策 5（改變預設模型；該決策的另一半「生成與 Run 分開計額度」不變）
- 依據：[m5/report-generate-baseline.md](../plans/mvp/m5/report-generate-baseline.md)（B 輪 20 次 ＋ mini 20 次，閘道實付 $2.4820）
- 相關：[ADR-017](./ADR-017-model-gateway-and-llm-observability.md)、`PDM-003`（試跑預設是 mini 級）、[ADR-048](./ADR-048-not-every-blocking-finding-is-a-random-slip.md)、`02:GEN-001`

## 背景：ADR-047 決策 5 自己寫好了解鎖條件

該決策逐字是：

> **預設維持 flagship，不現在改 mini。** 手上只有 flagship 的一個數（16／20），沒有 mini 的任何數。**用沒量過的東西省錢，省下來的是錢，賠掉的是那個數字的意義。**
>
> **`GEN-009` 完整版增加一組 mini 級對照。** 如果 mini 夠用，成本降一個量級，那是一個值得買的數字；買它的方式是量，不是猜。

**量完了，而結果比「夠用」強得多。**

| | flagship（A＋B 兩輪平均） | **mini** |
| --- | --- | --- |
| 通過 `skillpkg.Validate` | 16／20（80%） | **19／20（95%）** |
| 每次成本 | $0.1186 | **$0.00553**（**21.4 倍**） |
| completion token 中位數 | 3571 | 1023 |
| 本文長度中位數 | 3122 runes | 2440 runes |

## 決策 1：生成的預設模型改為 `gpt-5.4-mini`

**便宜的那個在唯一量過的維度上更好，而且不是差一點。**

通過率的差異有一個看得懂的機制，不是運氣：**兩個模型的失敗全部落在 frontmatter 的鍵名上**——多一個空格、黏一個阿拉伯字母、把 `description` 寫成 `说明`。那是生成層的字元級瑕疵，而 mini 每次少寫 3.5 倍的 token。**寫得少，弄壞的機會就少。** 這不是「mini 比較聰明」，是暴露面比較小——但對這個用途來說，那正是我們要的性質。

模型以 `GENERATE_SKILL_MODEL` 環境變數注入，預設 `gpt-5.4-mini`，形狀與 `JUDGE_MODEL`／`ENRICH_MODEL`／`SUGGEST_CRITERIA_MODEL` 一致（`apps/llm`）。切回 flagship 是改一個值，不是改程式。

**與 PDM-003 一致**：試跑的預設本來就是 mini 級。生成沒有理由比試跑更貴。

## 決策 2：**記下 mini 不寫腳本，而且不假裝知道那是好是壞**

mini **20／20 都只產出一個檔案**；flagship 兩輪各有 6／20 產出多檔（Python 與 shell 腳本）。

抽樣讀過 mini 的產出，它不是被砍短的 flagship——frontmatter 完整、`compatibility` 有加引號、本文是可執行的步驟說明。**它是一份好的純指示型 Skill。**

**但「帶腳本的 Skill 是否比純指示的 Skill 更有用」，本批一個字都沒量到。** 兩組在那件事上同樣未知，因為那要靠試跑與人（`GEN-009` ③④）。

所以這一條**不是**決策 1 的但書，它是一個具名的未知：**如果 `GEN-009` ③④ 顯示帶腳本的產出明顯更有用，決策 1 要重開。** 寫在這裡，免得日後有人拿「mini 通過率高」當成它產出更好的證據——**它證明的只有它比較不會弄壞 frontmatter。**

## 決策 3：重試之後仍有殘餘失敗，**不得對外表述為「幾乎一定會成功」**

ADR-047 決策 1 的重試規則不變，但它的理由要換：實測 **6／20 的描述至少失敗一次，2／20 兩輪都失敗**。把兩輪當兩次抽樣，一次重試把 80% 帶到 **90%**——**有用，但不是趨近於零**。

- 決策 1 原本的理由「缺陷是隨機的排版手滑」**只對一半**：具體的缺陷確實是隨機的（同一段描述兩輪的失敗碼不同），但**哪些描述會失敗不是均勻分布的**。
- **UI 不得在生成前承諾成功率**（同 `02:§2.2` 對「不得顯示沒被強制的承諾」的既有紀律）。
- **mini 的重試期望值未測**：mini 只跑了一輪。95% 之上重試一次會到哪裡，不知道，不得推估。

## 影響

### 正面

- 生成的單次成本從 $0.1186 降到 $0.00553。ADR-047 決策 5 擔心的「新路徑侵蝕試跑額度」**在量級上不再是問題**——它現在與一次試跑同級。
- 通過率同時上升，所以這不是一個取捨。

### 成本與限制

- **mini 不寫腳本**（決策 2）。這是本 ADR 最大的未知。
- **樣本仍然小**：mini 只有 20 次、一輪。95% 的信賴區間很寬。
- **`possible-secret` 在三輪 59 個套件裡 0 命中**（ADR-048 的規則仍是未觀測的分支）。換成 mini 之後它更不可能被觸發——mini 不寫腳本，而腳本是憑證樣式最可能出現的地方。**ADR-048 不撤回**（它守的是 fail-closed 方向，成本是一個 `if`），但它的狀態要誠實標成「未觀測」。
- **一個新的失敗形狀被觀測到，而 harness 抓不到它**：B 輪的 DAT-1 交出一份 **38 個字元**的 SKILL.md——語法正確、本文完全是空的。它這次是因為鍵名也壞了才被擋下來；**鍵名如果對，它會通過每一道檢查（08-24 補記：apps/llm 現已把空 body 直接拒絕為 malformed；見 `03` GEN-003）**。`02:GEN-004` 那句「沒有經過任何人工檢視、沒有任何試跑證據」因此不是禮貌用語，它是這個產品對那份 38 字元檔案唯一說得出口的話。
