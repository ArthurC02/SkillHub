# 更新驗收條件數量規則的來源引用

本提案只將既有「模型回覆最多 12 條驗收條件」規則的程式引用縮小到實際檢查函式，移除同一段中無關的案例檢查。規則敘述、Creation 所有權、同步一致性與測試引用均保留。

內部分類保存會修改鄰近的案例驗證程式，因此原先涵蓋兩個函式的引用已失效；目前限制仍由 `validateCriteria` 實作，既有 13 條拒絕測試也保留。本提案不修改模型、公開契約或政策。

引用檢查透過提案覆蓋層執行，原生工具已驗證提案；沿用既有已審查規則，沒有新增領域事實。正式套用透過持有提案的簽名提交與原生 `ship-package` 完成。分類是否符合案例語意及真模型品質仍屬其他驗收工作。
